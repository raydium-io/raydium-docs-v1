## Mevcut olanlar

| Yüzey | URL deseni | Ne zaman kullanılır |
|---|---|---|
| **MCP sunucusu** | `https://docs.raydium.io/mcp` | AI editörünüzün (Claude Code, Cursor, Windsurf vb.) Raydium dokümentasyonunu yerel olarak sorgulamasını ve alıntı yapmasını istiyorsunuz. |
| **`llms.txt` dizini** | `https://docs.raydium.io/llms.txt` | RAG ardışık düzeni oluşturuyor ve her sayfanın düz bir dizinine ihtiyacınız var. |
| **`llms-full.txt` gövdesi** | `https://docs.raydium.io/llms-full.txt` | Çevrimdışı dizinleme için tam külliyatı tek bir birleştirilmiş dosya olarak istiyorsunuz. |
| **Sayfa başına kopyalama menüsü** | Her gövde sayfasının üstündeki `Sayfayı kopyala` düğmesi | Bir sayfayı bir LLM sohbetine yapıştırıyorsunuz. |

`Sayfayı kopyala` düğmesi ve derin bağlantı menüsü her sayfanın sağ üstünde (sayfa başlığının yanında) bulunur. Her ikisi de dokümentasyon platformunun bağlamsal menüsü tarafından desteklenir.

## MCP sunucusu

MCP (Model Context Protocol) sunucusu, yapay zeka istemcilerinin Raydium dokümentasyonunu bir araç olarak sorgulamasına olanak tanır. Yapılandırıldıktan sonra, ajanınız "Raydium dokümentasyonunda `addLiquidity` parametrelerini ara" diyebilir ve yetkili yanıtlar alıntılanmış olarak geri alabilir.

### Claude Code

```bash
claude mcp add --transport http raydium-docs https://docs.raydium.io/mcp
```

Ekledikten sonra, Claude Code'a "Raydium dokümentasyonunda X'i ara" diyebilirsiniz ve aracı kullanacaktır.

### Cursor

Cursor ayarlarınıza ekleyin (`Cmd/Ctrl + ,` → MCP):

```json
{
  "mcpServers": {
    "raydium-docs": {
      "url": "https://docs.raydium.io/mcp"
    }
  }
}
```

### Windsurf, Continue, genel istemciler

Herhangi bir MCP uyumlu istemci `https://docs.raydium.io/mcp` adresine işaret edebilir. İstemciniz bir manifest gerektiriyorsa, `https://docs.raydium.io/mcp/.well-known/mcp.json` adresindedir.

### Sunucu ne ortaya koymaktadır

Raydium dokümentasyonu MCP sunucusu, sorgu için en yüksek sıralanmış pasajları ve bunların kanonik URL'lerini döndüren bir birincil araç olan `search_docs(query: string)` ortaya koymaktadır. Ajan, kullandığı URL'yi alıntı yapmaktan sorumludur; biz ajan başına izleme veya hız sınırlaması yapmayız.

## RAG için `llms.txt`

`llms.txt`, "makine tarafından okunabilir dokümentasyon dizini" için ortaya çıkan bir standarttır. Raydium yayınlar:

- `https://docs.raydium.io/llms.txt` — her sayfanın başlığı ve tek satırlık özeti ile düz bir liste, bölüm başına organize edilmiş.
- `https://docs.raydium.io/llms-full.txt` — her sayfanın tam Markdown gövdesi, birleştirilmiş, sayfa sınırları başlık olarak korunmuş.

`full` varyantı her dokümentasyon dağıtımında yeniden oluşturulur. Bunu bir programa göre çekin (günlük yeterlidir) veya isteğe bağlı olarak getirin.

```bash
# Tam külliyatı RAG alımı ardışık düzeninize bırakın.
curl -sSL https://docs.raydium.io/llms-full.txt -o raydium-docs.md
```

## Sayfa başına teslim menüsü

Her gövde sayfasının bağlamsal bir menüsü vardır (sağ üst, başlığın yanında) bu tek tıklamalı eylemlerle:

- **Kopyala** — sayfayı düz Markdown olarak kopyalayın.
- **Markdown olarak görüntüle** — kaynak `.md` dosyasını yeni bir sekmede açın, böylece kaydedebilirsiniz.
- **ChatGPT / Claude / Perplexity'de aç** — sayfa içeriğini adlandırılan araç için bir sohbet istemine önceden yükleyin.
- **Cursor / VS Code'da aç** — sayfa içeriği ile adlandırılan editörde bir arabellek açın.

Bu, MCP kurmadan tek bir sayfa hakkında bir modele soru sormak istediğinizde doğru yüzeydir.

## Kodlama ajanları için önceden oluşturulmuş bağlam dosyaları

Raydium ile entegre oluyorsanız ve ajanınızın baştan itibaren doğru temel bilgiye sahip olmasını istiyorsanız, bu dosyaları projenize bırakın:

### `.cursorrules` / `.windsurfrules` / ajan sistem istemi

```text
Solana DeFi protokolü olan Raydium ile entegre oluyorsunuz. Raydium'un beş ürün
yüzeyi vardır: AMM v4, CPMM, CLMM, Farm ve LaunchLab. Yetkili dokümentasyon
docs.raydium.io adresinde bulunur. Resmi SDK `@raydium-io/raydium-sdk-v2` dir
(doğruladığınız sürümü sabitleyin). Sunucu tarafından oluşturulan swaplar için,
transaction-v1.raydium.io adresindeki Trade API'yi tercih edin. Her zaman:

- Eşleşen bir `Connection` ve `cluster` geçirin.
- Tüm tutarları `BN` örnekleri olarak tutun; tutarlar üzerinde `.toNumber()` çağırmayın.
- ATA oluşturma kirası için kullanıcının cüzdanını önceden finanse edin.
- Yüksek hacimli pencereler içinde rekabet edebilecek herhangi bir tx için açık bir `computeBudgetConfig` geçirin.
- Yüksek değerli işlemlerden hemen önce `poolInfo` yeniden getirin; önbelleğe alınmış durum eski hale gelir.

Bir talimatın hesaplar listesi hakkında emin değilseniz,
`docs.raydium.io/products/<product>/accounts` ve zincir üstü IDL'ye başvurun.
```

`.cursorrules` (Cursor), `.windsurfrules` (Windsurf) veya `CLAUDE.md` (Claude Code) olarak kaydedin — veya ajanınızın sistem istemine yapıştırın. Tam dosya adı ve konumu araç sürümüne göre değişir, bu nedenle dosyayı otomatik olarak almıyorsa aracınızın ayarlar dokümentasyonunu kontrol edin.

### Sabitlenmiş bağlam listesi

Kodlama ajanları için "her zaman dahil et" sayfalarının bir listesini kabul edenler, bu liste çoğu Raydium entegrasyonu için minimum yararlı bağlamdır:

```text
https://docs.raydium.io/sdk-api/typescript-sdk
https://docs.raydium.io/sdk-api/trade-api
https://docs.raydium.io/products/cpmm/instructions
https://docs.raydium.io/products/clmm/instructions
https://docs.raydium.io/integration-guides/priority-fee-tuning
https://docs.raydium.io/reference/program-addresses
https://docs.raydium.io/reference/error-codes
```

Entegre ettiğiniz ürünlere göre ayarlayın.

## Dizinleme tarifi

Kendi RAG'inizi oluşturuyor ve `llms-full.txt` kullanmak istemiyorsanız, kanonik tarif şu şekildedir:

```ts
import { fetch } from "undici";

const INDEX_URL = "https://docs.raydium.io/llms.txt";
const BASE      = "https://docs.raydium.io";

const index    = await (await fetch(INDEX_URL)).text();
const pageUrls = [...index.matchAll(/^- \[(.+?)\]\((.+?)\)/gm)].map(m => m[2]);

for (const path of pageUrls) {
  const md = await (await fetch(`${BASE}${path}.md`)).text();
  // md'yi vektör deponuza yol ile anahtarlanmış olarak alın
}
```

Her sayfa, kanonik yolu ile `.md` soneki eklenerek sunulur (örn. `/sdk-api/typescript-sdk` → `/sdk-api/typescript-sdk.md`).

## Uyarılar

- **Özel durumu isteklere yapıştırmayın.** MCP sunucusu yalnızca genel dokümentasyonda olanları bilir. Cüzdan anahtarları, RPC kimlik bilgileri ve benzer sırlar asla ajan bağlamına girmemelidir.
- **AI çıktısı yetkili değildir.** Modeller program adreslerini, talimat adlarını ve hesap listelerini endişe verici bir şekilde halüsinasyon yapar. Ajan tarafından oluşturulan işlemlere güvenmeden önce her zaman dokümentasyon ve IDL'ye karşı doğrulayın.
- **Sürüm kayması.** SDK v2 1.0 öncesidir; eski sürümler üzerinde eğitilen ajanlar, sabitlenmiş sürümünüze karşı derlenmeyen kod yayabilir. Sabitlenmiş SDK sürümünü ajanınızın sistem istemine dahil edin.
