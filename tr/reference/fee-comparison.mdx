## Ürün başına swap ücretleri

Ücret değerleri giriş miktarının yüzdesidir ve havuz matematiğinden önce uygulanır.

| Ürün | Mevcut katmanlar | Varsayılan / en çok kullanılan | Bölüşüm |
|---------|-----------------|---------------------|-------|
| **AMM v4** | 0.25% (sadece) | 0.25% | %88 LP, %12 protokol (25'in 22/3'ü) |
| **CPMM** | 0.01%, 0.25%, 1% | 0.25% | %100 LP (protokol payı AmmConfig başına yapılandırılabilir, şu anda %0) |
| **CLMM** | 0.01%, 0.05%, 0.25%, 1% | 0.25% | %88 LP, %12 protokol |
| **LaunchLab (mezuniyet öncesi)** | %1 (varsayılan) | %1 | %50 havuz tohumuna, %50 LaunchLab hazinesine |
| **LaunchLab (mezuniyet sonrası CPMM)** | 0.25% | 0.25% | CPMM bölüşümünü devralır |

### Ücret paydası kuralı

- **AMM v4**: ücretler x/10.000 olarak kodlanır. "25" %0.25 anlamına gelir.
- **CPMM/CLMM**: ücretler x/1.000.000 olarak kodlanır. "2500" %0.25 anlamına gelir.

Zincir üstü verileri doğrudan okurken, havuzun programı için doğru paydayı kullanın.

## Protokol ücret bölüşümleri

Her ücretin "protokol" payı içinde, daha ileri bölüşümler uygulanır:

| Ürün | Swap ücretinin protokol payı | Protokol içindeki bölüşüm |
|---------|----------------------------|------------------------|
| AMM v4 | %12 (3/25) | %100 hazineye |
| CPMM | AmmConfig başına yapılandırılabilir (şu anda %0) | Yok |
| CLMM | Swap ücretinin %12'si | %100 hazineye |
| LaunchLab | Mezuniyet öncesi swap ücretinin %50'si | %100 LaunchLab hazinesine |

**LP payı** otomatik olarak LP token sahiplerine akar:

- AMM v4 / CPMM: havuz rezervlerinde birikir, çekilişte orantılı olarak dağıtılır.
- CLMM: `fee_growth_global_X/Y` içinde birikir, `collectFee` aracılığıyla talep edilebilir.

## Oluşturma maliyetleri

Bir havuz dağıtmak için SOL cinsinden ödenen tek seferlik maliyetler.

| Ürün | Kira maliyeti | Oluşturma ücreti | Tipik toplam |
|---------|-----------|--------------|---------------|
| AMM v4 | ~0.15 SOL (birden fazla hesap) | 0.2 SOL | ~0.35 SOL |
| CPMM | ~0.04 SOL (havuz + kasalar + gözlem) | 0.15 SOL | ~0.19 SOL |
| CLMM | ~0.075 SOL (havuz + gözlem + ilk tick dizileri) | 0 SOL | ~0.075 SOL |
| Farm v6 | ~0.02 SOL (farm durumu + ödül kasaları) | 0.1 SOL (spam karşıtı) | ~0.12 SOL |
| LaunchLab başlatma | ~0.015 SOL (bağlama eğrisi hesabı) | 0.1 SOL (LaunchLab ücreti) | ~0.115 SOL |

Tüm kiralar geri alınabilir — havuzu / pozisyonu / farm'ı kapatmak lamportları geri verir.

## Mezuniyet / geçiş maliyetleri

| Olay | Maliyet | Kim öder |
|-------|------|----------|
| LaunchLab → CPMM mezuniyeti | ~0.04 SOL (yeni CPMM havuzu oluşturma) | Bağlama eğrisi rezervlerinden ödenir |
| AMM v4 → CPMM geçişi | ~0.04 SOL CPMM oluşturma + ~0.000005 SOL tx ücreti | Geçişi yapan LP |
| CLMM pozisyon NFT transferi | ~0.000005 SOL tx ücreti; dondurulmuş kısıtlı yayıncı pozisyonları için kullanılamaz | Transferi yapan |

## Tipik işlem başına ağ ücretleri

Bunlar Solana tabanı + öncelik ücretleridir, Raydium protokol ücretlerinden ayrıdır.

| İşlem | CU | Taban ücreti | Öncelik ücreti (10k µL/CU) | Toplam ağ |
|-----------|-----|----------|---------------------------|---------------|
| CPMM swap | ~140.000 | 0.000005 SOL | 0.0014 SOL | ~0.0015 SOL |
| CLMM swap (tick yok) | ~170.000 | 0.000005 SOL | 0.0017 SOL | ~0.0017 SOL |
| CLMM swap (4 tick geçişi) | ~320.000 | 0.000005 SOL | 0.0032 SOL | ~0.0032 SOL |
| CLMM pozisyonu aç | ~280.000 | 0.000005 SOL | 0.0028 SOL | ~0.0028 SOL |
| Farm v6 stake | ~130.000 | 0.000005 SOL | 0.0013 SOL | ~0.0013 SOL |
| Farm ödüllerini talep et | ~160.000 | 0.000005 SOL | 0.0016 SOL | ~0.0016 SOL |
| v4 → CPMM geçişi (2 tx) | ~200.000 + ~200.000 | 0.00001 SOL | 0.004 SOL | ~0.004 SOL |

Öncelik ücretleri CU fiyatıyla doğrusal olarak ölçeklenir; bkz. [`integration-guides/priority-fee-tuning`](/tr/integration-guides/priority-fee-tuning).

## Token-2022 ücret etkileşimi

Bir havuzun bir veya her iki tarafı transfer ücreti olan Token-2022 kullandığında, etkili ücret bileşik olur:

```
havuza net giriş   = amount_in × (1 − transfer_fee_in)
havuz swap ücreti  = net × swap_fee_rate
kullanıcıya net çıkış = out × (1 − transfer_fee_out)
```

Örnek: CPMM %0.25 havuzu, giriş tarafında %1 transfer ücreti, çıkış tarafında %0.5 transfer ücreti.

```
amount_in        = 1000
net_to_pool      = 1000 × 0.99    = 990
pool swap fee    = 990 × 0.0025   = 2.475 (LP ücreti olarak tutulur)
amount_after_fee = 987.525
amount_out (AMM) = 987.525 × ratio, diyelim 987.525 × 0.98 = 967.77
net_out_to_user  = 967.77 × 0.995 = 962.94
```

Etkili ücret: **~%3.7** nominal %0.25 havuz ücretine rağmen.

SDK, `getComputeAmountOut` aracılığıyla etkili oranı hesaplar — Token-2022 havuzlarını fiyatlandırırken her zaman bunu kullanın.

## LaunchLab özellikleri

| Aşama | Ücret |
|-------|-----|
| Bağlama eğrisi işlemleri (satın alma veya satış) | %1 (havuz/hazine arasında 50/50 bölüşüm) |
| Mezuniyet (tek seferlik) | eğri rezervlerinden ~0.04 SOL |
| Mezuniyet sonrası (CPMM havuzu) | %0.25 (standart CPMM ücretleri) |

Token başlatan projeler, bağlama eğrisi aşamasında bir yaratıcı ücreti ekleyebilir. Mezuniyetten sonra, seçilen CPMM yapılandırması, kaydedilen havuz yaratıcısı için ayrı bir CPMM yaratıcı ücreti de talep edebilir. Platform'a ait Fee Key, LP-ücret haklarını temsil eder ve yaratıcı-ücret kimlik bilgisi değildir. Bkz. [`products/launchlab/creator-fees`](/tr/products/launchlab/creator-fees).

## Farm v6 ödül maliyet modeli

Farm'lar kesin anlamda ücret talep etmezler — bunlar ödül dağıtımıdır. Ancak çalıştırmak için SOL maliyeti vardır:

| Maliyet | Tipik |
|------|---------|
| Farm oluşturma | 0.1 SOL spam karşıtı + ~0.02 SOL kira |
| Ödül kasasını doldur | Sadece tokenler + ~0.0005 SOL tx |
| Kullanılmayan ödülleri geri al | ~0.0005 SOL tx |

Farm'lar ayrıca ödül kasasında farm'ın ömrü boyunca kirayı karşılamak için yeterli lamport gerektirir; kapatma onları geri verir.

## Zincir üstü mevcut değerleri nasıl okuyacağınız

### CPMM/CLMM AmmConfig

```ts
const config = await raydium.cpmm.getAmmConfigs();
console.log(config[0]);
// {
//   id: "...",
//   tradeFeeRate: 2500,         // 2500 / 1_000_000 = 0.25%
//   protocolFeeRate: 0,         // 0 / 1_000_000 = 0%
//   fundFeeRate: 0,
//   ...
// }
```

### AMM v4 havuzu

```ts
const poolInfo = await raydium.liquidity.getPoolInfoFromRpc({ poolId });
console.log(poolInfo.ammFeesNumerator, poolInfo.ammFeesDenominator);
// 25, 10000 → 0.25%
```

### Farm v6 ödül oranı

```ts
const farm = await raydium.farm.getFarmInfoFromRpc({ id: farmId });
console.log(farm.farmData.rewardInfos);
// Ödül başına: emissionsPerSecond, startTime, endTime
```
