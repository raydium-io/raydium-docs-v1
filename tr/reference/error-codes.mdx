## Anchor hata kodları nasıl çalışır?

Anchor, bir programın `ErrorCode` numaralandırmasının her varyantına `6000` ile başlayan sayısal bir kod atar. Başarısız bir işlem şunları ortaya çıkarır:

- **Sayısal hata kodu** (örn. `0x1771` = 6001) işlem günlüklerinde.
- **Hata adı** (örn. `InvalidOwner`) IDL'den.
- **`#[msg(...)]` dizesi** Anchor tarafından `log_messages` içinde yayılan.

Entegratörler **sayısal koda** göre eşleşme yapmalıdır, mesaj dizesine göre değil (dize sürüm yükseltilmeden yeniden yazılabilir).

```ts
// Örnek: CPMM slippage hatasını algıla ve temiz bir UX mesajı göster.
const CPMM_EXCEEDED_SLIPPAGE = 6005;

try {
  await sdk.cpmm.swap({ ... });
} catch (err: any) {
  const code = err?.error?.errorCode?.number ?? err?.code;
  if (code === CPMM_EXCEEDED_SLIPPAGE) {
    showToast("Fiyat slippage toleransınızı aştı. Slippage'ı artırın veya yeniden deneyin.");
    return;
  }
  throw err;
}
```

## SDK hatalarını program hatalarına eşleme

Resmi TypeScript SDK, zincir üstü hataları `SendTransactionError` ve Anchor programları için `AnchorError` içine sarar:

```ts
import { AnchorError } from "@coral-xyz/anchor";

try {
  await sdk.cpmm.swap({ ... });
} catch (err) {
  if (err instanceof AnchorError) {
    console.log(err.error.errorCode.number, err.error.errorCode.code, err.error.errorMessage);
    // 6005 ExceededSlippage "Exceeds desired slippage limit"
  } else {
    // Ham SendTransactionError — "custom program error: 0x..." satırı için err.logs'u inceleyin.
  }
}
```

İstemci tarafında Anchor kullanmıyorsanız, işlem günlüklerini ayrıştırın:

```
Program <ProgramID> invoke [1]
Program log: AnchorError caused by account: pool_state. Error Code: ExceededSlippage. Error Number: 6005. Error Message: Exceeds desired slippage limit.
```

`Error Number: (\d+)` deseni Anchor sürümleri arasında kararlıdır ve eşleştirmek için güvenlidir.

## Bu tabloları yeniden oluşturma

Bir program yükseltildiğinde ve yeni bir hata eklediğinde, kaynaktan yeniden çıkarın:

```bash
# Klonla ve hata numaralandırmasını sırayla grep'le.
git clone --depth=1 https://github.com/raydium-io/raydium-cp-swap
awk '/#\[msg\(/{ gsub(/^[ \t]*#\[msg\("|"\)\][ \t]*/,""); m=$0; getline; gsub(/,/,""); gsub(/^[ \t]+/,""); print "6000+++\t" $0 "\t" m }' \
  raydium-cp-swap/programs/cp-swap/src/error.rs
# 6000+++' yerine monoton artan 6000,6001,... yazın. Yukarıdaki tabloya yeni satırlar ekleyin.
```

Yeni bir varyant eklendiğinde her zaman [`reference/changelog`](/tr/reference/changelog) güncelleyin, böylece SDK'yı yükselten entegratörler hata işleyicilerini yenilemeyi bilirler.
