## Talimat envanteri

| Grup | Talimat | Çağrılabilir |
|-------|---------|-------------|
| Genel yapılandırma | `CreateConfig` / `UpdateConfig` | Program yöneticisi; delegeli create-config yetkilisi de `CreateConfig` çağırabilir |
| Başlatma yaşam döngüsü | `Initialize` / `InitializeV2` | Herkes (yaratıcı) — SPL Token temel mint; V2, eventual CPMM mezuniyeti için `amm_creator_fee_on` kaydeder. Yalnızca V2, Token-2022 quote mint'i kabul eder. |
| Başlatma yaşam döngüsü | `InitializeWithToken2022` | Herkes (yaratıcı) — Token-2022 temel mint, isteğe bağlı `TransferFeeConfig`; her iki quote token programını kabul eder |
| İşlem | `BuyExactIn` / `BuyExactOut` | Herkes — bonding curve üzerinde tam giriş / tam çıkış satın alma |
| İşlem | `SellExactIn` / `SellExactOut` | Herkes — bonding curve üzerinde tam giriş / tam çıkış satış |
| Mezuniyet | `MigrateToAmm` | Geçiş cüzdanı — CPMM-only oluşturma uygulanmadan önce başlatılan havuzlar için eski AMM v4 mezuniyeti. |
| Mezuniyet | `MigrateToCpswap` | Geçiş cüzdanı — CPMM'ye mezun ol. Tüm yeni başlatılan başlatmalar bu yolu kullanır. CPMM'de `InitializeWithPermission` sarmalanır. |
| Ücretler | `CollectFee` | Yönetici — bir başlatmadan protokol ücretlerini temizle |
| Ücretler | `CollectMigrateFee` | Yönetici — birikmiş geçiş ücretlerini temizle |
| Ücretler | `ClaimCreatorFee` | Yaratıcı — eğri aşaması sırasında birikmiş yaratıcı ücretlerini talep et |
| Vesting | `CreateVestingAccount` | Yaratıcı — kilitli token'ları bir yararlanıcıya tahsis et, mezuniyetten sonra açılır |
| Vesting | `CreatePlatformVestingAccount` | Platform yöneticisi — kilitli token'ları platform tarafı yararlanıcılara tahsis et |
| Vesting | `ClaimVestedToken` | Yararlanıcı — cliff'ten sonra açılan token'ları talep et |
| Platform yapılandırması | `CreatePlatformConfig` / `UpdatePlatformConfig` | Platform yöneticisi |
| Platform yapılandırması | `UpdatePlatformCurveParam` / `RemovePlatformCurveParam` | Platform yöneticisi — platform başına izin verilen eğri şekillerinin listesini yönet |
| Platform ücretleri | `ClaimPlatformFee` / `ClaimPlatformFeeFromVault` | Platform yöneticisi |
| Platform erişimi | `CreatePlatformAllowConfig` / `ClosePlatformAllowConfig` | Platform yöneticisi — bu platform kısıtlamayı etkinleştirdiğinde kullanılan `GlobalConfig` izin listesini yönet |

"ExactIn/ExactOut" bölünmesi CPMM'nin `SwapBaseInput` / `SwapBaseOutput` yöntemini yansıtır — zincir üzerinde bunlar biraz farklı yuvarlama ile ayrı talimat ayırıcılarıdır.

**Mezuniyet yolu seçimi.** Her yeni `Initialize`, `InitializeV2` ve `InitializeWithToken2022` çağrısı `migrate_type = 1` (`CPSWAP`) ayarlamalıdır. Yeni bir AMM v4'e bağlı havuz başlatmaya yönelik herhangi bir girişim `MigrateTypeNotMatch` döndürür. `amm_creator_fee_on` yalnızca ortaya çıkan CPMM yaratıcı ücretinin quote token'ına mı yoksa her iki token'a mı uygulanacağını seçer; hedef programı seçmez.

`MigrateToAmm`, bu kısıtlamadan önce `migrate_type = 0` ile başlatılan mevcut bir `PoolState` için çağrılabilir kalır. Sürüm, mevcut havuz durumunu yeniden yazmaz veya eski talimatı kaldırmaz.

**Quote tarafı token programı.** Quote mint, SPL Token programı veya Token-2022 tarafından sahip olunabilir. Buna dokunan her talimat — `CreateConfig`, `InitializeV2`, `InitializeWithToken2022`, dört işlem talimatının tümü, `CollectFee`, `CollectMigrateFee`, `ClaimCreatorFee`, `ClaimPlatformFee` ve `ClaimPlatformFeeFromVault` — quote-program hesap yuvasında sahip olan programı alır. Hesap konumları değişmedi; yalnızca kabul edilen değer değişti. `GlobalConfig.quote_mint`'i gerçekten sahip olan programı geçin; bunu mevcut bir başlatma için `PoolState.token_program_flag` bit1'den okuyabilirsiniz (bkz. [`accounts`](/tr/products/launchlab/accounts#poolstate)) veya aksi takdirde mint hesabının sahibinden.

Kullanımdan kaldırılan `Initialize` istisnadır: quote-program hesabı hala SPL Token'a yazılmıştır, bu nedenle quote mint'i Token-2022 olan bir yapılandırma `InitializeV2` veya `InitializeWithToken2022` aracılığıyla başlatılmalıdır.

`MigrateToCpswap` diğer istisnadır, ters yönde — bir mint başına bir yerine koşulsuz olarak **her iki** programı alır. Aşağıdaki [geçiş hesaplarına](#cpmm-migration-token-programs) bakın.

## `Initialize`

Yeni bir başlatma oluştur.

**Argümanlar**

```
launch_params: {
    curve_type:                 u8,
    base_supply_max:            u64,
    base_supply_graduation:     u64,
    k:                          u128,              // or initial_virtual_quote_reserve for curve_type=1
    open_time:                  u64,
    quote_mint:                 Pubkey,
    base_token_metadata: {                         // inline name/symbol/uri; program CPIs to Metaplex
        name:   String,
        symbol: String,
        uri:    String,
    },
    fees: {
        buy_numerator:   u64,
        buy_denominator: u64,
        sell_numerator:  u64,
        sell_denominator: u64,
        lp_share:        u64,
        creator_share:   u64,
        protocol_share:  u64,
        total_share:     u64,
    },
    post_graduation_lp_policy:  u8,                // 0 = Burn, 1 = Lock, 2 = ToCreator
}
```

**Hesaplar** (kısaltılmış)

| # | Ad | W | S | Notlar |
|---|-----|---|---|--------|
| 1 | `creator` | W | S | Kira + temel mint oluşturmayı öder. |
| 2 | `launch_config` |   |   | Protokol yapılandırması bağlaması. |
| 3 | `launch_state` | W |   | Yeni hesap. |
| 4 | `launch_authority` |   |   | PDA. |
| 5 | `base_mint` | W | S | Yeni Keypair (veya PDA) — bu talimat bunu başlatır. |
| 6 | `base_vault` | W |   | `launch_authority`'nin `base_mint` üzerindeki ATA'sı. |
| 7 | `quote_mint` |   |   | |
| 8 | `quote_vault` | W |   | `launch_authority`'nin `quote_mint` üzerindeki ATA'sı. |
| 9 | `metadata` | W |   | Metaplex metadata PDA'sı. |
| 10 | `metaplex_program` |   |   | |
| 11 | `token_program` |   |   | Temel mint için SPL Token. `InitializeV2` ve `InitializeWithToken2022` her iki program da olabilecek ayrı bir quote-program hesabı alır. |
| 12 | `system_program` |   |   | |
| 13 | `rent` |   |   | |

**Ön koşullar**

- `quote_mint ∈ launch_config.allowed_quote_mints`.
- `base_supply_graduation ≤ base_supply_max`.
- Ücret parametreleri `launch_config.max_*_fee_rate` kontrollerini geçer.
- `open_time ≥ now − slop` (SDK `≥ now` uygular; program hafif geriye dönük tarihlendirmeyi tolere eder).
- `curve_type` tanınır.

**Son koşullar**

- `base_mint`, `supply = base_supply_max` ile, tümü `base_vault`'ta.
- `base_mint.mint_authority = launch_authority`, `freeze_authority = None`.
- `LaunchState`, `status = Active`, `base_sold = 0`, `quote_reserve_real = 0` ile başlatılır.
- `quote_reserve_target`, eğri parametreleri + `base_supply_graduation` + `buy_numerator` (yaklaşık olarak) hesaplanır.

**Yaygın hatalar** — `InvalidQuoteMint`, `FeeRateTooHigh`, `InvalidCurveParams`, `MathOverflow`.

## `Buy` (kanonik varyant: `BuyExactIn`)

Kullanıcı sabit bir `quote_in` sağlar; eğri `base_out` hesaplar.

**Argümanlar**

```
quote_in:          u64
minimum_base_out:  u64
```

**Hesaplar**

| # | Ad | W | S |
|---|-----|---|---|
| 1 | `user` | W | S |
| 2 | `launch_state` | W |   |
| 3 | `launch_authority` |   |   |
| 4 | `base_vault` | W |   |
| 5 | `quote_vault` | W |   |
| 6 | `user_base_ata` | W |   |
| 7 | `user_quote_ata` | W |   |
| 8 | `base_mint` |   |   |
| 9 | `quote_mint` |   |   |
| 10 | `token_program` |   |   |
| 11 | `associated_token_program` |   |   |
| 12 | `system_program` |   |   |

**Ön koşullar**

- `launch_state.status == Active`.
- `now ≥ open_time`.
- `user_quote_ata.balance ≥ quote_in`.
- `quote_in > 0`.

**Etki**

1. `quote_in`'i `quote_in_after_fee` ve ücret kısımlarına böl.
2. Post-fee quote'u verilen `base_out` için eğriyi Newton-çöz.
3. `require(base_out ≥ minimum_base_out)` aksi takdirde `ExceededSlippage` ile geri dön.
4. `quote_in` kullanıcı → vault'a taşı. `base_out` vault → kullanıcıya taşı.
5. `base_sold += base_out`, `quote_reserve_real += quote_in_after_fee × (lp_share / total_share)` güncelle.
6. Ücret sayaçlarını güncelle (`protocol_fees_quote`, `creator_fees_quote`).
7. `state_data.num_buys += 1`.
8. Güncelleme sonrasında `quote_reserve_real ≥ quote_reserve_target` ise, SDK tipik olarak aynı işlemde bir `Graduate` ix'i zincirler. Program `Buy` içinde otomatik olarak mezun olmaz — sonraki bir `Graduate` gereklidir.

## `BuyExactOut`

Kullanıcı tam `base_out` belirtir; program `quote_in` hesaplar.

**Argümanlar**

```
base_out:      u64
maximum_quote_in: u64
```

`BuyExactIn` ile aynı hesaplar. Newton iterasyonu yerine kapalı form ikinci dereceden integral (veya curve_type 1 için CPMM tersi) kullanır.

## `Sell` / `SellExactIn` / `SellExactOut`

`Buy`'ın aynası. Kullanıcı `base_in`'i eğriye geri döndürür ve `quote_out` alır. Ücret `quote_out`'tan düşülür, bu nedenle kullanıcı ham entegre gelirlerden daha az alır.

**Ön koşullar** —

- `user_base_ata.balance ≥ base_in`.
- Satış, `base_sold`'u 0'ın altına itemiyor (muhasebe tutarlı olduğu göz önüne alındığında yukarıdakiyle gereksiz).
- Başlatma `Active`'dir.

**Etki** — `Buy`'a simetrik. `base_sold` azalır, `quote_reserve_real` azalır. Ücretler yine de tahakkuk eder.

### Quote tarafı transfer ücretleri

Quote mint bir `TransferFeeConfig` taşıdığında, vault'un taşıdığı miktar ve ödeyicinin borçlandırıldığı veya alacaklandırıldığı miktar farklıdır ve slippage sınırı ödeyicinin tarafına karşı kontrol edilir. Transfer ücreti uzantısı olmayan bir quote mint'te aşağıdaki her durum düz bir eski mint ile aynıdır.

| Talimat | Argüman | Kontrol edilen |
|---------|---------|----------------|
| `BuyExactIn` | `amount_in` | Eğri `amount_in − transfer_fee(amount_in)` üzerinde fiyatlandırılır — vault'a ulaşan. Tam bir doldurma tam olarak `amount_in` borçlandırır; kısmi bir doldurma tüketilen vault miktarı artı ters ücretini borçlandırır. |
| `BuyExactOut` | `maximum_amount_in` | Vault miktarı **artı** ters transfer ücreti — gerçek borç. |
| `SellExactIn` | `minimum_amount_out` | Satıcının mint ücretini kestikten sonra tuttuğu, vault'tan ayrılan brüt miktar değil. |
| `SellExactOut` | `amount_out` | Tam olarak teslim edilir. Eğri `amount_out` artı ters transfer ücretini hedefler. |

Alıntı için iki sonuç:

- Mint ücretsiz olsaydı hesaplanan bir sınır reddedilir. Ücretsiz maliyeti `maximum_amount_in` olarak veya ücretsiz geliri `minimum_amount_out` olarak geçmek `ExceededSlippage` ile geri döner.
- `real_quote` yalnızca vault'a ulaşan miktarla ilerler. %5 quote mint'te `amount_in` `BuyExactIn`'i `amount_in × 0.95` ile `real_quote`'u ilerletir.

%100 ücretli quote mint (`10000` basis puan) ters çevrilemez ve tam çıkış yollarında `CalculateOverflow` ile geri döner.

Her iki işlem tarafı mint'i de eşleşen yuvasında geçirilen programa kısıtlanır, bu nedenle uyumsuz bir `base_token_program` artık yok sayılmak yerine başarısız olur. Temel ücret matematiği için [`algorithms/token-2022-transfer-fees`](/tr/algorithms/token-2022-transfer-fees) bölümüne bakın.

## `MigrateToAmm` / `MigrateToCpswap`

Eğri `total_quote_fund_raising`'e ulaştığında bir başlatmayı işlem yapılabilir bir havuza mezun et. Yeni başlatmalar yalnızca CPMM'dir. `MigrateToAmm`, depolanan `migrate_type`'ı `0` olan mevcut havuzlar için tutulur.

**Kim imzalar**

- `MigrateToAmm` — bağlama `GlobalConfig`'de kaydedilen `migrate_to_amm_wallet`.
- `MigrateToCpswap` — bağlama `GlobalConfig`'de kaydedilen `migrate_to_cpswap_wallet`.

Bu cüzdanlar tipik olarak Raydium tarafından işletilen mezuniyet krankı tarafından tutulur; pratikte mezuniyet eşik geçildikten sonra saniyeler içinde gerçekleşir, son satın almayı kimin tetiklediğine bakılmaksızın.

**Argümanlar**

`MigrateToAmm` üç tane alır (esas olarak programın AMM v4'e ileteceği OpenBook pazar parametreleri):

```
base_lot_size:               u64
quote_lot_size:              u64
market_vault_signer_nonce:   u8
```

`MigrateToCpswap` hiçbirini almaz.

**Etki (her ikisine de ortak)**

1. `pool_state.status == Migrate` doğrula (yani, `quote_reserve_target` ulaşıldı). Aksi takdirde `PoolMigrated` (durum zaten `Migrated` idi) veya `PoolFunding` (hala finansman aşamasında) ile geri dön.
2. `pool_state.migrate_type`'ın talimatla eşleştiğini doğrula (AMM için `0`, CPMM için `1`). Aksi takdirde `MigrateTypeNotMatch` ile geri dön.
3. Mezuniyet sonrası rezervleri hesapla:
   - `base_amount_out = base_vault.amount − vesting_schedule.total_locked_amount`
   - `quote_amount_out = quote_vault.amount − quote_protocol_fee − migrate_fee − platform_fee`
4. Hedef programa (`AMM v4 Initialize2` veya `CPMM InitializeWithPermission`) bu rezervlerle CPI yap ve mezuniyet sonrası havuzu oluştur.
5. 2026-08-17 yükseltmesinden sonra yürütülen CPMM geçişleri için `platform_scale + creator_scale`'i bir platform tarafından sahip olunan kilitli LP payına birleştir ve en fazla bir Fee Key NFT'yi `platform_nft_wallet`'a mint et. `burn_scale` kalanını yak. Yükseltmeden önce, `creator_scale` ayrı olarak kilitliydi ve Fee Key'i token yaratıcısına gitti. Tamamlanan tarihsel geçişler değiştirilmez. Eski AMM v4 mezuniyeti için, LP dağılımı bu talimatın mevcut akışını izler.
6. `base_mint.mint_authority`'yi iptal et (`None` olarak ayarla).
7. `pool_state.status = Migrated` çevir, `vesting_schedule.start_time = block_time + cliff_period` ayarla.

**Son koşullar** — `BuyExactIn`, `BuyExactOut`, `SellExactIn`, `SellExactOut` bu noktadan itibaren `PoolMigrated` ile reddedecektir. Ortaya çıkan AMM havuzu kanonik ve diğer herhangi bir AMM v4 / CPMM havuzu gibi işlem yapar.

**Yaygın hatalar** — `PoolFunding`, `PoolMigrated`, `MigrateTypeNotMatch`, `InvalidCpSwapConfig`, `MathOverflow`.

### CPMM geçişi kalan hesaplar

`MigrateToCpswap` oluşturan istemciler bu sabit `remaining_accounts` indekslerini kullanmalıdır:

| İndeks | Hesap |
|--------|-------|
| 0–4 | Platform Fee Key sahibi, mint, token hesabı, kilitli likidite PDA'sı ve metadata hesabı |
| 5 | Orijinal başlatma yaratıcısı; `platform_cp_creator` ayarlanmadığında kullanılır |
| 6 | `[b"permission", launch_authority]` türetilen CPMM permission PDA'sı |
| 7 | Yapılandırılmış `platform_cp_creator`; alan varsayılan olmadığında kullanılır |
| 8 | Sıralanmış `mint0` için CPMM support-mint PDA'sı, `[b"support_mint", mint0]` türetilmiş |
| 9 | Sıralanmış `mint1` için CPMM support-mint PDA'sı, `[b"support_mint", mint1]` türetilmiş |

Talimat, yükseltilmiş yolda en az on kalan hesap gerektirir. Support-mint hesapları salt okunur CPI girdileridir. Mint'in başlatılmış bir destek kaydı olmasa bile her iki adresi türet. Hala yaratıcı-kilit hesapları ekleyen veya indeksleri 8–9 atlayan eski oluşturucular güncellenmeli.

### CPMM geçişi token programları

`MigrateToCpswap` koşulsuz olarak her iki token programını alır ve hangi birinin her mint'i sahip olduğunu kendisi çözer. İki token-program hesabı buna göre yeniden adlandırıldı:

| Konum | Hesap | Değer |
|-------|-------|-------|
| birinci | `token_program` | Her zaman eski SPL Token programı |
| ikinci | `token_program_2022` | Her zaman Token-2022 programı |

Bunlar eski `base_token_program` (temel mint'i sahip olan program) ve `quote_token_program` (her zaman eski) yerine geçer. Konumlar değişmez, bu nedenle bu bir düzen değişikliği yerine bir değer değişikliğidir — ancak iki değer neredeyse ters çevrilmiş ve eski çiftini geçmeye devam eden bir oluşturucu, her iki mint de Token-2022 mint'i olur olmaz Token-2022'yi eski programın gerekli olduğu yere sağlayacaktır.

Eski program, hiçbir mint bunu kullanmasa bile gereklidir, çünkü CPMM LP mint'i ve kilitli likidite Fee Key NFT'si her zaman bunda yaşar.

## Platform `GlobalConfig` izin listesi

`PlatformConfig.restrict_global_config` kontrolü yönetir:

- `0`: platform herhangi bir başka şekilde geçerli `GlobalConfig`'i kabul eder; izin hesabı gerekli değildir.
- `1`: `Initialize`, `InitializeV2` ve `InitializeWithToken2022` eşleşen `PlatformAllowConfig`'i `remaining_accounts`'ın herhangi bir yerine dahil etmelidir.

Platform yöneticisi `CreatePlatformAllowConfig` ve `ClosePlatformAllowConfig` ile PDA'yı oluşturur veya kapatır. Tohumları `[b"platform_allow_config", platform_config, global_config]`'dir. Eski yönetici tarafından yönetilen `PlatformGlobalAccess` talimatları ve PDA'sı emekli olmuştur.

## `CollectMigrateFee`

Mezuniyet sırasında birikmiş geçiş ücretinin yönetici tarafından temizlenmesi. `CollectFee` ile aynı hesap şekli, `protocol_fee_owner` yerine `migrate_fee_owner` imzalayan ve `pool_state.migrate_fee` drained sayacı olarak.

## `ClaimCreatorFee`

Yaratıcının sahip olduğu **her başlatmada** birikmiş yaratıcı ücretlerinin yaratıcı başına temizlenmesi, aynı quote mint'i kullanan. Per-pool olanı değil, per-yaratıcı ücret vault'unu boşaltır.

**Argümanlar** — hiçbiri.

**Hesaplar**

| # | Ad | W | S | Notlar |
|---|-----|---|---|--------|
| 1 | `creator` | W | S | Havuz yaratıcısı. |
| 2 | `fee_vault_authority` |   |   | PDA `[b"creator_fee_vault_auth_seed"]`. |
| 3 | `creator_fee_vault` | W |   | `[creator, quote_mint]` tohumlarında PDA; toplam yaratıcı vault'u. |
| 4 | `recipient_token_account` | W |   | `init_if_needed`; `creator`'ın `quote_mint` üzerindeki ATA'sı. |
| 5 | `quote_mint` |   |   | |
| 6 | `token_program` |   |   | |
| 7 | `system_program` |   |   | Gerekirse ATA oluşturması için. |
| 8 | `associated_token_program` |   |   | |
