## Talimat envanteri

| Grup | Talimat | Çağrılabilir |
|-------|---------|-------------|
| Global yapılandırma | `CreateConfig` / `UpdateConfig` | Program yöneticisi; delegeli create-config yetkilisi de `CreateConfig` çağırabilir |
| Başlatma yaşam döngüsü | `Initialize` / `InitializeV2` | Herkes (yaratıcı) — SPL Token başlatmaları; V2, sonraki CPMM mezuniyeti için `amm_creator_fee_on` kaydeder |
| Başlatma yaşam döngüsü | `InitializeWithToken2022` | Herkes (yaratıcı) — Token-2022 başlatması, isteğe bağlı `TransferFeeConfig` |
| İşlem | `BuyExactIn` / `BuyExactOut` | Herkes — bağlama eğrisinde tam giriş / tam çıkış satın alma |
| İşlem | `SellExactIn` / `SellExactOut` | Herkes — bağlama eğrisinde tam giriş / tam çıkış satış |
| Mezuniyet | `MigrateToAmm` | Geçiş cüzdanı — CPMM-yalnızca oluşturma zorunlu kılınmadan önce başlatılan havuzlar için eski AMM v4 mezuniyeti. |
| Mezuniyet | `MigrateToCpswap` | Geçiş cüzdanı — CPMM'ye mezun olun. Tüm yeni başlatılan başlatmalar bu yolu kullanır. CPMM'de `InitializeWithPermission` sarmalanır. |
| Ücretler | `CollectFee` | Yönetici — bir başlatmadan protokol ücretlerini temizle |
| Ücretler | `CollectMigrateFee` | Yönetici — birikmiş geçiş ücretlerini temizle |
| Ücretler | `ClaimCreatorFee` | Yaratıcı — eğri aşaması sırasında birikmiş yaratıcı ücretlerini talep et |
| Vesting | `CreateVestingAccount` | Yaratıcı — kilitli jetonları bir lehtar için ayır, mezuniyetten sonra açılır |
| Vesting | `CreatePlatformVestingAccount` | Platform yöneticisi — kilitli jetonları platform tarafı lehtarlar için ayır |
| Vesting | `ClaimVestedToken` | Lehtar — uçurum sonrası açılan jetonları talep et |
| Platform yapılandırması | `CreatePlatformConfig` / `UpdatePlatformConfig` | Platform yöneticisi |
| Platform yapılandırması | `UpdatePlatformCurveParam` / `RemovePlatformCurveParam` | Platform yöneticisi — izin verilen eğri şekillerinin platform başına listesini yönet |
| Platform ücretleri | `ClaimPlatformFee` / `ClaimPlatformFeeFromVault` | Platform yöneticisi |
| Platform erişimi | `CreatePlatformAllowConfig` / `ClosePlatformAllowConfig` | Platform yöneticisi — o platform kısıtlamayı etkinleştirdiğinde kullanılan `GlobalConfig` izin listesini koru |

"ExactIn/ExactOut" bölünmesi CPMM'nin `SwapBaseInput` / `SwapBaseOutput` yöntemini yansıtır — zincir üzerinde bunlar biraz farklı yuvarlama ile ayrı talimat ayırıcılarıdır.

**Mezuniyet yolu seçimi.** Her yeni `Initialize`, `InitializeV2` ve `InitializeWithToken2022` çağrısı `migrate_type = 1` (`CPSWAP`) ayarlamalıdır. Yeni bir AMM v4 bağlı havuzu başlatmaya yönelik herhangi bir girişim `MigrateTypeNotMatch` döndürür. `amm_creator_fee_on` yalnızca ortaya çıkan CPMM yaratıcı ücretinin alıntı jetonuna mı yoksa her iki jetona mı uygulanacağını seçer; hedef programı seçmez.

`MigrateToAmm`, bu kısıtlama öncesinde `migrate_type = 0` ile başlatılan mevcut bir `PoolState` için çağrılabilir kalır. Sürüm mevcut havuz durumunu yeniden yazmaz veya eski talimatı kaldırmaz.

## `Initialize`

Yeni bir başlatma oluştur.

**Argümanlar**

```
launch_params: {
    curve_type:                 u8,
    base_supply_max:            u64,
    base_supply_graduation:     u64,
    k:                          u128,              // veya curve_type=1 için initial_virtual_quote_reserve
    open_time:                  u64,
    quote_mint:                 Pubkey,
    base_token_metadata: {                         // satır içi ad/sembol/uri; program Metaplex'e CPI yapar
        name:   String,
        symbol: String,
        uri:    String,
    },
    fees: {
        buy_numerator:   u64,
        buy_denominator: u64,
        sell_numerator:  u64,
        sell_denominator: u64,
        lp_share:        u64,
        creator_share:   u64,
        protocol_share:  u64,
        total_share:     u64,
    },
    post_graduation_lp_policy:  u8,                // 0 = Burn, 1 = Lock, 2 = ToCreator
}
```

**Hesaplar** (kısaltılmış)

| # | Ad | W | S | Notlar |
|---|-----|---|---|--------|
| 1 | `creator` | W | S | Kira + temel mint oluşturmayı öder. |
| 2 | `launch_config` |   |   | Protokol yapılandırması bağlaması. |
| 3 | `launch_state` | W |   | Yeni hesap. |
| 4 | `launch_authority` |   |   | PDA. |
| 5 | `base_mint` | W | S | Yeni Keypair (veya PDA) — bu talimat bunu başlatır. |
| 6 | `base_vault` | W |   | `launch_authority` öğesinin `base_mint` üzerindeki ATA'sı. |
| 7 | `quote_mint` |   |   | |
| 8 | `quote_vault` | W |   | `launch_authority` öğesinin `quote_mint` üzerindeki ATA'sı. |
| 9 | `metadata` | W |   | Metaplex metadata PDA'sı. |
| 10 | `metaplex_program` |   |   | |
| 11 | `token_program` |   |   | Yalnızca SPL Token. |
| 12 | `system_program` |   |   | |
| 13 | `rent` |   |   | |

**Ön koşullar**

- `quote_mint ∈ launch_config.allowed_quote_mints`.
- `base_supply_graduation ≤ base_supply_max`.
- Ücret parametreleri `launch_config.max_*_fee_rate` kontrollerini geçer.
- `open_time ≥ now − slop` (SDK `≥ now` uygular; program hafif geriye dönük tarihlendirmeyi tolere eder).
- `curve_type` tanınır.

**Son koşullar**

- `base_mint` `supply = base_supply_max` ile, tümü `base_vault` içinde.
- `base_mint.mint_authority = launch_authority`, `freeze_authority = None`.
- `LaunchState` `status = Active`, `base_sold = 0`, `quote_reserve_real = 0` ile başlatılır.
- `quote_reserve_target` eğri parametrelerinden + `base_supply_graduation` + `buy_numerator` (yaklaşık olarak) hesaplanır.

**Yaygın hatalar** — `InvalidQuoteMint`, `FeeRateTooHigh`, `InvalidCurveParams`, `MathOverflow`.

## `Buy` (kanonik varyant: `BuyExactIn`)

Kullanıcı sabit bir `quote_in` sağlar; eğri `base_out` hesaplar.

**Argümanlar**

```
quote_in:          u64
minimum_base_out:  u64
```

**Hesaplar**

| # | Ad | W | S |
|---|-----|---|---|
| 1 | `user` | W | S |
| 2 | `launch_state` | W |   |
| 3 | `launch_authority` |   |   |
| 4 | `base_vault` | W |   |
| 5 | `quote_vault` | W |   |
| 6 | `user_base_ata` | W |   |
| 7 | `user_quote_ata` | W |   |
| 8 | `base_mint` |   |   |
| 9 | `quote_mint` |   |   |
| 10 | `token_program` |   |   |
| 11 | `associated_token_program` |   |   |
| 12 | `system_program` |   |   |

**Ön koşullar**

- `launch_state.status == Active`.
- `now ≥ open_time`.
- `user_quote_ata.balance ≥ quote_in`.
- `quote_in > 0`.

**Etki**

1. `quote_in` öğesini `quote_in_after_fee` ve ücret kısımlarına böl.
2. Post-ücret alıntısı verilen `base_out` için eğriyi Newton-çöz.
3. `require(base_out ≥ minimum_base_out)` aksi takdirde `ExceededSlippage` ile geri dön.
4. `quote_in` kullanıcı → kasa taşı. `base_out` kasa → kullanıcı taşı.
5. `base_sold += base_out`, `quote_reserve_real += quote_in_after_fee × (lp_share / total_share)` güncelle.
6. Ücret sayaçlarını güncelle (`protocol_fees_quote`, `creator_fees_quote`).
7. `state_data.num_buys += 1`.
8. Güncelleme sonrası `quote_reserve_real ≥ quote_reserve_target` ise, SDK tipik olarak aynı işlemde bir `Graduate` ix zincirler. Program `Buy` içinde otomatik olarak mezun olmaz — sonraki bir `Graduate` gereklidir.

## `BuyExactOut`

Kullanıcı tam `base_out` belirtir; program `quote_in` hesaplar.

**Argümanlar**

```
base_out:      u64
maximum_quote_in: u64
```

`BuyExactIn` ile aynı hesaplar. Newton yinelemesi yerine kapalı form ikinci dereceden integral (veya curve_type 1 için CPMM tersi) kullanır.

## `Sell` / `SellExactIn` / `SellExactOut`

`Buy` yansıması. Kullanıcı `base_in` öğesini eğriye döndürür ve `quote_out` alır. Ücret `quote_out` öğesinden düşülür, bu nedenle kullanıcı ham entegre gelirlerin daha azını alır.

**Ön koşullar** —

- `user_base_ata.balance ≥ base_in`.
- Satış `base_sold` öğesini 0'ın altına itemiyor (muhasebe tutarlı olduğu göz önüne alındığında yukarıdakiyle gereksiz).
- Başlatma `Active` durumundadır.

**Etki** — `Buy` ile simetrik. `base_sold` azalır, `quote_reserve_real` azalır. Ücretler yine de tahakkuk eder.

## `MigrateToAmm` / `MigrateToCpswap`

Eğri `total_quote_fund_raising` öğesine ulaştığında bir başlatmayı işlem gören bir havuza mezun et. Yeni başlatmalar yalnızca CPMM'dir. `MigrateToAmm`, depolanan `migrate_type` öğesi `0` olan mevcut havuzlar için tutulur.

**İmzalayan**

- `MigrateToAmm` — bağlama `GlobalConfig` öğesinde kaydedilen `migrate_to_amm_wallet`.
- `MigrateToCpswap` — bağlama `GlobalConfig` öğesinde kaydedilen `migrate_to_cpswap_wallet`.

Bu cüzdanlar tipik olarak Raydium tarafından işletilen mezuniyet krankı tarafından tutulur; uygulamada mezuniyet eşik geçildikten sonra saniyeler içinde gerçekleşir, son satın almayı kimin tetiklediğine bakılmaksızın.

**Argümanlar**

`MigrateToAmm` üç tane alır (esas olarak programın AMM v4'e ileteceği OpenBook pazar parametreleri):

```
base_lot_size:               u64
quote_lot_size:              u64
market_vault_signer_nonce:   u8
```

`MigrateToCpswap` hiçbirini almaz.

**Etki (her ikisine de ortak)**

1. `pool_state.status == Migrate` doğrula (yani, `quote_reserve_target` ulaşıldı). Aksi takdirde `PoolMigrated` (durum zaten `Migrated` idi) veya `PoolFunding` (hala finansman aşamasında) ile geri dön.
2. `pool_state.migrate_type` öğesinin talimatla eşleştiğini doğrula (`0` AMM için, `1` CPMM için). Aksi takdirde `MigrateTypeNotMatch` ile geri dön.
3. Mezuniyet sonrası rezervleri hesapla:
   - `base_amount_out = base_vault.amount − vesting_schedule.total_locked_amount`
   - `quote_amount_out = quote_vault.amount − quote_protocol_fee − migrate_fee − platform_fee`
4. Hedef programa (`AMM v4 Initialize2` veya `CPMM InitializeWithPermission`) bu rezervlerle CPI yaparak mezuniyet sonrası havuzu oluştur.
5. 2026-08-17 yükseltmesinden sonra yürütülen CPMM geçişleri için, `platform_scale + creator_scale` öğesini bir platform tarafından sahip olunan kilitli LP payına birleştir ve en fazla bir Fee Key NFT'yi `platform_nft_wallet` öğesine bas. `burn_scale` kalanını yak. Yükseltmeden önce, `creator_scale` ayrı olarak kilitliydi ve Fee Key'i jeton yaratıcısına gitti. Tamamlanan tarihsel geçişler değiştirilmez. Eski AMM v4 mezuniyeti için, LP dağılımı bu talimatın mevcut akışını izler.
6. `base_mint.mint_authority` öğesini iptal et (`None` olarak ayarla).
7. `pool_state.status = Migrated` çevir, `vesting_schedule.start_time = block_time + cliff_period` ayarla.

**Son koşullar** — `BuyExactIn`, `BuyExactOut`, `SellExactIn`, `SellExactOut` bu noktadan itibaren `PoolMigrated` ile reddedecektir. Ortaya çıkan AMM havuzu kanonik ve diğer herhangi bir AMM v4 / CPMM havuzu gibi işlem görür.

**Yaygın hatalar** — `PoolFunding`, `PoolMigrated`, `MigrateTypeNotMatch`, `InvalidCpSwapConfig`, `MathOverflow`.

### CPMM geçişi kalan hesapları

`MigrateToCpswap` oluşturan istemciler bu sabit `remaining_accounts` dizinlerini kullanmalıdır:

| Dizin | Hesap |
|---|---|
| 0–4 | Platform Fee Key sahibi, mint, jeton hesabı, kilitli likidite PDA'sı ve metadata hesabı |
| 5 | Orijinal başlatma yaratıcısı; `platform_cp_creator` ayarlanmadığında kullanılır |
| 6 | `[b"permission", launch_authority]` öğesinden türetilen CPMM izin PDA'sı |
| 7 | Yapılandırılmış `platform_cp_creator`; alan varsayılan olmayan olduğunda kullanılır |
| 8 | Sıralanmış `mint0` için CPMM destek-mint PDA'sı, `[b"support_mint", mint0]` öğesinden türetilmiş |
| 9 | Sıralanmış `mint1` için CPMM destek-mint PDA'sı, `[b"support_mint", mint1]` öğesinden türetilmiş |

Talimat, yükseltilmiş yolda en az on kalan hesap gerektirir. Destek-mint hesapları salt okunur CPI girdileridir. Her iki adresi de mint'in başlatılmış bir destek kaydı olmasa bile türet. Hala yaratıcı-kilit hesapları ekleyen veya dizinleri 8–9 atlayan eski oluşturucular güncellenmeli.

## Platform `GlobalConfig` izin listesi

`PlatformConfig.restrict_global_config` kontrolü denetler:

- `0`: platform herhangi bir başka şekilde geçerli `GlobalConfig` öğesini kabul eder; izin hesabı gerekli değildir.
- `1`: `Initialize`, `InitializeV2` ve `InitializeWithToken2022` eşleşen `PlatformAllowConfig` öğesini `remaining_accounts` içinde herhangi bir yere dahil etmelidir.

Platform yöneticisi `CreatePlatformAllowConfig` ve `ClosePlatformAllowConfig` ile PDA'yı oluşturur veya kapatır. Tohumları `[b"platform_allow_config", platform_config, global_config]` öğesidir. Eski yönetici tarafından yönetilen `PlatformGlobalAccess` talimatları ve PDA'sı emekli olmuştur.

## `CollectMigrateFee`

**Hesaplar**
