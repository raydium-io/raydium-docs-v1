<Info>
  `GlobalConfig`, **protokol seviyesi** yapılandırma hesabıdır. Birçok tane olabilir — `(curve_type, index)` ile anahtarlanır — ve her başlatma `Initialize` sırasında tam olarak birini seçer. Seçilen `GlobalConfig` üzerindeki değerler, o başlatmanın parametreleri için sabit sınırlar haline gelir. Platform seviyesi özelleştirme için (platform başına ücret oranı, izin verilen eğri şekilleri, mezuniyet sırasında NFT bölünmesi), bkz. [`products/launchlab/platform-config`](/tr/products/launchlab/platform-config).
</Info>

## Nedir

`GlobalConfig`, `(curve_type, index)` başına tekil bir PDA olup, her başlatmanın uyması gereken protokol tarafı kurallarını belirler:

- İzin verilen bağlama eğrisinin türü (`curve_type`).
- Eğrinin her alım ve satışta uyguladığı işlem ücreti oranı.
- Mezuniyet sırasında alınan göç ücreti.
- Arz, kilit oranı, satış oranı ve göç oranı üzerindeki tabanlar.
- Alıntı mint'i (genellikle sarılı SOL veya USDC) — kullanıcıların satın aldığı varlık.
- Dört protokol tarafı cüzdan: protokol ücreti sahibi, göç ücreti sahibi ve CPMM ile eski AMM v4 mezuniyeti için saklanan iki göç kontrol cüzdanı.

`GlobalConfig` hesapları LaunchLab program yöneticisi veya devredilen yapılandırma oluşturma yetkisi tarafından oluşturulabilir. Yalnızca yönetici mevcut yapılandırmaları günceller. Kanonik yetkililer için [`reference/program-addresses`](/tr/reference/program-addresses) bölümüne bakın.

## Düzen

```rust
// states/config.rs
pub const GLOBAL_CONFIG_SEED: &str = "global_config";

#[account]
pub struct GlobalConfig {
    pub epoch:                   u64,         // recent_epoch tracker
    pub curve_type:              u8,          // 0 = ConstantProduct, 1 = FixedPrice, 2 = LinearPrice
    pub index:                   u16,         // discriminator within a curve_type
    pub migrate_fee:             u64,         // SOL paid on graduation
    pub trade_fee_rate:          u64,         // 1/1_000_000 of volume
    pub max_share_fee_rate:      u64,         // 100 bps cap on platform share fee
    pub min_base_supply:         u64,         // floor on Initialize supply (no decimals)
    pub max_lock_rate:           u64,         // ceiling on vesting locked / supply
    pub min_base_sell_rate:      u64,         // floor on base_supply_graduation / supply
    pub min_base_migrate_rate:   u64,         // floor on tokens that seed the post-graduation pool
    pub min_quote_fund_raising:  u64,         // floor on quote_reserve_target (with decimals)
    pub quote_mint:              Pubkey,
    pub protocol_fee_owner:      Pubkey,      // claims protocol fees via CollectFee
    pub migrate_fee_owner:       Pubkey,      // claims migration fees via CollectMigrateFee
    pub migrate_to_amm_wallet:   Pubkey,      // can sign MigrateToAmm
    pub migrate_to_cpswap_wallet:Pubkey,      // can sign MigrateToCpswap
    pub padding_alignment:       [u8; 8],
    pub padding:                 [u64; 15],
}
```

PDA türetimi:

```ts
const [globalConfig] = PublicKey.findProgramAddressSync(
  [
    Buffer.from("global_config"),
    Buffer.from(quoteMint.toBytes()),
    Buffer.from([curveType]),
    u16ToBytes(index),
  ],
  LAUNCHLAB_PROGRAM_ID,
);
```

(İmzalamadan önce zincir üzerindeki hesaptan tam seed sırasını doğrulayın — programın `create_config` talimatı gerçeğin kaynağıdır.)

## Alan semantiği

### `curve_type` ve `index`

Birlikte bir `GlobalConfig`'i benzersiz şekilde anahtarlarlar. `(curve_type, index)` çifti başına bir `GlobalConfig` vardır:

- `curve_type = 0` — Sabit ürün sanal rezerv eğrisi. Varsayılan ve en çok kullanılan.
- `curve_type = 1` — Sabit fiyat eğrisi.
- `curve_type = 2` — Doğrusal fiyat eğrisi.

`index`, yöneticinin eğri türü başına birden fazla yapılandırma yayınlamasına izin veren bir `u16`'dır (örn. daha sıkı bir ücret ile bir tane, daha yüksek minimum alıntı artışı ile bir tane). `Initialize` sırasında başlatma bir `(curve_type, index)` çifti sağlar ve program eşleşen `GlobalConfig`'i yükler.

### Ücretler

- `trade_fee_rate` — işlem hacminin `1/1_000_000` cinsinden ifade edilir. Eğri üzerindeki her alım ve satışa uygulanır. `protocol_fee_owner`, `CollectFee` aracılığıyla payını talep eder.
- `migrate_fee` — mezuniyet sırasında bir kez alınan lamport cinsinden sabit bir ücret (veya yapılandırmaya bağlı olarak alıntı birimleri). `migrate_fee_owner` tarafından `CollectMigrateFee` aracılığıyla talep edilir.
- `max_share_fee_rate` — `10_000` (100 bps) olarak başlatılır. Bağlayıcı `PlatformConfig`'den **platform'un** paylaşım ücreti oranını sınırlar (bkz. [`platform-config`](/tr/products/launchlab/platform-config)). Program `trade_fee_rate + max_share_fee_rate < RATE_DENOMINATOR_VALUE` olmasını zorunlu kılar.

### Arz ve oran tabanları

Bu tabanlar, bir başlatmanın `Initialize` sırasında seçebileceği eğri şekli parametrelerini sınırlar. Yaratıcının `CurveParams`'ı bunlardan herhangi birini ihlal ederse, `Initialize` `InvalidInput` ile geri döner.

- `min_base_supply` — eğrinin bildirebileceği minimum `supply` (ondalık yok). Varsayılan `10_000_000`.
- `max_lock_rate` — `1/1_000_000` cinsinden ifade edilir; varsayılan `300_000` (%30). `total_locked_amount <= supply * max_lock_rate / 1_000_000` aracılığıyla vesting'i sınırlar.
- `min_base_sell_rate` — `1/1_000_000` cinsinden ifade edilir; varsayılan `200_000` (%20). `base_supply_graduation / supply`'yi aşağıdan sınırlar.
- `min_base_migrate_rate` — `1/1_000_000` cinsinden ifade edilir; varsayılan `200_000` (%20). Mezuniyet sonrası havuzu tohumlamak için kalan token sayısını sınırlar.
- `min_quote_fund_raising` — bir başlatmanın bildirebileceği minimum `quote_reserve_target` (ondalık ile). Varsayılan alıntı mint'inin `30_000_000_000` birimi.

### Alıntı mint'i ve protokol cüzdanları

- `quote_mint` — kullanıcıların satın aldığı varlık. Çoğu başlatma sarılı SOL (`So111…112`) veya USDC (`EPjF…Dt1v`) kullanır. Bir `GlobalConfig` bir alıntı mint'ine bağlıdır; farklı bir alıntı hedefine ihtiyaç duyan başlatmalar farklı bir `(curve_type, index)` hedefler. Mint, SPL Token programı veya Token-2022 tarafından sahip olunabilir — aşağıya bakın.
- `protocol_fee_owner` — `CollectFee`'yi imzalayan ve bu yapılandırmaya bağlı her başlatmada tahakkuk eden protokol ücretlerini talep eden pubkey. Zincir üzerinde depolanır; yönetici `UpdateConfig` aracılığıyla döndürebilir.
- `migrate_fee_owner` — `CollectMigrateFee`'yi imzalayan pubkey.

#### Token-2022 alıntı mint'leri

`CreateConfig`, Token-2022 `quote_mint`'ini kabul eder ve böyle bir yapılandırmaya bağlı havuzlar bunu sondan sona taşır: alıntı kasası, her iki ücret kasası ve paylaşım ücreti alıcısının token hesabı hepsi Token-2022'de oluşturulur ve swap talimatları alıntı tarafında bir `TransferFeeConfig` için hesap tutar. `PoolState.token_program_flag` bit1 başlatma başına seçimi kaydeder.

Birine güvenmeden önce bilmek değer iki kısıtlama vardır:

- **Kullanımdan kaldırılan `Initialize` buna karşı başlatılamaz.** Yalnızca `InitializeV2` ve `InitializeWithToken2022` Token-2022 alıntı programını kabul eder. Bkz. [`instructions`](/tr/products/launchlab/instructions#instruction-inventory).
- **Hiçbir uzantı izin listesi uygulanmaz.** CPMM ve CLMM'nin aksine, LaunchLab bir alıntı mint'inin uzantılarını taramaz — `CreateConfig` mint'i olduğu gibi alır, bu nedenle tek kapı yönetici takdirine bağlıdır hangi mint'lerin bir yapılandırmaya bağlanacağı. Programın `NoSupportExtension` kontrolü yalnızca LaunchLab'ın kendisinin oluşturduğu Token-2022 temel mint'lerini kapsar. Birine bağlanmayı yüksek güven gerektiren bir eylem olarak değerlendirin; bkz. [`reference/token-2022-support`](/tr/reference/token-2022-support#launchlab-quote-mints).

### Göç cüzdanları

Depolanan iki mezuniyet cüzdanı farklı imzacılar gerektirir:

- `migrate_to_amm_wallet` — depolanan `migrate_type = 0` olan mevcut eski bir başlatma için `MigrateToAmm`'yi imzalar.
- `migrate_to_cpswap_wallet` — `MigrateToCpswap`'ı imzalar. Yeni başlatılan her başlatma bu yolu kullanır.

Bunlar genellikle Raydium tarafından işletilen mezuniyet krankı tarafından tutulur, bu nedenle mezuniyet eğri eşiğe ulaştıktan kısa süre sonra gerçekleşir, yaratıcının bunu çağrmasını beklemek yerine.

### Platform tarafı izin listeleri

`GlobalConfig` artık `requires_platform_auth`'a sahip değildir. Eski baytı padding'dir, bu nedenle hesap boyutu değişmez. Erişim artık `PlatformConfig.restrict_global_config` ve o platform'un yöneticisi tarafından oluşturulan `PlatformAllowConfig` hesapları tarafından kontrol edilir. Bkz. [`platform-config`](/tr/products/launchlab/platform-config).

## Başlatma sırasında varsayılanlar

`CreateConfig` çağrıldığında, program birçok alanı sabit kodlanmış varsayılanlarla tohumlar:

```rust
self.max_share_fee_rate     = 10_000;                  // 100 bps
self.min_base_supply        = 10_000_000;              // no decimals
self.max_lock_rate          = 300_000;                 // 30%
self.min_base_migrate_rate  = 200_000;                 // 20%
self.min_base_sell_rate     = 200_000;                 // 20%
self.min_quote_fund_raising = 30_000_000_000;
```

Yönetici `curve_type`, `index`, `migrate_fee`, `trade_fee_rate`, `quote_mint` ve dört cüzdan pubkey'ini oluşturma sırasında açıkça ayarlar; sonraki değerler `UpdateConfig` aracılığıyla ayarlanabilir.

## Bir başlatma `GlobalConfig`'i nasıl seçer

`Initialize` sırasında, yaratıcı şunları geçer:

- Hangi `GlobalConfig` PDA'sını yükleyeceğini seçmek için `(curve_type, index)`.
- Eğri şeklini tanımlayan `CurveParams` (`supply`, `total_base_sell`, `total_quote_fund_raising`, `migrate_type`).
- Kilitli arzı tanımlayan `VestingParams`.
- Temel mint için `MintParams`.

Program şunları zorunlu kılar:

- `curve_type`, `global_config.curve_type` ile eşleşir.
- `supply >= global_config.min_base_supply`.
- `total_locked_amount <= supply * max_lock_rate / 1_000_000`.
- `total_base_sell >= supply * min_base_sell_rate / 1_000_000`.
- `(supply − total_base_sell − total_locked_amount) >= supply * min_base_migrate_rate / 1_000_000` — yani, mezuniyet sonrası havuzu tohumlamak için yeterli token.
- `total_quote_fund_raising >= min_quote_fund_raising`.
- `migrate_type == 1` (`CPSWAP`).
- Seçilen platform `restrict_global_config == 1` varsa, eşleşen `PlatformAllowConfig` dahil edilir.

`Initialize` sonrasında, başlatmanın `PoolState`'i `global_config` pubkey'ini doğrudan depolar, bu nedenle bağlama kalıcıdır.

## Güncelleme yolu

`UpdateConfig` yalnızca yönetici tarafından yapılır ve bir `(param: u8, value: u64)` çifti alır. Her `param` değeri hangi alanın mutasyona uğrayacağını seçer:

| `param` | Değiştirilen alan |
|---------|---------------|
| 0 | `migrate_fee` |
| 1 | `trade_fee_rate` |
| 2 | `max_share_fee_rate` |
| 3 | `min_base_supply` |
| 4 | `max_lock_rate` |
| 5 | `min_base_sell_rate` |
| 6 | `min_base_migrate_rate` |
| 7 | `min_quote_fund_raising` |

Cüzdan döndürmeleri (`protocol_fee_owner`, `migrate_fee_owner`, `migrate_to_amm_wallet`, `migrate_to_cpswap_wallet`) ayrı bir `Pubkey` argüman şekli alır; yönetici işlemi oluşturmadan önce tam gönderme tablosu için `update_config` kaynağını kontrol edin.

Eski `UpdateConfig` seçicisi `12` platform yetkilendirmesi için kaldırılmıştır. Platform yöneticileri artık kendi izin listelerini yönetir.

## İstemciden `GlobalConfig` okuma

```ts
import { Raydium } from "@raydium-io/raydium-sdk-v2";

// PDA türetimi ile getir:
const [configPda] = PublicKey.findProgramAddressSync(
  [
    Buffer.from("global_config"),
    quoteMint.toBytes(),
    Buffer.from([curveType]),
    u16ToBytes(index),
  ],
  LAUNCHLAB_PROGRAM_ID,
);

const config = await raydium.launchpad.getGlobalConfig(configPda);
console.log(config.tradeFeeRate, config.minQuoteFundRaising);
```

Mevcut tüm yapılandırmaları listeleyen bir UI için SDK'nın `getAllGlobalConfigs` yardımcısını yürütün veya onları yansıtan LaunchLab API uç noktasını sorgulayın; zincir üzerindeki hesap sayısı küçüktür (pratikte tek haneli).
