## Kurulum

Buradaki örnekler [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad) içindeki dosyaları yansıtır. Başlatma, demo repo'sunun [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) dosyasını takip eder:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Başlatma oluşturun

Kaynak: [`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts) (ve API tabanlı Bonk varyantı için [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts))

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId: /* reference/program-addresses'ten LaunchLab program ID */,
  // Yeni base mint için token metadata:
  name:   "Example Token",
  symbol: "EXMPL",
  uri:    "https://example.com/metadata.json",
  decimals: 6,

  // Curve parametreleri:
  curveType: 0,                                      // 0 = quadratic
  supply:    new BN(1_000_000_000).mul(new BN(10).pow(new BN(6))), // 1B base (6 dec)
  graduationFractionBps: 8000,                       // 80% → graduation
  initialK:  new BN("40"),                           // curve şekil parametresi

  // Quote tarafı:
  quoteMint: NATIVE_MINT,                            // WSOL
  openTime:  new BN(Math.floor(Date.now() / 1000) + 60),  // 1 dakika içinde açılır

  // Ücret politikası:
  fees: {
    buyNumerator:   new BN(100),                     // 1.00%
    buyDenominator: new BN(10_000),
    sellNumerator:  new BN(100),
    sellDenominator: new BN(10_000),
    lpShare:         new BN(60),
    creatorShare:    new BN(20),
    protocolShare:   new BN(20),
    totalShare:      new BN(100),
  },

  postGraduationLpPolicy: "burn",                    // "burn" | "lock" | "toCreator"

  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Launch:", extInfo.launchState.toBase58());
console.log("Base mint:", extInfo.baseMint.toBase58());
console.log("Create tx:", txId);
```

Notlar:

- `initialK`, quadratic curve için ölçek faktörüdür. Graduation sırasında belirli bir açılış CPMM fiyatını hedeflemek için ayarlayın. Türetme için [`products/launchlab/bonding-curve`](/tr/products/launchlab/bonding-curve) bölümüne bakın.
- SDK, base mint'i, metadata PDA'sını ve her iki vault'u tek bir işlemde oluşturur. Metadata URI'si uzunsa 1232 baytı aşabilir; bu durumda SDK iki işleme böler.
- `Initialize` sonrasında, başlatma `openTime` kadar işlem görmez. Front-runner'lara ilk alımı kapmak için daha az şans vermek için `openTime`'ı bir veya iki dakika ileri ayarlayın.

## Başlatma durumunu getirin

```ts
const launchId = new PublicKey("<LAUNCH_STATE>");

const launch = await raydium.launchpad.getLaunchById({ launchId });
console.log("Status:", ["Active","Graduated","Cancelled"][launch.status]);
console.log("Base sold:", launch.baseSold.toString(),
            "/", launch.baseSupplyMax.toString());
console.log("Quote collected:", launch.quoteReserveReal.toString(),
            "target:", launch.quoteReserveTarget.toString());
if (launch.status === 1) {
  console.log("Post-graduation CPMM pool:", launch.cpmmPoolState.toBase58());
}
```

`getLaunchById`, çözülen `LaunchState` ve hesaplanan "graduation'a doğru ilerleme" kesrini `Decimal` olarak döndürür.

## Alım — tam quote giriş

Kaynak: [`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

```ts
const quoteIn        = new BN(1).mul(new BN(10).pow(new BN(9)));  // 1 SOL
const minimumBaseOut = new BN(0);  // herhangi birini kabul et; üretim için sıkılaştır

// UI'nızın beklenen base_out'u gösterebilmesi için quote'u zincir dışında önizleyin:
const preview = raydium.launchpad.computeBuyBase({
  launchState: launch,
  quoteIn,
});
console.log("Expected base_out:", preview.baseOut.toString(),
            "price impact:", preview.priceImpact.toString());

const { execute } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn,
  minimumBaseOut,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

`computeBuyBase`, zincir üstü Newton çözücüsünü (quadratic curve) veya kapalı form CPMM-tersini (curve_type 1) yansıtır. "Alacağınız" UI alanını doldurmak için kullanın.

## Alım — tam base çıkış

```ts
const baseOut         = new BN(1_000_000).mul(new BN(10).pow(new BN(6)));  // 1M base
const maximumQuoteIn  = new BN(2).mul(new BN(10).pow(new BN(9)));          // 2 SOL'da sınırla

const { execute } = await raydium.launchpad.buyExactOut({
  launchInfo: launch,
  baseOut,
  maximumQuoteIn,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

"Tam olarak X token alın" UI'ları için kullanışlıdır. Curve yeterince hareket etmişse ve quote gereksinimi şimdi `maximumQuoteIn`'i aşıyorsa `ExceededSlippage` ile reddeder.

## Satış

```ts
const baseIn           = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M base
const minimumQuoteOut  = new BN(0);

const { execute } = await raydium.launchpad.sellExactIn({
  launchInfo: launch,
  baseIn,
  minimumQuoteOut,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Curve'ün satış yolu alım yoluna simetriktir: `base_sold`'u `baseIn` kadar azaltmak, `base_sold − baseIn` ile `base_sold` arasında curve'ün altındaki entegre alanına eşit `quote_out` döndürür, satış ücreti eksi.

## Eşik geçişi alımında otomatik graduation

SDK, post-alım durumunun eşiği geçeceğini algıladığında `buy*` işleminin içine bir `Graduate` talimatı zincirler:

```ts
const { execute, willGraduate } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn: new BN(100).mul(new BN(10).pow(new BN(9))),    // büyük alım
  minimumBaseOut: new BN(0),
  txVersion: TxVersion.V0,
  autoGraduate: true,                                      // varsayılan
});

if (willGraduate) {
  console.log("This buy will trigger graduation.");
}

const { txId } = await execute({ sendAndConfirm: true });
```

`Graduate` izinsiz olduğundan, herkes (MEV bot'u da dahil) eşik geçildikten sonra ilk `Graduate`'i iniş için yarışabilir — tipik olarak dakikalar değil saniyeler sonra. İlk iniş yapan sadece CPMM pool hesaplarının kirasını öder; başka bir fayda almazlar.

## Manuel `Graduate`

`autoGraduate` kapalıysa veya eşik geçişi işlemi başarısız olduysa, graduation'ı ayrı olarak başlatabilirsiniz:

```ts
const { execute } = await raydium.launchpad.graduate({
  launchInfo: launch,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Gönderim sırasında `quote_reserve_real < quote_reserve_target` ise `NotAtThreshold` ile geri döner. Yeniden deneme güvenlidir — başarıdan sonra ikinci `Graduate` denemesi `NotActive` ile geri döner.

## Başlatmayı yaşam döngüsü boyunca izleyin

Bir araya getirerek, bir izleme betiği şöyle görünebilir:

```ts
async function watch(launchId: PublicKey) {
  while (true) {
    const launch = await raydium.launchpad.getLaunchById({ launchId });
    const progress =
      Number(launch.quoteReserveReal) /
      Number(launch.quoteReserveTarget);

    console.log(
      `status=${["Active","Graduated","Cancelled"][launch.status]}`,
      `progress=${(progress * 100).toFixed(2)}%`,
      `num_buys=${launch.stateData.numBuys}`,
    );

    if (launch.status === 1) {
      console.log("Graduated to CPMM pool:", launch.cpmmPoolState.toBase58());
      break;
    }
    await new Promise(r => setTimeout(r, 10_000));
  }
}
```

## gRPC üzerinden config'leri ve pool'ları izleyin

Kaynak: [`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

LaunchLab programını Yellowstone gRPC üzerinden abone olur ve her mint'in token programı ile her `GlobalConfig` ve `PoolState` güncellemesini kaydeder. Bir `accounts` aboneliğinde iki `datasize` filtresi iki hesap türünü ayırır, bu nedenle tek bir akış her ikisini de kapsar.

Demo, [Token-2022 quote-mint sürümü](/tr/reference/changelog/2026-08-24-launchlab-token2022-quote-mint) tarafından gerekli kılınan başlatmanın mint'lerini sınıflandırmak için en kısa doğru referanstır:

- **Pool'lar** doğrudan `PoolState.token_program_flag`'den sınıflandırılır, hiç mint getirmeden base mint için bit0'ı ve quote mint için bit1'i çözer. Tüm baytı `0`'a karşı test etmek — quote mint'leri eski olduğu sürece yeterli idi — quote mint Token-2022 olduğunda eski bir base mint'i Token-2022 olarak yanlış okur.
- **Config'ler** bu şekilde sınıflandırılamaz: bir `GlobalConfig` quote mint'inin adresini ve program bayrağını depolamaz, bu nedenle demo mint hesabının sahibini bir kez okur ve mint başına önbelleğe alır.

Ayrıca ikisini birbirine karşı çapraz kontrol eder, bu da kendi indexer'ınızda tutmanız gereken yararlı bir iddidir. `create` ile `update`'in demo'nun kendi önbelleklerinden çıkarıldığını unutmayın, başlangıçta `getProgramAccounts`'tan tohumlanır; bu tohumlama devre dışı bırakılırsa, "create"'i "bu akışta ilk görülen" olarak okuyun.

gRPC erişimi genel RPC yüzeyinin bir parçası değildir — demo repo'sunun [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md) dosyasına bakın.

## Rust CPI

LaunchLab'ı kendi Anchor programınızdan çağırmak nadirdir (çoğu başlatma entegrasyonu yalnızca TS tarafıdır). Bunu yaparsanız, program `cpi::accounts::Buy`, `cpi::accounts::Sell` vb. ile bir Anchor crate `raydium_launchlab` gönderir — desen CPMM / CLMM CPI örneklerini yansıtır. Bu site doldurulduktan sonra genelleştirilmiş bir şablon için [`sdk-api/rust-cpi`](/tr/sdk-api/rust-cpi) bölümüne bakın.

## Tuzaklar

- **Ücret bölme aritmetiği kapalı bir tane.** `total_share` tam olarak `lp_share + creator_share + protocol_share` değilse, `Initialize` `InvalidFeeShares` ile geri döner. `totalShare`'i toplama eşit olarak ayarlayın.
- **İzin verilmeyen bir quote mint kullanmak.** `launch_config.allowed_quote_mints` sabit bir listedir; başka bir mint geçirmek geri döner. Önce `raydium.launchpad.getConfig()` ile kontrol edin.
- **Metadata boyutu.** Uzun `uri` dizgileri Metaplex CPI'sini bütçenin üzerine iter. `uri`'yi ~200 karakterin altında tutun — çoğu CDN tarafından barındırılan JSON metadata kolayca sığar.
- **Graduation yarışı.** Otomatik bot'lar `quote_reserve_real`'i izler ve eşik geçildikten sonra bir veya iki slot içinde `Graduate`'i ön çalıştırır. Bu zararsızdır — sadece onlara kira maliyeti — ancak UI'nızın `status` geçişlerini hızlı olaylar olarak ele alması gerektiği anlamına gelir.
