## Kurulum

Buradaki örnekler [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad) içindeki dosyaları yansıtır. Başlatma, demo repo'nun [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) dosyasını takip eder:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Başlatma oluşturun

Kaynak: [`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts) (ve Bonk varyantı için [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts))

Başlatmanın ekonomisinin çoğu **argüman değildir** — `configId` aracılığıyla bağladığınız `GlobalConfig`'ten gelir ve SDK geri kalanını API'nin varsayılan parametrelerinden doldurur. Mint'in kimliğini, bağlanacak konfigürasyonu ve (isteğe bağlı olarak) ilk bir alımı geçersiniz:

```ts
import {
  LAUNCHPAD_PROGRAM,
  DEVNET_PROGRAM_ID,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";

const programId = LAUNCHPAD_PROGRAM;          // devnet: DEVNET_PROGRAM_ID.LAUNCHPAD_PROGRAM

// Temel mint, oluşturduğunuz ve imzaladığınız bir keypair'dir.
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// GlobalConfig'i bağlayın: (quote mint, curve_type, index).
const configId = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
if (!configData) throw new Error("config not found");
const configInfo = LaunchpadConfig.decode(configData.data);
const mintBInfo = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, transactions, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "Example Token",
  symbol: "EXMPL",                 // en fazla 10 karakter olmalı
  uri:    "https://example.com/metadata.json",   // boş olmamalı
  migrateType: "amm",              // "amm" | "cpmm"

  configId,
  configInfo,                      // isteğe bağlı; SDK configId'yi atlandığında yeniden okur
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  // İsteğe bağlı ilk alım aynı bundle'da.
  createOnly: true,                // true = sadece mint'i oluştur
  buyAmount:  new BN(1000),        // createOnly true olduğunda yoksayılır
  slippage:   new BN(100),         // 100 = %1

  extraSigners: [pair],            // temel mint keypair'i imzalamalı
  txVersion: TxVersion.V0,

  // Varsayılanlar bağlı config'in API varsayılanlarından gelir; sadece gerekirse geçersiz kılın:
  // supply:            new BN(1_000_000_000_000_000),
  // totalSellA:        new BN(793_100_000_000_000),
  // totalFundRaisingB: new BN(85_000_000_000),   // mintB SOL olduğunda 85 SOL
  // totalLockedAmount: new BN(0),
  // cliffPeriod:       new BN(0),                // saniye
  // unlockPeriod:      new BN(0),                // saniye
  // platformId:        new PublicKey("4Bu96XjU84XjPDSpveTVf6LYGCkfW5FK7SNkREWcEfV4"), // Raydium'un, varsayılan
});

// createLaunchpad MULTIPLE işlem döndürür - bunları sırayla yürütün.
const { txIds } = await execute({ sequentially: true });
console.log("Pool:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
console.log("Create txs:", txIds);
```

Notlar:

- **Hiçbir** `curveType`, `graduationFractionBps`, `initialK`, `quoteMint`, `openTime`, `fees` veya `postGraduationLpPolicy` argümanı yoktur. Curve şekli ve quote mint, bağladığınız `GlobalConfig`'in özellikleridir; ücret oranları `GlobalConfig` ve `PlatformConfig`'te yaşar; mezuniyet sırasında LP elden çıkarılması bir `PlatformConfig` ayarıdır. `InitializeV2`'nin tam olarak ne kabul ettiğini görmek için [`products/launchlab/instructions`](/tr/products/launchlab/instructions#initialize) bölümüne bakın.
- 10 karakterden uzun `symbol` ve boş `uri` her ikisi de herhangi bir RPC'den önce istemci tarafında reddedilir.
- `transferFeeExtensionParams` geçirmek, builder'ı `InitializeWithToken2022`'ye geçirir ve `migrateType`'ı `"cpmm"`'ye zorlar.
- Builder bir `transactions` dizisi döndürür; `createOnly: false` ilk alım işlemini ekler. Her zaman `execute({ sequentially: true })` çalıştırın — mint alımdan önce var olmalıdır.

## Başlatma durumunu getirin

Kaynak: [`src/launchpad/poolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/poolInfo.ts)

`getLaunchById` yoktur. Pool id, `(programId, mintA, mintB)` öğesinin bir PDA'sıdır ve `getRpcPoolInfo` bağlı `configInfo` ile birlikte çözülen `PoolState`'i döndürür:

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log("status:", poolInfo.status);
console.log("base sold:", poolInfo.realA.toString(), "/", poolInfo.totalSellA.toString());
console.log("quote raised:", poolInfo.realB.toString(), "/", poolInfo.totalFundRaisingB.toString());

// Curve'deki mevcut spot fiyat.
const price = Curve.getPrice({
  poolInfo,
  curveType: poolInfo.configInfo.curveType,
  decimalA: poolInfo.mintDecimalsA,
  decimalB: poolInfo.mintDecimalsB,
});
console.log("price:", price.toString());
```

`getRpcPoolsInfo({ poolIdList })` toplu formdur ve pool id'ye göre anahtarlanmış bir `poolInfoMap` döndürür — döngü yapmak yerine portföy görünümleri için kullanın. Ham hesapları kendiniz çözmek istiyorsanız, `LaunchpadPool.decode` ve `LaunchpadConfig.decode` dışa aktarılır.

## Alım — tam quote giriş

Kaynak: [`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

Zincir dışı fiyat teklifi yardımcısı **`Curve.buyExactIn`**'dir, dışa aktarılan `Curve` sınıfında statik bir yöntemdir — `raydium.launchpad`'da bir yöntem değildir. İşlem builder'ı **`buyToken`**'dır. Her ikisinin de platform'un ücret oranlarına ihtiyacı vardır, bunlar ayrı bir `PlatformConfig` hesabında yaşar:

```ts
import { Curve, PlatformConfig, toTransferFeeConfig } from "@raydium-io/raydium-sdk-v2";

const inAmount = new BN(1).mul(new BN(10).pow(new BN(9)));   // 1 SOL
const slippage = new BN(100);                                 // 100 = %1

const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });
const platformData = await raydium.connection.getAccountInfo(poolInfo.platformId);
const platformInfo = PlatformConfig.decode(platformData!.data);

const mintInfo  = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(poolInfo.mintB);
const epochInfo = await raydium.connection.getEpochInfo();

// Zincir dışı önizleme — zincir üstü curve matematiğini yansıtır.
const res = Curve.buyExactIn({
  poolInfo,
  amountB: inAmount,
  protocolFeeRate: poolInfo.configInfo.tradeFeeRate,
  platformFeeRate: platformInfo.feeRate,
  creatorFeeRate:  platformInfo.creatorFeeRate,
  curveType:       poolInfo.configInfo.curveType,
  shareFeeRate:    new BN(0),
  transferFeeConfigA: mintInfo.extensions.feeConfig  ? toTransferFeeConfig(mintInfo,  epochInfo.epoch) : undefined,
  transferFeeConfigB: mintBInfo.extensions.feeConfig ? toTransferFeeConfig(mintBInfo, epochInfo.epoch) : undefined,
  slot: await raydium.connection.getSlot(),
});
console.log("expected out:", res.amountA.amount.sub(res.amountA.fee ?? new BN(0)).toString());

const { execute, extInfo } = await raydium.launchpad.buyToken({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  transferFeeConfigB: toTransferFeeConfig(mintBInfo, epochInfo.epoch),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,
  buyAmount:       inAmount,
  slippage,                       // BN bps'de; SDK minMintAAmount'ı ondan türetir
  txVersion: TxVersion.V0,
});

console.log("expected receive amount:", extInfo.decimalOutAmount.toString());
const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

`slippage` yerine `minMintAAmount`'ı açıkça geçebilirsiniz; her ikisini de atın ve SDK sınırı canlı RPC verilerinden hesaplar. `shareFeeRate`, `poolInfo.configInfo.maxShareFeeRate`'i aşmamalı ve sadece bir `shareFeeReceiver` da geçtiğinizde geçerlidir.

## Alım — tam base çıkış

Builder **`buyTokenExactOut`**'dur ve miktar argümanları `outAmount` (istediğiniz base) ve `maxBuyAmount` (en fazla harcayacağınız quote) şeklindedir. `Curve.buyExactOut({ poolInfo, amountA, ... })` eşleşen zincir dışı önizlemedir.

```ts
const { execute, extInfo } = await raydium.launchpad.buyTokenExactOut({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,

  outAmount:    new BN(1_000_000).mul(new BN(10).pow(new BN(6))),  // 1M base
  maxBuyAmount: new BN(2).mul(new BN(10).pow(new BN(9))),          // en fazla 2 SOL
  slippage:     new BN(100),

  txVersion: TxVersion.V0,
});

console.log("out:", extInfo.outAmount.toString(), "max spent:", extInfo.maxSpentAmount.toString());
await execute({ sendAndConfirm: true });
```

"Tam olarak X token satın al" UI'ları için kullanışlıdır. Builder, sıfır `outAmount`'ı istemci tarafında reddeder ve curve yeterince hareket ettiyse program geri döner, quote gereksinimi `maxBuyAmount`'ı aşar.

## Satış

Kaynak: [`src/launchpad/sell.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/sell.ts)

Builder **`sellToken`**'dır (tam quote çıkış varyantı için `sellTokenExactOut`), `sellAmount` ve isteğe bağlı `minAmountB` ile. `Curve.sellExactIn({ poolInfo, amountA, ... })` bunu önizler.

```ts
const inAmount = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M base

const res = Curve.sellExactIn({
  poolInfo,
  amountA: inAmount,
  protocolFeeRate: poolInfo.configInfo.tradeFeeRate,
  platformFeeRate: platformInfo.feeRate,
  creatorFeeRate:  platformInfo.creatorFeeRate,
  curveType:       poolInfo.configInfo.curveType,
  shareFeeRate:    new BN(0),
  transferFeeConfigA: mintInfo.extensions.feeConfig  ? toTransferFeeConfig(mintInfo,  epochInfo.epoch) : undefined,
  transferFeeConfigB: mintBInfo.extensions.feeConfig ? toTransferFeeConfig(mintBInfo, epochInfo.epoch) : undefined,
  slot: await raydium.connection.getSlot(),
});
console.log("expected quote out:", res.amountB.toString());

const { execute } = await raydium.launchpad.sellToken({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,
  sellAmount:      inAmount,
  slippage:        new BN(100),
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Curve'ün satış yolu alım yoluna simetriktir: `real_a`'yı `sellAmount` kadar azaltmak, `real_a − sellAmount` ile `real_a` arasında curve'ün altındaki entegre alanına eşit `quote_out` döndürür, satış ücreti eksi. `sellAmount` sıfırdan büyük olmalıdır — builder sıfırı herhangi bir RPC'den önce reddeder.

## Mezuniyet

<Warning>
  **Mezuniyet, bir entegratörün tetikleyebileceği bir şey değildir.** `raydium.launchpad.graduate` yoktur, alım builder'larında `autoGraduate` bayrağı yoktur ve dönüş değerlerinde `willGraduate` alanı yoktur. Zincir üstünde, mezuniyet `MigrateToCpswap` (veya eski `MigrateToAmm`) şeklindedir ve her iki talimat da imzalayanlarını bağlı `GlobalConfig`'te kaydedilen bir cüzdana kısıtlar — `migrate_to_cpswap_wallet` ve `migrate_to_amm_wallet` sırasıyla. Başka bir imzalayan'dan gelen bir çağrı `InvalidOwner` ile başarısız olur. **İzinsiz değildir** ve hiçbir MEV bot bunu yarışamaz.
</Warning>

Bu cüzdanlar Raydium'un mezuniyet crank'ı tarafından işletilir, bu nedenle pratikte göç, eşik geçildikten sonra son alımı kimin yaptığından bağımsız olarak saniyeler içinde gerçekleşir. Bir entegratör tarafından yapılacak tek şey, durum geçişini hızlı bir olay olarak ele almaktır: `getRpcPoolInfo`'yi yoklayın (veya aşağıda gRPC üzerinden abone olun) ve `status` değiştiğinde UI'nızı curve'den sonuçlanan CPMM pool'una geçirin.

Hesap listeleri, göç ücreti ve mezuniyet sırasında LP'nin nasıl bölündüğü için [`products/launchlab/instructions`](/tr/products/launchlab/instructions#migratetoamm-/-migratetocpswap) bölümüne bakın.

## Yaratıcı ücretlerini toplayın

Kaynak: [`src/launchpad/claimCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/claimCreatorFee.ts) (tek mint) ve [`collectAllCreatorFees.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/collectAllCreatorFees.ts) (toplu)

Yöntem **`claimCreatorFee`**'dir (toplu form için `claimMultipleCreatorFee`). **Quote mint** tarafından anahtarlanır, başlatma tarafından değil — bir çağrı, imzalayanın o mint'te biriken yaratıcı ücretlerini başlatmalarında temizler:

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute } = await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,          // talep edilecek quote mint
  // mintBProgram: TOKEN_PROGRAM_ID,   // veya TOKEN_2022_PROGRAM_ID
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Biriken yaratıcı ücreti sayacını yaratıcının quote mint'teki ATA'sına aktarır. Mezuniyet öncesi veya sonrası çağrılabilir; muazzam bir bakiye birikene kadar beklemek yerine periyodik olarak kullanın. Platform operatörleri paralel `claimPlatformFee` / `claimAllPlatformFee` / `claimVaultPlatformFee` builder'larına sahiptir.

## Başlatmayı yaşam döngüsü boyunca izleyin

Bir araya getirerek, bir izleme betiği şöyle görünebilir:

```ts
async function watch(poolId: PublicKey) {
  const startStatus = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

  while (true) {
    const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
    const progress = Number(p.realB.toString()) / Number(p.totalFundRaisingB.toString());

    console.log(`status=${p.status}`, `progress=${(progress * 100).toFixed(2)}%`);

    if (p.status !== startStatus) {
      console.log("status changed - the launch has migrated; switch to the pool page");
      break;
    }
    await new Promise((r) => setTimeout(r, 10_000));
  }
}
```

Tek bir başlatmada `getRpcPoolInfo`'yi 10 saniyelik bir zamanlayıcıda yoklamak iyidir. Bir indexer için, bunun yerine aşağıdaki gRPC aboneliğini kullanın — `getRpcPoolsInfo({ poolIdList })` toplu işlem yapar, ancak yüzlerce pool'u yoklamak hiçbir fayda için RPC kredilerini yakar.

## Konfigürasyonları ve pool'ları gRPC üzerinden izleyin

Kaynak: [`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

LaunchLab programına Yellowstone gRPC üzerinden abone olur ve her `GlobalConfig` ve `PoolState` güncellemesini her mint'in token programı ile günlüğe kaydeder. Bir `accounts` aboneliğinde iki `datasize` filtresi iki hesap türünü ayırır, bu nedenle tek bir akış her ikisini de kapsar.

Demo, [Token-2022 quote-mint sürümü](/tr/reference/changelog/2026-08-24-launchlab-token2022-quote-mint) gerekli kılan başlatmanın mint'lerini sınıflandırmak için en kısa doğru referanstır:

- **Pool'lar** doğrudan `PoolState.token_program_flag`'den sınıflandırılır, hiçbir mint getirmeden bit0'ı base mint için ve bit1'i quote mint için çözerek. Tüm baytı `0`'a karşı test etmek — quote mint'ler eski olduğu sürece yeterli idi — quote mint Token-2022 olduğunda eski bir base mint'i yanlış okur.
- **Konfigürasyonlar** bu şekilde sınıflandırılamaz: bir `GlobalConfig` quote mint'inin adresini ve program bayrağını depolamaz, bu nedenle demo mint hesabının sahibini bir kez okur ve mint başına önbelleğe alır.

Ayrıca ikisini birbirine karşı çapraz kontrol eder, bu da kendi indexer'ınızda tutmak için yararlı bir iddidir. `create` ile `update` arasındaki fark, demo'nun kendi önbelleklerinden çıkarılır, başlangıçta `getProgramAccounts`'tan tohumlanır; bu tohumlama devre dışı bırakıldığında, "oluştur"u "bu akışta ilk görülen" olarak okuyun.

gRPC erişimi genel RPC yüzeyinin bir parçası değildir — demo repo'nun [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md) dosyasına bakın.

## Rust CPI

Kendi Anchor programınızdan LaunchLab'ı çağırmak nadirdir (çoğu başlatma entegrasyonu sadece TS tarafında). Yaparsanız:

- Crate **`raydium-launchpad`**'dır (lib adı `raydium_launchpad`), sürüm `0.2.0` ve bir `cpi` özelliğini ortaya çıkarır. **`raydium_launchlab` yoktur.**
- **crates.io'da yayınlanmamıştır** — diğer Raydium program crate'leriyle aynı şekilde git revizyonuna göre bağımlılık yapın.
- CPI giriş noktaları, SDK'nın TypeScript yöntemlerinden sonra değil, zincir üstü talimatlardan sonra adlandırılır: `buy_exact_in`, `buy_exact_out`, `sell_exact_in`, `sell_exact_out`, `claim_creator_fee`, `create_vesting_account`, `claim_vested_token`. `migrate_to_amm` / `migrate_to_cpswap`, `GlobalConfig` göç cüzdanlarına imzalayan kapılı ve bir entegratör programından çağrılamaz.

Crate sabitleme kuralları için [`sdk-api/rust-cpi`](/tr/sdk-api/rust-cpi) bölümüne bakın — özellikle LaunchLab ve CLMM'ye CPI yapabilen bir crate'i belirleyen Anchor sürümü bölümü.

## Tuzaklar

- **Zincir üstü talimat adlarını SDK yöntem adlarıyla karıştırmak.** Program `buy_exact_in` / `sell_exact_in`'e sahiptir; SDK `buyToken` / `sellToken`'a sahiptir. `buyExactIn` ve `sellExactIn` sadece **`Curve`'de statik yöntemler** olarak mevcuttur ve bir fiyat teklifi hesaplarlar — bir işlem oluşturmazlar.
- **`extraSigners`'ı unutmak.** `createLaunchpad`, base mint'i oluşturduğunuz bir keypair'den oluşturur, bu nedenle bu keypair imzalamalıdır. `extraSigners: [pair]`'ı atın ve işlem imza doğrulaması başarısız olur.
- **Quote mint'i seçmemek.** Bir tane geçmezsiniz. Quote mint, `configId` aracılığıyla bağladığınız `GlobalConfig`'in bir özelliğidir — `getPdaLaunchpadConfigId(programId, quoteMint, curveType, index)`. Farklı bir quote mint'e karşı başlatmak için farklı bir config bağlayın; `raydium.api.fetchLaunchConfigs()` varsayılan parametreleriyle mevcut olanları listeler.
- **Metadata boyutu.** Uzun `uri` dizileri Metaplex CPI'ı bütçenin üzerine çıkarır. `uri`'yi ~200 karakterin altında tutun — çoğu CDN tarafından barındırılan JSON metadata kolayca uyar. `symbol` 10 karakterde sabit sınırlandırılır.
- **Mezuniyeti girebileceğiniz bir yarış olarak ele almak.** Değildir — yukarıdaki uyarıya bakın. UI'nız yine de `status` geçişlerini hızlı olaylar olarak ele almalıdır, çünkü Raydium'un crank'ı göç'ü eşik geçildikten sonra saniyeler içinde gerçekleştirir.
