SDK'nın `raydium.launchpad.getLaunchById` işlevi `PoolState` artı başlatmanın mezun olup olmadığını gösteren bir bayrak döndürür; eğer mezun olduysa, göç sonrası havuz kimliği dahil edilir.

## `PoolState`

Başlatma başına kök durum. Aşağıdaki alan adları zincir üzerindeki Rust yapısıyla eşleşir (`states/pool.rs`); bazı değerler okunabilirlik için basitleştirilmiştir — tam bellek düzeni için kaynağa bakın.

```rust
// states/pool.rs (kısaltılmış)
pub struct PoolState {
    pub epoch:                     u64,        // recent_epoch tracker
    pub auth_bump:                 u8,
    pub status:                    u8,         // PoolStatus enum
    pub base_decimals:             u8,
    pub quote_decimals:            u8,
    pub migrate_type:              u8,         // 0 = AMM v4, 1 = CPMM
    pub supply:                    u64,        // total base tokens (no decimals)
    pub total_base_sell:           u64,        // base supply allocated to the curve
    pub virtual_base:              u64,        // virtual-reserve seed
    pub virtual_quote:             u64,        // virtual-reserve seed
    pub real_base:                 u64,        // base sold so far
    pub real_quote:                u64,        // quote raised so far (excl. fees)
    pub total_quote_fund_raising:  u64,        // graduation threshold in quote

    pub quote_protocol_fee:        u64,        // accrued, pending CollectFee
    pub platform_fee:              u64,        // accrued, pending ClaimPlatformFee
    pub migrate_fee:               u64,        // accrued, pending CollectMigrateFee
    pub vesting_schedule:          VestingSchedule,

    pub global_config:             Pubkey,
    pub platform_config:           Pubkey,
    pub creator:                   Pubkey,
    pub base_mint:                 Pubkey,
    pub quote_mint:                Pubkey,
    pub base_vault:                Pubkey,
    pub quote_vault:               Pubkey,

    pub amm_creator_fee_on:        u8,         // 0 = QuoteToken, 1 = BothToken (CPMM-only)
    pub token_program_flag:        u8,         // bit0 = base mint, bit1 = quote mint; 0 = SPL Token, 1 = Token-2022
    pub padding:                   [u8; 54],
}

#[derive(Default, Debug, Clone)]
pub struct VestingSchedule {
    pub total_locked_amount:    u64,
    pub cliff_period:           u64,
    pub unlock_period:          u64,
    pub start_time:             u64,           // set at graduation
    pub allocated_share_amount: u64,           // running sum across VestingRecords
}
```

`PoolStatus` değerleri (Anchor IDL'den):

```
0 = Funding         — alımları/satışları kabul eder; quote_reserve_target'ın altında
1 = Migrate         — quote_reserve_target'a ulaşıldı; MigrateTo* bekliyor
2 = Migrated        — MigrateTo* zaten yürütüldü; vesting saati çalışıyor
```

Entegratör tarafından kullanılan alanlar:

- **`status`** — üç değer, monoton (Funding → Migrate → Migrated). Okumalar her zaman güvenli; yazımlar kapılı.
- **`real_base`**, **`real_quote`** — mevcut eğri durumu. `virtual_base` / `virtual_quote` ile birlikte kasalara dokunmadan spot fiyatı hesaplamak için yeterlidirler. Bkz. [`bonding-curve`](/tr/products/launchlab/bonding-curve).
- **`total_base_sell`** vs `real_base` — UI'ler için "mezuniyete doğru ilerleme" oranı.
- **`migrate_type`** — yeni başlatma `1` (`CPSWAP`) gerektirir. Depolanan `0` yalnızca CPMM-only uygulaması öncesinde oluşturulan mevcut bir başlatma için anlamlı kalır.
- **`amm_creator_fee_on`** — mezuniyet sonrası CPMM havuzunda `creator_fee_on = OnlyQuoteToken` (`0`) veya `BothToken` (`1`) seçer. Göç hedefini seçmez. Bkz. [`creator-fees`](/tr/products/launchlab/creator-fees).
- **`token_program_flag`** — bir boolean değil, bir bit alanı. Bit0 temel mint, bit1 alıntı mint'tir, her biri SPL Token için `0`, Token-2022 için `1`'dir, bu nedenle bayt dört değer alır: `0` (her ikisi de eski), `1` (Token-2022 temel), `2` (Token-2022 alıntı), `3` (her ikisi de Token-2022). Bir mint'i `(token_program_flag >> bit) & 1` ile okuyun. Tüm baytı `0` ile karşılaştırarak temel mint'i sınıflandırmak `2`'yi yanlış programa çözer. Bit1, Token-2022 alıntı mintleri desteklenene kadar sabit `0` idi.
- **`quote_protocol_fee` / `platform_fee` / `migrate_fee`** — üç bağımsız ücret sayacı. Her birinin kendi talep talimatı vardır; bkz. [`instructions`](/tr/products/launchlab/instructions).
- **`vesting_schedule`** — her `PoolState` üzerinde mevcut ancak `total_locked_amount == 0` olduğunda etkin değil. Tam yaşam döngüsü için bkz. [`vesting`](/tr/products/launchlab/vesting).

## Yetki PDA'sı

LaunchLab, tüm başlatmalar arasında **tek** bir yetki PDA'sı kullanır, başlatma başına tohum olmadan türetilir:

```ts
const LAUNCHLAB_PROGRAM_ID = new PublicKey("<LAUNCHLAB_ID>"); // bkz. reference/program-addresses

const [authority, bump] = PublicKey.findProgramAddressSync(
  [Buffer.from("vault_auth_seed")],
  LAUNCHLAB_PROGRAM_ID,
);
```

Bu tek PDA:

- Her başlatmanın `base_vault` ve `quote_vault` üzerinde yetki.
- `base_mint` üzerinde hiçbir şey değil — mint yetkilisi `InitializeV2` dönmeden önce iptal edilir (aşağıya bakın).
- CPMM mezuniyet CPI'sinde imzalayan ve mevcut durum için eski AMM v4 mezuniyetinde.
- `ClaimVestedToken` transferlerinin temel kasadan dışarı imzalayanı.
- Token-2022 temel mint'inin `TransferFeeConfig` üzerinde `transfer_fee_config_authority` — ve `withdraw_withheld_authority` da, ancak yalnızca platform `PlatformConfig.transfer_fee_extension_auth` ayarlamadığında.

`mint_authority` mezuniyet sırasında değil, **başlatma** talimatında iptal edilir: `InitializeV2` ve `InitializeWithToken2022` tam arzı `base_vault` içine basarlar ve ardından aynı talimatında `MintTokens`'ı `None` olarak ayarlarlar. Arz bu nedenle başlatma var olduğu andan itibaren sabitlenir ve göçün mint-authority adımı yoktur. Yan etki: kimse temel mint için imza atamaz, bu nedenle kirasını [`CollectExcessLamports`](/tr/products/launchlab/instructions#collectexcesslamports) tarafından geri talep edilemez.

İki ek PDA ücret kasalarını kapılar:

```ts
const [creatorFeeVaultAuthority] = PublicKey.findProgramAddressSync(
  [Buffer.from("creator_fee_vault_auth_seed")],
  LAUNCHLAB_PROGRAM_ID,
);

const [platformFeeVaultAuthority] = PublicKey.findProgramAddressSync(
  [Buffer.from("platform_fee_vault_auth_seed")],
  LAUNCHLAB_PROGRAM_ID,
);
```

Bunlar `ClaimCreatorFee` ve `ClaimPlatformFeeFromVault` sırasında ilgili ücret kasasından transferi imzalarlar.

## Temel mint

`Initialize` tarafından satır içi oluşturulur:

- `mint_authority = authority` (mezuniyette iptal edilir).
- `freeze_authority = None`.
- `supply = supply`, tamamen `base_vault` içine basılır.
- `decimals` yaratıcı tarafından `Initialize` sırasında seçilir (yaygın olarak 6).

Tam arz önceden basıldığından, `base_mint.supply` başlatmanın ömrü boyunca sabittir. Eğri alımları tokenleri `base_vault`'tan alıcıya taşır, ancak `mint_to` çağırmaz.

`Initialize` / `InitializeV2` SPL Token temel mintleri oluşturur. Özel `InitializeWithToken2022` talimatı temel mint'in Token-2022 mint'i olmasını sağlar (isteğe bağlı `TransferFeeConfig` ile). Üç başlatma yolu da CPMM mezuniyeti gerektirir.

`InitializeWithToken2022` bir `TransferFeeConfig` eklediğinde, mint `transfer_fee_config_authority = authority` ve `withdraw_withheld_authority = PlatformConfig.transfer_fee_extension_auth` ile oluşturulur, platform bu alanı ayarlamadığında `authority`'ye geri döner. Her iki yetki de mezuniyette platform anahtarına yeniden atanır, çekme tarafı yalnızca PDA hala tutuyorsa. Bkz. [`platform-config`](/tr/products/launchlab/platform-config#token-2022-transfer-fee-authorities).

Alıntı mint, temel mint'ten bağımsızdır ve kendisi Token-2022 mint'i olabilir — `InitializeV2` ve `InitializeWithToken2022` alıntı-program yuvasında her iki programı da kabul eder. Kullanımdan kaldırılan `Initialize` yapmaz: alıntı-program hesabı hala SPL Token'a yazılmıştır, bu nedenle alıntı mint'i Token-2022 olan bir yapılandırma yalnızca diğer ikisi aracılığıyla başlatılabilir. Alıntı mint asla LaunchLab tarafından oluşturulmaz; `GlobalConfig.quote_mint` adlandırdığı şeydir. Bkz. [`global-config`](/tr/products/launchlab/global-config#token-2022-quote-mints) ve [`reference/token-2022-support`](/tr/reference/token-2022-support#launchlab-quote-mints).

## Kasalar

Hem `base_vault` hem de `quote_vault` LaunchLab `authority` PDA'sına ait token hesaplarıdır, her biri kendi mint'ine sahip olan programa oluşturulur — bu nedenle bir başlatma eski bir temel kasaya ve Token-2022 alıntı kasasına sahip olabilir veya başka herhangi bir kombinasyon. `token_program_flag` hangisinin hangisi olduğunu kaydeder. Adresler `PoolState` üzerinde depolanır ve ayrıca türetilebilir:

```ts
const [baseVault] = PublicKey.findProgramAddressSync(
  [Buffer.from("pool_vault"), poolState.toBuffer(), baseMint.toBuffer()],
  LAUNCHLAB_PROGRAM_ID,
);
const [quoteVault] = PublicKey.findProgramAddressSync(
  [Buffer.from("pool_vault"), poolState.toBuffer(), quoteMint.toBuffer()],
  LAUNCHLAB_PROGRAM_ID,
);
```

(Üretimde bir türetmeye güvenmeden önce tam tohum öneklerini kaynağın `Initialize` hesapları yapısından doğrulayın.)

## Ücret kasaları

İki PDA ücretleri başlatmalar arasında toplar:

- **Yaratıcı ücret kasası** — `[creator, quote_mint]` tohumlarında PDA. Aynı alıntı mint'inde aynı yaratıcı ücretlerini kazanan her başlatma aynı kasaya dökülür. Yaratıcı bunu `ClaimCreatorFee` aracılığıyla temizler.
- **Platform ücret kasası** — `[platform_config, quote_mint]` tohumlarında PDA. Aynı platform aracılığıyla yönlendirilen ve aynı alıntı mint'ini kullanan her başlatma aynı kasaya dökülür. Platformun `platform_fee_wallet`'ı bunu `ClaimPlatformFeeFromVault` aracılığıyla temizler. Başlatmanın `quote_vault`'undan doğrudan çeken ve toplu kasadan geçmeyen başlatma başına bir temizleme varyantı da vardır (`ClaimPlatformFee`).

Her ikisi de ücret tahakkuk ettiren ilk swap'ta, alıntı mint'ine sahip olan programa tembel olarak oluşturulur. Eski ve Token-2022 alıntı mint'ine karşı başlatmalar çalıştıran bir yaratıcı veya platform, zaten iki farklı eski mint için yaptığı gibi mint başına bir kasa ile sonuçlanır.

Toplu kasa deseni, yüksek hacimli bir yaratıcı veya platformun ücret birikiminin kira maliyetini birçok başlatma arasında amortize etmesini sağlar.

## Alıntı kasası ↔ `real_quote`

`quote_vault.balance` ve `PoolState.real_quote` senkronize kalmalıdır. Üç bekleyen ücret sayacının toplamı kadar sapabilirler (`quote_protocol_fee`, `platform_fee`, `migrate_fee`), bunlar kasada oturur ancak ücret sayaçlarına ve eğri rezervine değil. Eğri matematik her zaman `real_quote` kullanır, asla ham kasa bakiyesini değil.

Mezuniyet öncesi değişmez:

```
quote_vault.balance ==
   real_quote
 + quote_protocol_fee
 + platform_fee
 + migrate_fee
```

## `PlatformCurveRule`

`(PlatformConfig, GlobalConfig)` çifti başına bir hesap, o yapılandırmada platformun izin verdiği başlatma şekillerini tutar. PDA tohumları `[b"platform_curve_rule", platform_config, global_config]`'tir.

```rust
#[account]
pub struct PlatformCurveRule {
    pub bump:            u8,
    pub version:         u8,
    pub platform_config: Pubkey,
    pub global_config:   Pubkey,
    pub epoch:           u64,
    pub padding:         [u64; 8],
    pub groups:          Vec<CurveRuleGroup>,   // up to 10
}

pub struct CurveRuleGroup {
    pub group_id:    u16,                       // stable id, used to update or remove the group
    pub epoch:       u64,
    pub constraints: Vec<ParamConstraint>,      // up to 25, ANDed
}

pub struct ParamConstraint {
    pub field: u8,                              // which launch parameter
    pub op:    u8,                              // 0 Eq, 1 Gte, 2 Lte, 3 Neq
    pub value: u128,
}
```

Hesap hiçbir grup tutmadan oluşturulur ve her grup değişikliğinde yeniden boyutlandırılır, bu nedenle uzunluğu `150 + Σ(14 + 18 × constraints)`'tir ve kod çözücüler sabit bir boyut varsaymamalıdır. Gruplar OR'lanır: bir grubun kısıtlamalarının tümü tutulur tutulmaz bir başlatmaya izin verilir. Sıfır grup kısıtlama yok anlamına gelir.

Yalnızca sahibi `PlatformConfig.restrict_curve_param` `1` olduğunda okuyun — `0`'da program hesabı yok sayar ve eski bir kural orada oturuyor olabilir. Alan kimlikleri, operatörler ve oyun kitapları [`products/launchlab/curve-rules`](/tr/products/launchlab/curve-rules) içindedir.

| Olay | Durum | `real_base` | `real_quote` | Mezuniyet sonrası havuz |
