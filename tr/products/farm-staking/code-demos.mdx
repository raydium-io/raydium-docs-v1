## Kurulum

Buradaki örnekler [`raydium-sdk-V2-demo/src/farm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/farm) dosyalarını yansıtır. Bootstrap, demo repo'nun [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) dosyasını takip eder:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Farm'ı ID'ye göre getir

`raydium.farm.getFarmById` yoktur. Her farm örneği API modülünden başlar; bu modül `deposit` / `withdraw` / `harvestAllRewards` tarafından alınan normalleştirilmiş `FormatFarmInfoOut` şeklini döndürür:

```ts
const farmId = "CHYrUBX2RKX8iBg7gYTkccoGNBzP44LdaazMHCLcdEgS"; // RAY-USDC farm

const farmInfo = (await raydium.api.fetchFarmInfoById({ ids: farmId }))[0];
if (!farmInfo) throw new Error("farm not found");

console.log("LP mint:", farmInfo.lpMint.address);
console.log("TVL:", farmInfo.tvl);
for (const r of farmInfo.rewardInfos) {
  console.log("  -", r.mint.address, r.mint.symbol);
}
```

`fetchFarmInfoById` **virgülle ayrılmış bir ID dizesi** alır ve bir dizi döndürür; böylece bir çağrı tüm portföyü hidrate edebilir. Ham hesap anahtarlarına ihtiyacınız varsa, `raydium.api.fetchFarmKeysById({ ids })` vault'ları ve authority PDA'larını döndürür; SDK bunu aşağıdaki her builder içinde sizin için dahili olarak çağırır.

## LP token'larını stake et

Kaynak: [`src/farm/stake.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/stake.ts)

```ts
// Demo, cüzdan'ın tüm LP bakiyesini stake eder; ham birimler cinsinden herhangi bir BN çalışır.
const amount = raydium.account.tokenAccountRawInfos.find(
  (a) => a.accountInfo.mint.toBase58() === farmInfo.lpMint.address,
)?.accountInfo.amount;

if (!amount || amount.isZero()) throw new Error("user does not have an LP balance");

const { execute } = await raydium.farm.deposit({
  farmInfo,
  amount,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Deposit tx:", txId);
```

SDK, bekleyen ödüllerin ön kapatılmasını işler; bu nedenle bu cüzdan zaten bu farm'da stake'e sahipse, instruction aynı işlemde birikmiş ödülleri kullanıcının ATA'larına ödeyecektir.

## Yalnızca talep et (hasat)

Kaynak: [`src/farm/harvest.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/harvest.ts)

`farmInfoList` bir dizi değil, **farm id'ye göre anahtarlanmış bir `Record`** şeklindedir ve builder **birden fazla** işlem döndürür — bu nedenle `execute` öğesine `sequentially: true` verilmelidir:

```ts
const farmIds = [farmId, "<ANOTHER_FARM_ID>"];
const farmInfos = await raydium.api.fetchFarmInfoById({ ids: farmIds.join(",") });

const { execute } = await raydium.farm.harvestAllRewards({
  farmInfoList: Object.fromEntries(farmInfos.map((f) => [f.id, f])),
  txVersion: TxVersion.V0,
});

const { txIds } = await execute({ sequentially: true });
console.log("harvest txs:", txIds);
```

Builder, 1232 baytlık sınırın izin verdiği kadar çok farm'ı bir işlemde paketler ve geri kalanını takip eden işlemlere böler; bu nedenle tek bir `txId` yerine `txIds` döndürür.

Tek bir farm için, `amount: 0` idiomunu kullanarak hasat yapın — bu, [`src/farm/harvest.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/harvest.ts) dosyasının yaptığı şeydir, v6 dahil her sürümde:

```ts
const { execute } = await raydium.farm.withdraw({
  farmInfo,
  amount: new BN(0),        // 0 = harvest-only path
  txVersion: TxVersion.V0,
});
await execute({ sendAndConfirm: true });
```

## v6 farm oluştur

Kaynak: [`src/farm/createAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/createAmmFarm.ts) ve [`editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts)

`create`, LP mint'i stake edilen pool'un **pool info nesnesi** alır (bare mint değil) ve `rewardInfos` öğesinin her girdisi bir `FarmRewardInfo` şeklindedir: `{ mint: PublicKey, perSecond: string, openTime: number, endTime: number, rewardType: "Standard SPL" | "Option tokens" }`. Zamanlar **düz saniye** cinsindedir ve `perSecond` bir `BN` değil, **string** şeklindedir. `programId` varsayılan olarak v6 program'ıdır; bu nedenle nadiren geçirirsiniz.

```ts
import type { ApiV3PoolInfoStandardItem, FarmRewardInfo } from "@raydium-io/raydium-sdk-v2";
import { RAYMint } from "@raydium-io/raydium-sdk-v2";

// LP mint'i stake mint'i olacak olan sahip olduğunuz pool.
const poolInfo = (
  await raydium.api.fetchPoolById({ ids: "<POOL_ID>" })
)[0] as ApiV3PoolInfoStandardItem;
if (!poolInfo) throw new Error("pool not found");

const rewardMint = await raydium.token.getTokenInfo(RAYMint);

// Duvar saati zamanı değil, zincir zamanını kullanın — program bunu doğrular.
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);
const endTime  = openTime + 60 * 60 * 24 * 7; // 7 days

const rewardInfos: FarmRewardInfo[] = [
  {
    mint:       new PublicKey(rewardMint.address),
    perSecond:  "1",              // string, in raw units per second
    openTime,                      // seconds, not BN
    endTime,
    rewardType: "Standard SPL",   // "Option tokens" is the only other value
  },
];

const { execute, extInfo } = await raydium.farm.create({
  poolInfo,
  rewardInfos,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Farm:", extInfo.farmId.toBase58(), "createTx:", txId);
```

Önemli noktalar:

- `perSecond`, ödül mint'inin **ham** birimlerinde saniye başına emisyon oranıdır; ondalık string olarak geçirilir. SDK, göndermeden önce bunu zincir üstü sabit nokta gösterimine paketler.
- Tam bütçe (`perSecond × (endTime − openTime)`) ödül ATA'nızda bulunmalıdır — `create` bunu ödül vault'una atomik olarak taşır.
- **Token-2022 ödül mint'leri bu SDK sürümünde SDK'nın farm builder'ları tarafından desteklenmez**; ödüller için düz SPL mint kullanın.
- Bir `create` çağrısında 5'e kadar ödülü seed'leyebilirsiniz. Hesap listesi her ekstra stream için `(reward_mint, reward_vault, sender_ata, token_program)` kadar büyür; 1232 baytlık işlem boyutu sınırının farkında olun. 4+ ödül için 1–2 ile oluşturun ve takip eden işlemlerde `addNewRewardsToken` kullanın.

## Yeni ödül akışı ekle

`raydium.farm.setRewards` yoktur. Farm'ın ödüllerini değiştiren iki builder, `addNewRewardToken` / `addNewRewardsToken` (boş bir slot'u **yeni** bir mint ile işgal et) ve `restartReward` / `restartRewards` (akışı sona ermiş bir slot'u yeniden başlat) şeklindedir. Her ikisi de `create` tarafından kullanılan şekilde tam olarak `FarmRewardInfo` nesneleri alır.

```ts
import { USDCMint } from "@raydium-io/raydium-sdk-v2";

const added = await raydium.token.getTokenInfo(USDCMint);
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);

const { execute } = await raydium.farm.addNewRewardsToken({
  farmInfo,
  newRewardInfos: [
    {
      mint:       new PublicKey(added.address),
      perSecond:  "1",
      openTime,
      endTime:    openTime + 60 * 60 * 24 * 7,
      rewardType: "Standard SPL",
    },
  ],
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Delta bütçesi (`perSecond × duration`) işlemin bir parçası olarak ödeyenin ATA'sından çekilir. Temel instruction, bir akışı kısaltamaz, canlı bir akışta `per_second` öğesini düşüremez ve bir slot'un ödül mint'ini değiştiremez — mint'leri değiştirmek için `end_time` bekleyin ve serbest bırakılan bir slot'ta `addNewRewardsToken` kullanın veya yeni bir farm oluşturun.

<Tip>
  `restartRewards` ve `addNewRewardsToken` her biri bir builder döndürür; bu nedenle tek bir işlem her ikisini de yapabilir. [`src/farm/editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts) deseni gösterir: `editFarmBuilder.builder.addInstruction(addNewRewardBuildData.builder.AllTxData)`, ardından bir `versionBuild({ txVersion })`.
</Tip>

## Bitmiş akışı yeniden başlat

Kaynak: [`src/farm/editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts)

`restartRewards` **`newRewardInfos`** (çoğul, bir dizi) alır; `restartReward` tek öğeli form'dur ve `newRewardInfo` alır. Mint alanı `mint` şeklindedir, `rewardMint` değil ve farm'da zaten var olan bir slot'u eşleştirmelidir — builder slot'u mint'e göre arar ve yoksa hata verir.

```ts
import type { FarmRewardInfo } from "@raydium-io/raydium-sdk-v2";

// Farm'ın mevcut ilk ödül slot'unu yeniden başlat.
const existing = await raydium.token.getTokenInfo(farmInfo.rewardInfos[0].mint.address);
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);

const newRewardInfos: FarmRewardInfo[] = [
  {
    mint:       new PublicKey(existing.address),
    perSecond:  "1",
    openTime,
    endTime:    openTime + 60 * 60 * 24 * 14,
    rewardType: "Standard SPL",
  },
];

const { execute } = await raydium.farm.restartRewards({
  farmInfo,
  newRewardInfos,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

`restartRewards` **yalnızca v6'dır** — builder farm'ın program id'sini okur ve v3 / v5 farm'ları için hata verir. Yalnızca hedef slot'un `reward_state == 2` (bitmiş) olduğunda geçerlidir; çağıran slot'un `reward_sender` öğesi olmalıdır. `openTime >= endTime` öğesinin herhangi bir RPC yapılmadan önce istemci tarafında reddedildiğini unutmayın.

## Rust CPI

<Warning>
  **`raydium_farm_v6` Anchor crate'i yoktur.** crates.io'da bu adı taşıyan hiçbir crate yoktur, Farm v6 program'ı hiçbir zincir üstü IDL yayınlamaz (ne eski `anchor:idl` hesabı ne de Program Metadata program'ında bir giriş) ve bunun için hiçbir genel kaynak deposu yoktur. Bu sayfanın önceki bir revizyonu `raydium_farm_v6::cpi::deposit` örneği göstermiştir; hiçbir şeye karşı derlenmiş değildir ve kaldırılmıştır.
</Warning>

Farm v6, 2024-05-13 tarihinde son kez dağıtılmıştır ve bir integratör açısından Anchor program'ı değildir. Kendi zincir üstü program'ınızdan bununla oluşturmanız gerekiyorsa, `Instruction` öğesini elle oluşturun — hesap listesini ve instruction discriminator'larını bağımsız olarak türetin (SDK'nın `raydium-sdk-V2/src/raydium/farm/` altındaki TypeScript düzenlerinden veya gerçek işlemleri çözerek) ve `invoke_signed` yapın. Bu prosedür için [`sdk-api/rust-cpi`](/tr/sdk-api/rust-cpi#farm-v6) bölümüne bakın.

Hangi yolu alırsanız alın, `remaining_accounts` tail'i farm'ın etkin ödül slot'larıyla 1'e 1 eşleşmelidir (`reward_vault_i`, `user_reward_ata_i` çiftleri dizin sırasında). Bunları atlama veya yanlış sıralama sessiz yanlış muhasebeleye neden olur — program yanlış tutarı transfer eder.

## Tuzaklar

- **Çekmeden önce talep etmeyi unutmak.** Zararsız — `Withdraw` önce bekleyen ödülleri kapatır. Ancak UI'niz "talep"i "çek"ten ayrı gösteriyorsa, kullanıcı `Withdraw` sonrasında talep edilecek bir şey olduğunu düşünebilir. Yoktur; o noktaya kadar birikmiş her şey ödendi.
- **Emisyon sırasında `total_staked = 0`**. Hiçbir şey stake edilmemişken birikmiş emisyonlar kaybedilir (`reward_per_share` güncelleme formülü 0'a bölünür ve program güncellemeyi atlar). Zamanlanmış `open_time` olan program'lar için, bunu önlemek amacıyla open_time'da "seed stake" çalıştırın.
- **Token-2022 transfer ücretleri.** Token-2022 ödül mint'lerine sahip v6 farm'larında, transfer ücreti emit sırasında uygulanır (vault → kullanıcı). Bunu APR alıntılarına dahil edin.
- **v5'te küçük `per_second`**. v5'in `u64` oranı, herhangi bir `per_second < 1` token-birim saniye başına (9+ ondalık basamağa sahip mint'lerde bu genellikle istenen orandır) ifade edilemeyeceği anlamına gelir — akış oranı 0'a yuvarlanır ve farm hiçbir şey yayınlamaz. v6 kullanın.
