  SDK'nın `liquidity` modülü Stable AMM havuzlarını yerel olarak işler. Stable havuzlar `ApiV3PoolInfoStandardItem` üzerinde **`version: 5`** (veya `pooltype: "StablePool"`) olarak görünür; AMM v4 (`version: 4`) sabit-ürün havuzları için olduğu gibi aynı `addLiquidity` / `removeLiquidity` / swap yardımcıları bunlar için de çalışır — SDK varyantı algılar ve doğru talimatları otomatik olarak yayınlar. Off-chain stable-curve matematiği `src/raydium/liquidity/stable.ts` içinde yer alır.
</Info>

## Kurulum

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token
```

```ts
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import BN from "bn.js";
import bs58 from "bs58";

const connection = new Connection(clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(bs58.decode(process.env.PRIVATE_KEY!));

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });

// Herhangi bir Stable-pool fiyatlandırması öncesinde GEREKLI. initLayout() on-chain
// ModelDataInfo arama tablosunu raydium.liquidity.stableLayout içine yükler.
await raydium.liquidity.initLayout();
```

<Warning>
  **`initLayout()` Stable havuzlar için isteğe bağlı değildir.** `liquidity.computeAmountOut` `poolInfo.version` üzerinde dallanır: version 4 için sabit-ürün formülünü kullanır, diğer her şey için `this.stableLayout.stableModelData` okur ve arama tablosunu enterpolasyon eder. Bu önbellek `initLayout()` çalışana kadar boştur, bu nedenle bunu olmadan v5 havuzunun fiyatlandırılması hata yerine çöp üretir. İdempotent ve ucuzdur — başlangıçta bir kez çağırın.

  İşlem *oluşturucuları* (`swap`, `addLiquidity`, `removeLiquidity`) buna ihtiyaç duymaz: `pooltype.includes("StablePool")` üzerinde gönderir ve `AmmV5*` talimatlarını yayınlar, ve ilettiğiniz miktar sınırları zaten hesaplanmıştır.
</Warning>

<Warning>
  **`liquidity.computeAmountIn` Stable havuzları desteklemez.** `computeAmountOut` aksine, sürüm dalı yoktur — her zaman sabit-ürün tersini uygular, bu nedenle v5 havuzunda yanlış `maxAmountIn` döndürür. Stable havuza karşı tam çıktı swap'ı için `getDxByDyBaseIn` ile kendiniz ters çevirin (aşağıdaki [Off-chain fiyat yardımcıları](#off-chain-quote-helpers-stablets) bölümüne bakın) ve sonucu `swap`'a `fixedSide: "out"` ile iletin.
</Warning>

## Stable havuzunu tanımlama

`ApiV3PoolInfoStandardItem` üzerinde iki eşdeğer sinyal:

```ts
const isStable =
  pool.version === 5 ||
  pool.pooltype.includes("StablePool"); // SDK bu dize kontrolünü dahili olarak kullanır

// Alternatif olarak, program ID'ye göre:
const STABLE_AMM_PROGRAM_ID = "5quBtoiQqxF9Jv6KYKctB59NT3gtJD2Y65kdnB1Uev3h";
const isStableByProgram = pool.programId === STABLE_AMM_PROGRAM_ID;
```

Hem AMM v4 (`version: 4`, sabit-ürün) hem de Stable AMM (`version: 5`) SDK'daki aynı `LiquidityModule` API'si aracılığıyla akar. Dahili olarak modül şu şekilde gönderir:

- `InstructionType.AmmV4AddLiquidity` / `AmmV4RemoveLiquidity` v4 havuzları için
- `InstructionType.AmmV5AddLiquidity` / `AmmV5RemoveLiquidity` v5 (Stable) havuzları için

Havuzun `programId` (havuz anahtarlarıyla döndürülen) SDK'ya hangi programa CPI yapacağını söyler; bunu hardcode etmeniz gerekmez.

## Mint çiftine göre havuz bulma

```ts
import { PublicKey } from "@solana/web3.js";
import type { ApiV3PoolInfoStandardItem } from "@raydium-io/raydium-sdk-v2";

// Örnek olarak kullanılacak iki yaygın mint
const mintA = new PublicKey("Es9vMFrzaCERmJfrF4H2FYD4KCoNkY11McCe8BenwNYB"); // USDT — bkz. reference/program-addresses
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// fetchPoolByMints sayfalı bir zarf döndürür: { count, data, hasNextPage }
const res = await raydium.api.fetchPoolByMints({
  mint1: mintA.toBase58(),
  mint2: mintB.toBase58(),
});

const stablePool = res.data.find(
  (p) => p.version === 5 || p.pooltype.includes("StablePool"),
) as ApiV3PoolInfoStandardItem | undefined;

if (!stablePool) {
  throw new Error("Bu mint çifti için Stable havuz yok");
}

console.log("Stable havuz id:", stablePool.id);
console.log("Stable havuz programId:", stablePool.programId);
console.log("TVL:", stablePool.tvl);
```

Mint çiftinin hem v4 (sabit-ürün) havuzu hem de v5 (stable) havuzu varsa, yanıt her ikisini de içerir — akışınızın ihtiyaç duyduğu birini seçin veya her ikisini [AMM Routing](/tr/products/routing) programına verin ve en iyi rotayı seçmesine izin verin.

## Stable havuz aracılığıyla swap yapma

`LiquidityModule.swap` akışı v4 havuzları için aynı şekildedir — sadece v5 havuz nesnesini iletin. İki ayrıntı yanlış anlaşılması kolaydır: `computeAmountOut` havuzun **canlı rezervlerini** havuz bilgisine eklemesi gerekir (API öğesi tek başına bunları taşımaz) ve `slippage` düz bir **sayıdır**, `Percent` değildir:

```ts
import BN from "bn.js";

const amountIn = new BN(1_000_000); // 1 USDT (6 ondalık), ham birimler

// Canlı rezervler + durum. Mainnet'te poolKeys'i
// getAmmPoolKeys(poolId) ve rezervleri getRpcPoolInfo(poolId) adresinden de alabilirsiniz.
const rpcData  = await raydium.liquidity.getRpcPoolInfo(stablePool.id);
const poolKeys = await raydium.liquidity.getAmmPoolKeys(stablePool.id);

const out = raydium.liquidity.computeAmountOut({
  poolInfo: {
    ...stablePool,
    baseReserve:  rpcData.baseReserve,
    quoteReserve: rpcData.quoteReserve,
    status:       rpcData.status.toNumber(),
    version:      5, // 5 = Stable; eğri dalı buna göre seçilir
  },
  amountIn,
  mintIn:  stablePool.mintA.address,
  mintOut: stablePool.mintB.address,
  slippage: 0.005, // düz sayı: 0.005 = 0.5% (aralık 1 ~ 0.0001)
});

// amountOut / minAmountOut ham birimler içinde BN'dir, TokenAmount değildir.
console.log("Beklenen çıktı:", out.amountOut.toString());
console.log("Minimum çıktı:", out.minAmountOut.toString());

// Swap işlemini oluşturun ve imzalayın. `inputMint` gereklidir — bunu olmadan SDK
// havuzun hangi tarafını sattığınızı söyleyemez.
const { transaction, execute } = await raydium.liquidity.swap({
  poolInfo:  stablePool,
  poolKeys,
  amountIn,
  amountOut: out.minAmountOut, // out.amountOut kaymadan önceki rakamdır
  inputMint: stablePool.mintA.address,
  fixedSide: "in",
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Stable swap tx:", txId);
```

SDK havuzun `programId`'sini havuz anahtarlarından okur ve Stable AMM programına gönderir. Özel `programId` argümanı gerekmez.

## Likidite ekleme ve kaldırma

`addLiquidity` ve `removeLiquidity` v4 ve v5 havuzları arasında aynı şekilde çalışır:

```ts
import { Percent, TokenAmount, toToken } from "@raydium-io/raydium-sdk-v2";
import Decimal from "decimal.js";

const inputAmount = "100"; // 100 USDT, insan birimlerinde — computePairAmount ondalık dize alır

// Eğrinin bu A boyutu için gerektirdiği eşleşen B miktarını hesaplayın.
// Not: computePairAmount'ın slippage'ı Percent'tir (computeAmountOut'unkinin aksine).
const r = raydium.liquidity.computePairAmount({
  poolInfo: stablePool,
  amount:   inputAmount,
  baseIn:   true,
  slippage: new Percent(50, 10_000), // 0.5%
});

const { execute } = await raydium.liquidity.addLiquidity({
  poolInfo: stablePool,
  poolKeys,
  amountInA: new TokenAmount(
    toToken(stablePool.mintA),
    new Decimal(inputAmount).mul(10 ** stablePool.mintA.decimals).toFixed(0),
  ),
  amountInB: new TokenAmount(
    toToken(stablePool.mintB),
    new Decimal(r.maxAnotherAmount.toExact()).mul(10 ** stablePool.mintB.decimals).toFixed(0),
  ),
  otherAmountMin: r.minAnotherAmount,
  fixedSide:      "a",
  txVersion:      TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Likidite ekleme tx:", txId);
```

Dahili olarak SDK `pooltype.includes("StablePool")` doğru olduğu için `InstructionType.AmmV5AddLiquidity` yayınlar. Karşılık gelen `removeLiquidity` akışı simetrik — `lpAmount` ve her bir tarafta kabul edeceğiniz minimum miktarları iletin.

## Off-chain fiyat yardımcıları (stable.ts)

Sunucu tarafı fiyatlandırması veya geriye dönük test için SDK, temel stable-curve matematiğini ortaya çıkarır:

```ts
import {
  getStablePrice,
  getDxByDyBaseIn,
  getDyByDxBaseIn,
} from "@raydium-io/raydium-sdk-v2";

// Bunları kullanmadan önce initLayout() bir kez çağırmalısınız (on-chain
// `ModelDataInfo` PDA'sını SDK'nın StableLayout önbelleğine yükler).
await raydium.liquidity.initLayout();

// initLayout() StableLayout örneğini doldurur; aşağıdaki üç yardımcının
// beklediği düz veri nesnesi örneğin kendisi değil, `stableModelData` getter'ıdır.
const modelData = raydium.liquidity.stableLayout.stableModelData;

// Rezervler insan birimlerinde düz sayılar olarak iletilir (BN değil, ham birimler değil).
const coinReserve = 1_200_000; // havuzun coin-tarafı rezervi
const pcReserve   = 1_150_000; // havuzun pc-tarafı rezervi

// Havuzun mevcut rezervlerindeki spot fiyat. 4. argüman `baseCoin`'dir:
// true coin-per-pc döndürür, false karşılıklı döndürür.
const price = getStablePrice(modelData, coinReserve, pcReserve, true);
console.log("Spot fiyat:", price);

// Fiyat: dx girdisi verildiğinde, ne kadar dy çıktısı (ücret uygulanmaz)?
const dyOut = getDyByDxBaseIn(modelData, coinReserve, pcReserve, 1_000);

// Fiyat: dy çıktısı hedefi verildiğinde, ne kadar dx girdisi gerekir?
const dxIn  = getDxByDyBaseIn(modelData, coinReserve, pcReserve, 1_000);
```

Bunlar saf işlevlerdir — RPC yok, imzalama yok. On-chain `ModelDataInfo` `initLayout()` tarafından bir kez alınır ve `raydium.liquidity.stableLayout` içinde önbelleğe alınır, `.stableModelData` olarak okunabilir. `initStableModelLayout()` idempotent'tir: yalnızca `validDataCount === 0` iken yeniden alır, bu nedenle `initLayout()` tekrar çağırmak ücretsizdir. Mevcut rezervleri (`x`, `y`) iletin ve yardımcılar arama tablosunu ikili arama yaparak ve iki çevreleyen `DataElement` satırı arasında doğrusal enterpolasyon yaparak hesaplar. Temel algoritma için [`products/stable/math`](/tr/products/stable/math) bölümüne bakın.

## AMM Routing aracılığıyla yönlendirme (multi-hop / en iyi fiyat)

Bir mekanı kendiniz seçmek istemiyorsanız, [AMM Routing](/tr/products/routing) programı her Raydium AMM'yi (v4 / CPMM / CLMM / Stable) dikkate alacak ve en iyi olan kombinasyon aracılığıyla yönlendirecektir:

Router tek bir `swap()` yerine beş çağrılı bir boru hattıdır ve onu tam olarak yazılmıştır — onu üretimde kullanılabilir kılan önbellek tavsiyesi ile — [`products/routing/code-demos`](/tr/products/routing/code-demos) üzerinde. Şekil:

```ts
import { Router } from "@raydium-io/raydium-sdk-v2";

const poolData = await raydium.tradeV2.fetchRoutePoolBasicInfo(); // bunu önbelleğe alın
const routes   = raydium.tradeV2.getAllRoute({ inputMint: mintA, outputMint: mintB, ...poolData });
const ctx      = await raydium.tradeV2.fetchSwapRoutesData({ routes, inputMint: mintA, outputMint: mintB });
const quotes   = raydium.tradeV2.getAllRouteComputeAmountOut({ /* ...ctx, amount, slippage, ... */ });

const best = quotes[0]; // en iyi-ilk sıralanmış
if (!best) throw new Error("swap rotası bulunamadı");

// best.poolInfoList girdileri `version` taşır — 5 yoldaki Stable havuzunu işaretler.
console.log(best.routeType, best.poolInfoList.map((p) => p.version));

const poolKeys = await raydium.tradeV2.computePoolToPoolKeys({
  pools: best.poolInfoList,
  ammRpcData:  ctx.ammPoolsRpcInfo,
  clmmRpcData: ctx.clmmPoolsRpcInfo,
});

const { execute } = await raydium.tradeV2.swap({
  routeProgram: Router,
  swapInfo:     best,
  swapPoolKeys: poolKeys,
  ownerInfo:    { associatedOnly: true, checkCreateATAOwner: true },
  txVersion:    TxVersion.V0,
});

// tradeV2.swap birkaç işlem döndürebilir; ilki ara ATA'lar oluşturur.
const { txIds } = await execute({ sequentially: true });
```

<Warning>
  `raydium.tradeV2.fetchRoutes` yoktur ve `tradeV2.swap` **`inputMint` / `outputMint` / `slippage` kabul etmez** — zaten hesaplanmış `swapInfo`'yu `getAllRouteComputeAmountOut` adresinden alır. **Tek** bilinen havuz için, bu sayfa üzerinde daha önce gösterildiği gibi o havuz türünün kendi oluşturucusunu kullanın (`raydium.liquidity.swap` AMM v4 ve Stable için, `raydium.cpmm.swap`, `raydium.clmm.swap`).
</Warning>

Bu, üretim swapper'ları ve toplayıcıları için önerilen yoldur — Stable havuzunun var olup olmadığını veya bugün daha iyi mekan olup olmadığını manuel olarak karar vermeniz gerekmez.

## Öneriler

1. **Son kullanıcı swap'ları için**, [`tradeV2`](/tr/products/routing) yönlendirme akışını tercih edin. Stable dahil her Raydium havuz türünü işler.
2. **Havuz özel işlemleri için** (bilinen Stable havuzda LP ekleme / kaldırma), `LiquidityModule`'ü doğrudan kullanın — v5 havuzlarını otomatik olarak algılar.
3. **Off-chain fiyatlandırması / analitik için**, `initLayout()` sonrasında `getStablePrice` / `getDyByDxBaseIn` / `getDxByDyBaseIn` çağırın. Model verileri önbelleğe alındıktan sonra fiyatlandırma başına RPC trafiği yok.
4. **Ham `SwapBaseIn` talimatlarını elle kodlamayın.** [2026-06-22 yükseltmesi](/tr/reference/changelog) ölü OpenBook hesaplarını kaldırdı, bu nedenle yeni swap düzeni **9 hesap** alır (eski 18 hesap düzeni geriye dönük uyumluluk için hala ayrıştırılır). `Deposit` artık 12 hesaptır (eski 14 uyumlu), `Withdraw` 12 (eski 21/22 uyumlu) ve `WithdrawPnl` 10 **uyumluluk yolu olmadan**. SDK'nın önceden oluşturulmuş yardımcıları doğru düzeni ve sıralamayı seçer; kendi kodunuzu yazmak hata eğilimlidir. Tam hesap tabloları için [`products/stable/instructions`](/tr/products/stable/instructions) bölümüne bakın.
