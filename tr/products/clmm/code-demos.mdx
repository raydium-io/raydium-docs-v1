## Kurulum

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js decimal.js
```

Bu sayfadaki her örnek [`raydium-sdk-V2-demo/src/clmm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/clmm) klasöründeki bir dosyayı yansıtır; GitHub bağlantısı her bölümün yanında yer alır. Başlatma, demo repo'sunun `config.ts.template` dosyasını ([kaynak](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)) takip eder — `disableFeatureCheck: true` herhangi bir önemsiz entegrasyon için önerilen ayardır:

```ts
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## CLMM havuzu oluşturma

Kaynak: [`src/clmm/createPool.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/createPool.ts)

```ts
import { PublicKey } from "@solana/web3.js";
import { CLMM_PROGRAM_ID } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import Decimal from "decimal.js";

const mintA = await raydium.token.getTokenInfo(
  new PublicKey("So11111111111111111111111111111111111111112"));   // wSOL
const mintB = await raydium.token.getTokenInfo(
  new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"));   // USDC

const ammConfigs = await raydium.api.getClmmConfigs();
const ammConfig  = ammConfigs.find((c) => c.index === 1)!;        // 0.05% tier

const initialPrice = new Decimal(160);        // SOL başına 160 USDC
const { execute, extInfo } = await raydium.clmm.createPool({
  programId: CLMM_PROGRAM_ID,
  mint1:     mintA,
  mint2:     mintB,
  ammConfig,
  initialPrice,
  startTime: new BN(0),
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Pool:", extInfo.address.id.toBase58(), "tx:", txId);
```

SDK şunları yapar:

- Türetme öncesinde `mint1`/`mint2` öğelerini bayt sırasına göre sıralar.
- `sqrt_price_x64 = floor(sqrt(initialPrice × 10^(dB−dA)) × 2^64)` hesaplar.
- `observation` ve `tick_array_bitmap_extension` hesaplarını oluşturur.
- `ammConfig` tarafından tanımlanan havuz oluşturma ücretini öder.

## Seçilen aralıkta pozisyon açma

Kaynak: [`src/clmm/createPosition.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/createPosition.ts)

```ts
import { PoolUtils, TickUtils } from "@raydium-io/raydium-sdk-v2";

const poolId = new PublicKey("<POOL_ID>");
const { poolInfo, poolKeys, rpcData } = await raydium.clmm.getPoolInfoFromRpc(poolId);

// Fiyat aralığı seçin. Burada: mevcut fiyatın ±%10.
const currentPrice = new Decimal(poolInfo.price);
const lowerPrice   = currentPrice.mul(0.9);
const upperPrice   = currentPrice.mul(1.1);

// Bu havuzun tick_spacing'i için geçerli tick'lere yasla.
const { tick: tickLower } = TickUtils.getPriceAndTick({
  poolInfo, price: lowerPrice, baseIn: true,
});
const { tick: tickUpper } = TickUtils.getPriceAndTick({
  poolInfo, price: upperPrice, baseIn: true,
});

// Her bir token'dan ne kadar yatırılacağı.
const inputAmount = new BN(10_000_000);  // 0.01 SOL
const inputMint   = poolInfo.mintA.address;

const res = PoolUtils.getLiquidityAmountOutFromAmountIn({
  poolInfo,
  slippage: 0.01,
  inputA: true,
  tickUpper,
  tickLower,
  amount: inputAmount,
  add: true,
  amountHasFee: true,
  epochInfo: await raydium.fetchEpochInfo(),
});

const { execute } = await raydium.clmm.openPositionFromBase({
  poolInfo,
  poolKeys,
  tickUpper,
  tickLower,
  base: "MintA",
  ownerInfo: { useSOLBalance: true },
  baseAmount: inputAmount,
  otherAmountMax: res.amountSlippageB.amount,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Pozisyon açıldı, tx:", txId);
```

SDK otomatik olarak aralığın hangi tick dizilerini etkilediğini hesaplar ve başlatılmamış olanlar için `InitTickArray` talimatlarını paketler.

## Likidite azaltma (ve aynı anda ücret toplama)

Kaynak: [`src/clmm/decreaseLiquidity.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/decreaseLiquidity.ts) ve [`src/clmm/closePosition.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/closePosition.ts)

```ts
const { execute } = await raydium.clmm.decreaseLiquidity({
  poolInfo,
  poolKeys,
  ownerPosition: positionAccount,
  liquidity: positionAccount.liquidity.divn(2),   // yarıya indir
  amountMinA: new BN(0),
  amountMinB: new BN(0),
  closePosition: false,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

**Yalnızca ücret toplamak için**, `decreaseLiquidity` öğesini `liquidity = new BN(0)` ile çağırın. Talimatın yan etkisi `tokens_fees_owed_{0,1}` öğesini kapatmak ve bunları aktarmaktır.

Likiditeyi ve ücretleri sıfırladıktan sonra pozisyonu tamamen kapatmak için, son `decreaseLiquidity` çağrısında `closePosition: true` geçirin. SDK `ClosePosition` ekler ve NFT'yi yakar.

<Warning>
  **Kısıtlı yayıncı pozisyonları uyumlu bir kapatma oluşturucusu gerektirir.** Bu pozisyonların dondurulmuş bir NFT token hesabı vardır. `ClosePosition`, CLMM'nin hesabı yakmadan önce çözmesi için havuz ID'sini ilk kalan hesap olarak eklemelidir. Program kaynağı dalı SDK değişikliği içermez. Kısıtlı yayıncı pozisyon oluşturmayı etkinleştirmeden önce SDK sürümünüzün dondurulmuş kapatma yolunu açıkça desteklediğini doğrulayın.
</Warning>

Doğrudan bir Anchor istemcisi için, bildirilen hesapları değişmeden tutun ve havuzu ekleyin:

```ts
// CLMM programı: reference/program-addresses bölümüne bakın; kaynak ecb1577;
// Solana mainnet-beta; son doğrulama 2026-08-13.
await program.methods
  .closePosition()
  .accounts({
    nftOwner,
    positionNftMint,
    positionNftAccount,
    personalPosition,
    systemProgram: SystemProgram.programId,
    tokenProgram: positionNftTokenProgram,
  })
  .remainingAccounts([
    { pubkey: poolId, isWritable: false, isSigner: false },
  ])
  .rpc();
```

Her kapatmada `poolId` geçirebilirsiniz. CLMM bunu yalnızca `positionNftAccount` dondurulduğunda okur, bu da bir istemci yolunu eski ve yeni pozisyonlarla uyumlu tutar.

## Swap

Kaynak: [`src/clmm/swap.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/swap.ts)

```ts
import { PoolUtils } from "@raydium-io/raydium-sdk-v2";

const amountIn = new BN(10_000_000);
const baseIn   = true;               // A (SOL) → B (USDC) swap yap
const slippage = 0.005;

const { minAmountOut, remainingAccounts, priceImpact } =
  PoolUtils.computeAmountOutFormat({
    poolInfo,
    tickArrayCache: await raydium.clmm.fetchTickArrays({ poolInfo }),
    amountIn,
    tokenOut: poolInfo.mintB,
    slippage,
    epochInfo: await raydium.fetchEpochInfo(),
  });

const { execute } = await raydium.clmm.swap({
  poolInfo,
  poolKeys,
  inputMint: new PublicKey(poolInfo.mintA.address),
  amountIn,
  amountOutMin: minAmountOut.amount,
  observationId: poolKeys.observationId,
  remainingAccounts,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

`computeAmountOutFormat`, zincir dışında tick haritasını zincir üstü programla aynı mantığı kullanarak yürür ve şunları döndürür:

- beklenen çıkış miktarı,
- kayma sonrası minimum çıkış miktarı,
- gerçek swap'ın dokunacağı tick dizisi hesaplarının listesi (`remainingAccounts`).

Simülasyon tarafından döndürülen `remainingAccounts` öğesini her zaman geçirin: çok az geçirirseniz, swap `TickArrayNotFound` ile yürüyüş ortasında geri döner; eski olanları geçirirseniz, boşa harcanan işlem.

## Özelleştirilebilir CLMM havuzu oluşturma

`createCustomizablePool`, havuz oluşturma zamanında dinamik ücret ve tek taraflı ücret geçişlerini ortaya koyan yeni giriş noktasıdır. `createPool` ile aynı şekli alır ve üç ek öğe:

```ts
import { CLMM_PROGRAM_ID, CollectFeeOn } from "@raydium-io/raydium-sdk-v2";

const dynamicFeeConfigs = await raydium.api.getClmmDynamicConfigs();    // GET /main/clmm-dynamic-config
const dynamicFeeConfig  = dynamicFeeConfigs.find((c) => c.index === 0); // bir kalibrasyon katmanı seçin

const { execute, extInfo } = await raydium.clmm.createCustomizablePool({
  programId: CLMM_PROGRAM_ID,
  mint1:     mintA,
  mint2:     mintB,
  ammConfig,
  initialPrice,
  startTime: new BN(0),
  // Yeni alanlar:
  collectFeeOn:        CollectFeeOn.Token1Only,   // 0 = FromInput, 1 = Token0Only, 2 = Token1Only
  enableDynamicFee:    true,
  dynamicFeeConfigId:  dynamicFeeConfig?.id,      // enableDynamicFee yanlış olduğunda atla
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
console.log("Özelleştirilebilir havuz:", extInfo.address.id.toBase58());
```

`createPool`, varsayılan ücret, limit emri yok, dinamik ücret yok yolu için çalışmaya devam eder. Üç yeni düğmeden herhangi birine ihtiyacınız olduğunda `createCustomizablePool` kullanın. Zincir üstü hesap listesi için [`products/clmm/instructions`](/tr/products/clmm/instructions) bölümüne bakın.

## Limit emirleri

Bir limit emri, kullanıcı girdisini tek bir tick'te park eder ve bir swap bu tick'i geçtiğinde FIFO'da doldurulur. Çıktılar, sahibinin ATA'sına kapatma zamanında itilir; sahibinin doldurulması için çevrimiçi olması gerekmez.

### Limit emri açma

```ts
import { TickUtils } from "@raydium-io/raydium-sdk-v2";

const limitConfigs = await raydium.api.getClmmLimitOrderConfigs(); // GET /main/clmm-limit-order-config
const limitConfig  = limitConfigs.find((c) => c.poolId === poolInfo.id);

// Limit fiyatı tick_spacing'e nicelleştirilmelidir.
const targetPrice = new Decimal(180);                              // SOL'u 180 USDC'de sat
const { tick: limitTick } = TickUtils.getPriceAndTick({
  poolInfo, price: targetPrice, baseIn: true,
});

const { execute } = await raydium.clmm.openLimitOrder({
  poolInfo,
  poolKeys,
  limitOrderConfig: limitConfig,
  inputMint: poolInfo.mintA.address,         // SOL satıyor
  inputAmount: new BN(50_000_000),           // 0.05 SOL
  tick: limitTick,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Limit emri açıldı, tx:", txId);
```

SDK, `LimitOrderState` PDA'sını `(pool, owner, tick, nonce)` öğesinden türetir, başına `LimitOrderNonce` öğesini çıkarır ve emri o tick'teki FIFO kohortuna ekler.

### Açık bir emri artırma / azaltma

```ts
await raydium.clmm.increaseLimitOrder({
  poolInfo,
  poolKeys,
  limitOrderId: <LIMIT_ORDER_PUBKEY>,
  addAmount: new BN(20_000_000),
  txVersion: TxVersion.V0,
}).then((b) => b.execute({ sendAndConfirm: true }));

await raydium.clmm.decreaseLimitOrder({
  poolInfo,
  poolKeys,
  limitOrderId: <LIMIT_ORDER_PUBKEY>,
  removeAmount: new BN(10_000_000),
  txVersion: TxVersion.V0,
}).then((b) => b.execute({ sendAndConfirm: true }));
```

`decreaseLimitOrder`, emrin yalnızca **doldurulmamış** kısmından kaldırabilir; doldurulmuş kısım kapatılana kadar kilitlenir. Her iki talimat da emir zaten tamamen doldurulmuşsa `InvalidOrderPhase` ile geri döner.

### Doldurulmuş bir emri kapatma

```ts
await raydium.clmm.settleLimitOrder({
  poolInfo,
  poolKeys,
  limitOrderId: <LIMIT_ORDER_PUBKEY>,
  txVersion: TxVersion.V0,
}).then((b) => b.execute({ sendAndConfirm: true }));
```

`settleLimitOrder`, emrin `unfilled_ratio_x64` öğesini kohort izleyicisine karşı okur, doldurulmuş çıktıyı hesaplar ve sahibinin ATA'sına aktarır. Sahibi bunu kendileri çağırabilir; `limit_order_admin` (çevrimdışı operasyonel bekçi) de sahibinin adına çağırabilir — çıktı yine de sahibine gider.

Tamamen kapatılan emirleri kapat kirasını kurtarmak için `closeLimitOrder` (tek) veya `closeAllLimitOrder` (toplu) kullanın. Aynı anda birçoğunu kapatmak için `settleAllLimitOrder`, v0 tx'e sığan kadar `SettleLimitOrder` çağrısını paketler.

### Bir cüzdanın park edilmiş emirlerini listeleme (çevrimdışı)

```ts
// API yardımcısı. api-reference/temp-api-v1 bölümüne bakın.
const active = await fetch(
  `https://temp-api-v1.raydium.io/limit-order/order/list?wallet=<your-wallet-pubkey>`,
).then((r) => r.json());
```

Etkin emirler uç noktası, doldurulmamış ve kısmen doldurulmuş emirleri tek bir yüklemede döndürür (`totalAmount` / `filledAmount` / `pendingSettle` aşamaları ayırt eder). Kapalı emir geçmişi için `/limit-order/history/order/list-by-user?wallet=…` kullanın (cüzdan başına, `nextPageId` ile sayfalandırılmış); belirli bir emrin tam olay günlüğü için `/limit-order/history/event/list-by-pda?pda=…` kullanın.

## Rust CPI iskelet

```rust
use anchor_lang::prelude::*;
use raydium_amm_v3::cpi;
use raydium_amm_v3::program::AmmV3;
use raydium_amm_v3::cpi::accounts::SwapV2;

#[derive(Accounts)]
pub struct ProxyClmmSwap<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,
    /// CHECK:
    pub amm_config: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub pool_state: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub input_token_account: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub output_token_account: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub input_vault: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub output_vault: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub observation_state: UncheckedAccount<'info>,
    /// CHECK:
    pub token_program: UncheckedAccount<'info>,
    /// CHECK:
    pub token_program_2022: UncheckedAccount<'info>,
    /// CHECK:
    pub memo_program: UncheckedAccount<'info>,
    /// CHECK:
    pub input_vault_mint: UncheckedAccount<'info>,
    /// CHECK:
    pub output_vault_mint: UncheckedAccount<'info>,
    pub clmm_program: Program<'info, AmmV3>,
    // `remaining_accounts` tick_array ve bitmap_extension hesaplarını taşır.
}

pub fn proxy_swap(
    ctx: Context<ProxyClmmSwap>,
    amount: u64,
    other_amount_threshold: u64,
    sqrt_price_limit_x64: u128,
    is_base_input: bool,
) -> Result<()> {
    let cpi_accounts = SwapV2 {
        payer:                 ctx.accounts.payer.to_account_info(),
        amm_config:            ctx.accounts.amm_config.to_account_info(),
        pool_state:            ctx.accounts.pool_state.to_account_info(),
        input_token_account:   ctx.accounts.input_token_account.to_account_info(),
        output_token_account:  ctx.accounts.output_token_account.to_account_info(),
        input_vault:           ctx.accounts.input_vault.to_account_info(),
        output_vault:          ctx.accounts.output_vault.to_account_info(),
        observation_state:     ctx.accounts.observation_state.to_account_info(),
        token_program:         ctx.accounts.token_program.to_account_info(),
        token_program_2022:    ctx.accounts.token_program_2022.to_account_info(),
        memo_program:          ctx.accounts.memo_program.to_account_info(),
        input_vault_mint:      ctx.accounts.input_vault_mint.to_account_info(),
        output_vault_mint:     ctx.accounts.output_vault_mint.to_account_info(),
    };
    let cpi_ctx = CpiContext::new(ctx.accounts.clmm_program.to_account_info(), cpi_accounts)
        .with_remaining_accounts(ctx.remaining_accounts.to_vec());
    cpi::swap_v2(cpi_ctx, amount, other_amount_threshold, sqrt_price_limit_x64, is_base_input)
}
```

`SwapV2` için kalan hesap sırası:

```
[tick_array_bitmap_extension?, tick_array_0, tick_array_1, …]
```

Swap hiçbir zaman uzantıya ihtiyaç duymazsa, atla; aksi takdirde ilk kalan hesaptır.

## Yaygın tuzaklar

- **Aralık dışı tick uç noktaları** → `InvalidTickIndex`. Her zaman `TickUtils.getPriceAndTick` aracılığıyla yasla.
- **`SwapV2` içinde sağlanan yeterli tick dizisi yok** → `TickArrayNotFound`. Tam listeyi almak için `computeAmountOutFormat` kullanın.
- **Bitmap uzantısı olmayan tam aralık pozisyonu** → uzantı PDA yazılabilir olmalıdır; SDK bunu otomatik olarak işler.
- **`sqrt_price_x64` öğesini `price` ile karıştırmak** → burada 2 faktörlü bir karışıklık özellikle acı vericidir. Şüphe duyduğunuzda, SDK'nın bunu insan tarafından okunabilir bir fiyattan hesaplamasına izin verin.
- **Ödülleri çok hevesle toplama** → her toplama bir işlem maliyeti. `harvestAllRewards` aracılığıyla birçok pozisyon arasında toplu hale getirin.
- **NFT hesaplarını kendiniz kapatma** → `ClosePosition` NFT'yi yakar ve ATA'sını kapatır. Ayrıca Token-2022 NFT mint'ini kapatır; klasik SPL Token mint'i sıfır arzda kalır çünkü bu program mint'leri kapatamaz. Desteklenen hesapları ayrı ayrı kapatmayın veya talimat geri döner.
- **Limit emrini boşluk dışı tick'te açma** → `InvalidTickIndex`. Her zaman `TickUtils.getPriceAndTick` aracılığıyla nicelleştirin.
- **Tamamen doldurulmuş bir emride `decreaseLimitOrder` çağırma** → `InvalidOrderPhase`. Bunun yerine `settleLimitOrder` ardından `closeLimitOrder` kullanın.
- **`enableDynamicFee: true` geçerken `dynamicFeeConfigId` unutma** → `CreateCustomizablePool` geri dönüşü `InvalidDynamicFeeConfigParams` olur. Dinamik ücreti kapatın veya `/main/clmm-dynamic-config` öğesinden bir yapılandırma seçin.
