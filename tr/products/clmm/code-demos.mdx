## Kurulum

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js decimal.js
```

Bu sayfadaki her örnek [`raydium-sdk-V2-demo/src/clmm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/clmm) içindeki bir dosyayı yansıtır; GitHub bağlantısı her bölümün yanında yer alır. Bootstrap, demo repo'nun `config.ts.template` ([kaynak](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)) izler — `disableFeatureCheck: true` herhangi bir önemsiz entegrasyon için önerilen ayardır:

```ts
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## CLMM havuzu oluşturun

Kaynak: [`src/clmm/createPool.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/createPool.ts)

```ts
import { PublicKey } from "@solana/web3.js";
import { CLMM_PROGRAM_ID } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import Decimal from "decimal.js";

const mintA = await raydium.token.getTokenInfo(
  new PublicKey("So11111111111111111111111111111111111111112"));   // wSOL
const mintB = await raydium.token.getTokenInfo(
  new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"));   // USDC

// getClmmConfigs() ApiClmmConfigInfo döndürür (id bir string'dir). createPool
// ClmmConfigInfo ister, bu da PublicKey id artı fundOwner/description gerektirir — dönüştürün:
const clmmConfigs = await raydium.api.getClmmConfigs();
const picked = clmmConfigs.find((c) => c.index === 1)!;        // 0.05% tier
const ammConfig = { ...picked, id: new PublicKey(picked.id), fundOwner: "", description: "" };

const initialPrice = new Decimal(160);        // SOL başına 160 USDC
const { execute, extInfo } = await raydium.clmm.createPool({
  programId: CLMM_PROGRAM_ID,
  mint1:     mintA,
  mint2:     mintB,
  ammConfig,
  initialPrice,
  txVersion: TxVersion.V0,   // startTime yok — CreateConcentratedPool böyle bir alana sahip değil
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Pool:", extInfo.address.id, "tx:", txId);   // zaten base58 string'i
```

SDK:

- Türetme öncesinde `mint1`/`mint2` öğelerini bayt sırasına göre sıralar.
- `sqrt_price_x64 = floor(sqrt(initialPrice × 10^(dB−dA)) × 2^64)` hesaplar.
- `observation` ve `tick_array_bitmap_extension` hesaplarını oluşturur.
- `ammConfig` tarafından tanımlanan havuz oluşturma ücretini öder.

## Seçilen aralıkta pozisyon açın

Kaynak: [`src/clmm/createPosition.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/createPosition.ts)

```ts
import { PoolUtils, TickUtil } from "@raydium-io/raydium-sdk-v2";

const POOL_ID = "<POOL_ID>";   // base58 string
// not: CLMM'nin getPoolInfoFromRpc `rpcPoolInfo` döndürür, CPMM'nin yaptığı `rpcData` değil
const { poolInfo, poolKeys, rpcPoolInfo } = await raydium.clmm.getPoolInfoFromRpc(POOL_ID);

// Fiyat aralığı seçin. Burada: mevcut fiyatın ±10'u.
const currentPrice = new Decimal(poolInfo.price);
const lowerPrice   = currentPrice.mul(0.9);
const upperPrice   = currentPrice.mul(1.1);

// Bu havuzun tick_spacing'i için geçerli tick'lere yapıştırın.
// Sınıf TickUtil (tekil) ve poolInfo değil, ondalıklar + tickSpacing alır.
const { tick: tickLower } = TickUtil.getPriceAndTick({
  price: lowerPrice,
  mintADecimals: poolInfo.mintA.decimals,
  mintBDecimals: poolInfo.mintB.decimals,
  zeroForOne: true,
  tickSpacing: poolInfo.config.tickSpacing,
});
const { tick: tickUpper } = TickUtil.getPriceAndTick({
  price: upperPrice,
  mintADecimals: poolInfo.mintA.decimals,
  mintBDecimals: poolInfo.mintB.decimals,
  zeroForOne: true,
  tickSpacing: poolInfo.config.tickSpacing,
});

// Her bir token'dan ne kadar yatırılacağı.
const inputAmount = new BN(10_000_000);  // 0.01 SOL

// getLiquidityAmountOutFromAmountIn async'tir — await edin.
const res = await PoolUtils.getLiquidityAmountOutFromAmountIn({
  poolInfo,
  slippage: 0.01,
  inputA: true,
  tickUpper,
  tickLower,
  amount: inputAmount,
  add: true,
  amountHasFee: true,
  epochInfo: await raydium.fetchEpochInfo(),
});

const { execute } = await raydium.clmm.openPositionFromBase({
  poolInfo,
  poolKeys,
  tickUpper,
  tickLower,
  base: "MintA",
  ownerInfo: { useSOLBalance: true },
  baseAmount: inputAmount,
  otherAmountMax: res.amountSlippageB.amount,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Pozisyon açıldı, tx:", txId);
```

SDK, aralığın dokunduğu tick dizilerini hesaplar ve bunları hesap olarak iletir. Herhangi bir init talimatını paketlemeye gerek yoktur — init-tick-array talimatı yoktur; `OpenPosition*` eksik bir tick dizisini kendisi ayırır, ödeyenin masrafına.

## Likiditeyi azaltın (ve aynı anda ücretleri toplayın)

Kaynak: [`src/clmm/decreaseLiquidity.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/decreaseLiquidity.ts) ve [`src/clmm/closePosition.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/closePosition.ts)

```ts
const { execute } = await raydium.clmm.decreaseLiquidity({
  poolInfo,
  poolKeys,
  ownerPosition: positionAccount,
  ownerInfo: {                       // gerekli; closePosition burada yaşıyor
    useSOLBalance: true,
    closePosition: false,
  },
  liquidity: positionAccount.liquidity.divn(2),   // yarıya indir
  amountMinA: new BN(0),
  amountMinB: new BN(0),
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

**Yalnızca ücretleri ve ödülleri toplamak için**, `decreaseLiquidity` öğesini `liquidity = new BN(0)` ile çağırın. Talimatın yan etkisi `token_fees_owed_{0,1}` ve `reward_amount_owed` öğelerini kapatmak ve bunları aktarmaktır — bu, ikisini de toplamak için tek yoldur.

Likiditeyi ve ücretleri sıfırladıktan sonra pozisyonu tamamen kapatmak için, son `decreaseLiquidity` çağrısında `ownerInfo: { closePosition: true }` geçirin. SDK `ClosePosition` ekler ve NFT'yi yakar.

<Warning>
  **Kısıtlı yayıncı pozisyonları uyumlu bir kapatma oluşturucusu gerektirir.** Bu pozisyonların dondurulmuş bir NFT token hesabı vardır. `ClosePosition`, CLMM'nin hesabı yakmadan önce çözmesi için pozisyonun havuz ID'sini ilk kalan hesap olarak eklemelidir. Program kaynağı dalı bir SDK değişikliği içermez. Kısıtlı yayıncı pozisyon oluşturmayı etkinleştirmeden önce SDK sürümünüzün açıkça dondurulmuş kapatma yolunu desteklediğini doğrulayın.
</Warning>

Doğrudan bir Anchor istemcisi için, bildirilen hesapları değişmeden tutun ve havuzu ekleyin:

```ts
// CLMM programı: reference/program-addresses bölümüne bakın; kaynak ecb1577;
// Solana mainnet-beta; son doğrulama 2026-08-13.
await program.methods
  .closePosition()
  .accounts({
    nftOwner,
    positionNftMint,
    positionNftAccount,
    personalPosition,
    systemProgram: SystemProgram.programId,
    tokenProgram: positionNftTokenProgram,
  })
  .remainingAccounts([
    { pubkey: poolId, isWritable: false, isSigner: false },
  ])
  .rpc();
```

Her kapatmada `poolId` geçirebilirsiniz. CLMM bunu yalnızca `positionNftAccount` dondurulduğunda okur, bu da bir istemci yolunu eski ve yeni pozisyonlarla uyumlu tutar.

## Swap

Kaynak: [`src/clmm/swap.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/clmm/swap.ts)

```ts
Bu, `PoolUtils.computeAmountOutFormat` yerine `swapInternal` ile simüle eden `src/clmm/swap.ts` öğesini yansıtır.

```ts
import {
  swapInternal,
  getPdaExBitmapAccount,
  TickArrayBitmapExtensionLayout,
  CLMM_PROGRAM_ID,
} from "@raydium-io/raydium-sdk-v2";

const amountIn   = new BN(10_000_000);
const zeroForOne = true;             // A (SOL) → B (USDC) swap yapın

const poolIdPub = new PublicKey(poolInfo.id);
const { rpcData, tickArrays, configInfo } =
  await raydium.clmm.getSwapPoolInfo(poolInfo.id, zeroForOne);

const exBitmap = getPdaExBitmapAccount(CLMM_PROGRAM_ID, poolIdPub).publicKey;
const exBitmapInfo = await raydium.connection.getAccountInfo(exBitmap);

const simulation = swapInternal({
  programId: CLMM_PROGRAM_ID,
  poolId: poolIdPub,
  poolInfo: rpcData,
  tickArrays,
  configInfo,
  tickarrayBitmapExtension: TickArrayBitmapExtensionLayout.decode(exBitmapInfo!.data),
  amountSpecified: amountIn,
  sqrtPriceLimitX64: new BN(0),
  zeroForOne,
  isBaseInput: true,               // kesin çıktı için false
  blockTimestamp: Math.floor(Date.now() / 1000),
  includeExtraTickArrays: true,
});

const { execute } = await raydium.clmm.swap({
  poolInfo,
  poolKeys,
  inputMint: poolInfo.mintA.address,
  amountIn,
  amountOutMin: simulation.amountCalculated,
  observationId: rpcData.observationId,
  ownerInfo: { useSOLBalance: true },   // gerekli
  remainingAccounts: simulation.accounts,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Simülasyon, tick haritasını zincir dışında, zincir üstü program ile aynı mantıkla yürür ve çıktı miktarını (`amountCalculated`) artı swap'ın dokunacağı tam hesap listesini (`accounts`) döndürür.

Her zaman simülasyonun döndürdüğü `remainingAccounts` öğesini geçirin: çok az ve swap `NotEnoughTickArrayAccount` ile yürüyüş ortasında geri döner; eski olanlar sadece işlem harcamasını boşa harcar.

<Note>
  `PoolUtils.computeAmountOutFormat` hala var, ancak bir `ComputeClmmPoolInfo` (API havuzu nesnesi değil, `getPoolInfoFromRpc` öğesinden `computePoolInfo`) artı iki daha gerekli argüman — `tickarrayBitmapExtension` ve `blockTimestamp` — gerektirir ve `raydium.clmm.fetchTickArrays` yöntemi yoktur (`fetchTickArrays` serbest bir işlevdir; modül düzeyindeki yardımcılar `PoolUtils.fetchMultiplePoolTickArrays` ve `getPoolInfoFromRpc` tarafından döndürülen `tickData` / `tickArrays` öğeleridir).
</Note>

## Özelleştirilebilir CLMM havuzu oluşturun

`createCustomizablePool`, havuz oluşturma zamanında dinamik ücret ve tek taraflı ücret geçişlerini ortaya çıkaran giriş noktasıdır. `createPool` şeklini artı **iki** ek alır:

```ts
import { CLMM_PROGRAM_ID, CollectFeeOn } from "@raydium-io/raydium-sdk-v2";

const dynamicFeeConfigs = await raydium.api.getClmmDynamicConfigs();    // GET /main/clmm-dynamic-config
const dynamicFeeConfig  = dynamicFeeConfigs.find((c) => c.index === 0); // bir kalibrasyon katmanı seçin

const { execute, extInfo } = await raydium.clmm.createCustomizablePool({
  programId: CLMM_PROGRAM_ID,
  mint1:     mintA,
  mint2:     mintB,
  ammConfig,
  initialPrice,
  // İki ek:
  collectFeeOn:      CollectFeeOn.TokenOnlyB,   // FromInput | TokenOnlyA | TokenOnlyB
  dynamicFeeConfig:  new PublicKey(dynamicFeeConfig!.id),
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
console.log("Özelleştirilebilir havuz:", extInfo.address.id);   // base58 string
```

<Warning>
  `enableDynamicFee` bayrağı yok ve `dynamicFeeConfigId` parametresi yok ve `startTime` yok.
  **`dynamicFeeConfig` sağlamak dinamik ücretleri etkinleştirir** — bunu atlayın ve statik ücretli bir havuz alırsınız, hatasız. Ayrıca SDK enum üyeleri `TokenOnlyA` / `TokenOnlyB` iken, zincir üstü Rust enum'u `Token0Only` / `Token1Only` olarak yazar; sayısal değerler eşleşir (`FromInput` = 0).
</Warning>

`createPool` varsayılan ücret, dinamik ücret yok yolu için çalışmaya devam eder. Her iki düğmeye de ihtiyacınız olduğunda `createCustomizablePool` kullanın. Zincir üstü hesap listesi için [`products/clmm/instructions`](/tr/products/clmm/instructions) bölümüne bakın.

## Limit emirleri

Bir limit emri, kullanıcı girdisini tek bir tick'te park eder ve bir swap bu tick'i geçtiğinde FIFO olarak doldurulur. Çıktılar, sahibinin ATA'sına kapatma zamanında itilir; sahibinin doldurulması için çevrimiçi olması gerekmez.

### Limit emri açın

```ts
Havuz başına limit emri yapılandırma hesabı yok ve `getClmmLimitOrderConfigs()` yardımcısı yok — emirler tick'e göre anahtarlanır.

```ts
import {
  getOrderTick,
  getPdaExBitmapAccount,
  CLMM_PROGRAM_ID,
} from "@raydium-io/raydium-sdk-v2";

const { poolInfo, rpcData } = await raydium.clmm.getSimplePoolInfo(POOL_ID);

// Limit fiyatı tick_spacing'e nicelenmeli — getOrderTick bunu yapar.
const targetPrice = new Decimal(180);                              // SOL'u 180 USDC'de sat
const orderData = getOrderTick({
  baseIn: true,                                                    // mintA satıyor
  mintADecimal: poolInfo.mintA.decimals,
  mintBDecimal: poolInfo.mintB.decimals,
  tickSpacing: poolInfo.config.tickSpacing,
  price: targetPrice,
});

// Bir satış emri mevcut tick'in üzerinde oturmalı; bir satın alma emri altında.
if (orderData.tick < rpcData.tickCurrent) throw new Error("satış fiyatı > mevcut fiyat olmalı");

const { execute, extInfo } = await raydium.clmm.openLimitOrder({
  poolInfo,
  baseIn: true,
  orderTick: orderData.tick,
  amount: new BN(50_000_000),                // 0.05 SOL
  tickArrayBitmap: getPdaExBitmapAccount(
    CLMM_PROGRAM_ID,
    new PublicKey(poolInfo.id),
  ).publicKey,
  // noneIndex: 0,                           // isteğe bağlı, varsayılan 0
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Limit emri açıldı:", extInfo.limitOrder.toBase58(), "tx:", txId);
```

SDK, `LimitOrderState` PDA'sını `(owner, nonce PDA, order nonce)` öğesinden türetir, cüzdan başına `LimitOrderNonce` öğesini çıkarır ve emri o tick'teki FIFO kohortuna ekler.

### Açık bir emri artırın / azaltın

```ts
const limitOrder = new PublicKey("<LIMIT_ORDER_PDA>");

await raydium.clmm.increaseLimitOrder({
  poolInfo,
  limitOrder,
  amount: new BN(20_000_000),
  txVersion: TxVersion.V0,
}).then((b) => b.execute({ sendAndConfirm: true }));

await raydium.clmm.decreaseLimitOrder({
  poolInfo,
  limitOrder,
  amount: new BN(10_000_000),
  slippage: 100,                 // isteğe bağlı; DecreaseLimitOrder bunu Increase'in üzerine ekler
  txVersion: TxVersion.V0,
}).then((b) => b.execute({ sendAndConfirm: true }));
```

`decreaseLimitOrder` yalnızca emrin **doldurulmamış** kısmından kaldırabilir; doldurulmuş kısım kapatılana kadar kilitlenir. Her iki talimat da emir zaten tamamen doldurulduysa `InvalidOrderPhase` ile geri döner.

### Doldurulmuş bir emri kapatın

```ts
// settleLimitOrder YALNIZCA emir PDA'sını alır — poolInfo yok, poolKeys yok.
await raydium.clmm.settleLimitOrder({
  limitOrder,
  txVersion: TxVersion.V0,
}).then((b) => b.execute({ sendAndConfirm: true }));
```

`settleLimitOrder`, emrin `unfilled_ratio_x64` öğesini kohort izleyicisine karşı okur, doldurulmuş çıktıyı hesaplar ve sahibinin ATA'sına aktarır. Sahibi bunu kendileri çağırabilir; `limit_order_admin` (çevrimdışı operasyonel bekçi) de sahibinin adına çağırabilir — çıktı yine de sahibine gider.

Tamamen kapatılan emirleri kira kurtarmak için kapatmak için `closeLimitOrder` (tek) veya `closeAllLimitOrder` (toplu) kullanın. Aynı anda birçoğunu kapatmak için, `settleAllLimitOrder` kadar çok `SettleLimitOrder` çağrısını bir v0 tx'e sığdırır.

### Bir cüzdanın park edilmiş emirlerini listeleyin (çevrimdışı)

```ts
// API yardımcısı. api-reference/temp-api-v1 bölümüne bakın.
const active = await fetch(
  `https://temp-api-v1.raydium.io/limit-order/order/list?wallet=<your-wallet-pubkey>`,
).then((r) => r.json());
```

Etkin emirler uç noktası, doldurulmamış ve kısmen doldurulmuş emirleri bir yüklemede döndürür (`totalAmount` / `filledAmount` / `pendingSettle` aşamaları ayırt eder). Kapalı emir geçmişi için `/limit-order/history/order/list-by-user?wallet=…` kullanın (cüzdan başına, `nextPageId` ile sayfalandırılmış); belirli bir emrin tam olay günlüğü için `/limit-order/history/event/list-by-pda?pda=…` kullanın.

## Rust CPI iskeleti

```rust
// Cargo.toml — CLMM hala Anchor 0.32'de, bu nedenle products/cpmm/code-demos'taki
// CPMM örneği ile bir crate'i paylaşamaz (=1.0.2 sabitler).
// anchor-lang  = "=0.32.1"
// anchor-spl   = "=0.32.1"
// raydium-clmm = { git = "https://github.com/raydium-io/raydium-clmm",
//                  branch = "master", features = ["cpi"] }

use anchor_lang::prelude::*;
use raydium_clmm::cpi;
use raydium_clmm::program::RaydiumClmm;
use raydium_clmm::cpi::accounts::SwapSingleV2;   // `SwapV2` talimat adı,
                                                 // `SwapSingleV2` hesaplar yapısı

#[derive(Accounts)]
pub struct ProxyClmmSwap<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,
    /// CHECK:
    pub amm_config: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub pool_state: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub input_token_account: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub output_token_account: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub input_vault: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub output_vault: UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub observation_state: UncheckedAccount<'info>,
    /// CHECK:
    pub token_program: UncheckedAccount<'info>,
    /// CHECK:
    pub token_program_2022: UncheckedAccount<'info>,
    /// CHECK:
    pub memo_program: UncheckedAccount<'info>,
    /// CHECK:
    pub input_vault_mint: UncheckedAccount<'info>,
    /// CHECK:
    pub output_vault_mint: UncheckedAccount<'info>,
    pub clmm_program: Program<'info, RaydiumClmm>,
    // `remaining_accounts` tick_array ve bitmap_extension hesaplarını taşır.
}

pub fn proxy_swap(
    ctx: Context<ProxyClmmSwap>,
    amount: u64,
    other_amount_threshold: u64,
    sqrt_price_limit_x64: u128,
    is_base_input: bool,
) -> Result<()> {
    let cpi_accounts = SwapSingleV2 {
        payer:                 ctx.accounts.payer.to_account_info(),
        amm_config:            ctx.accounts.amm_config.to_account_info(),
        pool_state:            ctx.accounts.pool_state.to_account_info(),
        input_token_account:   ctx.accounts.input_token_account.to_account_info(),
        output_token_account:  ctx.accounts.output_token_account.to_account_info(),
        input_vault:           ctx.accounts.input_vault.to_account_info(),
        output_vault:          ctx.accounts.output_vault.to_account_info(),
        observation_state:     ctx.accounts.observation_state.to_account_info(),
        token_program:         ctx.accounts.token_program.to_account_info(),
        token_program_2022:    ctx.accounts.token_program_2022.to_account_info(),
        memo_program:          ctx.accounts.memo_program.to_account_info(),
        input_vault_mint:      ctx.accounts.input_vault_mint.to_account_info(),
        output_vault_mint:     ctx.accounts.output_vault_mint.to_account_info(),
    };
    // Anchor 0.32 programın AccountInfo'sunu burada alır. Bunu bir
    // Pubkey'e değiştirmeyin — bu Anchor 1.0 formu, CLMM kullanmaz.
    let cpi_ctx = CpiContext::new(ctx.accounts.clmm_program.to_account_info(), cpi_accounts)
        .with_remaining_accounts(ctx.remaining_accounts.to_vec());
    cpi::swap_v2(cpi_ctx, amount, other_amount_threshold, sqrt_price_limit_x64, is_base_input)
}
```

`SwapV2` için kalan hesap sırası:

```
[tick_array_bitmap_extension?, tick_array_0, tick_array_1, …]
```

Swap hiçbir zaman uzantıya ihtiyaç duymazsa, bunu atlayın; aksi takdirde ilk kalan hesaptır.

## Yaygın tuzaklar

- **Aralık dışı tick uç noktaları** → `TickAndSpacingNotMatch`. Her zaman `TickUtil.getPriceAndTick` (tekil `TickUtil`) aracılığıyla yapıştırın.
- **`SwapV2` içinde sağlanan yeterli tick dizisi yok** → `NotEnoughTickArrayAccount`. Listeyi `swapInternal(...).accounts` öğesinden alın.
- **Bitmap uzantısı olmayan tam aralık pozisyonu** → uzantı PDA yazılabilir olmalı; SDK bunu otomatik olarak işler.
- **`sqrt_price_x64` öğesini `price` ile karıştırmak** → burada 2 faktörlü bir karışıklık özellikle acı vericidir. Şüphe duyduğunuzda, SDK'nın bunu insan tarafından okunabilir bir fiyattan hesaplamasına izin verin.
- **Ödülleri çok hevesli toplamak** → her toplama sıfır likidite `DecreaseLiquidity` ve bir işlem maliyeti. `harvestAllRewards` aracılığıyla birçok pozisyon arasında toplu hale getirin ve `execute` öğesinin `{ sequentially: true }` gerektirdiğini unutmayın.
- **NFT hesaplarını kendiniz kapatmak** → `ClosePosition` NFT'yi yakar ve ATA'sını kapatır. Ayrıca Token-2022 NFT mint'ini kapatır; klasik SPL Token mint'i sıfır arzda kalır çünkü bu program mint'leri kapatamaz. Desteklenen hesapları ayrı olarak kapatmayın veya talimat geri döner.
- **Limit emrini boşluksuz olmayan tick'te açmak** → `TickAndSpacingNotMatch`. Her zaman dışa aktarılan `getOrderTick` yardımcısı aracılığıyla nicelleyin.
- **Tamamen doldurulmuş bir emride `decreaseLimitOrder` çağırmak** → `InvalidOrderPhase`. Bunun yerine `settleLimitOrder` sonra `closeLimitOrder` kullanın.
- **`enableDynamicFee` bayrağı beklentisi** → yok. `dynamicFeeConfig` öğesini atlayarak, sessizce ve hatasız statik ücretli bir havuz oluşturursunuz. Dinamik ücretler istiyorsanız, `/main/clmm-dynamic-config` öğesinden seçilen yapılandırma hesabının `PublicKey` öğesini geçirin.
