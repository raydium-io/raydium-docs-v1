## Talimat özeti

| Ayırıcı adı | İmzalayan | Ne yapar |
|-------|-----------|--------------|
| `Initialize` | havuz oluşturucu | İki mint ve bir `AmmConfig` adresinden yeni bir CPMM havuzu oluştur. İzinsiz; herkes çağırabilir. Yeni havuzda `enable_creator_fee = false` sabit kodlanır. `pool_state` hesabı, kanonik PDA veya yeni rastgele bir anahtar çifti olabilir (bkz. Initialize hesapları). |
| `InitializeWithPermission` | ödeyici + `Permission` PDA sahibi | `Initialize` izinli varyantı. Çağıran (`payer`) kendi genel anahtarından türetilen bir `Permission` PDA'ya sahip olmalıdır. Havuz oluşturmayı kısıtlayan platformlar tarafından kullanılır (örn. LaunchLab mezuniyetleri). Çağıranın `creator_fee_on` (`BothToken` / `OnlyToken0` / `OnlyToken1`) sabitlemesine ve yeni havuzda `enable_creator_fee = true` zorlanmasına izin verir. `pool_state` üzerindeki `creator` alanı, ödeyici değil, ayrı olarak geçirilen bir `creator` hesabına ayarlanır. `pool_state` için `Initialize` ile aynı kanonik-PDA-veya-rastgele-anahtar esnekliği. |
| `Deposit` | LP | Her iki token'de likidite ekle; LP token'i al. |
| `Withdraw` | LP | LP token'i yak; her iki temel token'i orantılı olarak al. |
| `SwapBaseInput` | takas yapan | Tam giriş takaşı (`amount_in` giriş, ≥ `minimum_amount_out` çıkış). |
| `SwapBaseOutput` | takas yapan | Tam çıkış takaşı (≤ `maximum_amount_in` giriş, `amount_out` çıkış). |
| `CollectProtocolFee` | `protocol_owner` (`AmmConfig` adresinden) | Birikmiş protokol ücretlerini kasalardan topla. |
| `CollectFundFee` | `fund_owner` (`AmmConfig` adresinden) | Birikmiş fon ücretlerini kasalardan topla. |
| `CollectCreatorFee` | `pool_creator` | Birikmiş oluşturucu ücretlerini topla (oluşturucu ücreti etkinleştirilmişse). |
| `CollectCreatorFeePermissionless` | herhangi bir ödeyici | Tüm birikmiş oluşturucu ücretlerini `pool_creator`'ın kanonik token hesaplarına topla. Ödeyici eksik alıcı ATA'larını oluşturabilir ancak transferi yönlendiremez. |
| `UpdatePoolStatus` | `admin` | Bir havuzdaki belirli işlemleri bit maskesi aracılığıyla duraklat / devam ettir. |
| `UpdateAmmConfig` | `admin` | Bir `AmmConfig` üzerindeki ücret oranlarını veya protokol/fon sahibini değiştir. |
| `CreateAmmConfig` | `admin` | Yeni bir ücret katmanı oluştur (yeni `AmmConfig` hesabı). |
| `CreatePermissionPda` | `admin` veya delegeli izin-PDA oluşturucu | Belirli bir yetkilinin `InitializeWithPermission` çağırmasına izin veren bir `Permission` PDA'sı mint et. |
| `ClosePermissionPda` | `admin` | Daha önce verilen bir `Permission` PDA'sını iptal et. |

Durum bit maskesi: her havuzun `status` değeri, bit 0 = depozito devre dışı, bit 1 = çekim devre dışı, bit 2 = takas devre dışı (`PoolStatusBitIndex { Deposit, Withdraw, Swap }` programda) olan bir `u8` değeridir. Temiz bir bit işlemin izin verildiği anlamına gelir; ayarlanmış bir bit duraklatıldığı anlamına gelir. `UpdatePoolStatus` ham bir `u8` alır ve mevcut değerin üzerine yazar.

Sonraki bölümler her birini ayrıntılı olarak açıklar. Hesap sıralaması CPMM IDL'sini takip eder; SDK ve `raydium-cp-swap/programs/cp-swap/src/instructions` içindeki Rust istemcisi bu sırayı eşleştirir.

## `Initialize`

Yeni bir CPMM havuzu oluştur.

**Argümanlar**

```
init_amount_0: u64
init_amount_1: u64
open_time:     u64   // Unix zaman damgası; bu tarihten önce takaşlar reddedilir
```

**Hesaplar** (W = yazılabilir, S = imzalayan)

| # | Ad | W | S | Notlar |
|---|------|---|---|-------|
| 1 | `creator` | W | S | Kirayı öder; `pool_state.pool_creator` olarak kaydedilir. |
| 2 | `amm_config` |   |   | Seçilen ücret katmanı. |
| 3 | `authority` |   |   | CPMM global yetki PDA'sı. |
| 4 | `pool_state` | W | S* | Burada `init` edilir. **Ya** kanonik PDA `["pool", amm_config, token_0_mint, token_1_mint]` **ya da** yeni rastgele bir anahtar çifti — kanonik PDA olmadığında, program `pool_state`'in imzalamasını gerektirir (`require_eq!(pool_account_info.is_signer, true)`). Rastgele anahtar çifti yolu, oluşturucunun kanonik PDA üzerindeki ön çalıştırma girişimlerinden kaçınmasını sağlar. Aşağı akış PDA'ları (`lp_mint`, `vaults`, `observation_state`) her iki durumda da `pool_state.key()` adresinden türetilir. |
| 5 | `token_0_mint` |   |   | Sıralanmış: `token_0_mint < token_1_mint`. |
| 6 | `token_1_mint` |   |   | |
| 7 | `lp_mint` | W |   | Burada `init` edilir. Yetki `authority` olarak ayarlanır. |
| 8 | `creator_token_0` | W |   | `init_amount_0` için kaynak ATA. |
| 9 | `creator_token_1` | W |   | `init_amount_1` için kaynak ATA. |
| 10 | `creator_lp_token` | W |   | LP için hedef (eksikse oluşturulur). |
| 11 | `token_0_vault` | W |   | Burada `init` edilir. `authority` tarafından sahiplenilir. |
| 12 | `token_1_vault` | W |   | |
| 13 | `create_pool_fee` | W |   | Oluşturucu tarafından ödenen `create_pool_fee` için hedef ATA. |
| 14 | `observation_state` | W |   | Burada `init` edilir. |
| 15 | `token_program` |   |   | SPL Token (LP mint için). |
| 16 | `token_0_program` |   |   | SPL Token veya Token-2022. |
| 17 | `token_1_program` |   |   | SPL Token veya Token-2022. |
| 18 | `associated_token_program` |   |   | |
| 19 | `system_program` |   |   | |
| 20 | `rent` |   |   | |

`*` `pool_state` yalnızca rastgele anahtar çifti yolunda imzalar; kanonik-PDA yolu `pool_state` imzalaması olmadan çalışır.

**Ön koşullar**

- Mint'ler sıralanmıştır (`token_0_mint < token_1_mint` bayt sırasına göre).
- Hiçbir mint, CPMM izin listesi dışında bir uzantı kullanmaz (`TransferFeeConfig`, `MetadataPointer`, `TokenMetadata`, `InterestBearingConfig`, `ScaledUiAmount`) — bkz. [`products/cpmm/accounts`](/tr/products/cpmm/accounts#vaults-and-token-2022). Program içindeki küçük bir mint başına izin listesi, durum bazında ekleme için kontrolü atlar.
- `creator` ilgili ATA'larda en az `init_amount_0` ve `init_amount_1` değerine sahiptir.
- `amm_config.disable_create_pool == false`.

**Son koşullar**

- `pool_state` `lp_supply = sqrt(init_amount_0 * init_amount_1) − LOCKED_LP` ile var olur.
- `LOCKED_LP` (`100` lamport LP token) başlangıç değeri havuzda kalıcı olarak kilitlenir — `pool_state.lp_supply` `liquidity − 100` kaydeder, `100` LP birimi dolaşımın dışında kalır, havuzun tamamen boşaltılmasını ve sıfıra bölünmeyi engeller.
- `observation_state` başlatılır; `observation_index = 0` ve `pool_id = pool_state.key()`.
- `create_pool_fee` lamport'ları oluşturucudan alıcıya aktarılır ve yerel SOL olarak senkronize edilir (wSOL ATA'sıdır).
- Havuzun durum bit maskesi `0` (depozito / çekim / takas tümü etkindir).
- `enable_creator_fee = false` ve `creator_fee_on = BothToken`. `Initialize` oluşturucu ücretini etkinleştirmeyi **desteklemez** — bu yol `InitializeWithPermission` adresindedir.
- `open_time`, çağıran `<= block_timestamp` değeri geçtiyse `block_timestamp + 1` olarak yükseltilir. Takaşlar `open_time` öncesinde reddedilir; depozitolar ve çekimler hemen çalışır.

**Yaygın hatalar** (tam liste [`reference/error-codes`](/tr/reference/error-codes) adresinde)

- `InvalidInput` — mint'ler sıralanmamış veya özdeş mint'ler.
- `NotSupportMint` — engellenen Token-2022 uzantısı.
- `ExceededSlippage` — nadiren; `init_amount_0/1` ondalık uyumsuzluğu nedeniyle sıfır LP ile sonuçlanırsa.

## `Deposit`

Havuza orantılı olarak her iki token'de likidite ekle.

**Argümanlar**

```
lp_token_amount:   u64   // LP'ye mint edilecek kaç LP token'i
maximum_token_0:   u64
maximum_token_1:   u64
```

**Hesaplar**

| # | Ad | W | S |
|---|------|---|---|
| 1 | `owner` |   | S |
| 2 | `authority` |   |   |
| 3 | `pool_state` | W |   |
| 4 | `owner_lp_token` | W |   |
| 5 | `token_0_account` | W |   |
| 6 | `token_1_account` | W |   |
| 7 | `token_0_vault` | W |   |
| 8 | `token_1_vault` | W |   |
| 9 | `token_program` |   |   |
| 10 | `token_program_2022` |   |   |
| 11 | `vault_0_mint` |   |   |
| 12 | `vault_1_mint` |   |   |
| 13 | `lp_mint` | W |   |

**Matematik**

```
needed_token_0 = ceil(lp_token_amount * vault_0 / lp_supply)
needed_token_1 = ceil(lp_token_amount * vault_1 / lp_supply)
require(needed_token_0 <= maximum_token_0, "ExceededSlippage")
require(needed_token_1 <= maximum_token_1, "ExceededSlippage")
```

`k`'nin orantılılığında değişiklik yok — hem kasalar hem de `lp_supply` aynı faktörle ölçeklenir.

**Son koşullar**

- `lp_supply += lp_token_amount`.
- `vault_0 += needed_token_0` (giriş üzerindeki herhangi bir Token-2022 transfer ücreti net).
- `vault_1 += needed_token_1` (giriş üzerindeki herhangi bir Token-2022 transfer ücreti net).

**Yaygın hatalar** — `ExceededSlippage`, `ZeroTradingTokens`, depozito duraklatılmışsa `InvalidStatus`.

## `Withdraw`

LP token'lerini yak ve her iki temel token'i orantılı olarak al.

**Argümanlar**

```
lp_token_amount:   u64
minimum_token_0:   u64
minimum_token_1:   u64
```

**Hesaplar**

| # | Ad | W | S |
|---|------|---|---|
| 1 | `owner` |   | S |
| 2 | `authority` |   |   |
| 3 | `pool_state` | W |   |
| 4 | `owner_lp_token` | W |   |
| 5 | `token_0_account` | W |   |
| 6 | `token_1_account` | W |   |
| 7 | `token_0_vault` | W |   |
| 8 | `token_1_vault` | W |   |
| 9 | `token_program` |   |   |
| 10 | `token_program_2022` |   |   |
| 11 | `vault_0_mint` |   |   |
| 12 | `vault_1_mint` |   |   |
| 13 | `lp_mint` | W |   |

(`Deposit` ile özdeş; `lp_mint` yazılabilir çünkü LP token'leri yakılır.)

**Matematik**

```
out_token_0 = floor(lp_token_amount * vault_0 / lp_supply)
out_token_1 = floor(lp_token_amount * vault_1 / lp_supply)
require(out_token_0 >= minimum_token_0, "ExceededSlippage")
require(out_token_1 >= minimum_token_1, "ExceededSlippage")
```

**Son koşullar**

- `lp_supply -= lp_token_amount`.
- Kasalar `out_token_0` / `out_token_1` gönderir (brüt; kullanıcı herhangi bir Token-2022 transfer ücreti net olarak alır).

## `SwapBaseInput`

Tam giriş takaşı.

**Argümanlar**

```
amount_in:            u64
minimum_amount_out:   u64
```

**Hesaplar**

| # | Ad | W | S |
|---|------|---|---|
| 1 | `payer` |   | S |
| 2 | `authority` |   |   |
| 3 | `amm_config` |   |   |
| 4 | `pool_state` | W |   |
| 5 | `input_token_account` | W |   |
| 6 | `output_token_account` | W |   |
| 7 | `input_vault` | W |   |
| 8 | `output_vault` | W |   |
| 9 | `input_token_program` |   |   |
| 10 | `output_token_program` |   |   |
| 11 | `input_token_mint` |   |   |
| 12 | `output_token_mint` |   |   |
| 13 | `observation_state` | W |   |

Sıralama **giriş → çıkış**, havuzun kanonik `token_0 / token_1` değeri değil, kullanıcının yönüne göre yapılır. Program, mint'leri eşleştirerek hangi kasanın hangisi olduğunu belirler.

**Matematik** — bkz. [`products/cpmm/math`](/tr/products/cpmm/math).

**Ön koşullar**

- `open_time <= now`.
- `pool_status` takaşa izin verir.
- Bu yetki için hiçbir mint duraklatılmamış veya dondurulmamış.
- `amount_in > 0`.

**Yaygın hatalar**

- `ExceededSlippage` — `amount_out < minimum_amount_out`.
- `ZeroTradingTokens` — ticaret sıfıra yuvarlanır.
- `NotApproved` — havuz `UpdatePoolStatus` aracılığıyla takaşlar için duraklatılmış.
- `InvalidInput` — mint'ler havuzun kasa mint'lerinden hiçbiriyle eşleşmez.

## `SwapBaseOutput`

Tam çıkış takaşı.

**Argümanlar**

```
max_amount_in:  u64
amount_out:     u64
```

**Hesaplar** — `SwapBaseInput` ile aynı.

**Matematik** — tavan ile ters eğri, bkz. [`products/cpmm/math`](/tr/products/cpmm/math).

**Yaygın hatalar** — `ExceededSlippage` (`gross_in > max_amount_in`), `ZeroTradingTokens`, `InvalidInput`, `NotApproved`.

## `CollectCreatorFee`

`pool_state.pool_creator` tarafından imzalanır. Tam `creator_fees_token_0` ve `creator_fees_token_1` bakiyelerini oluşturucunun token hesaplarına aktarır, ardından her iki sayacı sıfırlar. Her iki sayaç da sıfır olduğunda `NoFeeCollect` döndürür.

## `UpdatePoolStatus`

Bir havuzdaki bireysel işlemleri duraklat veya devam ettir. `status` alanı bir bit maskesidir:

| Bit | Bayrak | Ayarlandığında etki |
|-----|------|-----------------|
| 0 | `DEPOSIT_DISABLED` | `Deposit` `NotApproved` ile reddeder. |
| 1 | `WITHDRAW_DISABLED` | `Withdraw` reddeder. |
| 2 | `SWAP_DISABLED` | `SwapBaseInput` / `SwapBaseOutput` reddeder. |

**Argümanlar**

```
status: u8      // yeni bit maskesi
```

**Hesaplar**

| # | Ad | W | S |
|---|------|---|---|
| 1 | `authority` |   | S | CPMM programındaki admin anahtarı ile eşleşmeli. |
| 2 | `pool_state` | W |   |

Admin anahtarı, CPMM programındaki yükseltme yetkilisidir — pratikte Raydium çoklu imza. Bkz. [`security/admin-and-multisig`](/tr/security/admin-and-multisig).


**Hesaplar**

**Ön koşullar**

- Aynı `index` ile mevcut `AmmConfig` yok.

## `UpdateAmmConfig`

Mevcut bir `AmmConfig` üzerindeki ücret oranlarını veya sahipliği değiştir. Bir `param: u8` (hangi alanın güncelleneceğinin ayırıcısı) ve bir `value: u64` alır. Param başına değer semantiği kaynakta; yaygın olarak:

- `param = 0` → `trade_fee_rate`
- `param = 1` → `protocol_fee_rate`
- `param = 2` → `fund_fee_rate`
- `param = 3` → `new_protocol_owner` (yeniden yorumlama olarak `Pubkey` baytlarını geç)
- `param = 4` → `new_fund_owner`
- `param = 5` → `create_pool_fee`
- `param = 6` → `disable_create_pool`

Değişiklikler admin tarafından imzalanır ve **bu `AmmConfig`'e bağlı her havuzu** sonraki takaşta etkiler. Geçiş yok; havuzlar yeni değerleri okur.

## Durum değişikliği matrisi

| Talimat | `lp_supply` | Kasa bakiyeleri | Birikmiş ücret alanları | `observation` |
|-------------|------------|---------------|-------------------|---------------|
| `Initialize` | + init LP | + `init_amount_{0,1}` | 0 | init |
| `InitializeWithPermission` | + init LP | + `init_amount_{0,1}` | 0 | init |
| `Deposit` | + | + her ikisi | — | — |
| `Withdraw` | − | − her ikisi | — | — |
| `SwapBaseInput` | — | + giriş, − çıkış | + `trade_fee` protokol/fona bölünür; etkinleştirilmişse + `creator_fee` | + (aralık geçtiyse) |
| `SwapBaseOutput` | — | + giriş, − çıkış | + `trade_fee` protokol/fona bölünür; etkinleştirilmişse + `creator_fee` | + (aralık geçtiyse) |
