## Ön koşullar

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js decimal.js
```

Bu sayfadaki her örnek [`raydium-sdk-V2-demo/src/cpmm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/cpmm) klasöründeki bir dosyayı yansıtır; GitHub bağlantısı her bölümün yanında yer alır. Başlatma, demo deposunun `config.ts.template` dosyasını takip eder ([kaynak](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)):

```ts
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);

const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
```

`Raydium` örneği SDK'nın cephesidir — aşağıdaki her örnek bunu kullanır. `Raydium.load` asenkron olduğu için varsayılan olarak token listesini yükler; bu getiriyi atlamak için `disableLoadToken: true` geçirin. Kullanılabilirlik özelliği kontrolü zaten atlanmıştır; `disableFeatureCheck: false` geçirmediğiniz sürece. Ücret yapılandırmaları `raydium.api.getCpmmConfigs()` aracılığıyla ilk kullanımda tembel olarak getirilir.

## CPMM havuzu oluşturma

Kaynak: [`src/cpmm/createCpmmPool.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/createCpmmPool.ts)

```ts
import { PublicKey } from "@solana/web3.js";
import BN from "bn.js";
import { CREATE_CPMM_POOL_PROGRAM, CREATE_CPMM_POOL_FEE_ACC }
  from "@raydium-io/raydium-sdk-v2";
// (Tüm havuz PDA'larını bir kerede almanız gerekiyorsa, dışa aktarılan yardımcı
//  `getCreatePoolKeys` adresindedir. `getCpmmPdas` yoktur.)

const mintA = new PublicKey("So11111111111111111111111111111111111111112"); // wSOL
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// 1. Bir ücret yapılandırması seçin. index=0, %0,25 katmanıdır.
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0)!;

// 2. SDK'nın Token-2022 uzantılarını işleyebilmesi için mint meta verilerini alın.
const mintAInfo = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(mintB);

// 3. İşlemi oluşturun.
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA:           mintAInfo,
  mintB:           mintBInfo,
  mintAAmount:     new BN(1_000_000_000),   // 1 SOL (9 ondalık basamak varsayılarak)
  mintBAmount:     new BN(   160_000_000),  // 160 USDC (SOL başına 160)
  startTime:       new BN(0),               // hemen aç
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Havuz oluşturuldu:", extInfo.address.poolId.toBase58());
console.log("İşlem:", txId);
```

SDK'nın sessizce hallettiği birkaç şey:

- Mint'leri token0/token1 sırasına göre sıralama ve PDA'yı türetme.
- Tek seferlik `create_pool_fee` ödemesi `poolFeeAccount` adresine.
- Eksikse arayanın ilişkili token hesaplarını oluşturma.
- Her taraf için doğru token programını seçme (SPL Token vs Token-2022).

Onaylandıktan sonra canlı havuz durumunu şu şekilde getirebilirsiniz:

```ts
// getPoolInfoFromRpc, base58 dizesi alır; PublicKey veya nesne değil.
const { poolKeys, poolInfo, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(
  extInfo.address.poolId.toBase58(),
);
```

## Swap (taban-giriş)

Kaynak: [`src/cpmm/swap.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swap.ts)

```ts
import { CurveCalculator, FeeOn } from "@raydium-io/raydium-sdk-v2";

const POOL_ID = "<POOL_ID>";   // base58 dizesi

// 1. Mevcut havuz durumunu doğrudan RPC'den yükleyin (API'den değil).
const { poolInfo, poolKeys, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(POOL_ID);

const inputMint  = poolInfo.mintA.address;                // A → B swap
const amountIn   = new BN(100_000_000);                   // 0,1 SOL
const slippage   = 0.005;                                 // %0,5

// 2. Yerel olarak fiyat belirleyin. CurveCalculator zincir üstü matematiği yansıtır,
//    her iki tarafta Token-2022 transfer ücretleri dahil. Tüm sekiz argüman gereklidir.
const baseIn = inputMint === poolInfo.mintA.address;
const swapResult = CurveCalculator.swapBaseInput(
  amountIn,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// swapResult alanları: inputAmount / outputAmount / tradeFee / protocolFee /
// fundFee / creatorFee / newInputVaultAmount / newOutputVaultAmount.
// destinationAmountSwapped veya sourceAmountSwapped yoktur.

// 3. Oluşturun ve gönderin. Burada `slippage` geçirmek sınırı uygular —
//    manuel minimum-out aritmetiğine gerek yoktur.
const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: amountIn,
  swapResult,
  slippage,
  baseIn,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Swap işlemi:", txId);
```

Not: SDK **her zaman** `getPoolInfoFromRpc` içinde havuz durumunu RPC'den yeniden getirir. İmzalamak üzere olduğunuz bir işlem için `api-v3.raydium.io` adresinden fiyat belirtmeyin — bir blok eski bir fiyat, iniş zamanında `ExceededSlippage` içine kayabilir.

## Swap (taban-çıkış)

Kaynak: [`src/cpmm/swapBaseOut.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swapBaseOut.ts)

```ts
const amountOutWanted = new BN(15_000_000);        // 15 USDC
const slippage        = 0.005;

const baseIn = false; // false → mintB giriş tarafıdır
const swapResult = CurveCalculator.swapBaseOutput(
  amountOutWanted,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// swapResult.inputAmount gerekli giriştir; sourceAmountSwapped yoktur.

const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: new BN(0),   // fixedOut olduğunda kullanılmaz — tutar swapResult'tan gelir
  fixedOut:    true,
  swapResult,               // gerekli ve hedef çıkış tutarını taşır
  baseIn,
  slippage,
  txVersion:   TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

## Likidite yatırma

Kaynak: [`src/cpmm/deposit.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/deposit.ts)

```ts
import { Percent } from "@raydium-io/raydium-sdk-v2";
import Decimal from "decimal.js";

// addLiquidity, LP tutarı değil, GİRİŞ tutarı tarafından yönlendirilir.
const uiInputAmount = "0.0001";
const inputAmount = new BN(
  new Decimal(uiInputAmount).mul(10 ** poolInfo.mintA.decimals).toFixed(0),
);
const slippage = new Percent(1, 100);   // sayı değil, Percent

const { execute } = await raydium.cpmm.addLiquidity({
  poolInfo,
  poolKeys,
  inputAmount,
  baseIn: true,           // inputAmount mintA cinsinden
  slippage,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

SDK, eşleştirilmiş tutarı havuzun mevcut rezervlerinden türetir, her tarafı talimatın `maximum_*` argümanları için slippage ile şişirir ve gerekirse ATA oluşturmalarını oluşturur. `raydium.cpmm.computePairAmount({ ... })` bir UI önizlemesi için istiyorsanız aynı sayıları döndürür.

## Protokol/fon/yaratıcı ücretlerini toplama

Kaynak: [`src/cpmm/collectCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectCreatorFee.ts), [`src/cpmm/collectAllCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectAllCreatorFee.ts)

Protokol ve fon toplama, yetki tarafından korunur. Yaratıcı ücretlerinin iki yolu vardır: yaratıcı tarafından imzalanan `CollectCreatorFee` ve katkı `CollectCreatorFeePermissionless`, herhangi bir ödeyici tarafından çağrılabilir ancak yalnızca yaratıcının kanonik ATA'larına aktarabilir. `0.2.64-alpha` her iki yaratıcı yolu için modül düzeyinde oluşturucuları gönderir:

```ts
// yaratıcı tarafından imzalanan
const { execute } = await raydium.cpmm.collectCreatorFees({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// izinsiz — herhangi bir ödeyici; gelirler yaratıcının kanonik ATA'larına gider
const { execute } = await raydium.cpmm.collectCreatorFeesPermissionless({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// bir kerede birkaç havuz, yaratıcı tarafından imzalanan
await raydium.cpmm.collectMultiCreatorFees({ poolInfoList, txVersion: TxVersion.V0 });
```

<Note>
  İki yaratıcı talimatının **farklı ayırıcıları ve hesap düzenleri vardır** — izinsiz olan,
  yaratıcı imzalayan / `amm_config` konumlarını ayrı bir `payer` ve imzalamayan bir `creator`
  ile değiştirir. Diğerinin hesaplarını el ile değiştirmek yerine eşleşen oluşturucuyu kullanın.

  SDK'da protokol veya fon ücreti oluşturucusu yoktur (`makeCollectProtocolFeeInstruction` ve
  `makeCollectFundFeeInstruction` hiçbir ad altında mevcut değildir) — bunlar yönetici yollarıdır.
  Mevcut olan düşük düzey talimat oluşturucuları `collectCpFeeInstruction`,
  `makeCollectCreatorFeeInstruction` ve `collectCreatorFeePermissionlessInInstruction` adresindedir.
</Note>

Zincir dışında, `PoolState` adresinden doğrudan tahakkuk eden ücretleri okuyabilirsiniz:

```ts
const pool = await raydium.cpmm.getRpcPoolInfo(POOL_ID);   // base58 dizesi
console.log("Tahakkuk eden protokol ücreti mintA:", pool.protocolFeesMintA.toString());
console.log("Tahakkuk eden protokol ücreti mintB:", pool.protocolFeesMintB.toString());
// CpmmPoolInfoLayout alanları protocolFeesMintA/B, fundFeesMintA/B ve
// creatorFeesMintA/B adresindedir — ...Token0/...Token1 alanları yoktur.
```

## Rust CPI iskeletini

Kendi Anchor programınızdan CPMM'yi çağırmak istiyorsanız — örneğin, mevduat sahipleri adına swap yapan bir kasa — CPI bağlamı şöyle görünür. Hesap sırası [`products/cpmm/instructions`](/tr/products/cpmm/instructions) adresini takip eder.

```rust
// Cargo.toml — dal önemlidir: `master` hâlâ anchor-lang 0.32.1 kullanır.
// raydium-cp-swap = { git = "https://github.com/raydium-io/raydium-cp-swap",
//                     branch = "chore/upgrade-anchor", features = ["cpi"] }
// anchor-lang      = "=1.0.2"   // raydium-cp-swap'ın kullandığı sürümle eşleşmelidir
// anchor-spl       = "=1.0.2"
//
// `cpi` özelliği gereklidir — `raydium_cp_swap::cpi` modülü yalnızca
// altında mevcuttur. Bu crate, anchor-lang =0.32.1 kullanan
// products/clmm/code-demos adresindeki CLMM örneği ile bir program paylaşamaz.

use anchor_lang::prelude::*;
use anchor_spl::token_interface::{TokenAccount, TokenInterface, Mint};
use raydium_cp_swap::cpi::accounts::Swap;
use raydium_cp_swap::cpi;
use raydium_cp_swap::program::RaydiumCpSwap;

#[derive(Accounts)]
pub struct ProxySwap<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,

    /// CHECK: CPMM programı tarafından doğrulanır
    pub authority:     UncheckedAccount<'info>,
    /// CHECK:
    pub amm_config:    UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub pool_state:    UncheckedAccount<'info>,

    #[account(mut)]
    pub input_token_account:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_token_account: InterfaceAccount<'info, TokenAccount>,

    #[account(mut)]
    pub input_vault:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_vault: InterfaceAccount<'info, TokenAccount>,

    pub input_token_program:  Interface<'info, TokenInterface>,
    pub output_token_program: Interface<'info, TokenInterface>,

    pub input_token_mint:  InterfaceAccount<'info, Mint>,
    pub output_token_mint: InterfaceAccount<'info, Mint>,

    #[account(mut)]
    /// CHECK: halka arabelleği
    pub observation_state: UncheckedAccount<'info>,

    pub cpmm_program: Program<'info, RaydiumCpSwap>,
}

pub fn proxy_swap_base_input(
    ctx: Context<ProxySwap>,
    amount_in: u64,
    minimum_amount_out: u64,
) -> Result<()> {
    let cpi_accounts = Swap {
        payer:                ctx.accounts.payer.to_account_info(),
        authority:            ctx.accounts.authority.to_account_info(),
        amm_config:           ctx.accounts.amm_config.to_account_info(),
        pool_state:           ctx.accounts.pool_state.to_account_info(),
        input_token_account:  ctx.accounts.input_token_account.to_account_info(),
        output_token_account: ctx.accounts.output_token_account.to_account_info(),
        input_vault:          ctx.accounts.input_vault.to_account_info(),
        output_vault:         ctx.accounts.output_vault.to_account_info(),
        input_token_program:  ctx.accounts.input_token_program.to_account_info(),
        output_token_program: ctx.accounts.output_token_program.to_account_info(),
        input_token_mint:     ctx.accounts.input_token_mint.to_account_info(),
        output_token_mint:    ctx.accounts.output_token_mint.to_account_info(),
        observation_state:    ctx.accounts.observation_state.to_account_info(),
    };
    // Anchor 1.0, programın AccountInfo'sunu değil Pubkey'ini alır.
    let cpi_ctx = CpiContext::new(
        *ctx.accounts.cpmm_program.key,
        cpi_accounts,
    );
    cpi::swap_base_input(cpi_ctx, amount_in, minimum_amount_out)
}
```

CPI'niz bir PDA olarak imzalarsa (örneğin, mevduat sahipleri adına bir kasa yönetiyorsanız), `CpiContext::new` yerine `CpiContext::new_with_signer` kullanın ve tohumlarınızı geçin.

## Yaygın tuzaklar

Bir destek talebini açmadan önce kısa bir kontrol listesi:

- **Sıralanmış mint'ler.** Türetilmiş `poolState` PDA'nız zincir üstü havuzla eşleşmiyorsa, muhtemelen mint'leri sıralamayı unuttunuz.
- **Eski API fiyatı.** Hiçbir zaman `api-v3.raydium.io` adresinden bir rezerv değerini `CurveCalculator.swap` adresine geçirmeyin. RPC'den getirin.
- **Yanlış token programı.** Token-2022 mint'inin kasası SPL Token tarafından değil Token-2022 programı tarafından sahiplenilir. Her zaman havuzun `token_0_program` / `token_1_program` alanlarını kullanın.
- **Transfer ücreti mint'leri için yetersiz slippage.** Havuzun her iki tarafı da Token-2022 transfer ücreti mint'i ise, `minimum_amount_out` kasanın gönderdiği değil, kullanıcının gerçekten aldığı şey cinsinden olmalıdır.
- **Swap'ta `NotApproved`.** `PoolState.status` adresini kontrol edin — yönetici bu havuzda swap'ları duraklatmış olabilir. Durum bitmaski için [`products/cpmm/instructions`](/tr/products/cpmm/instructions) adresine bakın.
