<Info>
  LaunchLab, Raydium'un birincil pazar başlatma mekanıdır. Bir proje token arzını bonding eğrisine yatırır; alıcılar eğriye karşı SOL (veya başka bir quote mint) ile işlem yapar; mezuniyet eşiğine ulaşıldığında, eğrinin varlıkları otomatik olarak bir CPMM havuzuna geçer ve token serbestçe işlem görmek üzere hazır hale gelir. Bu sayfa, proje tarafından tüm akışı adım adım açıklar.
</Info>

## İhtiyacınız olan şeyler

- **Token mint** — satmak istediğiniz token. Aşağıdakilerle yeni basılmış olmalıdır:
  - Tam arz cüzdanınıza basılmış (böylece eğriye yatırabilirsiniz).
  - Başlatmadan önce mint yetkisi iptal edilmiş (aksi takdirde eğri fiyatı yeni basımlarla oynanabilir).
- **Metadata** — ad, sembol, görüntü, sosyal bağlantılar. Metaplex metadata veya benzer.
- **Cüzdan** — oluşturma kirası + vault finansmanı + öncelik ücretleri için ~1 SOL (mezuniyet kendisi graduatör tarafından ödenir, siz tarafından değil).
- **Karar verin**:
  - Eğri türü (ikinci dereceden vs sanal-rezervler CPMM).
  - Mezuniyet eşiği.
  - LP elden çıkarma politikası (Yakma / Kilitleme / Yaratıcıya).
  - İlk fiyat ve üst sınır.

## Eğri seçimi

LaunchLab iki eğri ailesini destekler:

### İkinci Dereceden (`curve_type = 0`)

Fiyat satılan arz ile ikinci dereceden büyür. Klasik "adil başlatma" hissi — erken alıcılar fiyat avantajı alır, geç alıcılar daha fazla öder, fiyat düzgün şekilde hızlanır.

```
price(s) = a * s^2 + b * s + c
```

burada `s` satılan arzdır. Tipik olarak `a > 0` (dışbükey). İlk ve mezuniyet fiyatları arasındaki fark, `a, b, c` ve üst sınır verildiğinde belirlenimcidir.

En iyi: yeni başlayan projeler, memeler, topluluk odaklı projeler.

### Sanal-Rezervler CPMM (`curve_type = 1`)

Sanal rezervler kullanarak sabit-ürün AMM'yi taklit eder — eğri `x * y = k` ile bir CPMM gibi davranır ancak havuz hiçbir zaman çekilmeyen sentetik tokenlerle başlatılır.

```
price = virtual_quote_reserve / virtual_base_reserve
```

Alıcılar satın aldıkça, `virtual_base_reserve` azalır ve `virtual_quote_reserve` artar — eğri, mezuniyet sonrası CPMM'nin tam olarak neye benzeceğine özdeş görünür. Daha düzgün geçiş.

En iyi: mezuniyet sonrası fiyat sürekliliğini tahmin edilebilir kılmak isteyen başlatmalar.

## Arayüz kılavuzu

[raydium.io/launchpad/create](https://raydium.io/launchpad/create) adresinde:

1. **Token.** Mint adresini yapıştırın. Arayüz metadata'yı getirir ve görüntüler.
2. **Eğri türü.** İkinci dereceden veya sanal-CPMM seçin; arayüz her biri için fiyat grafiği önizlemesi gösterir.
3. **Mezuniyet eşiği.** Varsayılan: eğri `total_base_supply` tamamı satıldıktan sonra biter. Alternatif: belirli bir `graduation_quote_amount` (örn. 85 SOL) adresinde bitir.
4. **Quote mint.** SOL (varsayılan), USDC veya başka herhangi bir mint. SOL standarttır.
5. **LP elden çıkarma politikası:**
   - **Yakma** — LP tokenları mezuniyet sırasında kullanılamaz bir adrese gönderilir. Yaratıcı likiditeyi çekemez; kullanıcılar havuza sonsuza kadar güvenir.
   - **Kilitleme** — LP tokenları `lock_duration` için zaman kilitli emanete gönderilir.
   - **Yaratıcıya** — LP tokenları yaratıcıya gönderilir. En esnek, en az güven minimizasyonu.

   En saygın başlatmalar Yakma kullanır.

6. **İnceleme.** Arayüz özetler: beklenen fiyat aralığı, eğri tamamlanırsa ilk artış, mezuniyet CPMM yapılandırması.
7. **İmzala.** Bir işlem başlatma durumunu + temel vault'u + quote vault'u oluşturur, `total_base_supply` öğesini cüzdanınızdan temel vault'a aktarır.

## Programlı kılavuz

Eğri şekli, quote mint'i, artış hedefi ve LP-elden çıkarma politikası **argüman değildir** — bunlar bağladığınız `GlobalConfig` öğesinden ve başlatmanızın altında çalıştığı `PlatformConfig` öğesinden gelir. Geçirdiğiniz şey, mint'in kimliği, bağlanacak config ve isteğe bağlı olarak ilk bir satın almadır:

```ts
import {
  Raydium,
  TxVersion,
  LAUNCHPAD_PROGRAM,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";
import BN from "bn.js";

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });
const programId = LAUNCHPAD_PROGRAM;

// Temel mint'in keypair'ini oluşturur ve onunla imzalarsınız.
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// Config'i bağla: (quote mint, curve_type, index). Bu, eğri
// şeklini, quote mint'i ve artış hedefini sabitler.
const configId   = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
const configInfo = LaunchpadConfig.decode(configData!.data);
const mintBInfo  = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "My New Token",
  symbol: "MYNEW",                    // 10 karakter veya daha az
  uri:    "https://example.com/metadata.json",
  migrateType: "amm",                 // "amm" | "cpmm"

  configId,
  configInfo,
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  createOnly: true,                   // true = ilk satın alma olmadan mint'i oluştur
  buyAmount:  new BN(1000),
  slippage:   new BN(100),            // 100 = %1

  extraSigners: [pair],               // temel-mint keypair'i imzalamalıdır
  txVersion: TxVersion.V0,
  computeBudgetConfig: { units: 400_000, microLamports: 50_000 },
});

// createLaunchpad birkaç işlem döndürür - sırayla çalıştırın.
const { txIds } = await execute({ sequentially: true });
console.log("Pool ID:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
```

`raydium.api.fetchLaunchConfigs()` mevcut config'leri varsayılan arz, satış miktarı ve artış hedefi ile listeler, böylece kullanıcıya imzalamadan önce belirli bir config'in ne anlama geldiğini gösterebilirsiniz. Token-2022 varyantı da dahil olmak üzere tam açıklamalı sürüm: [`products/launchlab/code-demos`](/tr/products/launchlab/code-demos#create-a-launch).

## Mezuniyet öncesi izleme

API aracılığıyla aktiviteyi izleyin:

LaunchLab'ın `api-v3.raydium.io` öğesinden ayrı kendi API ana bilgisayarları vardır:

```ts
// Mint düzeyinde bilgi, temel mint tarafından anahtarlanmış (toplu işlem için virgülle ayrılmış).
const r = await fetch(
  `https://launch-mint-v1.raydium.io/get/by/mints?ids=${mintA.toBase58()}`,
).then((r) => r.json());
console.log(r.data.rows[0]);

// Ayrıca kullanılabilir: /main/configs (config listesi) aynı ana bilgisayarda ve
// https://launch-history-v1.raydium.io/kline ve /trade fiyat ve doldurma için.
```

Veya zincir üstü durumu doğrudan okuyun. Pool id, `(programId, mintA, mintB)` öğesinin bir PDA'sıdır:

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log({
  status:      poolInfo.status,
  baseSold:    poolInfo.realA.toString(),
  totalSellA:  poolInfo.totalSellA.toString(),
  quoteRaised: poolInfo.realB.toString(),
  raiseTarget: poolInfo.totalFundRaisingB.toString(),
});
```

İlerleme, eğri doğrusal olmadığı için artış yüzdesi yerine **fiyat** terimleriyle en iyi şekilde ifade edilir. Demo repo'nun [`getFinishRate.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/getFinishRate.ts) dosyası bunu `Curve.getPrice`, `Curve.getPoolEndPriceReal` ve `Curve.getPoolInitPriceByPool` ile yapar:

```
finishRate = (currentPrice − initPrice) / (endPrice − initPrice)   // 1'e sabitlenmiş
```

### İzlenecek metrikler

- **Satış oranı**: satılan temel yüzdesi. Mezuniyet eşiği tipik olarak %80–100 satıldığında.
- **Mevcut fiyat**: geçerli `baseSold` adresindeki eğriden türetilmiş.
- **Benzersiz alıcılar**: indexer aracılığıyla farklı ödeyenlerin sayısı.
- **Satın alma-satış oranı**: erken başlatmalar yavaşlayan ağır satın alma baskısı görür.

24 saat sonra satış oranı `<10%` ise, pazarlamanın yeterli olup olmadığını düşünün. LaunchLab, az tanıtılan başlatmaları kurtarmaz.

## Mezuniyet

Mezuniyet ayrı bir işlemdir ve **kimse tarafından** çağrılamaz: `MigrateToCpswap` ve eski `MigrateToAmm` her biri, imzalayanın bağlama `GlobalConfig` (`migrate_to_cpswap_wallet` / `migrate_to_amm_wallet`) üzerinde kaydedilen bir cüzdanla eşleşmesini gerektirir ve başka herhangi bir imzalayan `InvalidOwner` alır. Hiçbir ödül yoktur. Bu cüzdanlar Raydium'un mezuniyet krankı tarafından çalıştırılır ve eşik geçildiğinde saniyeler içinde geçişi gerçekleştirir. Yaratıcı olarak ilk kurulum ötesinde sizden herhangi bir işlem gerekmez.

### Mezuniyet ne yapar

1. Vault bakiyelerini okur.
2. Eğriyi kapatır (artık satın alma/satış yok).
3. Vault bakiyelerini ilk likidite olarak kullanan yeni bir CPMM havuzu oluşturur.
4. Vault bakiyelerine dayalı ilk LP tokenları basar.
5. LP tokenlarını yapılandırılan politikaya göre elden çıkarır (Yakma / Kilitleme / Yaratıcıya).

Mezuniyet sonrası, CPMM havuzu canlı ve normal Raydium yönlendirmesi aracılığıyla işlem görür.

### Mezuniyet için izleme

Pool durumundaki `status` öğesini izleyin ve değiştiğinde arayüzünüzü değiştirin:

```ts
const before = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

setInterval(async () => {
  const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
  if (p.status !== before) console.log("migrated - switch to the CPMM pool page");
}, 10_000);
```

Mezun havuzun adresi `(cpswap config, token0, token1)` için CPMM PDA'sıdır, bu nedenle rapor edilmesini beklemek yerine türetebilirsiniz. Bir indexer için, yoklama yerine gRPC üzerinden abone olun — bkz. [`products/launchlab/code-demos`](/tr/products/launchlab/code-demos#watch-configs-and-pools-over-grpc).

Yaratıcı veya üçüncü taraf için "manuel mezuniyet" yolu yoktur. Bir başlatma eşiğini geçmişse ve geçişi yapmamışsa, bu istemciden zorlayabileceğiniz bir şey değil, geçiş cüzdanı için operasyonel bir konudur.

## Mezuniyet sonrası

### CPMM havuzunu doğrulayın

```ts
const pool = await raydium.cpmm.getPoolInfoFromRpc({ poolId: cpmmPoolId });
console.log("CPMM price:", pool.poolInfo.price);
console.log("CPMM TVL:  ", pool.poolInfo.tvl);
```

CPMM havuzu (yaklaşık olarak) aşağıdakilere sahip olmalıdır:

- Temel token bakiyesi: `total_base_supply - baseSold` + eğri kalıntısı.
- Quote token bakiyesi: `quoteRaised - graduationFee`.
- Fiyat: son eğri fiyatıyla eşleşir.

### LP elden çıkarmayı doğrulayın

- **Yakma**: LP mint'in arzı 1nc1nerator11111111111111111111111111111111 veya benzerine gönderilen gösterir.
- **Kilitleme**: Kilit açma zaman damgası ile emanet PDA'sında LP tokenları.
- **Yaratıcıya**: Yaratıcının cüzdanında LP tokenları.

### Yaratıcı ücretlerini toplayın

Yaratıcı ücreti payı yapılandırdıysanız, periyodik olarak çağırın:

Builder `claimCreatorFee` öğesidir ve **quote mint** tarafından değil, başlatma tarafından anahtarlanır — bir çağrı, o mint'teki tahakkuk eden yaratıcı ücretlerinizi temizler:

```ts
import { NATIVE_MINT } from "@solana/spl-token";

await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,      // talep edilecek quote mint
  txVersion: TxVersion.V0,
});
```

Mint'ler arasında toplu işlem yapmak için `claimMultipleCreatorFee` kullanın. Ücretler mezuniyet öncesi eğri işlemlerinden tahakkuk eder ve mezuniyet sonrası CPMM havuzunun yaratıcı ücreti yolundan, platform'un `platform_cp_creator` sizi kaydedilen havuz yaratıcısı olarak bıraktığında — bkz. [`products/launchlab/platform-config`](/tr/products/launchlab/platform-config).

## Duyuru kontrol listesi

Mezuniyet sonrası duyuru şunları içermelidir:

- [ ] Mezuniyet işlem hash'i.
- [ ] Yeni CPMM pool ID'si.
- [ ] LP elden çıkarma kanıtı (yakma tx / kilitleme tx / yaratıcı cüzdanı).
- [ ] Toplayıcı kapsama ETA'sı (cüzdanlar tipik olarak 5 dakika içinde dizine alır).
- [ ] Token sözleşmesi doğrulaması (mint adresini duyuru kanalları arasında eşleştirin).

## Tuzaklar

### 1. Mint yetkisi iptal edilmedi

`baseMint.mintAuthority` hala kontrol ettiğiniz bir anahtar ise, yeni arz basabilir ve kendi eğrinize satabilirsiniz. Iptal etmemiş başlatmalar, toplayıcılar ve listeleme siteleri tarafından yaygın olarak yüksek riskli veya doğrulanmamış olarak işaretlenir. Başlatmadan önce iptal edin.

### 2. Yanlış eğri parametreleri

`a` çok yüksek olan ikinci dereceden eğriler erken tokenları ücretsiz yapar (fiyat ≈ 0) ve sonraki tokenları saçma kılar. `a` çok düşük olan eğriler eğriyi neredeyse doğrusal yapar ("bonding" hissini kaybeder). Parametreleri devnet'te önce test edin.

### 3. Mezuniyet eşiği çok yüksek

Mezuniyet gerçekçi talepten daha fazla sermaye gerektiriyorsa, eğri asla mezun olmaz ve alıcılar yalnızca eğriye geri satabilecekleri tokenlerle sıkışır (daha kötü fiyatlarla). Gerçekten vurabileceğiniz bir eşik seçin.

### 4. Quote mint dolandırıcılığı

Quote mint'iniz özel bir token ise (SOL/USDC değil), kullanıcılar buna güvenmez. Quote için SOL veya USDC'ye bağlı kalın.

### 5. Temel vault'u finanse etmeyi unuttunuz

SDK, oluşturma sırasında `totalBaseSupply` öğesini cüzdanınızdan aktarır. Cüzdanınızda yoksa, tx geri döner. İmzalamadan önce bakiyeyi onaylayın.

### 6. LP elden çıkarma = Yakma geri alınamaz

LP 1nc1nerator'a gönderildikten sonra, **siz de dahil olmak üzere** kimse likiditeyi çekemez. Bu nokta — güven minimizasyonu. Emin değilseniz Yakma seçmeyin.

### 7. Mezuniyet sonrası CPMM ücret katmanı

Mezun havuz LaunchLab'ın varsayılan CPMM config'ini (%0,25) kullanır. %1 veya %0,01 istiyorsanız, mezuniyet sonrası kendiniz ikinci bir CPMM havuzu oluşturmalı ve likiditeyi geçirmelisiniz — hantal ve parçalayıcı. Varsayılanı kabul edin veya LaunchLab yerine doğrudan CPMM oluşturma aracılığıyla başlatın.
