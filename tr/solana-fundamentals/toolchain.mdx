Bu belgelerdeki her şey, çalışan bir Solana geliştirme araç zincirinin mevcut olduğunu varsayar. Bu sayfa araçları, Raydium ile çalışması bilinen sürümleri (Eylül 2026 itibariyle) ve belirli kurulum sorunlarını listeler. Sonraki bölümlerdeki kod örneklerinden herhangi birini çalıştırmadan önce buradan başlayın.

**İki sürüm seti önemlidir ve bunlar aynı değildir.** Raydium programlarını *oluşturmak veya çatallak* için tam olarak sabitlediği araç zincirini gerekir — Rust 1.91.0, Agave 3.1.10, Anchor 1.0.2 (2026-09-09 yükseltmesi itibariyle). TypeScript veya Python'dan dağıtılan programlara karşı *entegre* olmak için yalnızca onlarla konuşmak için yeterince güncel bir istemci kitaplığına ihtiyacınız vardır ve sürüm sabitlemeleri tavsiye niteliğindedir. Aşağıdaki her bölüm hangi durumu kapsadığını belirtir.

## Temel araçlar

### Solana CLI

Solana kümeleriyle etkileşim kurmak için kanonik komut satırı arayüzü — cüzdan yönetimi, RPC çağrıları, program dağıtımı.

Kurulum:

```bash
# Raydium programlarının oluşturulduğu ve test edildiği sürüm
sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.10/install)"

# Veya bir etiketi takip etmek yerine bir kanalı takip edin
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

Doğrulama:

```bash
solana --version   # → solana-cli 3.1.10 (... client:Agave)
```

<Note>
  **Kurulum ana bilgisayarı taşındı.** `release.solana.com` Solana Labs'a aitti; istemci artık Anza tarafından **Agave** olarak korunmakta ve sürümler `release.anza.xyz` adresinden sunulmaktadır. Kendi kendini güncelleyen ikili `agave-install` (`solana-install` eski bir takma ad olarak tutulur), bu nedenle `agave-install update` ve `agave-install init <version>` güncel yazılışlardır. Solana'nın kendi belgeleri ayrıca CLI, Rust ve Anchor'u birlikte çeken tek komutlu bir yükleyici sunar:

  ```bash
  curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
  ```

  Bu yükleyici kendi güncel fikrini takip eder ve Raydium'un programlarının sabitlediğinden farklı bir Anchor size verebilir — sonrasında `anchor --version` kontrol edin.
</Note>

Mainnet için yapılandırma:

```bash
solana config set --url https://api.mainnet-beta.solana.com
solana config set --keypair ~/.config/solana/id.json
solana-keygen new                           # cüzdanınız yoksa oluşturun
solana address                              # genel anahtarınız
```

Raydium testi için neredeyse her zaman finanse edilmiş bir devnet cüzdanı isteyeceksiniz:

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2                            # test için 2 SOL
```

### SPL Token CLI

SPL Token / Token-2022 işlemleri için resmi CLI — mint'ler oluşturma, token'ları basma, aktarma.

Kurulum (Solana CLI'ye dahil):

```bash
spl-token --version
```

Yaygın işlemler:

```bash
spl-token create-token                                  # SPL Token mint'i oluştur
spl-token create-token --program-id TOKEN_2022 ...      # Token-2022 mint'i oluştur
spl-token create-account <MINT>                         # ATA oluştur
spl-token mint <MINT> 1000                              # ATA'nıza 1000 token bas
spl-token transfer <MINT> 100 <RECIPIENT>               # 100 aktar
spl-token display <ACCOUNT_OR_MINT>                     # incele
```

### Anchor CLI

Raydium IDL'lerini getirmek, istemciler oluşturmak ve programları doğrulamak için gerekli.

Kurulum:

```bash
cargo install --git https://github.com/solana-foundation/anchor avm --locked --force
avm install 1.0.2
avm use 1.0.2
anchor --version   # → anchor-cli 1.0.2
```

<Note>
  **Anchor depo ve ana sürümü taşındı.** Kanonik depo artık `github.com/solana-foundation/anchor` (daha önce `coral-xyz/anchor` idi) ve Anchor 1.0, Raydium programlarının kullandığı ilk sürüm satırıdır — CPMM ve LaunchLab her ikisi de 2026-09-09 yükseltmesi itibariyle `anchor-lang`/`anchor-spl` `=1.0.2` sabitlemiştir, `0.32.1`'den yükseltilmiştir. `avm` birkaç sürümü tutabilir; `avm use 1.0.2`, `anchor build`'in Raydium'un yapılarını yeniden üretmesini sağlayan şeydir. Anchor 1.1 ve 1.2 mevcut ve kendi programlarınız için iyi oluşturulur, ancak hedef programın sabitlediğinden farklı bir `anchor-lang` minörüne karşı derlenmiş bir CPI sandığı bağlanmayacaktır — bkz. [`sdk-api/rust-cpi`](/tr/sdk-api/rust-cpi).
</Note>

Yaygın işlemler:

```bash
anchor idl fetch <PROGRAM_ID> -o program.idl.json       # zincir üstü IDL'yi getir
anchor idl init -f idl.json <PROGRAM_ID>                # IDL'yi yükle
anchor build                                             # kaynaktan program oluştur
```

## TypeScript kurulumu

Raydium için birincil entegrasyon yolu.

### Paketler

```bash
npm install \
  @solana/web3.js \
  @solana/spl-token \
  @anchor-lang/core \
  @raydium-io/raydium-sdk-v2 \
  bn.js \
  decimal.js
```

Eylül 2026 itibariyle birlikte çalışması bilinen sürümler:

| Paket | Sürüm | Not |
|---------|---------|------|
| `@solana/web3.js` | `^1.95` | 1.x API'si. `2.x` / `3.x` farklı, uyumsuz bir API yüzeyidir; Raydium SDK 1.x'i hedefler. |
| `@solana/spl-token` | `^0.4.15` | 0.4.15, `createUnwrapLamportsInstruction`'ı ortaya çıkaran sürümdür — bkz. [geri alınabilir kira](/tr/solana-fundamentals/rent-and-reclaimable-rent). |
| `@anchor-lang/core` | `^1.0` | Anchor 1.x TypeScript istemcisi. |
| `@raydium-io/raydium-sdk-v2` | `0.2.64-alpha` | Bu belgelerdeki her kod demosunun kullandığı sabitleme. |

<Note>
  **`@anchor-lang/core` dondurulmuştur; paket artık `@anchor-lang/core`'dir.** `@anchor-lang/core` Anchor Solana Vakfı'na taşındığında `0.32.1`'de durdu. Anchor 1.x, `@anchor-lang/core` olarak yayınlanır ve Raydium'un kendi program depoları 2026-09-09 yükseltmesinde test paketlerini buna geçirdi. Gerçekten kullandığınız içe aktarmalar değişmemiştir — `import { Program, BN, AnchorProvider } from "@anchor-lang/core"` — bu nedenle geçiş yapmak bir paket yeniden adlandırması artı bir lockfile güncellemesidir.

  `0.3x`'ten geçiyorsanız iki davranışsal not: `.accounts({...})` artık yalnızca Anchor'un kendisi çözemediği hesapları kabul eder, bu nedenle tam seti geçen bir oluşturucu bunun yerine `.accountsPartial({...})` çağırmalıdır; ve `@anchor-lang/core/dist/cjs/utils/token`, `ASSOCIATED_PROGRAM_ID` gibi yardımcıların taşındığı yerdir.
</Note>

### Minimal betik

```ts
import { Connection, Keypair } from "@solana/web3.js";
import { Raydium } from "@raydium-io/raydium-sdk-v2";

const connection = new Connection("https://api.mainnet-beta.solana.com", "confirmed");
const owner      = Keypair.fromSecretKey(/* your key */);

const raydium = await Raydium.load({
  connection,
  owner,
  cluster:      "mainnet",
  disableFeatureCheck: true,
});

// `ids` virgülle ayrılmış bir listedir ve çağrı bir dizi döndürür
const [poolInfo] = await raydium.api.fetchPoolById({ ids: "..." });
console.log(poolInfo);
```

Tam SDK referansı için [`sdk-api/typescript-sdk`](/tr/sdk-api/typescript-sdk) bölümüne bakın.

## Rust kurulumu

CPI entegrasyonu ve zincir üstü programlar için.

### Araç zinciri

```bash
rustup install 1.91.0           # Raydium programlarının sabitlediği sürüm
rustup default 1.91.0
rustup component add rustfmt clippy
agave-install init 3.1.10       # SBF araç zinciri dahil
```

Programları `cargo build-sbf` ile oluşturun (eski `cargo build-bpf` yazılışı gitti).

### Raydium CPI entegrasyonu için Program Cargo.toml

```toml
# CPMM entegrasyonu (Anchor 1.0)
[dependencies]
anchor-lang        = "=1.0.2"
anchor-spl         = "=1.0.2"
raydium-cp-swap    = { version = "0.2", features = ["cpi"] }
```

```toml
# CLMM entegrasyonu — hala Anchor 0.32, bu nedenle kendi sandığına ihtiyaç duyar
[dependencies]
anchor-lang        = "=0.32.1"
anchor-spl         = "=0.32.1"
raydium-clmm       = { version = "0.1", features = ["cpi"] }
```

`anchor-lang` ve `anchor-spl`'yi hedef programın sabitlediği sürüme `=` ile sabitleyin. 2026-09 itibariyle CPMM `=1.0.2` sabitlemiş ve CLMM hala `=0.32.1` sabitlemiştir, bu nedenle **tek bir sandık her ikisine de CPI yapamaz** — bkz. [`sdk-api/rust-cpi`](/tr/sdk-api/rust-cpi#cargo-dependencies).

`"cpi"` özelliği CPI yardımcılarıyla `cpi` modülünü içe aktarır (böylece `raydium_cp_swap::cpi::swap_base_input(...)` yapabilirsiniz). Bkz. [`sdk-api/rust-cpi`](/tr/sdk-api/rust-cpi).

## Python kurulumu

İkincil entegrasyon yolu — bot geliştiricileri için yaygın.

### Paketler

```bash
pip install solders solana anchorpy
```

Sürümler:

| Paket | PyPI adı | Sürüm |
|---------|-----------|---------|
| `solders` | `solders` | ≥0.29 |
| solana-py | `solana` | ≥0.40 |
| `anchorpy` | `anchorpy` | ≥0.21 |

<Note>
  İki adlandırma tuzağı. RPC istemcisi `solana` olarak içe aktarılır ancak proje **solana-py** olarak adlandırılır — `pip install solana-py` hiçbir şey yararlı yüklemez. Ve PyPI'de **`raydium-py` paketi yoktur**: topluluk Raydium yardımcısı klonladığınız bir depo, [`AL-THE-BOT-FATHER/raydium_py`](https://github.com/AL-THE-BOT-FATHER/raydium_py), yayınlanmış bir dağıtım değildir. Bu sayfanın önceki revizyonları hiçbir zaman çalışmayan bir `pip install raydium-py` satırı listelemiştir.
</Note>

### Minimal betik

```python
from solana.rpc.async_api import AsyncClient
from solders.keypair import Keypair
from anchorpy import Provider, Wallet, Program

async def main():
    conn = AsyncClient("https://api.mainnet-beta.solana.com")
    owner = Keypair()
    wallet = Wallet(owner)
    provider = Provider(conn, wallet)

    # IDL ve programı yükle
    with open("cpmm.idl.json") as f:
        idl = json.load(f)
    program = Program(idl, CPMM_PROGRAM_ID, provider)

    pool = await program.account["PoolState"].fetch(pool_id)
    print(pool)
```

Bkz. [`sdk-api/python-integration`](/tr/sdk-api/python-integration).

## RPC uç noktaları

Genel mainnet RPC (`api.mainnet-beta.solana.com`) ağır oranda sınırlandırılmış ve herhangi bir yük altında kısıtlanır. Önemsiz olmayan kullanım için özel bir uç nokta alın:

| Sağlayıcı | Notlar |
|----------|-------|
| Helius | En popüler; cömert ücretsiz katman. |
| Triton | Kurumsal; premium fiyatlandırma, istikrarlı. |
| QuickNode | Katı; saniye başına alt gecikme. |
| Kendi RPC düğümünüz | Donanımda ~\$500/ay maliyeti; tam kontrol. |

Yapılandırma:

```ts
const connection = new Connection("https://mainnet.helius-rpc.com/?api-key=...");
```

Bazı RPC işlemleri genişletilmiş yeteneklere ihtiyaç duyar:

- `getProgramAccounts` — sınırsız taramalar pahalıdır; bazı sağlayıcılar kapı veya tarama başına ücret alır.
- `getPriorityFeeEstimate` — Helius'a özgü uç nokta; diğerlerinin eşdeğerleri vardır.
- `geyser` / WebSocket akışı — düşük gecikmeli botlar için gerekli; tüm sağlayıcılar bunu ortaya çıkarmaz.

## Devnet ve localnet

### Devnet

Solana'nın genel test kümesi. Raydium'un kısmi bir devnet dağıtımı vardır:

- Test için bazı CPMM havuzları mevcuttur.
- AMM v4'ün tarihsel devnet havuzları vardır.
- CLMM'nin birkaç demo havuzu vardır.
- Farm v6 dağıtılmıştır.

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2
```

SDK, `cluster: "devnet"` aracılığıyla devnet'i destekler:

```ts
const raydium = await Raydium.load({ connection, owner, cluster: "devnet" });
```

**Uyarı**: devnet havuzlarının ince likiditeleri vardır ve eski duruma sahip olabilir. Fiyat keşfi için devnet'e güvenmeyin; yalnızca talimat akışlarını oluşturmak ve test etmek için kullanın.

### Çatallı mainnet durumuna sahip Localnet

Gerçekçi test için mainnet durumunu yerel bir doğrulayıcıya çatallayın:

```bash
solana-test-validator \
  --url https://api.mainnet-beta.solana.com \
  --clone CPMMoo8L3F4NbTegBCKVNunggL7H1ZpdTHKxQB5qKP1C \
  --clone CAMMCzo5YL8w4VFF8KVHrK22GGUsp5VTaW7grrKgrWqK \
  --clone <SOME_POOL_ID> \
  --clone <SOME_MINT_ID>
```

Bu, belirli program/hesap durumunu localhost'a klonlar; burada serbestçe işlem yapabilirsiniz. İdeal:

- CPI entegrasyonunuzu gerçek bir Raydium programına karşı birim test etmek.
- Hata ayıklamak için değiştirilmiş bir parametreyle bir işlemi yeniden oynatmak.
- Büyük sentetik hacimlerle stres testi yapmak.

Raydium'un ekibi, mainnet dağıtımından önce regresyon testi için çatallı localnet'i kapsamlı bir şekilde kullanır.

## Proje şablonları

### TypeScript entegrasyon başlangıcı

```
my-raydium-app/
├── package.json
├── tsconfig.json
├── src/
│   ├── swap.ts           # swap örneği
│   ├── add-liquidity.ts
│   └── read-pool.ts
└── .env                  # RPC URL'si, cüzdan yolu
```

Minimal `package.json`:

```json
{
  "name": "my-raydium-app",
  "type": "module",
  "scripts": { "swap": "tsx src/swap.ts" },
  "dependencies": {
    "@raydium-io/raydium-sdk-v2": "0.2.64-alpha",
    "@solana/web3.js": "^1.95",
    "@solana/spl-token": "^0.4.15"
  },
  "devDependencies": {
    "@types/node": "^20",
    "tsx": "^4",
    "typescript": "^5"
  }
}
```

### Anchor CPI program başlangıcı

```
my-raydium-cpi/
├── Anchor.toml
├── Cargo.toml
├── programs/
│   └── my-cpi/
│       ├── Cargo.toml
│       └── src/lib.rs
└── tests/
    └── my-cpi.ts
```

Anchor 1.0 ile:

```bash
anchor init my-raydium-cpi
cd my-raydium-cpi
```

## Ortam hijyeni

### Amaç başına ayrı cüzdanlar

- **Geliştirme cüzdanı**: testnet SOL tutar, oluşturma için kullanılır.
- **Üretim cüzdanı**: gerçek SOL tutar, yalnızca dağıtımlar / multisig gönderileri için kullanılır.
- **Botlar için sıcak cüzdan**: küçük bakiye, dar izinler.

Anahtarlar hiçbir zaman kodlanmış olmamalıdır. Ortam değişkenlerini veya gizli yöneticileri kullanın.

### `.env` deseni

```
# .env (işlenmemiş)
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=...
WALLET_PATH=/Users/you/.config/solana/id.json
```

```ts
import { config } from "dotenv";
config();

const connection = new Connection(process.env.SOLANA_RPC_URL!);
```

### Sürüm sabitleme

Tüm Solana ekosistemi bağımlılıklarını kilitleyin. Ekosistem hızlı hareket eder; `@solana/web3.js`'nin küçük bir sürüm çarpması daha önce kırıcı değişiklikler getirmiştir. `package-lock.json` / `Cargo.lock`'u dindar bir şekilde kullanın.
