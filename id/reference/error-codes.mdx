## Cara kerja kode kesalahan Anchor

Anchor menetapkan setiap varian enum `ErrorCode` program dengan kode numerik mulai dari `6000`. Transaksi yang gagal menampilkan:

- **Kode kesalahan numerik** (misalnya `0x1771` = 6001) dalam log transaksi.
- **Nama kesalahan** (misalnya `InvalidOwner`) dari IDL.
- **String `#[msg(...)]`** yang dipancarkan Anchor dalam `log_messages`.

Integrator harus mencocokkan **kode numerik**, bukan string pesan (string dapat diubah kata-katanya tanpa menaikkan versi).

```ts
// Contoh: deteksi kesalahan slippage CPMM dan tampilkan pesan UX yang bersih.
const CPMM_EXCEEDED_SLIPPAGE = 6005;

try {
  await sdk.cpmm.swap({ ... });
} catch (err: any) {
  const code = err?.error?.errorCode?.number ?? err?.code;
  if (code === CPMM_EXCEEDED_SLIPPAGE) {
    showToast("Harga bergerak melampaui toleransi slippage Anda. Tingkatkan slippage atau coba lagi.");
    return;
  }
  throw err;
}
```

## Memetakan kesalahan SDK ke kesalahan program

SDK TypeScript resmi membungkus kesalahan on-chain ke dalam `SendTransactionError` dan, untuk program Anchor, `AnchorError`:

```ts
import { AnchorError } from "@coral-xyz/anchor";

try {
  await sdk.cpmm.swap({ ... });
} catch (err) {
  if (err instanceof AnchorError) {
    console.log(err.error.errorCode.number, err.error.errorCode.code, err.error.errorMessage);
    // 6005 ExceededSlippage "Exceeds desired slippage limit"
  } else {
    // Raw SendTransactionError — periksa err.logs untuk baris "custom program error: 0x...".
  }
}
```

Jika Anda tidak menggunakan klien Anchor, analisis log transaksi:

```
Program <ProgramID> invoke [1]
Program log: AnchorError caused by account: pool_state. Error Code: ExceededSlippage. Error Number: 6005. Error Message: Exceeds desired slippage limit.
```

Pola `Error Number: (\d+)` stabil di seluruh versi Anchor dan aman untuk dicocokkan.

## Meregenerasi tabel-tabel ini

Ketika program diperbarui dan menambahkan kesalahan baru, ekstrak ulang dari sumber:

```bash
# Clone dan grep enum kesalahan secara berurutan.
git clone --depth=1 https://github.com/raydium-io/raydium-cp-swap
awk '/#\[msg\(/{ gsub(/^[ \t]*#\[msg\("|"\)\][ \t]*/,""); m=$0; getline; gsub(/,/,""); gsub(/^[ \t]+/,""); print "6000+++\t" $0 "\t" m }' \
  raydium-cp-swap/programs/cp-swap/src/error.rs
# Ganti 6000+++ dengan 6000,6001,... yang meningkat secara monoton. Tambahkan baris baru ke tabel di atas.
```

Selalu perbarui [`reference/changelog`](/id/reference/changelog) ketika varian baru ditambahkan, sehingga integrator yang meningkatkan SDK tahu untuk menyegarkan penanganan kesalahan mereka.
