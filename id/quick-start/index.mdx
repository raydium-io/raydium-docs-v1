## Prasyarat

Jalankan ini sekali:

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

Anda memerlukan:

- **Node 18+** dengan dukungan ESM (`"type": "module"` di `package.json` atau ekstensi `.mjs`).
- **Keypair Solana** di `~/.config/solana/id.json` (atau di mana saja — atur `KEYPAIR`). Lihat [`solana-fundamentals/toolchain`](/id/solana-fundamentals/toolchain#solana-cli) untuk membuat keypair.
- **Dompet yang didanai.** Skrip swap hanya memerlukan jumlah input ditambah bantalan kecil — swap CPMM biaya ~0,0015 SOL dalam biaya jaringan (lihat [`reference/fee-comparison`](/id/reference/fee-comparison#network-fees-per-typical-operation)), ditambah rent satu kali jika swap harus membuka akun token untuk Anda. Membuat pool lebih mahal: skrip CPMM saja membawa biaya pembuatan pool satu kali ~0,15 SOL sebelum likuiditas seed atau rent. Lihat bagian Setup masing-masing skrip untuk angka terkini sebelum mendanai dompet Anda.
- **URL RPC.** RPC publik gratis berfungsi untuk pengujian; untuk apa pun lebih dari smoke test, gunakan penyedia berbayar.

Atur ini sekali per shell:

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **Cluster.** Ketiga skrip default ke mainnet. Devnet memerlukan `RPC_URL=https://api.devnet.solana.com` ditambah `cluster: "devnet"` di dalam skrip — untuk dua skrip pembuatan pool, itu bukan satu-satunya perubahan; lihat bagian Setup masing-masing skrip untuk apa lagi yang harus berubah. Ketahui bahwa likuiditas seed pool di devnet jarang; bersiaplah untuk membuat token uji Anda sendiri.
</Info>

## Setelah bab ini

Setiap skrip mencetak hasil on-chain-nya — quote swap dan tautan transaksi, alamat pool baru, atau posisi baru dan NFT-nya — dan satu baris yang menunjuk ke halaman berikutnya di bab [SDK & API](/id/sdk-api) untuk operasi yang dilakukannya. Ketika Anda siap menulis integrasi Anda sendiri:

- **Backend dan bot** → [Trade API](/id/sdk-api/trade-api).
- **Frontend dan aplikasi kontrol penuh** → [TypeScript SDK](/id/sdk-api/typescript-sdk).
- **Komposisi on-chain** → [Rust CPI](/id/sdk-api/rust-cpi).
- **Memilih di antara mereka** → tabel perbandingan di bagian atas [SDK & API](/id/sdk-api).
