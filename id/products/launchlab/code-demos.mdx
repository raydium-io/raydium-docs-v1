## Setup

Demo di sini mencerminkan file di [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad). Bootstrap mengikuti [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) repo demo:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Buat peluncuran

Sumber: [`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts) (dan [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts) untuk varian Bonk yang didorong API)

Sebagian besar ekonomi peluncuran **bukan** argumen — mereka berasal dari `GlobalConfig` yang Anda ikat melalui `configId`, dan SDK mengisi sisanya dari parameter default API. Anda meneruskan identitas mint, konfigurasi untuk diikat, dan (opsional) pembelian pertama:

```ts
import {
  LAUNCHPAD_PROGRAM,
  DEVNET_PROGRAM_ID,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";

const programId = LAUNCHPAD_PROGRAM;          // devnet: DEVNET_PROGRAM_ID.LAUNCHPAD_PROGRAM

// Mint dasar adalah keypair yang Anda buat dan tanda tangani.
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// Ikat GlobalConfig: (quote mint, curve_type, index).
const configId = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
if (!configData) throw new Error("config not found");
const configInfo = LaunchpadConfig.decode(configData.data);
const mintBInfo = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, transactions, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "Example Token",
  symbol: "EXMPL",                 // harus 10 karakter atau kurang
  uri:    "https://example.com/metadata.json",   // harus tidak kosong
  migrateType: "amm",              // "amm" | "cpmm"

  configId,
  configInfo,                      // opsional; SDK membaca ulang configId saat dihilangkan
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  // Pembelian pertama opsional dalam bundel yang sama.
  createOnly: true,                // true = buat mint saja
  buyAmount:  new BN(1000),        // diabaikan saat createOnly adalah true
  slippage:   new BN(100),         // 100 = 1%

  extraSigners: [pair],            // keypair mint dasar harus menandatangani
  txVersion: TxVersion.V0,

  // Default berasal dari default API konfigurasi terikat; hanya timpa jika Anda harus:
  // supply:            new BN(1_000_000_000_000_000),
  // totalSellA:        new BN(793_100_000_000_000),
  // totalFundRaisingB: new BN(85_000_000_000),   // 85 SOL saat mintB adalah SOL
  // totalLockedAmount: new BN(0),
  // cliffPeriod:       new BN(0),                // detik
  // unlockPeriod:      new BN(0),                // detik
  // platformId:        new PublicKey("4Bu96XjU84XjPDSpveTVf6LYGCkfW5FK7SNkREWcEfV4"), // Raydium's, default
});

// createLaunchpad mengembalikan MULTIPLE transaksi - jalankan secara berurutan.
const { txIds } = await execute({ sequentially: true });
console.log("Pool:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
console.log("Create txs:", txIds);
```

Catatan:

- **Tidak ada** argumen `curveType`, `graduationFractionBps`, `initialK`, `quoteMint`, `openTime`, `fees`, atau `postGraduationLpPolicy`. Bentuk kurva dan quote mint adalah properti `GlobalConfig` yang Anda ikat; tingkat biaya hidup di `GlobalConfig` dan `PlatformConfig`; pembuangan LP saat lulus adalah pengaturan `PlatformConfig`. Lihat [`products/launchlab/instructions`](/id/products/launchlab/instructions#initialize) untuk mengetahui dengan tepat apa yang diterima `InitializeV2`.
- `symbol` lebih panjang dari 10 karakter dan `uri` kosong keduanya ditolak sisi klien sebelum RPC apa pun.
- Melewatkan `transferFeeExtensionParams` mengalihkan builder ke `InitializeWithToken2022` dan memaksa `migrateType` menjadi `"cpmm"`.
- Builder mengembalikan array `transactions`; `createOnly: false` menambahkan transaksi pembelian pertama. Selalu `execute({ sequentially: true })` — mint harus ada sebelum pembelian mendarat.

## Ambil status peluncuran

Sumber: [`src/launchpad/poolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/poolInfo.ts)

Tidak ada `getLaunchById`. ID pool adalah PDA dari `(programId, mintA, mintB)`, dan `getRpcPoolInfo` mengembalikan `PoolState` yang didekodekan dengan `configInfo` terikatnya:

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log("status:", poolInfo.status);
console.log("base sold:", poolInfo.realA.toString(), "/", poolInfo.totalSellA.toString());
console.log("quote raised:", poolInfo.realB.toString(), "/", poolInfo.totalFundRaisingB.toString());

// Harga spot saat ini di kurva.
const price = Curve.getPrice({
  poolInfo,
  curveType: poolInfo.configInfo.curveType,
  decimalA: poolInfo.mintDecimalsA,
  decimalB: poolInfo.mintDecimalsB,
});
console.log("price:", price.toString());
```

`getRpcPoolsInfo({ poolIdList })` adalah bentuk batch dan mengembalikan `poolInfoMap` yang dikunci berdasarkan ID pool — gunakan untuk tampilan portofolio alih-alih looping. Jika Anda ingin mendekodekan akun mentah sendiri, `LaunchpadPool.decode` dan `LaunchpadConfig.decode` diekspor.

## Beli — quote tepat masuk

Sumber: [`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

Pembantu kutipan off-chain adalah **`Curve.buyExactIn`**, metode statis pada kelas `Curve` yang diekspor — bukan metode pada `raydium.launchpad`. Builder transaksi adalah **`buyToken`**. Keduanya memerlukan tingkat biaya platform, yang hidup di akun `PlatformConfig` terpisah:

```ts
import { Curve, PlatformConfig, toTransferFeeConfig } from "@raydium-io/raydium-sdk-v2";

const inAmount = new BN(1).mul(new BN(10).pow(new BN(9)));   // 1 SOL
const slippage = new BN(100);                                 // 100 = 1%

const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });
const platformData = await raydium.connection.getAccountInfo(poolInfo.platformId);
const platformInfo = PlatformConfig.decode(platformData!.data);

const mintInfo  = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(poolInfo.mintB);
const epochInfo = await raydium.connection.getEpochInfo();

// Pratinjau off-chain — mencerminkan matematika kurva on-chain.
const res = Curve.buyExactIn({
  poolInfo,
  amountB: inAmount,
  protocolFeeRate: poolInfo.configInfo.tradeFeeRate,
  platformFeeRate: platformInfo.feeRate,
  creatorFeeRate:  platformInfo.creatorFeeRate,
  curveType:       poolInfo.configInfo.curveType,
  shareFeeRate:    new BN(0),
  transferFeeConfigA: mintInfo.extensions.feeConfig  ? toTransferFeeConfig(mintInfo,  epochInfo.epoch) : undefined,
  transferFeeConfigB: mintBInfo.extensions.feeConfig ? toTransferFeeConfig(mintBInfo, epochInfo.epoch) : undefined,
  slot: await raydium.connection.getSlot(),
});
console.log("expected out:", res.amountA.amount.sub(res.amountA.fee ?? new BN(0)).toString());

const { execute, extInfo } = await raydium.launchpad.buyToken({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  transferFeeConfigB: toTransferFeeConfig(mintBInfo, epochInfo.epoch),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,
  buyAmount:       inAmount,
  slippage,                       // BN dalam bps; SDK menurunkan minMintAAmount darinya
  txVersion: TxVersion.V0,
});

console.log("expected receive amount:", extInfo.decimalOutAmount.toString());
const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

Anda dapat meneruskan `minMintAAmount` secara eksplisit alih-alih `slippage`; hilangkan keduanya dan SDK menghitung batas dari data RPC langsung. `shareFeeRate` tidak boleh melebihi `poolInfo.configInfo.maxShareFeeRate`, dan hanya berlaku saat Anda juga meneruskan `shareFeeReceiver`.

## Beli — base tepat keluar

Builder adalah **`buyTokenExactOut`**, dan argumen jumlah adalah `outAmount` (base yang Anda inginkan) dan `maxBuyAmount` (quote yang akan Anda belanjakan paling banyak). `Curve.buyExactOut({ poolInfo, amountA, ... })` adalah pratinjau off-chain yang cocok.

```ts
const { execute, extInfo } = await raydium.launchpad.buyTokenExactOut({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,

  outAmount:    new BN(1_000_000).mul(new BN(10).pow(new BN(6))),  // 1M base
  maxBuyAmount: new BN(2).mul(new BN(10).pow(new BN(9))),          // cap at 2 SOL
  slippage:     new BN(100),

  txVersion: TxVersion.V0,
});

console.log("out:", extInfo.outAmount.toString(), "max spent:", extInfo.maxSpentAmount.toString());
await execute({ sendAndConfirm: true });
```

Berguna untuk UI "beli tepat X token". Builder menolak `outAmount` nol sisi klien, dan program kembali jika kurva telah bergerak cukup sehingga persyaratan kutipan melebihi `maxBuyAmount`.

## Jual

Sumber: [`src/launchpad/sell.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/sell.ts)

Builder adalah **`sellToken`** (`sellTokenExactOut` untuk varian exact-quote-out), dengan `sellAmount` dan `minAmountB` opsional. `Curve.sellExactIn({ poolInfo, amountA, ... })` mempratinjauinya.

```ts
const inAmount = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M base

const res = Curve.sellExactIn({
  poolInfo,
  amountA: inAmount,
  protocolFeeRate: poolInfo.configInfo.tradeFeeRate,
  platformFeeRate: platformInfo.feeRate,
  creatorFeeRate:  platformInfo.creatorFeeRate,
  curveType:       poolInfo.configInfo.curveType,
  shareFeeRate:    new BN(0),
  transferFeeConfigA: mintInfo.extensions.feeConfig  ? toTransferFeeConfig(mintInfo,  epochInfo.epoch) : undefined,
  transferFeeConfigB: mintBInfo.extensions.feeConfig ? toTransferFeeConfig(mintBInfo, epochInfo.epoch) : undefined,
  slot: await raydium.connection.getSlot(),
});
console.log("expected quote out:", res.amountB.toString());

const { execute } = await raydium.launchpad.sellToken({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,
  sellAmount:      inAmount,
  slippage:        new BN(100),
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Jalur jual kurva simetris dengan jalur beli: mengurangi `real_a` sebesar `sellAmount` mengembalikan `quote_out` sama dengan area terintegrasi di bawah kurva antara `real_a − sellAmount` dan `real_a`, dikurangi biaya jual. `sellAmount` harus lebih besar dari nol — builder menolak nol sebelum RPC apa pun.

## Kelulusan

<Warning>
  **Kelulusan bukan sesuatu yang dapat dipicu oleh integrator.** Tidak ada `raydium.launchpad.graduate`, tidak ada flag `autoGraduate` pada builder beli, dan tidak ada field `willGraduate` pada nilai kembalian mereka. On-chain, kelulusan adalah `MigrateToCpswap` (atau `MigrateToAmm` warisan), dan kedua instruksi membatasi penanda tangan mereka ke dompet yang dicatat pada `GlobalConfig` pengikatan — `migrate_to_cpswap_wallet` dan `migrate_to_amm_wallet` masing-masing. Panggilan dari penanda tangan lain gagal dengan `InvalidOwner`. Ini **bukan** tanpa izin, dan tidak ada bot MEV yang dapat berlomba dengannya.
</Warning>

Dompet tersebut dioperasikan oleh crank kelulusan Raydium, jadi dalam praktik migrasi mendarat dalam hitungan detik setelah ambang batas terlampaui terlepas dari siapa yang melakukan pembelian terakhir. Dari sisi integrator, satu-satunya hal yang harus dilakukan adalah memperlakukan transisi status sebagai peristiwa cepat: polling `getRpcPoolInfo` (atau berlangganan melalui gRPC, di bawah) dan alihkan UI Anda dari kurva ke pool CPMM yang dihasilkan saat `status` berubah.

Lihat [`products/launchlab/instructions`](/id/products/launchlab/instructions#migratetoamm-/-migratetocpswap) untuk daftar akun, biaya migrasi, dan bagaimana LP dibagi saat kelulusan.

## Kumpulkan biaya kreator

Sumber: [`src/launchpad/claimCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/claimCreatorFee.ts) (mint tunggal) dan [`collectAllCreatorFees.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/collectAllCreatorFees.ts) (batch)

Metodenya adalah **`claimCreatorFee`** (dan `claimMultipleCreatorFee` untuk bentuk batch). Ini dikunci berdasarkan **quote mint**, bukan oleh peluncuran — satu panggilan menyapu biaya kreator yang terakumulasi penanda tangan di mint itu di seluruh peluncuran mereka:

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute } = await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,          // quote mint untuk diklaim
  // mintBProgram: TOKEN_PROGRAM_ID,   // atau TOKEN_2022_PROGRAM_ID
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Mentransfer penghitung biaya kreator yang terakumulasi ke ATA kreator di quote mint. Dapat dipanggil sebelum atau sesudah kelulusan; gunakan secara berkala daripada menunggu saldo besar terakumulasi. Operator platform memiliki builder paralel `claimPlatformFee` / `claimAllPlatformFee` / `claimVaultPlatformFee`.

## Lacak peluncuran melalui siklus hidupnya

Menyatukannya, skrip pemantauan mungkin terlihat seperti:

```ts
async function watch(poolId: PublicKey) {
  const startStatus = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

  while (true) {
    const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
    const progress = Number(p.realB.toString()) / Number(p.totalFundRaisingB.toString());

    console.log(`status=${p.status}`, `progress=${(progress * 100).toFixed(2)}%`);

    if (p.status !== startStatus) {
      console.log("status changed - the launch has migrated; switch to the pool page");
      break;
    }
    await new Promise((r) => setTimeout(r, 10_000));
  }
}
```

Polling `getRpcPoolInfo` pada timer 10 detik baik-baik saja untuk satu peluncuran. Untuk indexer, gunakan langganan gRPC di bawah sebagai gantinya — `getRpcPoolsInfo({ poolIdList })` batch, tetapi polling ratusan pool masih membakar kredit RPC tanpa manfaat.

## Pantau konfigurasi dan pool melalui gRPC

Sumber: [`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

Berlangganan program LaunchLab melalui gRPC Yellowstone dan mencatat setiap pembaruan `GlobalConfig` dan `PoolState` dengan program token setiap mint. Dua filter `datasize` pada satu langganan `accounts` memisahkan dua jenis akun, jadi satu aliran mencakup keduanya.

Demo adalah referensi paling singkat yang benar untuk mengklasifikasikan mint peluncuran, yang diperlukan oleh [rilis quote-mint Token-2022](/id/reference/changelog/2026-08-24-launchlab-token2022-quote-mint):

- **Pool** diklasifikasikan langsung dari `PoolState.token_program_flag`, mendekodekan bit0 untuk mint dasar dan bit1 untuk quote mint tanpa pengambilan mint sama sekali. Menguji seluruh byte terhadap `0` — yang cukup saat quote mint hanya warisan — salah membaca mint dasar warisan sebagai Token-2022 kapan pun quote mint adalah Token-2022.
- **Config** tidak dapat diklasifikasikan dengan cara itu: `GlobalConfig` menyimpan alamat quote mint dan tidak ada flag program, jadi demo membaca pemilik akun mint sekali dan menyimpannya per mint.

Ini juga melakukan cross-check keduanya satu sama lain, yang merupakan pernyataan berguna untuk disimpan di indexer Anda sendiri. Perhatikan bahwa `create` versus `update` disimpulkan dari cache demo sendiri, ditanam saat startup dari `getProgramAccounts`; dengan seeding itu dinonaktifkan, baca "create" sebagai "pertama kali terlihat di aliran ini".

Akses gRPC bukan bagian dari permukaan RPC publik — lihat [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md) repo demo.

## Rust CPI

Memanggil LaunchLab dari program Anchor Anda sendiri jarang terjadi (sebagian besar integrasi peluncuran hanya sisi TS). Jika Anda melakukannya:

- Crate adalah **`raydium-launchpad`** (nama lib `raydium_launchpad`), versi `0.2.0`, dan itu mengekspos fitur `cpi`. **Tidak ada** `raydium_launchlab`.
- Ini **tidak dipublikasikan di crates.io** — bergantung padanya dengan revisi git, cara yang sama seperti crate program Raydium lainnya.
- Titik masuk CPI dinamai setelah instruksi on-chain, bukan setelah metode TypeScript SDK: `buy_exact_in`, `buy_exact_out`, `sell_exact_in`, `sell_exact_out`, `claim_creator_fee`, `create_vesting_account`, `claim_vested_token`. `migrate_to_amm` / `migrate_to_cpswap` adalah gated penanda tangan ke dompet migrasi `GlobalConfig` dan tidak dapat dipanggil dari program integrator.

Lihat [`sdk-api/rust-cpi`](/id/sdk-api/rust-cpi) untuk aturan pengikat crate — khususnya pemisahan versi Anchor, yang menentukan apakah satu crate dapat CPI ke dalam LaunchLab dan CLMM.

## Jebakan

- **Membingungkan nama instruksi on-chain dengan nama metode SDK.** Program memiliki `buy_exact_in` / `sell_exact_in`; SDK memiliki `buyToken` / `sellToken`. `buyExactIn` dan `sellExactIn` hanya ada sebagai **metode statis pada `Curve`**, dan mereka menghitung kutipan — mereka tidak membangun transaksi.
- **Lupa `extraSigners`.** `createLaunchpad` membuat mint dasar dari keypair yang Anda buat, jadi keypair itu harus menandatangani. Hilangkan `extraSigners: [pair]` dan transaksi gagal verifikasi tanda tangan.
- **Tidak memilih quote mint.** Anda tidak meneruskan satu. Quote mint adalah properti `GlobalConfig` yang Anda ikat melalui `configId` — `getPdaLaunchpadConfigId(programId, quoteMint, curveType, index)`. Untuk meluncurkan terhadap quote mint yang berbeda, ikat konfigurasi yang berbeda; `raydium.api.fetchLaunchConfigs()` mencantumkan yang tersedia dengan parameter default mereka.
- **Ukuran metadata.** String `uri` panjang mendorong CPI Metaplex melampaui anggaran. Jaga `uri` di bawah ~200 karakter — sebagian besar metadata JSON yang dihosting CDN cocok dengan mudah. `symbol` dibatasi keras pada 10 karakter.
- **Memperlakukan kelulusan sebagai perlombaan yang dapat Anda masuki.** Bukan — lihat peringatan di atas. UI Anda masih harus memperlakukan transisi `status` sebagai peristiwa cepat, karena crank Raydium mendarat migrasi dalam hitungan detik setelah ambang batas terlampaui.
