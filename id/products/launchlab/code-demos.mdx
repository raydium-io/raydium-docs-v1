## Setup

Demo di sini mencerminkan file di [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad). Bootstrap mengikuti [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) dari repo demo:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Buat peluncuran

Sumber: [`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts) (dan [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts) untuk varian Bonk berbasis API)

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId: /* LaunchLab program ID dari reference/program-addresses */,
  // Metadata token untuk base mint baru:
  name:   "Example Token",
  symbol: "EXMPL",
  uri:    "https://example.com/metadata.json",
  decimals: 6,

  // Parameter curve:
  curveType: 0,                                      // 0 = quadratic
  supply:    new BN(1_000_000_000).mul(new BN(10).pow(new BN(6))), // 1B base (6 dec)
  graduationFractionBps: 8000,                       // 80% → lulus
  initialK:  new BN("40"),                           // parameter bentuk curve

  // Sisi quote:
  quoteMint: NATIVE_MINT,                            // WSOL
  openTime:  new BN(Math.floor(Date.now() / 1000) + 60),  // dibuka dalam 1 menit

  // Kebijakan biaya:
  fees: {
    buyNumerator:   new BN(100),                     // 1.00%
    buyDenominator: new BN(10_000),
    sellNumerator:  new BN(100),
    sellDenominator: new BN(10_000),
    lpShare:         new BN(60),
    creatorShare:    new BN(20),
    protocolShare:   new BN(20),
    totalShare:      new BN(100),
  },

  postGraduationLpPolicy: "burn",                    // "burn" | "lock" | "toCreator"

  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Launch:", extInfo.launchState.toBase58());
console.log("Base mint:", extInfo.baseMint.toBase58());
console.log("Create tx:", txId);
```

Catatan:

- `initialK` adalah faktor skala untuk curve kuadratik. Sesuaikan untuk menargetkan harga CPMM pembukaan tertentu saat lulus. Lihat [`products/launchlab/bonding-curve`](/id/products/launchlab/bonding-curve) untuk penurunannya.
- SDK menangani pembuatan base mint, metadata PDA, dan kedua vault dalam satu transaksi. Mungkin melebihi 1232 byte jika URI metadata panjang; dalam hal itu SDK membagi menjadi dua transaksi.
- Setelah `Initialize`, peluncuran tidak dapat diperdagangkan sampai `openTime`. Atur `openTime` satu atau dua menit ke depan untuk memberi front-runner kesempatan lebih sedikit untuk merebut pembelian pertama.

## Ambil status peluncuran

```ts
const launchId = new PublicKey("<LAUNCH_STATE>");

const launch = await raydium.launchpad.getLaunchById({ launchId });
console.log("Status:", ["Active","Graduated","Cancelled"][launch.status]);
console.log("Base sold:", launch.baseSold.toString(),
            "/", launch.baseSupplyMax.toString());
console.log("Quote collected:", launch.quoteReserveReal.toString(),
            "target:", launch.quoteReserveTarget.toString());
if (launch.status === 1) {
  console.log("Post-graduation CPMM pool:", launch.cpmmPoolState.toBase58());
}
```

`getLaunchById` mengembalikan `LaunchState` yang didekode ditambah fraksi "kemajuan menuju lulus" yang dihitung sebagai `Decimal`.

## Beli — quote tepat masuk

Sumber: [`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

```ts
const quoteIn        = new BN(1).mul(new BN(10).pow(new BN(9)));  // 1 SOL
const minimumBaseOut = new BN(0);  // terima apa saja; ketat untuk produksi

// Pratinjau quote off-chain sehingga UI Anda dapat menampilkan base_out yang diharapkan:
const preview = raydium.launchpad.computeBuyBase({
  launchState: launch,
  quoteIn,
});
console.log("Expected base_out:", preview.baseOut.toString(),
            "price impact:", preview.priceImpact.toString());

const { execute } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn,
  minimumBaseOut,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

`computeBuyBase` mencerminkan pemecah Newton on-chain (curve kuadratik) atau CPMM-inverse bentuk tertutup (curve_type 1). Gunakan untuk mengisi bidang UI "Anda terima".

## Beli — base tepat keluar

```ts
const baseOut         = new BN(1_000_000).mul(new BN(10).pow(new BN(6)));  // 1M base
const maximumQuoteIn  = new BN(2).mul(new BN(10).pow(new BN(9)));          // batas di 2 SOL

const { execute } = await raydium.launchpad.buyExactOut({
  launchInfo: launch,
  baseOut,
  maximumQuoteIn,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Berguna untuk UI "beli tepat X token". Ditolak dengan `ExceededSlippage` jika curve telah bergerak cukup sehingga persyaratan quote sekarang melebihi `maximumQuoteIn`.

```ts
const baseIn           = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M base
const minimumQuoteOut  = new BN(0);

const { execute } = await raydium.launchpad.sellExactIn({
  launchInfo: launch,
  baseIn,
  minimumQuoteOut,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Jalur jual curve simetris dengan jalur beli: mengurangi `base_sold` sebesar `baseIn` mengembalikan `quote_out` sama dengan area terintegrasi di bawah curve antara `base_sold − baseIn` dan `base_sold`, dikurangi biaya jual.

## Lulus otomatis pada pembelian penyeberangan ambang

SDK merantai instruksi `Graduate` di dalam transaksi `buy*` ketika mendeteksi status pasca-beli akan melampaui ambang:

```ts
const { execute, willGraduate } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn: new BN(100).mul(new BN(10).pow(new BN(9))),    // pembelian besar
  minimumBaseOut: new BN(0),
  txVersion: TxVersion.V0,
  autoGraduate: true,                                      // default
});

if (willGraduate) {
  console.log("Pembelian ini akan memicu kelulusan.");
}

const { txId } = await execute({ sendAndConfirm: true });
```

Karena `Graduate` tidak memerlukan izin, siapa pun (termasuk bot MEV) dapat berlomba untuk mendarat `Graduate` pertama setelah ambang dilampaui — biasanya dalam hitungan detik, bukan menit. Pendaratan pertama hanya membayar sewa untuk akun pool CPMM; mereka tidak mendapat manfaat lain.

## `Graduate` manual

Jika `autoGraduate` dimatikan atau transaksi penyeberangan ambang gagal, Anda dapat menjalankan kelulusan secara terpisah:

```ts
const { execute } = await raydium.launchpad.graduate({
  launchInfo: launch,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Kembali dengan `NotAtThreshold` jika `quote_reserve_real < quote_reserve_target` pada waktu pengajuan. Aman untuk coba ulang — upaya `Graduate` kedua setelah sukses kembali dengan `NotActive`.

Mentransfer jumlah penghitung biaya kreator yang terkumpul ke ATA kreator pada quote mint. Dapat dipanggil sebelum atau sesudah kelulusan; gunakan secara berkala daripada menunggu saldo besar terakumulasi.

## Lacak peluncuran melalui siklus hidupnya

Menyatukannya, skrip pemantauan mungkin terlihat seperti:

```ts
async function watch(launchId: PublicKey) {
  while (true) {
    const launch = await raydium.launchpad.getLaunchById({ launchId });
    const progress =
      Number(launch.quoteReserveReal) /
      Number(launch.quoteReserveTarget);

    console.log(
      `status=${["Active","Graduated","Cancelled"][launch.status]}`,
      `progress=${(progress * 100).toFixed(2)}%`,
      `num_buys=${launch.stateData.numBuys}`,
    );

    if (launch.status === 1) {
      console.log("Lulus ke pool CPMM:", launch.cpmmPoolState.toBase58());
      break;
    }
    await new Promise(r => setTimeout(r, 10_000));
  }
}
```

## Pantau konfigurasi dan pool melalui gRPC

Sumber: [`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

Berlangganan program LaunchLab melalui Yellowstone gRPC dan catat setiap pembaruan `GlobalConfig` dan `PoolState` dengan program token setiap mint. Dua filter `datasize` pada satu langganan `accounts` memisahkan dua jenis akun, jadi satu aliran mencakup keduanya.

Demo adalah referensi paling singkat yang benar untuk mengklasifikasikan mint peluncuran, yang diperlukan oleh [rilis quote-mint Token-2022](/id/reference/changelog/2026-08-24-launchlab-token2022-quote-mint):

- **Pool** diklasifikasikan langsung dari `PoolState.token_program_flag`, mendekode bit0 untuk base mint dan bit1 untuk quote mint tanpa pengambilan mint sama sekali. Menguji seluruh byte terhadap `0` — yang cukup saat quote mint hanya legacy — salah membaca base mint legacy sebagai Token-2022 kapan pun quote mint adalah Token-2022.
- **Config** tidak dapat diklasifikasikan dengan cara itu: `GlobalConfig` menyimpan alamat quote mint dan tidak ada flag program, jadi demo membaca pemilik akun mint sekali dan menyimpannya per mint.

Ini juga melakukan cross-check keduanya satu sama lain, yang merupakan pernyataan berguna untuk disimpan di indexer Anda sendiri. Perhatikan bahwa `create` versus `update` disimpulkan dari cache demo sendiri, ditanam saat startup dari `getProgramAccounts`; dengan seeding itu dinonaktifkan, baca "create" sebagai "pertama kali terlihat di aliran ini".

Akses gRPC bukan bagian dari permukaan RPC publik — lihat [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md) dari repo demo.

## Rust CPI

Memanggil LaunchLab dari program Anchor Anda sendiri jarang terjadi (sebagian besar integrasi peluncuran hanya di sisi TS). Jika Anda melakukannya, program mengirimkan crate Anchor `raydium_launchlab` dengan `cpi::accounts::Buy`, `cpi::accounts::Sell`, dll. — pola mencerminkan contoh CPI CPMM / CLMM. Lihat [`sdk-api/rust-cpi`](/id/sdk-api/rust-cpi) untuk template umum setelah situs ini diisi.

## Jebakan

- **Aritmetika pembagian biaya off-by-one.** Jika `total_share` bukan persis `lp_share + creator_share + protocol_share`, `Initialize` kembali dengan `InvalidFeeShares`. Atur `totalShare` sama dengan jumlahnya.
- **Menggunakan quote mint yang tidak diizinkan.** `launch_config.allowed_quote_mints` adalah daftar tetap; melewati mint lain apa pun kembali. Periksa dengan `raydium.launchpad.getConfig()` terlebih dahulu.
- **Ukuran metadata.** String `uri` panjang mendorong Metaplex CPI melampaui anggaran. Jaga `uri` di bawah ~200 karakter — sebagian besar metadata JSON yang dihosting CDN cocok dengan mudah.
- **Perlombaan kelulusan.** Bot otomatis memantau `quote_reserve_real` dan front-run `Graduate` dalam satu atau dua slot setelah penyeberangan ambang. Ini tidak berbahaya — hanya menghabiskan sewa mereka — tetapi berarti UI Anda harus memperlakukan transisi `status` sebagai peristiwa cepat.
