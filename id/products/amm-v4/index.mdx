## Apa itu AMM v4

AMM v4 adalah pool generasi pertama Raydium. Ini mempertahankan invariant constant-product (xy=k). Pool awalnya dirancang sebagai **AMM hibrida**: di samping kurva, pool memposting grid limit order berspasi Fibonacci ke pasar OpenBook yang terikat sehingga likuiditas pool terlihat oleh orderbook taker. **Integrasi OpenBook tersebut telah dihapus dari program** (lihat peringatan di atas); AMM v4 hari ini adalah AMM constant-product murni. Akun `AmmInfo` on-chain mempertahankan field referensi `market` / `open_orders` mereka untuk kompatibilitas tata letak, tetapi program tidak lagi membaca atau bertindak atas mereka.

Ini masih merupakan produk dengan likuiditas tertinggi di Raydium untuk banyak pasangan legacy tetapi **tidak lagi direkomendasikan untuk pool baru** — lihat [CPMM](/id/products/cpmm) untuk deployment baru.

**Program ID:** lihat [reference/program-addresses](/id/reference/program-addresses).

**Token-2022:** tidak didukung. Pool AMM v4 hanya menerima token SPL klasik.
