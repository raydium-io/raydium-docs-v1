## Prasyarat

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js decimal.js
```

Setiap demo di halaman ini mencerminkan file dalam [`raydium-sdk-V2-demo/src/cpmm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/cpmm); tautan GitHub berada di samping setiap bagian. Bootstrap mengikuti `config.ts.template` repo demo ([sumber](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)):

```ts
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);

const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
```

Instans `Raydium` adalah facade SDK — setiap demo di bawah menggunakannya. `Raydium.load` bersifat async karena memuat daftar token secara default; teruskan `disableLoadToken: true` untuk melewati pengambilan tersebut. Pemeriksaan fitur ketersediaan sudah dilewati kecuali Anda melewati `disableFeatureCheck: false`. Konfigurasi biaya diambil secara lazy pada penggunaan pertama melalui `raydium.api.getCpmmConfigs()`.

## Buat pool CPMM

Sumber: [`src/cpmm/createCpmmPool.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/createCpmmPool.ts)

```ts
import { PublicKey } from "@solana/web3.js";
import BN from "bn.js";
import { CREATE_CPMM_POOL_PROGRAM, CREATE_CPMM_POOL_FEE_ACC }
  from "@raydium-io/raydium-sdk-v2";
// (Jika Anda memerlukan setiap PDA pool sekaligus, helper yang diekspor adalah `getCreatePoolKeys`.
//  Tidak ada `getCpmmPdas`.)

const mintA = new PublicKey("So11111111111111111111111111111111111111112"); // wSOL
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// 1. Pilih konfigurasi biaya. index=0 adalah tier 0,25%.
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0)!;

// 2. Tarik metadata mint sehingga SDK dapat menangani ekstensi Token-2022.
const mintAInfo = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(mintB);

// 3. Bangun transaksi.
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA:           mintAInfo,
  mintB:           mintBInfo,
  mintAAmount:     new BN(1_000_000_000),   // 1 SOL (asumsikan 9 desimal)
  mintBAmount:     new BN(   160_000_000),  // 160 USDC (pada 160/SOL)
  startTime:       new BN(0),               // buka segera
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Pool dibuat di", extInfo.address.poolId.toBase58());
console.log("Tx:", txId);
```

Beberapa hal yang SDK tangani secara diam-diam:

- Mengurutkan mint ke dalam urutan token0/token1 sebelum menurunkan PDA.
- Membayar `create_pool_fee` sekali ke `poolFeeAccount`.
- Membuat akun token terkait pemanggil jika hilang.
- Memilih program token yang tepat (SPL Token vs Token-2022) per sisi.

Setelah konfirmasi Anda dapat mengambil status pool langsung dengan:

```ts
// getPoolInfoFromRpc mengambil string base58 posisional, bukan PublicKey dan bukan objek.
const { poolKeys, poolInfo, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(
  extInfo.address.poolId.toBase58(),
);
```

## Swap (base-input)

Sumber: [`src/cpmm/swap.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swap.ts)

```ts
import { CurveCalculator, FeeOn } from "@raydium-io/raydium-sdk-v2";

const POOL_ID = "<POOL_ID>";   // string base58

// 1. Muat status pool saat ini langsung dari RPC (bukan dari API).
const { poolInfo, poolKeys, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(POOL_ID);

const inputMint  = poolInfo.mintA.address;                // swap A → B
const amountIn   = new BN(100_000_000);                   // 0,1 SOL
const slippage   = 0.005;                                 // 0,5%

// 2. Kutip secara lokal. CurveCalculator mencerminkan matematika on-chain, termasuk
//    biaya transfer Token-2022 di kedua sisi. Semua delapan argumen diperlukan.
const baseIn = inputMint === poolInfo.mintA.address;
const swapResult = CurveCalculator.swapBaseInput(
  amountIn,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// Field swapResult adalah inputAmount / outputAmount / tradeFee / protocolFee /
// fundFee / creatorFee / newInputVaultAmount / newOutputVaultAmount.
// Tidak ada destinationAmountSwapped atau sourceAmountSwapped.

// 3. Bangun dan kirim. Melewati `slippage` di sini adalah yang menerapkan batas —
//    tidak perlu aritmatika minimum-out manual.
const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: amountIn,
  swapResult,
  slippage,
  baseIn,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Swap tx:", txId);
```

Catatan: SDK **selalu** mengambil ulang status pool dari RPC di dalam `getPoolInfoFromRpc`. Jangan kutip dari `api-v3.raydium.io` untuk transaksi yang akan Anda tandatangani — kutipan yang sudah usang satu blok dapat tergelincir ke `ExceededSlippage` saat waktu pendaratan.

## Swap (base-output)

Sumber: [`src/cpmm/swapBaseOut.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swapBaseOut.ts)

```ts
const amountOutWanted = new BN(15_000_000);        // 15 USDC
const slippage        = 0.005;

const baseIn = false; // false → mintB adalah sisi input
const swapResult = CurveCalculator.swapBaseOutput(
  amountOutWanted,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// swapResult.inputAmount adalah input yang diperlukan; tidak ada sourceAmountSwapped.

const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: new BN(0),   // tidak digunakan saat fixedOut — jumlah berasal dari swapResult
  fixedOut:    true,
  swapResult,               // diperlukan, dan membawa jumlah output target
  baseIn,
  slippage,
  txVersion:   TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

## Deposit likuiditas

Sumber: [`src/cpmm/deposit.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/deposit.ts)

```ts
import { Percent } from "@raydium-io/raydium-sdk-v2";
import Decimal from "decimal.js";

// addLiquidity didorong oleh jumlah INPUT, bukan jumlah LP.
const uiInputAmount = "0.0001";
const inputAmount = new BN(
  new Decimal(uiInputAmount).mul(10 ** poolInfo.mintA.decimals).toFixed(0),
);
const slippage = new Percent(1, 100);   // Percent, bukan angka

const { execute } = await raydium.cpmm.addLiquidity({
  poolInfo,
  poolKeys,
  inputAmount,
  baseIn: true,           // inputAmount didenominasikan dalam mintA
  slippage,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

SDK menurunkan jumlah berpasangan dari cadangan pool saat ini, menaikkan setiap sisi dengan slippage untuk argumen `maximum_*` instruksi, dan membangun pembuatan ATA jika diperlukan. `raydium.cpmm.computePairAmount({ ... })` mengembalikan angka yang sama jika Anda menginginkannya untuk pratinjau UI.

## Kumpulkan biaya protokol/dana/kreator

Sumber: [`src/cpmm/collectCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectCreatorFee.ts), [`src/cpmm/collectAllCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectAllCreatorFee.ts)

Pengumpulan protokol dan dana tetap terkunci otoritas. Biaya kreator memiliki dua jalur: `CollectCreatorFee` yang ditandatangani kreator, dan `CollectCreatorFeePermissionless` aditif, yang dapat dipanggil oleh pembayar apa pun tetapi hanya dapat mentransfer ke ATA kanonik kreator. `0.2.64-alpha` mengirimkan builder tingkat modul untuk kedua jalur kreator:

```ts
// ditandatangani kreator
const { execute } = await raydium.cpmm.collectCreatorFees({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// tanpa izin — pembayar apa pun; hasil masuk ke ATA kanonik kreator
const { execute } = await raydium.cpmm.collectCreatorFeesPermissionless({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// beberapa pool sekaligus, ditandatangani kreator
await raydium.cpmm.collectMultiCreatorFees({ poolInfoList, txVersion: TxVersion.V0 });
```

<Note>
  Dua instruksi kreator memiliki **diskriminator dan tata letak akun yang berbeda** — yang tanpa izin menggantikan posisi penandatangan kreator / `amm_config` dengan `payer` terpisah dan `creator` yang tidak menandatangani. Gunakan builder yang cocok daripada menukar akun secara manual di yang lain.

  Tidak ada builder biaya protokol atau dana dalam SDK (`makeCollectProtocolFeeInstruction` dan `makeCollectFundFeeInstruction` tidak ada di bawah nama apa pun) — itu adalah jalur admin. Builder instruksi tingkat rendah yang *ada* adalah `collectCpFeeInstruction`, `makeCollectCreatorFeeInstruction` dan `collectCreatorFeePermissionlessInInstruction`.
</Note>

Off-chain Anda dapat membaca biaya yang terkumpul langsung dari `PoolState`:

```ts
const pool = await raydium.cpmm.getRpcPoolInfo(POOL_ID);   // string base58
console.log("Biaya protokol terkumpul mintA:", pool.protocolFeesMintA.toString());
console.log("Biaya protokol terkumpul mintB:", pool.protocolFeesMintB.toString());
// Field CpmmPoolInfoLayout adalah protocolFeesMintA/B, fundFeesMintA/B dan
// creatorFeesMintA/B — tidak ada field ...Token0/...Token1.
```

## Skeleton CPI Rust

Jika Anda ingin memanggil CPMM dari program Anchor Anda sendiri — misalnya, vault yang swap atas nama penyetornya — konteks CPI terlihat seperti ini. Urutan akun mengikuti [`products/cpmm/instructions`](/id/products/cpmm/instructions).

```rust
// Cargo.toml — cabang penting: `master` masih menggunakan anchor-lang 0.32.1.
// raydium-cp-swap = { git = "https://github.com/raydium-io/raydium-cp-swap",
//                     branch = "chore/upgrade-anchor", features = ["cpi"] }
// anchor-lang      = "=1.0.2"   // harus cocok dengan apa yang raydium-cp-swap gunakan
// anchor-spl       = "=1.0.2"
//
// Fitur `cpi` diperlukan — modul `raydium_cp_swap::cpi` hanya ada
// di bawahnya. Perhatikan crate ini tidak dapat berbagi program dengan sampel CLMM di
// products/clmm/code-demos, yang menggunakan anchor-lang =0.32.1.

use anchor_lang::prelude::*;
use anchor_spl::token_interface::{TokenAccount, TokenInterface, Mint};
use raydium_cp_swap::cpi::accounts::Swap;
use raydium_cp_swap::cpi;
use raydium_cp_swap::program::RaydiumCpSwap;

#[derive(Accounts)]
pub struct ProxySwap<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,

    /// CHECK: divalidasi oleh program CPMM
    pub authority:     UncheckedAccount<'info>,
    /// CHECK:
    pub amm_config:    UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub pool_state:    UncheckedAccount<'info>,

    #[account(mut)]
    pub input_token_account:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_token_account: InterfaceAccount<'info, TokenAccount>,

    #[account(mut)]
    pub input_vault:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_vault: InterfaceAccount<'info, TokenAccount>,

    pub input_token_program:  Interface<'info, TokenInterface>,
    pub output_token_program: Interface<'info, TokenInterface>,

    pub input_token_mint:  InterfaceAccount<'info, Mint>,
    pub output_token_mint: InterfaceAccount<'info, Mint>,

    #[account(mut)]
    /// CHECK: ring buffer
    pub observation_state: UncheckedAccount<'info>,

    pub cpmm_program: Program<'info, RaydiumCpSwap>,
}

pub fn proxy_swap_base_input(
    ctx: Context<ProxySwap>,
    amount_in: u64,
    minimum_amount_out: u64,
) -> Result<()> {
    let cpi_accounts = Swap {
        payer:                ctx.accounts.payer.to_account_info(),
        authority:            ctx.accounts.authority.to_account_info(),
        amm_config:           ctx.accounts.amm_config.to_account_info(),
        pool_state:           ctx.accounts.pool_state.to_account_info(),
        input_token_account:  ctx.accounts.input_token_account.to_account_info(),
        output_token_account: ctx.accounts.output_token_account.to_account_info(),
        input_vault:          ctx.accounts.input_vault.to_account_info(),
        output_vault:         ctx.accounts.output_vault.to_account_info(),
        input_token_program:  ctx.accounts.input_token_program.to_account_info(),
        output_token_program: ctx.accounts.output_token_program.to_account_info(),
        input_token_mint:     ctx.accounts.input_token_mint.to_account_info(),
        output_token_mint:    ctx.accounts.output_token_mint.to_account_info(),
        observation_state:    ctx.accounts.observation_state.to_account_info(),
    };
    // Anchor 1.0 mengambil Pubkey program di sini, bukan AccountInfo-nya.
    let cpi_ctx = CpiContext::new(
        *ctx.accounts.cpmm_program.key,
        cpi_accounts,
    );
    cpi::swap_base_input(cpi_ctx, amount_in, minimum_amount_out)
}
```

Jika CPI Anda menandatangani sebagai PDA (misalnya, Anda mengelola vault atas nama penyetor), tukar `CpiContext::new` dengan `CpiContext::new_with_signer` dan teruskan seed Anda.

## Jebakan umum

Daftar periksa singkat sebelum membuka tiket dukungan:

- **Mint yang diurutkan.** Jika PDA `poolState` yang Anda turunkan tidak cocok dengan pool on-chain, Anda mungkin lupa mengurutkan mint.
- **Kutipan API usang.** Jangan pernah teruskan nilai cadangan dari `api-v3.raydium.io` ke `CurveCalculator.swap`. Ambil dari RPC.
- **Program token yang salah.** Vault mint Token-2022 dimiliki oleh program Token-2022, bukan oleh SPL Token. Selalu gunakan field `token_0_program` / `token_1_program` pool.
- **Slippage kurang didenominasikan untuk mint biaya transfer.** Jika salah satu sisi pool adalah mint biaya transfer Token-2022, `minimum_amount_out` Anda harus didenominasikan dalam apa yang benar-benar diterima pengguna, bukan dalam apa yang dikirim vault.
- **`NotApproved` pada swap.** Periksa `PoolState.status` — admin mungkin telah menjeda swap di pool itu. Lihat [`products/cpmm/instructions`](/id/products/cpmm/instructions) untuk bitmask status.
