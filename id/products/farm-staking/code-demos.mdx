## Setup

Demo di sini mencerminkan file di [`raydium-sdk-V2-demo/src/farm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/farm). Bootstrap mengikuti [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) repo demo:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Ambil farm berdasarkan id

Tidak ada `raydium.farm.getFarmById`. Setiap demo farm dimulai dari modul API, yang mengembalikan bentuk `FormatFarmInfoOut` yang dinormalisasi yang diambil oleh `deposit` / `withdraw` / `harvestAllRewards`:

```ts
const farmId = "CHYrUBX2RKX8iBg7gYTkccoGNBzP44LdaazMHCLcdEgS"; // RAY-USDC farm

const farmInfo = (await raydium.api.fetchFarmInfoById({ ids: farmId }))[0];
if (!farmInfo) throw new Error("farm not found");

console.log("LP mint:", farmInfo.lpMint.address);
console.log("TVL:", farmInfo.tvl);
for (const r of farmInfo.rewardInfos) {
  console.log("  -", r.mint.address, r.mint.symbol);
}
```

`fetchFarmInfoById` mengambil **string yang dipisahkan koma** dari id dan mengembalikan array, jadi satu panggilan dapat menghidrasi seluruh portfolio. Jika Anda memerlukan kunci akun mentah daripada info tampilan, `raydium.api.fetchFarmKeysById({ ids })` mengembalikan vault dan PDA otoritas; SDK memanggilnya secara internal untuk Anda di dalam setiap builder di bawah.

## Stake token LP

Sumber: [`src/farm/stake.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/stake.ts)

```ts
// Demo melakukan stake seluruh saldo LP dompet; BN apa pun dalam unit mentah berfungsi.
const amount = raydium.account.tokenAccountRawInfos.find(
  (a) => a.accountInfo.mint.toBase58() === farmInfo.lpMint.address,
)?.accountInfo.amount;

if (!amount || amount.isZero()) throw new Error("user does not have an LP balance");

const { execute } = await raydium.farm.deposit({
  farmInfo,
  amount,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Deposit tx:", txId);
```

SDK menangani pre-settle dari reward apa pun yang tertunda, jadi jika dompet ini sudah memiliki stake di farm ini, instruksi akan membayarkan reward yang terakumulasi ke ATA pengguna dalam transaksi yang sama.

## Klaim saja (panen)

Sumber: [`src/farm/harvest.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/harvest.ts)

`farmInfoList` adalah **`Record` yang dikunci berdasarkan id farm**, bukan array, dan builder mengembalikan **beberapa** transaksi — jadi `execute` harus diberikan `sequentially: true`:

```ts
const farmIds = [farmId, "<ANOTHER_FARM_ID>"];
const farmInfos = await raydium.api.fetchFarmInfoById({ ids: farmIds.join(",") });

const { execute } = await raydium.farm.harvestAllRewards({
  farmInfoList: Object.fromEntries(farmInfos.map((f) => [f.id, f])),
  txVersion: TxVersion.V0,
});

const { txIds } = await execute({ sequentially: true });
console.log("harvest txs:", txIds);
```

Builder mengemas sebanyak mungkin farm per transaksi sesuai batas 1232-byte dan membagi sisanya menjadi transaksi lanjutan, itulah mengapa ia mengembalikan `txIds` daripada `txId` tunggal.

Untuk satu farm, panen dengan idiom `amount: 0` — ini adalah apa yang dilakukan [`src/farm/harvest.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/harvest.ts), di setiap versi termasuk v6:

```ts
const { execute } = await raydium.farm.withdraw({
  farmInfo,
  amount: new BN(0),        // 0 = harvest-only path
  txVersion: TxVersion.V0,
});
await execute({ sendAndConfirm: true });
```

## Buat farm v6

Sumber: [`src/farm/createAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/createAmmFarm.ts) dan [`editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts)

`create` mengambil **objek info pool** untuk pool yang mint LP-nya sedang di-stake (bukan mint kosong), dan setiap entri `rewardInfos` adalah `FarmRewardInfo`: `{ mint: PublicKey, perSecond: string, openTime: number, endTime: number, rewardType: "Standard SPL" | "Option tokens" }`. Waktu adalah **detik biasa**, dan `perSecond` adalah **string**, bukan `BN`. `programId` default ke program v6, jadi Anda jarang meneruskannya.

```ts
import type { ApiV3PoolInfoStandardItem, FarmRewardInfo } from "@raydium-io/raydium-sdk-v2";
import { RAYMint } from "@raydium-io/raydium-sdk-v2";

// Pool yang Anda miliki yang mint LP-nya akan menjadi mint staking.
const poolInfo = (
  await raydium.api.fetchPoolById({ ids: "<POOL_ID>" })
)[0] as ApiV3PoolInfoStandardItem;
if (!poolInfo) throw new Error("pool not found");

const rewardMint = await raydium.token.getTokenInfo(RAYMint);

// Gunakan waktu chain, bukan waktu dinding — program memvalidasi terhadap yang pertama.
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);
const endTime  = openTime + 60 * 60 * 24 * 7; // 7 days

const rewardInfos: FarmRewardInfo[] = [
  {
    mint:       new PublicKey(rewardMint.address),
    perSecond:  "1",              // string, in raw units per second
    openTime,                      // seconds, not BN
    endTime,
    rewardType: "Standard SPL",   // "Option tokens" is the only other value
  },
];

const { execute, extInfo } = await raydium.farm.create({
  poolInfo,
  rewardInfos,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Farm:", extInfo.farmId.toBase58(), "createTx:", txId);
```

Poin kunci:

- `perSecond` adalah laju emisi per detik dalam unit **mentah** mint reward, diteruskan sebagai string desimal. SDK mengemas ke representasi fixed-point on-chain sebelum mengirim.
- Anggaran penuh (`perSecond × (endTime − openTime)`) harus ada di ATA reward Anda — `create` memindahkannya ke vault reward secara atomik.
- **Mint reward Token-2022 tidak didukung oleh builder farm SDK** di versi SDK ini; gunakan mint SPL biasa untuk reward.
- Anda dapat menabur hingga 5 reward dalam satu panggilan `create`. Daftar akun tumbuh sebesar `(reward_mint, reward_vault, sender_ata, token_program)` per stream tambahan; tetap sadar akan batas ukuran transaksi 1232-byte. Untuk 4+ reward, buat dengan 1–2 dan gunakan `addNewRewardsToken` dalam transaksi lanjutan.

## Tambahkan aliran reward baru

Tidak ada `raydium.farm.setRewards`. Dua builder yang mengubah reward farm adalah `addNewRewardToken` / `addNewRewardsToken` (menempati slot gratis dengan mint **baru**) dan `restartReward` / `restartRewards` (re-arm slot yang alirannya telah berakhir). Keduanya mengambil objek `FarmRewardInfo` dalam bentuk yang sama persis dengan yang digunakan `create`.

```ts
import { USDCMint } from "@raydium-io/raydium-sdk-v2";

const added = await raydium.token.getTokenInfo(USDCMint);
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);

const { execute } = await raydium.farm.addNewRewardsToken({
  farmInfo,
  newRewardInfos: [
    {
      mint:       new PublicKey(added.address),
      perSecond:  "1",
      openTime,
      endTime:    openTime + 60 * 60 * 24 * 7,
      rewardType: "Standard SPL",
    },
  ],
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Anggaran delta (`perSecond × duration`) ditarik dari ATA pembayar sebagai bagian dari transaksi. Instruksi yang mendasar tidak dapat mempersingkat aliran, tidak dapat menurunkan `per_second` pada aliran aktif, dan tidak dapat mengubah mint reward slot — untuk menukar mint, tunggu `end_time` dan gunakan `addNewRewardsToken` pada slot yang dibebaskan, atau buat farm baru.

<Tip>
  `restartRewards` dan `addNewRewardsToken` masing-masing mengembalikan builder, jadi satu transaksi dapat melakukan keduanya. [`src/farm/editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts) menunjukkan polanya: `editFarmBuilder.builder.addInstruction(addNewRewardBuildData.builder.AllTxData)`, kemudian satu `versionBuild({ txVersion })`.
</Tip>

## Restart aliran yang selesai

Sumber: [`src/farm/editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts)

`restartRewards` mengambil **`newRewardInfos`** (jamak, array); `restartReward` adalah bentuk item tunggal dan mengambil `newRewardInfo`. Bidang mint adalah `mint`, bukan `rewardMint`, dan harus cocok dengan slot yang sudah ada di farm — builder mencari slot berdasarkan mint dan error jika tidak ada.

```ts
import type { FarmRewardInfo } from "@raydium-io/raydium-sdk-v2";

// Re-arm slot reward pertama yang ada di farm.
const existing = await raydium.token.getTokenInfo(farmInfo.rewardInfos[0].mint.address);
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);

const newRewardInfos: FarmRewardInfo[] = [
  {
    mint:       new PublicKey(existing.address),
    perSecond:  "1",
    openTime,
    endTime:    openTime + 60 * 60 * 24 * 14,
    rewardType: "Standard SPL",
  },
];

const { execute } = await raydium.farm.restartRewards({
  farmInfo,
  newRewardInfos,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

`restartRewards` adalah **v6-only** — builder membaca id program farm dan melempar untuk farm v3 / v5. Valid hanya ketika `reward_state == 2` slot target (berakhir); pemanggil harus menjadi `reward_sender` slot. Perhatikan `openTime >= endTime` ditolak sisi klien sebelum RPC apa pun dibuat.

## Rust CPI

<Warning>
  **Tidak ada crate Anchor `raydium_farm_v6`.** Tidak ada crate dengan nama itu di crates.io, program Farm v6 tidak menerbitkan IDL on-chain (baik akun `anchor:idl` warisan maupun entri dalam Program Metadata program), dan tidak ada repositori sumber publik untuknya. Revisi sebelumnya dari halaman ini menunjukkan contoh `raydium_farm_v6::cpi::deposit`; itu tidak dikompilasi terhadap apa pun dan telah dihapus.
</Warning>

Farm v6 terakhir kali di-deploy pada 2024-05-13 dan bukan program Anchor dari sudut pandang integrator. Jika Anda perlu membuat komposisi dengannya dari program on-chain Anda sendiri, buat `Instruction` dengan tangan — turunkan daftar akun dan diskriminator instruksi secara independen (dari layout TypeScript SDK di bawah `raydium-sdk-V2/src/raydium/farm/`, atau dengan mendekode transaksi nyata), dan `invoke_signed` itu. Lihat [`sdk-api/rust-cpi`](/id/sdk-api/rust-cpi#farm-v6) untuk prosedur itu.

Rute mana pun yang Anda ambil, ekor `remaining_accounts` harus cocok dengan slot reward aktif farm 1-untuk-1 (pasangan `reward_vault_i`, `user_reward_ata_i` dalam urutan indeks). Menghilangkan atau salah mengurutkan ini menghasilkan mis-akuntansi senyap — program akan mentransfer jumlah yang salah.

## Jebakan

- **Lupa klaim sebelum withdraw.** Tidak berbahaya — `Withdraw` menyelesaikan reward yang tertunda terlebih dahulu. Tetapi jika UI Anda menunjukkan "klaim" terpisah dari "withdraw", pengguna mungkin berpikir masih ada sesuatu untuk diklaim setelah `Withdraw`. Tidak ada; semuanya yang terakumulasi hingga titik itu telah dibayarkan.
- **`total_staked = 0` selama emisi.** Emisi yang terakumulasi saat tidak ada yang di-stake hilang (formula pembaruan `reward_per_share` membagi dengan 0 dan program melewati pembaruan). Untuk program dengan `open_time` terjadwal, jalankan "seed stake" pada open_time untuk menghindari ini.
- **Biaya transfer Token-2022.** Pada farm v6 dengan mint reward Token-2022, biaya transfer berlaku pada emit (vault → pengguna). Faktorkan ini ke dalam kutipan APR.
- **`per_second` kecil di v5.** Laju `u64` v5 berarti `per_second < 1` unit token per detik (pada mint dengan ≥9 desimal ini sering kali laju yang diinginkan) tidak dapat diekspresikan — laju aliran dibulatkan ke 0 dan farm tidak memancarkan apa pun. Gunakan v6.
