## Setup

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token
```

```ts
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import BN from "bn.js";
import bs58 from "bs58";

const connection = new Connection(clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(bs58.decode(process.env.PRIVATE_KEY!));

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });

// WAJIB sebelum quoting pool Stable apa pun. initLayout() mengambil tabel lookup
// ModelDataInfo on-chain ke dalam raydium.liquidity.stableLayout.
await raydium.liquidity.initLayout();
```

<Warning>
  **`initLayout()` tidak opsional untuk pool Stable.** `liquidity.computeAmountOut` bercabang pada `poolInfo.version`: untuk versi 4 menggunakan formula constant-product, dan untuk yang lain membaca `this.stableLayout.stableModelData` dan menginterpolasi tabel lookup. Cache itu kosong sampai `initLayout()` berjalan, jadi quoting pool v5 tanpanya menghasilkan sampah daripada error. Ini idempoten dan murah — panggil sekali saat startup.

  Pembangun transaksi (*builders*) (`swap`, `addLiquidity`, `removeLiquidity`) tidak membutuhkannya: mereka dispatch pada `pooltype.includes("StablePool")` dan memancarkan instruksi `AmmV5*`, dan batas jumlah yang Anda berikan sudah dihitung.
</Warning>

<Warning>
  **`liquidity.computeAmountIn` tidak mendukung pool Stable.** Tidak seperti `computeAmountOut`, tidak ada cabang versi — selalu menerapkan inverse constant-product, jadi pada pool v5 mengembalikan `maxAmountIn` yang salah. Untuk swap exact-output terhadap pool Stable, balikkan dengan `getDxByDyBaseIn` sendiri (lihat [Helper quote off-chain](#off-chain-quote-helpers-stablets) di bawah) dan berikan hasilnya ke `swap` dengan `fixedSide: "out"`.
</Warning>

## Mengidentifikasi pool Stable

Dua sinyal setara pada `ApiV3PoolInfoStandardItem`:

```ts
const isStable =
  pool.version === 5 ||
  pool.pooltype.includes("StablePool"); // SDK menggunakan pemeriksaan string ini secara internal

// Alternatif, berdasarkan ID program:
const STABLE_AMM_PROGRAM_ID = "5quBtoiQqxF9Jv6KYKctB59NT3gtJD2Y65kdnB1Uev3h";
const isStableByProgram = pool.programId === STABLE_AMM_PROGRAM_ID;
```

Baik AMM v4 (`version: 4`, constant-product) maupun Stable AMM (`version: 5`) mengalir melalui API `LiquidityModule` yang sama pada SDK. Secara internal modul dispatch ke:

- `InstructionType.AmmV4AddLiquidity` / `AmmV4RemoveLiquidity` untuk pool v4
- `InstructionType.AmmV5AddLiquidity` / `AmmV5RemoveLiquidity` untuk pool v5 (Stable)

`programId` pool (dikembalikan dengan kunci pool) memberi tahu SDK program mana yang akan di-CPI; Anda tidak perlu hardcode-nya.

## Temukan pool berdasarkan pasangan mint

```ts
import { PublicKey } from "@solana/web3.js";
import type { ApiV3PoolInfoStandardItem } from "@raydium-io/raydium-sdk-v2";

// Dua mint umum untuk digunakan sebagai contoh
const mintA = new PublicKey("Es9vMFrzaCERmJfrF4H2FYD4KCoNkY11McCe8BenwNYB"); // USDT — lihat reference/program-addresses
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// fetchPoolByMints mengembalikan envelope berpagina: { count, data, hasNextPage }
const res = await raydium.api.fetchPoolByMints({
  mint1: mintA.toBase58(),
  mint2: mintB.toBase58(),
});

const stablePool = res.data.find(
  (p) => p.version === 5 || p.pooltype.includes("StablePool"),
) as ApiV3PoolInfoStandardItem | undefined;

if (!stablePool) {
  throw new Error("Tidak ada pool Stable untuk pasangan mint ini");
}

console.log("ID pool Stable:", stablePool.id);
console.log("ID program pool Stable:", stablePool.programId);
console.log("TVL:", stablePool.tvl);
```

Jika pasangan mint memiliki pool v4 (constant-product) dan pool v5 (stable), respons menyertakan keduanya — pilih yang dibutuhkan alur Anda, atau serahkan ke program [AMM Routing](/id/products/routing) dan biarkan memilih rute terbaik.

## Swap melalui pool Stable

Alur `LiquidityModule.swap` memiliki bentuk yang sama seperti pool v4 — cukup berikan objek pool v5. Dua detail mudah salah: `computeAmountOut` membutuhkan **reserve live** pool yang digabungkan ke info pool (item API saja tidak membawanya), dan `slippage`-nya adalah **angka** biasa, bukan `Percent`:

```ts
import BN from "bn.js";

const amountIn = new BN(1_000_000); // 1 USDT (6 desimal), unit raw

// Reserve live + status. Di mainnet Anda juga bisa mengambil poolKeys dari
// getAmmPoolKeys(poolId) dan reserve dari getRpcPoolInfo(poolId).
const rpcData  = await raydium.liquidity.getRpcPoolInfo(stablePool.id);
const poolKeys = await raydium.liquidity.getAmmPoolKeys(stablePool.id);

const out = raydium.liquidity.computeAmountOut({
  poolInfo: {
    ...stablePool,
    baseReserve:  rpcData.baseReserve,
    quoteReserve: rpcData.quoteReserve,
    status:       rpcData.status.toNumber(),
    version:      5, // 5 = Stable; cabang kurva dipilih pada ini
  },
  amountIn,
  mintIn:  stablePool.mintA.address,
  mintOut: stablePool.mintB.address,
  slippage: 0.005, // angka biasa: 0.005 = 0.5% (rentang 1 ~ 0.0001)
});

// amountOut / minAmountOut adalah BN dalam unit raw, bukan TokenAmount.
console.log("Expected out:", out.amountOut.toString());
console.log("Minimum out:", out.minAmountOut.toString());

// Bangun & tandatangani transaksi swap. `inputMint` diperlukan — tanpanya SDK
// tidak dapat mengetahui sisi pool mana yang Anda jual.
const { transaction, execute } = await raydium.liquidity.swap({
  poolInfo:  stablePool,
  poolKeys,
  amountIn,
  amountOut: out.minAmountOut, // out.amountOut adalah angka pre-slippage
  inputMint: stablePool.mintA.address,
  fixedSide: "in",
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Tx swap Stable:", txId);
```

SDK membaca `programId` pool dari kunci pool dan dispatch ke program Stable AMM. Tidak ada argumen `programId` khusus yang diperlukan.

## Tambah dan hapus likuiditas

`addLiquidity` dan `removeLiquidity` bekerja identik di pool v4 dan v5:

```ts
import { Percent, TokenAmount, toToken } from "@raydium-io/raydium-sdk-v2";
import Decimal from "decimal.js";

const inputAmount = "100"; // 100 USDT, dalam unit manusia — computePairAmount mengambil string desimal

// Hitung jumlah B yang cocok yang diperlukan kurva untuk ukuran A ini.
// Catatan: slippage computePairAmount ADALAH Percent (tidak seperti computeAmountOut).
const r = raydium.liquidity.computePairAmount({
  poolInfo: stablePool,
  amount:   inputAmount,
  baseIn:   true,
  slippage: new Percent(50, 10_000), // 0.5%
});

const { execute } = await raydium.liquidity.addLiquidity({
  poolInfo: stablePool,
  poolKeys,
  amountInA: new TokenAmount(
    toToken(stablePool.mintA),
    new Decimal(inputAmount).mul(10 ** stablePool.mintA.decimals).toFixed(0),
  ),
  amountInB: new TokenAmount(
    toToken(stablePool.mintB),
    new Decimal(r.maxAnotherAmount.toExact()).mul(10 ** stablePool.mintB.decimals).toFixed(0),
  ),
  otherAmountMin: r.minAnotherAmount,
  fixedSide:      "a",
  txVersion:      TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Tx tambah-likuiditas:", txId);
```

Secara internal SDK memancarkan `InstructionType.AmmV5AddLiquidity` karena `pooltype.includes("StablePool")` benar. Alur `removeLiquidity` yang sesuai simetris — berikan `lpAmount` dan jumlah minimum yang akan Anda terima di setiap sisi.

## Helper quote off-chain (stable.ts)

Untuk quoting server-side atau backtesting, SDK mengekspos matematika kurva stabil yang mendasar:

```ts
import {
  getStablePrice,
  getDxByDyBaseIn,
  getDyByDxBaseIn,
} from "@raydium-io/raydium-sdk-v2";

// Anda harus memanggil initLayout() sekali sebelum menggunakan ini (memuat
// PDA `ModelDataInfo` on-chain ke cache StableLayout SDK).
await raydium.liquidity.initLayout();

// initLayout() mengisi instance StableLayout; objek data biasa yang
// tiga helper di bawah harapkan adalah getter `stableModelData`-nya, BUKAN instance.
const modelData = raydium.liquidity.stableLayout.stableModelData;

// Reserve dilewatkan sebagai angka biasa dalam unit manusia (bukan BN, bukan unit raw).
const coinReserve = 1_200_000; // reserve sisi coin pool
const pcReserve   = 1_150_000; // reserve sisi pc pool

// Harga spot pada reserve pool saat ini. Argumen ke-4 adalah `baseCoin`:
// true mengembalikan coin-per-pc, false mengembalikan kebalikannya.
const price = getStablePrice(modelData, coinReserve, pcReserve, true);
console.log("Harga spot:", price);

// Quote: diberikan dx masuk, berapa banyak dy keluar (tidak ada biaya diterapkan di sini)?
const dyOut = getDyByDxBaseIn(modelData, coinReserve, pcReserve, 1_000);

// Quote: diberikan target dy keluar, berapa banyak dx masuk yang diperlukan?
const dxIn  = getDxByDyBaseIn(modelData, coinReserve, pcReserve, 1_000);
```

Ini adalah fungsi murni — tidak ada RPC, tidak ada penandatanganan. `ModelDataInfo` on-chain diambil sekali oleh `initLayout()` dan di-cache di dalam `raydium.liquidity.stableLayout`, dapat dibaca sebagai `.stableModelData`. `initStableModelLayout()` idempoten: hanya re-fetch saat `validDataCount === 0`, jadi memanggil `initLayout()` lagi gratis. Berikan reserve saat ini (`x`, `y`) dan helper menghitung dengan binary-searching tabel lookup dan linear interpolating antara dua baris `DataElement` sekitarnya. Lihat [`products/stable/math`](/id/products/stable/math) untuk algoritma yang mendasar.

## Routing melalui AMM Routing (multi-hop / harga terbaik)

Jika Anda tidak ingin memilih venue sendiri, program [AMM Routing](/id/products/routing) akan mempertimbangkan setiap AMM Raydium (v4 / CPMM / CLMM / Stable) dan routing melalui kombinasi mana pun yang terbaik:

Router adalah pipeline lima-panggilan daripada `swap()` tunggal, dan ditulis sepenuhnya — dengan saran caching yang membuatnya dapat digunakan dalam produksi — pada [`products/routing/code-demos`](/id/products/routing/code-demos). Bentuknya adalah:

```ts
import { Router } from "@raydium-io/raydium-sdk-v2";

const poolData = await raydium.tradeV2.fetchRoutePoolBasicInfo(); // cache ini
const routes   = raydium.tradeV2.getAllRoute({ inputMint: mintA, outputMint: mintB, ...poolData });
const ctx      = await raydium.tradeV2.fetchSwapRoutesData({ routes, inputMint: mintA, outputMint: mintB });
const quotes   = raydium.tradeV2.getAllRouteComputeAmountOut({ /* ...ctx, amount, slippage, ... */ });

const best = quotes[0]; // diurutkan terbaik-pertama
if (!best) throw new Error("tidak ada rute swap yang ditemukan");

// Entri best.poolInfoList membawa `version` — 5 menandai pool Stable dalam jalur.
console.log(best.routeType, best.poolInfoList.map((p) => p.version));

const poolKeys = await raydium.tradeV2.computePoolToPoolKeys({
  pools: best.poolInfoList,
  ammRpcData:  ctx.ammPoolsRpcInfo,
  clmmRpcData: ctx.clmmPoolsRpcInfo,
});

const { execute } = await raydium.tradeV2.swap({
  routeProgram: Router,
  swapInfo:     best,
  swapPoolKeys: poolKeys,
  ownerInfo:    { associatedOnly: true, checkCreateATAOwner: true },
  txVersion:    TxVersion.V0,
});

// tradeV2.swap dapat mengembalikan beberapa transaksi; yang pertama membuat ATA perantara.
const { txIds } = await execute({ sequentially: true });
```

<Warning>
  Tidak ada `raydium.tradeV2.fetchRoutes`, dan `tradeV2.swap` **tidak** menerima `inputMint` / `outputMint` / `slippage` — ia mengambil `swapInfo` yang sudah dihitung dari `getAllRouteComputeAmountOut`. Untuk pool **tunggal** yang diketahui, gunakan pembangun tipe pool itu sendiri (`raydium.liquidity.swap` untuk AMM v4 dan Stable, `raydium.cpmm.swap`, `raydium.clmm.swap`) seperti yang ditunjukkan sebelumnya di halaman ini.
</Warning>

Ini adalah jalur yang direkomendasikan untuk swapper dan agregator produksi — Anda tidak perlu memutuskan secara manual apakah pool Stable ada atau apakah itu venue yang lebih baik hari ini.

## Rekomendasi

1. **Untuk swap end-user**, lebih suka alur routing [`tradeV2`](/id/products/routing). Ini menangani setiap tipe pool Raydium termasuk Stable.
2. **Untuk operasi pool-spesifik** (LP tambah / hapus pada pool Stable yang diketahui), gunakan `LiquidityModule` secara langsung — ia auto-detects pool v5.
3. **Untuk quoting off-chain / analytics**, panggil `getStablePrice` / `getDyByDxBaseIn` / `getDxByDyBaseIn` setelah `initLayout()`. Tidak ada traffic RPC per quote setelah data model di-cache.
4. **Jangan hand-encode instruksi `SwapBaseIn` raw.** [Upgrade 2026-06-22](/id/reference/changelog) menghapus akun OpenBook yang mati, jadi layout swap baru mengambil **9 akun** (layout 18-akun lama masih parse untuk kompatibilitas mundur). `Deposit` sekarang 12 akun (lama 14 kompatibel), `Withdraw` 12 (lama 21/22 kompatibel), dan `WithdrawPnl` 10 dengan **tidak ada** jalur kompatibilitas. Helper pre-built SDK memilih layout dan urutan yang benar untuk Anda; rolling your own error-prone. Lihat [`products/stable/instructions`](/id/products/stable/instructions) untuk tabel akun lengkap.
