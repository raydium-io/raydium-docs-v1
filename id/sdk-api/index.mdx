## Pilih jalur integrasi Anda

Lima jalur untuk dipilih. Jalur yang tepat tergantung pada apa yang memanggil Raydium dan seberapa banyak kontrol yang Anda butuhkan.

| Jalur | Terbaik untuk | Latensi | Logika kustom | Bahasa |
|---|---|---|---|---|
| [Trade API](/id/sdk-api/trade-api) | Backend, bot, Blink — di mana pun Anda ingin tx yang dibangun server | Terendah | Terbatas (rute preset) | Apa pun |
| [TypeScript SDK](/id/sdk-api/typescript-sdk) | Aplikasi Node/TS dan frontend yang membutuhkan akses builder penuh | Sedang | Penuh | TS / JS |
| [Integrasi Python](/id/sdk-api/python-integration) | Backend Python dan pipeline ML | Sedang | Penuh (pembuatan instr manual) | Python |
| [Rust CPI](/id/sdk-api/rust-cpi) | Program komposisi yang memanggil Raydium dari on-chain | N/A (on-chain) | Penuh + dapat dikomposisi | Rust |
| [Anchor IDL](/id/sdk-api/anchor-idl) | Codegen untuk bahasa tanpa dukungan pihak pertama (Go, Kotlin, Swift, ...) | Variabel | Penuh | Apa pun dengan alat codegen Anchor |

Jika Anda tidak yakin: backend dan bot → **Trade API**; frontend dan aplikasi kontrol penuh → **TypeScript SDK**; komposisi on-chain → **Rust CPI**.
