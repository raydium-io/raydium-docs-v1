<Info>
  LaunchLab adalah venue peluncuran pasar utama Raydium. Sebuah proyek menyetor pasokan tokennya ke dalam bonding curve; pembeli melakukan perdagangan terhadap kurva menggunakan SOL (atau quote mint lainnya); ketika ambang kelulusan tercapai, aset kurva bermigrasi secara otomatis ke pool CPMM, dan token menjadi dapat diperdagangkan secara bebas. Halaman ini memandu seluruh alur dari sisi proyek.
</Info>

## Yang Anda butuhkan

- **Token mint** — token yang ingin Anda jual. Harus baru dimint dengan:
  - Pasokan penuh dimint ke dompet Anda (sehingga Anda dapat menyetornya ke kurva).
  - Mint authority dicabut sebelum peluncuran (jika tidak, harga kurva dapat dimanipulasi dengan mint baru).
- **Metadata** — nama, simbol, gambar, tautan media sosial. Metadata Metaplex atau serupa.
- **Dompet** — ~1 SOL untuk biaya pembuatan + pendanaan vault + biaya prioritas (kelulusan itu sendiri dibayar oleh pihak yang meluluskan, bukan Anda).
- **Keputusan tentang**:
  - Jenis kurva (kuadratik vs virtual-reserves CPMM).
  - Ambang kelulusan.
  - Kebijakan pembuangan LP (Burn / Lock / ToCreator).
  - Harga awal dan cap.

## Pemilihan kurva

LaunchLab mendukung dua keluarga kurva:

### Kuadratik (`curve_type = 0`)

Harga tumbuh secara kuadratik dengan pasokan yang terjual. Nuansa "fair launch" klasik — pembeli awal mendapat keuntungan harga, pembeli akhir membayar lebih, harga meningkat dengan mulus.

```
price(s) = a * s^2 + b * s + c
```

di mana `s` adalah pasokan yang terjual. Biasanya `a > 0` (cembung). Penyebaran antara harga awal dan kelulusan bersifat deterministik mengingat `a, b, c` dan cap.

Terbaik untuk: peluncuran novelti, meme, proyek yang didorong komunitas.

### Virtual-reserves CPMM (`curve_type = 1`)

Meniru AMM constant-product menggunakan reserve *virtual* — kurva berperilaku seperti CPMM dengan `x * y = k` tetapi pool dimulai dengan token sintetis yang tidak pernah ditarik.

```
price = virtual_quote_reserve / virtual_base_reserve
```

Saat pembeli membeli, `virtual_base_reserve` berkurang dan `virtual_quote_reserve` meningkat — kurva terlihat identik dengan apa yang akan dilihat CPMM pasca-kelulusan. Transisi lebih mulus.

Terbaik untuk: peluncuran yang menginginkan kontinuitas harga pasca-kelulusan yang dapat diprediksi.

## Panduan UI

Di [raydium.io/launchpad/create](https://raydium.io/launchpad/create):

1. **Token.** Tempel alamat mint. UI mengambil metadata dan menampilkannya.
2. **Jenis kurva.** Pilih kuadratik atau virtual-CPMM; UI menampilkan pratinjau bagan harga untuk masing-masing.
3. **Ambang kelulusan.** Default: kurva berakhir setelah semua `total_base_supply` telah terjual. Alternatif: berakhir pada `graduation_quote_amount` tertentu (misalnya 85 SOL).
4. **Quote mint.** SOL (default), USDC, atau mint lainnya. SOL adalah standar.
5. **Kebijakan pembuangan LP:**
   - **Burn** — Token LP dikirim ke alamat yang tidak dapat digunakan saat kelulusan. Kreator tidak dapat menarik likuiditas; pengguna mempercayai pool selamanya.
   - **Lock** — Token LP dikirim ke escrow terkunci waktu untuk `lock_duration`.
   - **ToCreator** — Token LP dikirim ke kreator. Paling fleksibel, paling sedikit meminimalkan kepercayaan.

   Peluncuran paling dihormati menggunakan Burn.

6. **Tinjau.** UI merangkum: rentang harga yang diharapkan, kenaikan awal jika kurva terjual habis, konfigurasi CPMM kelulusan.
7. **Tanda tangani.** Satu transaksi membuat status peluncuran + base vault + quote vault, mentransfer `total_base_supply` dari dompet Anda ke base vault.

## Panduan pemrograman

Bentuk kurva, quote mint, target kenaikan, dan kebijakan pembuangan LP **bukan** argumen — mereka berasal dari `GlobalConfig` yang Anda ikat dan dari `PlatformConfig` yang peluncuran Anda jalankan. Yang Anda berikan adalah identitas mint, config untuk mengikat, dan secara opsional pembelian pertama:

```ts
import {
  Raydium,
  TxVersion,
  LAUNCHPAD_PROGRAM,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";
import BN from "bn.js";

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });
const programId = LAUNCHPAD_PROGRAM;

// Anda membuat keypair base mint dan menandatangani dengannya.
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// Ikat config: (quote mint, curve_type, index). Ini adalah yang memperbaiki bentuk kurva,
// quote mint dan target kenaikan.
const configId   = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
const configInfo = LaunchpadConfig.decode(configData!.data);
const mintBInfo  = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "My New Token",
  symbol: "MYNEW",                    // 10 karakter atau lebih sedikit
  uri:    "https://example.com/metadata.json",
  migrateType: "amm",                 // "amm" | "cpmm"

  configId,
  configInfo,
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  createOnly: true,                   // true = buat mint tanpa pembelian pertama
  buyAmount:  new BN(1000),
  slippage:   new BN(100),            // 100 = 1%

  extraSigners: [pair],               // keypair base-mint harus menandatangani
  txVersion: TxVersion.V0,
  computeBudgetConfig: { units: 400_000, microLamports: 50_000 },
});

// createLaunchpad mengembalikan beberapa transaksi - jalankan secara berurutan.
const { txIds } = await execute({ sequentially: true });
console.log("Pool ID:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
```

`raydium.api.fetchLaunchConfigs()` mencantumkan config yang tersedia dengan pasokan default, jumlah penjualan, dan target kenaikan mereka, sehingga Anda dapat menunjukkan kepada pengguna apa yang diimplikasikan config tertentu sebelum mereka menandatangani. Versi lengkap dengan anotasi, termasuk varian Token-2022: [`products/launchlab/code-demos`](/id/products/launchlab/code-demos#create-a-launch).

## Pemantauan pra-kelulusan

Lacak aktivitas melalui API:

LaunchLab memiliki host API-nya sendiri, terpisah dari `api-v3.raydium.io`:

```ts
// Info tingkat mint, diindeks berdasarkan base mint (dipisahkan koma untuk batch).
const r = await fetch(
  `https://launch-mint-v1.raydium.io/get/by/mints?ids=${mintA.toBase58()}`,
).then((r) => r.json());
console.log(r.data.rows[0]);

// Juga tersedia: /main/configs (daftar config) di host yang sama, dan
// https://launch-history-v1.raydium.io/kline dan /trade untuk harga dan pengisian.
```

Atau baca status on-chain secara langsung. ID pool adalah PDA dari `(programId, mintA, mintB)`:

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log({
  status:      poolInfo.status,
  baseSold:    poolInfo.realA.toString(),
  totalSellA:  poolInfo.totalSellA.toString(),
  quoteRaised: poolInfo.realB.toString(),
  raiseTarget: poolInfo.totalFundRaisingB.toString(),
});
```

Kemajuan paling baik diekspresikan dalam istilah **harga** daripada sebagai fraksi dari kenaikan, karena kurva bersifat non-linear. Repo demo [`getFinishRate.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/getFinishRate.ts) melakukannya dengan `Curve.getPrice`, `Curve.getPoolEndPriceReal` dan `Curve.getPoolInitPriceByPool`:

```
finishRate = (currentPrice − initPrice) / (endPrice − initPrice)   // diklem ke 1
```

### Metrik untuk dipantau

- **Tingkat penjualan**: persentase base yang terjual. Ambang kelulusan biasanya pada 80–100% terjual.
- **Harga saat ini**: berasal dari kurva pada `baseSold` saat ini.
- **Pembeli unik**: jumlah pembayar berbeda melalui indexer.
- **Rasio beli-vs-jual**: peluncuran awal melihat tekanan beli berat yang melambat.

Jika penjualan adalah `<10%` setelah 24 jam, pertimbangkan apakah pemasaran memadai. LaunchLab tidak menyelamatkan peluncuran yang kurang dipublikasikan.

## Kelulusan

Kelulusan adalah transaksi terpisah, dan **tidak** dapat dipanggil oleh siapa pun: `MigrateToCpswap` dan `MigrateToAmm` warisan masing-masing memerlukan penandatangan mereka agar sesuai dengan dompet yang dicatat pada `GlobalConfig` pengikatan (`migrate_to_cpswap_wallet` / `migrate_to_amm_wallet`), dan penandatangan lainnya mendapat `InvalidOwner`. Tidak ada hadiah. Dompet tersebut dijalankan oleh crank kelulusan Raydium, yang mendarat migrasi dalam hitungan detik setelah ambang tercapai. Tidak ada tindakan yang diperlukan dari Anda sebagai kreator di luar pengaturan awal.

### Apa yang dilakukan kelulusan

1. Membaca saldo vault.
2. Menutup kurva (tidak ada lagi pembelian/penjualan terhadapnya).
3. Membuat pool CPMM baru dengan saldo vault sebagai likuiditas awal.
4. Mencetak token LP awal berdasarkan saldo vault.
5. Membuang token LP sesuai kebijakan yang dikonfigurasi (Burn / Lock / ToCreator).

Setelah kelulusan, pool CPMM aktif dan berdagang melalui routing Raydium normal.

### Pemantauan untuk kelulusan

Tonton `status` pada status pool dan alihkan UI Anda saat berubah:

```ts
const before = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

setInterval(async () => {
  const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
  if (p.status !== before) console.log("migrated - switch to the CPMM pool page");
}, 10_000);
```

Alamat pool yang telah lulus adalah PDA CPMM untuk `(cpswap config, token0, token1)`, sehingga Anda dapat menurunkannya daripada menunggu untuk dilaporkan. Untuk indexer, berlangganan melalui gRPC daripada polling — lihat [`products/launchlab/code-demos`](/id/products/launchlab/code-demos#watch-configs-and-pools-over-grpc).

Tidak ada jalur "kelulusan manual" untuk kreator atau pihak ketiga. Jika peluncuran telah melampaui ambangnya dan belum bermigrasi, itu adalah masalah operasional untuk dompet migrasi, bukan sesuatu yang dapat Anda paksa dari klien.

## Pasca-kelulusan

### Verifikasi pool CPMM

```ts
const pool = await raydium.cpmm.getPoolInfoFromRpc({ poolId: cpmmPoolId });
console.log("CPMM price:", pool.poolInfo.price);
console.log("CPMM TVL:  ", pool.poolInfo.tvl);
```

Pool CPMM harus memiliki (kira-kira):

- Saldo token base: `total_base_supply - baseSold` + sisa kurva.
- Saldo token quote: `quoteRaised - graduationFee`.
- Harga: cocok dengan harga kurva terakhir.

### Verifikasi pembuangan LP

- **Burn**: Pasokan mint LP menunjukkan dikirim ke 1nc1nerator11111111111111111111111111111111 atau serupa.
- **Lock**: Token LP di PDA escrow dengan stempel waktu pembukaan.
- **ToCreator**: Token LP di dompet kreator.

### Kumpulkan biaya kreator

Jika Anda mengonfigurasi bagian biaya kreator, panggil secara berkala:

Builder adalah `claimCreatorFee`, dan diindeks berdasarkan **quote mint** daripada peluncuran — satu panggilan menyapu biaya kreator terakumulasi Anda dalam mint itu:

```ts
import { NATIVE_MINT } from "@solana/spl-token";

await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,      // quote mint untuk diklaim
  txVersion: TxVersion.V0,
});
```

Gunakan `claimMultipleCreatorFee` untuk batch di seluruh mint. Biaya terakumulasi dari perdagangan kurva pra-kelulusan, dan pasca-kelulusan dari jalur biaya kreator pool CPMM ketika `platform_cp_creator` platform meninggalkan Anda sebagai kreator pool yang dicatat — lihat [`products/launchlab/platform-config`](/id/products/launchlab/platform-config).

## Daftar periksa pengumuman

Pengumuman pasca-kelulusan harus mencakup:

- [ ] Hash transaksi kelulusan.
- [ ] ID pool CPMM baru.
- [ ] Bukti pembuangan LP (burn tx / lock tx / dompet kreator).
- [ ] ETA cakupan aggregator (dompet biasanya mengindeks dalam 5 menit).
- [ ] Verifikasi kontrak token (cocokkan alamat mint di seluruh saluran pengumuman).

## Jebakan

### 1. Mint authority tidak dicabut

Jika `baseMint.mintAuthority` masih merupakan kunci yang Anda kontrol, Anda dapat mencetak pasokan baru dan menjual ke kurva Anda sendiri. Peluncuran yang belum mencabut umumnya ditandai sebagai berisiko tinggi atau tidak terverifikasi oleh aggregator dan situs listing. Cabut sebelum meluncurkan.

### 2. Parameter kurva salah

Kurva kuadratik dengan `a` terlalu tinggi membuat token awal gratis (harga ≈ 0) dan token kemudian absurd. Kurva dengan `a` terlalu rendah membuat kurva hampir linear (kehilangan nuansa "bonding"). Uji parameter di devnet terlebih dahulu.

### 3. Ambang kelulusan terlalu tinggi

Jika kelulusan memerlukan lebih banyak modal daripada permintaan realistis, kurva tidak pernah lulus dan pembeli terjebak dengan token yang hanya dapat mereka jual kembali ke kurva (dengan harga lebih buruk). Pilih ambang yang benar-benar dapat Anda capai.

### 4. Scam quote mint

Jika quote mint Anda adalah token khusus (bukan SOL/USDC), pengguna tidak akan mempercayainya. Tetap gunakan SOL atau USDC untuk quote.

### 5. Lupa mendanai base vault

SDK mentransfer `totalBaseSupply` dari dompet Anda saat pembuatan. Jika dompet Anda tidak memilikinya, tx akan kembali. Konfirmasi saldo sebelum menandatangani.

### 6. Pembuangan LP = Burn tidak dapat dibalikkan

Setelah LP dikirim ke 1nc1nerator, tidak ada yang dapat menarik likuiditas, *termasuk Anda*. Ini adalah intinya — meminimalkan kepercayaan. Jangan pilih Burn jika Anda tidak yakin.

### 7. Tingkat biaya CPMM pasca-kelulusan

Pool yang telah lulus menggunakan config CPMM default LaunchLab (0,25%). Jika Anda menginginkan 1% atau 0,01%, Anda perlu membuat pool CPMM kedua sendiri pasca-kelulusan dan bermigrasi likuiditas — canggung, dan memecah. Terima default, atau luncurkan melalui pembuatan CPMM langsung daripada LaunchLab.
