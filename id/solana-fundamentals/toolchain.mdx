## Alat inti

### Solana CLI

Antarmuka baris perintah kanonik untuk berinteraksi dengan cluster Solana — manajemen wallet, panggilan RPC, deployment program.

Instalasi:

```bash
# Versi yang digunakan program Raydium untuk dibangun dan diuji
sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.10/install)"

# Atau ikuti channel daripada tag
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

Verifikasi:

```bash
solana --version   # → solana-cli 3.1.10 (... client:Agave)
```

<Note>
  **Host instalasi telah pindah.** `release.solana.com` milik Solana Labs; klien sekarang dikelola oleh Anza sebagai **Agave**, dan rilis disajikan dari `release.anza.xyz`. Binary self-update adalah `agave-install` (`solana-install` dipertahankan sebagai alias legacy), jadi `agave-install update` dan `agave-install init <version>` adalah ejaan saat ini. Dokumen Solana sendiri juga menawarkan installer satu perintah yang menarik CLI, Rust, dan Anchor bersama-sama:

  ```bash
  curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
  ```

  Installer itu melacak ide sendiri tentang versi terkini dan mungkin memberi Anda Anchor yang berbeda dari yang di-pin program Raydium — periksa `anchor --version` setelahnya.
</Note>

Konfigurasi untuk mainnet:

```bash
solana config set --url https://api.mainnet-beta.solana.com
solana config set --keypair ~/.config/solana/id.json
solana-keygen new                           # buat wallet jika Anda belum memilikinya
solana address                              # kunci publik Anda
```

Untuk pengujian Raydium, Anda hampir selalu menginginkan wallet devnet yang didanai:

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2                            # 2 SOL untuk pengujian
```

### SPL Token CLI

CLI resmi untuk operasi SPL Token / Token-2022 — membuat mint, minting token, transfer.

Instalasi (disertakan dengan Solana CLI):

```bash
spl-token --version
```

Operasi umum:

```bash
spl-token create-token                                  # buat mint SPL Token
spl-token create-token --program-id TOKEN_2022 ...      # buat mint Token-2022
spl-token create-account <MINT>                         # buat ATA
spl-token mint <MINT> 1000                              # mint 1000 token ke ATA Anda
spl-token transfer <MINT> 100 <RECIPIENT>               # transfer 100
spl-token display <ACCOUNT_OR_MINT>                     # inspeksi
```

### Anchor CLI

Diperlukan untuk mengambil IDL Raydium, membangun klien, dan memverifikasi program.

Instalasi:

```bash
cargo install --git https://github.com/solana-foundation/anchor avm --locked --force
avm install 1.0.2
avm use 1.0.2
anchor --version   # → anchor-cli 1.0.2
```

<Note>
  **Anchor pindah repository dan major version.** Repo kanonik sekarang `github.com/solana-foundation/anchor` (sebelumnya `coral-xyz/anchor`), dan Anchor 1.0 adalah baris rilis pertama yang digunakan program Raydium — CPMM dan LaunchLab keduanya pin `anchor-lang`/`anchor-spl` `=1.0.2` per upgrade 2026-09-09, naik dari `0.32.1`. `avm` dapat menampung beberapa versi; `avm use 1.0.2` adalah yang membuat `anchor build` mereproduksi artifact Raydium. Anchor 1.1 dan 1.2 ada dan membangun dengan baik untuk program Anda sendiri, tetapi crate CPI yang dikompilasi terhadap `anchor-lang` minor yang berbeda dari yang di-pin program target tidak akan link — lihat [`sdk-api/rust-cpi`](/id/sdk-api/rust-cpi).
</Note>

Operasi umum:

```bash
anchor idl fetch <PROGRAM_ID> -o program.idl.json       # ambil IDL on-chain
anchor idl init -f idl.json <PROGRAM_ID>                # upload IDL
anchor build                                             # bangun program dari sumber
```

## Setup TypeScript

Jalur integrasi utama untuk Raydium.

### Paket

```bash
npm install \
  @solana/web3.js \
  @solana/spl-token \
  @anchor-lang/core \
  @raydium-io/raydium-sdk-v2 \
  bn.js \
  decimal.js
```

Versi yang diketahui bekerja bersama per September 2026:

| Paket | Versi | Catatan |
|---------|---------|------|
| `@solana/web3.js` | `^1.95` | API 1.x. `2.x` / `3.x` adalah permukaan API yang berbeda dan tidak kompatibel; SDK Raydium menargetkan 1.x. |
| `@solana/spl-token` | `^0.4.15` | 0.4.15 adalah yang mengekspos `createUnwrapLamportsInstruction` — lihat [reclaimable rent](/id/solana-fundamentals/rent-and-reclaimable-rent). |
| `@anchor-lang/core` | `^1.0` | Klien TypeScript Anchor 1.x. |
| `@raydium-io/raydium-sdk-v2` | `0.2.64-alpha` | Pin yang digunakan setiap demo kode dalam dokumentasi ini. |

<Note>
  **`@anchor-lang/core` beku; paket sekarang `@anchor-lang/core`.** `@anchor-lang/core` berhenti di `0.32.1` ketika Anchor pindah ke Solana Foundation. Anchor 1.x menerbitkan sebagai `@anchor-lang/core`, dan repository program Raydium sendiri mengganti test suite mereka ke dalamnya di upgrade 2026-09-09. Import yang sebenarnya Anda gunakan tidak berubah — `import { Program, BN, AnchorProvider } from "@anchor-lang/core"` — jadi migrasi adalah rename paket plus update lockfile.

  Dua catatan perilaku jika Anda pindah dari `0.3x`: `.accounts({...})` sekarang hanya menerima akun yang tidak dapat diselesaikan Anchor sendiri, jadi builder yang melewatkan set lengkap harus memanggil `.accountsPartial({...})` sebagai gantinya; dan `@anchor-lang/core/dist/cjs/utils/token` adalah tempat helper seperti `ASSOCIATED_PROGRAM_ID` pindah.
</Note>

### Skrip minimal

```ts
import { Connection, Keypair } from "@solana/web3.js";
import { Raydium } from "@raydium-io/raydium-sdk-v2";

const connection = new Connection("https://api.mainnet-beta.solana.com", "confirmed");
const owner      = Keypair.fromSecretKey(/* kunci Anda */);

const raydium = await Raydium.load({
  connection,
  owner,
  cluster:      "mainnet",
  disableFeatureCheck: true,
});

// `ids` adalah daftar yang dipisahkan koma, dan panggilan mengembalikan array
const [poolInfo] = await raydium.api.fetchPoolById({ ids: "..." });
console.log(poolInfo);
```

Lihat [`sdk-api/typescript-sdk`](/id/sdk-api/typescript-sdk) untuk referensi SDK lengkap.

## Setup Rust

Untuk integrasi CPI dan program on-chain.

### Toolchain

```bash
rustup install 1.91.0           # apa yang di-pin program Raydium
rustup default 1.91.0
rustup component add rustfmt clippy
agave-install init 3.1.10       # SBF toolchain disertakan
```

Bangun program dengan `cargo build-sbf` (ejaan lama `cargo build-bpf` sudah hilang).

### Program Cargo.toml untuk integrasi Raydium CPI

```toml
# Integrasi CPMM (Anchor 1.0)
[dependencies]
anchor-lang        = "=1.0.2"
anchor-spl         = "=1.0.2"
raydium-cp-swap    = { version = "0.2", features = ["cpi"] }
```

```toml
# Integrasi CLMM — masih Anchor 0.32, jadi memerlukan crate sendiri
[dependencies]
anchor-lang        = "=0.32.1"
anchor-spl         = "=0.32.1"
raydium-clmm       = { version = "0.1", features = ["cpi"] }
```

Pin `anchor-lang` dan `anchor-spl` dengan `=` ke versi yang di-pin program target. Per 2026-09 CPMM pin `=1.0.2` dan CLMM masih pin `=0.32.1`, jadi **satu crate tidak dapat CPI ke keduanya** — lihat [`sdk-api/rust-cpi`](/id/sdk-api/rust-cpi#cargo-dependencies).

Fitur `"cpi"` mengimpor modul `cpi` dengan helper CPI (jadi Anda dapat `raydium_cp_swap::cpi::swap_base_input(...)`). Lihat [`sdk-api/rust-cpi`](/id/sdk-api/rust-cpi).

## Setup Python

Jalur integrasi sekunder — umum untuk pengembang bot.

### Paket

```bash
pip install solders solana anchorpy
```

Versi:

| Paket | Nama PyPI | Versi |
|---------|-----------|---------|
| `solders` | `solders` | ≥0.29 |
| solana-py | `solana` | ≥0.40 |
| `anchorpy` | `anchorpy` | ≥0.21 |

<Note>
  Dua jebakan penamaan. Klien RPC diimpor sebagai `solana` tetapi proyek disebut **solana-py** — `pip install solana-py` tidak menginstal apa pun yang berguna. Dan tidak ada **paket `raydium-py` di PyPI**: helper Raydium komunitas adalah repository yang Anda clone, [`AL-THE-BOT-FATHER/raydium_py`](https://github.com/AL-THE-BOT-FATHER/raydium_py), bukan distribusi yang diterbitkan. Revisi sebelumnya dari halaman ini mencantumkan baris `pip install raydium-py` yang tidak pernah bekerja.
</Note>

### Skrip minimal

```python
from solana.rpc.async_api import AsyncClient
from solders.keypair import Keypair
from anchorpy import Provider, Wallet, Program

async def main():
    conn = AsyncClient("https://api.mainnet-beta.solana.com")
    owner = Keypair()
    wallet = Wallet(owner)
    provider = Provider(conn, wallet)

    # Muat IDL dan program
    with open("cpmm.idl.json") as f:
        idl = json.load(f)
    program = Program(idl, CPMM_PROGRAM_ID, provider)

    pool = await program.account["PoolState"].fetch(pool_id)
    print(pool)
```

## Endpoint RPC

Mainnet RPC publik (`api.mainnet-beta.solana.com`) sangat dibatasi rate dan throttle di bawah beban apa pun. Untuk penggunaan non-trivial, dapatkan endpoint privat:

| Penyedia | Catatan |
|----------|-------|
| Helius | Paling populer; tier gratis yang murah hati. |
| Triton | Enterprise; harga premium, stabil. |
| QuickNode | Solid; latensi sub-per-detik. |
| Node RPC Anda sendiri | Biaya ~\$500/bulan dalam hardware; kontrol penuh. |

Konfigurasi:

```ts
const connection = new Connection("https://mainnet.helius-rpc.com/?api-key=...");
```

Beberapa operasi RPC memerlukan kemampuan yang diperluas:

- `getProgramAccounts` — scan tanpa batasan mahal; beberapa penyedia membatasi atau mengenakan biaya per scan.
- `getPriorityFeeEstimate` — endpoint spesifik Helius; yang lain memiliki setara.
- `geyser` / WebSocket streaming — diperlukan untuk bot latensi rendah; tidak semua penyedia mengeksposnya.

## Devnet dan localnet

### Devnet

Cluster test publik Solana. Raydium memiliki deployment devnet parsial:

- Beberapa pool CPMM ada untuk pengujian.
- AMM v4 memiliki pool devnet historis.
- CLMM memiliki beberapa pool demo.
- Farm v6 di-deploy.

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2
```

SDK mendukung devnet melalui `cluster: "devnet"`:

```ts
const raydium = await Raydium.load({ connection, owner, cluster: "devnet" });
```

**Caveat**: pool devnet memiliki likuiditas tipis dan mungkin memiliki state basi. Jangan andalkan devnet untuk price discovery; gunakan hanya untuk membangun-dan-menguji alur instruksi.

### Localnet dengan state mainnet yang di-fork

Untuk pengujian realistis, fork state mainnet ke validator lokal:

```bash
solana-test-validator \
  --url https://api.mainnet-beta.solana.com \
  --clone CPMMoo8L3F4NbTegBCKVNunggL7H1ZpdTHKxQB5qKP1C \
  --clone CAMMCzo5YL8w4VFF8KVHrK22GGUsp5VTaW7grrKgrWqK \
  --clone <SOME_POOL_ID> \
  --clone <SOME_MINT_ID>
```

Ini mengkloning state program/akun spesifik ke localhost, di mana Anda dapat bertransaksi dengan bebas. Ideal untuk:

- Unit-testing integrasi CPI Anda terhadap program Raydium nyata.
- Memutar ulang transaksi dengan parameter yang dimodifikasi untuk debug.
- Stress-testing dengan volume sintetis besar.

Tim Raydium menggunakan localnet yang di-fork secara ekstensif untuk regression testing sebelum deployment mainnet.

## Template proyek

### Starter integrasi TypeScript

```
my-raydium-app/
├── package.json
├── tsconfig.json
├── src/
│   ├── swap.ts           # contoh swap
│   ├── add-liquidity.ts
│   └── read-pool.ts
└── .env                  # RPC URL, jalur wallet
```

`package.json` minimal:

```json
{
  "name": "my-raydium-app",
  "type": "module",
  "scripts": { "swap": "tsx src/swap.ts" },
  "dependencies": {
    "@raydium-io/raydium-sdk-v2": "0.2.64-alpha",
    "@solana/web3.js": "^1.95",
    "@solana/spl-token": "^0.4.15"
  },
  "devDependencies": {
    "@types/node": "^20",
    "tsx": "^4",
    "typescript": "^5"
  }
}
```

### Starter program Anchor CPI

```
my-raydium-cpi/
├── Anchor.toml
├── Cargo.toml
├── programs/
│   └── my-cpi/
│       ├── Cargo.toml
│       └── src/lib.rs
└── tests/
    └── my-cpi.ts
```

Dengan Anchor 1.0:

```bash
anchor init my-raydium-cpi
cd my-raydium-cpi
# tambahkan raydium-cp-swap ke Cargo.toml dengan features = ["cpi"]
anchor build
anchor test
```

## Kebersihan lingkungan

### Wallet terpisah per tujuan

- **Wallet pengembangan**: memegang testnet SOL, digunakan untuk membangun.
- **Wallet produksi**: memegang SOL nyata, digunakan hanya untuk deploy / pengajuan multisig.
- **Hot wallet untuk bot**: saldo kecil, izin sempit.

Kunci tidak boleh hardcoded. Gunakan variabel lingkungan atau secret manager.

### Pola `.env`

```
# .env (tidak di-commit)
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=...
WALLET_PATH=/Users/you/.config/solana/id.json
```

```ts
import { config } from "dotenv";
config();

const connection = new Connection(process.env.SOLANA_RPC_URL!);
```

### Pinning versi

Kunci semua dependensi ekosistem Solana. Ekosistem bergerak cepat; bump versi minor `@solana/web3.js` sebelumnya telah memperkenalkan breaking change. Gunakan `package-lock.json` / `Cargo.lock` dengan religius.
