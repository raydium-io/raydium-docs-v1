## Mendeteksi posisi Raydium

### Token LP klasik (CPMM, AMM v4)

Token ini terlihat seperti SPL Token lainnya: ATA pengguna memegang saldo. Dompet menampilkan ini sebagai token lain secara default. Untuk mengungkapnya sebagai posisi LP Raydium:

1. Enumerasi akun token pengguna: `connection.getParsedTokenAccountsByOwner(user, { programId: TOKEN_PROGRAM_ID })`.
2. Untuk setiap mint, periksa daftar mint Raydium: `GET https://api-v3.raydium.io/pools/info/lps?lps=<LP_MINT>,...` (batch hingga ~50 LP mint per panggilan).
3. Untuk mint yang cocok, API mengembalikan referensi pool. Gunakan untuk menghitung nilai posisi yang dinyatakan dalam token:

```
token_a_owned = user_lp_balance * poolReserves.A / lpMint.supply
token_b_owned = user_lp_balance * poolReserves.B / lpMint.supply
usd_value     = token_a_owned * priceA_usd + token_b_owned * priceB_usd
```

Tampilkan baik saldo LP maupun jumlah yang dibuka — pengguna berpikir dalam token dasar, bukan unit LP.

### NFT posisi CLMM

Posisi CLMM adalah NFT. PDA `PersonalPositionState` setiap posisi diturunkan dari mint NFT. Untuk mendeteksi:

1. Enumerasi NFT pengguna. Untuk NFT Metaplex warisan: filter akun token ke yang memiliki supply 1 dan desimal 0.
2. Untuk setiap mint NFT, coba turunkan PDA PersonalPositionState:

```ts
import { CLMM_PROGRAM_ID } from "@raydium-io/raydium-sdk-v2";

const [positionPda] = PublicKey.findProgramAddressSync(
  [Buffer.from("position"), nftMint.toBuffer()],
  CLMM_PROGRAM_ID,
);

const accountInfo = await connection.getAccountInfo(positionPda);
if (!accountInfo || !accountInfo.owner.equals(CLMM_PROGRAM_ID)) return null;
// Ini adalah posisi CLMM Raydium — dekode.
```

3. Enumerasi posisi dompet dengan `raydium.clmm.getOwnerPositionInfo({ programId })` dan cocokkan pada `nftMint` (tidak ada `getPositionInfo`). Setiap entri memberi Anda:
   - `poolId` → ambil pool untuk menyelesaikan mint
   - `tickLower`, `tickUpper` → tampilkan rentang
   - `liquidity`, `tokensOwedA/B` → hitung nilai posisi + biaya yang tertunda
   - `rewardInfos` → reward per-stream yang tertunda

4. Untuk NFT posisi yang dikeluarkan di bawah Token-2022 (`OpenPositionWithToken22Nft`), program mint NFT adalah Token-2022 bukan SPL Token. Enumerasi keduanya saat memindai.

### Taruhan farm

Farm v3 / v5 / v6 masing-masing memiliki PDA ledger per-pengguna. Penurunan:

```ts
// Coba ketiga versi farm untuk setiap interaksi farm potensial pengguna.
// Pendekatan termurah: tanya API terlebih dahulu, yang telah mengindeks semua posisi pengguna.

const r = await fetch(
  `https://api-v3.raydium.io/positions/staking?wallet=${user.toBase58()}`
).then(r => r.json());

for (const s of r.data.stakings) {
  // s.farmId, s.stakedAmount, s.pendingRewards[], s.poolApr, ...
}
```

Untuk dompet yang lebih suka deteksi sepenuhnya on-chain: iterasi PDA `UserLedger` yang mungkin dengan hash pengguna dengan daftar farm ID yang dikurasi "kemungkinan". Menumerasi semua farm ID secara lengkap tidak praktis (ribuan ada); gunakan API.

## Menghitung nilai posisi

### LP CPMM / AMM v4

Ketiga modul **tidak** berbagi tanda tangan: `liquidity.getPoolInfoFromRpc` mengambil `{ poolId }`, sementara `cpmm.getPoolInfoFromRpc` dan `clmm.getPoolInfoFromRpc` mengambil string base58 posisional.

```ts
// AMM v4
const { poolInfo, poolRpcData } = await raydium.liquidity.getPoolInfoFromRpc({ poolId: POOL_ID });
// CPMM
// const { poolInfo, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(POOL_ID);

// `poolInfo.lpMint` adalah ApiV3Token dan tidak memiliki field `supply`. Baca
// supply mint LP dari chain, atau gunakan mirror pool sendiri:
const lpSupply = BigInt(poolRpcData.lpAmount.toString());

const tokensA = BigInt(poolInfo.mintAmountA) * BigInt(userLpBalance) / lpSupply;
const tokensB = BigInt(poolInfo.mintAmountB) * BigInt(userLpBalance) / lpSupply;
```

Kemudian kalikan masing-masing dengan harga USD mint (dari `raydium.token` atau oracle harga).

### Posisi CLMM

```ts
const pool      = await raydium.clmm.getPoolInfoFromRpc(POOL_ID);   // string base58
const positions = await raydium.clmm.getOwnerPositionInfo({
  programId: pool.poolInfo.programId,
});
const position  = positions.find((p) => p.poolId.toBase58() === pool.poolInfo.id)!;

// getAmountsFromLiquidity adalah async, mengambil epochInfo + poolInfo + add,
// dan mengembalikan jumlah yang dibungkus biaya.
const { amountA, amountB } = await PoolUtils.getAmountsFromLiquidity({
  epochInfo:  await raydium.fetchEpochInfo(),
  poolInfo:   pool.poolInfo,
  tickLower:  position.tickLower,
  tickUpper:  position.tickUpper,
  liquidity:  position.liquidity,
  slippage:   0,      // untuk tampilan, tanpa slippage
  add:        false,
});
// amountA.amount / amountB.amount adalah BN; .fee adalah biaya transfer Token-2022.

// Biaya yang tertunda — tampilkan terpisah sebagai "tidak dikumpulkan"
const fees = {
  A: position.tokenFeesOwedA,
  B: position.tokenFeesOwedB,
};

// Reward yang tertunda — pool CLMM memiliki 0–3 aliran reward. Entri
// rewardInfos posisi adalah { growthInsideLastX64, rewardAmountOwed } saja, jadi
// mint harus berasal dari rewardInfos POOL pada indeks yang sama.
const rewards = position.rewardInfos.map((r, i) => ({
  mint:         pool.poolInfo.rewardDefaultInfos[i]?.mint,
  rewardAmount: r.rewardAmountOwed,
}));
```

Render sebagai:

- Nilai likuiditas (harga saat ini)
- Biaya yang tidak dikumpulkan
- Reward yang tertunda per aliran
- Rentang: `[tickLower_price, tickUpper_price]` dengan batang visual yang menunjukkan apakah harga saat ini dalam rentang

### Taruhan farm

```ts
// Respons API sudah mencakup reward yang tertunda; gunakan langsung.
const apr       = stakingFarm.apr;               // %, tahunan
const staked    = stakingFarm.stakedAmount;      // unit terkecil dari mint staking
const rewards   = stakingFarm.pendingRewards;    // array dari { mint, amount }
```

Untuk perhitungan on-chain, cerminkan akuntansi farm:

```
pending_reward_i = user.deposited
                 * farm.reward_per_share_x64[i] / 2^64
                 - user.reward_debts[i]
```

Pastikan untuk menyegarkan `reward_per_share_x64` dengan formula pembaruan malas sebelum menghitung (waktu yang telah berlalu × tingkat emisi ÷ total_staked).

## Simulasi transaksi untuk pratinjau

Sebelum pengguna menandatangani, dompet biasanya menampilkan pratinjau perubahan saldo. Gunakan `simulateTransaction`:

```ts
const sim = await connection.simulateTransaction(tx, {
  sigVerify: false,
  commitment: "confirmed",
  accounts: {
    encoding: "base64",
    addresses: [userTokenAtaA, userTokenAtaB, userLpAta].map(a => a.toBase58()),
  },
});

// Dekode saldo setiap akun yang dikembalikan dan diff terhadap saldo pra-tx.
for (const [i, acctData] of sim.value.accounts!.entries()) {
  const newBalance = decodeTokenAccount(acctData!.data[0]).amount;
  // bandingkan dengan saldo pra-tx, tampilkan Δ
}
```

Parameter `accounts` meminta validator untuk mengembalikan status akun pasca-simulasi untuk alamat yang terdaftar. Jauh lebih akurat daripada mencoba memprediksi perubahan saldo dari bentuk instruksi saja.

### Jebakan simulasi

- **Swap CLMM memerlukan array tick yang valid.** Jika ukuran input pengguna akan memasuki array tick yang tidak diinisialisasi, simulasi kembali (sama seperti eksekusi). Tampilkan ini dengan jelas di UI.
- **Biaya prioritas.** Simulasi berjalan tanpa instruksi compute-budget yang diterapkan. Untuk transaksi besar yang akan melebihi 200k CU default, simulasi gagal tetapi eksekusi aktual dengan batas CU eksplisit berhasil. Selalu atur batas CU pada tx yang disimulasikan juga.
- **Blockhash segar.** Simulasi menggunakan blockhash saat ini; jika penandatanganan memakan waktu >60 detik tx menjadi tidak valid. Simulasi ulang jika pengguna ragu.

## Tampilan Token-2022

Token di bawah program Token-2022 harus diberi label sebagai demikian dalam daftar token dompet, karena mereka memiliki permukaan risiko yang berbeda:

- **Mint dengan biaya transfer**: tampilkan `transferFeeBasisPoints` saat ini sebagai "Biaya transfer: X%" di sebelah saldo. Peringatkan saat menerima — pengguna mungkin tidak menyadari mereka akan menerima lebih sedikit dari yang dikirim pengirim.
- **Mint dengan transfer-hook**: tampilkan ID program hook. Hook yang berbahaya dapat memblokir transfer keluar; pengguna harus memverifikasi hook adalah yang mereka harapkan.
- **Mint yang tidak dapat ditransfer**: tampilkan "Tidak dapat ditransfer" dan nonaktifkan swap/kirim. Ini biasanya token terikat jiwa atau kredensial.
- **Mint yang menghasilkan bunga**: saldo UI yang diturunkan dari `TokenAccount.amount` **tidak** mencerminkan bunga yang terkumpul. Gunakan `amountToUiAmount` dari `@solana/spl-token` (yang menerapkan faktor penskalaan) untuk nilai yang ditampilkan.

## Tampilan APR Farm

APR yang ditampilkan kepada pengguna harus menggabungkan semua aliran reward langsung, dikonversi ke USD, dan tahunan:

```ts
let apr = 0;
for (const r of farm.rewardInfos) {
  if (r.rewardState !== 1) continue;   // lewati yang tidak berjalan
  const annualRewardTokens = Number(r.emissionPerSecond) * 86400 * 365 / 1e<decimals>;
  const annualRewardValue  = annualRewardTokens * priceUsd(r.rewardMint);
  const tvlValue           = Number(farm.totalStaked) * priceUsd(farm.stakingMint) / 1e<decimals>;
  apr += annualRewardValue / tvlValue;
}
```

Tampilkan sebagai `APR: X.Y%`. Jika mint staking adalah token LP, juga hitung APR biaya dasar LP yang mendasar dan beri label jumlahnya sebagai "Total APR" atau "APR + biaya".
