## MCP-Server

Der MCP-Server (Model Context Protocol) ermöglicht es KI-Clients, die Raydium-Dokumentation als Tool abzufragen. Nach der Konfiguration kann Ihr Agent fragen wie „search Raydium docs for `addLiquidity` parameters" und erhält autorisierte, zitierte Antworten.

### Claude Code

```bash
claude mcp add --transport http raydium-docs https://docs.raydium.io/mcp
```

Nach dem Hinzufügen können Sie Claude Code auffordern, „search the Raydium docs for X" zu durchsuchen, und es wird das Tool verwenden.

### Cursor

Fügen Sie dies zu Ihren Cursor-Einstellungen hinzu (`Cmd/Ctrl + ,` → MCP):

```json
{
  "mcpServers": {
    "raydium-docs": {
      "url": "https://docs.raydium.io/mcp"
    }
  }
}
```

### Windsurf, Continue, generische Clients

Jeder MCP-kompatible Client kann auf `https://docs.raydium.io/mcp` verweisen. Dieser Endpunkt *ist* die Discovery-Oberfläche — ein `GET` liefert die Server-Konfiguration zurück (Name, Version, Transport, Anweisungen und die Tool-Liste), sodass keine separate Manifest-Datei benötigt oder ausgeliefert wird.

### Was der Server bereitstellt

Der Raydium-Dokumentations-MCP-Server stellt ein primäres Tool bereit: `search_docs(query: string)`, das die höchstbewerteten Passagen für die Abfrage zusammen mit ihren kanonischen URLs zurückgibt. Der Agent ist verantwortlich für das Zitieren der verwendeten URL; wir verfolgen oder limitieren nicht pro Agent.

## `llms.txt` für RAG

`llms.txt` ist ein aufstrebender Standard für „maschinenlesbare Dokumentationsindizes". Raydium veröffentlicht:

- `https://docs.raydium.io/llms.txt` — eine flache Liste aller Seiten mit Titel und einzeiliger Zusammenfassung, organisiert nach Kapiteln.
- `https://docs.raydium.io/llms-full.txt` — der vollständige Markdown-Inhalt aller Seiten, verkettet, mit bewahrten Seitengrenzen als Überschriften.

Die `full`-Variante wird bei jedem Dokumentations-Deploy neu generiert. Rufen Sie sie regelmäßig ab (täglich ist ausreichend) oder laden Sie sie bei Bedarf.

```bash
# Legen Sie das vollständige Dokumentationskorpus in Ihre RAG-Ingestion-Pipeline.
curl -sSL https://docs.raydium.io/llms-full.txt -o raydium-docs.md
```

## Seitenweise Übergabe-Menü

Jede Inhaltsseite hat ein Kontextmenü (oben rechts, neben dem Titel) mit diesen Ein-Klick-Aktionen:

- **Copy** — kopieren Sie die Seite als einfaches Markdown.
- **View as Markdown** — öffnen Sie die Quelle `.md` in einem neuen Tab, um sie zu speichern.
- **Open in ChatGPT / Claude / Perplexity** — laden Sie den Seiteninhalt vorab in eine Chat-Eingabeaufforderung für das benannte Tool.
- **Open in Cursor / VS Code** — öffnen Sie einen Buffer im benannten Editor mit dem Seiteninhalt.

Dies ist die richtige Oberfläche, wenn Sie ein Modell eine Frage zu einer einzelnen Seite stellen möchten, ohne MCP einzurichten.

## Vorgefertigte Kontextdateien für Coding Agents

Wenn Sie Raydium integrieren und möchten, dass Ihr Agent von Anfang an das richtige Grundwissen hat, legen Sie diese Dateien in Ihr Projekt:

### `.cursorrules` / `.windsurfrules` / Agent-Systemprompt

```text
You are integrating with Raydium, a Solana DeFi protocol with five product
surfaces: AMM v4, CPMM, CLMM, Farm, and LaunchLab. Authoritative docs live
at docs.raydium.io. The official SDK is `@raydium-io/raydium-sdk-v2` (pin
the version you've verified against). For server-built swaps, prefer the
Trade API at transaction-v1.raydium.io. Always:

- Pass a `Connection` and `cluster` that match.
- Keep all amounts as `BN` instances; never call `.toNumber()` on amounts.
- Pre-fund the user's wallet for ATA creation rent.
- Pass an explicit `computeBudgetConfig` for any tx that may compete in
  high-volume windows.
- Re-fetch `poolInfo` immediately before high-value transactions; cached
  state goes stale.

When uncertain about an instruction's accounts list, defer to
`docs.raydium.io/products/<product>/accounts` and the on-chain IDL.
```

Speichern Sie als `.cursorrules` (Cursor), `.windsurfrules` (Windsurf) oder `CLAUDE.md` (Claude Code) — oder fügen Sie in den Systemprompt Ihres Agents ein. Der genaue Dateiname und Speicherort variieren je nach Tool-Version. Überprüfen Sie die Einstellungsdokumentation Ihres Tools, falls die Datei nicht automatisch erkannt wird.

## Indizierungs-Rezept

Wenn Sie Ihre eigene RAG erstellen und `llms-full.txt` nicht verwenden möchten, hier ist das kanonische Rezept:

```ts
import { fetch } from "undici";

const INDEX_URL = "https://docs.raydium.io/llms.txt";
const BASE      = "https://docs.raydium.io";

const index    = await (await fetch(INDEX_URL)).text();
const pageUrls = [...index.matchAll(/^- \[(.+?)\]\((.+?)\)/gm)].map(m => m[2]);

for (const path of pageUrls) {
  const md = await (await fetch(`${BASE}${path}.md`)).text();
  // ingest md into your vector store, keyed by path
}
```

Jede Seite wird unter ihrem kanonischen Pfad mit angefügtem `.md`-Suffix bereitgestellt (z. B. `/sdk-api/typescript-sdk` → `/sdk-api/typescript-sdk.md`).

## Einschränkungen

- **Fügen Sie keinen privaten Status in Prompts ein.** Der MCP-Server kennt nur das, was in der öffentlichen Dokumentation steht. Wallet-Schlüssel, RPC-Anmeldedaten und ähnliche Geheimnisse sollten niemals in den Agent-Kontext gelangen.
- **KI-Ausgabe ist nicht maßgeblich.** Modelle halluzinieren Programmadressen, Anweisungsnamen und Kontolisten mit besorgniserregender Leichtigkeit. Überprüfen Sie immer gegen die Dokumentation und die IDL, bevor Sie Agent-generierte Transaktionen vertrauen.
- **Versionsdrift.** SDK v2 ist vor 1.0; Agents, die auf älteren Versionen trainiert wurden, können Code ausgeben, der nicht gegen Ihre gepinnte Version kompiliert. Fügen Sie die gepinnte SDK-Version in den Systemprompt Ihres Agents ein.
