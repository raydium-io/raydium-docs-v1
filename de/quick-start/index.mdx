## Voraussetzungen

Führen Sie dies einmalig aus:

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

Sie benötigen:

- **Node 18+** mit ESM-Unterstützung (`"type": "module"` in `package.json` oder `.mjs`-Erweiterung).
- **Ein Solana-Keypair** unter `~/.config/solana/id.json` (oder überall — setzen Sie `KEYPAIR`). Siehe [`solana-fundamentals/toolchain`](/de/solana-fundamentals/toolchain#solana-cli) zum Generieren eines Keypairs.
- **Ein finanziertes Wallet.** Das Swap-Skript benötigt nur seinen Eingabebetrag plus einen kleinen Puffer — ein CPMM-Swap kostet etwa 0,0015 SOL an Netzwerkgebühren (siehe [`reference/fee-comparison`](/de/reference/fee-comparison#network-fees-per-typical-operation)), plus einmalige Miete, wenn der Swap ein Token-Konto für Sie öffnen muss. Das Erstellen eines Pools kostet mehr: Das CPMM-Skript allein trägt eine einmalige Pool-Erstellungsgebühr von etwa 0,15 SOL vor Seed-Liquidität oder Miete. Siehe den Setup-Abschnitt jedes Skripts für die aktuelle Zahl, bevor Sie Ihr Wallet finanzieren.
- **Eine RPC-URL.** Kostenlose öffentliche RPC funktioniert zum Testen; für mehr als einen Smoke-Test verwenden Sie einen bezahlten Anbieter.

Setzen Sie diese einmalig pro Shell:

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **Cluster.** Alle drei Skripte verwenden standardmäßig Mainnet. Devnet benötigt `RPC_URL=https://api.devnet.solana.com` plus `cluster: "devnet"` im Skript — für die beiden Pool-Erstellungs-Skripte ist das nicht die einzige Änderung; siehe den Setup-Abschnitt jedes Skripts für weitere erforderliche Änderungen. Beachten Sie, dass die Pool-Seed-Liquidität auf Devnet spärlich ist; rechnen Sie damit, Ihre eigenen Test-Token zu prägen.
</Info>

## Nach diesem Kapitel

Jedes Skript gibt sein On-Chain-Ergebnis aus — ein Swap-Angebot und Transaktionslink, neue Pool-Adressen oder eine neue Position und deren NFT — und eine einzelne Zeile, die auf die nächste Seite im [SDK & API](/de/sdk-api)-Kapitel für die Operation verweist, die es durchgeführt hat. Wenn Sie bereit sind, Ihre eigene Integration zu schreiben:

- **Backends und Bots** → [Trade API](/de/sdk-api/trade-api).
- **Frontends und Full-Control-Apps** → [TypeScript SDK](/de/sdk-api/typescript-sdk).
- **On-Chain-Komposition** → [Rust CPI](/de/sdk-api/rust-cpi).
- **Auswahl zwischen ihnen** → die Vergleichstabelle oben auf [SDK & API](/de/sdk-api).
