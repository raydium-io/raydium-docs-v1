## Phase 1: Bonding-Curve Creator-Gebühren

Während Ihr Token auf der Bonding Curve gehandelt wird, kann die Plattform eine Creator-Gebührenkomponente auf Käufe und Verkäufe erheben.

- Sie fallen im Quote-Token an, normalerweise SOL.
- Die Plattform legt den Satz fest.
- Sie können diese über den LaunchLab Creator-Gebühren-Abruf-Flow einfordern.
- Die Graduation stoppt neue Bonding-Curve-Ansammlungen. Jeder vorhandene Saldo bleibt abrufbar.

## Phase 2: CPMM Creator-Gebühren

Jede neu initialisierte Launch graduiert zu CPMM. CPMM Creator-Gebühren fallen nur an, wenn die ausgewählte `AmmConfig` einen Satz für Creator-Gebühren ungleich Null hat.

Standardmäßig wird der Launch-Creator zum CPMM-Pool-Creator. Eine Plattform kann stattdessen `platform_cp_creator` setzen, in welchem Fall diese Adresse die CPMM Creator-Gebührenrechte erhält.

Der eingetragene CPMM-Creator kann direkt einfordern. Ein anderer Zahler kann auch eine gebührenfreie Erfassung auslösen, aber CPMM legt die Ziele auf die kanonischen Token-Konten des Creators fest.

## Was mit LP-Tokens geschieht

Die Plattformkonfiguration speichert `platformScale`, `creatorScale` und `burnScale`. Vor dem Upgrade vom 2026-08-14 erzeugte `creatorScale` einen Creator-eigenen Fee Key. Für Migrationen, die nach dem Upgrade ausgeführt werden, kombiniert LaunchLab ihn mit `platformScale`:

```text
platform locked LP = platformScale + creatorScale
burned LP          = burnScale
```

Wenn der gesperrte Anteil ungleich Null ist, geht ein Fee Key NFT an die konfigurierte NFT-Wallet der Plattform. Dieses NFT kontrolliert die LP-Gebühren-Ernte. Es kontrolliert nicht die CPMM Creator-Gebühren-Erfassung. Creator Fee Keys aus Migrationen, die vor dem Upgrade abgeschlossen wurden, bleiben bei ihren bestehenden Inhabern.

## Gebührenfluss-Zusammenfassung

```text
Bonding Curve
  Creator-Gebühr → Launch-Creator-Vault

Graduation zu CPMM
  Vor Upgrade → Platform Fee Key + Creator Fee Key + verbrannter Anteil
  Nach Upgrade  → kombinierter Platform Fee Key-Anteil + verbrannter Anteil

CPMM-Handel
  Creator-Gebühr → eingetragener CPMM-Pool-Creator
  LP-Gebühr      → Platform Fee Key-Inhaber für den gesperrten Anteil
```

## Vor dem Launch

- Überprüfen Sie die Bonding-Curve `creator_fee_rate`.
- Überprüfen Sie, ob `platform_cp_creator` Sie als CPMM-Creator-of-Record ersetzt.
- Für Migrationen, die nach dem Upgrade ausgeführt werden, behandeln Sie `creatorScale` nicht als zugesicherte Creator Fee Key-Zuweisung. Für frühere Migrationen überprüfen Sie den vorhandenen Fee Key-Datensatz.
- Überprüfen Sie die Creator-Gebührenrate und die Fee-On-Einstellung der CPMM-Konfiguration.
