<Info>
  LaunchLab ist Raydiums primärer Marktplatz für Token-Starts. Ein Projekt hinterlegt sein Token-Angebot in einer Bonding-Curve; Käufer handeln gegen die Kurve mit SOL (oder einem anderen Quote-Mint); wenn ein Abschluss-Schwellenwert erreicht wird, migrieren die Vermögenswerte der Kurve automatisch zu einem CPMM-Pool, und der Token wird frei handelbar. Diese Seite führt Sie durch den gesamten Ablauf aus der Perspektive des Projekts.
</Info>

## Was Sie benötigen

- **Token-Mint** — der Token, den Sie verkaufen möchten. Muss neu geprägt sein mit:
  - Vollständigem Angebot in Ihrer Wallet (damit Sie es in die Kurve einzahlen können).
  - Mint-Autorität vor dem Start widerrufen (sonst kann der Kurvenkurs durch neue Prägungen manipuliert werden).
- **Metadaten** — Name, Symbol, Bild, Social-Links. Metaplex-Metadaten oder ähnlich.
- **Wallet** — ~1 SOL für Erstellungsgebühren + Vault-Finanzierung + Prioritätsgebühren (der Abschluss selbst wird vom Abschluss-Executor bezahlt, nicht von Ihnen).
- **Entscheidung über**:
  - Kurventyp (quadratisch vs. Virtual-Reserves CPMM).
  - Abschluss-Schwellenwert.
  - LP-Entsorgungsrichtlinie (Burn / Lock / ToCreator).
  - Anfangspreis und Obergrenze.

## Kurvenauswahl

LaunchLab unterstützt zwei Kurvenfamilien:

### Quadratisch (`curve_type = 0`)

Der Preis wächst quadratisch mit dem verkauften Angebot. Klassisches „Fair-Launch"-Gefühl — frühe Käufer erhalten einen Preisvorteil, späte Käufer zahlen mehr, der Preis beschleunigt sich sanft.

```
price(s) = a * s^2 + b * s + c
```

wobei `s` das verkaufte Angebot ist. Typischerweise `a > 0` (konvex). Die Spanne zwischen Anfangs- und Abschlusspreis ist deterministisch gegeben `a, b, c` und die Obergrenze.

Beste Verwendung für: Neuartige Starts, Memes, Community-getriebene Projekte.

### Virtual-Reserves CPMM (`curve_type = 1`)

Emuliert einen Constant-Product-AMM mit *virtuellen* Reserven — die Kurve verhält sich wie ein CPMM mit `x * y = k`, aber der Pool startet mit synthetischen Tokens, die nie abgezogen werden.

```
price = virtual_quote_reserve / virtual_base_reserve
```

Wenn Käufer kaufen, sinkt `virtual_base_reserve` und `virtual_quote_reserve` steigt — die Kurve sieht identisch mit dem Post-Abschluss-CPMM aus. Sanfterer Übergang.

Beste Verwendung für: Starts, die vorhersehbare Post-Abschluss-Preiskontinuität wünschen.

## UI-Anleitung

Auf [raydium.io/launchpad/create](https://raydium.io/launchpad/create):

1. **Token.** Mint-Adresse einfügen. Die UI ruft Metadaten ab und zeigt sie an.
2. **Kurventyp.** Wählen Sie quadratisch oder Virtual-CPMM; die UI zeigt eine Preisdiagramm-Vorschau für jeden.
3. **Abschluss-Schwellenwert.** Standard: Die Kurve endet, nachdem das gesamte `total_base_supply` verkauft wurde. Alternative: Beenden bei einem bestimmten `graduation_quote_amount` (z. B. 85 SOL).
4. **Quote-Mint.** SOL (Standard), USDC oder ein beliebiger anderer Mint. SOL ist Standard.
5. **LP-Entsorgungsrichtlinie:**
   - **Burn** — LP-Tokens an eine unbrauchbare Adresse beim Abschluss gesendet. Der Ersteller kann keine Liquidität abheben; Benutzer vertrauen dem Pool für immer.
   - **Lock** — LP-Tokens an einen zeitgesperrten Escrow für `lock_duration` gesendet.
   - **ToCreator** — LP-Tokens an den Ersteller gesendet. Am flexibelsten, am wenigsten vertrauensmindernd.

   Die meisten angesehenen Starts verwenden Burn.

6. **Überprüfung.** Die UI fasst zusammen: erwarteter Preisbereich, anfängliche Mittelbeschaffung, wenn die Kurve ausverkauft ist, Abschluss-CPMM-Konfiguration.
7. **Signieren.** Eine Transaktion erstellt den Start-Status + Base-Vault + Quote-Vault, überträgt `total_base_supply` von Ihrer Wallet zum Base-Vault.

## Programmgesteuerte Anleitung

Die Kurvenform, der Quote-Mint, das Mittelbeschaffungsziel und die LP-Entsorgungsrichtlinie sind **keine** Argumente — sie stammen aus der `GlobalConfig`, an die Sie gebunden sind, und aus der `PlatformConfig`, unter der Ihr Start läuft. Was Sie übergeben, ist die Identität des Mints, die Konfiguration zum Binden und optional ein erster Kauf:

```ts
import {
  Raydium,
  TxVersion,
  LAUNCHPAD_PROGRAM,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";
import BN from "bn.js";

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });
const programId = LAUNCHPAD_PROGRAM;

// Sie generieren das Keypair des Base-Mints und signieren damit.
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// Binden Sie eine Konfiguration: (Quote-Mint, curve_type, Index). Dies legt die Kurvenform,
// den Quote-Mint und das Mittelbeschaffungsziel fest.
const configId   = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
const configInfo = LaunchpadConfig.decode(configData!.data);
const mintBInfo  = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "My New Token",
  symbol: "MYNEW",                    // 10 Zeichen oder weniger
  uri:    "https://example.com/metadata.json",
  migrateType: "amm",                 // "amm" | "cpmm"

  configId,
  configInfo,
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  createOnly: true,                   // true = Mint erstellen ohne ersten Kauf
  buyAmount:  new BN(1000),
  slippage:   new BN(100),            // 100 = 1%

  extraSigners: [pair],               // das Base-Mint-Keypair muss signieren
  txVersion: TxVersion.V0,
  computeBudgetConfig: { units: 400_000, microLamports: 50_000 },
});

// createLaunchpad gibt mehrere Transaktionen zurück - führen Sie sie der Reihe nach aus.
const { txIds } = await execute({ sequentially: true });
console.log("Pool ID:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
```

`raydium.api.fetchLaunchConfigs()` listet die verfügbaren Konfigurationen mit ihrem Standard-Angebot, Verkaufsmenge und Mittelbeschaffungsziel auf, damit Sie dem Benutzer zeigen können, was eine bestimmte Konfiguration bedeutet, bevor er signiert. Vollständig kommentierte Version, einschließlich der Token-2022-Variante: [`products/launchlab/code-demos`](/de/products/launchlab/code-demos#create-a-launch).

## Überwachung vor dem Abschluss

Verfolgen Sie die Aktivität über die API:

LaunchLab hat seine eigenen API-Hosts, getrennt von `api-v3.raydium.io`:

```ts
// Mint-Level-Informationen, nach Base-Mint indiziert (kommagetrennt für einen Batch).
const r = await fetch(
  `https://launch-mint-v1.raydium.io/get/by/mints?ids=${mintA.toBase58()}`,
).then((r) => r.json());
console.log(r.data.rows[0]);

// Auch verfügbar: /main/configs (Konfigurationsliste) auf demselben Host und
// https://launch-history-v1.raydium.io/kline und /trade für Preis und Fills.
```

Oder lesen Sie den On-Chain-Status direkt. Die Pool-ID ist eine PDA von `(programId, mintA, mintB)`:

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log({
  status:      poolInfo.status,
  baseSold:    poolInfo.realA.toString(),
  totalSellA:  poolInfo.totalSellA.toString(),
  quoteRaised: poolInfo.realB.toString(),
  raiseTarget: poolInfo.totalFundRaisingB.toString(),
});
```

Der Fortschritt wird am besten in **Preis**-Begriffen ausgedrückt, anstatt als Bruchteil der Mittelbeschaffung, da die Kurve nicht-linear ist. Das Demo-Repo's [`getFinishRate.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/getFinishRate.ts) macht es mit `Curve.getPrice`, `Curve.getPoolEndPriceReal` und `Curve.getPoolInitPriceByPool`:

```
finishRate = (currentPrice − initPrice) / (endPrice − initPrice)   // auf 1 begrenzt
```

### Zu überwachende Metriken

- **Verkaufsquote**: Prozentsatz des verkauften Base. Der Abschluss-Schwellenwert liegt typischerweise bei 80–100% verkauft.
- **Aktueller Preis**: abgeleitet von der Kurve beim aktuellen `baseSold`.
- **Eindeutige Käufer**: Anzahl der unterschiedlichen Zahler über Indexer.
- **Kauf-zu-Verkauf-Verhältnis**: frühe Starts sehen starken Kaufdruck, der nachlässt.

Wenn die Verkaufsquote nach 24 Stunden `<10%` beträgt, überprüfen Sie, ob das Marketing angemessen ist. LaunchLab rettet unterhypte Starts nicht.

## Abschluss

Der Abschluss ist eine separate Transaktion, und er ist **nicht** von jedem aufrufbar: `MigrateToCpswap` und das Legacy-`MigrateToAmm` erfordern jeweils, dass ihr Signer einer Wallet entspricht, die auf der Binding-`GlobalConfig` aufgezeichnet ist (`migrate_to_cpswap_wallet` / `migrate_to_amm_wallet`), und jeder andere Signer erhält `InvalidOwner`. Es gibt keine Belohnung. Diese Wallets werden von Raydiums Abschluss-Crank betrieben, der die Migration innerhalb von Sekunden nach Überschreitung des Schwellenwerts durchführt. Keine Aktion erforderlich von Ihnen als Ersteller über die Erstkonfiguration hinaus.

### Was der Abschluss bewirkt

1. Liest die Vault-Salden.
2. Schließt die Kurve (keine weiteren Käufe/Verkäufe dagegen).
3. Erstellt einen neuen CPMM-Pool mit den Vault-Salden als anfängliche Liquidität.
4. Prägt anfängliche LP-Tokens basierend auf den Vault-Salden.
5. Entsorgt die LP-Tokens gemäß der konfigurierten Richtlinie (Burn / Lock / ToCreator).

Nach dem Abschluss ist der CPMM-Pool live und handelt über normales Raydium-Routing.

### Überwachung auf Abschluss

Beobachten Sie `status` im Pool-Status und wechseln Sie Ihre UI, wenn er sich ändert:

```ts
const before = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

setInterval(async () => {
  const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
  if (p.status !== before) console.log("migriert - zur CPMM-Pool-Seite wechseln");
}, 10_000);
```

Die Adresse des abgeschlossenen Pools ist die CPMM-PDA für `(cpswap config, token0, token1)`, daher können Sie sie ableiten, anstatt darauf zu warten, dass sie gemeldet wird. Für einen Indexer abonnieren Sie über gRPC statt zu pollen — siehe [`products/launchlab/code-demos`](/de/products/launchlab/code-demos#watch-configs-and-pools-over-grpc).

Es gibt keinen „manuellen Abschluss"-Pfad für einen Ersteller oder Dritte. Wenn ein Start seinen Schwellenwert überschritten hat und nicht migriert wurde, ist das eine operative Angelegenheit für die Migrations-Wallet, nicht etwas, das Sie von einem Client erzwingen können.

## Nach dem Abschluss

### Verifizieren Sie den CPMM-Pool

```ts
const pool = await raydium.cpmm.getPoolInfoFromRpc({ poolId: cpmmPoolId });
console.log("CPMM-Preis:", pool.poolInfo.price);
console.log("CPMM-TVL:  ", pool.poolInfo.tvl);
```

Der CPMM-Pool sollte (ungefähr) haben:

- Base-Token-Saldo: `total_base_supply - baseSold` + Kurvenrest.
- Quote-Token-Saldo: `quoteRaised - graduationFee`.
- Preis: entspricht dem letzten Kurvenkurs.

### Verifizieren Sie die LP-Entsorgung

- **Burn**: LP-Mint-Angebot zeigt an 1nc1nerator11111111111111111111111111111111 oder ähnlich gesendet.
- **Lock**: LP-Tokens im Escrow-PDA mit Entsperr-Zeitstempel.
- **ToCreator**: LP-Tokens in der Wallet des Erstellers.

### Sammeln Sie Ersteller-Gebühren

Wenn Sie einen Ersteller-Gebühren-Anteil konfiguriert haben, rufen Sie regelmäßig auf:

Der Builder ist `claimCreatorFee`, und er wird nach dem **Quote-Mint** indiziert, anstatt nach einem Start — ein Aufruf sammelt Ihre aufgelaufenen Ersteller-Gebühren in diesem Mint:

```ts
import { NATIVE_MINT } from "@solana/spl-token";

await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,      // der Quote-Mint zum Beanspruchen
  txVersion: TxVersion.V0,
});
```

Verwenden Sie `claimMultipleCreatorFee`, um über Mints zu batchen. Gebühren sammeln sich von Kurvenhandeln vor dem Abschluss an, und nach dem Abschluss vom CPMM-Pool's Ersteller-Gebühren-Pfad, wenn die Plattform's `platform_cp_creator` Sie als aufgezeichneten Pool-Ersteller belässt — siehe [`products/launchlab/platform-config`](/de/products/launchlab/platform-config).

## Ankündigungs-Checkliste

Die Post-Abschluss-Ankündigung sollte enthalten:

- [ ] Abschluss-Transaktions-Hash.
- [ ] Neue CPMM-Pool-ID.
- [ ] LP-Entsorgungsnachweis (Burn-Tx / Lock-Tx / Ersteller-Wallet).
- [ ] Aggregator-Abdeckungs-ETA (Wallets indizieren typischerweise innerhalb von 5 Minuten).
- [ ] Token-Vertragsverifizierung (Mint-Adresse über Ankündigungskanäle abgleichen).

## Fallstricke

### 1. Mint-Autorität nicht widerrufen

Wenn `baseMint.mintAuthority` immer noch ein Schlüssel ist, den Sie kontrollieren, können Sie neues Angebot prägen und in Ihre eigene Kurve verkaufen. Starts, die nicht widerrufen haben, werden häufig von Aggregatoren und Listing-Seiten als hohes Risiko oder unverifiziiert gekennzeichnet. Widerrufen Sie vor dem Start.

### 2. Falsche Kurvenparameter

Quadratische Kurven mit zu hohem `a` machen frühe Tokens kostenlos (Preis ≈ 0) und später Tokens absurd. Kurven mit zu niedrigem `a` machen die Kurve fast linear (verlieren das „Bonding"-Gefühl). Testen Sie Parameter zuerst auf Devnet.

### 3. Abschluss-Schwellenwert zu hoch

Wenn der Abschluss mehr Kapital erfordert als realistische Nachfrage, graduiert die Kurve nie und Käufer sind mit Tokens stecken, die sie nur zurück an die Kurve verkaufen können (zu schlechteren Preisen). Wählen Sie einen Schwellenwert, den Sie tatsächlich erreichen können.

### 4. Quote-Mint-Betrügereien

Wenn Ihr Quote-Mint ein benutzerdefinierter Token ist (nicht SOL/USDC), werden Benutzer ihm nicht vertrauen. Bleiben Sie bei SOL oder USDC für Quote.

### 5. Vergessen, Base-Vault zu finanzieren

Das SDK überträgt `totalBaseSupply` von Ihrer Wallet bei der Erstellung. Wenn Ihre Wallet es nicht hat, wird die Tx zurückgewiesen. Bestätigen Sie den Saldo vor dem Signieren.

### 6. LP-Entsorgung = Burn ist irreversibel

Sobald LP an 1nc1nerator gesendet wird, kann niemand Liquidität abheben, *einschließlich Sie*. Das ist der Sinn — Vertrauensminderung. Wählen Sie nicht Burn, wenn Sie sich nicht sicher sind.

### 7. Post-Abschluss-CPMM-Gebühren-Tier

Der abgeschlossene Pool verwendet LaunchLabs Standard-CPMM-Konfiguration (0,25%). Wenn Sie 1% oder 0,01% wollten, müssen Sie nach dem Abschluss selbst einen zweiten CPMM-Pool erstellen und Liquidität migrieren — umständlich und fragmentierend. Akzeptieren Sie den Standard, oder starten Sie über direkte CPMM-Erstellung statt LaunchLab.
