## Was Burn & Earn ist

Burn & Earn ist eine Raydium-Funktion, mit der ein Pool-Ersteller (oder jeder LP) eine Einzahlung **dauerhaft** in der Blockchain verankern kann, während er das Recht behält, Handelsgebühren zu ernten. Eine Position wird nicht mehr rückgängig gemacht, aber ein neu geprägtes **Raydium Fee Key** NFT repräsentiert das laufende Recht, Gebühren (`collectFees`) von dieser gesperrten Position einzufordern.

Häufige Anwendungsfälle:

- **Launch-Vertrauen.** Projekte verpflichten sich, nicht zu rug-pullen, indem sie die LP des Deployers sperren. Inhaber können überprüfen, dass die Liquidität dauerhaft ist.
- **Gebührentragende Sammelware.** Ein handelbares NFT, das Rendite generiert. Verkaufen Sie das NFT; übertragen Sie den Gebührenstrom.
- **Treasury-Grade LP.** Protokolle, die Liquidität für immer für Marken- / Erkennungszwecke behalten möchten, während sie die Gebührenseite monetarisieren.

## Unterstützte Pool-Typen

| Programm | Burn & Earn-Unterstützung |
|---|---|
| CPMM | Ja |
| CLMM | **Nur vollständiger Bereich** (empfohlen) |
| AMM v4 (Hybrid) | Nicht unterstützt |

Bei CLMM sollten nur Positionen, die den gesamten Preisbereich umfassen, gesperrt werden. Nach dem Sperren können Sie nicht neu ausgleichen – wenn sich der Preis außerhalb Ihres gewählten Bereichs bewegt, verdienen Sie dauerhaft keine Gebühren mehr mit dieser Position. Eine eng begrenzte Burn & Earn-Position ist fast immer ein Fehler.

## Wie die Sperre auf Programmebene funktioniert

1. Der ursprüngliche LP-Token (CPMM) oder die Position-NFT (CLMM) wird in einen programmgesteuerten PDA übertragen, der dem Burn & Earn-Programm gehört.
2. Ein **Fee Key NFT** wird an den Aufrufer geprägt. Seine Metadaten verweisen zurück auf den PDA der gesperrten Position.
3. Burn & Earn stellt `collectFees` (oder den entsprechenden Pool-Typ-spezifischen Aufruf) bereit, der:
   - Überprüft, dass der Unterzeichner das Fee Key NFT für die gegebene gesperrte Position hält.
   - Ruft die Fee-Claim-Anweisung des zugrunde liegenden Pool-Programms über CPI auf.
   - Leitet die eingezogenen Gebühren an die ATAs des Fee Key-Inhabers weiter.
4. Es gibt keinen entsprechenden `withdraw` – der zugrunde liegende LP / die Position verlässt den Escrow niemals.

Das Fee Key ist ein Standard-SPL-NFT. Es kann auf jedem Solana-NFT-Marktplatz verkauft, zwischen Wallets verschoben, als Sicherheit bei Kreditprotokollen verwendet werden, die NFTs akzeptieren, oder in einen anderen Vertrag eingewickelt werden. Wer es zum Zeitpunkt eines `collectFees`-Aufrufs hält, erhält die Gebühren.

## UI-Anleitung

1. Erstellen Sie einen CPMM-Pool oder einen CLMM-Pool mit einer vollständigen Bereichsposition wie gewohnt.
2. Gehen Sie zu **Liquidity → Create → Burn & Earn**.
3. Wählen Sie die zu sperrende Position aus.
4. Überprüfen Sie die Positionsdetails (NFT-Adresse, Größe, Pool) und geben Sie den Bestätigungssatz ein, den die UI anzeigt. Dies ist absichtlich reibungsreich, da der Vorgang nicht rückgängig gemacht werden kann.
5. Klicken Sie auf **Confirm, lock the liquidity permanently** (Bestätigen, Liquidität dauerhaft sperren).
6. Ein Fee Key NFT kommt in Ihre Wallet. Es erscheint auf der Portfolio-Seite unter gesperrten Positionen.

Fordern Sie Gebühren auf die gleiche Weise ein wie bei jeder Position – über die Portfolio-Seite oder über `collectFees`.

## API-Oberfläche

Der Pool-Info-Endpunkt gibt ein `burnPercent`-Feld zurück, das den Anteil der Liquidität dieses Pools angibt, der über Burn & Earn gesperrt wurde:

```http
GET https://api-v3.raydium.io/pools/info/list
  ?poolType=standard
  &poolSortField=default
  &sortType=desc
  &pageSize=1
  &page=1
```

```json
{
  "data": [
    {
      "id": "...",
      "burnPercent": 99.17,
      ...
    }
  ]
}
```

`burnPercent` ist eine praktische Oberfläche für Vertrauenssignalisierung: Ein Token, dessen LP zu 99%+ gebrannt ist, ist dramatisch weniger rug-anfällig als einer, dessen LP zu 0% gebrannt ist.

## Fallstricke

- **Nicht rückgängig zu machen.** Die LP-Seite kann niemals abgerufen werden. Bestätigen Sie, dass der Betrag etwas ist, das Sie nie wieder anfassen möchten.
- **CLMM enge Bereiche sind eine Falle.** Sperren Sie nur vollständige CLMM-Positionen, es sei denn, Sie verstehen wirklich, dass eine bereichsgebundene gesperrte Position aufhört zu verdienen, sobald der Preis das Band verlässt.
- **Das Fee Key NFT zu verlieren bedeutet, die Gebühren für immer zu verlieren.** Behandeln Sie es wie eine Urkunde. Brennen Sie es nicht versehentlich; staken Sie es nicht in einem feindlichen Vertrag.
- **Token-2022-Mints mit Transfergebühren**: Burn & Earn unterstützt sie, aber der Transfergebühren-Haarschnitt wird bei jedem Fee-Claim angewendet – budgetieren Sie dafür.
- **Es gibt keine teilweise Sperre.** Wenn Sie 50% gesperrt und 50% beweglich möchten, teilen Sie die Position zuerst in zwei Positionen auf und sperren Sie dann nur eine.

## LaunchLab verwendet Burn & Earn unter der Haube

Token, die von [LaunchLab](/de/products/launchlab) abgestuft wurden, verwenden LP-Lock für gesperrte LP. Vor dem Upgrade vom 2026-08-17 produzierte `creatorScale` einen vom Ersteller gehaltenen Fee Key. Migrationen, die danach ausgeführt wurden, kombinieren `platformScale + creatorScale` in eine Platform Fee Key-Position und brennen `burnScale`. Fee Keys aus früheren abgeschlossenen Migrationen bleiben unverändert. Siehe [`products/launchlab/platforms`](/de/products/launchlab/platforms) und [`products/launchlab/creator-fees`](/de/products/launchlab/creator-fees).
