## Zwei Erstellungsmodi

LaunchLab bietet zwei Erstellungswege, die über [raydium.io/launchlab/create](https://raydium.io/launchlab/create) zugänglich sind:

| | **JustSendit** | **LaunchLab** |
|---|---|---|
| Einrichtungszeit | ~1 Minute | ~5 Minuten |
| Token-Angebot | Festes Standard | Vollständig konfigurierbar |
| SOL-Ziel | 85 SOL (fest) | Mindestens 24 SOL, benutzerdefiniert |
| Kurven-% | Standard | 51–80% auf Kurve |
| Vesting | Keine | Optional |
| Gebühren nach Migration | Plattform-definierte CPMM-Creator-Gebühr und LP-Richtlinie | Plattform-definierte CPMM-Creator-Gebühr und LP-Richtlinie |
| Am besten für | Schnelle Community-Starts | Strukturierte Token-Starts |

## JustSendit-Modus

Der schnellste Weg zum Token-Start. Minimale Eingabe erforderlich; die Plattform füllt sinnvolle Standardwerte aus.

### Was Sie benötigen

- Ein verbundenes Wallet mit ausreichend SOL für Transaktionsgebühren (~0,05–0,1 SOL für die Erstellung).
- Ein Token-Name und Ticker-Symbol.
- Ein Bild oder GIF, das die UI-Anforderungen erfüllt.

### Schritte

1. Gehen Sie zu [raydium.io/launchlab/create](https://raydium.io/launchlab/create) und wählen Sie **JustSendit**.
2. Geben Sie den Token-**Namen** und das **Ticker-Symbol** ein.
3. Fügen Sie optional eine **Beschreibung** und **Social-Links** hinzu (Website, Twitter/X, Telegram).
4. Laden Sie ein **Logo-Bild oder GIF** hoch.
5. Geben Sie optional einen **anfänglichen Kaufbetrag** in SOL ein, um Tokens bei der Erstellung zu kaufen. Dies ändert den ersten On-Curve-Preis und sollte vor dem Signieren überprüft werden.
6. Überprüfen Sie die Zusammenfassung und klicken Sie auf **Create**.
7. Genehmigen Sie die Transaktion in Ihrem Wallet.

Ihr Token wird sofort auf der Bonding Curve gestartet. Er wird zu einem Raydium AMM-Pool migriert, sobald 85 SOL durch die Kurve gesammelt wurden.

## LaunchLab-Modus

Erstellung mit vollständiger Kontrolle über Angebot, Fundraising-Ziel, Kurvenverteilung, Vesting und Gebührenparameter.

### Was Sie benötigen

- Ein verbundenes Wallet mit ~0,1–0,5 SOL für Erstellung und Vault-Miete.
- Alle nachfolgenden Eingaben vor dem Start bereit (Einstellungen können nach dem Start nicht geändert werden).

### Konfigurationsoptionen

#### Token-Details

- **Name, Ticker, Logo** — wie bei JustSendit.
- **Beschreibung und Social-Links** — empfohlen für bessere Auffindbarkeit.

#### Angebot und Kurvenverteilung

- **Gesamtangebot** — Gesamtzahl der zu prägenden Tokens (z. B. 1.000.000.000).
- **Kurvenverteilung (%)** — der Prozentsatz des Gesamtangebots, das auf der Bonding Curve für öffentliche Käufe platziert wird (51–80%). Der Rest wird für den Liquiditätspool nach der Migration verwendet.

<Warning>
  Die Kurvenverteilung und das Gesamtangebot sind beim Start fest und **können nicht geändert werden**. Wählen Sie sorgfältig aus, bevor Sie signieren.
</Warning>

#### SOL-Fundraising-Ziel

- Der Mindest-Migrationsschwellenwert beträgt **24 SOL**. Sie können ihn höher setzen.
- Dies ist der SOL-Betrag, den die Kurve sammeln muss, bevor der Token zu einem CPMM-Pool migriert wird.
- Ein zu hohes Ziel riskiert, dass die Kurve nie migriert, wenn die Nachfrage unzureichend ist.

#### Vesting (optional)

Vesting sperrt einen Teil des Token-Angebots und gibt ihn linear über einen Zeitplan an bestimmte Wallets frei.

| Feld | Beschreibung |
|---|---|
| Gesamter gesperrter Betrag | Tokens, die über alle Begünstigten gesperrt werden (als % des Gesamtangebots, unterliegt Programmgrenzen). |
| Cliff-Periode | Wartezeit nach der Migration, bevor Tokens freigegeben werden (z. B. 180 Tage). |
| Freigabeperiode | Dauer der linearen Freigabe nach der Cliff-Periode (z. B. 365 Tage). |

Gesperrte Tokens treten nicht in die Kurve ein und sind nicht Teil des Liquiditätspools nach der Migration. Sie werden an das Wallet jedes Begünstigten nach dem obigen Zeitplan freigegeben.

**Wichtige Vesting-Regeln:**
- Cliff- und Freigabeperioden sind beim Start fest — sie können nicht nachträglich geändert werden.
- Wenn ein Begünstigter seinen Wallet-Schlüssel verliert, sind gesperrte Tokens dauerhaft unerreichbar. Verwenden Sie ein Multisig, wenn Wiederherstellung wichtig ist.
- Jeder Teil von `total_locked_amount`, der vor der Migration nicht einem Begünstigten zugeordnet wird, bleibt dauerhaft stecken. Ordnen Sie den vollständigen Betrag zu.

Für die vollständige On-Chain-Mechanik siehe [LaunchLab Vesting](/de/products/launchlab/vesting).

#### Gebührenverteilung nach Migration

Wenn der Token migriert:
- LP-Tokens werden zum CPMM-Pool geprägt.
- Lesen Sie die aktuelle Plattformkonfiguration vor dem Signieren. Vor dem Upgrade vom 2026-08-17 erzeugte `creatorScale` einen Creator Fee Key. Für Migrationen, die danach ausgeführt werden, wird `platformScale + creatorScale` zu einer plattformeigenen Fee Key Position und `burnScale` wird verbrannt. Bestehende Creator Fee Keys aus früheren Migrationen bleiben unverändert.
- Ihre Creator-Einnahmen nach der Migration stammen nur aus CPMM-Creator-Gebühren, wenn Sie der eingetragene CPMM-Pool-Creator bleiben und die ausgewählte Konfiguration diese aktiviert.

Siehe [Wie Creator-Gebühren funktionieren](/de/user-flows/how-creator-fees-work) für Details.

### Schritte

1. Wählen Sie den **LaunchLab**-Modus auf der Erstellungsseite.
2. Füllen Sie Token-Details aus (Name, Ticker, Logo, Beschreibung, Social-Links).
3. Legen Sie **Gesamtangebot** und **Kurvenverteilungsprozentsatz** fest.
4. Legen Sie Ihr **SOL-Fundraising-Ziel** fest (≥ 24 SOL).
5. Konfigurieren Sie **Vesting**, falls erforderlich (legen Sie Begünstigten-Wallets und Zeitplan fest).
6. Aktivieren Sie **Gebührenverteilung nach Migration**, wenn Sie einen Creator LP-Anteil möchten.
7. Geben Sie optional einen anfänglichen Kaufbetrag ein.
8. Überprüfen Sie die vollständige Zusammenfassung — Kurvenpreisbereich, Migrationsbedingung, LP-Aufteilung.
9. Klicken Sie auf **Create** und genehmigen Sie die Transaktion.

## Nach dem Start Ihres Tokens

### Überwachen Sie den Kurvenfortschritt

Die LaunchLab-Seite Ihres Tokens zeigt den Echtzeit-Fortschritt:
- % der verkauften Kurve.
- Gesammelte SOL vs. Migrationsziel.
- Aktueller Preis und Preischart.

LaunchLab greift nicht in Starts ein, die das Migrationsziel nicht erreichen. Überwachen Sie den Kurvenfortschritt und kommunizieren Sie klar mit Ihrer Community.

### Migration

Die Migration wird automatisch durch die erste Transaktion ausgelöst, die die Kurve über den Schwellenwert drückt — dies kann von jedem Benutzer aufgerufen werden (der Aufrufer erhält eine kleine Belohnung). Als Creator ist keine Aktion erforderlich.

Nach der Migration:
- Ein CPMM-Pool wird mit dem gesammelten SOL und den verbleibenden Kurven-Tokens als anfängliche Liquidität erstellt.
- Wenn Sie Gebühren nach der Migration aktiviert haben, wird ein **Fee Key NFT** zu Ihrem Wallet geprägt.
- Fordern Sie Creator-Gebühren vor der Migration von Ihrer Portfolio-Seite an.

### Fordern Sie Creator-Gebühren vor der Migration an

Wenn Ihre Plattform Creator-Gebühren während der Bonding Curve-Phase aktiviert, sammeln sie sich in einem Vault. Fordern Sie sie jederzeit von der **Portfolio**-Seite auf raydium.io an.

## Fallstricke, die Sie vermeiden sollten

| Fallstrick | Was zu tun ist |
|---|---|
| SOL-Ziel zu hoch setzen | Wählen Sie ein Ziel, das der Markt realistisch erreichen kann. |
| Vesting vor Bestätigung der Begünstigten überallokieren | Nicht zugeordnetes Vesting-Angebot ist nach der Migration dauerhaft unerreichbar. |
| Fee Key NFT unbeabsichtigt übertragen oder verbrennen | Gebührenanspruchsrechte gehen dauerhaft verloren. Behalten Sie das NFT im erstellenden Wallet oder einem Wallet, das Sie kontrollieren. |
| Keinen anfänglichen Kauf tätigen | Ohne frühen Kauf können Sniping-Bots alle frühen Tokens zu nahezu Nullkosten erfassen, was das Vertrauen der Community untergraben kann. |
