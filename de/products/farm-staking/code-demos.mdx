## Setup

Die Demos hier spiegeln Dateien in [`raydium-sdk-V2-demo/src/farm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/farm) wider. Das Bootstrap folgt der [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) des Demo-Repos:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Farm nach ID abrufen

Es gibt kein `raydium.farm.getFarmById`. Jede Farm-Demo beginnt mit dem API-Modul, das die normalisierte `FormatFarmInfoOut`-Form zurückgibt, die `deposit` / `withdraw` / `harvestAllRewards` alle verwenden:

```ts
const farmId = "CHYrUBX2RKX8iBg7gYTkccoGNBzP44LdaazMHCLcdEgS"; // RAY-USDC Farm

const farmInfo = (await raydium.api.fetchFarmInfoById({ ids: farmId }))[0];
if (!farmInfo) throw new Error("farm not found");

console.log("LP mint:", farmInfo.lpMint.address);
console.log("TVL:", farmInfo.tvl);
for (const r of farmInfo.rewardInfos) {
  console.log("  -", r.mint.address, r.mint.symbol);
}
```

`fetchFarmInfoById` nimmt eine **kommagetrennte Zeichenkette** von IDs und gibt ein Array zurück, sodass ein Aufruf ein ganzes Portfolio hydratisieren kann. Wenn Sie die rohen Kontoschlüssel statt der Anzeigeinformationen benötigen, gibt `raydium.api.fetchFarmKeysById({ ids })` die Vaults und Authority-PDAs zurück; das SDK ruft es intern für Sie in jedem Builder unten auf.

## LP-Token staken

Quelle: [`src/farm/stake.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/stake.ts)

```ts
// Die Demo staked den gesamten LP-Saldo des Wallets; jede BN in Raw-Einheiten funktioniert.
const amount = raydium.account.tokenAccountRawInfos.find(
  (a) => a.accountInfo.mint.toBase58() === farmInfo.lpMint.address,
)?.accountInfo.amount;

if (!amount || amount.isZero()) throw new Error("user does not have an LP balance");

const { execute } = await raydium.farm.deposit({
  farmInfo,
  amount,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Deposit tx:", txId);
```

Das SDK verwaltet die Vorabsettlement aller ausstehenden Rewards, sodass wenn dieser Wallet bereits einen Stake in dieser Farm hat, die Anweisung aufgelaufene Rewards in den ATAs des Benutzers in derselben Transaktion auszahlt.

## Nur Einfordern (Harvest)

Quelle: [`src/farm/harvest.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/harvest.ts)

`farmInfoList` ist ein **`Record` mit Farm-ID als Schlüssel**, kein Array, und der Builder gibt **mehrere** Transaktionen zurück — daher muss `execute` mit `sequentially: true` aufgerufen werden:

```ts
const farmIds = [farmId, "<ANOTHER_FARM_ID>"];
const farmInfos = await raydium.api.fetchFarmInfoById({ ids: farmIds.join(",") });

const { execute } = await raydium.farm.harvestAllRewards({
  farmInfoList: Object.fromEntries(farmInfos.map((f) => [f.id, f])),
  txVersion: TxVersion.V0,
});

const { txIds } = await execute({ sequentially: true });
console.log("harvest txs:", txIds);
```

Der Builder packt so viele Farms pro Transaktion wie das 1232-Byte-Limit erlaubt und teilt den Rest in Folgetransaktionen auf, weshalb er `txIds` statt einer einzelnen `txId` zurückgibt.

Für eine einzelne Farm ernten Sie mit der `amount: 0`-Idiomatik — das ist das, was [`src/farm/harvest.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/harvest.ts) tut, in jeder Version einschließlich v6:

```ts
const { execute } = await raydium.farm.withdraw({
  farmInfo,
  amount: new BN(0),        // 0 = harvest-only path
  txVersion: TxVersion.V0,
});
await execute({ sendAndConfirm: true });
```

## Eine v6-Farm erstellen

Quelle: [`src/farm/createAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/createAmmFarm.ts) und [`editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts)

`create` nimmt das **Pool-Info-Objekt** für den Pool, dessen LP-Mint gestaked wird (nicht ein bloßer Mint), und jeder Eintrag von `rewardInfos` ist ein `FarmRewardInfo`: `{ mint: PublicKey, perSecond: string, openTime: number, endTime: number, rewardType: "Standard SPL" | "Option tokens" }`. Zeiten sind **einfache Sekunden**, und `perSecond` ist ein **String**, keine `BN`. `programId` wird standardmäßig auf das v6-Programm gesetzt, daher übergeben Sie es selten.

```ts
import type { ApiV3PoolInfoStandardItem, FarmRewardInfo } from "@raydium-io/raydium-sdk-v2";
import { RAYMint } from "@raydium-io/raydium-sdk-v2";

// Der Pool, den Sie besitzen, dessen LP-Mint der Staking-Mint sein wird.
const poolInfo = (
  await raydium.api.fetchPoolById({ ids: "<POOL_ID>" })
)[0] as ApiV3PoolInfoStandardItem;
if (!poolInfo) throw new Error("pool not found");

const rewardMint = await raydium.token.getTokenInfo(RAYMint);

// Verwenden Sie Chain-Zeit, nicht Wanduhrzeit — das Programm validiert gegen erstere.
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);
const endTime  = openTime + 60 * 60 * 24 * 7; // 7 Tage

const rewardInfos: FarmRewardInfo[] = [
  {
    mint:       new PublicKey(rewardMint.address),
    perSecond:  "1",              // String, in Raw-Einheiten pro Sekunde
    openTime,                      // Sekunden, keine BN
    endTime,
    rewardType: "Standard SPL",   // "Option tokens" ist der einzige andere Wert
  },
];

const { execute, extInfo } = await raydium.farm.create({
  poolInfo,
  rewardInfos,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Farm:", extInfo.farmId.toBase58(), "createTx:", txId);
```

Wichtige Punkte:

- `perSecond` ist die Emissionsrate pro Sekunde in den **Raw**-Einheiten des Reward-Mints, übergeben als Dezimalstring. Das SDK packt es vor dem Versenden in die On-Chain-Festkommadarstellung.
- Das vollständige Budget (`perSecond × (endTime − openTime)`) muss in Ihrem Reward-ATA vorhanden sein — `create` verschiebt es atomar in den Reward-Vault.
- **Token-2022-Reward-Mints werden von den Farm-Buildern des SDK** in dieser SDK-Version **nicht unterstützt**; verwenden Sie einen einfachen SPL-Mint für Rewards.
- Sie können bis zu 5 Rewards in einem `create`-Aufruf seeden. Die Kontoliste wächst um `(reward_mint, reward_vault, sender_ata, token_program)` pro zusätzlichem Stream; beachten Sie das 1232-Byte-Transaktionsgrößenlimit. Für 4+ Rewards erstellen Sie mit 1–2 und verwenden Sie `addNewRewardsToken` in Folgetransaktionen.

## Einen neuen Reward-Stream hinzufügen

Es gibt kein `raydium.farm.setRewards`. Die zwei Builder, die die Rewards einer Farm ändern, sind `addNewRewardToken` / `addNewRewardsToken` (belegen einen freien Slot mit einem **neuen** Mint) und `restartReward` / `restartRewards` (reaktivieren einen Slot, dessen Stream beendet ist). Beide nehmen `FarmRewardInfo`-Objekte in genau der Form, die `create` verwendet.

```ts
import { USDCMint } from "@raydium-io/raydium-sdk-v2";

const added = await raydium.token.getTokenInfo(USDCMint);
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);

const { execute } = await raydium.farm.addNewRewardsToken({
  farmInfo,
  newRewardInfos: [
    {
      mint:       new PublicKey(added.address),
      perSecond:  "1",
      openTime,
      endTime:    openTime + 60 * 60 * 24 * 7,
      rewardType: "Standard SPL",
    },
  ],
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Das Delta-Budget (`perSecond × duration`) wird als Teil der Transaktion aus dem ATA des Zahlers gezogen. Die zugrunde liegende Anweisung kann einen Stream nicht verkürzen, kann `per_second` auf einem aktiven Stream nicht senken und kann den Reward-Mint eines Slots nicht ändern — um Mints zu tauschen, warten Sie auf `end_time` und verwenden Sie `addNewRewardsToken` auf einem freigegebenen Slot, oder erstellen Sie eine neue Farm.

<Tip>
  `restartRewards` und `addNewRewardsToken` geben jeweils einen Builder zurück, sodass eine einzelne Transaktion beide tun kann. [`src/farm/editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts) zeigt das Muster: `editFarmBuilder.builder.addInstruction(addNewRewardBuildData.builder.AllTxData)`, dann ein `versionBuild({ txVersion })`.
</Tip>

## Einen beendeten Stream neu starten

Quelle: [`src/farm/editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts)

`restartRewards` nimmt **`newRewardInfos`** (Plural, ein Array); `restartReward` ist die Einzelform und nimmt `newRewardInfo`. Das Feld `mint` ist `mint`, nicht `rewardMint`, und es muss einem Slot entsprechen, der bereits auf der Farm existiert — der Builder schlägt nach dem Slot nach Mint nach und gibt einen Fehler aus, wenn er fehlt.

```ts
import type { FarmRewardInfo } from "@raydium-io/raydium-sdk-v2";

// Reaktivieren Sie den bestehenden ersten Reward-Slot der Farm.
const existing = await raydium.token.getTokenInfo(farmInfo.rewardInfos[0].mint.address);
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);

const newRewardInfos: FarmRewardInfo[] = [
  {
    mint:       new PublicKey(existing.address),
    perSecond:  "1",
    openTime,
    endTime:    openTime + 60 * 60 * 24 * 14,
    rewardType: "Standard SPL",
  },
];

const { execute } = await raydium.farm.restartRewards({
  farmInfo,
  newRewardInfos,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

`restartRewards` ist **nur v6** — der Builder liest die Programm-ID der Farm und wirft einen Fehler für v3 / v5-Farms. Gültig nur, wenn der `reward_state` des Zielslots `== 2` (beendet) ist; der Aufrufer muss der `reward_sender` des Slots sein. Beachten Sie, dass `openTime >= endTime` client-seitig abgelehnt wird, bevor ein RPC erfolgt.

Eine frühere Überarbeitung dieser Seite zeigte ein `raydium_farm_v6::cpi::deposit`-Beispiel; es wurde gegen nichts kompiliert und wurde entfernt.
</Warning>

Farm v6 wurde zuletzt am 2024-05-13 bereitgestellt und ist aus Integrator-Sicht kein Anchor-Programm. Wenn Sie es von Ihrem eigenen On-Chain-Programm aus zusammensetzen müssen, konstruieren Sie die `Instruction` von Hand — leiten Sie die Kontoliste und Anweisungs-Diskriminatoren unabhängig ab (aus den TypeScript-Layouts des SDK unter `raydium-sdk-V2/src/raydium/farm/`, oder durch Dekodieren echter Transaktionen), und `invoke_signed` es. Siehe [`sdk-api/rust-cpi`](/de/sdk-api/rust-cpi#farm-v6) für dieses Verfahren.

Welche Route Sie auch nehmen, der `remaining_accounts`-Schwanz muss die aktiven Reward-Slots der Farm 1-zu-1 entsprechen (Paare von `reward_vault_i`, `user_reward_ata_i` in Indexreihenfolge). Das Weglassen oder Falschordnen dieser führt zu einer stillen Fehlbuchung — das Programm überträgt den falschen Betrag.

## Fallstricke

- **Vergessen, vor dem Abheben einzufordern.** Harmlos — `Withdraw` settlement ausstehende Rewards zuerst. Aber wenn Ihre UI „Einfordern" separat von „Abheben" anzeigt, könnte der Benutzer denken, dass nach einem `Withdraw` noch etwas zu fordern ist. Das ist nicht der Fall; alles bis zu diesem Punkt Aufgelaufene wurde ausgezahlt.
- **`total_staked = 0` während Emissionen.** Emissionen, die aufgelaufen sind, während nichts gestaked war, werden verfallen (die `reward_per_share`-Update-Formel dividiert durch 0 und das Programm überspringt das Update). Für Programme mit geplanter `open_time` führen Sie einen „Seed-Stake" zur open_time aus, um dies zu vermeiden.
- **Token-2022-Transfergebühren.** Auf v6-Farms mit Token-2022-Reward-Mints gilt die Transfergebühr bei der Emission (Vault → Benutzer). Berücksichtigen Sie dies in APR-Angeboten.
- **Kleine `per_second` auf v5.** v5s `u64`-Rate bedeutet, dass jede `per_second < 1` Token-Einheit pro Sekunde (auf Mints mit ≥9 Dezimalstellen ist dies oft die gewünschte Rate) nicht ausgedrückt werden kann — die Stream-Rate rundet auf 0 und die Farm emittiert nichts. Verwenden Sie v6.
