## 前置條件

執行一次：

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

你需要：

- **Node 18+** 且支援 ESM（`package.json` 中有 `"type": "module"` 或使用 `.mjs` 副檔名）。
- **Solana 金鑰對** 位於 `~/.config/solana/id.json`（或任何位置 — 設定 `KEYPAIR`）。參閱 [`solana-fundamentals/toolchain`](/zh-Hant/solana-fundamentals/toolchain#solana-cli) 以產生金鑰對。
- **已充值的錢包。** 交換指令碼只需要輸入金額加上小額緩衝 — CPMM 交換的網路費用約 0.0015 SOL（參閱 [`reference/fee-comparison`](/zh-Hant/reference/fee-comparison#network-fees-per-typical-operation)），如果交換需要為你開設代幣帳戶則需一次性租金。建立池的成本更高：CPMM 指令碼本身在種子流動性或租金之前需要約 0.15 SOL 的一次性池建立費用。在充值錢包前，請查看各指令碼的設定部分以了解目前的費用。
- **RPC URL。** 免費公開 RPC 適合測試；若要進行超過煙霧測試的操作，請使用付費提供商。

每個 shell 工作階段設定一次：

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **叢集。** 三個指令碼預設使用主網。Devnet 需要 `RPC_URL=https://api.devnet.solana.com` 加上指令碼內的 `cluster: "devnet"` — 對於兩個池建立指令碼，這不是唯一的變更；詳見各指令碼的設定部分以了解還需要改變什麼。請注意 devnet 上的池種子流動性稀少；預期需要自行鑄造測試代幣。
</Info>
