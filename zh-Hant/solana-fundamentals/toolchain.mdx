本文件中的所有內容都假設你已有可用的 Solana 開發工具鏈。本頁列出工具、截至 2026 年 9 月已知可與 Raydium 搭配使用的版本，以及特定的設置注意事項。在執行後續章節中的任何程式碼範例之前，請先從這裡開始。

**有兩組版本需要注意，它們並不相同。** 若要*建構或分叉* Raydium 程式，你需要它們所固定的確切工具鏈 — Rust 1.91.0、Agave 3.1.10、Anchor 1.0.2（截至 2026-09-09 升級）。若要從 TypeScript 或 Python *整合*已部署的程式，你只需要足夠新的用戶端程式庫來與其通訊，版本固定是建議性的。下面每個部分都會說明涵蓋的是哪種情況。

## 核心工具

### Solana CLI

與 Solana 叢集互動的標準命令列介面 — 錢包管理、RPC 呼叫、程式部署。

安裝：

```bash
# Raydium 程式建構和測試所用的版本
sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.10/install)"

# 或追蹤一個頻道而不是標籤
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

驗證：

```bash
solana --version   # → solana-cli 3.1.10 (... client:Agave)
```

<Note>
  **安裝主機已移動。** `release.solana.com` 屬於 Solana Labs；用戶端現在由 Anza 維護，稱為 **Agave**，版本發佈來自 `release.anza.xyz`。自我更新二進位檔是 `agave-install`（`solana-install` 保留為舊版別名），所以 `agave-install update` 和 `agave-install init <version>` 是目前的用法。Solana 自己的文件也提供了一個一行安裝程式，可同時拉取 CLI、Rust 和 Anchor：

  ```bash
  curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
  ```

  該安裝程式追蹤自己的當前版本概念，可能會給你一個與 Raydium 程式所固定的 Anchor 不同的版本 — 之後請檢查 `anchor --version`。
</Note>

為主網設定：

```bash
solana config set --url https://api.mainnet-beta.solana.com
solana config set --keypair ~/.config/solana/id.json
solana-keygen new                           # 如果沒有錢包，建立一個
solana address                              # 你的公鑰
```

對於 Raydium 測試，你幾乎總是需要一個已資助的 devnet 錢包：

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2                            # 2 SOL 用於測試
```

### SPL Token CLI

SPL Token / Token-2022 操作的官方 CLI — 建立 mint、鑄造代幣、轉移。

安裝（包含在 Solana CLI 中）：

```bash
spl-token --version
```

常見操作：

```bash
spl-token create-token                                  # 建立 SPL Token mint
spl-token create-token --program-id TOKEN_2022 ...      # 建立 Token-2022 mint
spl-token create-account <MINT>                         # 建立 ATA
spl-token mint <MINT> 1000                              # 鑄造 1000 個代幣到你的 ATA
spl-token transfer <MINT> 100 <RECIPIENT>               # 轉移 100 個
spl-token display <ACCOUNT_OR_MINT>                     # 檢查
```

### Anchor CLI

用於取得 Raydium IDL、建構用戶端和驗證程式。

安裝：

```bash
cargo install --git https://github.com/solana-foundation/anchor avm --locked --force
avm install 1.0.2
avm use 1.0.2
anchor --version   # → anchor-cli 1.0.2
```

<Note>
  **Anchor 已移動儲存庫和主要版本。** 標準儲存庫現在是 `github.com/solana-foundation/anchor`（之前是 `coral-xyz/anchor`），Anchor 1.0 是 Raydium 程式使用的第一個發佈線 — CPMM 和 LaunchLab 都在 2026-09-09 升級時固定 `anchor-lang`/`anchor-spl` `=1.0.2`，從 `0.32.1` 升級。`avm` 可以保存多個版本；`avm use 1.0.2` 是讓 `anchor build` 重現 Raydium 工件的方式。Anchor 1.1 和 1.2 存在且可以為你自己的程式建構，但針對與目標程式所固定的 `anchor-lang` 次版本不同的版本編譯的 CPI crate 將無法連結 — 見 [`sdk-api/rust-cpi`](/zh-Hant/sdk-api/rust-cpi)。
</Note>

常見操作：

```bash
anchor idl fetch <PROGRAM_ID> -o program.idl.json       # 取得鏈上 IDL
anchor idl init -f idl.json <PROGRAM_ID>                # 上傳 IDL
anchor build                                             # 從原始碼建構程式
```

## TypeScript 設置

Raydium 的主要整合路徑。

### 套件

```bash
npm install \
  @solana/web3.js \
  @solana/spl-token \
  @anchor-lang/core \
  @raydium-io/raydium-sdk-v2 \
  bn.js \
  decimal.js
```

截至 2026 年 9 月已知可一起使用的版本：

| 套件 | 版本 | 備註 |
|---------|---------|------|
| `@solana/web3.js` | `^1.95` | 1.x API。`2.x` / `3.x` 是不同的、不相容的 API 表面；Raydium SDK 以 1.x 為目標。 |
| `@solana/spl-token` | `^0.4.15` | 0.4.15 是公開 `createUnwrapLamportsInstruction` 的版本 — 見[可回收租金](/zh-Hant/solana-fundamentals/rent-and-reclaimable-rent)。 |
| `@anchor-lang/core` | `^1.0`（目前解析為 `1.2.0`） | Anchor 1.x TypeScript 用戶端。Raydium 自己的儲存庫精確固定為 `1.0.2`；用於客戶端時任何 1.x 都可以，但如果你想與他們的測試套件一致，請固定 `1.0.2`。 |
| `@raydium-io/raydium-sdk-v2` | `0.2.64-alpha` | 本文件中每個程式碼示例使用的固定版本。 |

<Note>
  **`@coral-xyz/anchor` 已凍結；套件現在是 `@anchor-lang/core`。** `@coral-xyz/anchor` 在 Anchor 移出 Coral 時停留在 `0.32.1`。Anchor 1.x 發佈為 `@anchor-lang/core`，Raydium 自己的程式儲存庫在 2026-09-09 升級時將其測試套件切換到了它。你實際使用的匯入保持不變 — `import { Program, BN, AnchorProvider } from "@anchor-lang/core"` — 所以遷移只是套件重新命名加上鎖定檔案更新。

  如果你正在從 `0.3x` 遷移，有兩個行為注意事項：`.accounts({...})` 現在只接受 Anchor 無法自行解析的帳戶，所以傳遞完整集合的建構器應改為呼叫 `.accountsPartial({...})`；而 `@anchor-lang/core/dist/cjs/utils/token` 是 `ASSOCIATED_PROGRAM_ID` 等幫助程式移動到的位置。
</Note>

### 最小指令碼

```ts
import { Connection, Keypair } from "@solana/web3.js";
import { Raydium } from "@raydium-io/raydium-sdk-v2";

const connection = new Connection("https://api.mainnet-beta.solana.com", "confirmed");
const owner      = Keypair.fromSecretKey(/* your key */);

const raydium = await Raydium.load({
  connection,
  owner,
  cluster:      "mainnet",
  disableFeatureCheck: true,
});

// `ids` 是逗號分隔的列表，呼叫會傳回陣列
const [poolInfo] = await raydium.api.fetchPoolById({ ids: "..." });
console.log(poolInfo);
```

見 [`sdk-api/typescript-sdk`](/zh-Hant/sdk-api/typescript-sdk) 以取得完整 SDK 參考。

## Rust 設置

用於 CPI 整合和鏈上程式。

### 工具鏈

```bash
rustup install 1.91.0           # Raydium 程式所固定的版本
rustup default 1.91.0
rustup component add rustfmt clippy
agave-install init 3.1.10       # 包含 SBF 工具鏈
```

使用 `cargo build-sbf` 建構程式（舊的 `cargo build-bpf` 用法已移除）。

### Raydium CPI 整合的程式 Cargo.toml

```toml
# CPMM 整合（Anchor 1.0）
[dependencies]
anchor-lang     = "=1.0.2"
anchor-spl      = "=1.0.2"
raydium-cp-swap = { git = "https://github.com/raydium-io/raydium-cp-swap", branch = "chore/upgrade-anchor", features = ["cpi"] }
```

```toml
# CLMM 整合 — 仍為 Anchor 0.32，所以需要自己的 crate
[dependencies]
anchor-lang  = "=0.32.1"
anchor-spl   = "=0.32.1"
raydium-clmm = { git = "https://github.com/raydium-io/raydium-clmm", branch = "master", features = ["cpi"] }
```

使用 `=` 將 `anchor-lang` 和 `anchor-spl` 固定到目標程式所固定的版本。截至 2026-09，CPMM 固定 `=1.0.2`，CLMM 仍固定 `=0.32.1`，所以**單一 crate 無法 CPI 到兩者** — 見 [`sdk-api/rust-cpi`](/zh-Hant/sdk-api/rust-cpi#cargo-dependencies)。

`"cpi"` 功能匯入 `cpi` 模組及 CPI 幫助程式（所以你可以 `raydium_cp_swap::cpi::swap_base_input(...)`）。見 [`sdk-api/rust-cpi`](/zh-Hant/sdk-api/rust-cpi)。

## Python 設置

次要整合路徑 — 對機器人開發者常見。

### 套件

```bash
pip install solders solana anchorpy
```

版本：

| 套件 | PyPI 名稱 | 版本 |
|---------|-----------|---------|
| `solders` | `solders` | ≥0.29 |
| solana-py | `solana` | ≥0.40 |
| `anchorpy` | `anchorpy` | ≥0.21 |

<Note>
  兩個命名陷阱。RPC 用戶端匯入為 `solana`，但專案稱為 **solana-py** — `pip install solana-py` 安裝不了任何有用的東西。而且 **PyPI 上沒有 `raydium-py` 套件**：社群 Raydium 幫助程式是你克隆的儲存庫，[`AL-THE-BOT-FATHER/raydium_py`](https://github.com/AL-THE-BOT-FATHER/raydium_py)，不是已發佈的發行版。本頁的早期版本列出了一個 `pip install raydium-py` 行，但它從未有效。
</Note>

### 最小指令碼

```python
from solana.rpc.async_api import AsyncClient
from solders.keypair import Keypair
from anchorpy import Provider, Wallet, Program

async def main():
    conn = AsyncClient("https://api.mainnet-beta.solana.com")
    owner = Keypair()
    wallet = Wallet(owner)
    provider = Provider(conn, wallet)

    # 載入 IDL 和程式
    with open("cpmm.idl.json") as f:
        idl = json.load(f)
    program = Program(idl, CPMM_PROGRAM_ID, provider)

    pool = await program.account["PoolState"].fetch(pool_id)
    print(pool)
```

## RPC 端點

公開主網 RPC（`api.mainnet-beta.solana.com`）受到嚴格速率限制，在任何負載下都會節流。對於非平凡的使用，取得私有端點：

| 提供者 | 備註 |
|----------|-------|
| Helius | 最受歡迎；慷慨的免費層。 |
| Triton | 企業級；高級定價，穩定。 |
| QuickNode | 穩定；次秒級延遲。 |
| 你自己的 RPC 節點 | 成本約 \$500/月硬體；完全控制。 |

設定：

```ts
const connection = new Connection("https://mainnet.helius-rpc.com/?api-key=...");
```

某些 RPC 操作需要擴展功能：

- `getProgramAccounts` — 無限制掃描成本高；某些提供者會限制或按掃描收費。
- `getPriorityFeeEstimate` — Helius 特定端點；其他提供者有等效項。
- `geyser` / WebSocket 串流 — 低延遲機器人需要；並非所有提供者都公開。

## Devnet 和 localnet

### Devnet

Solana 的公開測試叢集。Raydium 有部分 devnet 部署：

- 存在一些 CPMM 池用於測試。
- AMM v4 有歷史 devnet 池。
- CLMM 有幾個示例池。
- Farm v6 已部署。

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2
```

SDK 透過 `cluster: "devnet"` 支援 devnet：

```ts
const raydium = await Raydium.load({ connection, owner, cluster: "devnet" });
```

**注意**：devnet 池流動性稀薄，可能有過時狀態。不要依賴 devnet 進行價格發現；僅將其用於建構和測試指令流。

### 使用分叉主網狀態的 Localnet

為了進行逼真的測試，將主網狀態分叉到本地驗證器：

```bash
solana-test-validator \
  --url https://api.mainnet-beta.solana.com \
  --clone CPMMoo8L3F4NbTegBCKVNunggL7H1ZpdTHKxQB5qKP1C \
  --clone CAMMCzo5YL8w4VFF8KVHrK22GGUsp5VTaW7grrKgrWqK \
  --clone <SOME_POOL_ID> \
  --clone <SOME_MINT_ID>
```

這會將特定程式/帳戶狀態克隆到 localhost，你可以在那裡自由交易。理想用於：

- 針對真實 Raydium 程式單元測試你的 CPI 整合。
- 使用修改的參數重放交易以進行除錯。
- 使用大型合成交易量進行壓力測試。

Raydium 團隊在主網部署前廣泛使用分叉 localnet 進行迴歸測試。

## 環境衛生

### 按用途分離錢包

- **開發錢包**：持有測試網 SOL，用於建構。
- **生產錢包**：持有真實 SOL，僅用於部署/多簽提交。
- **機器人熱錢包**：小餘額、狹窄權限。

金鑰不應硬編碼。使用環境變數或密鑰管理器。

### `.env` 模式

```
# .env（未提交）
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=...
WALLET_PATH=/Users/you/.config/solana/id.json
```

```ts
import { config } from "dotenv";
config();

const connection = new Connection(process.env.SOLANA_RPC_URL!);
```

### 版本固定

鎖定所有 Solana 生態系統依賴項。生態系統發展迅速；`@solana/web3.js` 的次版本升級以前曾引入破壞性變更。虔誠地使用 `package-lock.json` / `Cargo.lock`。
