## 版本

<Update label="2026-08-17" description="LaunchLab：僅限 CPMM 的啟動和平台設定控制">
  新的啟動初始化現在需要 CPMM，而舊版 AMM v4 綁定的狀態仍可遷移。在此版本之前，`creator_scale` 會產生創作者擁有的費用金鑰；升級後執行的 CPMM 遷移會將 `platform_scale + creator_scale` 合併為一個平台擁有的費用金鑰份額。平台也可以使用自己的 `PlatformAllowConfig` PDA 限制啟動，遷移建構者必須附加兩個 CPMM 支援鑄幣 PDA。

  [閱讀完整項目 →](/zh-Hant/reference/changelog/2026-08-17-launchlab-cpmm-only-platform-config)
</Update>

<Update label="2026-08-17" description="CLMM：受限發行者頭寸 NFT 凍結">
  新的 CLMM 頭寸 NFT 鑄幣使用其池作為凍結權限，但其代幣帳戶預設保持未凍結。凍結僅在 `OpenPositionV2` 或 `OpenPositionWithToken22Nft` 時發生，當任一基礎保管庫鑄幣的凍結權限與受限發行者清單相符時。相符的頭寸無法轉移或更改擁有者，但仍可管理流動性。其 `ClosePosition` 呼叫必須附加池，以便 CLMM 可以原子性地解凍、燒毀和關閉。現有頭寸保持不變。

  [閱讀完整項目 →](/zh-Hant/reference/changelog/2026-08-17-clmm-restricted-position-nft-freeze)
</Update>

<Update label="2026-08-17" description="CPMM：無許可創作者費用收集">
  新增的 `CollectCreatorFeePermissionless` 指令讓任何支付者掃除所有累積的創作者費用，同時將受益人和兩個代幣目的地限制為 `PoolState.pool_creator` 和創作者的規範 ATA。原始創作者簽署的路徑保持不變。`CreatePermissionPda` 也接受專用的授予權限，而 `ClosePermissionPda` 仍為僅限管理員。

  [閱讀完整項目 →](/zh-Hant/reference/changelog/2026-08-17-cpmm-permissionless-creator-fee-collection)
</Update>

<Update label="2026-07-30" description="CLMM：許可多池和限價單凍結帳戶防護">
  兩個新增的、向後相容的 CLMM 程式更新。`CreatePermissionedPool` 將用戶端提供的非零 `seed_index` 折疊到池 PDA 種子中，讓白名單操作者（持有 `Permission` PDA 的操作者）為每個 `(config, mint0, mint1)` 建立多個池——因此池 ID 不再是交易對的規範。新的管理員指令 `CreatePermissionPda` / `ClosePermissionPda` 管理這些授予，`PoolState` 獲得 `seed_index` 欄位（從填充中提取，無大小變更）。另外，`OpenLimitOrder` 現在接受輸出端帳戶，並拒絕其輸入或輸出代幣帳戶被凍結的訂單（`NotApproved`）。

  [閱讀完整項目 →](/zh-Hant/reference/changelog/2026-07-30-clmm-permissioned-pools)
</Update>

<Update label="2026-07-22" description="AMM v4：移除 OpenBook / Serum 依賴">
  AMM v4 移除其長期休眠的 OpenBook/Serum 依賴、所有訂單簿 CPI 和已廢棄的造市指令。`SwapBaseIn` / `SwapBaseOut`、`Deposit` 和 `Withdraw` 保持其佈局（移除的市場帳戶現在被忽略，不驗證）；**硬性破壞性** `WithdrawPnl`（17 → 10，無相容性）和 `SetParams`（帳戶減少 + 重新編號 `param`）；`Initialize`、`PreInitialize`、`MonitorStep`、`MigrateToOpenBook`、`WithdrawSrm`、`SimulateInfo`、`AdminCancelOrders` 不再可呼叫。鏈上帳戶佈局和錯誤代碼保持穩定；將交換遷移到 V2 進入點。

  [閱讀完整項目 →](/zh-Hant/reference/changelog/2026-07-22-amm-v4-openbook-removal)
</Update>

<Update label="2026-06-22" description="穩定 AMM：移除已廢棄的 OpenBook（市場）代碼">
  穩定 AMM 移除其長期休眠的 OpenBook 造市帳戶和代碼。較小的 `SwapBaseIn` / `SwapBaseOut`（18 → 9）、`Deposit`（14 → 12）和 `Withdraw`（21/22 → 12）佈局（舊佈局仍相容）；**硬性破壞性** `WithdrawPnl` 變更（16 → 10，無相容性）；推薦費已停用；以及簡化的僅保管庫池資產公式。大多數其他穩定指令不再可呼叫。

  [閱讀完整項目 →](/zh-Hant/reference/changelog/2026-06-22-stable-amm-openbook-cleanup)
</Update>

<Update label="2026-05-18" description="CLMM：限價單、單邊費用、動態費用">
  三個可選的、向後相容的 CLMM 功能：一級限價單（具有 `limit_order_admin` 結算保管人）、單邊費用收集（`CollectFeeOn`）和波動率追蹤動態費用。新增 `CreateCustomizablePool`、`PoolState` 重塑（**索引器破壞性變更**）、新的 `TickState` 欄位、十一個新的錯誤代碼（具有數值偏移），以及匹配的 SDK / API 新增。

  [閱讀完整項目 →](/zh-Hant/reference/changelog/2026-05-18-clmm-limit-orders)
</Update>
