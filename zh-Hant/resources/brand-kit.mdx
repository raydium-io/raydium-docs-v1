## 名稱和大小寫

| 形式 | 用途 |
|---|---|
| **Raydium** | 協議名稱。始終使用標題大小寫。不要寫成 `raydium` 或 `RAYDIUM`。 |
| **Raydium Protocol** | 在需要與其他背景下的 Raydium 名稱區分時可使用（例如化學元素、電子遊戲等）。 |
| **$RAY** 或 **RAY** | Raydium 的原生 SPL 代幣。在行銷文案中使用美元前綴，在技術或表格背景中使用純 `RAY`。 |
| **Raydium AMM v4** / **Raydium CPMM** / **Raydium CLMM** / **LaunchLab** | 產品名稱。LaunchLab 為一個單詞，L 大寫。 |
| **Burn & Earn** | 一個結構，使用 & 符號，兩個名詞都大寫。 |

不要寫成 `Raydium DEX`、`Ray protocol` 或 `Raydiums`（無複數形式）。該協議是單數名詞。

## 標誌

Raydium 標誌有兩種形式：

- **文字標誌** — 完整的「Raydium」字體鎖定。在標題、新聞稿和任何需要名稱可讀的背景中使用。
- **符號標誌** — 獨立的單字母標誌。在應用程式圖示、網站圖示和受限空間（頭像、社交媒體頭像）中使用，其中文字標誌在可讀大小下無法容納。

### 淺色和深色版本

每種形式有兩種配色：

| 檔案 | 背景 | 使用時機 |
|---|---|---|
| `logo-light.svg` | 深色背景 | 深色 UI 介面上的主要放置位置。 |
| `logo-dark.svg` | 淺色背景 | 淺色 UI 介面上的主要放置位置。 |
| `mark-light.svg` | 深色背景 | 深色介面上的符號專用。 |
| `mark-dark.svg` | 淺色背景 | 淺色介面上的符號專用。 |

所有資產均為向量 SVG 格式。盡可能使用 SVG。僅在最終渲染大小時才柵格化為 PNG（避免縮放 PNG）。

### 清晰空間

在標誌周圍保持清晰空間，其大小等於 Raydium「R」字元的高度。不要在此邊距內用文字、圖示或圖形擁擠標誌。

### 最小尺寸

文字標誌：螢幕上不低於 **120 px** 寬，或列印時不低於 **20 mm**。
符號：螢幕上不低於 **24 px** 寬，或列印時不低於 **6 mm**。

低於這些閾值時，標誌會失去清晰度，合作夥伴應改用替代形式（例如在空間受限時用符號替換文字標誌）。

## 色彩調色板

Raydium 識別系統以紫羅蘭色主色為中心，配合更深和更淺的變體用於狀態、深度和對比。

| 角色 | 十六進位 | RGB | 用途 |
|---|---|---|---|
| **主色** | `#8C6EFF` | 140 / 110 / 255 | 主要品牌色。行動呼籲、連結、關鍵強調。 |
| **淺色** | `#A88BFF` | 168 / 139 / 255 | 懸停狀態、次要強調、淺色主題背景。 |
| **深色** | `#5E3BE1` | 94 / 59 / 225 | 活躍/按下狀態、深色主題強調、深度。 |

支援中性色：

| 角色 | 十六進位 | 用途 |
|---|---|---|
| **前景（淺色）** | `#0A0A0F` | 淺色介面上的正文。 |
| **前景（深色）** | `#FAFAFA` | 深色介面上的正文。 |
| **表面（淺色）** | `#FFFFFF` | 頁面背景、淺色主題。 |
| **表面（深色）** | `#0F0F1A` | 頁面背景、深色主題。 |
| **邊框** | `#E5E5EB`（淺色）/ `#1F1F2E`（深色） | 卡片和分隔線邊框。 |

不要重新著色標誌。文字標誌和符號始終以淺色或深色主要配色呈現 — 永遠不要著色、永遠不要漸層替換、永遠不要套用品牌色。

## 字體

文件和網站使用 **Inter** 作為 UI 和正文。標題使用 Inter 的粗體重量（600–800）。程式碼區塊使用 **JetBrains Mono** 或任何等寬字體備選。

| 樣式 | 字族 | 字重 | 用途 |
|---|---|---|---|
| 顯示 / H1 | Inter | 800 | 頁面標題。 |
| H2–H4 | Inter | 700 | 章節標題。 |
| 正文 | Inter | 400 | 段落文字。 |
| 強調 | Inter | 600 | 內嵌強調、粗體文字。 |
| 程式碼 | JetBrains Mono | 400–500 | 內嵌 `code` 和程式碼區塊。 |

Inter 是開放授權的，可從 [rsms.me/inter](https://rsms.me/inter) 取得。

## 標誌的做法和禁忌

**應該做：**

- 使用文件儲存庫 `/logo/` 目錄中的官方 SVG 主檔案。
- 保持清晰空間和最小尺寸。
- 僅在文字標誌和符號視覺平衡時配對使用（不要並排顯示衝突大小的兩者）。
- 在具有足夠對比度的背景上渲染 — 在深色背景上使用淺色主檔案，在淺色背景上使用深色主檔案。

**不應該做：**

- 重新著色標誌。沒有紫色文字標誌、沒有彩虹、沒有超出提供的淺色/深色之外的單色變體。
- 扭曲寬高比（無拉伸、無傾斜）。
- 添加投影、輪廓、發光或其他效果。
- 將標誌放在繁忙的背景圖像上，而不在下方放置保持對比度的純色面板。
- 裁剪標誌（不要只顯示從文字標誌裁剪出的「R」— 改用符號標誌）。
- 使用標誌暗示對 Raydium 未正式合作的產品的認可。在中立背景中使用「Powered by Raydium」或「Integrated with Raydium」徽章，不暗示任何審查。

## 「Powered by Raydium」徽章

如果你的整合使用 Raydium 作為路由來源或流動性場所，簡單的文字或徽章歸屬是受歡迎的：

```text
Powered by Raydium
Integrated with Raydium
Liquidity via Raydium
```

這些措辭已預先批准。放置在整合的定價、交換或池介面附近 — 不要放在顯著位置，這會暗示正式合作。

如果你是聚合器或錢包通過 Raydium 進行路由，並希望獲得更顯著的歸屬，請在發佈前通過 Discord（`#partnerships`）聯繫團隊。
