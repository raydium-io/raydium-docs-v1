<Info>
  LaunchLab 是 Raydium 的一級市場啟動平台。專案將其代幣供應存入聯合曲線；買家使用 SOL（或其他報價幣種）與曲線交易；當達到畢業閾值時，曲線的資產會自動遷移到 CPMM 池，代幣變成自由交易。本頁將從專案方的角度逐步介紹整個流程。
</Info>

## 你需要的東西

- **代幣鑄造** — 你想要銷售的代幣。必須是新鑄造的，具備：
  - 完整供應量鑄造到你的錢包（以便存入曲線）。
  - 在啟動前撤銷鑄造權限（否則曲線價格可能被新鑄造的代幣操縱）。
- **元數據** — 名稱、符號、圖像、社交連結。Metaplex 元數據或類似。
- **錢包** — 約 1 SOL 用於創建租金 + 金庫資金 + 優先費用（畢業本身由畢業者支付，不是你）。
- **決定**：
  - 曲線類型（二次方 vs 虛擬儲備 CPMM）。
  - 畢業閾值。
  - LP 處置政策（銷毀 / 鎖定 / 轉給創建者）。
  - 初始價格和上限。

## 曲線選擇

LaunchLab 支援兩種曲線族：

### 二次方（`curve_type = 0`）

價格隨著銷售供應量二次方增長。經典的「公平啟動」感覺 — 早期買家獲得價格優勢，後期買家支付更多，價格平穩加速。

```
price(s) = a * s^2 + b * s + c
```

其中 `s` 是銷售供應量。通常 `a > 0`（凸）。初始價格和畢業價格之間的差價由 `a, b, c` 和上限決定。

最適合：新奇啟動、迷因、社區驅動的專案。

### 虛擬儲備 CPMM（`curve_type = 1`）

使用*虛擬*儲備模擬恆定乘積 AMM — 曲線的行為像 CPMM，其中 `x * y = k`，但池開始時使用從不提取的合成代幣進行種子填充。

```
price = virtual_quote_reserve / virtual_base_reserve
```

當買家購買時，`virtual_base_reserve` 減少，`virtual_quote_reserve` 增加 — 曲線看起來與畢業後的 CPMM 完全相同。更平順的交接。

最適合：希望畢業後價格連續性可預測的啟動。

## UI 逐步說明

在 [raydium.io/launchpad/create](https://raydium.io/launchpad/create)：

1. **代幣。** 貼上鑄造地址。UI 會獲取元數據並顯示。
2. **曲線類型。** 選擇二次方或虛擬 CPMM；UI 會為每種顯示價格圖表預覽。
3. **畢業閾值。** 預設：曲線在所有 `total_base_supply` 銷售後結束。替代方案：在特定 `graduation_quote_amount` 結束（例如 85 SOL）。
4. **報價幣種。** SOL（預設）、USDC 或任何其他幣種。SOL 是標準。
5. **LP 處置政策：**
   - **銷毀** — LP 代幣在畢業時發送到無法使用的地址。創建者無法提取流動性；使用者永遠信任該池。
   - **鎖定** — LP 代幣發送到時間鎖定的託管，持續 `lock_duration`。
   - **轉給創建者** — LP 代幣發送給創建者。最靈活，最不信任最小化。

   最受尊敬的啟動使用銷毀。

6. **檢查。** UI 總結：預期價格範圍、曲線售完時的初始籌資、畢業 CPMM 設定。
7. **簽署。** 一筆交易創建啟動狀態 + 基礎金庫 + 報價金庫，將 `total_base_supply` 從你的錢包轉移到基礎金庫。

## 程式化逐步說明

曲線形狀、報價幣種、籌資目標和 LP 處置政策**不是**參數 — 它們來自你綁定的 `GlobalConfig` 和你的啟動運行的 `PlatformConfig`。你傳遞的是鑄造的身份、要綁定的設定，以及可選的首次購買：

```ts
import {
  Raydium,
  TxVersion,
  LAUNCHPAD_PROGRAM,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";
import BN from "bn.js";

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });
const programId = LAUNCHPAD_PROGRAM;

// 你生成基礎鑄造的密鑰對並用它簽署。
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// 綁定一個設定：(報價幣種, curve_type, 索引)。這是固定曲線
// 形狀、報價幣種和籌資目標的方式。
const configId   = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
const configInfo = LaunchpadConfig.decode(configData!.data);
const mintBInfo  = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "My New Token",
  symbol: "MYNEW",                    // 10 個字元或更少
  uri:    "https://example.com/metadata.json",
  migrateType: "amm",                 // "amm" | "cpmm"

  configId,
  configInfo,
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  createOnly: true,                   // true = 建立鑄造而不進行首次購買
  buyAmount:  new BN(1000),
  slippage:   new BN(100),            // 100 = 1%

  extraSigners: [pair],               // 基礎鑄造密鑰對必須簽署
  txVersion: TxVersion.V0,
  computeBudgetConfig: { units: 400_000, microLamports: 50_000 },
});

// createLaunchpad 返回多筆交易 - 按順序運行。
const { txIds } = await execute({ sequentially: true });
console.log("Pool ID:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
```

`raydium.api.fetchLaunchConfigs()` 列出可用的設定及其預設供應、銷售金額和籌資目標，因此你可以在使用者簽署前向他們展示給定設定的含義。完整註解版本，包括 Token-2022 變體：[`products/launchlab/code-demos`](/zh-Hant/products/launchlab/code-demos#create-a-launch)。

## 畢業前監控

透過 API 追蹤活動：

LaunchLab 有自己的 API 主機，與 `api-v3.raydium.io` 分開：

```ts
// 鑄造級別資訊，按基礎鑄造鍵入（批次用逗號分隔）。
const r = await fetch(
  `https://launch-mint-v1.raydium.io/get/by/mints?ids=${mintA.toBase58()}`,
).then((r) => r.json());
console.log(r.data.rows[0]);

// 也可用：同一主機上的 /main/configs（設定列表），以及
// https://launch-history-v1.raydium.io/kline 和 /trade 用於價格和成交。
```

或直接讀取鏈上狀態。池 ID 是 `(programId, mintA, mintB)` 的 PDA：

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log({
  status:      poolInfo.status,
  baseSold:    poolInfo.realA.toString(),
  totalSellA:  poolInfo.totalSellA.toString(),
  quoteRaised: poolInfo.realB.toString(),
  raiseTarget: poolInfo.totalFundRaisingB.toString(),
});
```

進度最好用**價格**術語表示，而不是籌資的分數，因為曲線是非線性的。演示倉庫的 [`getFinishRate.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/getFinishRate.ts) 使用 `Curve.getPrice`、`Curve.getPoolEndPriceReal` 和 `Curve.getPoolInitPriceByPool` 做到這一點：

```
finishRate = (currentPrice − initPrice) / (endPrice − initPrice)   // 限制為 1
```

### 要監控的指標

- **銷售穿透率**：銷售的基礎百分比。畢業閾值通常在銷售 80–100% 時。
- **當前價格**：從當前 `baseSold` 的曲線衍生。
- **獨特買家**：透過索引器的不同付款人計數。
- **買賣比率**：早期啟動看到重買壓力然後放緩。

如果 24 小時後銷售穿透率 `<10%`，考慮行銷是否充分。LaunchLab 不會拯救宣傳不足的啟動。

## 畢業

畢業是一筆單獨的交易，它**不是**任何人都可以呼叫的：`MigrateToCpswap` 和舊版 `MigrateToAmm` 各自要求其簽署者與綁定 `GlobalConfig` 上記錄的錢包相符（`migrate_to_cpswap_wallet` / `migrate_to_amm_wallet`），任何其他簽署者都會得到 `InvalidOwner`。沒有獎勵。這些錢包由 Raydium 的畢業 crank 運行，在閾值被超越後的幾秒內進行遷移。除了初始設定外，作為創建者無需採取任何行動。

### 畢業做什麼

1. 讀取金庫餘額。
2. 關閉曲線（不再對其進行買賣）。
3. 使用金庫餘額作為初始流動性建立新的 CPMM 池。
4. 根據金庫餘額鑄造初始 LP 代幣。
5. 根據配置的政策處置 LP 代幣（銷毀 / 鎖定 / 轉給創建者）。

畢業後，CPMM 池上線並透過正常 Raydium 路由進行交易。

### 監控畢業

監控池狀態上的 `status` 並在其變化時切換你的 UI：

```ts
const before = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

setInterval(async () => {
  const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
  if (p.status !== before) console.log("migrated - switch to the CPMM pool page");
}, 10_000);
```

已畢業池的地址是 `(cpswap config, token0, token1)` 的 CPMM PDA，因此你可以衍生它而不是等待它被報告。對於索引器，透過 gRPC 訂閱而不是輪詢 — 見 [`products/launchlab/code-demos`](/zh-Hant/products/launchlab/code-demos#watch-configs-and-pools-over-grpc)。

創建者或第三方沒有「手動畢業」路徑。如果啟動已超越其閾值且尚未遷移，這是遷移錢包的操作問題，不是你可以從客戶端強制的。

## 畢業後

### 驗證 CPMM 池

```ts
const pool = await raydium.cpmm.getPoolInfoFromRpc({ poolId: cpmmPoolId });
console.log("CPMM price:", pool.poolInfo.price);
console.log("CPMM TVL:  ", pool.poolInfo.tvl);
```

CPMM 池應該有（大約）：

- 基礎代幣餘額：`total_base_supply - baseSold` + 曲線餘數。
- 報價代幣餘額：`quoteRaised - graduationFee`。
- 價格：與最後曲線價格相符。

### 驗證 LP 處置

- **銷毀**：LP 鑄造的供應顯示發送到 1nc1nerator11111111111111111111111111111111 或類似。
- **鎖定**：LP 代幣在託管 PDA 中，帶有解鎖時間戳。
- **轉給創建者**：LP 代幣在創建者的錢包中。

### 收集創建者費用

如果你配置了創建者費用份額，定期呼叫：

建構者是 `claimCreatorFee`，它由**報價幣種**而不是啟動鍵入 — 一次呼叫會掃除你在該幣種中累積的創建者費用：

```ts
import { NATIVE_MINT } from "@solana/spl-token";

await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,      // 要在其中聲稱的報價幣種
  txVersion: TxVersion.V0,
});
```

使用 `claimMultipleCreatorFee` 跨幣種批次。費用從畢業前的曲線交易累積，畢業後從 CPMM 池的創建者費用路徑累積，當平台的 `platform_cp_creator` 將你留作記錄的池創建者時 — 見 [`products/launchlab/platform-config`](/zh-Hant/products/launchlab/platform-config)。

## 公告檢查清單

畢業後公告應包括：

- [ ] 畢業交易雜湊。
- [ ] 新 CPMM 池 ID。
- [ ] LP 處置證明（銷毀交易 / 鎖定交易 / 創建者錢包）。
- [ ] 聚合器覆蓋 ETA（錢包通常在 5 分鐘內索引）。
- [ ] 代幣合約驗證（在公告頻道中匹配鑄造地址）。

## 陷阱

### 1. 鑄造權限未撤銷

如果 `baseMint.mintAuthority` 仍然是你控制的密鑰，你可以鑄造新供應並賣入你自己的曲線。未撤銷的啟動通常被聚合器和列表網站標記為高風險或未驗證。在啟動前撤銷。

### 2. 曲線參數錯誤

`a` 太高的二次方曲線使早期代幣免費（價格 ≈ 0），後期代幣荒謬。`a` 太低的曲線使曲線幾乎線性（失去「聯合」感覺）。先在 devnet 上測試參數。

### 3. 畢業閾值太高

如果畢業需要比現實需求更多的資本，曲線永遠不會畢業，買家被困在只能以更差價格賣回曲線的代幣中。選擇你實際上可以達到的閾值。

### 4. 報價幣種詐騙

如果你的報價幣種是自訂代幣（不是 SOL/USDC），使用者不會信任它。堅持使用 SOL 或 USDC 作為報價。

### 5. 忘記資助基礎金庫

SDK 在建立時從你的錢包轉移 `totalBaseSupply`。如果你的錢包沒有它，交易會還原。簽署前確認餘額。

### 6. LP 處置 = 銷毀是不可逆的

一旦 LP 發送到 1nc1nerator，沒有人可以提取流動性，*包括你*。這是重點 — 信任最小化。如果你不確定，不要選擇銷毀。

### 7. 畢業後 CPMM 費用層級

已畢業的池使用 LaunchLab 的預設 CPMM 設定（0.25%）。如果你想要 1% 或 0.01%，你需要在畢業後自己建立第二個 CPMM 池並遷移流動性 — 笨拙且分散。接受預設，或透過直接 CPMM 建立而不是 LaunchLab 啟動。
