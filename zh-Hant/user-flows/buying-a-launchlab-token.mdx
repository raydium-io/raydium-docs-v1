## LaunchLab 代幣是什麼

LaunchLab 代幣在**聯合曲線**上發行：一條由智能合約管理的價格曲線，隨著更多代幣被購買而上升，隨著代幣被售出而下降。曲線運作直到達到畢業閾值，此時每個新初始化的發行會遷移到 Raydium CPMM 池，並可透過正常的 DEX 路由進行交易。

畢業前，你只能對曲線本身進行買賣。畢業後，代幣像任何其他池一樣在 Raydium 上交易。

## 購買前

### 進行自己的研究

- 驗證代幣的 mint 地址與項目方宣布的地址相符 — 詐騙者經常建立名稱相同的代幣。
- 檢查 **mint 權限是否已被撤銷**。如果未撤銷，創建者可能會鑄造新供應量並稀釋你的頭寸。Solflare 等錢包和 Solscan 等瀏覽器會顯示此狀態。
- 查看聯合曲線進度：已售出多少代幣、還剩多少，以及當前價格。這在代幣的 LaunchLab 頁面上可見。
- 如果可能，檢查創建者地址的歷史記錄。

### 理解曲線機制

聯合曲線上的價格**不是固定的**。每次購買都會推高價格；每次售出都會降低價格。在你購買前的大額購買可能會大幅提高你支付的價格（搶先交易／三明治攻擊風險）。使用滑點限制（見下文）。

## 逐步指南：透過 UI 購買

1. 導航至 [raydium.io/launchlab](https://raydium.io/launchlab) 並找到你想購買的代幣。
2. 點擊代幣頁面以開啟其詳細檢視。
3. 如果尚未連接，請連接你的錢包。
4. 輸入你想花費的 SOL（或報價代幣）數量。
5. 查看 UI 中顯示的**預估代幣接收量**和**價格影響**。
6. 如需要，調整你的**滑點容限**（見下文）。
7. 點擊**購買**並在你的錢包中批准交易。
8. 交易確認後，代幣將出現在你的錢包中。

<Tip>
  在畢業前，你可以隨時使用同一代幣頁面上的**售出**按鈕將代幣賣回曲線。畢業後，代幣在 Raydium 池中；改用標準交換介面。
</Tip>

## 滑點

<Warning>
  **設定適當的滑點容限。** 聯合曲線代幣可能波動很大。如果滑點設定過低，當價格在你的報價和執行之間變動時，交易可能失敗。如果設定過高，你會暴露於三明治機器人的風險。對於大多數發行，合理的起點是 1–3%；只有在接近畢業的極低流動性發行上才需要提高。
</Warning>

滑點容限是你願意接受的報價價格和執行價格之間的最大價格差異。LaunchLab UI 允許你在確認交易前設定此值。

## 畢業後

當曲線的畢業閾值被達到（由任何交易者），代幣會自動遷移到 Raydium AMM 池。此時：

- 聯合曲線關閉；沒有進一步的買賣通過它。
- 你的代幣保持在你的錢包中不變。
- 你現在可以在 Raydium 的交換頁面或任何索引 Raydium 池的聚合器上交易代幣。
- 池遷移可能需要幾分鐘才能在聚合器 UI 中顯示。

## 風險

| 風險 | 說明 |
|---|---|
| 流動性控制風險 | LP 處理取決於平台和發行設定。檢查 LP 是否被銷毀、鎖定、分配給創建者或分配給平台。 |
| 無畢業 | 如果曲線永遠無法達到其閾值，交易仍然僅限於曲線。你仍然可以賣回曲線，但價格可能低於你支付的價格。 |
| 價格波動 | 聯合曲線本質上是投機性的。價格可能跌至接近零。 |
| 假代幣 | 詐騙者建立外觀相似的代幣。獨立驗證 mint 地址。 |
| 智能合約風險 | 沒有鏈上程式是完全無風險的。只使用你準備承擔風險的資金。 |
