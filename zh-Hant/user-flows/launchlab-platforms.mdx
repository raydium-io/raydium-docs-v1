<Info>
  LaunchLab 平台是由啟動介面或社群使用的鏈上設定。平台設定可以影響費用、品牌、創作者費用支援和遷移後的流動性池行為。
</Info>

LaunchLab 透過平台 PDA 支援第三方啟動環境。平台可以提供自己品牌的代幣啟動體驗，同時使用 LaunchLab 程式基礎設施和 Raydium 流動性池遷移。

## 平台可以控制的設定

| 設定 | 重要性 |
|---|---|
| 創作者費用 | 設定結合曲線創作者費用，並可選擇 CPMM 創作者記錄。 |
| 平台費用 | 設定平台級費用收入的接收地址。 |
| 品牌元資料 | 為平台提供名稱、描述和標誌，可在應用介面中顯示。 |
| 啟動分組 | 讓 UI 顯示在同一平台下啟動的代幣。 |
| 遷移後的流動性池設定 | 可在平台將啟動遷移至 CPMM 時定義 CPMM 費用設定。 |
| LP 分配 | 設定銷毀份額和平台擁有的鎖定 LP 份額。保留的創作者規模合併到平台份額中。 |
| 全域設定允許清單 | 可限制啟動僅使用平台管理員明確允許的 `GlobalConfig` 帳戶。 |

## 創作者應檢查的事項

在任何平台下啟動前，請確認：

- 哪個錢包接收平台費用。
- 是否啟用創作者費用。
- 畢業後平台使用的 CPMM 費用設定和創作者記錄。
- 畢業後 LP 代幣如何分配。
- 是否會鑄造平台費用金鑰 NFT。
- 平台是否有自己的條款、政策或資格要求。

<Warning>
  平台設定可能會大幅改變創作者經濟和使用者預期。在簽署啟動交易前請先檢查。本頁僅說明機制，不構成法律、財務或投資建議。
</Warning>

## 交易者應檢查的事項

購買 LaunchLab 代幣時，平台可能會影響費用路徑和遷移後的流動性處理。交易前：

- 檢查代幣的平台和啟動設定。
- 確認 UI 顯示的 CPMM 費用等級。
- 檢查 LP 是否被銷毀、鎖定或分配。
- 從代幣頁面驗證代幣鑄造地址，而不是僅從社群媒體文字。
