## Burn & Earn 是什麼

Burn & Earn 是 Raydium 的一項功能，讓池創建者（或任何 LP）將存款在鏈上**永久化**，同時保留領取交易費用的權利。頭寸變為不可贖回，但新鑄造的 **Raydium Fee Key** NFT 代表從該鎖定頭寸領取 `collectFees` 的持續權利。

常見用例：

- **啟動信任。** 專案透過鎖定部署者的 LP 來承諾不進行地毯式拉盤。持有人可在鏈上驗證流動性是永久的。
- **費用承載收藏品。** 可交易的 NFT，產生收益。出售 NFT；轉移費用流。
- **國庫級 LP。** 希望永久保持流動性以用於品牌／發現目的的協議，同時仍可從費用端獲利。

## 支援的池類型

| 程式 | Burn & Earn 支援 |
|---|---|
| CPMM | 是 |
| CLMM | **僅全範圍**（推薦） |
| AMM v4（混合） | 不支援 |

對於 CLMM，只應鎖定跨越完整價格範圍的頭寸。一旦鎖定，你無法重新平衡——如果價格移出你選擇的範圍，你將永久停止從該頭寸賺取費用。緊密範圍的 Burn & Earn 頭寸幾乎總是一個錯誤。

## 鎖定在程式層級的工作原理

1. 原始 LP 代幣（CPMM）或頭寸 NFT（CLMM）被轉移到由 Burn & Earn 程式擁有的程式擁有 PDA。
2. **Fee Key NFT** 被鑄造給呼叫者。其元資料指向鎖定頭寸的 PDA。
3. Burn & Earn 公開 `collectFees`（或每個池類型的等效呼叫），該呼叫：
   - 驗證簽署者持有給定鎖定頭寸的 Fee Key NFT。
   - 透過 CPI 呼叫底層池程式的費用領取指令。
   - 將收集的費用路由到 Fee Key 持有人的 ATA。
4. 沒有對應的 `withdraw`——底層 LP／頭寸永遠不會退出託管。

Fee Key 是標準 SPL NFT。它可以在任何 Solana NFT 市場上出售、在錢包之間移動、用作接受 NFT 的借貸協議的抵押品，或包裝到另一個合約中。在 `collectFees` 呼叫時持有它的人會收到費用。

## UI 演練

1. 像往常一樣建立 CPMM 池或具有全範圍頭寸的 CLMM 池。
2. 前往**流動性 → 建立 → Burn & Earn**。
3. 選擇要鎖定的頭寸。
4. 驗證頭寸詳情（NFT 地址、大小、池）並輸入 UI 顯示的確認句子。這故意設置了摩擦，因為該操作是不可逆的。
5. 點擊**確認，永久鎖定流動性**。
6. Fee Key NFT 到達你的錢包。它在投資組合頁面上的鎖定頭寸下出現。

以與任何頭寸相同的方式領取費用——透過投資組合頁面或透過 `collectFees`。

## API 介面

池資訊端點返回 `burnPercent` 欄位，指示該池透過 Burn & Earn 鎖定的流動性份額：

```http
GET https://api-v3.raydium.io/pools/info/list
  ?poolType=standard
  &poolSortField=default
  &sortType=desc
  &pageSize=1
  &page=1
```

```json
{
  "data": [
    {
      "id": "...",
      "burnPercent": 99.17,
      ...
    }
  ]
}
```

`burnPercent` 是信任信號的便利表面：LP 被 99%+ 燒毀的代幣比 LP 被 0% 燒毀的代幣的地毯式拉盤風險要低得多。

## 陷阱

- **不可逆。** LP 端永遠無法檢索。確認金額是你願意永遠不再接觸的。
- **CLMM 緊密範圍是陷阱。** 僅鎖定全範圍 CLMM 頭寸，除非你真正理解範圍限制的鎖定頭寸在價格退出該帶後停止賺取費用。
- **丟失 Fee Key NFT 就是永遠丟失費用。** 將其視為契約。不要意外燒毀它；不要將其質押在惡意合約中。
- **Token-2022 鑄造有轉移費用**：Burn & Earn 支援它們，但轉移費用扣除在每次費用領取時適用——預算它。
- **沒有部分鎖定。** 如果你想要 50% 鎖定和 50% 可移動，首先將頭寸分成兩個頭寸，然後僅鎖定其中一個。
