## 兩種建立模式

LaunchLab 提供兩條建立路徑，可從 [raydium.io/launchlab/create](https://raydium.io/launchlab/create) 存取：

| | **JustSendit** | **LaunchLab** |
|---|---|---|
| 設定時間 | 約 1 分鐘 | 約 5 分鐘 |
| 代幣供應量 | 固定預設值 | 完全可設定 |
| SOL 目標 | 85 SOL（固定） | 最少 24 SOL，可自訂 |
| 曲線百分比 | 預設值 | 曲線上 51–80% |
| 解鎖期 | 無 | 可選 |
| 遷移後費用 | 平台定義的 CPMM 建立者費用和 LP 政策 | 平台定義的 CPMM 建立者費用和 LP 政策 |
| 最適合 | 快速社群啟動 | 結構化代幣啟動 |

## JustSendit 模式

最快的啟動方式。所需輸入最少；平台會填入合理的預設值。

### 你需要的東西

- 已連接的錢包，有足夠的 SOL 支付交易費用（建立約需 0.05–0.1 SOL）。
- 代幣名稱和代號。
- 符合 UI 要求的圖片或 GIF。

### 步驟

1. 前往 [raydium.io/launchlab/create](https://raydium.io/launchlab/create) 並選擇 **JustSendit**。
2. 輸入代幣**名稱**和**代號**。
3. 可選：新增**描述**和**社群連結**（網站、Twitter/X、Telegram）。
4. 上傳**標誌圖片或 GIF**。
5. 可選：輸入**初始購買金額**（以 SOL 計），在建立時購買代幣。這會改變曲線上的初始價格狀態，簽署前應先檢查。
6. 檢查摘要並點擊**建立**。
7. 在錢包中批准交易。

你的代幣立即在結合曲線上啟動。一旦曲線收集到 85 SOL，它就會升級到 Raydium AMM 池。

## LaunchLab 模式

完全控制的建立，具有可設定的供應量、募資目標、曲線配置、解鎖期和費用參數。

### 你需要的東西

- 已連接的錢包，有約 0.1–0.5 SOL 用於建立和保管庫租金。
- 在開始前準備好下面的所有輸入（啟動後無法更改設定）。

### 設定選項

#### 代幣詳情

- **名稱、代號、標誌** — 與 JustSendit 相同。
- **描述和社群連結** — 建議用於提高可發現性。

#### 供應量和曲線配置

- **總供應量** — 要鑄造的代幣總數（例如 1,000,000,000）。
- **曲線配置（%）** — 放在結合曲線上供公眾購買的總供應量百分比（51–80%）。其餘部分用於種子化升級後的流動性池。

<Warning>
  曲線配置和總供應量在啟動時固定，**無法更改**。簽署前請仔細選擇。
</Warning>

#### SOL 募資目標

- 最低升級閾值為 **24 SOL**。你可以設定更高的值。
- 這是曲線在升級到 CPMM 池前必須收集的 SOL 金額。
- 設定過高會有曲線永遠無法升級的風險（如果需求不足）。

#### 解鎖期（可選）

解鎖期會鎖定部分代幣供應量，並根據時間表線性釋放給指定的錢包。

| 欄位 | 描述 |
|---|---|
| 鎖定總金額 | 跨所有受益人鎖定的代幣（佔總供應量的百分比，受程式上限限制）。 |
| 懸崖期 | 升級後到任何代幣解鎖前的等待時間（例如 180 天）。 |
| 解鎖期 | 懸崖期後線性解鎖的持續時間（例如 365 天）。 |

鎖定的代幣不進入曲線，也不是升級流動性池的一部分。它們根據上述時間表釋放給每個受益人的錢包。

**重要解鎖期規則：**
- 懸崖期和解鎖期在啟動時固定 — 無法事後更改。
- 如果受益人遺失錢包金鑰，鎖定的代幣將永久無法存取。如果恢復很重要，請使用多簽。
- 升級前未分配給受益人的 `total_locked_amount` 任何部分都會永久卡住。請分配全額。

如需完整的鏈上機制，請參閱 [LaunchLab 解鎖期](/zh-Hant/products/launchlab/vesting)。

#### 遷移後費用分享

當代幣升級時：
- LP 代幣被鑄造到 CPMM 池。
- 簽署前請閱讀目前的平台設定。在 2026-08-14 升級前，`creatorScale` 產生建立者費用金鑰。對於之後執行的遷移，`platformScale + creatorScale` 變成平台擁有的費用金鑰位置，`burnScale` 被銷毀。來自早期遷移的現有建立者費用金鑰保持不變。
- 你的升級後建立者收入僅來自 CPMM 建立者費用，前提是你仍是記錄的 CPMM 池建立者，且選定的設定啟用了費用。

詳見 [建立者費用如何運作](/zh-Hant/user-flows/how-creator-fees-work)。

### 步驟

1. 在建立頁面上選擇 **LaunchLab** 模式。
2. 填入代幣詳情（名稱、代號、標誌、描述、社群）。
3. 設定**總供應量**和**曲線配置百分比**。
4. 設定你的 **SOL 募資目標**（≥ 24 SOL）。
5. 如需要，設定**解鎖期**（設定受益人錢包和時間表）。
6. 如果你想要建立者 LP 份額，啟用**遷移後費用分享**。
7. 可選：輸入初始購買金額。
8. 檢查完整摘要 — 曲線價格範圍、升級條件、LP 分割。
9. 點擊**建立**並批准交易。

## 代幣啟動後

### 監控曲線進度

你的代幣 LaunchLab 頁面顯示實時進度：
- 曲線售出百分比。
- 募集的 SOL 與升級目標的對比。
- 目前價格和價格圖表。

LaunchLab 不會干預未達到升級的啟動。監控曲線進度並與社群清楚溝通。

### 升級

升級由第一筆將曲線推過閾值的交易自動觸發 — 任何使用者都可以呼叫（呼叫者獲得小額獎勵）。作為建立者，你無需採取任何行動。

升級後：
- 使用收集的 SOL 和剩餘曲線代幣作為初始流動性建立 CPMM 池。
- 如果你啟用了遷移後費用，**費用金鑰 NFT** 會被鑄造到你的錢包。
- 從你的投資組合頁面領取遷移前建立者費用。

### 領取遷移前建立者費用

如果你的平台在結合曲線階段啟用了建立者費用，它們會累積在保管庫中。可隨時從 raydium.io 上的**投資組合**頁面領取。

## 要避免的陷阱

| 陷阱 | 該怎麼做 |
|---|---|
| 設定 SOL 目標過高 | 選擇市場能實際達到的目標。 |
| 在受益人確認前過度分配解鎖期 | 未分配的解鎖供應量在升級後永久無法存取。 |
| 無意中轉移或銷毀費用金鑰 NFT | 費用領取權永久喪失。將 NFT 保留在建立錢包或你控制的錢包中。 |
| 不進行初始購買 | 沒有早期購買，狙擊機器人可能以接近零的成本捕獲所有早期代幣，這可能會損害社群信任。 |
