<Info>
  流動性部位和獎勵在 Raydium 產品中使用不同的機制。**CPMM** 部位使用可互換的 LP 代幣。**CLMM** 部位使用具有選定價格範圍的部位 NFT。**農場**獎勵在符合條件的 LP 代幣被質押時累積。
</Info>

## 開始前

確認你已準備好：

- 你想存入的代幣對。
- 足夠的 SOL 用於交易費用和優先費用。
- Raydium.io 上的正確池。
- 清楚了解該部位是被動 CPMM 流動性還是主動管理的 CLMM 流動性。

如果你正在建立新池，請從[池建立](/zh-Hant/user-flows/choosing-a-pool-type)開始。

## 新增流動性至 CPMM 池

1. 在 Raydium 上開啟池頁面。
2. 點擊**新增流動性**。
3. 輸入一個代幣的數量。另一個數量會按照池的目前比率自動填入。
4. 檢查你將收到的 LP 代幣和預期的池份額。
5. 在 Raydium 中確認，然後在你的錢包中批准。

UI 會建立缺少的代幣帳戶、支援的 Token-2022 轉帳費用鑄幣的帳戶，並在需要時包裝 SOL。

## 從 CPMM 池移除流動性

1. 開啟池頁面或你的投資組合部位。
2. 點擊**移除流動性**。
3. 輸入 LP 代幣數量，或使用百分比滑塊。
4. 檢查你將收到的兩個代幣數量。
5. 確認並在你的錢包中批准。

提取後可能會留下少量的舍入塵埃。這對於恆定乘積池是正常的。

## 開啟或管理 CLMM 部位

CLMM 部位是 NFT。它們有四個常見操作：

- **開啟部位**：使用初始範圍和流動性鑄造新的部位 NFT。
- **增加流動性**：向現有部位新增更多流動性。
- **減少流動性**：移除部分流動性，同時保留 NFT。
- **關閉部位**：移除所有流動性、收集待處理費用和獎勵，然後銷毀 NFT。

<Info>
  大多數新的 CLMM 部位保持未凍結且可轉讓。只有當部位使用 V2 開啟路徑且任一池鑄幣的凍結權限與 CLMM 的受限發行者清單相符時，部位才會綁定到其初始 NFT 所有者。該匹配的 NFT 帳戶被凍結，因此無法轉讓或移入託管。其所有者仍然可以透過 Raydium 增加或減少流動性、收集費用和獎勵，以及關閉部位。
</Info>

## 開啟 CLMM 部位

1. 開啟 CLMM 池頁面。
2. 選擇下限價格和上限價格。
3. 輸入存入金額。
4. 檢查部位是否在範圍內、部分在範圍內或超出範圍。
5. 確認並批准。

你選擇的範圍決定了代幣比率。如果目前價格接近下限邊緣，部位可能主要需要一個代幣。如果接近上限邊緣，可能主要需要另一個代幣。

## 增加、減少或關閉 CLMM 部位

- **增加**：開啟部位卡片，點擊**增加**，輸入金額，檢查所需的代幣對，然後簽署。
- **減少**：點擊**減少**，選擇百分比或金額，檢查估計的代幣回報，然後簽署。
- **關閉**：將流動性減少到零、收集未領取的費用和獎勵，然後關閉部位。關閉會銷毀部位 NFT 並在適用時返還租金。

如果部位屬於受限發行者池，請使用目前的 Raydium UI 或更新的 SDK 來關閉它。關閉交易必須包含池帳戶，以便 CLMM 程式可以原子性地解凍和銷毀凍結的部位 NFT。

如果目前價格在你選擇的範圍之外，存入可能是單邊的。UI 會在你簽署單邊或超出範圍的部位前發出警告。

## 收穫農場獎勵

當你的 LP 代幣在活躍農場中被質押時，農場獎勵會累積。收穫會將待處理獎勵轉移到你的錢包。它不會提取你的質押。

1. 開啟 [raydium.io/portfolio](https://raydium.io/portfolio)。
2. 找到你的農場部位。
3. 點擊**收穫**。
4. 檢查每個獎勵流的待處理金額。
5. 確認並在你的錢包中批准。

農場存入和提取通常會在同一操作中結算待處理獎勵。仔細檢查確認，因為它也可能收穫待處理獎勵。

## 收集 CLMM 費用和獎勵

CLMM 部位在兩個池鑄幣中賺取交換費用。費用在部位上累積，不會自動複利。

1. 從 [raydium.io/portfolio](https://raydium.io/portfolio) 開啟你的 CLMM 部位。
2. 點擊**收集費用**或**收集獎勵**。
3. 檢查代幣金額。
4. 確認並批准。

如果 UI 提供**全部收集**，請使用它來一起收集費用和獎勵。

若要手動複利，請收集費用、在需要時重新平衡兩個代幣，然後增加部位上的流動性。

## 時機和費用經濟學

每次領取都會產生 Solana 交易費用，在擁塞期間可能包括優先費用。

- 對於小額待處理金額，請等到獎勵相對於交易費用有意義時。
- 對於較大的部位，每週或每月領取通常就足夠了。
- 除非你正在主動複利，否則通常不需要每天領取。

## 驗證

在 CPMM 存入後：

- 檢查你的錢包是否顯示 LP 代幣餘額。
- 檢查 Raydium 的投資組合頁面是否顯示該部位。
- 開啟交易簽名並確認池存入成功。

在開啟或增加 CLMM 部位後：

- 檢查你的投資組合是否顯示部位 NFT。
- 確認下限和上限價格範圍與你選擇的相符。
- 檢查目前價格是否在範圍內。

在收穫或收集後：

- 檢查交易狀態是否為**成功**。
- 確認獎勵或費用代幣餘額在你的錢包中增加。
- 重新整理 Raydium 的投資組合頁面並確認待處理金額重置或減少。

## 故障排除

### 存入比率上的滑點

存入比率在報價時計算。如果你簽署前池價格移動，交易可能會失敗。重新報價並重試。只在易變對需要時提高滑點。

### 存入時的 Token-2022 轉帳費用

如果 Token-2022 鑄幣收取轉帳費用，池收到的金額會少於你發送的金額。Raydium 會在你簽署前顯示轉帳費用警告。

### 提取時的塵埃

舍入可能在池中或你的錢包中留下微小金額。這是正常的，不表示提取失敗。

### CLMM 部位不是 LP 代幣

CLMM 部位是 NFT。檢查 Raydium 的投資組合頁面或你的錢包的 NFT 檢視，而不是尋找可互換的 LP 代幣。

### 在獎勵結束前收穫

如果獎勵流在你有待處理獎勵時結束，待處理金額會停止增長。除非農場以不尋常的方式被清算，否則你仍然可以在結束時間後領取它。

### 優先費用過低

如果交易待處理或過期，請使用更高的優先費用設定重試。

### 跨多個農場領取

大型批量領取如果包含太多部位或獎勵流可能會失敗。一次領取幾個部位。
