  LaunchLab 是無許可的代幣發行基礎設施。任何人都可以建立代幣、選擇名稱或代碼，並設定發行參數。購買或推廣代幣前，務必驗證 mint 地址和發行設定。本頁僅說明產品機制，不構成財務、法律或投資建議。

LaunchLab 讓創作者透過聯合曲線發行代幣並引導初始流動性。買家在畢業前對著曲線交易。當發行達到畢業門檻時，流動性遷移至 Raydium AMM 池，交易透過正常的 Raydium 路由繼續進行。

## 誰使用 LaunchLab

| 使用者 | 常見任務 |
|---|---|
| 交易者 | 發現早期代幣、在聯合曲線上買賣，並追蹤畢業進度。 |
| 創作者 | 無需程式碼即可發行代幣、設定曲線參數，並可選擇賺取創作者費用。 |
| 平台 | 建立品牌化的發行環境，具有自訂費用設定、品牌和發行發現介面。 |

## 發行如何運作

1. 創作者設定代幣元資料、供應量、曲線設定、畢業目標和可選的費用設定。
2. 代幣在聯合曲線上開放。買家和賣家直接對著曲線交易。
3. 隨著買賣發生，曲線價格變化。
4. 當曲線達到畢業目標時，流動性遷移至 Raydium 池。
5. 畢業後，使用者透過 Raydium Swap 和路由至 Raydium 池的聚合器交易代幣。

## 建立模式

| 模式 | 何時使用 | 關鍵設定 |
|---|---|---|
| JustSendit | 你想要最快速的無程式碼發行，使用預設設定。 | 名稱、代碼、圖像、可選的社群連結、可選的首次購買。 |
| LaunchLab | 你需要更多控制供應量、畢業目標、曲線配置、解鎖期或創作者費用。 | 供應量、募資目標、曲線配置、解鎖期、遷移後費用分享。 |

JustSendit 使用預設畢業目標。LaunchLab 模式讓創作者設定畢業目標，受限於 UI 和程式限制。

## 畢業和流動性

畢業關閉聯合曲線並將資產遷移至 CPMM 池。LP 待遇和 CPMM 創作者記錄取決於平台設定。

- 所有新初始化的發行都遷移至 CPMM。
- 平台和創作者規模欄位合併為一個平台擁有的鎖定 LP 份額；剩餘份額被銷毀。
- CPMM 創作者費用與平台費用金鑰分開，遵循記錄的 CPMM 池創作者。

## 安全基礎

- 驗證代幣 mint，不只是代碼或標誌。
- 交易前檢查畢業目標和曲線進度。
- 發行或購買前檢查創作者和平台費用設定。
- 將平台費用金鑰 NFT 視為費用權利資產。如果轉移或銷毀，LP 費用索賠權可能移動或遺失。
- 連接錢包或簽署交易前，請閱讀[信任與安全](/zh-Hant/getting-started/trust-and-safety)。
