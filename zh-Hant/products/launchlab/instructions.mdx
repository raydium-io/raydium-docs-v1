## 指令清單

| 群組 | 指令 | 可呼叫者 |
|-------|-------------|-------------|
| 全域設定 | `CreateConfig` / `UpdateConfig` | 程式管理員；委派的建立設定授權也可呼叫 `CreateConfig` |
| 啟動生命週期 | `Initialize` / `InitializeV2` | 任何人（建立者）— SPL Token 啟動；V2 記錄 `amm_creator_fee_on` 供後續 CPMM 畢業使用 |
| 啟動生命週期 | `InitializeWithToken2022` | 任何人（建立者）— Token-2022 啟動，可選 `TransferFeeConfig` |
| 交易 | `BuyExactIn` / `BuyExactOut` | 任何人 — 在結合曲線上精確輸入/精確輸出買入 |
| 交易 | `SellExactIn` / `SellExactOut` | 任何人 — 在結合曲線上精確輸入/精確輸出賣出 |
| 畢業 | `MigrateToAmm` | 遷移錢包 — 舊版 AMM v4 畢業，適用於在強制執行 CPMM 專用建立前初始化的資金池。 |
| 畢業 | `MigrateToCpswap` | 遷移錢包 — 畢業至 CPMM。所有新初始化的啟動都使用此路徑。包裝 CPMM 上的 `InitializeWithPermission`。 |
| 費用 | `CollectFee` | 管理員 — 從啟動中清掃協議費用 |
| 費用 | `CollectMigrateFee` | 管理員 — 清掃累積的遷移費用 |
| 費用 | `ClaimCreatorFee` | 建立者 — 在曲線階段領取累積的建立者費用 |
| 鎖定 | `CreateVestingAccount` | 建立者 — 為受益人分配鎖定代幣，畢業後解鎖 |
| 鎖定 | `CreatePlatformVestingAccount` | 平台管理員 — 為平台端受益人分配鎖定代幣 |
| 鎖定 | `ClaimVestedToken` | 受益人 — 懸崖期後領取已解鎖代幣 |
| 平台設定 | `CreatePlatformConfig` / `UpdatePlatformConfig` | 平台管理員 |
| 平台設定 | `UpdatePlatformCurveParam` / `RemovePlatformCurveParam` | 平台管理員 — 管理每個平台允許的曲線形狀列表 |
| 平台費用 | `ClaimPlatformFee` / `ClaimPlatformFeeFromVault` | 平台管理員 |
| 平台存取 | `CreatePlatformAllowConfig` / `ClosePlatformAllowConfig` | 平台管理員 — 維護該平台啟用限制時使用的 `GlobalConfig` 允許清單 |

「ExactIn/ExactOut」分割鏡像 CPMM 的 `SwapBaseInput` / `SwapBaseOutput` — 在鏈上它們是具有略微不同舍入的獨立指令判別器。

**畢業路徑選擇。** 每個新的 `Initialize`、`InitializeV2` 及 `InitializeWithToken2022` 呼叫必須設定 `migrate_type = 1`（`CPSWAP`）。任何嘗試初始化新的 AMM v4 綁定資金池都會返回 `MigrateTypeNotMatch`。`amm_creator_fee_on` 僅選擇結果 CPMM 建立者費用是否適用於報價代幣或兩個代幣；它不選擇目標程式。

`MigrateToAmm` 對於在此限制前以 `migrate_type = 0` 初始化的現有 `PoolState` 仍可呼叫。此版本不會重寫現有資金池狀態或移除舊版指令。

## `Initialize`

建立新啟動。

**參數**

```
launch_params: {
    curve_type:                 u8,
    base_supply_max:            u64,
    base_supply_graduation:     u64,
    k:                          u128,              // 或 curve_type=1 的 initial_virtual_quote_reserve
    open_time:                  u64,
    quote_mint:                 Pubkey,
    base_token_metadata: {                         // 內聯名稱/符號/URI；程式 CPI 至 Metaplex
        name:   String,
        symbol: String,
        uri:    String,
    },
    fees: {
        buy_numerator:   u64,
        buy_denominator: u64,
        sell_numerator:  u64,
        sell_denominator: u64,
        lp_share:        u64,
        creator_share:   u64,
        protocol_share:  u64,
        total_share:     u64,
    },
    post_graduation_lp_policy:  u8,                // 0 = Burn, 1 = Lock, 2 = ToCreator
}
```

**帳戶**（簡化版）

| # | 名稱 | W | S | 備註 |
|---|------|---|---|-------|
| 1 | `creator` | W | S | 支付租金 + 基礎鑄幣建立。 |
| 2 | `launch_config` |   |   | 協議設定綁定。 |
| 3 | `launch_state` | W |   | 新帳戶。 |
| 4 | `launch_authority` |   |   | PDA。 |
| 5 | `base_mint` | W | S | 新 Keypair（或 PDA）— 此指令初始化它。 |
| 6 | `base_vault` | W |   | `launch_authority` 在 `base_mint` 上的 ATA。 |
| 7 | `quote_mint` |   |   | |
| 8 | `quote_vault` | W |   | `launch_authority` 在 `quote_mint` 上的 ATA。 |
| 9 | `metadata` | W |   | Metaplex 元資料 PDA。 |
| 10 | `metaplex_program` |   |   | |
| 11 | `token_program` |   |   | 僅 SPL Token。 |
| 12 | `system_program` |   |   | |
| 13 | `rent` |   |   | |

**前置條件**

- `quote_mint ∈ launch_config.allowed_quote_mints`。
- `base_supply_graduation ≤ base_supply_max`。
- 費用參數通過 `launch_config.max_*_fee_rate` 檢查。
- `open_time ≥ now − slop`（SDK 強制 `≥ now`；程式容許輕微回溯）。
- `curve_type` 被識別。

**後置條件**

- `base_mint` 有 `supply = base_supply_max`，全部在 `base_vault` 中。
- `base_mint.mint_authority = launch_authority`，`freeze_authority = None`。
- `LaunchState` 初始化為 `status = Active`、`base_sold = 0`、`quote_reserve_real = 0`。
- `quote_reserve_target` 從曲線參數 + `base_supply_graduation` + `buy_numerator` 計算（約略）。

**常見錯誤** — `InvalidQuoteMint`、`FeeRateTooHigh`、`InvalidCurveParams`、`MathOverflow`。

## `Buy`（標準變體：`BuyExactIn`）

使用者提供固定 `quote_in`；曲線計算 `base_out`。

**參數**

```
quote_in:          u64
minimum_base_out:  u64
```

**帳戶**

| # | 名稱 | W | S |
|---|------|---|---|
| 1 | `user` | W | S |
| 2 | `launch_state` | W |   |
| 3 | `launch_authority` |   |   |
| 4 | `base_vault` | W |   |
| 5 | `quote_vault` | W |   |
| 6 | `user_base_ata` | W |   |
| 7 | `user_quote_ata` | W |   |
| 8 | `base_mint` |   |   |
| 9 | `quote_mint` |   |   |
| 10 | `token_program` |   |   |
| 11 | `associated_token_program` |   |   |
| 12 | `system_program` |   |   |

**前置條件**

- `launch_state.status == Active`。
- `now ≥ open_time`。
- `user_quote_ata.balance ≥ quote_in`。
- `quote_in > 0`。

**效果**

1. 將 `quote_in` 分割為 `quote_in_after_fee` 及費用部分。
2. 牛頓法求解曲線，給定扣費後報價的 `base_out`。
3. `require(base_out ≥ minimum_base_out)` 否則回復 `ExceededSlippage`。
4. 移動 `quote_in` 使用者 → 金庫。移動 `base_out` 金庫 → 使用者。
5. 更新 `base_sold += base_out`、`quote_reserve_real += quote_in_after_fee × (lp_share / total_share)`。
6. 更新費用計數器（`protocol_fees_quote`、`creator_fees_quote`）。
7. `state_data.num_buys += 1`。
8. 如果更新後 `quote_reserve_real ≥ quote_reserve_target`，SDK 通常在同一交易中鏈接 `Graduate` 指令。程式不在 `Buy` 內自動畢業 — 需要後續 `Graduate`。

## `BuyExactOut`

使用者指定精確 `base_out`；程式計算 `quote_in`。

**參數**

```
base_out:      u64
maximum_quote_in: u64
```

與 `BuyExactIn` 相同的帳戶。使用閉式二次積分（或 curve_type 1 的 CPMM 反函數）而非牛頓迭代。

## `Sell` / `SellExactIn` / `SellExactOut`

`Buy` 的鏡像。使用者將 `base_in` 返回曲線並接收 `quote_out`。費用從 `quote_out` 扣除，所以使用者收到少於原始積分收益。

**前置條件** —

- `user_base_ata.balance ≥ base_in`。
- 賣出不能將 `base_sold` 推低於 0（給定帳戶一致性，此為冗餘）。
- 啟動為 `Active`。

**效果** — 對稱於 `Buy`。`base_sold` 減少，`quote_reserve_real` 減少。費用仍累積。

## `MigrateToAmm` / `MigrateToCpswap`

一旦曲線達到 `total_quote_fund_raising`，將啟動畢業至可交易資金池。新啟動為 CPMM 專用。`MigrateToAmm` 為存儲 `migrate_type` 為 `0` 的現有資金池保留。

**誰簽署**

- `MigrateToAmm` — 綁定 `GlobalConfig` 上記錄的 `migrate_to_amm_wallet`。
- `MigrateToCpswap` — 綁定 `GlobalConfig` 上記錄的 `migrate_to_cpswap_wallet`。

這些錢包通常由 Raydium 運營的畢業 crank 持有；實際上畢業在閾值被跨越後數秒內進行，無論誰觸發最後買入。

**參數**

`MigrateToAmm` 接受三個（主要是程式轉發至 AMM v4 的 OpenBook 市場參數）：

```
base_lot_size:               u64
quote_lot_size:              u64
market_vault_signer_nonce:   u8
```

`MigrateToCpswap` 不接受任何參數。

**效果（兩者共同）**

1. 驗證 `pool_state.status == Migrate`（即 `quote_reserve_target` 已達到）。否則以 `PoolMigrated`（狀態已為 `Migrated`）或 `PoolFunding`（仍在籌資）回復。
2. 驗證 `pool_state.migrate_type` 匹配指令（AMM 為 `0`，CPMM 為 `1`）。否則以 `MigrateTypeNotMatch` 回復。
3. 計算畢業後準備金：
   - `base_amount_out = base_vault.amount − vesting_schedule.total_locked_amount`
   - `quote_amount_out = quote_vault.amount − quote_protocol_fee − migrate_fee − platform_fee`
4. CPI 至目標程式（`AMM v4 Initialize2` 或 `CPMM InitializeWithPermission`）使用這些準備金建立畢業後資金池。
5. 對於 2026-08-17 升級後執行的 CPMM 遷移，將 `platform_scale + creator_scale` 合併為一個平台擁有的鎖定 LP 份額，並最多向 `platform_nft_wallet` 鑄造一個費用金鑰 NFT。燒毀 `burn_scale` 餘額。升級前，`creator_scale` 單獨鎖定，其費用金鑰轉至代幣建立者。已完成的歷史遷移不被修改。對於舊版 AMM v4 畢業，LP 配置遵循該指令的現有流程。
6. 撤銷 `base_mint.mint_authority`（設為 `None`）。
7. 翻轉 `pool_state.status = Migrated`，設定 `vesting_schedule.start_time = block_time + cliff_period`。

**後置條件** — `BuyExactIn`、`BuyExactOut`、`SellExactIn`、`SellExactOut` 從此點起將以 `PoolMigrated` 拒絕。結果 AMM 資金池是標準的，交易如同任何其他 AMM v4 / CPMM 資金池。

**常見錯誤** — `PoolFunding`、`PoolMigrated`、`MigrateTypeNotMatch`、`InvalidCpSwapConfig`、`MathOverflow`。

### CPMM 遷移剩餘帳戶

建立 `MigrateToCpswap` 的客戶端必須使用這些固定 `remaining_accounts` 索引：

| 索引 | 帳戶 |
|---|---|
| 0–4 | 平台費用金鑰擁有者、鑄幣、代幣帳戶、鎖定流動性 PDA 及元資料帳戶 |
| 5 | 原始啟動建立者；當 `platform_cp_creator` 未設定時使用 |
| 6 | CPMM 權限 PDA 衍生自 `[b"permission", launch_authority]` |
| 7 | 已設定的 `platform_cp_creator`；當欄位非預設時使用 |
| 8 | CPMM 支援鑄幣 PDA 用於排序 `mint0`，衍生自 `[b"support_mint", mint0]` |
| 9 | CPMM 支援鑄幣 PDA 用於排序 `mint1`，衍生自 `[b"support_mint", mint1]` |

升級路徑上的指令至少需要十個剩餘帳戶。支援鑄幣帳戶為唯讀 CPI 輸入。即使鑄幣沒有初始化的支援記錄，也要衍生兩個地址。仍然附加建立者鎖定帳戶或省略索引 8–9 的舊版建立者必須更新。

## 平台 `GlobalConfig` 允許清單

`PlatformConfig.restrict_global_config` 控制檢查：

- `0`：平台接受任何其他有效的 `GlobalConfig`；不需要允許帳戶。
- `1`：`Initialize`、`InitializeV2` 及 `InitializeWithToken2022` 必須在 `remaining_accounts` 中的任何位置包含匹配的 `PlatformAllowConfig`。

平台管理員使用 `CreatePlatformAllowConfig` 及 `ClosePlatformAllowConfig` 建立或關閉 PDA。其種子為 `[b"platform_allow_config", platform_config, global_config]`。前管理員管理的 `PlatformGlobalAccess` 指令及 PDA 已停用。

## `CollectFee`

管理員清掃單個啟動上協議累積交易費用。

**參數** — 無。

**帳戶**

| # | 名稱 | W | S | 備註 |
|---|------|---|---|-------|
| 1 | `protocol_fee_owner` |   | S | 必須等於 `global_config.protocol_fee_owner`。 |
| 2 | `authority` |   |   | PDA `[b"vault_auth_seed"]`；簽署金庫轉帳。 |
| 3 | `pool_state` | W |   | 變異為零 `quote_protocol_fee`。 |
| 4 | `global_config` |   |   | 簽署者的真實來源。 |
| 5 | `quote_vault` | W |   | 由 `quote_protocol_fee` 清空。 |
| 6 | `recipient_token_account` | W |   | `protocol_fee_owner` 在 `quote_mint` 上的 ATA。 |
| 7 | `quote_mint` |   |   | |
| 8 | `token_program` |   |   | SPL Token（報價鑄幣始終為 SPL Token）。 |

**效果** — 從 `quote_vault` 轉帳 `pool_state.quote_protocol_fee` 至 `recipient_token_account`，然後將計數器歸零。可在第一次買入後任何時間呼叫。

## `CollectMigrateFee`

管理員清掃畢業時累積的遷移費用。與 `CollectFee` 相同的帳戶形狀，但以 `migrate_fee_owner` 作為簽署者（而非 `protocol_fee_owner`）及 `pool_state.migrate_fee` 作為清空計數器。

**參數** — 無。

**帳戶**

|---|------|---|---|-------|
| 1 | `creator` | W | S | 資金池建立者。 |

| 3 | `creator_fee_vault` | W |   | PDA 在種子 `[creator, quote_mint]`；聚合建立者金庫。 |
| 4 | `recipient_token_account` | W |   | `init_if_needed`；`creator` 在 `quote_mint` 上的 ATA。 |
| 5 | `quote_mint` |   |   | |
| 6 | `token_program` |   |   | |

**效果** — 轉帳 `creator_fee_vault` 的全部餘額至 `recipient_token_account`。如果金庫為空，以大於零檢查回復。

| 5 | `quote_vault` | W |   | 清空。 |
| 6 | `recipient_token_account` | W |   | `init_if_needed`；`platform_fee_wallet` 的 ATA。 |
