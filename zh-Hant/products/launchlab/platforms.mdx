<Info>
  LaunchLab 中的**平台**是建立在 Raydium LaunchLab 程式之上的第三方發行環境。平台可以建立自己的品牌、收取自己的費用，並為在其下發行的每個代幣配置遷移後的參數——無需運行單獨的鏈上程式。Raydium 自己的發行 UI 只是眾多平台中的一個。
</Info>

## 平台存在的原因

Raydium 希望 LaunchLab 成為一個**共享原語**，而不是單一品牌產品。平台 PDA 系統讓生態系統、工具提供商、社區和迷因團隊能夠提供精選或品牌化的發行體驗，所有這些都最終結算到同一個底層 LaunchLab 結合曲線程式和 CPMM 遷移後流動性池。

你可能在實際應用中看到的平台示例：

- **Raydium 自有的 LaunchLab UI**（raydium.io/launchlab）——參考實現。
- **合作夥伴發行平台**——已註冊自己的平台 PDA 以品牌化發行體驗的第三方。
- **利基平台**——例如，只發行與特定主題相關的迷因幣的社區特定平台，具有自訂費用分享來資助其金庫。

所有這些代幣仍然存在於同一個 LaunchLab 程式上，畢業到同一個 CPMM 程式，並且可以由相同的聚合器路由。

## 平台 PDA

每個平台由存儲在 LaunchLab 程式中的平台 PDA 表示。欄位包括：

| 欄位 | 說明 |
|---|---|
| `platform_key` | 平台的種子/識別符，用於推導平台 PDA。 |
| `platform_fee_destination` | 接收平台在遷移前後交易費用分成的帳戶。 |
| `platform_fee_bps` | 遷移前交換的平台費用分成（因平台而異）。 |
| `creator_fee_rate` | 結合曲線交易期間的創作者費用率。 |
| `platform_scale`、`creator_scale`、`burn_scale` | 存儲的 LP 規模。升級前，創作者規模進入創作者費用密鑰。對於之後執行的遷移，前兩個合併為平台的鎖定 LP 分成；`burn_scale` 被銷毀。 |
| `cp_config_id` | 如果遷移後目標是 CPMM，使用哪個 `AmmConfig`——選擇費用層級。 |
| `restrict_global_config` | 發行是否必須為選定的 `GlobalConfig` 提供平台建立的允許 PDA。 |
| `name`、`description`、`image_url` | 由錢包和支持平台品牌的 UI 使用的顯示元數據。 |
| `tokens_launched` | 在此平台下建立的代幣計數器或鏈上索引。 |

確切的欄位名稱在 LaunchLab IDL（[`sdk-api/anchor-idl`](/zh-Hant/sdk-api/anchor-idl)）中。上表是描述性概述。

## 平台可以控制的內容

**費用捕獲：**

- 每次遷移前買賣的**平台費用分成**。
- **遷移後分成**——在 2026-08-14 升級之前，創作者規模產生單獨的創作者費用密鑰。對於之後執行的遷移，`platform_scale + creator_scale` 變成一個平台擁有的鎖定 LP 頭寸，`burn_scale` 被銷毀。

**遷移後目標：**

- **CPMM**，通過 `cp_config_id` 選擇的 `AmmConfig`。所有新初始化的發行都使用 CPMM。
- **AMM v4** 僅作為使用舊版遷移類型建立的現有發行狀態的畢業路徑。

**用戶體驗：**

- **品牌元數據**，由 Raydium 應用和任何顯示 LaunchLab 代幣的錢包/瀏覽器使用。
- **發行頁面自訂**——託管自己前端的平台可以篩選代幣，只顯示自己平台的發行。

## 平台無法控制的內容

- **結合曲線數學。** 曲線形狀（邏輯、指數等）是 LaunchLab 程式本身的一部分。平台從支持的曲線中選擇；它們無法添加任意自訂曲線。
- **遷移閾值邏輯。** 觸發畢業到 CPMM 的條件由程式強制執行。
- **核心安全/審計態勢。** 每個平台都繼承 LaunchLab 的審計歷史；惡意平台無法通過更改程式來繞過它。

## 註冊平台

LaunchLab 程式公開了 `create_platform` 指令（IDL 中的確切名稱）。呼叫者傳遞：

- 將推導平台 PDA 的種子。
- 費用目標帳戶。
- 所需的費用 bps（受程式級上限限制）。
- 遷移後配置（如適用，CPMM `AmmConfig` ID）。
- 品牌元數據。

平台 PDA 的租金由建立者支付。建立後，平台授權可以更新品牌和某些費用參數；結構參數（遷移目標程式）通常不能。

有關當前 LaunchLab IDL 中確切的指令簽名，請參閱 [`products/launchlab/instructions`](/zh-Hant/products/launchlab/instructions)。

## 經濟互動

LaunchLab 結合曲線上的單次交換大致分配價值如下（確切比率由平台設定）：

```
買方支付：                   100 SOL
協議費用 (LaunchLab)：       – 小百分比
平台費用：                   – platform_fee_bps%
創作者費用（遷移前）：       – creator_fee_bps%（如果啟用）
剩餘（進入曲線）：           ~ 其餘部分
```

遷移後，LP 代幣有兩個有效目標：

```
畢業時鑄造的 LP 代幣：  100%
  → 銷毀：                 burnScale
  → 平台費用密鑰：         platformScale + creatorScale
```

平台費用密鑰代表可索賠的 LP 費用權利，但無法提取鎖定的流動性。銷毀的 LP 沒有費用密鑰持有者。

## 限制全局配置

平台管理員可以設定 `restrict_global_config = 1` 並為每個接受的 `GlobalConfig` 建立一個 `PlatformAllowConfig`。新的發行交易必須附加匹配的允許 PDA。禁用限制後，平台接受通過程式其他驗證的任何配置。

## 整合商注意事項

- **按平台列出代幣。** 使用 API 池資訊/鑄造端點，帶有 `platform` 篩選器（如果支持），以僅列出在特定平台 PDA 下發行的代幣。
- **品牌顯示。** 如果你構建顯示 LaunchLab 代幣的錢包或瀏覽器，從平台 PDA 讀取平台的名稱/圖像 URL 遠比為每個代幣顯示「LaunchLab」更好的用戶體驗。
- **費用數學。** 每個結合曲線報價必須考慮平台費用以及協議和創作者費用。當提供平台 PDA 時，SDK 的報價幫助程式會自動執行此操作。
