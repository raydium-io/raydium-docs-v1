## 設定

此處的示例鏡像 [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad) 中的檔案。啟動程序遵循示例儲存庫的 [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)：

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## 建立發行

來源：[`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts)（以及 [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts) 用於 API 驅動的 Bonk 變體）

發行的大部分經濟學參數**不是**引數——它們來自你透過 `configId` 綁定的 `GlobalConfig`，SDK 從 API 的預設參數填充其餘部分。你傳遞代幣的身份、要綁定的設定，以及（可選）首次購買：

```ts
import {
  LAUNCHPAD_PROGRAM,
  DEVNET_PROGRAM_ID,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";

const programId = LAUNCHPAD_PROGRAM;          // devnet: DEVNET_PROGRAM_ID.LAUNCHPAD_PROGRAM

// 基礎代幣是你生成並簽署的金鑰對。
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// 綁定 GlobalConfig：(報價代幣、curve_type、索引)。
const configId = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
if (!configData) throw new Error("config not found");
const configInfo = LaunchpadConfig.decode(configData.data);
const mintBInfo = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, transactions, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "Example Token",
  symbol: "EXMPL",                 // 必須為 10 個字元或更少
  uri:    "https://example.com/metadata.json",   // 必須非空
  migrateType: "amm",              // "amm" | "cpmm"

  configId,
  configInfo,                      // 可選；SDK 在省略時重新讀取 configId
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  // 可選的同一捆綁中的首次購買。
  createOnly: true,                // true = 僅建立代幣
  buyAmount:  new BN(1000),        // 當 createOnly 為 true 時忽略
  slippage:   new BN(100),         // 100 = 1%

  extraSigners: [pair],            // 基礎代幣金鑰對必須簽署
  txVersion: TxVersion.V0,

  // 預設值來自綁定設定的 API 預設值；僅在必要時覆蓋：
  // supply:            new BN(1_000_000_000_000_000),
  // totalSellA:        new BN(793_100_000_000_000),
  // totalFundRaisingB: new BN(85_000_000_000),   // 當 mintB 為 SOL 時為 85 SOL
  // totalLockedAmount: new BN(0),
  // cliffPeriod:       new BN(0),                // 秒
  // unlockPeriod:      new BN(0),                // 秒
  // platformId:        new PublicKey("4Bu96XjU84XjPDSpveTVf6LYGCkfW5FK7SNkREWcEfV4"), // Raydium 的，預設值
});

// createLaunchpad 返回多個交易 - 按順序執行它們。
const { txIds } = await execute({ sequentially: true });
console.log("Pool:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
console.log("Create txs:", txIds);
```

注意：

- **沒有** `curveType`、`graduationFractionBps`、`initialK`、`quoteMint`、`openTime`、`fees` 或 `postGraduationLpPolicy` 引數。曲線形狀和報價代幣是你綁定的 `GlobalConfig` 的屬性；費率存在於 `GlobalConfig` 和 `PlatformConfig` 上；畢業時的 LP 處置是 `PlatformConfig` 設定。見 [`products/launchlab/instructions`](/zh-Hant/products/launchlab/instructions#initialize) 了解 `InitializeV2` 確切接受的內容。
- 超過 10 個字元的 `symbol` 和空的 `uri` 都在任何 RPC 之前被客戶端拒絕。
- 傳遞 `transferFeeExtensionParams` 將建構器切換到 `InitializeWithToken2022` 並強制 `migrateType` 為 `"cpmm"`。
- 建構器返回一個 `transactions` 陣列；`createOnly: false` 新增首次購買交易。始終 `execute({ sequentially: true })` ——代幣必須在購買到達之前存在。

## 取得發行狀態

來源：[`src/launchpad/poolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/poolInfo.ts)

沒有 `getLaunchById`。池 ID 是 `(programId, mintA, mintB)` 的 PDA，`getRpcPoolInfo` 返回解碼的 `PoolState` 及其綁定的 `configInfo`：

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log("status:", poolInfo.status);
console.log("base sold:", poolInfo.realA.toString(), "/", poolInfo.totalSellA.toString());
console.log("quote raised:", poolInfo.realB.toString(), "/", poolInfo.totalFundRaisingB.toString());

// 曲線上的當前現貨價格。
const price = Curve.getPrice({
  poolInfo,
  curveType: poolInfo.configInfo.curveType,
  decimalA: poolInfo.mintDecimalsA,
  decimalB: poolInfo.mintDecimalsB,
});
console.log("price:", price.toString());
```

`getRpcPoolsInfo({ poolIdList })` 是批量形式，返回由池 ID 鍵入的 `poolInfoMap` ——用於投資組合檢視而不是迴圈。如果你想自己解碼原始帳戶，`LaunchpadPool.decode` 和 `LaunchpadConfig.decode` 已匯出。

## 購買——精確報價輸入

來源：[`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

離線報價幫助程式是 **`Curve.buyExactIn`**，是匯出的 `Curve` 類上的靜態方法——不是 `raydium.launchpad` 上的方法。交易建構器是 **`buyToken`**。兩者都需要平台的費率，這些費率存在於單獨的 `PlatformConfig` 帳戶上：

```ts
import { Curve, PlatformConfig, toTransferFeeConfig } from "@raydium-io/raydium-sdk-v2";

const inAmount = new BN(1).mul(new BN(10).pow(new BN(9)));   // 1 SOL
const slippage = new BN(100);                                 // 100 = 1%

const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });
const platformData = await raydium.connection.getAccountInfo(poolInfo.platformId);
const platformInfo = PlatformConfig.decode(platformData!.data);

const mintInfo  = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(poolInfo.mintB);
const epochInfo = await raydium.connection.getEpochInfo();

// 離線預覽——鏡像鏈上曲線數學。
const res = Curve.buyExactIn({
  poolInfo,
  amountB: inAmount,
  protocolFeeRate: poolInfo.configInfo.tradeFeeRate,
  platformFeeRate: platformInfo.feeRate,
  creatorFeeRate:  platformInfo.creatorFeeRate,
  curveType:       poolInfo.configInfo.curveType,
  shareFeeRate:    new BN(0),
  transferFeeConfigA: mintInfo.extensions.feeConfig  ? toTransferFeeConfig(mintInfo,  epochInfo.epoch) : undefined,
  transferFeeConfigB: mintBInfo.extensions.feeConfig ? toTransferFeeConfig(mintBInfo, epochInfo.epoch) : undefined,
  slot: await raydium.connection.getSlot(),
});
console.log("expected out:", res.amountA.amount.sub(res.amountA.fee ?? new BN(0)).toString());

const { execute, extInfo } = await raydium.launchpad.buyToken({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  transferFeeConfigB: toTransferFeeConfig(mintBInfo, epochInfo.epoch),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,
  buyAmount:       inAmount,
  slippage,                       // BN in bps; SDK 從中衍生 minMintAAmount
  txVersion: TxVersion.V0,
});

console.log("expected receive amount:", extInfo.decimalOutAmount.toString());
const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

你可以明確傳遞 `minMintAAmount` 而不是 `slippage`；省略兩者，SDK 從即時 RPC 資料計算界限。`shareFeeRate` 不得超過 `poolInfo.configInfo.maxShareFeeRate`，且僅在你也傳遞 `shareFeeReceiver` 時適用。

## 購買——精確基礎輸出

建構器是 **`buyTokenExactOut`**，金額引數是 `outAmount`（你想要的基礎）和 `maxBuyAmount`（你最多花費的報價）。`Curve.buyExactOut({ poolInfo, amountA, ... })` 是匹配的離線預覽。

```ts
const { execute, extInfo } = await raydium.launchpad.buyTokenExactOut({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,

  outAmount:    new BN(1_000_000).mul(new BN(10).pow(new BN(6))),  // 1M 基礎
  maxBuyAmount: new BN(2).mul(new BN(10).pow(new BN(9))),          // 上限 2 SOL
  slippage:     new BN(100),

  txVersion: TxVersion.V0,
});

console.log("out:", extInfo.outAmount.toString(), "max spent:", extInfo.maxSpentAmount.toString());
await execute({ sendAndConfirm: true });
```

適用於「精確購買 X 個代幣」UI。建構器在客戶端拒絕零 `outAmount`，如果曲線移動足夠使報價要求超過 `maxBuyAmount`，程式會還原。

## 銷售

來源：[`src/launchpad/sell.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/sell.ts)

建構器是 **`sellToken`**（精確報價輸出變體為 `sellTokenExactOut`），帶有 `sellAmount` 和可選的 `minAmountB`。`Curve.sellExactIn({ poolInfo, amountA, ... })` 預覽它。

```ts
const inAmount = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M 基礎

const res = Curve.sellExactIn({
  poolInfo,
  amountA: inAmount,
  protocolFeeRate: poolInfo.configInfo.tradeFeeRate,
  platformFeeRate: platformInfo.feeRate,
  creatorFeeRate:  platformInfo.creatorFeeRate,
  curveType:       poolInfo.configInfo.curveType,
  shareFeeRate:    new BN(0),
  transferFeeConfigA: mintInfo.extensions.feeConfig  ? toTransferFeeConfig(mintInfo,  epochInfo.epoch) : undefined,
  transferFeeConfigB: mintBInfo.extensions.feeConfig ? toTransferFeeConfig(mintBInfo, epochInfo.epoch) : undefined,
  slot: await raydium.connection.getSlot(),
});
console.log("expected quote out:", res.amountB.toString());

const { execute } = await raydium.launchpad.sellToken({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,
  sellAmount:      inAmount,
  slippage:        new BN(100),
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

曲線的銷售路徑對稱於購買路徑：將 `real_a` 減少 `sellAmount` 返回 `quote_out` 等於曲線下在 `real_a − sellAmount` 和 `real_a` 之間的積分面積，減去銷售費用。`sellAmount` 必須大於零——建構器在任何 RPC 之前在客戶端拒絕零。

## 畢業

<Warning>
  **畢業不是整合者可以觸發的事情。** 沒有 `raydium.launchpad.graduate`、購買建構器上沒有 `autoGraduate` 標誌，其返回值上也沒有 `willGraduate` 欄位。在鏈上，畢業是 `MigrateToCpswap`（或舊版 `MigrateToAmm`），兩個指令都將其簽署者限制為綁定 `GlobalConfig` 上記錄的錢包——`migrate_to_cpswap_wallet` 和 `migrate_to_amm_wallet` 分別。來自任何其他簽署者的呼叫失敗並出現 `InvalidOwner`。它**不是**無許可的，沒有 MEV 機器人可以搶先它。
</Warning>

這些錢包由 Raydium 的畢業 crank 操作，所以實際上無論誰進行最後購買，遷移都會在閾值被超越後的幾秒內進行。從整合者的角度來看，唯一要做的是將狀態轉換視為快速事件：輪詢 `getRpcPoolInfo`（或透過 gRPC 訂閱，見下文）並在 `status` 變更時將你的 UI 從曲線切換到結果 CPMM 池。

見 [`products/launchlab/instructions`](/zh-Hant/products/launchlab/instructions#migratetoamm-/-migratetocpswap) 了解帳戶列表、遷移費用以及畢業時 LP 如何分割。

## 收取創作者費用

來源：[`src/launchpad/claimCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/claimCreatorFee.ts)（單一代幣）和 [`collectAllCreatorFees.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/collectAllCreatorFees.ts)（批量）

方法是 **`claimCreatorFee`**（批量形式為 `claimMultipleCreatorFee`）。它由**報價代幣**鍵入，而不是由發行鍵入——一次呼叫會掃除簽署者在該代幣中跨其發行的累積創作者費用：

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute } = await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,          // 要在其中領取的報價代幣
  // mintBProgram: TOKEN_PROGRAM_ID,   // 或 TOKEN_2022_PROGRAM_ID
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

將累積的創作者費用計數器轉移到創作者在報價代幣上的 ATA。可在畢業前或後呼叫；定期使用它而不是等待巨大餘額累積。平台運營商有平行的 `claimPlatformFee` / `claimAllPlatformFee` / `claimVaultPlatformFee` 建構器。

## 透過其生命週期追蹤發行

綜合起來，監控指令碼可能看起來像：

```ts
async function watch(poolId: PublicKey) {
  const startStatus = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

  while (true) {
    const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
    const progress = Number(p.realB.toString()) / Number(p.totalFundRaisingB.toString());

    console.log(`status=${p.status}`, `progress=${(progress * 100).toFixed(2)}%`);

    if (p.status !== startStatus) {
      console.log("status changed - the launch has migrated; switch to the pool page");
      break;
    }
    await new Promise((r) => setTimeout(r, 10_000));
  }
}
```

在 10 秒計時器上輪詢 `getRpcPoolInfo` 對單一發行來說很好。對於索引器，改用下面的 gRPC 訂閱——`getRpcPoolsInfo({ poolIdList })` 批量，但輪詢數百個池仍然會為無益處而燃燒 RPC 信用。

## 透過 gRPC 監視設定和池

來源：[`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

透過 Yellowstone gRPC 訂閱 LaunchLab 程式，並記錄每個 `GlobalConfig` 和 `PoolState` 更新及每個代幣的代幣程式。一個 `accounts` 訂閱上的兩個 `datasize` 篩選器分離兩種帳戶類型，所以單一流涵蓋兩者。

示例是分類發行代幣的最短正確參考，[Token-2022 報價代幣發行](/zh-Hant/reference/changelog/2026-08-24-launchlab-token2022-quote-mint)使其成為必要：

- **池**直接從 `PoolState.token_program_flag` 分類，解碼位 0 用於基礎代幣，位 1 用於報價代幣，完全不進行代幣提取。測試整個位元組對 `0` ——在報價代幣僅為舊版時足夠——當報價代幣為 Token-2022 時誤讀舊版基礎代幣。
- **設定**不能以這種方式分類：`GlobalConfig` 儲存其報價代幣的地址且沒有程式標誌，所以示例讀取代幣帳戶的擁有者一次並按代幣快取它。

它也相互交叉檢查，這是在你自己的索引器中保持的有用斷言。注意 `create` 對 `update` 是從示例自己的快取推斷的，在啟動時從 `getProgramAccounts` 播種；禁用該播種後，讀取「create」為「首次在此流上看到」。

gRPC 存取不是公共 RPC 表面的一部分——見示例儲存庫的 [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md)。

## Rust CPI

從你自己的 Anchor 程式呼叫 LaunchLab 很少見（大多數發行整合僅為 TS 端）。如果你這樣做：

- 箱子是 **`raydium-launchpad`**（lib 名稱 `raydium_launchpad`），版本 `0.2.0`，它確實公開了 `cpi` 功能。**沒有** `raydium_launchlab`。
- 它**未在 crates.io 上發佈**——透過 git 修訂依賴它，與其他 Raydium 程式箱子相同的方式。
- CPI 進入點以鏈上指令命名，而不是以 SDK 的 TypeScript 方法命名：`buy_exact_in`、`buy_exact_out`、`sell_exact_in`、`sell_exact_out`、`claim_creator_fee`、`create_vesting_account`、`claim_vested_token`。`migrate_to_amm` / `migrate_to_cpswap` 對 `GlobalConfig` 遷移錢包的簽署者進行門控，不可從整合者程式呼叫。

見 [`sdk-api/rust-cpi`](/zh-Hant/sdk-api/rust-cpi) 了解箱子固定規則——特別是 Anchor 版本分割，它決定一個箱子是否可以 CPI 進入 LaunchLab 和 CLMM。

## 陷阱

- **混淆鏈上指令名稱與 SDK 方法名稱。** 程式有 `buy_exact_in` / `sell_exact_in`；SDK 有 `buyToken` / `sellToken`。`buyExactIn` 和 `sellExactIn` 僅作為 **`Curve` 上的靜態方法**存在，它們計算報價——它們不建構交易。
- **忘記 `extraSigners`。** `createLaunchpad` 從你生成的金鑰對建立基礎代幣，所以該金鑰對必須簽署。省略 `extraSigners: [pair]` 交易失敗簽名驗證。
- **不選擇報價代幣。** 你不傳遞一個。報價代幣是你透過 `configId` 綁定的 `GlobalConfig` 的屬性——`getPdaLaunchpadConfigId(programId, quoteMint, curveType, index)`。要針對不同的報價代幣發行，綁定不同的設定；`raydium.api.fetchLaunchConfigs()` 列出可用的及其預設參數。
- **元資料大小。** 長 `uri` 字串將 Metaplex CPI 推過預算。保持 `uri` 在 ~200 個字元以下——大多數 CDN 託管的 JSON 元資料輕鬆適配。`symbol` 硬上限為 10 個字元。
- **將畢業視為你可以進入的競賽。** 它不是——見上面的警告。你的 UI 仍應將 `status` 轉換視為快速事件，因為 Raydium 的 crank 在閾值被超越後的幾秒內進行遷移。
