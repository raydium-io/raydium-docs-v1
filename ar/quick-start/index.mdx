## المتطلبات الأساسية

قم بتشغيل هذا مرة واحدة:

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

تحتاج إلى:

- **Node 18+** مع دعم ESM (`"type": "module"` في `package.json` أو امتداد `.mjs`).
- **مفتاح Solana** في `~/.config/solana/id.json` (أو في أي مكان — اضبط `KEYPAIR`). راجع [`solana-fundamentals/toolchain`](/ar/solana-fundamentals/toolchain#solana-cli) لإنشاء مفتاح.
- **محفظة ممولة.** نص المبادلة يحتاج فقط إلى مبلغ الإدخال بالإضافة إلى وسادة صغيرة — تكلفة مبادلة CPMM حوالي 0.0015 SOL في رسوم الشبكة (راجع [`reference/fee-comparison`](/ar/reference/fee-comparison#network-fees-per-typical-operation))، بالإضافة إلى إيجار لمرة واحدة إذا كان على المبادلة فتح حساب رمز لك. إنشاء مجمع يكلف أكثر: نص CPMM وحده يحمل رسم إنشاء مجمع لمرة واحدة حوالي 0.15 SOL قبل السيولة الأولية أو الإيجار. راجع قسم الإعداد الخاص بكل نص للحصول على الرقم الحالي قبل تمويل محفظتك.
- **عنوان RPC.** يعمل RPC العام المجاني للاختبار؛ لأي شيء أكثر من اختبار بسيط، استخدم موفر مدفوع.

اضبط هذه مرة واحدة لكل shell:

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **الشبكة.** تستخدم جميع النصوص الثلاثة mainnet بشكل افتراضي. يحتاج Devnet إلى `RPC_URL=https://api.devnet.solana.com` بالإضافة إلى `cluster: "devnet"` داخل النص — بالنسبة لنصي إنشاء المجمع، هذا ليس التغيير الوحيد؛ راجع قسم الإعداد الخاص بكل نص لمعرفة ما يجب تغييره أيضًا. كن على علم بأن سيولة بذور المجمع على devnet نادرة؛ توقع إنشاء رموزك الاختبارية الخاصة.
</Info>

## بعد هذا الفصل

يطبع كل نص نتيجته على السلسلة — عرض سعر المبادلة ورابط المعاملة، عناوين المجمع الجديدة، أو مركز جديد و NFT الخاص به — وسطر واحد يشير إلى الصفحة التالية في فصل [SDK & API](/ar/sdk-api) للعملية التي قام بها. عندما تكون مستعدًا لكتابة التكامل الخاص بك:

- **الخوادم الخلفية والبوتات** → [Trade API](/ar/sdk-api/trade-api).
- **الواجهات الأمامية وتطبيقات التحكم الكامل** → [TypeScript SDK](/ar/sdk-api/typescript-sdk).
- **التكوين على السلسلة** → [Rust CPI](/ar/sdk-api/rust-cpi).
- **الاختيار بينها** → جدول المقارنة في أعلى [SDK & API](/ar/sdk-api).

```text
SDK:       @raydium-io/raydium-sdk-v2@0.2.42-alpha
Programs:  see /reference/program-addresses
Cluster:   mainnet-beta (also runs on devnet with the change noted above)
Verified:  2026-04
```

إذا انقطع نص برمجي في إصدار SDK أحدث، تحقق من ملاحظات الإصدار الخاصة به — تطورت أشكال إرجاع المنشئ بين الإصدارات الثانوية.
