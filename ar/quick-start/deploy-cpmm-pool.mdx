## الإعداد

تأكد من أنك قرأت [متطلبات البدء السريع](/ar/quick-start) وأن لديك `RPC_URL` و`KEYPAIR` والمكتبات المثبتة.

ستحتاج أيضاً إلى **تمويل المحفظة بمبالغ البذر** من كلا العملتين، بالإضافة إلى ما يكفي من SOL لتغطية رسوم إنشاء المجمع لمرة واحدة وإيجار الحساب (~0.19 SOL إجمالي على mainnet — انظر [`reference/fee-comparison`](/ar/reference/fee-comparison#creation-costs) لتفصيل الإيجار والرسوم، أو [`ray/protocol-fees`](/ar/ray/protocol-fees#pool-creation-fees) للرسوم فقط).

**تشغيل هذا على devnet.** تبديل `cluster` إلى `"devnet"` وحده غير كافٍ. يثبّت هذا السكريبت استيرادين محددين لا يتبعان `cluster`: `programId: CREATE_CPMM_POOL_PROGRAM` و`poolFeeAccount: CREATE_CPMM_POOL_FEE_ACC`، وكلاهما ثوابت mainnet. استورد `DEVNET_PROGRAM_ID` من SDK واستخدم `DEVNET_PROGRAM_ID.CREATE_CPMM_POOL_PROGRAM` و`DEVNET_PROGRAM_ID.CREATE_CPMM_POOL_FEE_ACC` بدلاً منهما — نفس النمط الذي يستخدمه [سكريبت CLMM](/ar/quick-start/deploy-clmm-pool).

## السكريبت

احفظه باسم `create-cpmm.mjs`:

```ts create-cpmm.mjs icon="js"
import { Connection, Keypair, PublicKey } from "@solana/web3.js";
import {
  Raydium,
  TxVersion,
  CREATE_CPMM_POOL_PROGRAM,
  CREATE_CPMM_POOL_FEE_ACC,
} from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

// ── Config from env ──────────────────────────────────────────────
const RPC_URL  = process.env.RPC_URL  ?? "https://api.mainnet-beta.solana.com";
const KEYPAIR  = process.env.KEYPAIR  ?? `${process.env.HOME}/.config/solana/id.json`;
const MINT_A   = process.env.MINT_A;   // required, base58
const MINT_B   = process.env.MINT_B;   // required, base58
const AMOUNT_A = process.env.AMOUNT_A; // required, integer raw units
const AMOUNT_B = process.env.AMOUNT_B; // required, integer raw units

if (!MINT_A || !MINT_B || !AMOUNT_A || !AMOUNT_B) {
  console.error("Set MINT_A, MINT_B, AMOUNT_A, AMOUNT_B env vars.");
  process.exit(1);
}

// ── Setup ────────────────────────────────────────────────────────
const connection = new Connection(RPC_URL, "confirmed");
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(KEYPAIR, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});

// ── Pick the 0.25% fee tier ─────────────────────────────────────
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0);
if (!feeConfig) throw new Error("0.25% fee tier not found in CPMM configs.");

// ── Resolve mint metadata (Token-2022-aware) ────────────────────
const mintA = await raydium.token.getTokenInfo(new PublicKey(MINT_A));
const mintB = await raydium.token.getTokenInfo(new PublicKey(MINT_B));

// ── Build and execute ───────────────────────────────────────────
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA,
  mintB,
  mintAAmount:     new BN(AMOUNT_A),
  mintBAmount:     new BN(AMOUNT_B),
  startTime:       new BN(0), // open immediately
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
  computeBudgetConfig: {
    units: 600_000,
    microLamports: 100_000,
  },
});

const { txId } = await execute({ sendAndConfirm: true });

console.log(`Pool ID:  ${extInfo.address.poolId.toBase58()}`);
console.log(`LP mint:  ${extInfo.address.lpMint.toBase58()}`);
console.log(`Vault A:  ${extInfo.address.vaultA.toBase58()}`);
console.log(`Vault B:  ${extInfo.address.vaultB.toBase58()}`);
console.log(`Tx:       https://solscan.io/tx/${txId}`);
```

## تشغيله

مثال: إنشاء مجمع SOL/USDC بـ 1 SOL و160 USDC كبذر أولي:

```bash icon="terminal"
export MINT_A="So11111111111111111111111111111111111111112"   # wSOL
export MINT_B="EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"   # USDC
export AMOUNT_A="1000000000"   # 1 SOL (9 decimals)
export AMOUNT_B="160000000"    # 160 USDC (6 decimals)

node create-cpmm.mjs
```

المخرجات المتوقعة:

```text
Pool ID:  HgC5...3kXb
LP mint:  4ZAS...9rkV
Vault A:  J9Mu...mP2k
Vault B:  AaJq...8wxx
Tx:       https://solscan.io/tx/5dQ...
```

## ما حدث للتو

1. **`getCpmmConfigs`** جلبت قائمة فئات الرسوم المباشرة من `api-v3.raydium.io` واختارت الفهرس 0 (فئة 0.25% — انظر [`reference/fee-comparison`](/ar/reference/fee-comparison) للمجموعة الكاملة).
2. **`getTokenInfo`** حلّت بيانات كل عملة، بما في ذلك برنامج الرمز الذي يملكها. يقبل CPMM عملات SPL Token و Token-2022؛ يوجّه SDK تلقائياً.
3. **`createPool`** بنت معاملة واحدة تقوم بـ:
   - ترتيب العملات بالترتيب الكنسي،
   - اشتقاق PDA للمجمع والخزائن وعملة LP والسلطة،
   - دفع `create_pool_fee` لمرة واحدة إلى `CREATE_CPMM_POOL_FEE_ACC`،
   - إنشاء ATAs للمستدعي إذا كانت مفقودة،
   - زرع الخزائن بـ `AMOUNT_A` و`AMOUNT_B`.
4. **السعر الأولي** يُحدد بنسبة البذر: `price = AMOUNT_B / AMOUNT_A` بعد تعديل الكسور العشرية. اختر هذا بعناية — ستقوم البوتات بالمراجحة لأي سعر خاطئ في غضون ثوانٍ من فتح المجمع.
5. **`startTime: new BN(0)`** يفتح التداول فوراً. لتجميع السيولة قبل الفتح للجمهور، عيّن طابع زمني Unix مستقبلي.

## الأخطاء الشائعة

- **`pool already exists`** — يوجد مجمع بالفعل لهذا الزوج من العملات بفئة الرسوم هذه. ابحث عنه قبل الإنشاء.
- **`insufficient funds`** — محفظتك لا تحتوي على ما يكفي من `MINT_A` أو `MINT_B` أو SOL (لرسوم إنشاء المجمع + الإيجار).
- **`Token-2022 extension not supported`** — إحدى عملاتك تستخدم امتداد لا يقبله CPMM. انظر [`reference/token-2022-support`](/ar/reference/token-2022-support).

## بعد النشر

يمكنك المبادلة مباشرة مقابل المجمع الجديد — يقبل سكريبت [المبادلة من CLI](/ar/quick-start/swap-from-cli) معرّف المجمع الجديد مباشرة. ستفهرس المجمعات (Jupiter، وغيرها) المجمع الجديد في غضون دقائق.
