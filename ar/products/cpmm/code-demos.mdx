## المتطلبات الأساسية

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js decimal.js
```

كل مثال على هذه الصفحة يعكس ملف في [`raydium-sdk-V2-demo/src/cpmm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/cpmm)؛ رابط GitHub يظهر بجانب كل قسم. يتبع التهيئة ملف `config.ts.template` من مستودع العروض التوضيحية ([المصدر](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)):

```ts
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);

const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
```

مثيل `Raydium` هو واجهة SDK — كل مثال أدناه يستخدمه. `Raydium.load` غير متزامن لأنه يحمّل قائمة الرموز بشكل افتراضي؛ مرّر `disableLoadToken: true` لتخطي هذا الجلب. فحص توفر الميزات مُتخطّى بالفعل ما لم تمرّر `disableFeatureCheck: false`. يتم جلب تكوينات الرسوم بكسل على الاستخدام الأول عبر `raydium.api.getCpmmConfigs()`.

## إنشاء pool CPMM

المصدر: [`src/cpmm/createCpmmPool.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/createCpmmPool.ts)

```ts
import { PublicKey } from "@solana/web3.js";
import BN from "bn.js";
import { CREATE_CPMM_POOL_PROGRAM, CREATE_CPMM_POOL_FEE_ACC }
  from "@raydium-io/raydium-sdk-v2";
// (إذا كنت تحتاج إلى كل PDA pool في المرة الواحدة، المساعد المُصدَّر هو `getCreatePoolKeys`.
//  لا يوجد `getCpmmPdas`.)

const mintA = new PublicKey("So11111111111111111111111111111111111111112"); // wSOL
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// 1. اختر تكوين رسوم. index=0 هو المستوى 0.25%.
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0)!;

// 2. اسحب بيانات mint حتى يتمكن SDK من التعامل مع امتدادات Token-2022.
const mintAInfo = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(mintB);

// 3. بناء المعاملة.
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA:           mintAInfo,
  mintB:           mintBInfo,
  mintAAmount:     new BN(1_000_000_000),   // 1 SOL (بافتراض 9 منازل عشرية)
  mintBAmount:     new BN(   160_000_000),  // 160 USDC (عند 160/SOL)
  startTime:       new BN(0),               // افتح فوراً
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("تم إنشاء Pool في", extInfo.address.poolId.toBase58());
console.log("Tx:", txId);
```

بعض الأشياء التي يتعامل معها SDK بصمت:

- ترتيب الرموز في ترتيب token0/token1 قبل اشتقاق PDA.
- دفع `create_pool_fee` لمرة واحدة إلى `poolFeeAccount`.
- إنشاء حسابات الرموز المرتبطة بالمتصل إذا كانت مفقودة.
- اختيار برنامج الرموز الصحيح (SPL Token مقابل Token-2022) لكل جانب.

بعد التأكيد، يمكنك جلب حالة pool المباشرة باستخدام:

```ts
// getPoolInfoFromRpc تأخذ سلسلة base58 موضعية، وليس PublicKey وليس كائن.
const { poolKeys, poolInfo, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(
  extInfo.address.poolId.toBase58(),
);
```

## Swap (base-input)

المصدر: [`src/cpmm/swap.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swap.ts)

```ts
import { CurveCalculator, FeeOn } from "@raydium-io/raydium-sdk-v2";

const POOL_ID = "<POOL_ID>";   // سلسلة base58

// 1. حمّل حالة pool الحالية مباشرة من RPC (وليس من API).
const { poolInfo, poolKeys, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(POOL_ID);

const inputMint  = poolInfo.mintA.address;                // swap A → B
const amountIn   = new BN(100_000_000);                   // 0.1 SOL
const slippage   = 0.005;                                 // 0.5%

// 2. احسب محليًا. CurveCalculator يعكس الرياضيات على السلسلة، بما في ذلك
//    رسوم نقل Token-2022 على كلا الجانبين. جميع ثمانية حجج مطلوبة.
const baseIn = inputMint === poolInfo.mintA.address;
const swapResult = CurveCalculator.swapBaseInput(
  amountIn,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// حقول swapResult هي inputAmount / outputAmount / tradeFee / protocolFee /
// fundFee / creatorFee / newInputVaultAmount / newOutputVaultAmount.
// لا يوجد destinationAmountSwapped أو sourceAmountSwapped.

// 3. بناء وإرسال. تمرير `slippage` هنا هو ما يطبق الحد —
//    لا حاجة لحساب minimum-out يدوي.
const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: amountIn,
  swapResult,
  slippage,
  baseIn,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Swap tx:", txId);
```

ملاحظة: SDK **دائماً** يعيد جلب حالة pool من RPC داخل `getPoolInfoFromRpc`. لا تقتبس من `api-v3.raydium.io` لمعاملة على وشك التوقيع — اقتباس قديم بمقدار كتلة واحدة يمكن أن ينزلق إلى `ExceededSlippage` في وقت الهبوط.

## Swap (base-output)

المصدر: [`src/cpmm/swapBaseOut.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swapBaseOut.ts)

```ts
const amountOutWanted = new BN(15_000_000);        // 15 USDC
const slippage        = 0.005;

const baseIn = false; // false → mintB هو جانب الإدخال
const swapResult = CurveCalculator.swapBaseOutput(
  amountOutWanted,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// swapResult.inputAmount هو الإدخال المطلوب؛ لا يوجد sourceAmountSwapped.

const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: new BN(0),   // غير مستخدم عند fixedOut — المبلغ يأتي من swapResult
  fixedOut:    true,
  swapResult,               // مطلوب، ويحمل مبلغ الإخراج المستهدف
  baseIn,
  slippage,
  txVersion:   TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

## إيداع السيولة

المصدر: [`src/cpmm/deposit.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/deposit.ts)

```ts
import { Percent } from "@raydium-io/raydium-sdk-v2";
import Decimal from "decimal.js";

// addLiquidity يتم تشغيله بواسطة مبلغ INPUT، وليس مبلغ LP.
const uiInputAmount = "0.0001";
const inputAmount = new BN(
  new Decimal(uiInputAmount).mul(10 ** poolInfo.mintA.decimals).toFixed(0),
);
const slippage = new Percent(1, 100);   // Percent، وليس رقم

const { execute } = await raydium.cpmm.addLiquidity({
  poolInfo,
  poolKeys,
  inputAmount,
  baseIn: true,           // inputAmount مقوّم بـ mintA
  slippage,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

يشتق SDK المبلغ المقترن من احتياطيات pool الحالية، ويضخّم كل جانب بـ slippage لحجج التعليمات `maximum_*`، وينشئ إنشاءات ATA إذا لزم الأمر. `raydium.cpmm.computePairAmount({ ... })` يعيد نفس الأرقام إذا كنت تريدها لمعاينة واجهة المستخدم.

## جمع رسوم البروتوكول/الصندوق/المنشئ

المصدر: [`src/cpmm/collectCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectCreatorFee.ts)، [`src/cpmm/collectAllCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectAllCreatorFee.ts)

جمع البروتوكول والصندوق يبقى محمياً بالسلطة. رسوم المنشئ لها مساران: `CollectCreatorFee` الموقّع من المنشئ، و `CollectCreatorFeePermissionless` الإضافي، الذي يمكن لأي دافع استدعاؤه لكن يمكنه نقل فقط إلى ATAs المنشئ الكنسية. `0.2.64-alpha` يشحن منشئي مستوى الوحدة لكلا مساري المنشئ:

```ts
// موقّع من المنشئ
const { execute } = await raydium.cpmm.collectCreatorFees({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// بدون إذن — أي دافع؛ العائدات تذهب إلى ATAs المنشئ الكنسية
const { execute } = await raydium.cpmm.collectCreatorFeesPermissionless({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// عدة pools في المرة الواحدة، موقّع من المنشئ
await raydium.cpmm.collectMultiCreatorFees({ poolInfoList, txVersion: TxVersion.V0 });
```

<Warning>
  **كلا تعليمات المنشئ غيّرت قوائم حساباتهما في ترقية البرنامج 2026-09-13.** كل واحد
  يأخذ الآن PDA `creator_fee_share` في `["creator_fee_share", creator, ammConfig]`، والواحد
  بدون إذن يأخذ `amm_config` أيضاً — كلاهما مُدرج قبل الخزائن. منشئ مثبّت
  على إصدار SDK يسبق الترقية يصدر التخطيط القديم والمعاملة تفشل في فك التسلسل. تحقق من أن الإصدار الذي تثبّته
  يحمل الحسابات الجديدة قبل استخدام هذه المساعدات مقابل البرنامج المُرقّى، وحدّث IDL إذا
  أنشأت عملاء منه.

  تمرير PDA إلزامي حتى عندما لم يتم إنشاؤه أبداً — اشتقه ومرّره؛ البرنامج يعود إلى
  `AmmConfig.creator_fee_share_rate` عندما يكون الحساب فارغاً.
</Warning>

<Note>
  تعليمات المنشئ الاثنتان لها **مميزات وتخطيطات حسابات مختلفة** — الواحد
  بدون إذن يستبدل موقّع المنشئ بدافع منفصل و
  منشئ غير موقّع. استخدم المنشئ المطابق بدلاً من تبديل الحسابات يدويًا على الآخر.

  لا يوجد منشئ رسوم بروتوكول أو صندوق في SDK (`makeCollectProtocolFeeInstruction` و
  `makeCollectFundFeeInstruction` لا توجد تحت أي اسم) — تلك مسارات إدارية، وكذلك
  `CreateCreatorFeeShare` / `CloseCreatorFeeShare`، التي لا تملك منشئ أيضاً. منشئو التعليمات
  منخفضة المستوى التي *تفعل* موجودة هي `collectCpFeeInstruction`،
  `makeCollectCreatorFeeInstruction` و `collectCreatorFeePermissionlessInInstruction`.
</Note>

خارج السلسلة يمكنك قراءة الرسوم المتراكمة مباشرة من `PoolState`:

```ts
const pool = await raydium.cpmm.getRpcPoolInfo(POOL_ID);   // سلسلة base58
console.log("رسوم البروتوكول المتراكمة mintA:", pool.protocolFeesMintA.toString());
console.log("رسوم البروتوكول المتراكمة mintB:", pool.protocolFeesMintB.toString());
// حقول CpmmPoolInfoLayout هي protocolFeesMintA/B، fundFeesMintA/B و
// creatorFeesMintA/B — لا توجد حقول ...Token0/...Token1.
//
// creatorFeesMintA/B هي الاستحقاق *الإجمالي*. المنشئ يتلقاها ناقصاً حصة
// البروتوكول المحلولة في وقت الجمع؛ protocolFeesMintA/B يتلقى تلك
// الحصة، لذا ينمو أيضاً على جمع رسوم المنشئ، وليس فقط على swaps.
// انظر products/cpmm/fees#protocol-share-of-the-creator-fee.
```

## هيكل Rust CPI

إذا كنت تريد استدعاء CPMM من برنامج Anchor الخاص بك — على سبيل المثال، خزينة تقوم بـ swap نيابة عن المودعين — سياق CPI يبدو هكذا. ترتيب الحساب يتبع [`products/cpmm/instructions`](/ar/products/cpmm/instructions).

```rust
// Cargo.toml — الفرع مهم: `master` لا يزال يثبّت anchor-lang 0.32.1.
// raydium-cp-swap = { git = "https://github.com/raydium-io/raydium-cp-swap",
//                     branch = "chore/upgrade-anchor", features = ["cpi"] }
// anchor-lang      = "=1.0.2"   // يجب أن يطابق ما يثبّته raydium-cp-swap
// anchor-spl       = "=1.0.2"
//
// ميزة `cpi` مطلوبة — وحدة `raydium_cp_swap::cpi` موجودة فقط
// تحتها. لاحظ أن هذا الصندوق لا يمكنه مشاركة برنامج مع عينة CLMM في
// products/clmm/code-demos، التي تثبّت anchor-lang =0.32.1.

use anchor_lang::prelude::*;
use anchor_spl::token_interface::{TokenAccount, TokenInterface, Mint};
use raydium_cp_swap::cpi::accounts::Swap;
use raydium_cp_swap::cpi;
use raydium_cp_swap::program::RaydiumCpSwap;

#[derive(Accounts)]
pub struct ProxySwap<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,

    /// CHECK: تم التحقق من قبل برنامج CPMM
    pub authority:     UncheckedAccount<'info>,
    /// CHECK:
    pub amm_config:    UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub pool_state:    UncheckedAccount<'info>,

    #[account(mut)]
    pub input_token_account:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_token_account: InterfaceAccount<'info, TokenAccount>,

    #[account(mut)]
    pub input_vault:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_vault: InterfaceAccount<'info, TokenAccount>,

    pub input_token_program:  Interface<'info, TokenInterface>,
    pub output_token_program: Interface<'info, TokenInterface>,

    pub input_token_mint:  InterfaceAccount<'info, Mint>,
    pub output_token_mint: InterfaceAccount<'info, Mint>,

    #[account(mut)]
    /// CHECK: حلقة buffer
    pub observation_state: UncheckedAccount<'info>,

    pub cpmm_program: Program<'info, RaydiumCpSwap>,
}

pub fn proxy_swap_base_input(
    ctx: Context<ProxySwap>,
    amount_in: u64,
    minimum_amount_out: u64,
) -> Result<()> {
    let cpi_accounts = Swap {
        payer:                ctx.accounts.payer.to_account_info(),
        authority:            ctx.accounts.authority.to_account_info(),
        amm_config:           ctx.accounts.amm_config.to_account_info(),
        pool_state:           ctx.accounts.pool_state.to_account_info(),
        input_token_account:  ctx.accounts.input_token_account.to_account_info(),
        output_token_account: ctx.accounts.output_token_account.to_account_info(),
        input_vault:          ctx.accounts.input_vault.to_account_info(),
        output_vault:         ctx.accounts.output_vault.to_account_info(),
        input_token_program:  ctx.accounts.input_token_program.to_account_info(),
        output_token_program: ctx.accounts.output_token_program.to_account_info(),
        input_token_mint:     ctx.accounts.input_token_mint.to_account_info(),
        output_token_mint:    ctx.accounts.output_token_mint.to_account_info(),
        observation_state:    ctx.accounts.observation_state.to_account_info(),
    };
    // Anchor 1.0 يأخذ Pubkey البرنامج هنا، وليس AccountInfo.
    let cpi_ctx = CpiContext::new(
        *ctx.accounts.cpmm_program.key,
        cpi_accounts,
    );
    cpi::swap_base_input(cpi_ctx, amount_in, minimum_amount_out)
}
```

إذا كان CPI الخاص بك يوقّع كـ PDA (على سبيل المثال، تدير خزينة نيابة عن المودعين)، استبدل `CpiContext::new` بـ `CpiContext::new_with_signer` ومرّر بذورك.

## الأخطاء الشائعة

قائمة تحقق قصيرة قبل فتح تذكرة دعم:

- **الرموز المرتبة.** إذا كان `poolState` PDA المشتق الخاص بك لا يطابق pool على السلسلة، فربما نسيت ترتيب الرموز.
- **اقتباس API قديم.** لا تمرّر قيمة احتياطي من `api-v3.raydium.io` إلى `CurveCalculator.swap`. اجلب من RPC.
- **برنامج الرموز الخاطئ.** خزينة mint Token-2022 مملوكة من قبل برنامج Token-2022، وليس من قبل SPL Token. استخدم دائماً حقول pool `token_0_program` / `token_1_program`.
- **Slippage تحت المقسوم عليه لرموز رسوم النقل.** إذا كان أي جانب من pool هو mint Token-2022 برسوم نقل، فإن `minimum_amount_out` الخاص بك يجب أن يكون مقوّماً بما يتلقاه المستخدم فعلاً، وليس بما تُرسله الخزينة.
- **`NotApproved` على swap.** تحقق من `PoolState.status` — قد يكون المسؤول قد أوقف swaps على هذا pool. انظر [`products/cpmm/instructions`](/ar/products/cpmm/instructions) لقناع الحالة.
