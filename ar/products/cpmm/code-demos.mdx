## المتطلبات الأساسية

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js decimal.js
```

كل مثال على هذه الصفحة يعكس ملفًا في [`raydium-sdk-V2-demo/src/cpmm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/cpmm)؛ يوجد رابط GitHub بجانب كل قسم. يتبع التمهيد ملف `config.ts.template` الخاص بمستودع العرض التوضيحي ([المصدر](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)):

```ts
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);

const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
```

مثيل `Raydium` هو واجهة SDK — يستخدمه كل مثال أدناه. `Raydium.load` غير متزامن لأنه يحمل قائمة الرموز بشكل افتراضي؛ مرر `disableLoadToken: true` لتخطي هذا الجلب. تم بالفعل تخطي فحص توفر الميزة ما لم تمرر `disableFeatureCheck: false`. يتم جلب تكوينات الرسوم بكسل عند الاستخدام الأول عبر `raydium.api.getCpmmConfigs()`.

## إنشاء مجمع CPMM

المصدر: [`src/cpmm/createCpmmPool.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/createCpmmPool.ts)

```ts
import { PublicKey } from "@solana/web3.js";
import BN from "bn.js";
import { CREATE_CPMM_POOL_PROGRAM, CREATE_CPMM_POOL_FEE_ACC }
  from "@raydium-io/raydium-sdk-v2";
// (إذا كنت بحاجة إلى كل PDA مجمع في وقت واحد، فإن المساعد المُصدَّر هو `getCreatePoolKeys`.
//  لا يوجد `getCpmmPdas`.)

const mintA = new PublicKey("So11111111111111111111111111111111111111112"); // wSOL
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// 1. اختر تكوين رسوم. index=0 هو المستوى 0.25%.
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0)!;

// 2. اسحب بيانات وصف الرمز حتى يتمكن SDK من التعامل مع امتدادات Token-2022.
const mintAInfo = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(mintB);

// 3. بناء المعاملة.
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA:           mintAInfo,
  mintB:           mintBInfo,
  mintAAmount:     new BN(1_000_000_000),   // 1 SOL (بافتراض 9 منازل عشرية)
  mintBAmount:     new BN(   160_000_000),  // 160 USDC (عند 160/SOL)
  startTime:       new BN(0),               // افتح فورًا
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("تم إنشاء المجمع في", extInfo.address.poolId.toBase58());
console.log("Tx:", txId);
```

بعض الأشياء التي يتعامل معها SDK بصمت:

- فرز الرموز إلى ترتيب token0/token1 قبل اشتقاق PDA.
- دفع `create_pool_fee` لمرة واحدة إلى `poolFeeAccount`.
- إنشاء حسابات الرموز المرتبطة بالمتصل إذا كانت مفقودة.
- اختيار برنامج الرمز الصحيح (SPL Token مقابل Token-2022) لكل جانب.

<Note>
  **تبني `createPool` التعليمة `Initialize`، لذا تكون رسوم المنشئ للمجمع معطّلة.** لإنشاء مجمع مع تفعيل رسوم المنشئ، استخدم `InitializeV2` (أُضيفت في ترقية البرنامج 2026-10-30). أول 19 حسابًا فيها تطابق `Initialize`. تحذف `rent` وتأخذ معاملًا إضافيًا واحدًا، `creator_fee_on: Option<CreatorFeeOn>`. إصدار `0.2.64-alpha` المثبّت في هذه الصفحة أقدم من هذه التعليمة. إلى أن يتضمن إصدار SDK لديك منشئًا لها، رمّزها من IDL المحدَّث. انظر [`products/cpmm/instructions`](/ar/products/cpmm/instructions#initializev2).
</Note>

بعد التأكيد، يمكنك جلب حالة المجمع المباشرة باستخدام:

```ts
// getPoolInfoFromRpc تأخذ سلسلة base58 موضعية، وليس PublicKey وليس كائنًا.
const { poolKeys, poolInfo, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(
  extInfo.address.poolId.toBase58(),
);
```

## مبادلة (إدخال أساسي)

المصدر: [`src/cpmm/swap.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swap.ts)

```ts
import { CurveCalculator, FeeOn } from "@raydium-io/raydium-sdk-v2";

const POOL_ID = "<POOL_ID>";   // سلسلة base58

// 1. حمّل حالة المجمع الحالية مباشرة من RPC (وليس من API).
const { poolInfo, poolKeys, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(POOL_ID);

const inputMint  = poolInfo.mintA.address;                // مبادلة A → B
const amountIn   = new BN(100_000_000);                   // 0.1 SOL
const slippage   = 0.005;                                 // 0.5%

// 2. احصل على عرض سعر محليًا. CurveCalculator يعكس الرياضيات على السلسلة، بما في ذلك
//    رسوم نقل Token-2022 على كلا الجانبين. جميع ثمانية الحجج مطلوبة.
const baseIn = inputMint === poolInfo.mintA.address;
const swapResult = CurveCalculator.swapBaseInput(
  amountIn,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// حقول swapResult هي inputAmount / outputAmount / tradeFee / protocolFee /
// fundFee / creatorFee / newInputVaultAmount / newOutputVaultAmount.
// لا يوجد destinationAmountSwapped أو sourceAmountSwapped.

// 3. بناء وإرسال. تمرير `slippage` هنا هو ما يطبق الحد —
//    لا حاجة لحساب الحد الأدنى للإخراج اليدوي.
const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: amountIn,
  swapResult,
  slippage,
  baseIn,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("معاملة المبادلة:", txId);
```

ملاحظة: SDK **دائمًا** يعيد جلب حالة المجمع من RPC داخل `getPoolInfoFromRpc`. لا تحصل على عرض سعر من `api-v3.raydium.io` لمعاملة أنت على وشك التوقيع عليها — عرض سعر قديم بمقدار كتلة واحدة يمكن أن ينزلق إلى `ExceededSlippage` في وقت الهبوط.

const amountOutWanted = new BN(15_000_000);        // 15 USDC

## إيداع السيولة

المصدر: [`src/cpmm/deposit.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/deposit.ts)

```ts
import { Percent } from "@raydium-io/raydium-sdk-v2";
import Decimal from "decimal.js";

// addLiquidity يتم تشغيله بواسطة مبلغ INPUT، وليس مبلغ LP.
const uiInputAmount = "0.0001";
const inputAmount = new BN(
  new Decimal(uiInputAmount).mul(10 ** poolInfo.mintA.decimals).toFixed(0),
);
const slippage = new Percent(1, 100);   // Percent، وليس رقمًا

const { execute } = await raydium.cpmm.addLiquidity({
  poolInfo,
  poolKeys,
  inputAmount,
  baseIn: true,           // inputAmount مقوّم بـ mintA
  slippage,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

يشتق SDK المبلغ المقترن من احتياطيات المجمع الحالية، ويضخم كل جانب بمقدار الانزلاق لحجج `maximum_*` الخاصة بالتعليمات، وينشئ إنشاءات ATA إذا لزم الأمر. `raydium.cpmm.computePairAmount({ ... })` يعيد نفس الأرقام إذا كنت تريدها لمعاينة واجهة المستخدم.

## جمع رسوم البروتوكول والصندوق والمنشئ

المصدر: [`src/cpmm/collectCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectCreatorFee.ts)، [`src/cpmm/collectAllCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectAllCreatorFee.ts)

جمع البروتوكول والصندوق يبقى محميًا بالسلطة. رسوم المنشئ لها مساران: `CollectCreatorFee` الموقّع من المنشئ، و`CollectCreatorFeePermissionless` الإضافي، الذي يمكن لأي دافع أن يستدعيه لكنه يمكنه التحويل فقط إلى ATAs المنشئ الأساسية. يشحن الإصدار `0.2.64-alpha` منشئي مستوى الوحدة لكلا مسار المنشئ:

```ts
// موقّع من المنشئ
const { execute } = await raydium.cpmm.collectCreatorFees({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// بدون إذن — أي دافع؛ العائدات تذهب إلى ATAs المنشئ الأساسية
const { execute } = await raydium.cpmm.collectCreatorFeesPermissionless({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// عدة مجموعات في المرة الواحدة، موقّع من المنشئ
await raydium.cpmm.collectMultiCreatorFees({ poolInfoList, txVersion: TxVersion.V0 });
```

<Warning>
  **كلا تعليمات المنشئ غيّرت قوائم حساباتهما في ترقية البرنامج بتاريخ 2026-09-19.** كل واحدة تأخذ الآن PDA `creator_fee_share` في `["creator_fee_share", creator, ammConfig]`، والتعليمة بدون إذن تأخذ `amm_config` أيضًا — كلاهما **مُلحق بعد `system_program`** بدلاً من الإدراج، لذا الحسابات التي كانت موجودة بالفعل تحتفظ بمواضعها. منشئ مثبّت على إصدار SDK يسبق الترقية يصدر القائمة الأقصر والمعاملة مرفوضة لحسابات مفقودة. تحقق من أن الإصدار الذي تثبّته يحمل الحسابات الجديدة قبل استخدام هذه المساعدات مع البرنامج المُرقّى، وحدّث IDL إذا كنت تولّد عملاء منه.

  تمرير PDA إلزامي حتى عندما لم يتم إنشاؤه أبدًا — اشتقه ومرّره؛ البرنامج يعود إلى `AmmConfig.creator_fee_share_rate` عندما يكون الحساب فارغًا.
</Warning>

<Note>
  تعليمات المنشئ الاثنتان لها **مميزات وتخطيطات حسابات مختلفة** — التعليمة بدون إذن تستبدل موقّع المنشئ بـ `payer` منفصل و`creator` غير موقّع. استخدم المنشئ المطابق بدلاً من تبديل الحسابات يدويًا على الآخر.

  لا يوجد منشئ رسوم بروتوكول أو صندوق في SDK (`makeCollectProtocolFeeInstruction` و`makeCollectFundFeeInstruction` غير موجودة تحت أي اسم) — تلك مسارات إدارية، وكذلك `CreateCreatorFeeShare` / `CloseCreatorFeeShare`، التي ليس لها منشئ أيضًا. منشئو التعليمات منخفضة المستوى التي *توجد* هي `collectCpFeeInstruction`، `makeCollectCreatorFeeInstruction` و`collectCreatorFeePermissionlessInInstruction`.
</Note>

خارج السلسلة يمكنك قراءة الرسوم المتراكمة مباشرة من `PoolState`:

```ts
const pool = await raydium.cpmm.getRpcPoolInfo(POOL_ID);   // base58 string
console.log("Accrued protocol fee mintA:", pool.protocolFeesMintA.toString());
console.log("Accrued protocol fee mintB:", pool.protocolFeesMintB.toString());
// حقول CpmmPoolInfoLayout هي protocolFeesMintA/B, fundFeesMintA/B و
// creatorFeesMintA/B — لا توجد حقول ...Token0/...Token1.
//
// creatorFeesMintA/B هي التراكم *الإجمالي*. المنشئ يستقبله مطروحًا منه حصة
// البروتوكول المحسوبة عند الجمع؛ protocolFeesMintA/B يستقبل تلك
// الحصة، لذا ينمو أيضًا عند جمع رسوم المنشئ، وليس فقط عند المبادلات.
// انظر products/cpmm/fees#protocol-share-of-the-creator-fee.
```

## هيكل Rust CPI

إذا كنت تريد استدعاء CPMM من برنامج Anchor الخاص بك — على سبيل المثال، خزينة تقوم بالمبادلة نيابة عن المودعين — سياق CPI يبدو هكذا. ترتيب الحسابات يتبع [`products/cpmm/instructions`](/ar/products/cpmm/instructions).

```rust
// Cargo.toml — `master` يثبّت anchor-lang =1.0.2.
// raydium-cp-swap = { git = "https://github.com/raydium-io/raydium-cp-swap",
//                     branch = "master", features = ["cpi"] }
// anchor-lang      = "=1.0.2"   // يجب أن يطابق ما يثبّته raydium-cp-swap
// anchor-spl       = "=1.0.2"
//
// ميزة `cpi` مطلوبة — وحدة `raydium_cp_swap::cpi` موجودة فقط
// تحتها. العينة CLMM في products/clmm/code-demos تثبّت نفس
// =1.0.2 على `master` الخاص بها، لذا الاثنان يمكنهما مشاركة برنامج.

use anchor_lang::prelude::*;
use anchor_spl::token_interface::{TokenAccount, TokenInterface, Mint};
use raydium_cp_swap::cpi::accounts::Swap;
use raydium_cp_swap::cpi;
use raydium_cp_swap::program::RaydiumCpSwap;

#[derive(Accounts)]
pub struct ProxySwap<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,

    /// CHECK: validated by the CPMM program
    pub authority:     UncheckedAccount<'info>,
    /// CHECK:
    pub amm_config:    UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub pool_state:    UncheckedAccount<'info>,

    #[account(mut)]
    pub input_token_account:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_token_account: InterfaceAccount<'info, TokenAccount>,

    #[account(mut)]
    pub input_vault:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_vault: InterfaceAccount<'info, TokenAccount>,

    pub input_token_program:  Interface<'info, TokenInterface>,
    pub output_token_program: Interface<'info, TokenInterface>,

    pub input_token_mint:  InterfaceAccount<'info, Mint>,
    pub output_token_mint: InterfaceAccount<'info, Mint>,

    #[account(mut)]
    /// CHECK: ring buffer
    pub observation_state: UncheckedAccount<'info>,

    pub cpmm_program: Program<'info, RaydiumCpSwap>,
}

pub fn proxy_swap_base_input(
    ctx: Context<ProxySwap>,
    amount_in: u64,
    minimum_amount_out: u64,
) -> Result<()> {
    let cpi_accounts = Swap {
        payer:                ctx.accounts.payer.to_account_info(),
        authority:            ctx.accounts.authority.to_account_info(),
        amm_config:           ctx.accounts.amm_config.to_account_info(),
        pool_state:           ctx.accounts.pool_state.to_account_info(),
        input_token_account:  ctx.accounts.input_token_account.to_account_info(),
        output_token_account: ctx.accounts.output_token_account.to_account_info(),
        input_vault:          ctx.accounts.input_vault.to_account_info(),
        output_vault:         ctx.accounts.output_vault.to_account_info(),
        input_token_program:  ctx.accounts.input_token_program.to_account_info(),
        output_token_program: ctx.accounts.output_token_program.to_account_info(),
        input_token_mint:     ctx.accounts.input_token_mint.to_account_info(),
        output_token_mint:    ctx.accounts.output_token_mint.to_account_info(),
        observation_state:    ctx.accounts.observation_state.to_account_info(),
    };
    // Anchor 1.0 يأخذ Pubkey البرنامج هنا، وليس AccountInfo.
    let cpi_ctx = CpiContext::new(
        *ctx.accounts.cpmm_program.key,
        cpi_accounts,
    );
    cpi::swap_base_input(cpi_ctx, amount_in, minimum_amount_out)
}
```

إذا كان CPI الخاص بك يوقّع كـ PDA (على سبيل المثال، تدير خزينة نيابة عن المودعين)، استبدل `CpiContext::new` بـ `CpiContext::new_with_signer` ومرّر بذورك.

## الأخطاء الشائعة

قائمة تحقق قصيرة قبل فتح تذكرة دعم:

- **Sorted mints.** إذا كان PDA `poolState` المشتق لا يطابق المجموعة على السلسلة، فربما نسيت فرز الـ mints.
- **Stale API quote.** لا تمرر أبدًا قيمة احتياطي من `api-v3.raydium.io` إلى `CurveCalculator.swap`. اجلب من RPC.
- **Wrong token program.** خزينة mint Token-2022 مملوكة من برنامج Token-2022، وليس من SPL Token. استخدم دائمًا حقول `token_0_program` / `token_1_program` للمجموعة.
- **Slippage under-denominated for transfer-fee mints.** إذا كان أي جانب من المجموعة mint Token-2022 برسوم نقل، فإن `minimum_amount_out` الخاص بك يجب أن يكون مقومًا بما يستقبله المستخدم فعليًا، وليس بما ترسله الخزينة.
- **`NotApproved` on a swap.** تحقق من `PoolState.status` — قد يكون المسؤول قد أوقف المبادلات على تلك المجموعة. انظر [`products/cpmm/instructions`](/ar/products/cpmm/instructions) لقناع الحالة.
