<Info>
  `PlatformConfig` هو **تراكب على مستوى المنصة** يقع فوق [`GlobalConfig`](/ar/products/launchlab/global-config). بينما يحدد `GlobalConfig` القواعد على مستوى البروتوكول ("رسم التداول 1%، يجب أن يكون الإمداد 10 مليون على الأقل، فقط هذا المحفظة يمكنها التخرج")، `PlatformConfig` هو ما تستخدمه كل منصة إطلاق — pump.fun، واجهة Raydium الخاصة، منصات الإطلاق من جهات خارجية — لإضافة رسومها، والمطالبة بحصتها من LP بعد التخرج، وتقييد أشكال المنحنيات التي يمكن لعمليات الإطلاق الخاصة بها أن تختارها، وعرض علامتها التجارية (الاسم والموقع والصورة) على السلسلة.
</Info>

## ما هو

حساب `PlatformConfig` يمتلك خمس مخاوف متقاطعة لمنصة:

1. **العلامة التجارية** — الاسم والموقع ورابط الصورة، كلها مخزنة بشكل مضمن بحيث يمكن لأي مستكشف أو معالج بيانات عرض المنصة التي أطلقت الرمز.
2. **رسم المنصة** — رسم تداول إضافي (`fee_rate`) بالإضافة إلى `trade_fee_rate` الخاص بالبروتوكول. يتراكم في `platform_fee_wallet` الخاص بالمنصة. محدود بـ 100 bps بواسطة `GlobalConfig.max_share_fee_rate`.
3. **تقسيم هجرة LP** — ثلاثة أعداد مخزنة (`platform_scale`, `creator_scale`, `burn_scale`) تجمع إلى `1_000_000`. قبل ترقية 2026-08-17، كان مقياس المنشئ ينتج مفتاح رسم منشئ منفصل. الهجرات المنفذة بعد الترقية تجمع الاثنين الأولين في حصة LP مقفلة واحدة مملوكة للمنصة؛ الباقي يتم حرقه.
4. **قائمة بيضاء لمعاملات المنحنى** — `Vec<PlatformCurveParam>` يسرد بالضبط أي مجموعات `(supply, total_base_sell, total_quote_fund_raising, migrate_type, migrate_cpmm_fee_on, vesting_params...)` مسموحة على هذه المنصة. إذا كان المتجه فارغًا أو جميع الإدخالات غير صالحة، **أي** مجموعة مسموحة؛ وإلا يجب أن تطابق عمليات الإطلاق أحد الإدخالات بالضبط.
5. **قائمة بيضاء للتكوين العام** — تقييد اختياري يتطلب `PlatformAllowConfig` التي أنشأتها المنصة للـ `GlobalConfig` المختار.

اشتقاق PDA:

```ts
const [platformConfigPda] = PublicKey.findProgramAddressSync(
  [
    Buffer.from("platform_config"),
    platformAdmin.toBuffer(),       // platform's owning pubkey
  ],
  LAUNCHLAB_PROGRAM_ID,
);
```

(انظر `create_platform_config` في المصدر للحصول على قائمة البذور الموثوقة.)

## التخطيط

```rust
// states/platform_config.rs
pub const PLATFORM_CONFIG_SEED: &str = "platform_config";
pub const NAME_SIZE: usize = 64;
pub const WEB_SIZE:  usize = 256;
pub const IMG_SIZE:  usize = 256;
pub const MAX_CREATOR_FEE_RATE: u64 = 5000;       // 50 bps (denominator 1_000_000)
pub const MAX_TRANSFER_FEE_RATE: u16 = 500;       // 5%   (denominator 10_000)
pub const MAX_CURVE_PARAMS: usize = 10;

#[account]
pub struct PlatformConfig {
    pub epoch:                       u64,
    pub platform_fee_wallet:         Pubkey,            // signs ClaimPlatformFee
    pub platform_nft_wallet:         Pubkey,            // receives the platform NFT slice at CPMM graduation
    pub platform_scale:              u64,               // share of LP minted to platform NFT
    pub creator_scale:               u64,               // creator share before upgrade; added to platform share afterward
    pub burn_scale:                  u64,               // share of LP burned permanently
    pub fee_rate:                    u64,               // platform's trade fee (1/1_000_000)
    pub name:                        [u8; 64],          // utf-8 padded with zeros
    pub web:                         [u8; 256],
    pub img:                         [u8; 256],
    pub cpswap_config:               Pubkey,            // CPMM AmmConfig that the post-grad pool will bind to
    pub creator_fee_rate:            u64,               // creator-side fee taken pre-graduation
    pub transfer_fee_extension_auth: Pubkey,            // for Token-2022 launches: who inherits transfer-fee authorities post-graduation
    pub platform_vesting_wallet:     Pubkey,
    pub platform_vesting_scale:      u64,               // platform's slice of total_locked_amount
    pub platform_cp_creator:         Pubkey,            // optional creator-of-record on the post-graduation CPMM pool
    pub restrict_global_config:      u8,                // 0 = unrestricted, 1 = require allow PDA
    pub padding:                     [u8; 107],
    pub curve_params:                Vec<PlatformCurveParam>, // whitelist of permitted curve shapes
}
```

يجب أن يساوي `platform_scale + creator_scale + burn_scale` قيمة `1_000_000`. قبل ترقية 2026-08-17، كان `creator_scale` مقفولًا بشكل منفصل وذهب مفتاح الرسم الخاص به إلى منشئ الرمز. بالنسبة للهجرات المنفذة بعد الترقية، يتم إضافته إلى `platform_scale` وتذهب حقوق LP المقفلة الخاصة به إلى المنصة بدلاً من ذلك. نتائج مثال تحت المنطق المحدث:

- `(0, 100_000, 900_000)` — 90% LP محروق، 10% مقفل للمنصة.
- `(50_000, 100_000, 850_000)` — 85% محروق، 15% مقفل للمنصة.
- `(0, 0, 1_000_000)` — حرق كامل، لا توجد عملات NFT. عمليات إطلاق صارمة "بدون مطلعين".

## حقول العلامة التجارية

`name` و `web` و `img` عبارة عن مصفوفات بايت مضمنة مملوءة بأصفار حتى ثوابتها. لقراءتها كسلاسل، قم بالتقطيع حتى أول `\0`:

```ts
function readString(bytes: Uint8Array): string {
  const end = bytes.indexOf(0);
  return Buffer.from(end === -1 ? bytes : bytes.subarray(0, end)).toString("utf-8");
}
```

الثوابت متحفظة عن قصد (`name: 64`, `web: 256`, `img: 256`) بحيث يمكن للمنصات تضمين بيانات وصفية كافية للمستكشفات ومعالجات البيانات دون لمس التخزين خارج السلسلة. أي شيء يتجاوز هذه الأحجام سيعود عند `CreatePlatformConfig` مع `InvalidInput`.

## ميكانيكا الرسوم

يفرض التبديل على منحنى مرتبط بـ `PlatformConfig` ثلاث رسوم متعددة الطبقات:

```
trade_fee     = amount_in × global_config.trade_fee_rate    / 1_000_000
platform_fee  = amount_in × platform_config.fee_rate        / 1_000_000
creator_fee   = amount_in × platform_config.creator_fee_rate / 1_000_000

amount_after_fee = amount_in − trade_fee − platform_fee − creator_fee
```

- `trade_fee` يتراكم في `protocol_fee_owner` الخاص بالبروتوكول (يتم المطالبة به عبر `CollectFee`).
- `platform_fee` يتراكم في خزينة لكل منصة (يتم المطالبة به عبر `ClaimPlatformFee` أو `ClaimPlatformFeeFromVault`؛ انظر [`instructions`](/ar/products/launchlab/instructions)).
- `creator_fee` يتراكم في خزينة لكل منشئ مفتاح بواسطة pubkey المنشئ + quote mint (يتم المطالبة به عبر `ClaimCreatorFee`).

`creator_fee_rate` محدود بـ `MAX_CREATOR_FEE_RATE = 5000` (50 bps). `fee_rate` (رسم المنصة) محدود بـ `10000` (100 bps) بواسطة `GlobalConfig.max_share_fee_rate`.

## تقسيم هجرة NFT (CPMM فقط)

عندما يتخرج الإطلاق إلى CPMM، تقسم تعليمات الهجرة رموز LP التي تم سكها بواسطة `CPMM::InitializeWithPermission` بطريقتين:

```
lp_to_platform = floor(lp_total × (platform_scale + creator_scale) / 1_000_000)
lp_to_burn     = lp_total − lp_to_platform
```

إذا كان `lp_to_platform` غير صفري، يقوم برنامج LP-Lock بتغليفه في مفتاح رسم NFT واحد مملوك بواسطة `platform_nft_wallet`. هذا يحل محل السلوك السابق للترقية الذي أنشأ مفاتيح رسم منفصلة للمنصة والمنشئ. تبقى مفاتيح الرسم التي تم إنشاؤها بواسطة الهجرات المكتملة قبل الترقية دون تغيير. هذا الحق في رسم LP منفصل عن رسوم منشئ CPMM التي يتحكم فيها `platform_cp_creator`.

يتم حرق شريحة الحرق مباشرة، لذا لا يمكن لأي حساب سحبها أو المطالبة برسوم LP التي تمثلها تلك الحصة.

عمليات الإطلاق الموجودة مع `migrate_type = 0` المخزنة يمكنها لا تزال استخدام مسار AMM v4 القديم. يرفض التهيئة الجديدة نوع الهجرة هذا.

## قائمة بيضاء لمعاملات المنحنى

`curve_params: Vec<PlatformCurveParam>` هي آلية المنصة لتقييد أشكال المنحنيات التي يمكن لعمليات الإطلاق الخاصة بها أن تختارها. إذا كان المتجه غير فارغ وكان هناك إدخال واحد على الأقل صالحًا، يفرض البرنامج عند `Initialize` أن معاملات الإطلاق تطابق إدخالًا واحدًا على الأقل بالضبط.

```rust
#[derive(AnchorSerialize, AnchorDeserialize, Clone)]
pub struct PlatformCurveParam {
    pub epoch:                u64,
    pub index:                u8,           // ordinal within this platform's whitelist
    pub global_config:        Pubkey,       // which GlobalConfig this entry applies to
    pub bonding_curve_param:  BondingCurveParam,
    pub padding:              [u64; 50],
}

#[derive(AnchorSerialize, AnchorDeserialize, Clone)]
pub struct BondingCurveParam {
    pub migrate_type:               u8,    // new launches require 1 = CPMM; u8::MAX = wildcard
    pub migrate_cpmm_fee_on:        u8,    // 0 = quote-only, 1 = both. u8::MAX = wildcard
    pub supply:                     u64,   // 0 = wildcard
    pub total_base_sell:            u64,   // 0 = wildcard
    pub total_quote_fund_raising:   u64,   // 0 = wildcard
    pub total_locked_amount:        u64,   // u64::MAX = wildcard
    pub cliff_period:               u64,   // u64::MAX = wildcard
    pub unlock_period:              u64,   // u64::MAX = wildcard
}
```

كل حقل له قيمة حارسة تعني **wildcard** (أي قيمة تطابق): `u64::MAX` للحقول `u64`، `u8::MAX` للحقول `u8`، `0` لحقول الإمداد / البيع / جمع التمويل. `BondingCurveParam` مع جميع الحراس هو "السماح بأي شيء" — مكافئ لسلوك القائمة البيضاء الفارغة.

خوارزمية المطابقة عند `Initialize`:

1. تصفية `curve_params` للإدخالات التي يطابق `global_config` الخاص بها `GlobalConfig` المختار للإطلاق.
2. إذا كانت القائمة المصفاة فارغة، السماح بأي معاملات (لم تقم المنصة بإدراج أي شيء في القائمة البيضاء لهذا `GlobalConfig`).
3. إذا كان كل إدخال في القائمة المصفاة يحتوي على `all_is_invalid()` (كل حقل هو wildcard)، السماح بأي معاملات.
4. وإلا كرر الإدخالات؛ لكل إدخال، تحقق من معاملات الإطلاق مقابل كل حقل غير wildcard. إذا طابقت جميع الحقول غير wildcard، اقبل وعد.
5. إذا لم يطابق أي إدخال، عد مع `InvalidInput`.

هذا يسمح لمنصة بالقول "نحن نسمح فقط بشكل الإمداد القياسي 1B / 800M-sold / 30k-USDC-raise / no-vesting" بكتابة إدخال واحد بقيم ملموسة لتلك الحقول الأربعة و wildcards في كل مكان آخر. أو قد تحدد منصة أكثر صرامة ثلاثة أو أربعة أشكال منفصلة، واحد لكل مستوى إطلاق مدعوم.

`MAX_CURVE_PARAMS = 10` يحد من حجم القائمة البيضاء.

## `PlatformAllowConfig` — تقييد منصة

تقرر كل منصة ما إذا كانت ستقيد أي حسابات `GlobalConfig` قد تستخدمها عمليات الإطلاق الخاصة بها. اضبط `restrict_global_config` مع `UpdatePlatformConfig::RestrictGlobalConfig(0 | 1)`.

```rust
pub const PLATFORM_ALLOW_CONFIG_SEED: &str = "platform_allow_config";

#[account]
pub struct PlatformAllowConfig {
    pub bump:            u8,
    pub platform_config: Pubkey,
    pub global_config:   Pubkey,
    pub padding:         [u64; 8],
}
```

بذور PDA: `[b"platform_allow_config", platform_config, global_config]`.

ينشئ مسؤول المنصة أو يغلق حسابًا واحدًا لكل زوج مسموح به عبر `CreatePlatformAllowConfig` و `ClosePlatformAllowConfig`. عندما يكون التقييد `1`، تبحث التهيئة في `remaining_accounts` عن PDA المتوقع وترفض حسابًا مفقودًا مع `NotEnoughRemainingAccounts`. عندما يكون التقييد `0`، لا يلزم حساب السماح.

حساب `PlatformGlobalAccess` الذي تدار بواسطة مسؤول البروتوكول السابق وتعليمات الإنشاء / الإغلاق الخاصة به متقاعد. أحجام `PlatformConfig` و `GlobalConfig` الموجودة لا تتغير، لكن يجب على فك التشفير استبدال العلم العام القديم بالعلم الجديد للمنصة. لا يتم استهلاك PDAs الوصول القديمة بواسطة الفحص الجديد.

## مسار القراءة

```ts
const platformConfig = await raydium.launchpad.getPlatformConfig(platformConfigPda);

console.log("Platform:", readString(platformConfig.name));
console.log("Fee rate:", platformConfig.feeRate, "(/1M)");
console.log("NFT split:",
  platformConfig.platformScale,
  platformConfig.creatorScale,
  platformConfig.burnScale,
);
console.log("Curve whitelist size:", platformConfig.curveParams.length);
```

بالنسبة لواجهة مستخدم تعرض "من أين تم إطلاق هذا الرمز"، يشير `PoolState.platform_config` مباشرة إلى `PlatformConfig` الأصلي — قم بجلبه مرة واحدة وخزن العلامة التجارية.

## مسار التحديث

| التعليمة | من يوقع | ما يتغير |
|-------------|-----------|--------------|
| `CreatePlatformConfig` | مسؤول المنصة (مرة واحدة) | يهيئ الحساب مع `PlatformParams`. |
| `UpdatePlatformConfig` | مسؤول المنصة | إرسال عام مفتاح بـ `param: u8`؛ يغير حقل واحد لكل استدعاء. حقول العلامة التجارية ومعدلات الرسوم ومحفظة التوزيع المؤقت والمحافظ المختلفة كلها قابلة للتعيين من خلال هذا. |
| `CreatePlatformAllowConfig` / `ClosePlatformAllowConfig` | مسؤول المنصة | إضافة أو إزالة `GlobalConfig` مسموح به واحد لهذه المنصة. |
| `UpdatePlatformCurveParam` | مسؤول المنصة | إضافة أو استبدال إدخال `PlatformCurveParam` واحد بـ `(global_config, index)`. |
| `RemovePlatformCurveParam` | مسؤول المنصة | مسح إدخال واحد (تعيينه إلى جميع الحراس = wildcard). |
| `ClaimPlatformFee` | `platform_fee_wallet` | كنس رسم المنصة لكل مجموعة من `PoolState.quote_vault`. |
| `ClaimPlatformFeeFromVault` | `platform_fee_wallet` | كنس خزينة رسم المنصة لكل منصة (PDA في `[platform_config, quote_mint]`). |

تدويرات المحفظة (`platform_fee_wallet`, `platform_nft_wallet`, `platform_vesting_wallet`, `platform_cp_creator`, `transfer_fee_extension_auth`, `cpswap_config`) كلها تمر عبر `UpdatePlatformConfig`. اقرأ جدول الإرسال `update_platform_config` في المصدر للحصول على رموز `param` الدقيقة.

## الأخطاء الشائعة

- **حراس القائمة البيضاء غير محددة بشكل صحيح.** `BondingCurveParam` مع `total_locked_amount = 0` **ليس** wildcard — يطابق عمليات الإطلاق التي تختار بشكل صريح عدم استخدام التوزيع المؤقت. wildcard لهذا الحقل هو `u64::MAX`. نفس الفخ موجود لـ `cliff_period` و `unlock_period`. استخدم `clear()` (الذي يعرضه البرنامج) لتعيين الحراس بشكل صحيح.
- **تقريب تقسيم NFT.** يجب أن تجمع المقاييس الثلاثة إلى `1_000_000` بالضبط. أخطاء الانحراف بمقدار واحد عند `CreatePlatformConfig` تعود؛ الانحراف بمقدار واحد في وقت التشغيل سيسك أو يحرق وحدة LP إضافية واحدة، وهذا ما يوجد فحص المساواة الصارم لمنعه.
- **تخصيص التوزيع المؤقت المزدوج للمنصة.** إذا كان `platform_vesting_scale > 0`، يجب على المنصة استدعاء `CreatePlatformVestingAccount` مرة واحدة بعد انتهاء جمع التمويل للإطلاق؛ إذا نسيت، تبقى تلك الحصة غير مخصصة وخاملة إلى الأبد (يتم استهلاك ميزانية `total_locked_amount` للإطلاق لكن المنصة لا تطالب أبدًا).
- **غموض `platform_cp_creator`.** عند التعيين إلى `Pubkey::default()`، يتم تسجيل منشئ الإطلاق كـ `pool_creator` لمجموعة CPMM بعد التخرج؛ عند التعيين إلى مفتاح حقيقي، يتم تسجيل هذا المفتاح بدلاً من ذلك. هذا يحدد المستفيد من رسوم منشئ CPMM بعد التخرج ومن يمكنه توقيع مسار `CPMM::CollectCreatorFee` الأصلي. مسار الجمع بدون إذن لا يزال يدفع ATAs الموثوقة للمفتاح المسجل. قرر في وقت إنشاء تكوين المنصة أي نموذج تريد.
- **التقييد بدون حساب سماح.** تفعيل `restrict_global_config` قبل إنشاء `PlatformAllowConfig` المطلوب يحجب عمليات الإطلاق الجديدة التي تختار هذا التكوين.
