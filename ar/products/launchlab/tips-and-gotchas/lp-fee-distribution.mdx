عندما ينتقل رمز LaunchLab إلى CPMM، تصك المجموعة رموز LP. قبل ترقية 2026-08-14، كان `creatorScale` مقفلاً بشكل منفصل لمنشئ الرمز. بالنسبة للهجرات المنفذة بعد الترقية، يظل `migrateCpLockNftScale` يخزن ثلاثة حقول مجموعها `1_000_000`، لكن وقت التشغيل ينتج وجهتين فقط.

## التقسيم الفعلي

| الحقل | السلوك المحدّث |
|---|---|
| `platformScale` | مضمن في حصة LP المقفلة المملوكة للمنصة. |
| `creatorScale` | قبل الترقية، كان يصك Fee Key مملوكة للمنشئ. بعد الترقية، يتم تضمينه في حصة LP المقفلة المملوكة للمنصة. |
| `burnScale` | محروق بشكل دائم. لا يمثل أي Fee Key هذه الحصة. |

```text
effectivePlatformScale = platformScale + creatorScale
platformLp = floor(totalLp × effectivePlatformScale / 1_000_000)
burnLp = totalLp − platformLp
```

عندما يكون `burnScale` صفراً، تتلقى المنصة جميع وحدات LP. عندما يكون `effectivePlatformScale` صفراً، يتم حرق جميع LP ولا يتم إنشاء Fee Key للمنصة.

## أمثلة

```ts
// @raydium-io/raydium-sdk-v2@0.2.42-alpha · mainnet-beta · verified 2026-08-13
// 90% LP مملوكة للمنصة ومقفلة، 10% محروقة.
migrateCpLockNftScale: {
  platformScale: new BN(400_000),
  creatorScale: new BN(500_000),
  burnScale: new BN(100_000),
}

// بموجب البرنامج المحدّث، ينتج عن هذا 100% LP مملوكة للمنصة ومقفلة.
migrateCpLockNftScale: {
  platformScale: new BN(0),
  creatorScale: new BN(1_000_000),
  burnScale: new BN(0),
}

// 100% محروقة؛ لا توجد Fee Key.
migrateCpLockNftScale: {
  platformScale: new BN(0),
  creatorScale: new BN(0),
  burnScale: new BN(1_000_000),
}
```

## العلاقة برسوم منشئ CPMM

تتحكم حقول المقياس في ملكية LP فقط. لا تحدد معدلات رسوم المبادلة أو تحدد المستفيد من رسوم منشئ CPMM. يختار `cpConfigId` `AmmConfig` الخاص بـ CPMM؛ يحدد `platformCpCreator` ما إذا كانت مجموعة CPMM تسجل منشئ الإطلاق الأصلي أو عنواناً تختاره المنصة.

## تحديث التقسيم

قبل تحديث منصة:

- تأكد من أن القيم الثلاث مجموعها بالضبط `1_000_000`.
- قدّم `platformScale + creatorScale` كحصة المنصة الفعلية.
- لا تعد بـ Fee Key للمنشئ بناءً على `creatorScale`.
- احفظ ملكية Fee Key للمنشئ الموضحة بالهجرات المكتملة قبل الترقية؛ لا تتم إعادة كتابة تلك السجلات.
- اشرح التغيير قبل أن تستخدم الإطلاقات المستقبلية الإعدادات المحدّثة.
