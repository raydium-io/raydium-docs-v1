## الإعداد

العروض التوضيحية هنا تعكس الملفات في [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad). يتبع التمهيد [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) من مستودع العرض التوضيحي:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## إنشاء إطلاق

المصدر: [`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts) (و[`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts) لمتغير Bonk المدفوع بواسطة API)

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId: /* معرّف برنامج LaunchLab من reference/program-addresses */,
  // بيانات وصف الرمز للعملة الأساسية الجديدة:
  name:   "Example Token",
  symbol: "EXMPL",
  uri:    "https://example.com/metadata.json",
  decimals: 6,

  // معاملات المنحنى:
  curveType: 0,                                      // 0 = تربيعي
  supply:    new BN(1_000_000_000).mul(new BN(10).pow(new BN(6))), // 1B أساسي (6 عشري)
  graduationFractionBps: 8000,                       // 80% → التخرج
  initialK:  new BN("40"),                           // معامل شكل المنحنى

  // جانب الاقتباس:
  quoteMint: NATIVE_MINT,                            // WSOL
  openTime:  new BN(Math.floor(Date.now() / 1000) + 60),  // يفتح في دقيقة واحدة

  // سياسة الرسوم:
  fees: {
    buyNumerator:   new BN(100),                     // 1.00%
    buyDenominator: new BN(10_000),
    sellNumerator:  new BN(100),
    sellDenominator: new BN(10_000),
    lpShare:         new BN(60),
    creatorShare:    new BN(20),
    protocolShare:   new BN(20),
    totalShare:      new BN(100),
  },

  postGraduationLpPolicy: "burn",                    // "burn" | "lock" | "toCreator"

  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Launch:", extInfo.launchState.toBase58());
console.log("Base mint:", extInfo.baseMint.toBase58());
console.log("Create tx:", txId);
```

ملاحظات:

- `initialK` هو عامل المقياس للمنحنى التربيعي. اضبطه للوصول إلى سعر CPMM الافتتاحي المحدد عند التخرج. انظر [`products/launchlab/bonding-curve`](/ar/products/launchlab/bonding-curve) للاشتقاق.
- يتعامل SDK مع إنشاء العملة الأساسية وPDA البيانات الوصفية وكلا الخزانات في معاملة واحدة. قد يتجاوز 1232 بايت إذا كان URI البيانات الوصفية طويلاً؛ في هذه الحالة ينقسم SDK إلى معاملتين.
- بعد `Initialize`، الإطلاق غير قابل للتداول حتى `openTime`. اضبط `openTime` قبل دقيقة أو دقيقتين لإعطاء المتقدمين فرصة أقل للاستيلاء على أول عملية شراء.

## جلب حالة الإطلاق

```ts
const launchId = new PublicKey("<LAUNCH_STATE>");

const launch = await raydium.launchpad.getLaunchById({ launchId });
console.log("Status:", ["Active","Graduated","Cancelled"][launch.status]);
console.log("Base sold:", launch.baseSold.toString(),
            "/", launch.baseSupplyMax.toString());
console.log("Quote collected:", launch.quoteReserveReal.toString(),
            "target:", launch.quoteReserveTarget.toString());
if (launch.status === 1) {
  console.log("Post-graduation CPMM pool:", launch.cpmmPoolState.toBase58());
}
```

`getLaunchById` يعيد `LaunchState` المفكك بالإضافة إلى كسر "التقدم نحو التخرج" المحسوب كـ `Decimal`.

## الشراء — الاقتباس الدقيق في

المصدر: [`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

```ts
const quoteIn        = new BN(1).mul(new BN(10).pow(new BN(9)));  // 1 SOL
const minimumBaseOut = new BN(0);  // قبول أي شيء؛ شدّد للإنتاج

// معاينة الاقتباس خارج السلسلة حتى تتمكن واجهة المستخدم من عرض base_out المتوقع:
const preview = raydium.launchpad.computeBuyBase({
  launchState: launch,
  quoteIn,
});
console.log("Expected base_out:", preview.baseOut.toString(),
            "price impact:", preview.priceImpact.toString());

const { execute } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn,
  minimumBaseOut,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

`computeBuyBase` يعكس محلل Newton على السلسلة (منحنى تربيعي) أو معكوس CPMM بصيغة مغلقة (curve_type 1). استخدمه لملء حقل واجهة المستخدم "ستتلقى".

## الشراء — الإخراج الأساسي الدقيق

```ts
const baseOut         = new BN(1_000_000).mul(new BN(10).pow(new BN(6)));  // 1M أساسي
const maximumQuoteIn  = new BN(2).mul(new BN(10).pow(new BN(9)));          // حد أقصى 2 SOL

const { execute } = await raydium.launchpad.buyExactOut({
  launchInfo: launch,
  baseOut,
  maximumQuoteIn,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

مفيد لواجهات المستخدم "شراء بالضبط X رمز". يرفع مع `ExceededSlippage` إذا تحرك المنحنى بما يكفي بحيث يتجاوز متطلب الاقتباس الآن `maximumQuoteIn`.

## البيع

المصدر: [`src/launchpad/sell.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/sell.ts)

```ts
const baseIn           = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M أساسي
const minimumQuoteOut  = new BN(0);

const { execute } = await raydium.launchpad.sellExactIn({
  launchInfo: launch,
  baseIn,
  minimumQuoteOut,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

مسار البيع للمنحنى متماثل مع مسار الشراء: تقليل `base_sold` بمقدار `baseIn` يعيد `quote_out` مساوياً للمنطقة المتكاملة تحت المنحنى بين `base_sold − baseIn` و `base_sold`، ناقص رسم البيع.

## التخرج التلقائي عند عملية الشراء التي تعبر الحد الأدنى

يسلسل SDK تعليمات `Graduate` داخل معاملة `buy*` عندما يكتشف أن حالة ما بعد الشراء ستعبر الحد الأدنى:

```ts
const { execute, willGraduate } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn: new BN(100).mul(new BN(10).pow(new BN(9))),    // شراء كبير
  minimumBaseOut: new BN(0),
  txVersion: TxVersion.V0,
  autoGraduate: true,                                      // افتراضي
});

if (willGraduate) {
  console.log("This buy will trigger graduation.");
}

const { txId } = await execute({ sendAndConfirm: true });
```

لأن `Graduate` بدون إذن، يمكن لأي شخص (بما في ذلك بوت MEV) السباق للهبوط أول `Graduate` بعد عبور الحد الأدنى — عادة ثوانٍ لاحقة، وليس دقائق. الهابط الأول يدفع فقط الإيجار لحسابات مجموعة CPMM؛ لا يحصلون على أي فائدة أخرى.

## `Graduate` يدوي

إذا كان `autoGraduate` معطلاً أو فشلت معاملة عبور الحد الأدنى، يمكنك إطلاق التخرج بشكل منفصل:

```ts
const { execute } = await raydium.launchpad.graduate({
  launchInfo: launch,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

يعود مع `NotAtThreshold` إذا كان `quote_reserve_real < quote_reserve_target` في وقت الإرسال. آمن للإعادة — محاولة `Graduate` الثانية بعد النجاح تعود مع `NotActive`.

## تتبع إطلاق عبر دورة حياته

بجمع كل شيء معاً، قد تبدو نصيحة المراقبة كالتالي:

```ts
async function watch(launchId: PublicKey) {
  while (true) {
    const launch = await raydium.launchpad.getLaunchById({ launchId });
    const progress =
      Number(launch.quoteReserveReal) /
      Number(launch.quoteReserveTarget);

    console.log(
      `status=${["Active","Graduated","Cancelled"][launch.status]}`,
      `progress=${(progress * 100).toFixed(2)}%`,
      `num_buys=${launch.stateData.numBuys}`,
    );

    if (launch.status === 1) {
      console.log("Graduated to CPMM pool:", launch.cpmmPoolState.toBase58());
      break;
    }
    await new Promise(r => setTimeout(r, 10_000));
  }
}
```

## مراقبة الإعدادات والمجموعات عبر gRPC

المصدر: [`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

يشترك في برنامج LaunchLab عبر Yellowstone gRPC ويسجل كل تحديث `GlobalConfig` و `PoolState` مع برنامج الرمز لكل عملة. يفصل مرشحا `datasize` على اشتراك `accounts` واحد بين نوعي الحساب، لذا يغطي تيار واحد كليهما.

العرض التوضيحي هو أقصر مرجع صحيح لتصنيف عملات الإطلاق، والذي يجعل [إصدار عملة الاقتباس Token-2022](/ar/reference/changelog/2026-08-24-launchlab-token2022-quote-mint) ضروري:

- **المجموعات** يتم تصنيفها مباشرة من `PoolState.token_program_flag`، فك تشفير bit0 للعملة الأساسية و bit1 للعملة الاقتباس بدون جلب عملة على الإطلاق. اختبار البايت بالكامل مقابل `0` — والذي كان كافياً بينما كانت عملات الاقتباس موروثة فقط — يسيء قراءة عملة أساسية موروثة كـ Token-2022 كلما كانت عملة الاقتباس Token-2022.
- **الإعدادات** لا يمكن تصنيفها بهذه الطريقة: `GlobalConfig` يخزن عنوان عملة الاقتباس وعدم وجود علم برنامج، لذا يقرأ العرض التوضيحي مالك حساب العملة مرة واحدة ويخزنه مؤقتاً لكل عملة.

كما أنه يتحقق من الاثنين ضد بعضهما البعض، وهو تأكيد مفيد للاحتفاظ به في الفهرس الخاص بك. لاحظ أن `create` مقابل `update` يُستنتج من ذاكرات التخزين المؤقت الخاصة بالعرض التوضيحي، المزروعة عند بدء التشغيل من `getProgramAccounts`؛ مع تعطيل هذا البذر، اقرأ "create" كـ "أول ظهور على هذا التيار".

وصول gRPC ليس جزءاً من سطح RPC العام — انظر [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md) من مستودع العرض التوضيحي.

## Rust CPI

استدعاء LaunchLab من برنامج Anchor الخاص بك نادر (معظم تكاملات الإطلاق هي TS-side فقط). إذا فعلت ذلك، يشحن البرنامج صندوق Anchor `raydium_launchlab` مع `cpi::accounts::Buy`، `cpi::accounts::Sell`، إلخ. — النمط يعكس أمثلة CPMM / CLMM CPI. انظر [`sdk-api/rust-cpi`](/ar/sdk-api/rust-cpi) لقالب معمم بمجرد ملء هذا الموقع.

## الأخطاء الشائعة

- **حسابات تقسيم الرسوم خارج بواحد.** إذا لم يكن `total_share` مساوياً بالضبط `lp_share + creator_share + protocol_share`، `Initialize` يعود مع `InvalidFeeShares`. اضبط `totalShare` مساوياً للمجموع.
- **استخدام عملة اقتباس غير مسموحة.** `launch_config.allowed_quote_mints` قائمة ثابتة؛ تمرير أي عملة أخرى يعود. تحقق مع `raydium.launchpad.getConfig()` أولاً.
- **حجم البيانات الوصفية.** سلاسل `uri` الطويلة تدفع Metaplex CPI فوق الميزانية. احتفظ بـ `uri` تحت ~200 حرف — معظم بيانات JSON المستضافة على CDN تناسب بسهولة.
- **سباق التخرج.** الروبوتات الآلية تراقب `quote_reserve_real` وتتقدم على `Graduate` في فتحة أو اثنتين من عبور الحد الأدنى. هذا حميد — يكلفهم فقط الإيجار — لكنه يعني أن واجهة المستخدم الخاصة بك يجب أن تعامل انتقالات `status` كأحداث سريعة.
