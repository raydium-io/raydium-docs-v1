## رسوم المبادلة حسب المنتج

قيم الرسوم هي نسب مئوية من المبلغ المدخل، تُطبّق قبل حسابات التجمع.

| المنتج | الفئات المتاحة | الافتراضي / الأكثر استخداماً | التقسيم |
|---------|-----------------|---------------------|-------|
| **AMM v4** | 0.25% (فقط) | 0.25% | 88% LP، 12% بروتوكول (22/3 من 25) |
| **CPMM** | 0.01%، 0.25%، 1% | 0.25% | 100% LP (حصة البروتوكول قابلة للتكوين لكل AmmConfig، حالياً 0%) |
| **CLMM** | 0.01%، 0.05%، 0.25%، 1% | 0.25% | 88% LP، 12% بروتوكول |
| **LaunchLab (قبل التخرج)** | 1% (افتراضي) | 1% | 50% لبذرة التجمع، 50% لخزينة LaunchLab |
| **LaunchLab (بعد التخرج CPMM)** | 0.25% | 0.25% | يرث تقسيم CPMM |

### اتفاقية مقسوم الرسوم

- **AMM v4**: يتم ترميز الرسوم كـ x/10,000. "25" تعني 0.25%.
- **CPMM/CLMM**: يتم ترميز الرسوم كـ x/1,000,000. "2500" تعني 0.25%.

عند قراءة البيانات على السلسلة مباشرة، استخدم المقسوم الصحيح لبرنامج التجمع.

## تقسيمات رسوم البروتوكول

ضمن حصة "البروتوكول" من كل رسم، تنطبق تقسيمات إضافية:

| المنتج | حصة البروتوكول من رسم المبادلة | التقسيم ضمن البروتوكول |
|---------|----------------------------|------------------------|
| AMM v4 | 12% (3/25) | 100% للخزينة |
| CPMM | قابل للتكوين لكل AmmConfig (حالياً 0%) | غير متاح |
| CLMM | 12% من رسم المبادلة | 100% للخزينة |
| LaunchLab | 50% من رسم المبادلة قبل التخرج | 100% لخزينة LaunchLab |

تتدفق **حصة LP** إلى حاملي رموز LP تلقائياً:

- AMM v4 / CPMM: تتراكم في احتياطيات التجمع، توزع بشكل متناسب عند السحب.
- CLMM: تتراكم في `fee_growth_global_X/Y`، قابلة للمطالبة عبر `collectFee`.

## تكاليف الإنشاء

تكاليف لمرة واحدة مدفوعة بـ SOL لنشر تجمع.

| المنتج | تكلفة الإيجار | رسم الإنشاء | الإجمالي النموذجي |
|---------|-----------|--------------|---------------|
| AMM v4 | ~0.15 SOL (حسابات متعددة) | 0.2 SOL | ~0.35 SOL |
| CPMM | ~0.04 SOL (تجمع + خزائن + ملاحظة) | 0.15 SOL | ~0.19 SOL |
| CLMM | ~0.075 SOL (تجمع + ملاحظة + مصفوفات tick أولية) | 0 SOL | ~0.075 SOL |
| Farm v6 | ~0.02 SOL (حالة المزرعة + خزائن المكافآت) | 0.1 SOL (مكافحة البريد العشوائي) | ~0.12 SOL |
| إطلاق LaunchLab | ~0.015 SOL (حساب منحنى الربط) | 0.1 SOL (رسم LaunchLab) | ~0.115 SOL |

جميع الإيجارات قابلة للاسترجاع — إغلاق التجمع / المركز / المزرعة يعيد lamports.

## تكاليف التخرج / الهجرة

| الحدث | التكلفة | من يدفع |
|-------|------|----------|
| تخرج LaunchLab → CPMM | ~0.04 SOL (إنشاء تجمع CPMM جديد) | مدفوع من احتياطيات منحنى الربط |
| هجرة AMM v4 → CPMM | ~0.04 SOL إنشاء CPMM + ~0.000005 SOL رسم tx | LP الذي يقوم بالهجرة |
| نقل NFT موضع CLMM | ~0.000005 SOL رسم tx؛ غير متاح للمواضع المجمدة ذات المُصدر المقيد | الناقل |

## تفاعل رسم Token-2022

عندما يستخدم أحد جانبي التجمع أو كلاهما Token-2022 برسم نقل، يتراكم الرسم الفعلي:

```
net input to pool   = amount_in × (1 − transfer_fee_in)
pool charges swap   = net × swap_fee_rate
net output to user  = out × (1 − transfer_fee_out)
```

مثال: تجمع CPMM بنسبة 0.25%، جانب الإدخال به رسم نقل 1%، جانب الإخراج به رسم نقل 0.5%.

```
amount_in        = 1000
net_to_pool      = 1000 × 0.99    = 990
pool swap fee    = 990 × 0.0025   = 2.475 (kept as LP fee)
amount_after_fee = 987.525
amount_out (AMM) = 987.525 × ratio, say 987.525 × 0.98 = 967.77
net_out_to_user  = 967.77 × 0.995 = 962.94
```

الرسم الفعلي: **~3.7%** رغم رسم تجمع اسمي بنسبة 0.25%.

يحسب SDK المعدل الفعلي عبر `getComputeAmountOut` — استخدمه دائماً عند الاستشهاد بتجمعات Token-2022.

## تفاصيل LaunchLab

| المرحلة | الرسم |
|-------|-----|
| تداولات منحنى الربط (شراء أو بيع) | 1% (مقسم 50/50 تجمع/خزينة) |
| التخرج (لمرة واحدة) | ~0.04 SOL من احتياطيات المنحنى |
| بعد التخرج (تجمع CPMM) | 0.25% (رسوم CPMM القياسية) |

يمكن للمشاريع التي تطلق الرموز تضمين رسم منشئ أثناء مرحلة منحنى الربط. بعد التخرج، قد يفرض إعداد CPMM المختار أيضاً رسم منشئ CPMM منفصل لمنشئ التجمع المسجل. يمثل مفتاح الرسم المملوك للمنصة حقوق رسم LP وليس بيانات اعتماد رسم المنشئ. انظر [`products/launchlab/creator-fees`](/ar/products/launchlab/creator-fees).

## نموذج تكلفة مكافآت Farm v6

المزارع لا تفرض رسوماً بالمعنى الدقيق — فهي توزيع مكافآت. لكنها تكلف SOL للتشغيل:

| التكلفة | النموذجي |
|------|---------|
| إنشاء المزرعة | 0.1 SOL مكافحة بريد عشوائي + ~0.02 SOL إيجار |
| ملء خزينة المكافآت | فقط الرموز + ~0.0005 SOL tx |
| استرجاع المكافآت غير المستخدمة | ~0.0005 SOL tx |

تتطلب المزارع أيضاً lamports كافية في خزينة المكافآت لتغطية الإيجار طوال عمر المزرعة؛ الإغلاق يعيدها.

## كيفية قراءة القيم الحالية على السلسلة

### AmmConfig CPMM/CLMM

```ts
const config = await raydium.cpmm.getAmmConfigs();
console.log(config[0]);
// {
//   id: "...",
//   tradeFeeRate: 2500,         // 2500 / 1_000_000 = 0.25%
//   protocolFeeRate: 0,         // 0 / 1_000_000 = 0%
//   fundFeeRate: 0,
//   ...
// }
```

### تجمع AMM v4

```ts
const poolInfo = await raydium.liquidity.getPoolInfoFromRpc({ poolId });
console.log(poolInfo.ammFeesNumerator, poolInfo.ammFeesDenominator);
// 25, 10000 → 0.25%
```

### معدل مكافآت Farm v6

```ts
const farm = await raydium.farm.getFarmInfoFromRpc({ id: farmId });
console.log(farm.farmData.rewardInfos);
// Per-reward: emissionsPerSecond, startTime, endTime
```
