## ما هو متاح

| الواجهة | نمط URL | الاستخدام |
|---|---|---|
| **خادم MCP** | `https://docs.raydium.io/mcp` | تريد من محرر الذكاء الاصطناعي (Claude Code أو Cursor أو Windsurf وغيرها) الاستعلام عن توثيق Raydium والاستشهاد به بشكل أصلي. |
| **فهرس `llms.txt`** | `https://docs.raydium.io/llms.txt` | تبني خط أنابيب RAG وتحتاج إلى فهرس مسطح لكل صفحة. |
| **نص `llms-full.txt`** | `https://docs.raydium.io/llms-full.txt` | تريد المجموعة الكاملة كملف واحد مسلسل للفهرسة دون اتصال. |
| **قائمة النسخ لكل صفحة** | زر `Copy page` في أعلى كل صفحة محتوى | تلصق صفحة واحدة في محادثة مع LLM. |
| **روابط عميقة لكل صفحة** | `View as Markdown` و `Open in ChatGPT` و `Open in Claude` و `Open in Cursor` و `Open in VS Code` | نقل بنقرة واحدة من صفحة التوثيق إلى الأداة التي تختارها. |

يقع زر `Copy page` وقائمة الروابط العميقة في الزاوية العلوية اليمنى من كل صفحة (بجانب عنوان الصفحة). كلاهما مدعوم بقائمة السياق الخاصة بمنصة التوثيق.

## خادم MCP

يتيح خادم MCP (Model Context Protocol) لعملاء الذكاء الاصطناعي الاستعلام عن توثيق Raydium كأداة. بمجرد التكوين، يمكن لوكيلك أن يسأل "ابحث في توثيق Raydium عن معاملات `addLiquidity`" والحصول على إجابات موثوقة مع الاستشهاد بها.

### Claude Code

```bash
claude mcp add --transport http raydium-docs https://docs.raydium.io/mcp
```

بعد الإضافة، اطلب من Claude Code "البحث في توثيق Raydium عن X" وسيستخدم الأداة.

### Cursor

أضف إلى إعدادات Cursor (`Cmd/Ctrl + ,` → MCP):

```json
{
  "mcpServers": {
    "raydium-docs": {
      "url": "https://docs.raydium.io/mcp"
    }
  }
}
```

### Windsurf و Continue والعملاء العامين

يمكن لأي عميل متوافق مع MCP أن يشير إلى `https://docs.raydium.io/mcp`. وتلك النقطة النهائية *هي* سطح الاستكشاف — إذ يُرجع طلب `GET` تكوين الخادم (الاسم والإصدار والنقل والتعليمات وقائمة الأدوات)، فلا حاجة إلى ملف بيان منفصل ولا يُقدَّم أي ملف من هذا النوع.

### ما يعرضه الخادم

يعرض خادم MCP لتوثيق Raydium أداة أساسية واحدة، `search_docs(query: string)`، والتي تُرجع أعلى المقاطع المصنفة للاستعلام مع عناوين URL الأساسية الخاصة بها. الوكيل مسؤول عن الاستشهاد بـ URL الذي استخدمه؛ نحن لا نتتبع أو نحد من معدل الطلب لكل وكيل.

## `llms.txt` لـ RAG

`llms.txt` هو معيار ناشئ لـ "فهرس التوثيق الذي يمكن قراءته آليًا". تنشر Raydium:

- `https://docs.raydium.io/llms.txt` — قائمة مسطحة لكل صفحة مع العنوان وملخص سطر واحد، منظمة حسب الفصل.
- `https://docs.raydium.io/llms-full.txt` — نص Markdown الكامل لكل صفحة، مسلسل، مع الحفاظ على حدود الصفحات كعناوين.

يتم إعادة إنشاء المتغير `full` عند كل نشر توثيق. اسحبه على جدول زمني (يومي كافٍ) أو اجلبه عند الطلب.

```bash
# أسقط المجموعة الكاملة في خط أنابيب تناول RAG.
curl -sSL https://docs.raydium.io/llms-full.txt -o raydium-docs.md
```

## قائمة النقل لكل صفحة

تحتوي كل صفحة محتوى على قائمة سياق (أعلى اليمين، بجانب العنوان) مع هذه الإجراءات بنقرة واحدة:

- **Copy** — انسخ الصفحة كـ Markdown عادي.
- **View as Markdown** — افتح المصدر `.md` في علامة تبويب جديدة حتى تتمكن من حفظه.
- **Open in ChatGPT / Claude / Perplexity** — حمّل محتوى الصفحة مسبقًا في موجه الدردشة للأداة المسماة.
- **Open in Cursor / VS Code** — افتح مخزن مؤقت في محرر المسمى مع محتوى الصفحة.

هذه هي الواجهة الصحيحة عندما تريد أن تسأل نموذجًا سؤالاً حول صفحة واحدة دون إعداد MCP.

## ملفات السياق المُعدّة مسبقًا لوكلاء الترميز

إذا كنت تدمج Raydium وتريد أن يكون لدى وكيلك المعرفة الأساسية الصحيحة من البداية، فأسقط هذه الملفات في مشروعك:

### `.cursorrules` / `.windsurfrules` / موجه النظام للوكيل

```text
You are integrating with Raydium, a Solana DeFi protocol with five product
surfaces: AMM v4, CPMM, CLMM, Farm, and LaunchLab. Authoritative docs live
at docs.raydium.io. The official SDK is `@raydium-io/raydium-sdk-v2` (pin
the version you've verified against). For server-built swaps, prefer the
Trade API at transaction-v1.raydium.io. Always:

- Pass a `Connection` and `cluster` that match.
- Keep all amounts as `BN` instances; never call `.toNumber()` on amounts.
- Pre-fund the user's wallet for ATA creation rent.
- Pass an explicit `computeBudgetConfig` for any tx that may compete in
  high-volume windows.
- Re-fetch `poolInfo` immediately before high-value transactions; cached
  state goes stale.

When uncertain about an instruction's accounts list, defer to
`docs.raydium.io/products/<product>/accounts` and the on-chain IDL.
```

احفظ باسم `.cursorrules` (Cursor) أو `.windsurfrules` (Windsurf) أو `CLAUDE.md` (Claude Code) — أو الصق في موجه النظام الخاص بوكيلك. يختلف اسم الملف والموقع الدقيق حسب إصدار الأداة، لذا تحقق من توثيق إعدادات أداتك إذا لم تلتقطه تلقائيًا.

### قائمة السياق المثبتة

بالنسبة لوكلاء الترميز الذين يقبلون قائمة بصفحات "يجب تضمينها دائمًا"، هذه القائمة هي الحد الأدنى من السياق المفيد لمعظم تكاملات Raydium:

```text
https://docs.raydium.io/sdk-api/typescript-sdk
https://docs.raydium.io/sdk-api/trade-api
https://docs.raydium.io/products/cpmm/instructions
https://docs.raydium.io/products/clmm/instructions
https://docs.raydium.io/integration-guides/priority-fee-tuning
https://docs.raydium.io/reference/program-addresses
https://docs.raydium.io/reference/error-codes
```

اضبط بناءً على المنتجات التي تدمجها.

## وصفة الفهرسة

إذا كنت تبني RAG الخاص بك ولا تريد استخدام `llms-full.txt`، فإليك الوصفة الأساسية:

```ts
import { fetch } from "undici";

const INDEX_URL = "https://docs.raydium.io/llms.txt";
const BASE      = "https://docs.raydium.io";

const index    = await (await fetch(INDEX_URL)).text();
const pageUrls = [...index.matchAll(/^- \[(.+?)\]\((.+?)\)/gm)].map(m => m[2]);

for (const path of pageUrls) {
  const md = await (await fetch(`${BASE}${path}.md`)).text();
  // ingest md into your vector store, keyed by path
}
```

يتم تقديم كل صفحة في مسارها الأساسي مع إضافة لاحقة `.md` (على سبيل المثال `/sdk-api/typescript-sdk` → `/sdk-api/typescript-sdk.md`).

## تحذيرات

- **لا تلصق الحالة الخاصة في الموجهات.** خادم MCP يعرف فقط ما هو في التوثيق العام. لا يجب أن تدخل مفاتيح المحفظة وبيانات اعتماد RPC والأسرار المماثلة أبدًا إلى سياق الوكيل.
- **مخرجات الذكاء الاصطناعي ليست موثوقة.** تهلوس النماذج بسهولة مقلقة حول عناوين البرامج وأسماء التعليمات وقوائم الحسابات. تحقق دائمًا من التوثيق و IDL قبل الوثوق بالمعاملات التي ينشئها الوكيل.
- **انجراف الإصدار.** SDK v2 قبل 1.0؛ قد تصدر الوكلاء المدربة على الإصدارات الأقدم كودًا لا يتم تجميعه مقابل إصدارك المثبت. قم بتضمين إصدار SDK المثبت في موجه النظام الخاص بوكيلك.
