## Для кого этот раздел

Разработчики и исследователи протоколов, пришедшие из других блокчейнов (EVM, Cosmos, Move) или новые в Solana. Конечные пользователи могут пропустить этот раздел.

Цель практическая: дать читателю ровно то, что нужно для изучения разделов Products и SDK без неожиданностей. Это не общее руководство по Solana — для этого обратитесь к официальной документации Solana.

## Рекомендации по написанию

- Каждая страница содержит один практический пример, на который позже ссылаются в контексте Raydium.
- Token-2022 получает *первоклассное* внимание, так как CPMM его поддерживает; transfer fees и freeze authority изменяют математику свопов.
- Держите код коротким (`<30` строк) на этих страницах; полные примеры находятся в разделах SDK & API.
- Ссылайтесь на официальную документацию Solana один раз, а не повторно.
