Вся документация предполагает наличие рабочего инструментария разработки Solana. На этой странице перечислены инструменты, версии, известные как совместимые с Raydium по состоянию на сентябрь 2026 года, и специфические подводные камни при установке. Начните отсюда перед запуском любых примеров кода из последующих глав.

**Имеют значение два набора версий, и они не совпадают.** Чтобы *собрать или форкировать* программы Raydium, вам нужен точный инструментарий, который они закрепляют — Rust 1.91.0, Agave 3.1.10, Anchor 1.0.2 по состоянию на обновление 2026-09-09. Чтобы *интегрироваться* с развёрнутыми программами из TypeScript или Python, вам нужна только клиентская библиотека, достаточно свежая для общения с ними, и закрепления носят рекомендательный характер. Каждый раздел ниже указывает, какой случай он охватывает.

## Основные инструменты

### Solana CLI

Канонический интерфейс командной строки для взаимодействия с кластерами Solana — управление кошельками, RPC-вызовы, развёртывание программ.

Установка:

```bash
# Версия, для которой собраны и протестированы программы Raydium
sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.10/install)"

# Или отслеживайте канал вместо тега
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

Проверка:

```bash
solana --version   # → solana-cli 3.1.10 (... client:Agave)
```

<Note>
  **Хост установки переместился.** `release.solana.com` принадлежал Solana Labs; клиент теперь поддерживается Anza как **Agave**, и релизы распространяются с `release.anza.xyz`. Самообновляющийся бинарник — это `agave-install` (`solana-install` сохранён как устаревший псевдоним), поэтому `agave-install update` и `agave-install init <version>` — это текущие написания. Собственная документация Solana также предлагает установщик в одну команду, который загружает CLI, Rust и Anchor вместе:

  ```bash
  curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
  ```

  Этот установщик отслеживает собственное представление о текущем и может дать вам другой Anchor, чем тот, который закрепляют программы Raydium — проверьте `anchor --version` после этого.
</Note>

Конфигурация для mainnet:

```bash
solana config set --url https://api.mainnet-beta.solana.com
solana config set --keypair ~/.config/solana/id.json
solana-keygen new                           # создайте кошелёк, если его нет
solana address                              # ваш открытый ключ
```

Для тестирования Raydium вам почти всегда понадобится финансируемый devnet-кошелёк:

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2                            # 2 SOL для тестирования
```

### SPL Token CLI

Официальный CLI для операций SPL Token / Token-2022 — создание минтов, минтинг токенов, передачи.

Установка (включена в Solana CLI):

```bash
spl-token --version
```

Типичные операции:

```bash
spl-token create-token                                  # создать SPL Token mint
spl-token create-token --program-id TOKEN_2022 ...      # создать Token-2022 mint
spl-token create-account <MINT>                         # создать ATA
spl-token mint <MINT> 1000                              # минтить 1000 токенов в ваш ATA
spl-token transfer <MINT> 100 <RECIPIENT>               # передать 100
spl-token display <ACCOUNT_OR_MINT>                     # инспектировать
```

### Anchor CLI

Требуется для получения IDL Raydium, построения клиентов и верификации программ.

Установка:

```bash
cargo install --git https://github.com/solana-foundation/anchor avm --locked --force
avm install 1.0.2
avm use 1.0.2
anchor --version   # → anchor-cli 1.0.2
```

<Note>
  **Anchor переместился в репозиторий и мажорную версию.** Канонический репозиторий теперь `github.com/solana-foundation/anchor` (раньше был `coral-xyz/anchor`), и Anchor 1.0 — это первая линия релизов, которую используют программы Raydium — CPMM и LaunchLab оба закрепляют `anchor-lang`/`anchor-spl` `=1.0.2` по состоянию на обновление 2026-09-09, вверх с `0.32.1`. `avm` может держать несколько версий; `avm use 1.0.2` — это то, что заставляет `anchor build` воспроизводить артефакты Raydium. Anchor 1.1 и 1.2 существуют и хорошо собираются для ваших собственных программ, но CPI-крейт, скомпилированный против другого минора `anchor-lang`, чем тот, который закрепляет целевая программа, не будет линкован — см. [`sdk-api/rust-cpi`](/ru/sdk-api/rust-cpi).
</Note>

Типичные операции:

```bash
anchor idl fetch <PROGRAM_ID> -o program.idl.json       # получить IDL из блокчейна
anchor idl init -f idl.json <PROGRAM_ID>                # загрузить IDL
anchor build                                             # собрать программу из исходников
```

## Установка TypeScript

Основной путь интеграции для Raydium.

### Пакеты

```bash
npm install \
  @solana/web3.js \
  @solana/spl-token \
  @anchor-lang/core \
  @raydium-io/raydium-sdk-v2 \
  bn.js \
  decimal.js
```

Версии, известные как совместимые по состоянию на сентябрь 2026:

| Пакет | Версия | Примечание |
|---------|---------|------|
| `@solana/web3.js` | `^1.95` | API 1.x. `2.x` / `3.x` — это другая, несовместимая поверхность API; SDK Raydium нацелен на 1.x. |
| `@solana/spl-token` | `^0.4.15` | 0.4.15 — это то, что предоставляет `createUnwrapLamportsInstruction` — см. [возвратная аренда](/ru/solana-fundamentals/rent-and-reclaimable-rent). |
| `@anchor-lang/core` | `^1.0` | TypeScript-клиент Anchor 1.x. |
| `@raydium-io/raydium-sdk-v2` | `0.2.64-alpha` | Закрепление, которое использует каждый пример кода в этой документации. |

<Note>
  **`@anchor-lang/core` заморожен; пакет теперь `@anchor-lang/core`.** `@anchor-lang/core` остановился на `0.32.1`, когда Anchor переместился в Solana Foundation. Anchor 1.x публикуется как `@anchor-lang/core`, и собственные репозитории программ Raydium переключили свои тестовые наборы на него при обновлении 2026-09-09. Импорты, которые вы фактически используете, не изменились — `import { Program, BN, AnchorProvider } from "@anchor-lang/core"` — поэтому миграция — это переименование пакета плюс обновление lockfile.

  Два замечания о поведении, если вы переходите с `0.3x`: `.accounts({...})` теперь принимает только учётные записи, которые Anchor не может разрешить сам, поэтому построитель, который передаёт полный набор, должен вызвать `.accountsPartial({...})` вместо этого; и `@anchor-lang/core/dist/cjs/utils/token` — это место, куда переместились помощники, такие как `ASSOCIATED_PROGRAM_ID`.
</Note>

### Минимальный скрипт

```ts
import { Connection, Keypair } from "@solana/web3.js";
import { Raydium } from "@raydium-io/raydium-sdk-v2";

const connection = new Connection("https://api.mainnet-beta.solana.com", "confirmed");
const owner      = Keypair.fromSecretKey(/* your key */);

const raydium = await Raydium.load({
  connection,
  owner,
  cluster:      "mainnet",
  disableFeatureCheck: true,
});

// `ids` — это список, разделённый запятыми, и вызов возвращает массив
const [poolInfo] = await raydium.api.fetchPoolById({ ids: "..." });
console.log(poolInfo);
```

Полную справку SDK см. в [`sdk-api/typescript-sdk`](/ru/sdk-api/typescript-sdk).

## Установка Rust

Для интеграции CPI и программ в блокчейне.

### Инструментарий

```bash
rustup install 1.91.0           # то, что закрепляют программы Raydium
rustup default 1.91.0
rustup component add rustfmt clippy
agave-install init 3.1.10       # SBF-инструментарий включён
```

Собирайте программы с помощью `cargo build-sbf` (старое написание `cargo build-bpf` исчезло).

### Program Cargo.toml для интеграции Raydium CPI

```toml
# Интеграция CPMM (Anchor 1.0)
[dependencies]
anchor-lang        = "=1.0.2"
anchor-spl         = "=1.0.2"
raydium-cp-swap    = { version = "0.2", features = ["cpi"] }
```

```toml
# Интеграция CLMM — всё ещё Anchor 0.32, поэтому нужен собственный крейт
[dependencies]
anchor-lang        = "=0.32.1"
anchor-spl         = "=0.32.1"
raydium-clmm       = { version = "0.1", features = ["cpi"] }
```

Закрепляйте `anchor-lang` и `anchor-spl` с помощью `=` к версии, которую закрепляет целевая программа. По состоянию на 2026-09 CPMM закрепляет `=1.0.2`, а CLMM всё ещё закрепляет `=0.32.1`, поэтому **один крейт не может делать CPI в оба** — см. [`sdk-api/rust-cpi`](/ru/sdk-api/rust-cpi#cargo-dependencies).

Функция `"cpi"` импортирует модуль `cpi` с помощниками CPI (поэтому вы можете `raydium_cp_swap::cpi::swap_base_input(...)`). См. [`sdk-api/rust-cpi`](/ru/sdk-api/rust-cpi).

## Установка Python

Вторичный путь интеграции — распространён среди разработчиков ботов.

### Пакеты

```bash
pip install solders solana anchorpy
```

Версии:

| Пакет | Имя PyPI | Версия |
|---------|-----------|---------|
| `solders` | `solders` | ≥0.29 |
| solana-py | `solana` | ≥0.40 |
| `anchorpy` | `anchorpy` | ≥0.21 |

<Note>
  Две ловушки с именами. RPC-клиент импортируется как `solana`, но проект называется **solana-py** — `pip install solana-py` не устанавливает ничего полезного. И **нет пакета `raydium-py` на PyPI**: помощник Raydium сообщества — это репозиторий, который вы клонируете, [`AL-THE-BOT-FATHER/raydium_py`](https://github.com/AL-THE-BOT-FATHER/raydium_py), а не опубликованное распределение. Более ранние версии этой страницы содержали строку `pip install raydium-py`, которая никогда не работала.
</Note>

### Минимальный скрипт

```python
from solana.rpc.async_api import AsyncClient
from solders.keypair import Keypair
from anchorpy import Provider, Wallet, Program

async def main():
    conn = AsyncClient("https://api.mainnet-beta.solana.com")
    owner = Keypair()
    wallet = Wallet(owner)
    provider = Provider(conn, wallet)

    # Загрузить IDL и программу
    with open("cpmm.idl.json") as f:
        idl = json.load(f)
    program = Program(idl, CPMM_PROGRAM_ID, provider)

    pool = await program.account["PoolState"].fetch(pool_id)
    print(pool)
```

См. [`sdk-api/python-integration`](/ru/sdk-api/python-integration).

## RPC-эндпоинты

Публичный mainnet RPC (`api.mainnet-beta.solana.com`) сильно ограничен по частоте запросов и дросселируется под любой нагрузкой. Для нетривиального использования получите приватный эндпоинт:

| Провайдер | Примечания |
|----------|-------|
| Helius | Самый популярный; щедрый бесплатный уровень. |
| Triton | Корпоративный; премиум-цены, стабильный. |
| QuickNode | Хороший; задержка менее секунды. |
| Ваш собственный RPC-узел | Стоит ~\$500/мес в оборудовании; полный контроль. |

Конфигурация:

```ts
const connection = new Connection("https://mainnet.helius-rpc.com/?api-key=...");
```

Некоторые RPC-операции требуют расширенных возможностей:

- `getProgramAccounts` — неограниченные сканирования дорогие; некоторые провайдеры ограничивают или берут плату за сканирование.
- `getPriorityFeeEstimate` — специфичный для Helius эндпоинт; у других есть эквиваленты.
- `geyser` / WebSocket-потоковая передача — требуется для низколатентных ботов; не все провайдеры её предоставляют.

## Devnet и localnet

### Devnet

Публичный тестовый кластер Solana. Raydium имеет частичное развёртывание на devnet:

- Некоторые пулы CPMM существуют для тестирования.
- AMM v4 имеет исторические пулы devnet.
- CLMM имеет несколько демо-пулов.
- Farm v6 развёрнут.

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2
```

SDK поддерживает devnet через `cluster: "devnet"`:

```ts
const raydium = await Raydium.load({ connection, owner, cluster: "devnet" });
```

**Оговорка**: пулы devnet имеют тонкую ликвидность и могут иметь устаревшее состояние. Не полагайтесь на devnet для обнаружения цен; используйте его только для построения и тестирования потоков инструкций.

### Localnet с форкированным состоянием mainnet

Для реалистичного тестирования форкируйте состояние mainnet в локальный валидатор:

```bash
solana-test-validator \
  --url https://api.mainnet-beta.solana.com \
  --clone CPMMoo8L3F4NbTegBCKVNunggL7H1ZpdTHKxQB5qKP1C \
  --clone CAMMCzo5YL8w4VFF8KVHrK22GGUsp5VTaW7grrKgrWqK \
  --clone <SOME_POOL_ID> \
  --clone <SOME_MINT_ID>
```

Это клонирует специфичное состояние программы/учётной записи на localhost, где вы можете свободно совершать транзакции. Идеально для:

- Модульного тестирования вашей интеграции CPI против реальной программы Raydium.
- Воспроизведения транзакции с изменённым параметром для отладки.
- Стресс-тестирования с большими синтетическими объёмами.

Команда Raydium широко использует форкированный localnet для регрессионного тестирования перед развёртыванием на mainnet.

## Шаблоны проектов

### Стартер интеграции TypeScript

```
my-raydium-app/
├── package.json
├── tsconfig.json
├── src/
│   ├── swap.ts           # пример swap
│   ├── add-liquidity.ts
│   └── read-pool.ts
└── .env                  # RPC URL, путь к кошельку
```

Минимальный `package.json`:

```json
{
  "name": "my-raydium-app",
  "type": "module",
  "scripts": { "swap": "tsx src/swap.ts" },
  "dependencies": {
    "@raydium-io/raydium-sdk-v2": "0.2.64-alpha",
    "@solana/web3.js": "^1.95",
    "@solana/spl-token": "^0.4.15"
  },
  "devDependencies": {
    "@types/node": "^20",
    "tsx": "^4",
    "typescript": "^5"
  }
}
```

### Стартер программы Anchor CPI

```
my-raydium-cpi/
├── Anchor.toml
├── Cargo.toml
├── programs/
│   └── my-cpi/
│       ├── Cargo.toml
│       └── src/lib.rs
└── tests/
    └── my-cpi.ts
```

С Anchor 1.0:

```bash
anchor init my-raydium-cpi
cd my-raydium-cpi
# добавьте raydium-cp-swap в Cargo.toml с features = ["cpi"]
anchor build
anchor test
```

## Гигиена окружения

### Отдельные кошельки для разных целей

- **Кошелёк разработки**: содержит testnet SOL, используется для построения.
- **Кошелёк продакшена**: содержит реальный SOL, используется только для развёртываний / отправок multisig.
- **Горячий кошелёк для ботов**: небольшой баланс, узкие разрешения.

Ключи никогда не должны быть жёстко закодированы. Используйте переменные окружения или менеджеры секретов.

### Паттерн `.env`

```
# .env (не коммитится)
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=...
WALLET_PATH=/Users/you/.config/solana/id.json
```

```ts
import { config } from "dotenv";
config();

const connection = new Connection(process.env.SOLANA_RPC_URL!);
```

### Закрепление версий

Закрепляйте все зависимости экосистемы Solana. Экосистема движется быстро; минорное обновление версии `@solana/web3.js` ранее вводило критические изменения. Используйте `package-lock.json` / `Cargo.lock` религиозно.
