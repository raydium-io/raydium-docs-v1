## Настройка

Примеры здесь соответствуют файлам в [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad). Инициализация следует [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) из репозитория примеров:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Создание запуска

Источник: [`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts) (и [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts) для варианта на основе API Bonk)

Большинство экономических параметров запуска **не** передаются как аргументы — они берутся из `GlobalConfig`, который вы привязываете через `configId`, а SDK заполняет остальное из параметров API по умолчанию. Вы передаёте идентификатор монеты, конфигурацию для привязки и (опционально) первую покупку:

```ts
import {
  LAUNCHPAD_PROGRAM,
  DEVNET_PROGRAM_ID,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";

const programId = LAUNCHPAD_PROGRAM;          // devnet: DEVNET_PROGRAM_ID.LAUNCHPAD_PROGRAM

// Базовая монета — это keypair, который вы генерируете и подписываете.
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// Привяжите GlobalConfig: (quote mint, curve_type, index).
const configId = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
if (!configData) throw new Error("config not found");
const configInfo = LaunchpadConfig.decode(configData.data);
const mintBInfo = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, transactions, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "Example Token",
  symbol: "EXMPL",                 // не более 10 символов
  uri:    "https://example.com/metadata.json",   // не должен быть пустым
  migrateType: "amm",              // "amm" | "cpmm"

  configId,
  configInfo,                      // опционально; SDK перечитает configId при пропуске
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  // Опциональная первая покупка в одном пакете.
  createOnly: true,                // true = только создать монету
  buyAmount:  new BN(1000),        // игнорируется при createOnly: true
  slippage:   new BN(100),         // 100 = 1%

  extraSigners: [pair],            // keypair базовой монеты должен подписать
  txVersion: TxVersion.V0,

  // Параметры по умолчанию берутся из API привязанного конфига; переопределяйте только если необходимо:
  // supply:            new BN(1_000_000_000_000_000),
  // totalSellA:        new BN(793_100_000_000_000),
  // totalFundRaisingB: new BN(85_000_000_000),   // 85 SOL когда mintB это SOL
  // totalLockedAmount: new BN(0),
  // cliffPeriod:       new BN(0),                // секунды
  // unlockPeriod:      new BN(0),                // секунды
  // platformId:        new PublicKey("4Bu96XjU84XjPDSpveTVf6LYGCkfW5FK7SNkREWcEfV4"), // Raydium's, по умолчанию
});

// createLaunchpad возвращает НЕСКОЛЬКО транзакций — выполняйте их по порядку.
const { txIds } = await execute({ sequentially: true });
console.log("Pool:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
console.log("Create txs:", txIds);
```

Примечания:

- **Нет** аргументов `curveType`, `graduationFractionBps`, `initialK`, `quoteMint`, `openTime`, `fees` или `postGraduationLpPolicy`. Форма кривой и quote mint — это свойства `GlobalConfig`, который вы привязываете; ставки комиссий находятся на `GlobalConfig` и `PlatformConfig`; утилизация LP при выпуске — это параметр `PlatformConfig`. См. [`products/launchlab/instructions`](/ru/products/launchlab/instructions#initialize) для точного списка того, что принимает `InitializeV2`.
- `symbol` длиннее 10 символов и пустой `uri` отклоняются на клиенте перед любым RPC.
- Передача `transferFeeExtensionParams` переключает builder на `InitializeWithToken2022` и принудительно устанавливает `migrateType` в `"cpmm"`.
- Builder возвращает массив `transactions`; `createOnly: false` добавляет транзакцию первой покупки. Всегда используйте `execute({ sequentially: true })` — монета должна существовать перед тем, как покупка будет выполнена.

## Получение состояния запуска

Источник: [`src/launchpad/poolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/poolInfo.ts)

Нет `getLaunchById`. ID пула — это PDA от `(programId, mintA, mintB)`, и `getRpcPoolInfo` возвращает декодированный `PoolState` с привязанным `configInfo`:

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log("status:", poolInfo.status);
console.log("base sold:", poolInfo.realA.toString(), "/", poolInfo.totalSellA.toString());
console.log("quote raised:", poolInfo.realB.toString(), "/", poolInfo.totalFundRaisingB.toString());

// Текущая спотовая цена на кривой.
const price = Curve.getPrice({
  poolInfo,
  curveType: poolInfo.configInfo.curveType,
  decimalA: poolInfo.mintDecimalsA,
  decimalB: poolInfo.mintDecimalsB,
});
console.log("price:", price.toString());
```

`getRpcPoolsInfo({ poolIdList })` — это пакетная форма и возвращает `poolInfoMap`, индексированную по ID пула — используйте её для представлений портфеля вместо цикла. Если вы хотите декодировать сырые аккаунты самостоятельно, `LaunchpadPool.decode` и `LaunchpadConfig.decode` экспортируются.

## Покупка — точное количество quote

Источник: [`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

Вспомогательная функция для оффчейн-котировки — это **`Curve.buyExactIn`**, статический метод на экспортированном классе `Curve` — не метод на `raydium.launchpad`. Builder транзакции — это **`buyToken`**. Обоим нужны ставки комиссий платформы, которые находятся на отдельном аккаунте `PlatformConfig`:

```ts
import { Curve, PlatformConfig, toTransferFeeConfig } from "@raydium-io/raydium-sdk-v2";

const inAmount = new BN(1).mul(new BN(10).pow(new BN(9)));   // 1 SOL
const slippage = new BN(100);                                 // 100 = 1%

const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });
const platformData = await raydium.connection.getAccountInfo(poolInfo.platformId);
const platformInfo = PlatformConfig.decode(platformData!.data);

const mintInfo  = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(poolInfo.mintB);
const epochInfo = await raydium.connection.getEpochInfo();

// Оффчейн-превью — отражает математику кривой на цепи.
const res = Curve.buyExactIn({
  poolInfo,
  amountB: inAmount,
  protocolFeeRate: poolInfo.configInfo.tradeFeeRate,
  platformFeeRate: platformInfo.feeRate,
  creatorFeeRate:  platformInfo.creatorFeeRate,
  curveType:       poolInfo.configInfo.curveType,
  shareFeeRate:    new BN(0),
  transferFeeConfigA: mintInfo.extensions.feeConfig  ? toTransferFeeConfig(mintInfo,  epochInfo.epoch) : undefined,
  transferFeeConfigB: mintBInfo.extensions.feeConfig ? toTransferFeeConfig(mintBInfo, epochInfo.epoch) : undefined,
  slot: await raydium.connection.getSlot(),
});
console.log("expected out:", res.amountA.amount.sub(res.amountA.fee ?? new BN(0)).toString());

const { execute, extInfo } = await raydium.launchpad.buyToken({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  transferFeeConfigB: toTransferFeeConfig(mintBInfo, epochInfo.epoch),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,
  buyAmount:       inAmount,
  slippage,                       // BN в bps; SDK выводит minMintAAmount из него
  txVersion: TxVersion.V0,
});

console.log("expected receive amount:", extInfo.decimalOutAmount.toString());
const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

Вы можете передать `minMintAAmount` явно вместо `slippage`; пропустите оба и SDK вычислит границу из живых RPC данных. `shareFeeRate` не должен превышать `poolInfo.configInfo.maxShareFeeRate`, и он применяется только когда вы также передаёте `shareFeeReceiver`.

## Покупка — точное количество базовой монеты

Builder — это **`buyTokenExactOut`**, и аргументы количества — это `outAmount` (базовая монета, которую вы хотите) и `maxBuyAmount` (quote, который вы потратите максимум). `Curve.buyExactOut({ poolInfo, amountA, ... })` — это соответствующий оффчейн-превью.

```ts
const { execute, extInfo } = await raydium.launchpad.buyTokenExactOut({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,

  outAmount:    new BN(1_000_000).mul(new BN(10).pow(new BN(6))),  // 1M базовой
  maxBuyAmount: new BN(2).mul(new BN(10).pow(new BN(9))),          // лимит 2 SOL
  slippage:     new BN(100),

  txVersion: TxVersion.V0,
});

console.log("out:", extInfo.outAmount.toString(), "max spent:", extInfo.maxSpentAmount.toString());
await execute({ sendAndConfirm: true });
```

Полезно для UI типа "купить ровно X токенов". Builder отклоняет `outAmount` равный нулю на клиенте, и программа откатывает, если кривая сдвинулась настолько, что требование котировки превышает `maxBuyAmount`.

## Продажа

Источник: [`src/launchpad/sell.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/sell.ts)

Builder — это **`sellToken`** (`sellTokenExactOut` для варианта с точным выходом quote), с `sellAmount` и опциональным `minAmountB`. `Curve.sellExactIn({ poolInfo, amountA, ... })` показывает превью.

```ts
const inAmount = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M базовой

const res = Curve.sellExactIn({
  poolInfo,
  amountA: inAmount,
  protocolFeeRate: poolInfo.configInfo.tradeFeeRate,
  platformFeeRate: platformInfo.feeRate,
  creatorFeeRate:  platformInfo.creatorFeeRate,
  curveType:       poolInfo.configInfo.curveType,
  shareFeeRate:    new BN(0),
  transferFeeConfigA: mintInfo.extensions.feeConfig  ? toTransferFeeConfig(mintInfo,  epochInfo.epoch) : undefined,
  transferFeeConfigB: mintBInfo.extensions.feeConfig ? toTransferFeeConfig(mintBInfo, epochInfo.epoch) : undefined,
  slot: await raydium.connection.getSlot(),
});
console.log("expected quote out:", res.amountB.toString());

const { execute } = await raydium.launchpad.sellToken({
  programId,
  mintA,
  mintAProgram: new PublicKey(mintInfo.programId),
  mintB:        poolInfo.mintB,
  mintBProgram: new PublicKey(mintBInfo.programId),
  poolInfo,
  configInfo:      poolInfo.configInfo,
  platformFeeRate: platformInfo.feeRate,
  sellAmount:      inAmount,
  slippage:        new BN(100),
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Путь продажи на кривой симметричен пути покупки: уменьшение `real_a` на `sellAmount` возвращает `quote_out`, равный интегрированной площади под кривой между `real_a − sellAmount` и `real_a`, минус комиссия продажи. `sellAmount` должен быть больше нуля — builder отклоняет ноль перед любым RPC.

## Выпуск

<Warning>
  **Выпуск — это не то, что может запустить интегратор.** Нет `raydium.launchpad.graduate`, нет флага `autoGraduate` на builders покупки и нет поля `willGraduate` в их возвращаемом значении. На цепи выпуск — это `MigrateToCpswap` (или устаревший `MigrateToAmm`), и обе инструкции ограничивают своего подписывающего кошельком, записанным на привязанном `GlobalConfig` — `migrate_to_cpswap_wallet` и `migrate_to_amm_wallet` соответственно. Вызов от любого другого подписывающего завершается с ошибкой `InvalidOwner`. Это **не** разрешено всем, и никакой MEV-бот не может его перегнать.
</Warning>

Эти кошельки управляются cranком выпуска Raydium, поэтому на практике миграция происходит в течение нескольких секунд после пересечения порога, независимо от того, кто сделал финальную покупку. Со стороны интегратора единственное, что нужно делать — это рассматривать переход статуса как быстрое событие: опрашивайте `getRpcPoolInfo` (или подписывайтесь через gRPC, ниже) и переключайте ваш UI с кривой на результирующий пул CPMM, когда `status` меняется.

См. [`products/launchlab/instructions`](/ru/products/launchlab/instructions#migratetoamm-/-migratetocpswap) для списков аккаунтов, комиссии миграции и того, как LP разделяется при выпуске.

## Сбор комиссий создателя

Источник: [`src/launchpad/claimCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/claimCreatorFee.ts) (одна монета) и [`collectAllCreatorFees.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/collectAllCreatorFees.ts) (пакетная)

Метод — это **`claimCreatorFee`** (и `claimMultipleCreatorFee` для пакетной формы). Он индексируется по **quote mint**, а не по запуску — один вызов собирает накопленные комиссии создателя подписывающего в этой монете по всем его запускам:

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute } = await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,          // quote mint для сбора
  // mintBProgram: TOKEN_PROGRAM_ID,   // или TOKEN_2022_PROGRAM_ID
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Переводит счётчик накопленной комиссии создателя на ATA создателя на quote mint. Можно вызывать до или после выпуска; используйте периодически вместо ожидания огромного баланса. Операторы платформы имеют параллельные builders `claimPlatformFee` / `claimAllPlatformFee` / `claimVaultPlatformFee`.

## Отслеживание запуска через его жизненный цикл

Собирая всё вместе, скрипт мониторинга может выглядеть так:

```ts
async function watch(poolId: PublicKey) {
  const startStatus = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

  while (true) {
    const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
    const progress = Number(p.realB.toString()) / Number(p.totalFundRaisingB.toString());

    console.log(`status=${p.status}`, `progress=${(progress * 100).toFixed(2)}%`);

    if (p.status !== startStatus) {
      console.log("status changed - the launch has migrated; switch to the pool page");
      break;
    }
    await new Promise((r) => setTimeout(r, 10_000));
  }
}
```

Опрос `getRpcPoolInfo` с интервалом 10 секунд подходит для одного запуска. Для индексера используйте вместо этого подписку gRPC ниже — `getRpcPoolsInfo({ poolIdList })` пакетирует, но опрос сотен пулов всё равно сжигает RPC кредиты без пользы.

## Наблюдение за конфигами и пулами через gRPC

Источник: [`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

Подписывается на программу LaunchLab через Yellowstone gRPC и логирует каждое обновление `GlobalConfig` и `PoolState` с программой токена каждой монеты. Два фильтра `datasize` на одной подписке `accounts` разделяют два типа аккаунтов, поэтому один поток охватывает оба.

Демонстрация — это самая короткая правильная ссылка для классификации монет запуска, что выпуск [Token-2022 quote-mint](/ru/reference/changelog/2026-08-24-launchlab-token2022-quote-mint) делает необходимым:

- **Пулы** классифицируются прямо из `PoolState.token_program_flag`, декодируя бит0 для базовой монеты и бит1 для quote монеты без выборки монеты вообще. Проверка всего байта против `0` — что было достаточно, пока quote монеты были только legacy — неправильно интерпретирует legacy базовую монету как Token-2022 всякий раз, когда quote монета это Token-2022.
- **Конфиги** не могут быть классифицированы таким образом: `GlobalConfig` хранит адрес своей quote монеты и никакой флаг программы, поэтому демонстрация один раз читает владельца аккаунта монеты и кэширует его по монете.

Это также перекрёстно проверяет два друг против друга, что является полезным утверждением для сохранения в вашем собственном индексере. Обратите внимание, что `create` против `update` выводится из собственных кэшей демонстрации, инициализированных при запуске из `getProgramAccounts`; с отключённой инициализацией читайте "create" как "впервые видно на этом потоке".

Доступ gRPC не является частью публичной поверхности RPC — см. [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md) репозитория примеров.

## Rust CPI

Вызов LaunchLab из вашей собственной программы Anchor редок (большинство интеграций запусков только на стороне TS). Если вы это делаете:

- Крейт — это **`raydium-launchpad`** (имя lib `raydium_launchpad`), версия `0.2.0`, и он действительно предоставляет функцию `cpi`. **Нет** `raydium_launchlab`.
- Он **не опубликован на crates.io** — зависит от него по git-ревизии, так же как другие крейты программ Raydium.
- Точки входа CPI названы в честь инструкций на цепи, а не методов TypeScript SDK: `buy_exact_in`, `buy_exact_out`, `sell_exact_in`, `sell_exact_out`, `claim_creator_fee`, `create_vesting_account`, `claim_vested_token`. `migrate_to_amm` / `migrate_to_cpswap` ограничены подписывающим кошельками миграции `GlobalConfig` и не вызываются из программы интегратора.

См. [`sdk-api/rust-cpi`](/ru/sdk-api/rust-cpi) для правил фиксации крейта — в частности разделение версии Anchor, которое определяет, может ли один крейт вызывать CPI как в LaunchLab, так и в CLMM.

## Подводные камни

- **Путаница между названиями инструкций на цепи и методами SDK.** Программа имеет `buy_exact_in` / `sell_exact_in`; SDK имеет `buyToken` / `sellToken`. `buyExactIn` и `sellExactIn` существуют только как **статические методы на `Curve`**, и они вычисляют котировку — они не строят транзакцию.
- **Забывание `extraSigners`.** `createLaunchpad` создаёт базовую монету из keypair, который вы генерируете, поэтому этот keypair должен подписать. Пропустите `extraSigners: [pair]` и транзакция не пройдёт проверку подписи.
- **Не выбор quote mint.** Вы его не передаёте. Quote mint — это свойство `GlobalConfig`, который вы привязываете через `configId` — `getPdaLaunchpadConfigId(programId, quoteMint, curveType, index)`. Для запуска против другого quote mint привяжите другой конфиг; `raydium.api.fetchLaunchConfigs()` перечисляет доступные с их параметрами по умолчанию.
- **Размер метаданных.** Длинные строки `uri` выталкивают Metaplex CPI за бюджет. Держите `uri` под ~200 символов — большинство размещённых на CDN JSON метаданных легко подходят. `symbol` жёстко ограничен 10 символами.
- **Рассмотрение выпуска как гонки, в которую вы можете вступить.** Это не так — см. предупреждение выше. Ваш UI всё равно должен рассматривать переходы `status` как быстрые события, потому что crank Raydium приземляет миграцию в течение нескольких секунд после пересечения порога.
