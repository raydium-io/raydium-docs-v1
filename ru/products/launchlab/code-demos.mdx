## Подготовка

Примеры здесь соответствуют файлам в [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad). Инициализация следует шаблону репозитория демо [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template):

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Создание запуска

Источник: [`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts) (и [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts) для варианта на основе API Bonk)

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId: /* ID программы LaunchLab из reference/program-addresses */,
  // Метаданные токена для нового базового mint:
  name:   "Example Token",
  symbol: "EXMPL",
  uri:    "https://example.com/metadata.json",
  decimals: 6,

  // Параметры кривой:
  curveType: 0,                                      // 0 = квадратичная
  supply:    new BN(1_000_000_000).mul(new BN(10).pow(new BN(6))), // 1B базовых (6 дец)
  graduationFractionBps: 8000,                       // 80% → выпуск
  initialK:  new BN("40"),                           // параметр формы кривой

  // Сторона котировки:
  quoteMint: NATIVE_MINT,                            // WSOL
  openTime:  new BN(Math.floor(Date.now() / 1000) + 60),  // открывается через 1 мин

  // Политика комиссий:
  fees: {
    buyNumerator:   new BN(100),                     // 1.00%
    buyDenominator: new BN(10_000),
    sellNumerator:  new BN(100),
    sellDenominator: new BN(10_000),
    lpShare:         new BN(60),
    creatorShare:    new BN(20),
    protocolShare:   new BN(20),
    totalShare:      new BN(100),
  },

  postGraduationLpPolicy: "burn",                    // "burn" | "lock" | "toCreator"

  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Launch:", extInfo.launchState.toBase58());
console.log("Base mint:", extInfo.baseMint.toBase58());
console.log("Create tx:", txId);
```

Примечания:

- `initialK` — масштабирующий коэффициент для квадратичной кривой. Настройте его для достижения определённой цены открытия CPMM при выпуске. См. [`products/launchlab/bonding-curve`](/ru/products/launchlab/bonding-curve) для вывода формулы.
- SDK создаёт базовый mint, PDA метаданных и оба хранилища в одной транзакции. Если URI метаданных длинный, может превысить 1232 байта; в этом случае SDK разбивает на две транзакции.
- После `Initialize` запуск не торгуется до `openTime`. Установите `openTime` на минуту-две вперёд, чтобы дать фронт-раннерам меньше шансов захватить первую покупку.

## Получение состояния запуска

```ts
const launchId = new PublicKey("<LAUNCH_STATE>");

const launch = await raydium.launchpad.getLaunchById({ launchId });
console.log("Status:", ["Active","Graduated","Cancelled"][launch.status]);
console.log("Base sold:", launch.baseSold.toString(),
            "/", launch.baseSupplyMax.toString());
console.log("Quote collected:", launch.quoteReserveReal.toString(),
            "target:", launch.quoteReserveTarget.toString());
if (launch.status === 1) {
  console.log("Post-graduation CPMM pool:", launch.cpmmPoolState.toBase58());
}
```

`getLaunchById` возвращает декодированный `LaunchState` плюс вычисленную долю «прогресса к выпуску» как `Decimal`.

## Покупка — точный ввод котировки

Источник: [`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

```ts
const quoteIn        = new BN(1).mul(new BN(10).pow(new BN(9)));  // 1 SOL
const minimumBaseOut = new BN(0);  // принять любой; затянуть для production

// Предпросмотр котировки off-chain, чтобы UI показал ожидаемый base_out:
const preview = raydium.launchpad.computeBuyBase({
  launchState: launch,
  quoteIn,
});
console.log("Expected base_out:", preview.baseOut.toString(),
            "price impact:", preview.priceImpact.toString());

const { execute } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn,
  minimumBaseOut,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

`computeBuyBase` зеркалирует on-chain решатель Ньютона (квадратичная кривая) или замкнутую форму CPMM-инверсии (curve_type 1). Используйте его для заполнения поля UI «Вы получите».

## Покупка — точный вывод базы

```ts
const baseOut         = new BN(1_000_000).mul(new BN(10).pow(new BN(6)));  // 1M базовых
const maximumQuoteIn  = new BN(2).mul(new BN(10).pow(new BN(9)));          // лимит 2 SOL

const { execute } = await raydium.launchpad.buyExactOut({
  launchInfo: launch,
  baseOut,
  maximumQuoteIn,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Полезно для UI «купить ровно X токенов». Отклоняет с `ExceededSlippage`, если кривая сдвинулась настолько, что требование котировки теперь превышает `maximumQuoteIn`.

## Продажа

Источник: [`src/launchpad/sell.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/sell.ts)

```ts
const baseIn           = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M базовых
const minimumQuoteOut  = new BN(0);

const { execute } = await raydium.launchpad.sellExactIn({
  launchInfo: launch,
  baseIn,
  minimumQuoteOut,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Путь продажи кривой симметричен пути покупки: уменьшение `base_sold` на `baseIn` возвращает `quote_out`, равный интегрированной площади под кривой между `base_sold − baseIn` и `base_sold`, минус комиссия продажи.

## Автоматический выпуск при пересечении порога покупкой

SDK встраивает инструкцию `Graduate` внутри транзакции `buy*`, когда обнаруживает, что состояние после покупки пересечёт порог:

```ts
const { execute, willGraduate } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn: new BN(100).mul(new BN(10).pow(new BN(9))),    // крупная покупка
  minimumBaseOut: new BN(0),
  txVersion: TxVersion.V0,
  autoGraduate: true,                                      // по умолчанию
});

if (willGraduate) {
  console.log("This buy will trigger graduation.");
}

const { txId } = await execute({ sendAndConfirm: true });
```

Поскольку `Graduate` не требует разрешения, любой (включая MEV-бота) может попытаться приземлить первый `Graduate` после пересечения порога — обычно через несколько секунд, а не минут. Первый приземлившийся просто платит аренду за счета пула CPMM; они не получают никакой другой выгоды.

## Ручной `Graduate`

Если `autoGraduate` был отключен или транзакция пересечения порога не удалась, вы можете запустить выпуск отдельно:

```ts
const { execute } = await raydium.launchpad.graduate({
  launchInfo: launch,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Откатывается с `NotAtThreshold`, если `quote_reserve_real < quote_reserve_target` на момент отправки. Безопасно для повторных попыток — вторая попытка `Graduate` после успеха откатывается с `NotActive`.

## Сбор комиссий создателя

Источник: [`src/launchpad/claimCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/claimCreatorFee.ts) (один mint) и [`collectAllCreatorFees.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/collectAllCreatorFees.ts) (пакетный)

```ts
const { execute } = await raydium.launchpad.collectCreatorFees({
  launchInfo: launch,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Переводит накопленную сумму счётчика комиссии создателя на ATA создателя на mint котировки. Можно вызывать до или после выпуска; используйте периодически, а не ждите, пока накопится огромный баланс.

## Отслеживание запуска через его жизненный цикл

Собрав всё вместе, скрипт мониторинга может выглядеть так:

```ts
async function watch(launchId: PublicKey) {
  while (true) {
    const launch = await raydium.launchpad.getLaunchById({ launchId });
    const progress =
      Number(launch.quoteReserveReal) /
      Number(launch.quoteReserveTarget);

    console.log(
      `status=${["Active","Graduated","Cancelled"][launch.status]}`,
      `progress=${(progress * 100).toFixed(2)}%`,
      `num_buys=${launch.stateData.numBuys}`,
    );

    if (launch.status === 1) {
      console.log("Graduated to CPMM pool:", launch.cpmmPoolState.toBase58());
      break;
    }
    await new Promise(r => setTimeout(r, 10_000));
  }
}
```

## Мониторинг конфигов и пулов через gRPC

Источник: [`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

Подписывается на программу LaunchLab через Yellowstone gRPC и логирует каждое обновление `GlobalConfig` и `PoolState` с программой токена каждого mint. Два фильтра `datasize` на одной подписке `accounts` разделяют два типа счётов, поэтому один поток охватывает оба.

Демо — это самый короткий правильный справочник для классификации mint'ов запуска, что [выпуск Token-2022 quote-mint](/ru/reference/changelog/2026-08-24-launchlab-token2022-quote-mint) делает необходимым:

- **Пулы** классифицируются прямо из `PoolState.token_program_flag`, декодируя бит0 для базового mint и бит1 для quote mint без выборки mint вообще. Проверка всего байта против `0` — что было достаточно, пока quote mint были только legacy — неправильно читает legacy базовый mint как Token-2022 всякий раз, когда quote mint является Token-2022.
- **Конфиги** не могут быть классифицированы таким образом: `GlobalConfig` хранит адрес своего quote mint и никакой флаг программы, поэтому демо читает владельца счёта mint один раз и кэширует его для каждого mint.

Он также перекрёстно проверяет два друг против друга, что является полезным утверждением для сохранения в вашем собственном индексаторе. Обратите внимание, что `create` против `update` выводится из собственных кэшей демо, инициализированных при запуске из `getProgramAccounts`; с отключённой инициализацией читайте «create» как «впервые видно на этом потоке».

Доступ gRPC не является частью общедоступной поверхности RPC — см. [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md) репозитория демо.

## Rust CPI

Вызов LaunchLab из вашей собственной программы Anchor редок (большинство интеграций запусков только на стороне TS). Если вы это делаете, программа поставляется с крейтом Anchor `raydium_launchlab` с `cpi::accounts::Buy`, `cpi::accounts::Sell` и т. д. — паттерн зеркалирует примеры CPI CPMM / CLMM. См. [`sdk-api/rust-cpi`](/ru/sdk-api/rust-cpi) для обобщённого шаблона, когда этот сайт будет заполнен.

## Подводные камни

- **Арифметика разделения комиссии off-by-one.** Если `total_share` не равен ровно `lp_share + creator_share + protocol_share`, `Initialize` откатывается с `InvalidFeeShares`. Установите `totalShare` равным сумме.
- **Использование недопустимого quote mint.** `launch_config.allowed_quote_mints` — это фиксированный список; передача любого другого mint откатывается. Сначала проверьте с `raydium.launchpad.getConfig()`.
- **Размер метаданных.** Длинные строки `uri` выводят Metaplex CPI за пределы бюджета. Держите `uri` под ~200 символов — большинство размещённых на CDN JSON метаданных легко подходят.
- **Гонка выпуска.** Автоматизированные боты мониторят `quote_reserve_real` и фронт-раннят `Graduate` в пределах слота или двух после пересечения порога. Это безвредно — это только стоит им аренды — но это означает, что ваш UI должен рассматривать переходы `status` как быстрые события.
