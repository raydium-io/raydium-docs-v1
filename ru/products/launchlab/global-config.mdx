<Info>
  `GlobalConfig` — это конфигурационный счет на **уровне протокола**. Их может быть много — идентифицируются по `(curve_type, index)` — и каждый запуск выбирает ровно один при инициализации. Значения выбранного `GlobalConfig` становятся жёсткими ограничениями для параметров этого запуска. Для настройки на уровне платформы (комиссия за платформу, допустимые формы кривых, разделение NFT при выпуске) см. [`products/launchlab/platform-config`](/ru/products/launchlab/platform-config).
</Info>

## Что это такое

`GlobalConfig` — это PDA, уникальный для каждой пары `(curve_type, index)`, который устанавливает правила на уровне протокола, которым должен подчиняться каждый запуск:

- Тип допустимой кривой связи (`curve_type`).
- Ставка комиссии за торговлю, которую взимает кривая при каждой покупке и продаже.
- Комиссия за миграцию, взимаемая при выпуске.
- Минимумы для предложения, коэффициента блокировки, коэффициента продажи и коэффициента миграции.
- Минт котировки (обычно обёрнутый SOL или USDC) — актив, которым пользователи покупают.
- Четыре кошелька на уровне протокола: владелец комиссии протокола, владелец комиссии миграции и два кошелька управления миграцией, зарезервированные для выпуска CPMM и legacy AMM v4.

Счета `GlobalConfig` могут быть созданы администратором программы LaunchLab или делегированным органом создания конфигурации. Только администратор обновляет существующие конфигурации. См. [`reference/program-addresses`](/ru/reference/program-addresses) для получения канонических органов власти.

## Структура

```rust
// states/config.rs
pub const GLOBAL_CONFIG_SEED: &str = "global_config";

#[account]
pub struct GlobalConfig {
    pub epoch:                   u64,         // recent_epoch tracker
    pub curve_type:              u8,          // 0 = ConstantProduct, 1 = FixedPrice, 2 = LinearPrice
    pub index:                   u16,         // discriminator within a curve_type
    pub migrate_fee:             u64,         // SOL paid on graduation
    pub trade_fee_rate:          u64,         // 1/1_000_000 of volume
    pub max_share_fee_rate:      u64,         // 100 bps cap on platform share fee
    pub min_base_supply:         u64,         // floor on Initialize supply (no decimals)
    pub max_lock_rate:           u64,         // ceiling on vesting locked / supply
    pub min_base_sell_rate:      u64,         // floor on base_supply_graduation / supply
    pub min_base_migrate_rate:   u64,         // floor on tokens that seed the post-graduation pool
    pub min_quote_fund_raising:  u64,         // floor on quote_reserve_target (with decimals)
    pub quote_mint:              Pubkey,
    pub protocol_fee_owner:      Pubkey,      // claims protocol fees via CollectFee
    pub migrate_fee_owner:       Pubkey,      // claims migration fees via CollectMigrateFee
    pub migrate_to_amm_wallet:   Pubkey,      // can sign MigrateToAmm
    pub migrate_to_cpswap_wallet:Pubkey,      // can sign MigrateToCpswap
    pub padding_alignment:       [u8; 8],
    pub padding:                 [u64; 15],
}
```

Вывод PDA:

```ts
const [globalConfig] = PublicKey.findProgramAddressSync(
  [
    Buffer.from("global_config"),
    Buffer.from(quoteMint.toBytes()),
    Buffer.from([curveType]),
    u16ToBytes(index),
  ],
  LAUNCHLAB_PROGRAM_ID,
);
```

(Перед подписанием проверьте точный порядок seed в счёте в цепи — инструкция `create_config` программы является источником истины.)

## Семантика полей

### `curve_type` и `index`

Вместе они уникально идентифицируют `GlobalConfig`. Существует один `GlobalConfig` для каждой пары `(curve_type, index)`:

- `curve_type = 0` — кривая виртуального резерва с постоянным произведением. По умолчанию и наиболее используемая.
- `curve_type = 1` — кривая с фиксированной ценой.
- `curve_type = 2` — кривая с линейной ценой.

`index` — это `u16`, который позволяет администратору опубликовать несколько конфигураций для каждого типа кривой (например, одну с более жёсткой комиссией, одну с более высоким минимальным сбором котировки). При инициализации запуск предоставляет пару `(curve_type, index)`, и программа загружает соответствующий `GlobalConfig`.

### Комиссии

- `trade_fee_rate` — выражена в `1/1_000_000` от объёма торговли. Применяется к каждой покупке и продаже на кривой. `protocol_fee_owner` требует свою долю через `CollectFee`.
- `migrate_fee` — фиксированная комиссия в лампортах (или единицах котировки, в зависимости от конфигурации), взимаемая один раз при выпуске. Требуется `migrate_fee_owner` через `CollectMigrateFee`.
- `max_share_fee_rate` — инициализируется как `10_000` (100 bps). Ограничивает ставку комиссии за долю **платформы** из привязанного `PlatformConfig` (см. [`platform-config`](/ru/products/launchlab/platform-config)). Программа обеспечивает `trade_fee_rate + max_share_fee_rate < RATE_DENOMINATOR_VALUE`.

### Минимумы предложения и коэффициентов

Эти минимумы ограничивают параметры формы кривой, которые запуск может выбрать при инициализации. Если `CurveParams` создателя нарушает любой из них, `Initialize` откатывается с `InvalidInput`.

- `min_base_supply` — минимальное `supply` (без десятичных знаков), которое может объявить кривая. По умолчанию `10_000_000`.
- `max_lock_rate` — выражена в `1/1_000_000`; по умолчанию `300_000` (30%). Ограничивает vesting через `total_locked_amount <= supply * max_lock_rate / 1_000_000`.
- `min_base_sell_rate` — выражена в `1/1_000_000`; по умолчанию `200_000` (20%). Ограничивает `base_supply_graduation / supply` снизу.
- `min_base_migrate_rate` — выражена в `1/1_000_000`; по умолчанию `200_000` (20%). Ограничивает количество токенов, оставшихся для заполнения пула после выпуска.
- `min_quote_fund_raising` — минимальный `quote_reserve_target`, который может объявить запуск (с десятичными знаками). По умолчанию `30_000_000_000` единиц минта котировки.

### Минт котировки и кошельки протокола

- `quote_mint` — актив, которым пользователи покупают. Большинство запусков используют обёрнутый SOL (`So111…112`) или USDC (`EPjF…Dt1v`). Один `GlobalConfig` привязан к одному минту котировки; запуски, которым нужна другая котировка, нацелены на другой `(curve_type, index)`.
- `protocol_fee_owner` — публичный ключ, который подписывает `CollectFee` и требует накопленные комиссии протокола для каждого запуска, привязанного к этой конфигурации. Хранится в цепи; администратор может ротировать его через `UpdateConfig`.
- `migrate_fee_owner` — публичный ключ, который подписывает `CollectMigrateFee`.

### Кошельки миграции

Два хранящихся кошелька выпуска требуют разных подписантов:

- `migrate_to_amm_wallet` — подписывает `MigrateToAmm` для существующего legacy запуска, чей сохранённый `migrate_type = 0`.
- `migrate_to_cpswap_wallet` — подписывает `MigrateToCpswap`. Каждый вновь инициализированный запуск использует этот путь.

Обычно они удерживаются операционным механизмом выпуска Raydium, поэтому выпуск происходит вскоре после того, как кривая достигает порога, а не ждёт, пока создатель его вызовет.

### Списки разрешений на уровне платформы

`GlobalConfig` больше не имеет `requires_platform_auth`. Его бывший байт — это заполнение, поэтому размер счёта не меняется. Доступ теперь контролируется `PlatformConfig.restrict_global_config` и счётами `PlatformAllowConfig`, созданными администратором этой платформы. См. [`platform-config`](/ru/products/launchlab/platform-config).

## Значения по умолчанию при инициализации

Когда вызывается `CreateConfig`, программа инициализирует многие поля жёсткими значениями по умолчанию:

```rust
self.max_share_fee_rate     = 10_000;                  // 100 bps
self.min_base_supply        = 10_000_000;              // no decimals
self.max_lock_rate          = 300_000;                 // 30%
self.min_base_migrate_rate  = 200_000;                 // 20%
self.min_base_sell_rate     = 200_000;                 // 20%
self.min_quote_fund_raising = 30_000_000_000;
```

Администратор явно устанавливает `curve_type`, `index`, `migrate_fee`, `trade_fee_rate`, `quote_mint` и четыре публичных ключа кошельков при создании; последующие значения можно настроить через `UpdateConfig`.

## Как запуск выбирает `GlobalConfig`

При инициализации создатель передаёт:

- `(curve_type, index)` для выбора, какой PDA `GlobalConfig` загружать.
- `CurveParams`, описывающий форму кривой (`supply`, `total_base_sell`, `total_quote_fund_raising`, `migrate_type`).
- `VestingParams`, описывающий заблокированное предложение.
- `MintParams` для базового минта.

Программа обеспечивает:

- `curve_type` совпадает с `global_config.curve_type`.
- `supply >= global_config.min_base_supply`.
- `total_locked_amount <= supply * max_lock_rate / 1_000_000`.
- `total_base_sell >= supply * min_base_sell_rate / 1_000_000`.
- `(supply − total_base_sell − total_locked_amount) >= supply * min_base_migrate_rate / 1_000_000` — т.е. достаточно токенов, оставшихся для заполнения пула после выпуска.
- `total_quote_fund_raising >= min_quote_fund_raising`.
- `migrate_type == 1` (`CPSWAP`).
- Если выбранная платформа имеет `restrict_global_config == 1`, включается соответствующий `PlatformAllowConfig`.

После инициализации `PoolState` запуска хранит публичный ключ `global_config` напрямую, поэтому привязка постоянна.

## Путь обновления

`UpdateConfig` доступен только администратору и принимает пару `(param: u8, value: u64)`. Каждое значение `param` выбирает, какое поле мутировать:

| `param` | Изменённое поле |
|---------|---------------|
| 0 | `migrate_fee` |
| 1 | `trade_fee_rate` |
| 2 | `max_share_fee_rate` |
| 3 | `min_base_supply` |
| 4 | `max_lock_rate` |
| 5 | `min_base_sell_rate` |
| 6 | `min_base_migrate_rate` |
| 7 | `min_quote_fund_raising` |

Ротации кошельков (`protocol_fee_owner`, `migrate_fee_owner`, `migrate_to_amm_wallet`, `migrate_to_cpswap_wallet`) принимают отдельную форму аргумента `Pubkey`; проверьте исходный код `update_config` для точной таблицы диспетчеризации перед составлением транзакции администратора.

Бывший селектор `UpdateConfig` `12` для авторизации платформы удалён. Администраторы платформ теперь управляют своими собственными списками разрешений.

## Чтение `GlobalConfig` с клиента

```ts
import { Raydium } from "@raydium-io/raydium-sdk-v2";

// Fetch by PDA derivation:
const [configPda] = PublicKey.findProgramAddressSync(
  [
    Buffer.from("global_config"),
    quoteMint.toBytes(),
    Buffer.from([curveType]),
    u16ToBytes(index),
  ],
  LAUNCHLAB_PROGRAM_ID,
);

const config = await raydium.launchpad.getGlobalConfig(configPda);
console.log(config.tradeFeeRate, config.minQuoteFundRaising);
```

Для пользовательского интерфейса, перечисляющего все доступные конфигурации, используйте вспомогательный метод SDK `getAllGlobalConfigs` или запросите конечную точку API LaunchLab, которая их отражает; количество счётов в цепи невелико (на практике однозначное число).
