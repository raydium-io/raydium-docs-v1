## Проблема, которую решает LaunchLab

До появления LaunchLab запуск нового токена на Raydium требовал от создателя предварительного заполнения AMM пула обеими сторонами пары — то есть команда должна была предоставить ликвидность на стороне quote (SOL или USDC) из собственного кармана. Это благоприятствовало хорошо финансируемым проектам и ограничивало доступ к механизму launchpad начальным капиталом.

LaunchLab заменяет этот начальный этап на **bonding curve**: токен развёртывается против кривой, оценённой в quote mint (обычно SOL или USDC). Покупатели получают токен, отправляя quote на кривую, которая атомарно минтит или выпускает единицы базового токена по цене, определяемой формулой кривой и текущим предложением. Предварительно заполненная ликвидность не требуется.

Когда кривая накопит достаточно quote для соответствия формуле ликвидности реального AMM пула, она **выпускается**: программа создаёт CPMM пул на mainnet, заполненный базовым резервом и quote резервом кривой, и с этого момента торговля переходит на AMM.

## Жизненный цикл

```
             ┌───────────────────────┐
creator  ──▶ │  Initialize (Launch)  │   ▸ минтит базовый токен, финансирует хранилища кривой,
             │                        │     устанавливает параметры кривой и порог graduation
             └───────────┬────────────┘
                         │
                         ▼
             ┌───────────────────────┐       повторяется N раз
             │   Buy  /  Sell        │ ◀─── трейдеры взаимодействуют с кривой
             └───────────┬────────────┘
                         │ quote_vault кривой
                         │ пересекает порог
                         ▼
             ┌───────────────────────┐   ▸ снимает снимок состояния кривой
             │      Graduate         │   ▸ развёртывает CPMM пул, заполненный резервами кривой
             │                        │   ▸ блокирует / сжигает оставшееся предложение базового токена
             └───────────┬────────────┘
                         │
                         ▼
             ┌───────────────────────┐
             │   CPMM пул активен    │   ▸ стандартное поведение CPMM далее
             └───────────────────────┘
```

Каждый запуск проходит через эту последовательность ровно один раз. `Buy` и `Sell` — это инструкции, обращённые к пользователям на средней фазе. После пересечения порога кошелёк миграции, хранящийся на `GlobalConfig`, подписывает `MigrateToCpswap`.

## Две фиксированные стороны

Состояние LaunchLab имеет два выделенных аккаунта:

- **The base mint** — запускаемый токен. Его mint authority удерживается программой LaunchLab до graduation; после graduation он отзывается.
- **The quote mint** — залог. Всегда mainstream mint (SOL / USDC / RAY). Конфигурация запуска выбирает один при `Initialize`; он не может быть изменён.

Плюс два хранилища:

- **`base_vault`** — содержит часть предложения базового токена, которая была предварительно минтирована на кривую, но ещё не продана. Уменьшается по мере покупок пользователей.
- **`quote_vault`** — накапливает quote, выплаченный покупателями. Увеличивается по мере покупок пользователей. Этот баланс проверяется против порога graduation.

## Модель ценообразования

LaunchLab поддерживает несколько формул кривых (см. [`bonding-curve`](/ru/products/launchlab/bonding-curve)). Наиболее распространённая — это **квадратичная** bonding curve, аналогичная линии Pump.fun / Curve.fi / Bancor:

```
price(s) = k × (s / S_max)²     (или аналогично — точная формула зависит от конфигурации кривой)
```

где `s` — количество базового токена, уже проданного пользователям, а `S_max` — максимальное предложение кривой. Цена монотонно растёт с каждой покупкой и падает с каждой продажей. Поскольку программа вычисляет интегрированную стоимость, учитывающую AMM, покупка любого размера возвращает правильное интегрированное количество; нет проскальзывания за пределами естественной выпуклости кривой.

## Graduation

Запуск выпускается, когда `quote_vault.balance ≥ graduation_threshold`. Порог устанавливается при `Initialize` и обычно выбирается так, чтобы при graduation подразумеваемая цена кривой совпадала с ценой, при которой откроется AMM пул с собранными резервами. Конкретно:

```
threshold ≈ S_graduate × price(S_graduate) × f
```

где `S_graduate` — количество базового токена, уже проданного, `price(S_graduate)` — предельная цена кривой в этой точке, а `f` — небольшой коэффициент для учёта комиссии (1–2%).

При graduation:

1. Программа снимает снимок `(base_vault_remaining, quote_vault)`.
2. Она вызывает CPMM `CreatePool` CPI с этими двумя резервами, минтируя начальный LP программе-владельцу (обычно сжигается / блокируется в соответствии с политикой).
3. Она отзывает mint authority базового токена (чтобы больше никогда не могли быть минтированы базовые токены).
4. `LaunchState.status` переключается на `Graduated`.

После graduation `Buy` и `Sell` отклоняются. Торговля продолжается на полученном CPMM пуле, который неотличим от любого другого CPMM пула Raydium.

## Комиссии

На фазе кривой каждый `Buy` и `Sell` несёт комиссию, разделённую между:

- **Curve LP side** — увеличивает подразумеваемый `k` кривой, что выгодно более поздним покупателям (более плотная цена).
- **Protocol** — начисляется администратору LaunchLab, собирается через `CollectFees`.
- **Creator** — опционально, настраивается при `Initialize`. Некоторые запуски направляют долю создателю как постоянный поток доходов.

Ставки по умолчанию задокументированы на [`bonding-curve`](/ru/products/launchlab/bonding-curve). Точное разделение хранится на `LaunchState.fees` и может отличаться для каждого запуска.

После graduation комиссии следуют конфигурации CPMM, с которой был создан пул (обычно `AmmConfig[0]`, уровень 0.25%).

## Кто держит LP после graduation?

LaunchLab использует три сохранённые шкалы платформы для создания двух эффективных назначений LP:

- **Platform lock** — для миграций, выполненных после обновления 2026-08-14, `platform_scale + creator_scale` блокируется через LP-Lock и один Fee Key переходит на `platform_nft_wallet`, когда эта доля ненулевая. До обновления `creator_scale` создавал отдельный Fee Key создателя.
- **Burn** — `burn_scale` сжигается навсегда и не имеет Fee Key.

Шкалы находятся на `PlatformConfig` и должны суммироваться в `1_000_000`. Обновление изменяет только будущее выполнение миграции. Оно не изменяет Fee Keys создателя, созданные более ранними миграциями.

## Важные инварианты

- **Базовый mint не имеет инфляции после graduation.** Его `mint_authority` отзывается; `freeze_authority` никогда не устанавливался.
- **Все новые запуски только CPMM.** `Initialize`, `InitializeV2` и `InitializeWithToken2022` требуют `migrate_type = CPSWAP`. Существующее устаревшее состояние может по-прежнему использовать `MigrateToAmm`.
- **Состояние кривой монотонно в одном направлении.** `base_sold` только растёт при Buy, `quote_vault` только растёт при Buy (падает при Sell — что симметрично уменьшает `base_sold`). Программа никогда не позволяет кривой стать отрицательной.
- **Graduation — это односторонний шлюз.** Даже если торговля после graduation толкает цену AMM пула обратно ниже цены graduation, запуск не возвращается к кривой.

## Когда использовать LaunchLab

<Note>
  Эта страница описывает только механику протокола. Ничто здесь не является финансовым, юридическим или инвестиционным советом. Запуски токенов несут значительный финансовый риск. Проконсультируйтесь с соответствующими специалистами перед запуском токена, связанного с публичным сбором средств.
</Note>

- Вы запускаете новый токен без предыдущего рынка.
- Вы хотите, чтобы рынок определил открывающую цену CPMM, а не объявлял её заранее.
- Вы хотите позволить кому-либо — включая саму команду — покупать по одинаковым ценам, определяемым кривой, вместо предварительного распределения инсайдерам со скидкой.

**Не** используйте LaunchLab для:

- Существующих токенов с установленными рынками (используйте `CreatePool` на CPMM напрямую).
- Запусков, где вам нужен точный контроль над открывающей ценой AMM (вы можете приблизиться к ней с помощью тщательной конфигурации кривой, но механизм всё ещё управляется кривой).
- Токенов, требующих расширений Token-2022, которые LaunchLab не разрешает (программа запуска отклоняет расширения, такие как `TransferHook` и `PermanentDelegate`, даже на пути Token-2022).
