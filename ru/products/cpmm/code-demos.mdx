## Предварительные требования

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js decimal.js
```

Каждый пример на этой странице соответствует файлу в [`raydium-sdk-V2-demo/src/cpmm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/cpmm); ссылка на GitHub находится рядом с каждым разделом. Инициализация следует шаблону `config.ts.template` из репозитория демонстраций ([источник](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)):

```ts
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);

const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
```

Экземпляр `Raydium` — это фасад SDK, который используется во всех примерах ниже. `Raydium.load` асинхронен, потому что по умолчанию загружает список токенов; передайте `disableLoadToken: true`, чтобы пропустить эту загрузку. Проверка доступности функций уже пропущена, если вы не передадите `disableFeatureCheck: false`. Конфигурации комиссий загружаются лениво при первом использовании через `raydium.api.getCpmmConfigs()`.

## Создание пула CPMM

Источник: [`src/cpmm/createCpmmPool.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/createCpmmPool.ts)

```ts
import { PublicKey } from "@solana/web3.js";
import BN from "bn.js";
import { CREATE_CPMM_POOL_PROGRAM, CREATE_CPMM_POOL_FEE_ACC }
  from "@raydium-io/raydium-sdk-v2";
// (Если вам нужны все PDA пула сразу, экспортированный вспомогательный метод — `getCreatePoolKeys`.
//  Нет `getCpmmPdas`.)

const mintA = new PublicKey("So11111111111111111111111111111111111111112"); // wSOL
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// 1. Выберите конфигурацию комиссии. index=0 — это уровень 0.25%.
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0)!;

// 2. Получите метаданные монет, чтобы SDK мог обрабатывать расширения Token-2022.
const mintAInfo = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(mintB);

// 3. Постройте транзакцию.
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA:           mintAInfo,
  mintB:           mintBInfo,
  mintAAmount:     new BN(1_000_000_000),   // 1 SOL (при условии 9 десятичных знаков)
  mintBAmount:     new BN(   160_000_000),  // 160 USDC (при 160/SOL)
  startTime:       new BN(0),               // открыть сразу
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Пул создан в", extInfo.address.poolId.toBase58());
console.log("Tx:", txId);
```

Несколько вещей, которые SDK делает автоматически:

- Сортирует монеты в порядок token0/token1 перед выведением PDA.
- Платит одноразовую `create_pool_fee` на `poolFeeAccount`.
- Создаёт связанные токен-счета вызывающей стороны, если они отсутствуют.
- Выбирает правильную программу токенов (SPL Token или Token-2022) для каждой стороны.

После подтверждения вы можете получить состояние живого пула с помощью:

```ts
// getPoolInfoFromRpc принимает позиционную строку base58, не PublicKey и не объект.
const { poolKeys, poolInfo, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(
  extInfo.address.poolId.toBase58(),
);
```

## Своп (base-input)

Источник: [`src/cpmm/swap.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swap.ts)

```ts
import { CurveCalculator, FeeOn } from "@raydium-io/raydium-sdk-v2";

const POOL_ID = "<POOL_ID>";   // строка base58

// 1. Загрузите текущее состояние пула непосредственно из RPC (не из API).
const { poolInfo, poolKeys, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(POOL_ID);

const inputMint  = poolInfo.mintA.address;                // своп A → B
const amountIn   = new BN(100_000_000);                   // 0.1 SOL
const slippage   = 0.005;                                 // 0.5%

// 2. Получите котировку локально. CurveCalculator отражает математику в цепи, включая
//    комиссии за передачу Token-2022 с обеих сторон. Все восемь аргументов обязательны.
const baseIn = inputMint === poolInfo.mintA.address;
const swapResult = CurveCalculator.swapBaseInput(
  amountIn,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// Поля swapResult: inputAmount / outputAmount / tradeFee / protocolFee /
// fundFee / creatorFee / newInputVaultAmount / newOutputVaultAmount.
// Нет destinationAmountSwapped или sourceAmountSwapped.

// 3. Постройте и отправьте. Передача `slippage` здесь применяет ограничение —
//    не требуется ручная арифметика minimum-out.
const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: amountIn,
  swapResult,
  slippage,
  baseIn,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Tx свопа:", txId);
```

Примечание: SDK **всегда** повторно загружает состояние пула из RPC внутри `getPoolInfoFromRpc`. Не используйте котировку из `api-v3.raydium.io` для транзакции, которую вы собираетесь подписать — котировка, устаревшая на один блок, может привести к `ExceededSlippage` при посадке.

## Своп (base-output)

Источник: [`src/cpmm/swapBaseOut.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swapBaseOut.ts)

```ts
const amountOutWanted = new BN(15_000_000);        // 15 USDC
const slippage        = 0.005;

const baseIn = false; // false → mintB — входная сторона
const swapResult = CurveCalculator.swapBaseOutput(
  amountOutWanted,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// swapResult.inputAmount — требуемый вход; нет sourceAmountSwapped.

const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: new BN(0),   // не используется при fixedOut — сумма берётся из swapResult
  fixedOut:    true,
  swapResult,               // обязательно, и оно содержит целевую сумму выхода
  baseIn,
  slippage,
  txVersion:   TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

## Депозит ликвидности

Источник: [`src/cpmm/deposit.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/deposit.ts)

```ts
import { Percent } from "@raydium-io/raydium-sdk-v2";
import Decimal from "decimal.js";

// addLiquidity управляется ВХОДНОЙ суммой, а не суммой LP.
const uiInputAmount = "0.0001";
const inputAmount = new BN(
  new Decimal(uiInputAmount).mul(10 ** poolInfo.mintA.decimals).toFixed(0),
);
const slippage = new Percent(1, 100);   // Percent, а не число

const { execute } = await raydium.cpmm.addLiquidity({
  poolInfo,
  poolKeys,
  inputAmount,
  baseIn: true,           // inputAmount выражена в mintA
  slippage,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

SDK выводит парную сумму из текущих резервов пула, увеличивает каждую сторону на проскальзывание для аргументов инструкции `maximum_*` и создаёт ATA при необходимости. `raydium.cpmm.computePairAmount({ ... })` возвращает те же числа, если вам нужны они для предпросмотра UI.

## Сбор комиссий протокола/фонда/создателя

Источник: [`src/cpmm/collectCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectCreatorFee.ts), [`src/cpmm/collectAllCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectAllCreatorFee.ts)

Сбор протокола и фонда остаётся защищённым полномочиями. Комиссии создателя имеют два пути: подписанный создателем `CollectCreatorFee` и аддитивный `CollectCreatorFeePermissionless`, который может вызвать любой плательщик, но может передавать только на канонические ATA создателя. `0.2.64-alpha` поставляется с построителями уровня модуля для обоих путей создателя:

```ts
// подписано создателем
const { execute } = await raydium.cpmm.collectCreatorFees({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// без разрешения — любой плательщик; доходы идут на канонические ATA создателя
const { execute } = await raydium.cpmm.collectCreatorFeesPermissionless({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// несколько пулов сразу, подписано создателем
await raydium.cpmm.collectMultiCreatorFees({ poolInfoList, txVersion: TxVersion.V0 });
```

<Note>
  Две инструкции создателя имеют **разные дискриминаторы и макеты счетов** — инструкция без разрешения заменяет позиции подписывающего создателя / `amm_config` на отдельный `payer` и неподписывающего `creator`. Используйте соответствующий построитель вместо ручного обмена счетами на другом.

  В SDK нет построителя для комиссий протокола или фонда (`makeCollectProtocolFeeInstruction` и `makeCollectFundFeeInstruction` не существуют ни под каким именем) — это пути администратора. Построители инструкций низкого уровня, которые *существуют*, — это `collectCpFeeInstruction`, `makeCollectCreatorFeeInstruction` и `collectCreatorFeePermissionlessInInstruction`.
</Note>

Вне цепи вы можете читать накопленные комиссии непосредственно из `PoolState`:

```ts
const pool = await raydium.cpmm.getRpcPoolInfo(POOL_ID);   // строка base58
console.log("Накопленная комиссия протокола mintA:", pool.protocolFeesMintA.toString());
console.log("Накопленная комиссия протокола mintB:", pool.protocolFeesMintB.toString());
// Поля CpmmPoolInfoLayout — protocolFeesMintA/B, fundFeesMintA/B и
// creatorFeesMintA/B — нет полей ...Token0/...Token1.
```

## Скелет Rust CPI

Если вы хотите вызвать CPMM из собственной программы Anchor — например, хранилища, которое выполняет свопы от имени своих вкладчиков — контекст CPI выглядит так. Порядок счетов следует [`products/cpmm/instructions`](/ru/products/cpmm/instructions).

```rust
// Cargo.toml — ветка имеет значение: `master` всё ещё использует anchor-lang 0.32.1.
// raydium-cp-swap = { git = "https://github.com/raydium-io/raydium-cp-swap",
//                     branch = "chore/upgrade-anchor", features = ["cpi"] }
// anchor-lang      = "=1.0.2"   // должна совпадать с тем, что использует raydium-cp-swap
// anchor-spl       = "=1.0.2"
//
// Функция `cpi` обязательна — модуль `raydium_cp_swap::cpi` существует только
// под ней. Обратите внимание, что этот крейт не может делить программу с образцом CLMM в
// products/clmm/code-demos, который использует anchor-lang =0.32.1.

use anchor_lang::prelude::*;
use anchor_spl::token_interface::{TokenAccount, TokenInterface, Mint};
use raydium_cp_swap::cpi::accounts::Swap;
use raydium_cp_swap::cpi;
use raydium_cp_swap::program::RaydiumCpSwap;

#[derive(Accounts)]
pub struct ProxySwap<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,

    /// CHECK: проверяется программой CPMM
    pub authority:     UncheckedAccount<'info>,
    /// CHECK:
    pub amm_config:    UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub pool_state:    UncheckedAccount<'info>,

    #[account(mut)]
    pub input_token_account:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_token_account: InterfaceAccount<'info, TokenAccount>,

    #[account(mut)]
    pub input_vault:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_vault: InterfaceAccount<'info, TokenAccount>,

    pub input_token_program:  Interface<'info, TokenInterface>,
    pub output_token_program: Interface<'info, TokenInterface>,

    pub input_token_mint:  InterfaceAccount<'info, Mint>,
    pub output_token_mint: InterfaceAccount<'info, Mint>,

    #[account(mut)]
    /// CHECK: кольцевой буфер
    pub observation_state: UncheckedAccount<'info>,

    pub cpmm_program: Program<'info, RaydiumCpSwap>,
}

pub fn proxy_swap_base_input(
    ctx: Context<ProxySwap>,
    amount_in: u64,
    minimum_amount_out: u64,
) -> Result<()> {
    let cpi_accounts = Swap {
        payer:                ctx.accounts.payer.to_account_info(),
        authority:            ctx.accounts.authority.to_account_info(),
        amm_config:           ctx.accounts.amm_config.to_account_info(),
        pool_state:           ctx.accounts.pool_state.to_account_info(),
        input_token_account:  ctx.accounts.input_token_account.to_account_info(),
        output_token_account: ctx.accounts.output_token_account.to_account_info(),
        input_vault:          ctx.accounts.input_vault.to_account_info(),
        output_vault:         ctx.accounts.output_vault.to_account_info(),
        input_token_program:  ctx.accounts.input_token_program.to_account_info(),
        output_token_program: ctx.accounts.output_token_program.to_account_info(),
        input_token_mint:     ctx.accounts.input_token_mint.to_account_info(),
        output_token_mint:    ctx.accounts.output_token_mint.to_account_info(),
        observation_state:    ctx.accounts.observation_state.to_account_info(),
    };
    // Anchor 1.0 принимает здесь Pubkey программы, а не её AccountInfo.
    let cpi_ctx = CpiContext::new(
        *ctx.accounts.cpmm_program.key,
        cpi_accounts,
    );
    cpi::swap_base_input(cpi_ctx, amount_in, minimum_amount_out)
}
```

Если ваш CPI подписывает как PDA (например, вы управляете хранилищем от имени вкладчиков), замените `CpiContext::new` на `CpiContext::new_with_signer` и передайте ваши seeds.

## Частые ошибки

Краткий контрольный список перед открытием тикета поддержки:

- **Отсортированные монеты.** Если ваш выведённый PDA `poolState` не совпадает с пулом в цепи, вы, вероятно, забыли отсортировать монеты.
- **Устаревшая котировка API.** Никогда не передавайте значение резерва из `api-v3.raydium.io` в `CurveCalculator.swap`. Загружайте из RPC.
- **Неправильная программа токенов.** Хранилище монеты Token-2022 принадлежит программе Token-2022, а не SPL Token. Всегда используйте поля `token_0_program` / `token_1_program` пула.
- **Проскальзывание недостаточно для монет с комиссией за передачу.** Если любая сторона пула — монета Token-2022 с комиссией за передачу, ваш `minimum_amount_out` должен быть выражен в том, что пользователь фактически получает, а не в том, что отправляет хранилище.
- **`NotApproved` при свопе.** Проверьте `PoolState.status` — администратор может приостановить свопы на этом пуле. См. [`products/cpmm/instructions`](/ru/products/cpmm/instructions) для маски статуса.
