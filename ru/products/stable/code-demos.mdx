  Модуль `liquidity` SDK нативно поддерживает пулы Stable AMM. Стабильные пулы отображаются как **`version: 5`** (или `pooltype: "StablePool"`) на `ApiV3PoolInfoStandardItem`; те же вспомогательные функции `addLiquidity` / `removeLiquidity` / swap работают для них, как и для пулов AMM v4 (`version: 4`) с постоянным произведением — SDK автоматически определяет вариант и генерирует правильные инструкции. Математика стабильной кривой находится в `src/raydium/liquidity/stable.ts`.
</Info>

## Настройка

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token
```

```ts
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import BN from "bn.js";
import bs58 from "bs58";

const connection = new Connection(clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(bs58.decode(process.env.PRIVATE_KEY!));

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });

// ОБЯЗАТЕЛЬНО перед любым расчётом цены для пула Stable. initLayout() загружает
// таблицу поиска ModelDataInfo из блокчейна в raydium.liquidity.stableLayout.
await raydium.liquidity.initLayout();
```

<Warning>
  **`initLayout()` не опционален для пулов Stable.** `liquidity.computeAmountOut` ветвится по `poolInfo.version`: для версии 4 используется формула постоянного произведения, а для всех остальных читается `this.stableLayout.stableModelData` и интерполируется таблица поиска. Этот кэш пуст до запуска `initLayout()`, поэтому расчёт цены для пула v5 без него даст мусор вместо ошибки. Функция идемпотентна и дешёва — вызовите её один раз при запуске.

  Построители транзакций (`swap`, `addLiquidity`, `removeLiquidity`) не нуждаются в ней: они ветвятся по `pooltype.includes("StablePool")` и генерируют инструкции `AmmV5*`, а переданные вами границы сумм уже вычислены.
</Warning>

<Warning>
  **`liquidity.computeAmountIn` не поддерживает пулы Stable.** В отличие от `computeAmountOut`, у неё нет ветвления по версии — она всегда применяет обратную формулу постоянного произведения, поэтому на пуле v5 возвращает неправильный `maxAmountIn`. Для своппа с фиксированным выходом на пуле Stable используйте `getDxByDyBaseIn` самостоятельно (см. [Вспомогательные функции для расчёта цены](#вспомогательные-функции-для-расчёта-цены-stablets) ниже) и передайте результат в `swap` с `fixedSide: "out"`.
</Warning>

## Определение пула Stable

Два эквивалентных сигнала на `ApiV3PoolInfoStandardItem`:

```ts
const isStable =
  pool.version === 5 ||
  pool.pooltype.includes("StablePool"); // SDK использует эту проверку строки внутри

// Альтернативно, по ID программы:
const STABLE_AMM_PROGRAM_ID = "5quBtoiQqxF9Jv6KYKctB59NT3gtJD2Y65kdnB1Uev3h";
const isStableByProgram = pool.programId === STABLE_AMM_PROGRAM_ID;
```

И AMM v4 (`version: 4`, постоянное произведение), и Stable AMM (`version: 5`) проходят через один и тот же API `LiquidityModule` на SDK. Внутри модуль ветвится на:

- `InstructionType.AmmV4AddLiquidity` / `AmmV4RemoveLiquidity` для пулов v4
- `InstructionType.AmmV5AddLiquidity` / `AmmV5RemoveLiquidity` для пулов v5 (Stable)

`programId` пула (возвращаемый с ключами пула) сообщает SDK, в какую программу выполнить CPI; вам не нужно жёстко кодировать его.

## Поиск пула по паре монет

```ts
import { PublicKey } from "@solana/web3.js";
import type { ApiV3PoolInfoStandardItem } from "@raydium-io/raydium-sdk-v2";

// Две распространённые монеты для примера
const mintA = new PublicKey("Es9vMFrzaCERmJfrF4H2FYD4KCoNkY11McCe8BenwNYB"); // USDT — см. reference/program-addresses
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// fetchPoolByMints возвращает конверт с пагинацией: { count, data, hasNextPage }
const res = await raydium.api.fetchPoolByMints({
  mint1: mintA.toBase58(),
  mint2: mintB.toBase58(),
});

const stablePool = res.data.find(
  (p) => p.version === 5 || p.pooltype.includes("StablePool"),
) as ApiV3PoolInfoStandardItem | undefined;

if (!stablePool) {
  throw new Error("Для этой пары монет не существует пула Stable");
}

console.log("ID пула Stable:", stablePool.id);
console.log("ID программы пула Stable:", stablePool.programId);
console.log("TVL:", stablePool.tvl);
```

Если пара монет имеет и пул v4 (постоянное произведение), и пул v5 (стабильный), ответ включает оба — выберите нужный для вашего потока или передайте оба программе [AMM Routing](/ru/products/routing) и позвольте ей выбрать лучший маршрут.

## Своп через пул Stable

Поток `LiquidityModule.swap` имеет ту же форму, что и для пулов v4 — просто передайте объект пула v5. Два момента легко упустить: `computeAmountOut` нуждается в **живых резервах** пула, привитых к информации пула (элемент API сам по себе их не содержит), и его `slippage` — это простое **число**, а не `Percent`:

```ts
import BN from "bn.js";

const amountIn = new BN(1_000_000); // 1 USDT (6 десятичных), в сыром виде

// Живые резервы и статус. На mainnet вы также можете взять poolKeys из
// getAmmPoolKeys(poolId) и резервы из getRpcPoolInfo(poolId).
const rpcData  = await raydium.liquidity.getRpcPoolInfo(stablePool.id);
const poolKeys = await raydium.liquidity.getAmmPoolKeys(stablePool.id);

const out = raydium.liquidity.computeAmountOut({
  poolInfo: {
    ...stablePool,
    baseReserve:  rpcData.baseReserve,
    quoteReserve: rpcData.quoteReserve,
    status:       rpcData.status.toNumber(),
    version:      5, // 5 = Stable; ветвление кривой выбирается по этому значению
  },
  amountIn,
  mintIn:  stablePool.mintA.address,
  mintOut: stablePool.mintB.address,
  slippage: 0.005, // простое число: 0.005 = 0.5% (диапазон 1 ~ 0.0001)
});

// amountOut / minAmountOut — это BN в сыром виде, не TokenAmount.
console.log("Ожидаемый выход:", out.amountOut.toString());
console.log("Минимальный выход:", out.minAmountOut.toString());

// Постройте и подпишите транзакцию своппа. `inputMint` обязателен — без него
// SDK не может определить, какую сторону пула вы продаёте.
const { transaction, execute } = await raydium.liquidity.swap({
  poolInfo:  stablePool,
  poolKeys,
  amountIn,
  amountOut: out.minAmountOut, // out.amountOut — это значение до применения slippage
  inputMint: stablePool.mintA.address,
  fixedSide: "in",
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Транзакция своппа Stable:", txId);
```

SDK читает `programId` пула из ключей пула и ветвится в программу Stable AMM. Никакой специальный аргумент `programId` не требуется.

## Добавление и удаление ликвидности

`addLiquidity` и `removeLiquidity` работают одинаково для пулов v4 и v5:

```ts
import { Percent, TokenAmount, toToken } from "@raydium-io/raydium-sdk-v2";
import Decimal from "decimal.js";

const inputAmount = "100"; // 100 USDT, в человеческих единицах — computePairAmount принимает строку decimal

// Вычислите соответствующую сумму B, которую требует кривая для этого размера A.
// Примечание: slippage computePairAmount — это Percent (в отличие от computeAmountOut).
const r = raydium.liquidity.computePairAmount({
  poolInfo: stablePool,
  amount:   inputAmount,
  baseIn:   true,
  slippage: new Percent(50, 10_000), // 0.5%
});

const { execute } = await raydium.liquidity.addLiquidity({
  poolInfo: stablePool,
  poolKeys,
  amountInA: new TokenAmount(
    toToken(stablePool.mintA),
    new Decimal(inputAmount).mul(10 ** stablePool.mintA.decimals).toFixed(0),
  ),
  amountInB: new TokenAmount(
    toToken(stablePool.mintB),
    new Decimal(r.maxAnotherAmount.toExact()).mul(10 ** stablePool.mintB.decimals).toFixed(0),
  ),
  otherAmountMin: r.minAnotherAmount,
  fixedSide:      "a",
  txVersion:      TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Транзакция добавления ликвидности:", txId);
```

Внутри SDK генерирует `InstructionType.AmmV5AddLiquidity`, потому что `pooltype.includes("StablePool")` истинно. Соответствующий поток `removeLiquidity` симметричен — передайте `lpAmount` и минимальные суммы, которые вы примете с каждой стороны.

## Вспомогательные функции для расчёта цены (stable.ts)

Для расчёта цены на сервере или бэктестирования SDK предоставляет базовую математику стабильной кривой:

```ts
import {
  getStablePrice,
  getDxByDyBaseIn,
  getDyByDxBaseIn,
} from "@raydium-io/raydium-sdk-v2";

// Вы должны вызвать initLayout() один раз перед использованием этих функций
// (загружает PDA `ModelDataInfo` из блокчейна в кэш StableLayout SDK).
await raydium.liquidity.initLayout();

// initLayout() заполняет экземпляр StableLayout; простой объект данных, который
// три вспомогательные функции ниже ожидают, — это его getter `stableModelData`, НЕ сам экземпляр.
const modelData = raydium.liquidity.stableLayout.stableModelData;

// Резервы передаются как простые числа в человеческих единицах (не BN, не в сыром виде).
const coinReserve = 1_200_000; // резерв пула на стороне coin
const pcReserve   = 1_150_000; // резерв пула на стороне pc

// Спотовая цена при текущих резервах пула. 4-й аргумент — `baseCoin`:
// true возвращает coin-per-pc, false возвращает обратное.
const price = getStablePrice(modelData, coinReserve, pcReserve, true);
console.log("Спотовая цена:", price);

// Расчёт: дано dx на входе, сколько dy на выходе (без комиссии)?
const dyOut = getDyByDxBaseIn(modelData, coinReserve, pcReserve, 1_000);

// Расчёт: дана цель dy на выходе, сколько dx на входе требуется?
const dxIn  = getDxByDyBaseIn(modelData, coinReserve, pcReserve, 1_000);
```

Это чистые функции — без RPC, без подписей. `ModelDataInfo` из блокчейна загружается один раз `initLayout()` и кэшируется внутри `raydium.liquidity.stableLayout`, доступный как `.stableModelData`. `initStableModelLayout()` идемпотентна: она повторно загружает только пока `validDataCount === 0`, поэтому повторный вызов `initLayout()` бесплатен. Передайте текущие резервы (`x`, `y`) и вспомогательные функции вычислят путём двоичного поиска в таблице поиска и линейной интерполяции между двумя окружающими строками `DataElement`. См. [`products/stable/math`](/ru/products/stable/math) для базового алгоритма.

## Маршрутизация через AMM Routing (многоскачковые / лучшая цена)

Если вы не хотите выбирать площадку самостоятельно, программа [AMM Routing](/ru/products/routing) рассмотрит каждый Raydium AMM (v4 / CPMM / CLMM / Stable) и маршрутизирует через любую комбинацию, которая лучше всего:

Маршрутизатор — это пятивызовный конвейер, а не один `swap()`, и он полностью написан — с советом по кэшированию, который делает его пригодным для использования в production — на [`products/routing/code-demos`](/ru/products/routing/code-demos). Форма такова:

```ts
import { Router } from "@raydium-io/raydium-sdk-v2";

const poolData = await raydium.tradeV2.fetchRoutePoolBasicInfo(); // кэшируйте это
const routes   = raydium.tradeV2.getAllRoute({ inputMint: mintA, outputMint: mintB, ...poolData });
const ctx      = await raydium.tradeV2.fetchSwapRoutesData({ routes, inputMint: mintA, outputMint: mintB });
const quotes   = raydium.tradeV2.getAllRouteComputeAmountOut({ /* ...ctx, amount, slippage, ... */ });

const best = quotes[0]; // отсортировано лучшее первым
if (!best) throw new Error("маршруты своппа не найдены");

// Записи best.poolInfoList содержат `version` — 5 обозначает пул Stable в пути.
console.log(best.routeType, best.poolInfoList.map((p) => p.version));

const poolKeys = await raydium.tradeV2.computePoolToPoolKeys({
  pools: best.poolInfoList,
  ammRpcData:  ctx.ammPoolsRpcInfo,
  clmmRpcData: ctx.clmmPoolsRpcInfo,
});

const { execute } = await raydium.tradeV2.swap({
  routeProgram: Router,
  swapInfo:     best,
  swapPoolKeys: poolKeys,
  ownerInfo:    { associatedOnly: true, checkCreateATAOwner: true },
  txVersion:    TxVersion.V0,
});

// tradeV2.swap может вернуть несколько транзакций; первая создаёт промежуточные ATA.
const { txIds } = await execute({ sequentially: true });
```

<Warning>
  Нет `raydium.tradeV2.fetchRoutes`, и `tradeV2.swap` **не** принимает `inputMint` / `outputMint` / `slippage` — он принимает уже вычисленный `swapInfo` из `getAllRouteComputeAmountOut`. Для **одного** известного пула используйте построитель этого типа пула (`raydium.liquidity.swap` для AMM v4 и Stable, `raydium.cpmm.swap`, `raydium.clmm.swap`), как показано ранее на этой странице.
</Warning>

Это рекомендуемый путь для production-свопперов и агрегаторов — вам никогда не нужно вручную решать, существует ли пул Stable или является ли он лучшей площадкой сегодня.

## Рекомендации

1. **Для свопов конечных пользователей** предпочитайте поток маршрутизации [`tradeV2`](/ru/products/routing). Он обрабатывает каждый тип пула Raydium, включая Stable.
2. **Для операций, специфичных для пула** (добавление / удаление LP на известном пуле Stable), используйте `LiquidityModule` напрямую — он автоматически определяет пулы v5.
3. **Для расчёта цены на сервере / аналитики** вызовите `getStablePrice` / `getDyByDxBaseIn` / `getDxByDyBaseIn` после `initLayout()`. Никакого трафика RPC за расчёт после кэширования данных модели.
4. **Не кодируйте вручную сыр инструкции `SwapBaseIn`.** [Обновление от 2026-06-22](/ru/reference/changelog) удалило мёртвые счета OpenBook, поэтому новая раскладка своппа принимает **9 счётов** (старая раскладка из 18 счётов всё ещё парсится для обратной совместимости). `Deposit` теперь 12 счётов (старые 14 совместимы), `Withdraw` 12 (старые 21/22 совместимы), и `WithdrawPnl` 10 **без** пути совместимости. Предварительно построенные вспомогательные функции SDK выбирают правильную раскладку и порядок для вас; самостоятельное написание подвержено ошибкам. См. [`products/stable/instructions`](/ru/products/stable/instructions) для полных таблиц счётов.
