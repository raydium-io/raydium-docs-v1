## Что это такое

AMM v4 — это первое поколение пулов Raydium. Он поддерживает инвариант constant-product (xy=k). Пул был изначально разработан как **гибридный AMM**: помимо кривой, он размещал сетку лимитных ордеров с интервалом Фибоначчи на связанном маркете OpenBook, чтобы ликвидность пула была видна для участников orderbook. **Эта интеграция с OpenBook была удалена из программы** (см. предупреждение выше); сегодня AMM v4 — это чистый constant-product AMM. On-chain аккаунты `AmmInfo` сохраняют свои поля ссылок `market` / `open_orders` для совместимости макета, но программа больше их не читает и не использует.

Это по-прежнему продукт с наибольшей ликвидностью на Raydium для многих унаследованных пар, но **больше не рекомендуется для новых пулов** — см. [CPMM](/ru/products/cpmm) для новых развертываний.

**Program ID:** см. [reference/program-addresses](/ru/reference/program-addresses).

**Token-2022:** не поддерживается. Пулы AMM v4 принимают только классические SPL токены.
