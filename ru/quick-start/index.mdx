## Предварительные требования

Выполните один раз:

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

Вам потребуется:

- **Node 18+** с поддержкой ESM (`"type": "module"` в `package.json` или расширение `.mjs`).
- **Keypair Solana** в `~/.config/solana/id.json` (или в другом месте — установите `KEYPAIR`). Инструкции по генерации см. в [`solana-fundamentals/toolchain`](/ru/solana-fundamentals/toolchain#solana-cli).
- **Финансируемый кошелек.** Скрипт свопа требует только сумму входа плюс небольшой запас — CPMM своп стоит ~0.0015 SOL в сетевых комиссиях (см. [`reference/fee-comparison`](/ru/reference/fee-comparison#network-fees-per-typical-operation)), плюс одноразовая комиссия за аренду, если своп должен открыть для вас аккаунт токена. Создание пула дороже: скрипт CPMM имеет одноразовую комиссию за создание пула ~0.15 SOL перед начальной ликвидностью или арендой. Перед финансированием кошелька см. раздел Setup каждого скрипта для актуальной суммы.
- **URL RPC.** Бесплатный публичный RPC подходит для тестирования; для чего-либо более серьёзного используйте платного провайдера.

Установите один раз для сеанса:

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **Кластер.** Все три скрипта по умолчанию используют mainnet. Для devnet требуется `RPC_URL=https://api.devnet.solana.com` плюс `cluster: "devnet"` внутри скрипта — для двух скриптов создания пула это не единственное изменение; см. раздел Setup каждого скрипта для полного списка. Учтите, что начальная ликвидность пула на devnet ограничена; будьте готовы создавать собственные тестовые токены.
</Info>

## После этой главы

Каждый скрипт выводит результат на блокчейне — котировку свопа и ссылку на транзакцию, адреса новых пулов или новую позицию и её NFT — и одну строку, указывающую на следующую страницу в главе [SDK & API](/ru/sdk-api) для выполненной операции. Когда вы будете готовы написать собственную интеграцию:

- **Бэкенды и боты** → [Trade API](/ru/sdk-api/trade-api).
- **Фронтенды и приложения с полным контролем** → [TypeScript SDK](/ru/sdk-api/typescript-sdk).
- **Композиция на блокчейне** → [Rust CPI](/ru/sdk-api/rust-cpi).
- **Выбор между ними** → таблица сравнения в начале [SDK & API](/ru/sdk-api).
