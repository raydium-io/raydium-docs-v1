## Подготовка

Убедитесь, что вы прочитали [Предварительные требования быстрого старта](/ru/quick-start) и у вас установлены `RPC_URL`, `KEYPAIR` и необходимые зависимости.

Также необходимо **пополнить кошелек начальными суммами обеих монет**, плюс достаточно SOL для покрытия единовременной комиссии за создание пула и аренды аккаунта (~0,19 SOL всего на mainnet — см. [`reference/fee-comparison`](/ru/reference/fee-comparison#creation-costs) для разбивки аренды/комиссии или [`ray/protocol-fees`](/ru/ray/protocol-fees#pool-creation-fees) только для комиссии).

**Запуск на devnet.** Просто переключение `cluster` на `"devnet"` недостаточно. Этот скрипт использует два именованных импорта, которые не следуют за `cluster`: `programId: CREATE_CPMM_POOL_PROGRAM` и `poolFeeAccount: CREATE_CPMM_POOL_FEE_ACC`, оба константы mainnet. Импортируйте `DEVNET_PROGRAM_ID` из SDK и используйте вместо них `DEVNET_PROGRAM_ID.CREATE_CPMM_POOL_PROGRAM` и `DEVNET_PROGRAM_ID.CREATE_CPMM_POOL_FEE_ACC` — тот же паттерн, что использует [скрипт CLMM](/ru/quick-start/deploy-clmm-pool).

## Скрипт

Сохраните как `create-cpmm.mjs`:

```ts create-cpmm.mjs icon="js"
import { Connection, Keypair, PublicKey } from "@solana/web3.js";
import {
  Raydium,
  TxVersion,
  CREATE_CPMM_POOL_PROGRAM,
  CREATE_CPMM_POOL_FEE_ACC,
} from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

// ── Config from env ──────────────────────────────────────────────
const RPC_URL  = process.env.RPC_URL  ?? "https://api.mainnet-beta.solana.com";
const KEYPAIR  = process.env.KEYPAIR  ?? `${process.env.HOME}/.config/solana/id.json`;
const MINT_A   = process.env.MINT_A;   // required, base58
const MINT_B   = process.env.MINT_B;   // required, base58
const AMOUNT_A = process.env.AMOUNT_A; // required, integer raw units
const AMOUNT_B = process.env.AMOUNT_B; // required, integer raw units

if (!MINT_A || !MINT_B || !AMOUNT_A || !AMOUNT_B) {
  console.error("Set MINT_A, MINT_B, AMOUNT_A, AMOUNT_B env vars.");
  process.exit(1);
}

// ── Setup ────────────────────────────────────────────────────────
const connection = new Connection(RPC_URL, "confirmed");
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(KEYPAIR, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});

// ── Pick the 0.25% fee tier ─────────────────────────────────────
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0);
if (!feeConfig) throw new Error("0.25% fee tier not found in CPMM configs.");

// ── Resolve mint metadata (Token-2022-aware) ────────────────────
const mintA = await raydium.token.getTokenInfo(new PublicKey(MINT_A));
const mintB = await raydium.token.getTokenInfo(new PublicKey(MINT_B));

// ── Build and execute ───────────────────────────────────────────
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA,
  mintB,
  mintAAmount:     new BN(AMOUNT_A),
  mintBAmount:     new BN(AMOUNT_B),
  startTime:       new BN(0), // open immediately
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
  computeBudgetConfig: {
    units: 600_000,
    microLamports: 100_000,
  },
});

const { txId } = await execute({ sendAndConfirm: true });

console.log(`Pool ID:  ${extInfo.address.poolId.toBase58()}`);
console.log(`LP mint:  ${extInfo.address.lpMint.toBase58()}`);
console.log(`Vault A:  ${extInfo.address.vaultA.toBase58()}`);
console.log(`Vault B:  ${extInfo.address.vaultB.toBase58()}`);
console.log(`Tx:       https://solscan.io/tx/${txId}`);
```

## Запуск

Пример: создание пула SOL/USDC с начальной суммой 1 SOL и 160 USDC:

```bash icon="terminal"
export MINT_A="So11111111111111111111111111111111111111112"   # wSOL
export MINT_B="EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"   # USDC
export AMOUNT_A="1000000000"   # 1 SOL (9 decimals)
export AMOUNT_B="160000000"    # 160 USDC (6 decimals)

node create-cpmm.mjs
```

Ожидаемый результат:

```text
Pool ID:  HgC5...3kXb
LP mint:  4ZAS...9rkV
Vault A:  J9Mu...mP2k
Vault B:  AaJq...8wxx
Tx:       https://solscan.io/tx/5dQ...
```

## Что произошло

1. **`getCpmmConfigs`** получила актуальный список уровней комиссий с `api-v3.raydium.io` и выбрала индекс 0 (уровень 0,25% — см. [`reference/fee-comparison`](/ru/reference/fee-comparison) для полного набора).
2. **`getTokenInfo`** разрешила метаданные каждой монеты, включая то, какая программа токенов ею владеет. CPMM принимает как SPL Token, так и Token-2022 монеты; SDK маршрутизирует автоматически.
3. **`createPool`** построила одну транзакцию, которая:
   - сортирует монеты в каноническом порядке,
   - выводит PDA пула, хранилища, LP монету и полномочия,
   - платит единовременную `create_pool_fee` на `CREATE_CPMM_POOL_FEE_ACC`,
   - создает ATA вызывающей стороны, если они отсутствуют,
   - инициализирует хранилища с `AMOUNT_A` и `AMOUNT_B`.
4. **Начальная цена** устанавливается по соотношению начальных сумм: `price = AMOUNT_B / AMOUNT_A` после корректировки десятичных знаков. Выбирайте это тщательно — боты будут арбитражировать любое неправильное ценообразование в течение секунд после открытия пула.
5. **`startTime: new BN(0)`** открывает торговлю немедленно. Чтобы подготовить ликвидность перед открытием для публики, установите будущую временную метку Unix.

## Частые ошибки

- **`pool already exists`** — Пул уже существует для этой пары монет на этом уровне комиссии. Проверьте перед созданием.
- **`insufficient funds`** — Ваш кошелек не имеет достаточно `MINT_A`, `MINT_B` или SOL (для комиссии создания пула + аренды).
- **`Token-2022 extension not supported`** — Одна из ваших монет использует расширение, которое CPMM не поддерживает. См. [`reference/token-2022-support`](/ru/reference/token-2022-support).

## После развертывания

Вы можете сразу же совершать обмены в новом пуле — скрипт [Swap from CLI](/ru/quick-start/swap-from-cli) принимает ваш новый `POOL_ID` напрямую. Агрегаторы (Jupiter и т. д.) индексируют новый пул в течение нескольких минут.
