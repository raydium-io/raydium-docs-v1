## Что такое Burn & Earn

Burn & Earn — это функция Raydium, которая позволяет создателю пула (или любому LP) сделать депозит **постоянным** в блокчейне, сохраняя право на получение комиссий за торговлю. Позиция становится невозвратной, но вновь отчеканенный **Raydium Fee Key** NFT представляет постоянное право на `collectFees` из этой заблокированной позиции.

Типичные варианты использования:

- **Доверие при запуске.** Проекты обязуются не делать rug-pull, блокируя LP развёртывающего. Держатели могут проверить в блокчейне, что ликвидность постоянна.
- **Коллекционный предмет, приносящий доход.** Передаваемый NFT, который генерирует доход. Продайте NFT; передайте поток комиссий.
- **LP уровня казначейства.** Протоколы, которые хотят сохранить ликвидность навсегда для целей бренда / обнаружения, при этом монетизируя сторону комиссий.

## Поддерживаемые типы пулов

| Программа | Поддержка Burn & Earn |
|---|---|
| CPMM | Да |
| CLMM | **Только полный диапазон** (рекомендуется) |
| AMM v4 (Hybrid) | Не поддерживается |

Для CLMM следует блокировать только позиции, охватывающие полный диапазон цен. После блокировки вы не можете перебалансировать — если цена выходит за пределы выбранного диапазона, вы навсегда перестаёте получать комиссии по этой позиции. Заблокированная позиция Burn & Earn с узким диапазоном почти всегда ошибка.

## Как работает блокировка на уровне программы

1. Исходный LP-токен (CPMM) или NFT позиции (CLMM) передаётся в программный PDA, принадлежащий программе Burn & Earn.
2. **Fee Key NFT** отчеканивается вызывающему. Его метаданные указывают на PDA заблокированной позиции.
3. Burn & Earn предоставляет `collectFees` (или эквивалентный вызов для каждого типа пула), который:
   - Проверяет, что подписант владеет Fee Key NFT для данной заблокированной позиции.
   - Вызывает инструкцию получения комиссий базовой программы пула через CPI.
   - Маршрутизирует собранные комиссии на ATA держателя Fee Key.
4. Нет соответствующего `withdraw` — базовый LP / позиция никогда не выходит из escrow.

Fee Key — это стандартный SPL NFT. Он может быть продан на любом Solana NFT маркетплейсе, перемещён между кошельками, использован как залог на протоколах кредитования, принимающих NFT, или обёрнут в другой контракт. Тот, кто владеет им во время вызова `collectFees`, получает комиссии.

## Пошаговое руководство по интерфейсу

1. Создайте пул CPMM или пул CLMM с позицией полного диапазона обычным способом.
2. Перейдите в **Liquidity → Create → Burn & Earn**.
3. Выберите позицию для блокировки.
4. Проверьте детали позиции (адрес NFT, размер, пул) и введите предложение подтверждения, которое показывает интерфейс. Это намеренно создаёт трение, потому что операция необратима.
5. Нажмите **Confirm, lock the liquidity permanently** (Подтвердить, заблокировать ликвидность навсегда).
6. Fee Key NFT поступает в ваш кошелёк. Он появляется на странице Portfolio в разделе заблокированных позиций.

Получайте комиссии так же, как вы получаете их из любой позиции — через страницу Portfolio или через `collectFees`.

## API поверхность

Endpoint информации о пуле возвращает поле `burnPercent`, указывающее долю ликвидности пула, которая была заблокирована через Burn & Earn:

```http
GET https://api-v3.raydium.io/pools/info/list
  ?poolType=standard
  &poolSortField=default
  &sortType=desc
  &pageSize=1
  &page=1
```

```json
{
  "data": [
    {
      "id": "...",
      "burnPercent": 99.17,
      ...
    }
  ]
}
```

`burnPercent` — удобный способ сигнализировать о доверии: токен, чья LP на 99%+ заблокирована, намного менее подвержен rug-pull, чем токен с 0% заблокированной LP.

## Подводные камни

- **Необратимо.** Сторона LP никогда не может быть восстановлена. Подтвердите, что сумма — это то, к чему вы готовы никогда больше не прикасаться.
- **CLMM узкие диапазоны — ловушка.** Блокируйте только позиции CLMM полного диапазона, если вы действительно не понимаете, что заблокированная позиция с ограниченным диапазоном перестаёт приносить доход, когда цена выходит за пределы полосы.
- **Потеря Fee Key NFT — потеря комиссий навсегда.** Относитесь к нему как к документу о праве собственности. Не сжигайте его случайно; не ставьте его в враждебный контракт.
- **Минты Token-2022 с комиссиями за передачу**: Burn & Earn их поддерживает, но комиссия за передачу применяется при каждом получении комиссии — учтите это в бюджете.
- **Нет частичной блокировки.** Если вы хотите 50% заблокировано и 50% подвижно, сначала разделите позицию на две позиции, затем заблокируйте только одну.

## LaunchLab использует Burn & Earn под капотом

Токены, выпущенные из [LaunchLab](/ru/products/launchlab), используют LP-Lock для заблокированной LP. До обновления 2026-08-14 `creatorScale` создавал Fee Key, принадлежащий создателю. Миграции, выполненные после этого, объединяют `platformScale + creatorScale` в одну позицию Fee Key платформы и сжигают `burnScale`. Fee Keys из более ранних завершённых миграций остаются неизменными. См. [`products/launchlab/platforms`](/ru/products/launchlab/platforms) и [`products/launchlab/creator-fees`](/ru/products/launchlab/creator-fees).
