## Фаза 1: комиссии создателя на кривой связывания

Пока ваш токен торгуется на кривой связывания, платформа может взимать компонент комиссии создателя при покупках и продажах.

- Она начисляется в котировочном токене, обычно SOL.
- Платформа устанавливает ставку.
- Вы можете получить её через поток получения комиссии создателя LaunchLab.
- Выпуск останавливает новое начисление на кривой связывания. Любой существующий баланс остаётся доступным для получения.

## Фаза 2: комиссии создателя CPMM

Каждый новый выпуск переходит в CPMM. Комиссии создателя CPMM начисляются только если выбранный `AmmConfig` имеет ненулевую ставку комиссии создателя.

По умолчанию создатель выпуска становится создателем пула CPMM. Платформа может вместо этого установить `platform_cp_creator`, в этом случае этот адрес получает права на комиссию создателя CPMM.

Записанный создатель CPMM может получить комиссию напрямую. Другой плательщик также может инициировать сбор без разрешения, но CPMM фиксирует направления на канонические токен-счета создателя.

## Что происходит с LP-токенами

Конфигурация платформы хранит `platformScale`, `creatorScale` и `burnScale`. До обновления 2026-08-17 `creatorScale` создавал Fee Key, принадлежащий создателю. Для миграций, выполненных после обновления, LaunchLab объединяет его с `platformScale`:

```text
platform locked LP = platformScale + creatorScale
burned LP          = burnScale
```

Если заблокированная доля ненулевая, один NFT Fee Key переходит в настроенный кошелёк NFT платформы. Этот NFT контролирует сбор LP-комиссий. Он не контролирует сбор комиссии создателя CPMM. Fee Keys создателя из миграций, завершённых до обновления, остаются у своих текущих владельцев.

## Сводка потока комиссий

```text
Кривая связывания
  комиссия создателя → хранилище создателя выпуска

Выпуск в CPMM
  До обновления → Fee Key платформы + Fee Key создателя + сожженная доля
  После обновления  → объединённая доля Fee Key платформы + сожженная доля

Торговля CPMM
  комиссия создателя → записанный создатель пула CPMM
  комиссия LP      → владелец Fee Key платформы для заблокированной доли
```

## Перед запуском

- Проверьте `creator_fee_rate` кривой связывания.
- Проверьте, заменяет ли вас `platform_cp_creator` как создателя пула CPMM.
- Для миграций, выполненных после обновления, не рассматривайте `creatorScale` как гарантированное распределение Fee Key создателя. Для более ранних миграций проверьте существующую запись Fee Key.
- Проверьте ставку комиссии создателя конфигурации CPMM и параметр fee-on.
