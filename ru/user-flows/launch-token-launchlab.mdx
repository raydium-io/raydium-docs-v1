<Info>
  LaunchLab — основная площадка для запуска токенов на Raydium. Проект вносит свой токен в кривую связи; покупатели торгуют против кривой, используя SOL (или другой котирующий токен); когда достигается порог выпуска, активы кривой автоматически переходят в CPMM пул, и токен становится свободно торгуемым. На этой странице описан весь процесс со стороны проекта.
</Info>

## Что вам нужно

- **Минт токена** — токен, который вы хотите продать. Должен быть только что выпущен с:
  - Полным предложением, выпущенным на ваш кошелек (чтобы вы могли внести его в кривую).
  - Отозванным правом на выпуск перед запуском (иначе цена кривой может быть манипулирована новыми выпусками).
- **Метаданные** — имя, символ, изображение, ссылки на социальные сети. Метаданные Metaplex или аналогичные.
- **Кошелек** — ~1 SOL для создания хранилища + финансирования хранилища + комиссий приоритета (сам выпуск оплачивается выпускающей стороной, а не вами).
- **Решение по**:
  - Типу кривой (квадратичная vs виртуальные резервы CPMM).
  - Порогу выпуска.
  - Политике распределения LP (Burn / Lock / ToCreator).
  - Начальной цене и лимиту.

## Выбор кривой

LaunchLab поддерживает два семейства кривых:

### Квадратичная (`curve_type = 0`)

Цена растет квадратично с проданным предложением. Классический вид «честного запуска» — ранние покупатели получают преимущество в цене, поздние платят больше, цена растет плавно.

```
price(s) = a * s^2 + b * s + c
```

где `s` — проданное предложение. Обычно `a > 0` (выпуклая). Разница между начальной и финальной ценой детерминирована при заданных `a, b, c` и лимите.

Лучше всего для: новых запусков, мемов, проектов, управляемых сообществом.

### Виртуальные резервы CPMM (`curve_type = 1`)

Эмулирует постоянный продукт AMM, используя *виртуальные* резервы — кривая ведет себя как CPMM с `x * y = k`, но пул начинается с синтетических токенов, которые никогда не выводятся.

```
price = virtual_quote_reserve / virtual_base_reserve
```

По мере покупок `virtual_base_reserve` уменьшается, а `virtual_quote_reserve` увеличивается — кривая выглядит идентично тому, как будет выглядеть CPMM после выпуска. Более плавный переход.

Лучше всего для: запусков, которые хотят предсказуемой непрерывности цены после выпуска.

## Пошаговое руководство по интерфейсу

На [raydium.io/launchpad/create](https://raydium.io/launchpad/create):

1. **Токен.** Вставьте адрес минта. Интерфейс загружает метаданные и отображает их.
2. **Тип кривой.** Выберите квадратичную или виртуальную CPMM; интерфейс показывает предпросмотр графика цены для каждой.
3. **Порог выпуска.** По умолчанию: кривая заканчивается после продажи всего `total_base_supply`. Альтернатива: завершить при определенном `graduation_quote_amount` (например, 85 SOL).
4. **Котирующий минт.** SOL (по умолчанию), USDC или любой другой минт. SOL — стандарт.
5. **Политика распределения LP:**
   - **Burn** — LP токены отправляются на неиспользуемый адрес при выпуске. Создатель не может вывести ликвидность; пользователи доверяют пулу навсегда.
   - **Lock** — LP токены отправляются в заблокированное по времени хранилище на `lock_duration`.
   - **ToCreator** — LP токены отправляются создателю. Наиболее гибко, наименее минимизирует доверие.

   Наиболее уважаемые запуски используют Burn.

6. **Проверка.** Интерфейс суммирует: ожидаемый диапазон цен, начальный сбор, если кривая распродана, конфигурация CPMM при выпуске.
7. **Подпись.** Одна транзакция создает состояние запуска + базовое хранилище + котирующее хранилище, передает `total_base_supply` из вашего кошелька в базовое хранилище.

## Программный пошаговый процесс

Форма кривой, котирующий минт, целевой сбор и политика распределения LP — это **не** аргументы — они поступают из `GlobalConfig`, к которому вы привязываетесь, и из `PlatformConfig`, под которым работает ваш запуск. Что вы передаете — это идентификатор минта, конфигурация для привязки и опционально первая покупка:

```ts
import {
  Raydium,
  TxVersion,
  LAUNCHPAD_PROGRAM,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";
import BN from "bn.js";

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });
const programId = LAUNCHPAD_PROGRAM;

// Вы генерируете пару ключей базового минта и подписываете ею.
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// Привяжите конфигурацию: (котирующий минт, curve_type, индекс). Это фиксирует форму кривой,
// котирующий минт и целевой сбор.
const configId   = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
const configInfo = LaunchpadConfig.decode(configData!.data);
const mintBInfo  = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "My New Token",
  symbol: "MYNEW",                    // 10 символов или меньше
  uri:    "https://example.com/metadata.json",
  migrateType: "amm",                 // "amm" | "cpmm"

  configId,
  configInfo,
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  createOnly: true,                   // true = создать минт без первой покупки
  buyAmount:  new BN(1000),
  slippage:   new BN(100),            // 100 = 1%

  extraSigners: [pair],               // пара ключей базового минта должна подписать
  txVersion: TxVersion.V0,
  computeBudgetConfig: { units: 400_000, microLamports: 50_000 },
});

// createLaunchpad возвращает несколько транзакций - запустите их по порядку.
const { txIds } = await execute({ sequentially: true });
console.log("Pool ID:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
```

`raydium.api.fetchLaunchConfigs()` перечисляет доступные конфигурации с их предложением по умолчанию, суммой продажи и целевым сбором, чтобы вы могли показать пользователю, что подразумевает данная конфигурация перед подписью. Полная аннотированная версия, включая вариант Token-2022: [`products/launchlab/code-demos`](/ru/products/launchlab/code-demos#create-a-launch).

## Мониторинг перед выпуском

Отслеживайте активность через API:

LaunchLab имеет собственные хосты API, отдельные от `api-v3.raydium.io`:

```ts
// Информация на уровне минта, ключ — базовый минт (разделенные запятыми для пакета).
const r = await fetch(
  `https://launch-mint-v1.raydium.io/get/by/mints?ids=${mintA.toBase58()}`,
).then((r) => r.json());
console.log(r.data.rows[0]);

// Также доступны: /main/configs (список конфигураций) на том же хосте и
// https://launch-history-v1.raydium.io/kline и /trade для цены и сделок.
```

Или читайте состояние в цепи напрямую. ID пула — это PDA от `(programId, mintA, mintB)`:

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log({
  status:      poolInfo.status,
  baseSold:    poolInfo.realA.toString(),
  totalSellA:  poolInfo.totalSellA.toString(),
  quoteRaised: poolInfo.realB.toString(),
  raiseTarget: poolInfo.totalFundRaisingB.toString(),
});
```

Прогресс лучше всего выражается в **ценовых** терминах, а не как доля сбора, потому что кривая нелинейна. Репозиторий демонстрации [`getFinishRate.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/getFinishRate.ts) делает это с помощью `Curve.getPrice`, `Curve.getPoolEndPriceReal` и `Curve.getPoolInitPriceByPool`:

```
finishRate = (currentPrice − initPrice) / (endPrice − initPrice)   // ограничено до 1
```

### Метрики для отслеживания

- **Процент продаж**: процент проданного базового токена. Порог выпуска обычно составляет 80–100% продано.
- **Текущая цена**: получена из кривой при текущем `baseSold`.
- **Уникальные покупатели**: количество различных плательщиков через индексер.
- **Соотношение покупок к продажам**: ранние запуски видят сильное давление покупок, которое замедляется.

Если процент продаж `<10%` через 24 часа, рассмотрите, достаточен ли маркетинг. LaunchLab не спасает недостаточно раскрученные запуски.

## Выпуск

Выпуск — это отдельная транзакция, и она **не** может быть вызвана кем-либо: `MigrateToCpswap` и устаревший `MigrateToAmm` требуют, чтобы их подписант совпадал с кошельком, записанным на привязке `GlobalConfig` (`migrate_to_cpswap_wallet` / `migrate_to_amm_wallet`), и любой другой подписант получает `InvalidOwner`. Нет награды. Эти кошельки управляются кранком выпуска Raydium, который выполняет миграцию в течение секунд после пересечения порога. Никаких действий не требуется от вас как создателя, кроме начальной настройки.

### Что делает выпуск

1. Читает балансы хранилищ.
2. Закрывает кривую (больше нет покупок/продаж против нее).
3. Создает новый CPMM пул с балансами хранилищ как начальная ликвидность.
4. Выпускает начальные LP токены на основе балансов хранилищ.
5. Распределяет LP токены согласно настроенной политике (Burn / Lock / ToCreator).

После выпуска CPMM пул работает и торгуется через обычную маршрутизацию Raydium.

### Мониторинг выпуска

Следите за `status` в состоянии пула и переключайте ваш интерфейс, когда он изменяется:

```ts
const before = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

setInterval(async () => {
  const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
  if (p.status !== before) console.log("migrated - switch to the CPMM pool page");
}, 10_000);
```

Адрес выпущенного пула — это CPMM PDA для `(cpswap config, token0, token1)`, поэтому вы можете вывести его, а не ждать, пока он будет сообщен. Для индексера подпишитесь через gRPC вместо опроса — см. [`products/launchlab/code-demos`](/ru/products/launchlab/code-demos#watch-configs-and-pools-over-grpc).

Нет пути «ручного выпуска» для создателя или третьей стороны. Если запуск пересек свой порог и не был перенесен, это операционный вопрос для кошелька миграции, а не что-то, что вы можете заставить с клиента.

## После выпуска

### Проверьте CPMM пул

```ts
const pool = await raydium.cpmm.getPoolInfoFromRpc({ poolId: cpmmPoolId });
console.log("CPMM price:", pool.poolInfo.price);
console.log("CPMM TVL:  ", pool.poolInfo.tvl);
```

CPMM пул должен иметь (приблизительно):

- Баланс базового токена: `total_base_supply - baseSold` + остаток кривой.
- Баланс котирующего токена: `quoteRaised - graduationFee`.
- Цена: совпадает с последней ценой кривой.

### Проверьте распределение LP

- **Burn**: предложение LP минта показывает отправку на 1nc1nerator11111111111111111111111111111111 или аналогичный.
- **Lock**: LP токены в PDA хранилища с временной меткой разблокировки.
- **ToCreator**: LP токены в кошельке создателя.

### Собирайте комиссии создателя

Если вы настроили долю комиссии создателя, вызывайте периодически:

Построитель — это `claimCreatorFee`, и он ключевой по **котирующему минту**, а не по запуску — один вызов собирает вашу накопленную комиссию создателя в этом минте:

```ts
import { NATIVE_MINT } from "@solana/spl-token";

await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,      // котирующий минт для сбора
  txVersion: TxVersion.V0,
});
```

Используйте `claimMultipleCreatorFee` для пакетной обработки по минтам. Комиссии накапливаются от торговли кривой перед выпуском и после выпуска из пути комиссии создателя CPMM пула, когда `platform_cp_creator` платформы оставляет вас как записанного создателя пула — см. [`products/launchlab/platform-config`](/ru/products/launchlab/platform-config).

## Контрольный список объявления

Объявление после выпуска должно включать:

- [ ] Хеш транзакции выпуска.
- [ ] Новый ID CPMM пула.
- [ ] Доказательство распределения LP (tx сжигания / tx блокировки / кошелек создателя).
- [ ] ETA покрытия агрегатором (кошельки обычно индексируют в течение 5 минут).
- [ ] Проверка контракта токена (совпадение адреса минта по каналам объявления).

## Подводные камни

### 1. Право на выпуск не отозвано

Если `baseMint.mintAuthority` все еще является ключом, который вы контролируете, вы можете выпустить новое предложение и продать его в свою собственную кривую. Запуски, которые не отозвали, обычно помечаются как высокий риск или непроверенные агрегаторами и сайтами листинга. Отзовите перед запуском.

### 2. Неправильные параметры кривой

Квадратичные кривые с слишком высоким `a` делают ранние токены бесплатными (цена ≈ 0) и поздние токены абсурдными. Кривые с слишком низким `a` делают кривую почти линейной (теряют «связывающее» ощущение). Сначала протестируйте параметры на devnet.

### 3. Порог выпуска слишком высок

Если выпуск требует больше капитала, чем реалистичный спрос, кривая никогда не выпускается и покупатели застревают с токенами, которые они могут продать только обратно кривой (по худшим ценам). Выберите порог, который вы действительно можете достичь.

### 4. Мошенничество с котирующим минтом

Если ваш котирующий минт — это пользовательский токен (не SOL/USDC), пользователи ему не будут доверять. Придерживайтесь SOL или USDC для котировки.

### 5. Забыли финансировать базовое хранилище

SDK передает `totalBaseSupply` из вашего кошелька при создании. Если в вашем кошельке его нет, транзакция откатывается. Подтвердите баланс перед подписью.

### 6. Распределение LP = Burn необратимо

Как только LP отправлен на 1nc1nerator, никто не может вывести ликвидность, *включая вас*. В этом суть — минимизация доверия. Не выбирайте Burn, если вы не уверены.

### 7. Уровень комиссии CPMM после выпуска

Выпущенный пул использует конфигурацию CPMM LaunchLab по умолчанию (0,25%). Если вы хотели 1% или 0,01%, вам нужно создать второй CPMM пул самостоятельно после выпуска и перенести ликвидность — неудобно и фрагментирует. Примите значение по умолчанию или запустите через прямое создание CPMM вместо LaunchLab.
