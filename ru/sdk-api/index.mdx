## Для кого этот раздел

Разработчики, интегрирующие Raydium с внешних систем (TS/JS, Python, бэкенды) или из другой программы Solana (Rust CPI). Также для ИИ-агентов и интеграторов инструментов кодирования — см. [Интеграция с ИИ](/ru/sdk-api/ai-integration).

<Info>
  **Хотите сначала что-то запустить?** Три полные скрипты — swap, развёртывание CPMM пула, развёртывание CLMM пула — находятся в [Быстром старте](/ru/quick-start). Скрипты swap и CPMM — это отдельные файлы, которые вы копируете и запускаете; CLMM требует несколько дополнительных шагов. Сначала запустите реальную транзакцию, затем вернитесь сюда для полного справочника.
</Info>

## Выберите путь интеграции

Пять вариантов на выбор. Правильный зависит от того, что вызывает Raydium и сколько контроля вам нужно.

| Путь | Лучше всего для | Задержка | Пользовательская логика | Языки |
|---|---|---|---|---|
| [Trade API](/ru/sdk-api/trade-api) | Бэкенды, боты, Blinks — везде, где нужна транзакция, собранная сервером | Минимальная | Ограниченная (предустановленные маршруты) | Любой |
| [TypeScript SDK](/ru/sdk-api/typescript-sdk) | Node/TS приложения и фронтенды, нуждающиеся в полном доступе к построению | Средняя | Полная | TS / JS |
| [Python интеграция](/ru/sdk-api/python-integration) | Python бэкенды и ML конвейеры | Средняя | Полная (ручное построение инструкций) | Python |
| [Rust CPI](/ru/sdk-api/rust-cpi) | Композиция программ, вызывающих Raydium из блокчейна | N/A (on-chain) | Полная + композируемая | Rust |
| [Anchor IDL](/ru/sdk-api/anchor-idl) | Кодогенерация для языков без встроенной поддержки (Go, Kotlin, Swift, ...) | Переменная | Полная | Любой с инструментом Anchor кодогенерации |

Если вы не уверены: бэкенды и боты → **Trade API**; фронтенды и приложения с полным контролем → **TypeScript SDK**; композиция on-chain → **Rust CPI**.

## Дисциплина версионирования

Каждый пример кода на каждой странице в этом разделе имеет баннер в верхней части:

```
SDK:       @raydium-io/raydium-sdk-v2 vX.Y.Z
Program:   see /reference/program-addresses
Cluster:   mainnet-beta
Verified:  YYYY-MM-DD
```

Если вы изменяете пример кода, обновите баннер.
