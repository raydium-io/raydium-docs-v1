## Комиссии за свопы по продуктам

Значения комиссий — это проценты от входящей суммы, применяемые до расчётов в пуле.

| Продукт | Доступные уровни | По умолчанию / наиболее используемый | Разделение |
|---------|-----------------|---------------------|-------|
| **AMM v4** | 0.25% (только) | 0.25% | 88% LP, 12% протокол (22/3 от 25) |
| **CPMM** | 0.01%, 0.25%, 1% | 0.25% | 100% LP (доля протокола настраивается в AmmConfig, сейчас 0%) |
| **CLMM** | 0.01%, 0.05%, 0.25%, 1% | 0.25% | 88% LP, 12% протокол |
| **LaunchLab (до выпуска)** | 1% (по умолчанию) | 1% | 50% в пул, 50% в казну LaunchLab |
| **LaunchLab (после выпуска CPMM)** | 0.25% | 0.25% | Наследует разделение CPMM |

### Соглашение о знаменателе комиссии

- **AMM v4**: комиссии кодируются как x/10,000. "25" означает 0.25%.
- **CPMM/CLMM**: комиссии кодируются как x/1,000,000. "2500" означает 0.25%.

При чтении данных из блокчейна используйте правильный знаменатель для программы пула.

## Разделение комиссий протокола

В пределах доли "протокола" каждой комиссии применяются дополнительные разделения:

| Продукт | Доля протокола от комиссии свопа | Разделение внутри протокола |
|---------|----------------------------|------------------------|
| AMM v4 | 12% (3/25) | 100% в казну |
| CPMM | Настраивается в AmmConfig (сейчас 0%) | N/A |
| CLMM | 12% от комиссии свопа | 100% в казну |
| LaunchLab | 50% от комиссии свопа до выпуска | 100% в казну LaunchLab |

**Доля LP** автоматически поступает держателям LP токенов:

- AMM v4 / CPMM: накапливается в резервах пула, распределяется пропорционально при выводе.
- CLMM: накапливается в `fee_growth_global_X/Y`, может быть получена через `collectFee`.

## Стоимость создания

Единовременные затраты в SOL для развёртывания пула.

| Продукт | Стоимость аренды | Комиссия создания | Типичный итог |
|---------|-----------|--------------|---------------|
| AMM v4 | ~0.15 SOL (несколько аккаунтов) | 0.2 SOL | ~0.35 SOL |
| CPMM | ~0.04 SOL (пул + хранилища + наблюдение) | 0.15 SOL | ~0.19 SOL |
| CLMM | ~0.075 SOL (пул + наблюдение + начальные массивы тиков) | 0 SOL | ~0.075 SOL |
| Farm v6 | ~0.02 SOL (состояние фермы + хранилища вознаграждений) | 0.1 SOL (защита от спама) | ~0.12 SOL |
| LaunchLab запуск | ~0.015 SOL (аккаунт кривой связи) | 0.1 SOL (комиссия LaunchLab) | ~0.115 SOL |

Вся аренда возвратима — закрытие пула / позиции / фермы возвращает лампорты.

## Стоимость выпуска / миграции

| Событие | Стоимость | Кто платит |
|-------|------|----------|
| LaunchLab → CPMM выпуск | ~0.04 SOL (создание нового CPMM пула) | Оплачивается из резервов кривой связи |
| AMM v4 → CPMM миграция | ~0.04 SOL создание CPMM + ~0.000005 SOL комиссия транзакции | LP, выполняющий миграцию |
| Передача CLMM позиции NFT | ~0.000005 SOL комиссия транзакции; недоступна для замороженных позиций с ограниченным издателем | Отправитель |

## Взаимодействие комиссий Token-2022

Когда одна или обе стороны пула используют Token-2022 с комиссией передачи, эффективная комиссия складывается:

```
net input to pool   = amount_in × (1 − transfer_fee_in)
pool charges swap   = net × swap_fee_rate
net output to user  = out × (1 − transfer_fee_out)
```

Пример: CPMM пул 0.25%, входящая сторона имеет комиссию передачи 1%, исходящая сторона имеет комиссию передачи 0.5%.

```
amount_in        = 1000
net_to_pool      = 1000 × 0.99    = 990
pool swap fee    = 990 × 0.0025   = 2.475 (kept as LP fee)
amount_after_fee = 987.525
amount_out (AMM) = 987.525 × ratio, say 987.525 × 0.98 = 967.77
net_out_to_user  = 967.77 × 0.995 = 962.94
```

Эффективная комиссия: **~3.7%** несмотря на номинальную комиссию пула 0.25%.

SDK вычисляет эффективный курс через `getComputeAmountOut` — всегда используйте его при расчёте котировок для пулов Token-2022.

## Специфика LaunchLab

| Фаза | Комиссия |
|-------|-----|
| Торговля на кривой связи (покупка или продажа) | 1% (разделение 50/50 пул/казна) |
| Выпуск (единовременно) | ~0.04 SOL из резервов кривой |
| После выпуска (CPMM пул) | 0.25% (стандартные комиссии CPMM) |

Проекты, запускающие токены, могут включить комиссию создателя во время фазы кривой связи. После выпуска выбранная конфигурация CPMM может также взимать отдельную комиссию создателя CPMM для записанного создателя пула. Принадлежащий платформе Fee Key представляет права на комиссии LP и не является учётной записью комиссии создателя. См. [`products/launchlab/creator-fees`](/ru/products/launchlab/creator-fees).

## Модель стоимости вознаграждений Farm v6

Фермы не взимают комиссии как таковые — это распределение вознаграждений. Но они стоят SOL для работы:

| Стоимость | Типичная |
|------|---------|
| Создание фермы | 0.1 SOL защита от спама + ~0.02 SOL аренда |
| Пополнение хранилища вознаграждений | Только токены + ~0.0005 SOL транзакция |
| Возврат неиспользованных вознаграждений | ~0.0005 SOL транзакция |

Фермы также требуют достаточно лампортов в хранилище вознаграждений для покрытия аренды на весь период существования фермы; закрытие их возвращает.

## Как читать текущие значения из блокчейна

### CPMM/CLMM AmmConfig

```ts
const config = await raydium.cpmm.getAmmConfigs();
console.log(config[0]);
// {
//   id: "...",
//   tradeFeeRate: 2500,         // 2500 / 1_000_000 = 0.25%
//   protocolFeeRate: 0,         // 0 / 1_000_000 = 0%
//   fundFeeRate: 0,
//   ...
// }
```

### AMM v4 пул

```ts
const poolInfo = await raydium.liquidity.getPoolInfoFromRpc({ poolId });
console.log(poolInfo.ammFeesNumerator, poolInfo.ammFeesDenominator);
// 25, 10000 → 0.25%
```

### Farm v6 ставка вознаграждения

```ts
const farm = await raydium.farm.getFarmInfoFromRpc({ id: farmId });
console.log(farm.farmData.rewardInfos);
// Per-reward: emissionsPerSecond, startTime, endTime
```
