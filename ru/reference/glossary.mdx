## A

**AcceleRaytor** — оригинальная платформа запуска токенов Raydium (2021–2023). Снята с обслуживания, когда LaunchLab её заменил. См. [`introduction/history-and-milestones`](/ru/introduction/history-and-milestones).

**Account** — строка данных на Solana, идентифицируемая публичным ключом, принадлежащая программе, содержащая байты данных и лампорты. См. [`solana-fundamentals/account-model`](/ru/solana-fundamentals/account-model).

**Address Lookup Table (ALT)** — опубликованный аккаунт, позволяющий транзакциям ссылаться на аккаунты по однобайтовому индексу, экономя место. Raydium SDK использует ALT для многошаговых маршрутов. См. [`solana-fundamentals/transactions-and-fees`](/ru/solana-fundamentals/transactions-and-fees).

**AmmConfig** — конфигурационный аккаунт для CPMM/CLMM, определяющий уровень комиссии и долю комиссии протокола. Несколько конфигураций могут сосуществовать; пулы ссылаются на одну при создании. См. [`ray/protocol-fees`](/ru/ray/protocol-fees).

**AMM v4** — оригинальный AMM с постоянным произведением Raydium (2021). Первоначально гибридный дизайн, отражавший кривую на OpenBook; интеграция с OpenBook была деактивирована, и пулы теперь работают как чистые AMM с постоянным произведением. По-прежнему полностью функционален; больше не рекомендуется по умолчанию для новых пулов. См. [`products/amm-v4/overview`](/ru/products/amm-v4/overview).

**Anchor** — фреймворк Rust для программ Solana, обрабатывающий валидацию аккаунтов, обработку ошибок и генерирующий IDL. Используется CPMM, CLMM, Farm v6, LaunchLab. См. [`solana-fundamentals/programs-and-anchor`](/ru/solana-fundamentals/programs-and-anchor).

**Anchor discriminator** — 8-байтовый префикс на управляемых Anchor аккаунтах и инструкциях, производный от имени аккаунта/инструкции. Идентифицирует типы аккаунтов. См. [`solana-fundamentals/account-model`](/ru/solana-fundamentals/account-model).

**Arbitrage** — использование разницы в цене между площадками (Raydium ↔ Orca ↔ CEX) для выравнивания цен. Фундаментально для обнаружения цены AMM.

**Associated Token Account (ATA)** — условный PDA-производный токен-аккаунт для пары (пользователь, mint). См. [`solana-fundamentals/spl-token-and-token-2022`](/ru/solana-fundamentals/spl-token-and-token-2022).

## B

**Bonding curve** — функция ценообразования для токена, детерминированно устанавливающая цену как функцию предложения. Используется в LaunchLab перед выпуском. См. [`products/launchlab/bonding-curve`](/ru/products/launchlab/bonding-curve).

**BPF Loader (Upgradable)** — программа загрузчика Solana, развертывающая и обновляющая программы. См. [`solana-fundamentals/programs-and-anchor`](/ru/solana-fundamentals/programs-and-anchor).

**Bump** — один байт, добавляемый к семенам для получения PDA вне кривой. Канонический bump — это наибольшее значение, которое производит адрес вне кривой. См. [`solana-fundamentals/pdas-and-cpis`](/ru/solana-fundamentals/pdas-and-cpis).

## C

**Canonical bump** — bump, найденный путем уменьшения от 255. Программы Raydium всегда используют канонический bump. См. [`solana-fundamentals/pdas-and-cpis`](/ru/solana-fundamentals/pdas-and-cpis).

**CLMM** — Concentrated Liquidity Market Maker, продукт Raydium в стиле Uniswap V3 (2022). См. [`products/clmm/overview`](/ru/products/clmm/overview).

**Compute Budget** — лимит вычислительных единиц на транзакцию. По умолчанию 200k, максимум 1.4M. Устанавливается через `ComputeBudget::SetComputeUnitLimit`. См. [`solana-fundamentals/transactions-and-fees`](/ru/solana-fundamentals/transactions-and-fees).

**Compute Unit (CU)** — единица вычислительной стоимости Solana. Комиссии за приоритет взимаются за CU. См. [`integration-guides/priority-fee-tuning`](/ru/integration-guides/priority-fee-tuning).

**Constant product** — инвариант AMM `x × y = k`. См. [`algorithms/constant-product`](/ru/algorithms/constant-product).

**CPI (Cross-Program Invocation)** — одна программа Solana вызывает другую в рамках одной транзакции. См. [`solana-fundamentals/pdas-and-cpis`](/ru/solana-fundamentals/pdas-and-cpis).

**CPMM** — современный AMM с постоянным произведением Raydium (2024). Заменяет AMM v4 для новых пулов. См. [`products/cpmm/overview`](/ru/products/cpmm/overview).

**Creator fee (LaunchLab)** — опциональный процент комиссий за swap, направляемый создателю токена во время фазы bonding-curve. См. [`products/launchlab/overview`](/ru/products/launchlab/overview).

## D

**DLMM** — Dynamic Liquidity Market Maker. Вариант CLMM от Meteora. Не Raydium.

**Discriminator** — см. "Anchor discriminator".

## E

**Emissions (Farm)** — скорость распределения вознаграждений фермы в токенах в секунду. См. [`products/farm-staking/overview`](/ru/products/farm-staking/overview).

**Escrow** — PDA-удерживаемый токен-аккаунт, хранящий средства до выполнения условия. Общий паттерн интеграции. См. [`integration-guides/cpi-integration`](/ru/integration-guides/cpi-integration).

**Executable account** — аккаунт Solana с `executable = true`, содержащий байт-код программы. См. [`solana-fundamentals/account-model`](/ru/solana-fundamentals/account-model).

## F

**Farm v3 / v5 / v6** — последовательные поколения программы вознаграждения за фермерство Raydium. v6 — текущая; v3/v5 — устаревшие. См. [`products/farm-staking/overview`](/ru/products/farm-staking/overview).

**Fee growth (CLMM)** — глобальный счетчик комиссии на единицу ликвидности, отслеживаемый в `fee_growth_global_X` и `fee_growth_global_Y`. См. [`products/clmm/math`](/ru/products/clmm/math).

**Fee tier** — конкретный процент комиссии за swap, предлагаемый пулом. Например, уровень CLMM 0.05%. См. [`reference/fee-comparison`](/ru/reference/fee-comparison).

**Finalization** — самый сильный уровень обязательства Solana, примерно через 13 секунд после приземления tx. См. [`solana-fundamentals/transactions-and-fees`](/ru/solana-fundamentals/transactions-and-fees).

**Freeze authority** — полномочие заморозить (заблокировать) токен-аккаунты для данного mint. Это риск для пользователей, предоставляющих ликвидность в токены с активным freeze authority. CLMM также записывает пул PDA как freeze authority на каждый новый mint позиции NFT, но оставляет аккаунт NFT разморозенным по умолчанию. Он замораживает аккаунт только при открытии V2, когда freeze authority базового vault mint совпадает со списком restricted-issuer.

## G

**Graduation (LaunchLab)** — событие, при котором запуск bonding-curve достигает порога и автоматически переходит в пул CPMM. См. [`products/launchlab/overview`](/ru/products/launchlab/overview).

## H

**Hybrid AMM** — AMM, интегрирующийся с внешней книгой заказов для маршрутизации сделок через ту, которая имеет лучшие цены. AMM v4 был первоначально гибридным (против OpenBook), но его сторона книги заказов с тех пор была деактивирована, поэтому AMM v4 теперь работает как чистый AMM. CPMM не является гибридным.

## I

**IDL** — Interface Description Language. JSON-описание Anchor программы её инструкций, аккаунтов, событий, ошибок. См. [`sdk-api/anchor-idl`](/ru/sdk-api/anchor-idl).

**Impermanent loss (IL)** — разница в стоимости токенов LP в сравнении с удержанием базовых токенов из-за расхождения цен. Фундаментально для AMM. См. [`algorithms/constant-product`](/ru/algorithms/constant-product).

**Invoke / invoke_signed** — системные вызовы Solana для CPI. `invoke_signed` используется для CPI, авторизованных PDA. См. [`solana-fundamentals/pdas-and-cpis`](/ru/solana-fundamentals/pdas-and-cpis).

## J

**Jito** — блок-движок Solana, поддерживающий связанные транзакции для защиты от MEV. См. [`integration-guides/routing-and-mev`](/ru/integration-guides/routing-and-mev).

**Jupiter** — доминирующий агрегатор DEX на Solana. Маршрутизирует примерно 60% своего объема через Raydium. См. [`introduction/ecosystem-position`](/ru/introduction/ecosystem-position).

## K

**Kudelski** — аудиторская фирма, проводившая аудит программ Raydium. См. [`security/audits`](/ru/security/audits).

## L

**Lamport** — наименьшая единица SOL. 1 SOL = 1,000,000,000 лампортов.

**LaunchLab** — платформа запуска токенов Raydium (2024). Запуски bonding-curve, переходящие в CPMM. См. [`products/launchlab/overview`](/ru/products/launchlab/overview).

**Liquidity L (CLMM)** — вклад позиции в ценообразование пула в единицах, определенных математикой Uniswap V3. См. [`algorithms/clmm-math`](/ru/algorithms/clmm-math).

**LP (Liquidity Provider)** — пользователь, который вносит токены в пул в обмен на LP-токены (или NFT для CLMM) и претензию на будущие комиссии.

**LP token** — SPL-токен, представляющий долю LP в пуле CPMM или AMM v4. CLMM использует NFT вместо этого.

## M

**MadShield** — аудиторская фирма, проводившая аудит программ Raydium. См. [`security/audits`](/ru/security/audits).

**Master-chef pattern** — дизайн отслеживания вознаграждений, основанный на контракте MasterChef от SushiSwap. Стиль аккумулятора `reward_per_share`. Используется Farm v6.

**Memecoin** — неформальный термин для токена, управляемого сообществом/спекуляцией. Многие запускаются через LaunchLab.

**MEV (Maximal Extractable Value)** — стоимость, извлекаемая путем упорядочения транзакций (front-running, sandwich, back-running). См. [`integration-guides/routing-and-mev`](/ru/integration-guides/routing-and-mev).

**Mint** — аккаунт Token Mint, определяющий токен. Не путайте с глаголом "minting" (выпуск нового предложения).

**Multisig** — аккаунт с несколькими подписями, требующий N из M подписантов. Raydium использует multisig Squads для полномочий. См. [`security/admin-and-multisig`](/ru/security/admin-and-multisig).

## N

**Non-transferable (Token-2022)** — расширение, предотвращающее передачу токенов. Заблокировано при создании пула Raydium.

**NFT** — Non-Fungible Token. Позиции CLMM — это NFT; также некоторые артефакты LaunchLab.

## O

**Observation / ObservationState** — on-chain аккаунт истории цен CLMM. Хранит кумулятивную цену, взвешенную по времени, позволяя TWAP оракулам. См. [`products/clmm/accounts`](/ru/products/clmm/accounts).

**OpenBook** — ранее Serum. Центральная книга заказов Solana. AMM v4 *первоначально* интегрировался с OpenBook, но эта интеграция была деактивирована; CPMM и CLMM никогда не интегрировались с ней. См. [`products/amm-v4/overview`](/ru/products/amm-v4/overview).

**Oracle** — внешний источник цены. Pyth, Jupiter и (для внутреннего использования) TWAP ObservationState CLMM. См. [`security/oracle-and-token-risks`](/ru/security/oracle-and-token-risks).

**Orca** — конкурирующий DEX на Solana. Whirlpools — продукт CLMM от Orca.

## P

**PDA (Program-Derived Address)** — адрес, детерминированно производный от программы + семян. Нет приватного ключа; владеющая программа подписывает через `invoke_signed`. См. [`solana-fundamentals/pdas-and-cpis`](/ru/solana-fundamentals/pdas-and-cpis).

**Permanent delegate (Token-2022)** — расширение, предоставляющее назначенному кошельку безусловное полномочие передачи/сжигания. Заблокировано при создании пула Raydium.

**Phoenix** — нативная книга заказов DEX на Solana. Коллега, не прямой конкурент.

**PnL (AMM v4)** — исторически: Прибыль и убыток от заполнений OpenBook, накопленные в пулы AMM v4 и урегулированные через `MonitorStep` cranks. С деактивированной интеграцией OpenBook новый PnL книги заказов не накапливается — счетчики `state_data.total_pnl_*` содержат только исторические значения. Путь комиссии протокола 0.03%, использующий `need_take_pnl_*`, не затронут и остается активным.

**Pool authority** — PDA, подписывающий передачи хранилища пула. Один на программу (не на пул). См. [`solana-fundamentals/pdas-and-cpis`](/ru/solana-fundamentals/pdas-and-cpis).

**Pool state** — on-chain аккаунт, содержащий резервы пула, комиссии, конфигурацию. Центральная структура данных на продукт.

**Priority fee** — комиссия за CU, выплачиваемая валидаторам для приоритизации транзакции в блоке. См. [`integration-guides/priority-fee-tuning`](/ru/integration-guides/priority-fee-tuning).

**Program account** — аккаунт, содержащий метаданные/байт-код программы. См. [`solana-fundamentals/programs-and-anchor`](/ru/solana-fundamentals/programs-and-anchor).

**Program Derived Address** — см. PDA.

**Protocol fee** — часть комиссий за swap, направляемая на выкуп RAY или казну вместо LP. См. [`ray/protocol-fees`](/ru/ray/protocol-fees).

**Pyth** — сеть оракулов Solana. Используется фронтендами для отображения USD; не используется математикой пула Raydium.

## Q

**Q64.64 (sqrt_price_x64)** — представление с фиксированной точкой: 64 целых + 64 дробных бита. Используется CLMM для sqrt-price, чтобы избежать дрейфа с плавающей точкой. См. [`algorithms/clmm-math`](/ru/algorithms/clmm-math).

## R

**\$RAY** — нативный SPL-токен Raydium. См. [`ray/index`](/ru/ray).

**Realized fee (CLMM)** — комиссии, накопленные на позицию с момента последнего `collectFee`. Требуются через `collectFee`. См. [`products/clmm/math`](/ru/products/clmm/math).

**Remaining accounts** — дополнительные аккаунты, добавленные к списку аккаунтов инструкции, интерпретируемые по позиции. Используются для списков аккаунтов переменной длины (tick arrays, transfer-hook extras). См. [`solana-fundamentals/pdas-and-cpis`](/ru/solana-fundamentals/pdas-and-cpis).

**Rent** — Solana взимает плату за хранение, но все современные аккаунты должны быть освобождены от ренты (содержать достаточно лампортов для предоплаты ренты навсегда). См. [`solana-fundamentals/account-model`](/ru/solana-fundamentals/account-model).

## S

**Sandwich attack** — тактика MEV: front-run swap пользователя, затем back-run для извлечения влияния на цену. См. [`integration-guides/routing-and-mev`](/ru/integration-guides/routing-and-mev).

**Serum** — предшественник OpenBook. В настоящее время неактивен; см. "OpenBook".

**Slippage** — разница между котируемым и фактическим выходом, от влияния на цену + движения цены. Контролируется параметром `min_out` на swaps.

**SOL** — нативный токен Solana.

**SPL Token** — программа токена Solana. Адрес `Tokenkeg...`. См. [`solana-fundamentals/spl-token-and-token-2022`](/ru/solana-fundamentals/spl-token-and-token-2022).

**sqrt_price_x64** — см. Q64.64.

**Squads** — платформа multisig, которую Raydium использует для операционных и полномочий обновления. См. [`security/admin-and-multisig`](/ru/security/admin-and-multisig).

**Swap / SwapV2** — варианты инструкций Raydium. `SwapV2` поддерживает Token-2022; устаревший `Swap` — нет. См. [`solana-fundamentals/spl-token-and-token-2022`](/ru/solana-fundamentals/spl-token-and-token-2022).

## T

**Tick (CLMM)** — дискретный уровень цены. Позиции охватывают диапазон ticks. См. [`algorithms/clmm-math`](/ru/algorithms/clmm-math).

**Tick array** — PDA, содержащий состояние 60 последовательных ticks. Позволяет разбить хранилище решетки tick на части. См. [`products/clmm/ticks-and-positions`](/ru/products/clmm/ticks-and-positions).

**Tick spacing** — целочисленный промежуток между используемыми ticks в пуле. Привязан к уровню комиссии (0.01% → 1, 0.25% → 60 и т. д.). См. [`algorithms/clmm-math`](/ru/algorithms/clmm-math).

**Timelock** — задержка между одобрением и выполнением чувствительного действия. Обновления Raydium имеют 24-часовой timelock. См. [`security/admin-and-multisig`](/ru/security/admin-and-multisig).

**Token-2022** — более новая программа токена с расширениями. Адрес `TokenzQ...`. См. [`solana-fundamentals/spl-token-and-token-2022`](/ru/solana-fundamentals/spl-token-and-token-2022).

**Transfer fee (Token-2022)** — расширение, взимающее процент при каждой передаче токена. Учитывается в Raydium CPMM/CLMM через `SwapV2`.

**Transfer hook (Token-2022)** — расширение, вызывающее программу при каждой передаче. Поддерживается Raydium с оговорками.

**TVL (Total Value Locked)** — сумма балансов пула/фермы в USD. TVL Raydium по состоянию на апрель 2026: примерно \$1.8B.

**TWAP (Time-Weighted Average Price)** — средняя цена, взвешенная по времени, производная от CLMM ObservationState. См. [`products/clmm/accounts`](/ru/products/clmm/accounts).

## U

**UserLedger (Farm v6)** — PDA, хранящий баланс ставки пользователя и долг вознаграждения на ферме.

## V

**Vault** — Token Account, принадлежащий PDA authority программы пула, содержащий резервы пула. Каждый пул имеет два хранилища (по одному на каждую сторону).

**Versioned transaction (v0)** — текущий формат транзакции Solana, поддерживающий ALT. Устаревшие транзакции имеют версию 0xff. См. [`solana-fundamentals/transactions-and-fees`](/ru/solana-fundamentals/transactions-and-fees).

## W

**Whirlpools** — продукт CLMM от Orca. Похожий дизайн на Raydium CLMM; другая кодовая база.

**Wrapped SOL (wSOL)** — SOL, обернутый как SPL Token для использования в контекстах, предназначенных только для токен-аккаунтов. Создается и закрывается за транзакцию. См. [`user-flows/swap`](/ru/user-flows/swap).

## X

**x × y = k** — инвариант постоянного произведения. См. [`algorithms/constant-product`](/ru/algorithms/constant-product).
