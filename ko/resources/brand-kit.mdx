## 이름 및 대문자 표기

| 형식 | 사용 |
|---|---|
| **Raydium** | 프로토콜 이름입니다. 항상 제목 대문자로 표기합니다. `raydium`, `RAYDIUM`으로 쓰지 않습니다. |
| **Raydium Protocol** | 다른 맥락에서 Raydium 이름과 구분할 필요가 있을 때 사용 가능합니다 (화학 물질, 비디오 게임 등). |
| **\$RAY** 또는 **RAY** | Raydium의 네이티브 SPL 토큰입니다. 마케팅 문구에서는 달러 기호를 붙이고, 기술 또는 표 맥락에서는 `RAY`로만 표기합니다. |
| **Raydium AMM v4** / **Raydium CPMM** / **Raydium CLMM** / **LaunchLab** | 제품 이름입니다. LaunchLab은 한 단어이며 L은 대문자입니다. |
| **Burn & Earn** | 앰퍼샌드를 포함한 하나의 구성으로, 두 명사 모두 대문자입니다. |

`Raydium DEX`, `Ray protocol`, `Raydiums` (복수형)으로 쓰지 않습니다. 프로토콜은 단수 명사입니다.

## 로고

Raydium 로고는 두 가지 형태로 제공됩니다:

- **워드마크** — 전체 "Raydium" 타입 로고입니다. 헤더, 보도자료 및 이름을 읽을 수 있어야 하는 모든 맥락에서 사용합니다.
- **심볼 마크** — 독립형 모노그램입니다. 앱 아이콘, 파비콘 및 워드마크가 읽을 수 있는 크기로 맞지 않는 제한된 공간 (아바타, 소셜 프로필 사진)에서 사용합니다.

### 라이트 및 다크 버전

각 형태당 두 가지 마감:

| 파일 | 배경 | 사용 시기 |
|---|---|---|
| `logo-light.svg` | 어두운 배경 | 어두운 UI 표면에 주로 배치합니다. |
| `logo-dark.svg` | 밝은 배경 | 밝은 UI 표면에 주로 배치합니다. |
| `mark-light.svg` | 어두운 배경 | 어두운 표면의 심볼만 사용합니다. |
| `mark-dark.svg` | 밝은 배경 | 밝은 표면의 심볼만 사용합니다. |

모든 자산은 벡터 SVG입니다. 가능한 한 SVG를 사용합니다. 최종 렌더링 크기에서만 PNG로 래스터화합니다 (확대된 PNG는 피합니다).

### 여백

로고 주변에 Raydium "R" 문자의 높이와 같은 여백을 유지합니다. 이 여백 내에 텍스트, 아이콘 또는 그래픽으로 로고를 혼잡하게 하지 않습니다.

### 최소 크기

워드마크: 화면에서 **120 px** 이상, 인쇄물에서 **20 mm** 이상으로 렌더링합니다.
심볼: 화면에서 **24 px** 이상, 인쇄물에서 **6 mm** 이상으로 렌더링합니다.

이 임계값 아래에서는 로고의 가독성이 떨어지므로 파트너는 대체 형태로 전환해야 합니다 (예: 공간이 제한된 경우 워드마크를 심볼로 변경).

## 색상 팔레트

Raydium 정체성은 바이올렛 주색과 상태, 깊이 및 대비를 위한 더 어두운 및 더 밝은 변형을 중심으로 구축됩니다.

| 역할 | 16진수 | RGB | 사용 |
|---|---|---|---|
| **Primary** | `#8C6EFF` | 140 / 110 / 255 | 주요 브랜드 색상입니다. CTA, 링크, 주요 강조. |
| **Light** | `#A88BFF` | 168 / 139 / 255 | 호버 상태, 보조 강조, 라이트 테마 배경. |
| **Dark** | `#5E3BE1` | 94 / 59 / 225 | 활성/누른 상태, 다크 테마 강조, 깊이. |

보조 중립색:

| 역할 | 16진수 | 사용 |
|---|---|---|
| **Foreground (light)** | `#0A0A0F` | 밝은 표면의 본문 텍스트. |
| **Foreground (dark)** | `#FAFAFA` | 어두운 표면의 본문 텍스트. |
| **Surface (light)** | `#FFFFFF` | 페이지 배경, 라이트 테마. |
| **Surface (dark)** | `#0F0F1A` | 페이지 배경, 다크 테마. |
| **Border** | `#E5E5EB` (light) / `#1F1F2E` (dark) | 카드 및 구분선 테두리. |

로고를 다시 칠하지 않습니다. 워드마크와 심볼은 항상 라이트 또는 다크 마스터 마감으로 렌더링됩니다 — 색조 처리, 그래디언트 교체 또는 브랜드 색상을 통한 처리는 절대 하지 않습니다.

## 타이포그래피

문서 및 사이트는 UI 및 본문 복사에 **Inter**를 사용합니다. 제목은 굵은 가중치 (600–800)의 Inter를 사용합니다. 코드 블록은 **JetBrains Mono** 또는 모든 고정폭 폴백을 사용합니다.

| 스타일 | 글꼴 | 가중치 | 사용 |
|---|---|---|---|
| Display / H1 | Inter | 800 | 페이지 제목. |
| H2–H4 | Inter | 700 | 섹션 헤더. |
| Body | Inter | 400 | 단락 텍스트. |
| Emphasis | Inter | 600 | 인라인 강조, 굵은 텍스트. |
| Code | JetBrains Mono | 400–500 | 인라인 `code` 및 코드 블록. |

Inter는 오픈 라이선스이며 [rsms.me/inter](https://rsms.me/inter)에서 사용 가능합니다.

## 로고 해야 할 것과 하지 말아야 할 것

**해야 할 것:**

- 문서 저장소 `/logo/` 디렉토리의 공식 SVG 마스터를 사용합니다.
- 여백과 최소 크기를 유지합니다.
- 워드마크와 심볼을 시각적으로 균형이 맞을 때만 함께 사용합니다 (충돌하는 크기로 나란히 표시하지 않습니다).
- 충분한 대비가 있는 배경에 렌더링합니다 — 어두운 배경에는 라이트 마스터, 밝은 배경에는 다크 마스터를 사용합니다.

**하지 말아야 할 것:**

- 로고를 다시 칠합니다. 보라색 워드마크, 무지개, 제공된 라이트/다크 이외의 단색 변형은 없습니다.
- 종횡비를 왜곡합니다 (늘이거나 기울이지 않습니다).
- 드롭 섀도우, 윤곽선, 글로우 또는 기타 효과를 추가합니다.
- 바쁜 배경 이미지에 로고를 배치합니다 (대비를 유지하는 단색 패널 아래에 배치하지 않으면).
- 로고를 자릅니다 (워드마크에서 "R"만 자르지 않습니다 — 대신 심볼 마크를 사용합니다).
- 로고를 사용하여 Raydium이 공식적으로 파트너십을 맺지 않은 제품의 승인을 암시합니다. 중립적인 맥락에서 "Powered by Raydium" 또는 "Integrated with Raydium" 배지를 사용하며, 검증을 암시하지 않습니다.

## "Powered by Raydium" 배지

통합이 Raydium을 라우팅 소스 또는 유동성 거래소로 사용하는 경우, 간단한 텍스트 또는 배지 속성이 환영됩니다:

```text
Powered by Raydium
Integrated with Raydium
Liquidity via Raydium
```

이 표현은 사전 승인되었습니다. 통합의 가격 책정, 스왑 또는 풀 표면 근처에 배치합니다 — 공식 파트너십을 암시할 수 있는 마스트헤드 눈에 띄는 위치에는 배치하지 않습니다.

집계자 또는 지갑이 Raydium을 통해 라우팅하고 더 눈에 띄는 속성을 원하는 경우, 게시하기 전에 Discord (`#partnerships`)를 통해 팀에 문의합니다.
