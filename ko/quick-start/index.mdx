## 사전 요구사항

다음을 한 번 실행하세요:

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

필요한 것:

- **Node 18+** ESM 지원 포함 (`package.json`의 `"type": "module"` 또는 `.mjs` 확장자).
- **Solana 키페어** (`~/.config/solana/id.json` 또는 다른 위치 — `KEYPAIR` 설정). 키페어 생성은 [`solana-fundamentals/toolchain`](/ko/solana-fundamentals/toolchain#solana-cli)을 참조하세요.
- **자금이 있는 지갑.** 스왑 스크립트는 입력 금액과 작은 여유만 필요합니다 — CPMM 스왑은 네트워크 수수료로 약 0.0015 SOL이 소요됩니다 ([`reference/fee-comparison`](/ko/reference/fee-comparison#network-fees-per-typical-operation) 참조), 스왑이 토큰 계정을 열어야 하는 경우 일회성 렌트가 추가됩니다. 풀 생성은 더 많은 비용이 듭니다: CPMM 스크립트만 해도 시드 유동성이나 렌트 전에 약 0.15 SOL의 일회성 풀 생성 수수료가 발생합니다. 지갑에 자금을 지원하기 전에 각 스크립트의 설정 섹션에서 현재 수치를 확인하세요.
- **RPC URL.** 테스트에는 무료 공개 RPC가 작동하지만, 스모크 테스트 이상의 경우 유료 제공자를 사용하세요.

셸당 한 번 설정하세요:

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **클러스터.** 세 스크립트 모두 메인넷을 기본값으로 합니다. Devnet은 `RPC_URL=https://api.devnet.solana.com` 및 스크립트 내부의 `cluster: "devnet"`이 필요합니다 — 두 풀 생성 스크립트의 경우 이것이 유일한 변경 사항이 아닙니다. 각 스크립트의 설정 섹션에서 다른 변경 사항을 확인하세요. Devnet의 풀 시드 유동성이 부족하다는 점을 유의하세요. 자신의 테스트 토큰을 발행할 준비를 하세요.
</Info>

## 이 장 이후

각 스크립트는 온체인 결과 — 스왑 견적 및 트랜잭션 링크, 새 풀 주소, 또는 새 포지션 및 NFT — 와 [SDK & API](/ko/sdk-api) 장의 다음 페이지를 가리키는 한 줄을 출력합니다. 자신의 통합을 작성할 준비가 되면:

- **백엔드 및 봇** → [Trade API](/ko/sdk-api/trade-api).
- **프론트엔드 및 완전 제어 앱** → [TypeScript SDK](/ko/sdk-api/typescript-sdk).
- **온체인 구성** → [Rust CPI](/ko/sdk-api/rust-cpi).
- **선택 기준** → [SDK & API](/ko/sdk-api) 상단의 비교 표.
