## 핵심 도구

### Solana CLI

Solana 클러스터와 상호작용하기 위한 표준 명령줄 인터페이스 — 지갑 관리, RPC 호출, 프로그램 배포.

설치:

```bash
# Raydium 프로그램이 빌드되고 테스트되는 버전
sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.10/install)"

# 또는 태그 대신 채널을 추적
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

확인:

```bash
solana --version   # → solana-cli 3.1.10 (... client:Agave)
```

<Note>
  **설치 호스트가 변경되었습니다.** `release.solana.com`은 Solana Labs에 속했으며, 클라이언트는 이제 Anza에서 **Agave**로 유지보수되고 있으며, 릴리스는 `release.anza.xyz`에서 제공됩니다. 자체 업데이트 바이너리는 `agave-install`입니다 (`solana-install`은 레거시 별칭으로 유지됨). 따라서 `agave-install update`와 `agave-install init <version>`이 현재 표기법입니다. Solana의 공식 문서도 CLI, Rust, Anchor를 함께 가져오는 원라인 설치 프로그램을 제공합니다:

  ```bash
  curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
  ```

  이 설치 프로그램은 자체 최신 버전을 추적하며 Raydium 프로그램이 고정한 것과 다른 Anchor를 제공할 수 있습니다 — 이후 `anchor --version`을 확인하세요.
</Note>

메인넷 구성:

```bash
solana config set --url https://api.mainnet-beta.solana.com
solana config set --keypair ~/.config/solana/id.json
solana-keygen new                           # 지갑이 없으면 생성
solana address                              # 공개 키
```

Raydium 테스트를 위해 거의 항상 자금이 있는 devnet 지갑이 필요합니다:

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2                            # 테스트용 2 SOL
```

### SPL Token CLI

SPL Token / Token-2022 작업을 위한 공식 CLI — 민트 생성, 토큰 발행, 전송.

설치 (Solana CLI에 포함):

```bash
spl-token --version
```

일반적인 작업:

```bash
spl-token create-token                                  # SPL Token 민트 생성
spl-token create-token --program-id TOKEN_2022 ...      # Token-2022 민트 생성
spl-token create-account <MINT>                         # ATA 생성
spl-token mint <MINT> 1000                              # ATA에 1000개 토큰 발행
spl-token transfer <MINT> 100 <RECIPIENT>               # 100개 전송
spl-token display <ACCOUNT_OR_MINT>                     # 검사
```

### Anchor CLI

Raydium IDL 가져오기, 클라이언트 빌드, 프로그램 검증에 필요합니다.

설치:

```bash
cargo install --git https://github.com/solana-foundation/anchor avm --locked --force
avm install 1.0.2
avm use 1.0.2
anchor --version   # → anchor-cli 1.0.2
```

<Note>
  **Anchor가 저장소와 메이저 버전을 변경했습니다.** 표준 저장소는 이제 `github.com/solana-foundation/anchor`입니다 (이전: `coral-xyz/anchor`). Anchor 1.0은 Raydium 프로그램이 사용하는 첫 번째 릴리스 라인입니다 — CPMM과 LaunchLab 모두 2026-09-09 업그레이드 기준 `anchor-lang`/`anchor-spl` `=1.0.2`를 고정하고 있으며, 이전 `0.32.1`에서 업그레이드되었습니다. `avm`은 여러 버전을 보유할 수 있습니다. `avm use 1.0.2`는 `anchor build`가 Raydium의 아티팩트를 재현하도록 합니다. Anchor 1.1과 1.2가 존재하며 자신의 프로그램을 위해 잘 빌드되지만, 대상 프로그램이 고정한 것과 다른 `anchor-lang` 마이너 버전에 대해 컴파일된 CPI 크레이트는 링크되지 않습니다 — [`sdk-api/rust-cpi`](/ko/sdk-api/rust-cpi)를 참조하세요.
</Note>

일반적인 작업:

```bash
anchor idl fetch <PROGRAM_ID> -o program.idl.json       # 온체인 IDL 가져오기
anchor idl init -f idl.json <PROGRAM_ID>                # IDL 업로드
anchor build                                             # 소스에서 프로그램 빌드
```

## TypeScript 설정

Raydium의 주요 통합 경로입니다.

### 패키지

```bash
npm install \
  @solana/web3.js \
  @solana/spl-token \
  @anchor-lang/core \
  @raydium-io/raydium-sdk-v2 \
  bn.js \
  decimal.js
```

2026년 9월 기준 함께 작동하는 것으로 알려진 버전:

| 패키지 | 버전 | 참고 |
|---------|---------|------|
| `@solana/web3.js` | `^1.95` | 1.x API입니다. `2.x` / `3.x`는 다른 호환되지 않는 API 표면입니다. Raydium SDK는 1.x를 대상으로 합니다. |
| `@solana/spl-token` | `^0.4.15` | 0.4.15는 `createUnwrapLamportsInstruction`을 노출하는 버전입니다 — [회수 가능한 렌트](/ko/solana-fundamentals/rent-and-reclaimable-rent)를 참조하세요. |
| `@anchor-lang/core` | `^1.0` | Anchor 1.x TypeScript 클라이언트입니다. |
| `@raydium-io/raydium-sdk-v2` | `0.2.64-alpha` | 이 문서의 모든 코드 데모가 사용하는 버전입니다. |

<Note>
  **`@anchor-lang/core`는 고정되었습니다. 패키지는 이제 `@anchor-lang/core`입니다.** `@anchor-lang/core`는 Anchor가 Solana Foundation으로 이동했을 때 `0.32.1`에서 중단되었습니다. Anchor 1.x는 `@anchor-lang/core`로 발행되며, Raydium의 프로그램 저장소는 2026-09-09 업그레이드에서 테스트 스위트를 전환했습니다. 실제로 사용하는 임포트는 변경되지 않습니다 — `import { Program, BN, AnchorProvider } from "@anchor-lang/core"` — 따라서 마이그레이션은 패키지 이름 변경과 lockfile 업데이트입니다.

  `0.3x`에서 이동하는 경우 두 가지 동작 참고사항: `.accounts({...})`는 이제 Anchor가 자체적으로 해결할 수 없는 계정만 허용하므로, 전체 집합을 전달하는 빌더는 대신 `.accountsPartial({...})`을 호출해야 합니다. 그리고 `@anchor-lang/core/dist/cjs/utils/token`은 `ASSOCIATED_PROGRAM_ID`와 같은 헬퍼가 이동한 위치입니다.
</Note>

### 최소 스크립트

```ts
import { Connection, Keypair } from "@solana/web3.js";
import { Raydium } from "@raydium-io/raydium-sdk-v2";

const connection = new Connection("https://api.mainnet-beta.solana.com", "confirmed");
const owner      = Keypair.fromSecretKey(/* your key */);

const raydium = await Raydium.load({
  connection,
  owner,
  cluster:      "mainnet",
  disableFeatureCheck: true,
});

// `ids`는 쉼표로 구분된 목록이며, 호출은 배열을 반환합니다
const [poolInfo] = await raydium.api.fetchPoolById({ ids: "..." });
console.log(poolInfo);
```

전체 SDK 참조는 [`sdk-api/typescript-sdk`](/ko/sdk-api/typescript-sdk)를 참조하세요.

## Rust 설정

CPI 통합 및 온체인 프로그램용입니다.

### 도구 모음

```bash
rustup install 1.91.0           # Raydium 프로그램이 고정한 버전
rustup default 1.91.0
rustup component add rustfmt clippy
agave-install init 3.1.10       # SBF 도구 모음 포함
```

`cargo build-sbf`로 프로그램을 빌드합니다 (이전 `cargo build-bpf` 표기법은 없어졌습니다).

### Raydium CPI 통합을 위한 프로그램 Cargo.toml

```toml
# CPMM 통합 (Anchor 1.0)
[dependencies]
anchor-lang        = "=1.0.2"
anchor-spl         = "=1.0.2"
raydium-cp-swap    = { version = "0.2", features = ["cpi"] }
```

```toml
# CLMM 통합 — 여전히 Anchor 0.32이므로 자체 크레이트가 필요합니다
[dependencies]
anchor-lang        = "=0.32.1"
anchor-spl         = "=0.32.1"
raydium-clmm       = { version = "0.1", features = ["cpi"] }
```

`anchor-lang`과 `anchor-spl`을 대상 프로그램이 고정한 버전으로 `=`로 고정하세요. 2026-09 기준 CPMM은 `=1.0.2`를 고정하고 CLMM은 여전히 `=0.32.1`을 고정하므로, **단일 크레이트는 둘 다에 CPI할 수 없습니다** — [`sdk-api/rust-cpi`](/ko/sdk-api/rust-cpi#cargo-dependencies)를 참조하세요.

`"cpi"` 기능은 CPI 헬퍼가 있는 `cpi` 모듈을 임포트합니다 (따라서 `raydium_cp_swap::cpi::swap_base_input(...)`을 사용할 수 있습니다). [`sdk-api/rust-cpi`](/ko/sdk-api/rust-cpi)를 참조하세요.

## Python 설정

보조 통합 경로 — 봇 개발자에게 일반적입니다.

### 패키지

```bash
pip install solders solana anchorpy
```

버전:

| 패키지 | PyPI 이름 | 버전 |
|---------|-----------|---------|
| `solders` | `solders` | ≥0.29 |
| solana-py | `solana` | ≥0.40 |
| `anchorpy` | `anchorpy` | ≥0.21 |

<Note>
  두 가지 명명 함정이 있습니다. RPC 클라이언트는 `solana`로 임포트되지만 프로젝트는 **solana-py**라고 불립니다 — `pip install solana-py`는 유용한 것을 설치하지 않습니다. 그리고 **PyPI에 `raydium-py` 패키지가 없습니다**: 커뮤니티 Raydium 헬퍼는 클론하는 저장소입니다, [`AL-THE-BOT-FATHER/raydium_py`](https://github.com/AL-THE-BOT-FATHER/raydium_py), 발행된 배포판이 아닙니다. 이 페이지의 이전 개정판은 작동하지 않는 `pip install raydium-py` 라인을 나열했습니다.
</Note>

### 최소 스크립트

```python
from solana.rpc.async_api import AsyncClient
from solders.keypair import Keypair
from anchorpy import Provider, Wallet, Program

async def main():
    conn = AsyncClient("https://api.mainnet-beta.solana.com")
    owner = Keypair()
    wallet = Wallet(owner)
    provider = Provider(conn, wallet)

    # IDL 및 프로그램 로드
    with open("cpmm.idl.json") as f:
        idl = json.load(f)
    program = Program(idl, CPMM_PROGRAM_ID, provider)

    pool = await program.account["PoolState"].fetch(pool_id)
    print(pool)
```

[`sdk-api/python-integration`](/ko/sdk-api/python-integration)을 참조하세요.

## RPC 엔드포인트

공개 메인넷 RPC (`api.mainnet-beta.solana.com`)는 심하게 속도 제한되며 모든 부하에서 조절됩니다. 중요한 사용을 위해 개인 엔드포인트를 얻으세요:

| 제공자 | 참고 |
|----------|-------|
| Helius | 가장 인기 있음. 관대한 무료 계층. |
| Triton | 엔터프라이즈. 프리미엄 가격, 안정적. |
| QuickNode | 견고함. 밀리초 이하 지연시간. |
| 자신의 RPC 노드 | 하드웨어 비용 약 \$500/월. 완전한 제어. |

구성:

```ts
const connection = new Connection("https://mainnet.helius-rpc.com/?api-key=...");
```

일부 RPC 작업에는 확장된 기능이 필요합니다:

- `getProgramAccounts` — 제한 없는 스캔은 비용이 많이 듭니다. 일부 제공자는 게이트하거나 스캔당 요금을 청구합니다.
- `getPriorityFeeEstimate` — Helius 특정 엔드포인트. 다른 제공자는 동등한 기능을 가지고 있습니다.
- `geyser` / WebSocket 스트리밍 — 저지연 봇에 필요합니다. 모든 제공자가 노출하지는 않습니다.

## Devnet 및 localnet

### Devnet

Solana의 공개 테스트 클러스터입니다. Raydium은 부분적인 devnet 배포를 가지고 있습니다:

- 테스트용 일부 CPMM 풀이 존재합니다.
- AMM v4는 과거 devnet 풀을 가지고 있습니다.
- CLMM은 몇 가지 데모 풀을 가지고 있습니다.
- Farm v6이 배포되었습니다.

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2
```

SDK는 `cluster: "devnet"`을 통해 devnet을 지원합니다:

```ts
const raydium = await Raydium.load({ connection, owner, cluster: "devnet" });
```

**주의**: devnet 풀은 유동성이 얇고 상태가 오래되었을 수 있습니다. 가격 발견을 위해 devnet에 의존하지 마세요. 명령어 흐름 구성 및 테스트에만 사용하세요.

### 포크된 메인넷 상태를 사용한 Localnet

현실적인 테스트를 위해 메인넷 상태를 로컬 검증자로 포크합니다:

```bash
solana-test-validator \
  --url https://api.mainnet-beta.solana.com \
  --clone CPMMoo8L3F4NbTegBCKVNunggL7H1ZpdTHKxQB5qKP1C \
  --clone CAMMCzo5YL8w4VFF8KVHrK22GGUsp5VTaW7grrKgrWqK \
  --clone <SOME_POOL_ID> \
  --clone <SOME_MINT_ID>
```

이는 특정 프로그램/계정 상태를 localhost로 복제하여 자유롭게 거래할 수 있습니다. 다음에 이상적입니다:

- 실제 Raydium 프로그램에 대해 CPI 통합을 단위 테스트합니다.
- 수정된 매개변수로 트랜잭션을 재생하여 디버그합니다.
- 큰 합성 거래량으로 스트레스 테스트합니다.

Raydium 팀은 메인넷 배포 전 회귀 테스트를 위해 포크된 localnet을 광범위하게 사용합니다.

## 환경 위생

### 목적별 별도 지갑

- **개발 지갑**: 테스트넷 SOL을 보유하며, 빌드에 사용됩니다.
- **프로덕션 지갑**: 실제 SOL을 보유하며, 배포/멀티시그 제출에만 사용됩니다.
- **봇용 핫 지갑**: 작은 잔액, 좁은 권한.

키는 절대 하드코딩되어서는 안 됩니다. 환경 변수 또는 시크릿 관리자를 사용하세요.

### `.env` 패턴

```
# .env (커밋되지 않음)
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=...
WALLET_PATH=/Users/you/.config/solana/id.json
```

```ts
import { config } from "dotenv";
config();

const connection = new Connection(process.env.SOLANA_RPC_URL!);
```

### 버전 고정

모든 Solana 생태계 의존성을 잠그세요. 생태계는 빠르게 움직입니다. `@solana/web3.js`의 마이너 버전 범프는 이전에 주요 변경사항을 도입했습니다. `package-lock.json` / `Cargo.lock`을 종교적으로 사용하세요.
