<Info>
  LaunchLab의 **플랫폼**은 Raydium의 LaunchLab 프로그램 위에 구축된 제3자 런칭 환경입니다. 플랫폼은 자신의 브랜드를 표현하고, 자체 수수료를 부과하며, 자신의 플랫폼에서 런칭되는 모든 토큰에 대해 본딩 곡선 후 마이그레이션 파라미터를 구성할 수 있습니다. 별도의 온체인 프로그램을 실행할 필요가 없습니다. Raydium의 런칭 UI는 많은 플랫폼 중 하나일 뿐입니다.
</Info>

## 플랫폼이 존재하는 이유

Raydium은 LaunchLab이 **공유 프리미티브**가 되기를 원했으며, 단일 브랜드 제품이 아닙니다. 플랫폼 PDA 시스템을 통해 생태계, 도구 제공자, 커뮤니티, 밈 팀이 동일한 기본 LaunchLab 본딩 곡선 프로그램과 CPMM 마이그레이션 후 풀로 정산되는 큐레이션되거나 브랜드화된 런칭 경험을 제공할 수 있습니다.

실제로 볼 수 있는 플랫폼의 예시:

- **Raydium의 LaunchLab UI** (raydium.io/launchlab) — 참조 구현입니다.
- **파트너 런칭패드** — 자신의 플랫폼 PDA를 등록한 제3자로, 런칭 경험을 브랜드화합니다.
- **틈새 플랫폼** — 예를 들어, 특정 테마와 연결된 밈코인만 런칭하는 커뮤니티 전용 플랫폼으로, 커스텀 수수료 배분이 재무를 지원합니다.

이 모든 토큰은 여전히 동일한 LaunchLab 프로그램에 존재하고, 동일한 CPMM 프로그램으로 졸업하며, 동일한 애그리게이터로 라우팅될 수 있습니다.

## 플랫폼 PDA

각 플랫폼은 LaunchLab 프로그램에 저장된 플랫폼 PDA로 표현됩니다. 필드는 다음과 같습니다:

| 필드 | 설명 |
|---|---|
| `platform_key` | 플랫폼의 시드/식별자로, 플랫폼 PDA를 파생하는 데 사용됩니다. |
| `platform_fee_destination` | 마이그레이션 전후 거래 수수료의 플랫폼 몫을 받는 계정입니다. |
| `platform_fee_bps` | 마이그레이션 전 스왑에 대한 플랫폼 수수료 배분(플랫폼마다 다름). |
| `creator_fee_rate` | 본딩 곡선 거래 중 크리에이터 수수료 비율입니다. |
| `platform_scale`, `creator_scale`, `burn_scale` | 저장된 LP 스케일입니다. 업그레이드 전에는 크리에이터 스케일이 크리에이터 수수료 키로 이동했습니다. 그 이후에 실행된 마이그레이션의 경우, 처음 두 개가 플랫폼의 잠금 LP 배분으로 결합되고, `burn_scale`은 소각됩니다. |
| `cp_config_id` | 마이그레이션 후 대상이 CPMM인 경우, 사용할 `AmmConfig` — 수수료 계층을 선택합니다. |
| `restrict_global_config` | 런칭이 선택된 `GlobalConfig`에 대해 플랫폼에서 생성한 허용 PDA를 제시해야 하는지 여부입니다. |
| `name`, `description`, `image_url` | 플랫폼 브랜딩을 지원하는 지갑 및 UI에서 사용하는 표시 메타데이터입니다. |
| `tokens_launched` | 이 플랫폼에서 생성된 토큰의 카운터 또는 온체인 인덱스입니다. |

정확한 필드 이름은 LaunchLab IDL([`sdk-api/anchor-idl`](/ko/sdk-api/anchor-idl))에 있습니다. 위의 표는 설명적 개요입니다.

## 플랫폼이 제어할 수 있는 것

**수수료 포착:**

- 모든 마이그레이션 전 매수/매도에 대한 **플랫폼 수수료 배분**.
- **마이그레이션 후 배분** — 2026-08-14 업그레이드 전에는 크리에이터 스케일이 별도의 크리에이터 수수료 키를 생성했습니다. 그 이후에 실행된 마이그레이션의 경우, `platform_scale + creator_scale`이 하나의 플랫폼 소유 잠금 LP 포지션이 되고 `burn_scale`은 소각됩니다.

**마이그레이션 후 대상:**

- `cp_config_id`를 통해 선택된 `AmmConfig`가 있는 **CPMM**. 새로 초기화된 모든 런칭은 CPMM을 사용합니다.
- **AMM v4**는 레거시 마이그레이션 타입으로 생성된 기존 런칭 상태에 대한 졸업 경로로만 남아 있습니다.

**사용자 경험:**

- Raydium 앱 및 LaunchLab 토큰을 표시하는 모든 지갑/탐색기에서 사용하는 **브랜딩 메타데이터**.
- **런칭 페이지 커스터마이제이션** — 자신의 프론트엔드를 호스팅하는 플랫폼은 자신의 플랫폼 런칭만 표시하도록 토큰을 필터링할 수 있습니다.

## 플랫폼이 제어할 수 없는 것

- **본딩 곡선 수학**. 곡선 형태(로지스틱, 지수 등)는 LaunchLab 프로그램 자체의 일부입니다. 플랫폼은 지원되는 곡선 중에서 선택하며, 임의의 커스텀 곡선을 추가할 수 없습니다.
- **마이그레이션 임계값 로직**. CPMM으로의 졸업을 트리거하는 조건은 프로그램에서 강제됩니다.
- **핵심 보안/감사 태세**. 모든 플랫폼은 LaunchLab의 감사 이력을 상속받습니다. 악의적인 플랫폼은 프로그램을 변경하여 이를 우회할 수 없습니다.

## 플랫폼 등록

LaunchLab 프로그램은 `create_platform` 명령어를 노출합니다(IDL의 정확한 이름). 호출자는 다음을 전달합니다:

- 플랫폼 PDA를 파생할 시드.
- 수수료 대상 계정.
- 원하는 수수료 bps(프로그램 수준 상한 적용).
- 마이그레이션 후 구성(해당하는 경우 CPMM `AmmConfig` ID).
- 브랜딩 메타데이터.

플랫폼 PDA의 렌트는 크리에이터가 지불합니다. 브랜딩 및 일부 수수료 파라미터에 대한 업데이트는 생성 후 플랫폼의 권한에 의해 허용됩니다. 구조적 파라미터(마이그레이션 대상 프로그램)는 일반적으로 허용되지 않습니다.

현재 LaunchLab IDL의 정확한 명령어 서명은 [`products/launchlab/instructions`](/ko/products/launchlab/instructions)를 참조하세요.

## 경제적 상호작용

LaunchLab 본딩 곡선의 단일 스왑은 대략 다음과 같이 가치를 분배합니다(정확한 비율은 플랫폼에서 설정):

```
구매자 지불:                100 SOL
프로토콜 수수료 (LaunchLab): – 작은 %
플랫폼 수수료:              – platform_fee_bps%
크리에이터 수수료 (마이그레이션 전): – creator_fee_bps% (활성화된 경우)
나머지 (곡선으로):          ~ 나머지
```

마이그레이션 후, LP 토큰은 두 가지 효과적인 대상을 가집니다:

```
졸업 시 발행된 LP 토큰:  100%
  → 소각됨:                 burnScale
  → 플랫폼 수수료 키:       platformScale + creatorScale
```

플랫폼 수수료 키는 잠금 유동성을 인출할 수 없는 청구 가능한 LP 수수료 권리를 나타냅니다. 소각된 LP는 수수료 키 보유자가 없습니다.

## 글로벌 구성 제한

플랫폼 관리자는 `restrict_global_config = 1`을 설정하고 수락된 각 `GlobalConfig`에 대해 하나의 `PlatformAllowConfig`를 생성할 수 있습니다. 새 런칭 트랜잭션은 일치하는 허용 PDA를 추가해야 합니다. 제한이 비활성화되면, 플랫폼은 프로그램의 다른 검증을 통과하는 모든 구성을 수락합니다.

## 통합자 참고사항

- **플랫폼별 토큰 나열**. API 풀 정보/민트 엔드포인트를 `platform` 필터(지원되는 경우)와 함께 사용하여 특정 플랫폼 PDA에서 런칭된 토큰만 나열합니다.
- **브랜딩 표시**. LaunchLab 토큰을 표시하는 지갑 또는 탐색기를 구축하는 경우, 플랫폼 PDA에서 플랫폼의 이름/이미지 URL을 읽는 것이 모든 토큰에 대해 "LaunchLab"을 표시하는 것보다 훨씬 나은 UX입니다.
- **수수료 계산**. 모든 본딩 곡선 견적은 프로토콜 및 크리에이터 수수료 외에 플랫폼 수수료를 고려해야 합니다. SDK의 견적 헬퍼는 플랫폼 PDA가 제공될 때 이를 자동으로 수행합니다.
