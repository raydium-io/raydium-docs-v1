## 설정

여기의 데모는 [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad)의 파일을 반영합니다. 부트스트랩은 데모 저장소의 [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)을 따릅니다:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## 런칭 생성

소스: [`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts) (그리고 API 기반 Bonk 변형을 위한 [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts))

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId: /* reference/program-addresses의 LaunchLab 프로그램 ID */,
  // 새로운 베이스 민트의 토큰 메타데이터:
  name:   "Example Token",
  symbol: "EXMPL",
  uri:    "https://example.com/metadata.json",
  decimals: 6,

  // 곡선 파라미터:
  curveType: 0,                                      // 0 = quadratic
  supply:    new BN(1_000_000_000).mul(new BN(10).pow(new BN(6))), // 1B base (6 dec)
  graduationFractionBps: 8000,                       // 80% → graduation
  initialK:  new BN("40"),                           // curve shape parameter

  // 인용 측:
  quoteMint: NATIVE_MINT,                            // WSOL
  openTime:  new BN(Math.floor(Date.now() / 1000) + 60),  // 1분 후 오픈

  // 수수료 정책:
  fees: {
    buyNumerator:   new BN(100),                     // 1.00%
    buyDenominator: new BN(10_000),
    sellNumerator:  new BN(100),
    sellDenominator: new BN(10_000),
    lpShare:         new BN(60),
    creatorShare:    new BN(20),
    protocolShare:   new BN(20),
    totalShare:      new BN(100),
  },

  postGraduationLpPolicy: "burn",                    // "burn" | "lock" | "toCreator"

  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Launch:", extInfo.launchState.toBase58());
console.log("Base mint:", extInfo.baseMint.toBase58());
console.log("Create tx:", txId);
```

참고:

- `initialK`는 이차 곡선의 스케일 팩터입니다. 졸업 시 특정 오프닝 CPMM 가격을 목표로 조정하세요. 유도는 [`products/launchlab/bonding-curve`](/ko/products/launchlab/bonding-curve)를 참조하세요.
- SDK는 베이스 민트, 메타데이터 PDA, 그리고 두 개의 볼트를 단일 트랜잭션으로 생성합니다. 메타데이터 URI가 길면 1232바이트를 초과할 수 있으며, 이 경우 SDK는 두 개의 트랜잭션으로 분할합니다.
- `Initialize` 후, 런칭은 `openTime`까지 거래할 수 없습니다. `openTime`을 1~2분 앞으로 설정하여 프론트러너가 첫 매수를 잡을 기회를 줄이세요.

## 런칭 상태 조회

```ts
const launchId = new PublicKey("<LAUNCH_STATE>");

const launch = await raydium.launchpad.getLaunchById({ launchId });
console.log("Status:", ["Active","Graduated","Cancelled"][launch.status]);
console.log("Base sold:", launch.baseSold.toString(),
            "/", launch.baseSupplyMax.toString());
console.log("Quote collected:", launch.quoteReserveReal.toString(),
            "target:", launch.quoteReserveTarget.toString());
if (launch.status === 1) {
  console.log("Post-graduation CPMM pool:", launch.cpmmPoolState.toBase58());
}
```

`getLaunchById`는 디코딩된 `LaunchState`와 계산된 "졸업 진행도" 분수를 `Decimal`로 반환합니다.

## 매수 — 정확한 인용 입력

소스: [`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

```ts
const quoteIn        = new BN(1).mul(new BN(10).pow(new BN(9)));  // 1 SOL
const minimumBaseOut = new BN(0);  // 모두 수락; 프로덕션에서는 조정

// UI가 예상 base_out을 표시할 수 있도록 오프체인에서 인용을 미리 봅니다:
const preview = raydium.launchpad.computeBuyBase({
  launchState: launch,
  quoteIn,
});
console.log("Expected base_out:", preview.baseOut.toString(),
            "price impact:", preview.priceImpact.toString());

const { execute } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn,
  minimumBaseOut,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

`computeBuyBase`는 온체인 Newton 솔버(이차 곡선) 또는 폐쇄형 CPMM 역함수(curve_type 1)를 반영합니다. "수신할 금액" UI 필드를 채우는 데 사용하세요.

## 매수 — 정확한 베이스 출력

```ts
const baseOut         = new BN(1_000_000).mul(new BN(10).pow(new BN(6)));  // 1M base
const maximumQuoteIn  = new BN(2).mul(new BN(10).pow(new BN(9)));          // 2 SOL로 제한

const { execute } = await raydium.launchpad.buyExactOut({
  launchInfo: launch,
  baseOut,
  maximumQuoteIn,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

"정확히 X 토큰 매수" UI에 유용합니다. 곡선이 충분히 움직여서 인용 요구사항이 이제 `maximumQuoteIn`을 초과하면 `ExceededSlippage`로 거부합니다.

## 매도

소스: [`src/launchpad/sell.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/sell.ts)

```ts
const baseIn           = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M base
const minimumQuoteOut  = new BN(0);

const { execute } = await raydium.launchpad.sellExactIn({
  launchInfo: launch,
  baseIn,
  minimumQuoteOut,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

곡선의 매도 경로는 매수 경로와 대칭입니다: `base_sold`를 `baseIn`만큼 줄이면 `quote_out`은 `base_sold − baseIn`과 `base_sold` 사이의 곡선 아래 적분 영역에서 매도 수수료를 뺀 값과 같습니다.

## 임계값 교차 매수에서 자동 졸업

SDK는 사후 매수 상태가 임계값을 교차할 것으로 감지하면 `buy*` 트랜잭션 내에 `Graduate` 명령을 연결합니다:

```ts
const { execute, willGraduate } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn: new BN(100).mul(new BN(10).pow(new BN(9))),    // 큰 매수
  minimumBaseOut: new BN(0),
  txVersion: TxVersion.V0,
  autoGraduate: true,                                      // 기본값
});

if (willGraduate) {
  console.log("This buy will trigger graduation.");
}

const { txId } = await execute({ sendAndConfirm: true });
```

`Graduate`는 권한이 없으므로 누구든지(MEV 봇 포함) 임계값 교차 후 첫 `Graduate`를 착지하려고 경쟁할 수 있습니다 — 일반적으로 분 단위가 아닌 초 단위입니다. 첫 착지자는 CPMM 풀 계정의 임차료만 지불합니다. 다른 이점은 없습니다.

## 수동 `Graduate`

`autoGraduate`가 꺼져 있거나 임계값 교차 트랜잭션이 실패한 경우, 졸업을 별도로 실행할 수 있습니다:

```ts
const { execute } = await raydium.launchpad.graduate({
  launchInfo: launch,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

제출 시 `quote_reserve_real < quote_reserve_target`이면 `NotAtThreshold`로 되돌립니다. 재시도 안전 — 성공 후 두 번째 `Graduate` 시도는 `NotActive`로 되돌립니다.

## 런칭의 생명주기 추적

모두 함께 모니터링 스크립트는 다음과 같을 수 있습니다:

```ts
async function watch(launchId: PublicKey) {
  while (true) {
    const launch = await raydium.launchpad.getLaunchById({ launchId });
    const progress =
      Number(launch.quoteReserveReal) /
      Number(launch.quoteReserveTarget);

    console.log(
      `status=${["Active","Graduated","Cancelled"][launch.status]}`,
      `progress=${(progress * 100).toFixed(2)}%`,
      `num_buys=${launch.stateData.numBuys}`,
    );

    if (launch.status === 1) {
      console.log("Graduated to CPMM pool:", launch.cpmmPoolState.toBase58());
      break;
    }
    await new Promise(r => setTimeout(r, 10_000));
  }
}
```

## gRPC를 통해 구성 및 풀 감시

소스: [`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

Yellowstone gRPC를 통해 LaunchLab 프로그램을 구독하고 각 민트의 토큰 프로그램과 함께 모든 `GlobalConfig` 및 `PoolState` 업데이트를 기록합니다. 하나의 `accounts` 구독에 두 개의 `datasize` 필터가 두 계정 유형을 분리하므로, 단일 스트림이 둘 다를 포함합니다.

데모는 런칭의 민트를 분류하기 위한 가장 짧은 올바른 참조이며, [Token-2022 인용 민트 릴리스](/ko/reference/changelog/2026-08-24-launchlab-token2022-quote-mint)가 필요하게 합니다:

- **풀**은 `PoolState.token_program_flag`에서 직접 분류되며, 민트 페치 없이 베이스 민트에 대해 bit0을, 인용 민트에 대해 bit1을 디코딩합니다. 전체 바이트를 `0`에 대해 테스트하는 것 — 인용 민트가 레거시 전용이었을 때 충분했던 — 인용 민트가 Token-2022일 때마다 레거시 베이스 민트를 Token-2022로 잘못 읽습니다.
- **구성**은 그런 식으로 분류할 수 없습니다: `GlobalConfig`는 인용 민트의 주소를 저장하고 프로그램 플래그는 없으므로, 데모는 민트 계정의 소유자를 한 번 읽고 민트당 캐시합니다.

또한 둘을 서로 교차 검사하며, 이는 자신의 인덱서에 유지할 유용한 어설션입니다. `create` 대 `update`는 데모 자신의 캐시에서 추론되며, 시작 시 `getProgramAccounts`에서 시드됩니다. 시드가 비활성화되면 "create"를 "이 스트림에서 처음 본" 것으로 읽으세요.

gRPC 액세스는 공개 RPC 표면의 일부가 아닙니다 — 데모 저장소의 [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md)를 참조하세요.

## Rust CPI

자신의 Anchor 프로그램에서 LaunchLab을 호출하는 것은 드뭅니다(대부분의 런칭 통합은 TS 측만). 그렇다면, 프로그램은 `cpi::accounts::Buy`, `cpi::accounts::Sell` 등이 있는 Anchor 크레이트 `raydium_launchlab`을 제공합니다 — 패턴은 CPMM / CLMM CPI 예제를 반영합니다. 이 사이트가 채워지면 [`sdk-api/rust-cpi`](/ko/sdk-api/rust-cpi)를 일반화된 템플릿으로 참조하세요.

## 함정

- **수수료 분할 산술 오프바이원.** `total_share`가 정확히 `lp_share + creator_share + protocol_share`가 아니면, `Initialize`는 `InvalidFeeShares`로 되돌립니다. `totalShare`를 합계와 같게 설정하세요.
- **허용되지 않은 인용 민트 사용.** `launch_config.allowed_quote_mints`는 고정 목록입니다. 다른 민트를 전달하면 되돌립니다. 먼저 `raydium.launchpad.getConfig()`로 확인하세요.
- **메타데이터 크기.** 긴 `uri` 문자열은 Metaplex CPI를 예산 초과로 밀어냅니다. `uri`를 ~200자 이하로 유지하세요 — 대부분의 CDN 호스팅 JSON 메타데이터는 쉽게 맞습니다.
- **졸업 경쟁.** 자동화된 봇은 `quote_reserve_real`을 모니터링하고 임계값 교차 후 슬롯 또는 두 개 내에 `Graduate`를 프론트런합니다. 이는 무해합니다 — 임차료만 비용입니다 — 하지만 UI가 `status` 전환을 빠른 이벤트로 취급해야 함을 의미합니다.
