## LaunchLab이 해결하는 문제

LaunchLab 이전에는 Raydium에서 새로운 토큰을 런칭하려면 크리에이터가 AMM 풀에 양쪽 자산을 미리 준비해야 했습니다. 즉, 팀이 직접 인용 자산(SOL 또는 USDC)의 유동성을 제공해야 했다는 뜻입니다. 이는 자금이 충분한 프로젝트에 유리했고 초기 자본에 따라 런치패드 접근이 제한되었습니다.

LaunchLab은 이 초기 단계를 **본딩 곡선**으로 대체합니다. 토큰은 인용 민트(일반적으로 SOL 또는 USDC)로 가격이 책정된 곡선에 대해 배포됩니다. 구매자는 인용 자산을 곡선에 보내 토큰을 획득하며, 프로그램은 곡선 공식과 현재 공급량에 따라 결정된 가격으로 기본 토큰 단위를 원자적으로 발행하거나 해제합니다. 미리 준비된 유동성이 필요하지 않습니다.

곡선이 실제 AMM 풀의 유동성 공식과 일치하는 충분한 인용 자산을 수집하면 **졸업**합니다. 프로그램은 곡선의 기본 준비금과 인용 준비금으로 시드된 CPMM 풀을 메인넷에 생성하고, 그 이후로는 거래가 AMM으로 이동합니다.

## 생명주기

```
             ┌───────────────────────┐
creator  ──▶ │  Initialize (Launch)  │   ▸ 기본 토큰을 발행하고, 곡선 금고에 자금을 조성하며,
             │                        │     곡선 매개변수와 졸업 임계값을 설정합니다
             └───────────┬────────────┘
                         │
                         ▼
             ┌───────────────────────┐       N번 반복됨
             │   Buy  /  Sell        │ ◀─── 거래자들이 곡선과 상호작용합니다
             └───────────┬────────────┘
                         │ curve quote_reserve
                         │ 임계값을 넘음
                         ▼
             ┌───────────────────────┐   ▸ 곡선 상태를 스냅샷합니다
             │      Graduate         │   ▸ 곡선 준비금으로 시드된 CPMM 풀을 배포합니다
             │                        │   ▸ 정책에 따라 남은 기본 공급량을 잠금/소각합니다
             └───────────┬────────────┘
                         │
                         ▼
             ┌───────────────────────┐
             │   CPMM pool live      │   ▸ 이후로는 표준 CPMM 동작이 계속됩니다
             └───────────────────────┘
```

모든 런칭은 이 시퀀스를 정확히 한 번 거칩니다. `Buy`와 `Sell`은 중간 단계의 사용자 대면 명령어입니다. 임계값을 넘으면 `GlobalConfig`에 저장된 마이그레이션 지갑이 `MigrateToCpswap`에 서명합니다.

## 두 개의 고정 당사자

LaunchLab 상태에는 두 개의 구별되는 계정이 있습니다:

- **기본 민트** — 런칭되는 토큰입니다. 그 민트 권한은 졸업까지 LaunchLab 프로그램이 보유하며, 졸업 후에는 취소됩니다.
- **인용 민트** — 담보입니다. 항상 주류 민트(SOL / USDC / RAY)입니다. 런칭 설정은 `Initialize`에서 하나를 선택하며, 변경할 수 없습니다.

그리고 두 개의 금고:

- **`base_vault`** — 곡선에 미리 발행되었지만 아직 판매되지 않은 기본 공급량의 일부를 보유합니다. 사용자가 구매할 때마다 감소합니다.
- **`quote_vault`** — 구매자가 지불한 인용 자산을 누적합니다. 사용자가 구매할 때마다 증가합니다. 이 잔액이 졸업 임계값에 대해 확인됩니다.

## 가격 책정 모델

LaunchLab은 여러 곡선 공식을 지원합니다([`bonding-curve`](/ko/products/launchlab/bonding-curve) 참조). 가장 일반적인 것은 Pump.fun / Curve.fi / Bancor 계열과 유사한 **이차 함수** 본딩 곡선입니다:

```
price(s) = k × (s / S_max)²     (또는 유사 — 정확한 공식은 곡선 설정에 따라 다름)
```

여기서 `s`는 사용자에게 이미 판매된 기본 토큰의 양이고 `S_max`는 곡선의 최대 공급량입니다. 각 구매마다 가격이 단조적으로 상승하고 각 판매마다 하락합니다. 프로그램이 AMM 통합 비용을 정확히 계산하므로 모든 크기의 구매는 올바른 통합 금액을 반환하며, 곡선의 자연스러운 볼록성 이상의 거래별 슬리피지는 없습니다.

## 졸업

런칭은 `quote_vault.balance ≥ graduation_threshold`일 때 졸업합니다. 임계값은 `Initialize`에서 설정되며, 일반적으로 졸업 시 곡선의 암시적 가격이 수집된 준비금으로 AMM 풀이 개설될 가격과 일치하도록 선택됩니다. 구체적으로:

```
threshold ≈ S_graduate × price(S_graduate) × f
```

여기서 `S_graduate`는 이미 판매된 기본 토큰의 양이고, `price(S_graduate)`는 그 지점에서의 곡선의 한계 가격이며, `f`는 수수료 라인을 고려한 작은 계수(1–2%)입니다.

졸업 시:

1. 프로그램은 `(base_vault_remaining, quote_vault)`를 스냅샷합니다.
2. 이 두 준비금으로 CPMM `CreatePool` CPI를 호출하여 초기 LP를 프로그램 소유 권한에 발행합니다(일반적으로 정책에 따라 소각/잠금됨).
3. 기본 민트의 민트 권한을 취소합니다(더 이상 기본 토큰을 발행할 수 없도록).
4. `LaunchState.status`가 `Graduated`로 전환됩니다.

졸업 후 `Buy`와 `Sell`은 거부됩니다. 거래는 결과 CPMM 풀에서 계속되며, 이는 다른 Raydium CPMM 풀과 구별되지 않습니다.

## 수수료

곡선 단계 동안 각 `Buy`와 `Sell`은 다음 사이에 분할되는 수수료를 발생시킵니다:

- **곡선 LP 측** — 곡선의 암시적 `k`를 증가시키며, 이는 나중의 구매자에게 이익이 됩니다(더 타이트한 가격).
- **프로토콜** — LaunchLab 관리자에게 누적되며, `CollectFees`를 통해 수집됩니다.
- **크리에이터** — 선택사항이며, `Initialize`에서 설정 가능합니다. 일부 런칭은 크리에이터에게 지속적인 수익 흐름으로 일부를 지정합니다.

기본 요율은 [`bonding-curve`](/ko/products/launchlab/bonding-curve)에 문서화되어 있습니다. 정확한 분할은 `LaunchState.fees`에 저장되며 런칭마다 다를 수 있습니다.

졸업 후 수수료는 풀이 생성된 CPMM 설정을 따릅니다(일반적으로 `AmmConfig[0]`, 0.25% 계층).

## 졸업 후 LP를 누가 보유하나요?

LaunchLab은 플랫폼의 세 가지 저장된 스케일을 사용하여 두 가지 효과적인 LP 목적지를 생성합니다:

- **플랫폼 잠금** — 2026-08-17 업그레이드 후 실행된 마이그레이션의 경우, `platform_scale + creator_scale`은 LP-Lock을 통해 잠기고 이 공유가 0이 아닐 때 하나의 Fee Key가 `platform_nft_wallet`으로 이동합니다. 업그레이드 전에는 `creator_scale`이 별도의 크리에이터 Fee Key를 생성했습니다.
- **소각** — `burn_scale`은 영구적으로 소각되며 Fee Key가 없습니다.

스케일은 `PlatformConfig`에 있으며 `1_000_000`으로 합산되어야 합니다. 업그레이드는 향후 마이그레이션 실행만 변경합니다. 이전 마이그레이션으로 생성된 크리에이터 Fee Key는 변경하지 않습니다.

## 중요한 불변성

- **기본 민트는 졸업 후 인플레이션이 없습니다.** 그 `mint_authority`는 취소되며, `freeze_authority`는 설정되지 않았습니다.
- **모든 새로운 런칭은 CPMM 전용입니다.** `Initialize`, `InitializeV2`, 및 `InitializeWithToken2022`는 `migrate_type = CPSWAP`을 요구합니다. 기존 레거시 상태는 여전히 `MigrateToAmm`을 사용할 수 있습니다.
- **곡선 상태는 한 방향으로 단조입니다.** `base_sold`는 Buy 중에만 상승하고, `quote_vault`는 Buy 중에만 상승합니다(Sell 중에는 하락하며, 이는 대칭적으로 `base_sold`를 감소시킵니다). 프로그램은 곡선을 음수로 만들지 않습니다.
- **졸업은 일방통행 게이트입니다.** 졸업 후 거래가 AMM 풀 가격을 졸업 가격 아래로 밀어내더라도 런칭은 곡선으로 되돌아가지 않습니다.

## LaunchLab을 사용할 때

<Note>
  이 페이지는 프로토콜 메커니즘만 설명합니다. 여기의 어떤 내용도 재정, 법률 또는 투자 조언을 구성하지 않습니다. 토큰 런칭은 상당한 재정적 위험을 수반합니다. 공개 자금 조성을 포함하는 토큰을 런칭하기 전에 적절한 전문가와 상담하세요.
</Note>

- 기존 시장이 없는 새로운 토큰을 런칭하고 있습니다.
- 시장이 미리 선언된 가격이 아닌 개설 CPMM 가격을 결정하기를 원합니다.
- 팀 자신을 포함한 누구나 내부자 할인이 아닌 동일한 곡선 결정 가격으로 구매할 수 있도록 하려고 합니다.

LaunchLab을 사용하지 **마세요**:

- 확립된 시장이 있는 기존 토큰(CPMM에서 직접 `CreatePool` 사용).
- 개설 AMM 가격을 정확히 제어해야 하는 런칭(신중한 곡선 설정으로 근사할 수 있지만 메커니즘은 여전히 곡선 기반).
- LaunchLab이 허용 목록에 없는 Token-2022 확장이 필요한 토큰(런칭 프로그램은 Token-2022 경로에서도 `TransferHook` 및 `PermanentDelegate`와 같은 확장을 거부합니다).
