LaunchLab 토큰이 CPMM으로 마이그레이션될 때, 풀은 LP 토큰을 발행합니다. 2026-08-14 업그레이드 이전에는 `creatorScale`이 토큰 크리에이터를 위해 별도로 잠금되었습니다. 업그레이드 이후 실행된 마이그레이션의 경우, `migrateCpLockNftScale`은 여전히 `1_000_000`으로 합산되는 세 개의 필드를 저장하지만, 런타임은 두 개의 목적지만 생성합니다.

## 실제 분배 비율

| 필드 | 업데이트된 동작 |
|---|---|
| `platformScale` | 플랫폼 소유 잠금 LP 지분에 포함됩니다. |
| `creatorScale` | 업그레이드 이전에는 크리에이터 소유 Fee Key를 발행했습니다. 업그레이드 이후에는 플랫폼 소유 잠금 LP 지분에 포함됩니다. |
| `burnScale` | 영구적으로 소각됩니다. 이 지분을 나타내는 Fee Key가 없습니다. |

```text
effectivePlatformScale = platformScale + creatorScale
platformLp = floor(totalLp × effectivePlatformScale / 1_000_000)
burnLp = totalLp − platformLp
```

`burnScale`이 0일 때, 플랫폼은 모든 LP 단위를 받습니다. `effectivePlatformScale`이 0일 때, 모든 LP가 소각되고 플랫폼 Fee Key가 생성되지 않습니다.

## 예시

```ts
// @raydium-io/raydium-sdk-v2@0.2.42-alpha · mainnet-beta · verified 2026-08-13
// 90% 플랫폼 소유 잠금 LP, 10% 소각.
migrateCpLockNftScale: {
  platformScale: new BN(400_000),
  creatorScale: new BN(500_000),
  burnScale: new BN(100_000),
}

// 업데이트된 프로그램에서는 100% 플랫폼 소유 잠금 LP를 생성합니다.
migrateCpLockNftScale: {
  platformScale: new BN(0),
  creatorScale: new BN(1_000_000),
  burnScale: new BN(0),
}

// 100% 소각; Fee Key 없음.
migrateCpLockNftScale: {
  platformScale: new BN(0),
  creatorScale: new BN(0),
  burnScale: new BN(1_000_000),
}
```

## CPMM 크리에이터 수수료와의 관계

스케일 필드는 LP 소유권만 제어합니다. 스왑 수수료율을 설정하거나 CPMM 크리에이터 수수료 수혜자를 식별하지 않습니다. `cpConfigId`는 CPMM `AmmConfig`를 선택하고, `platformCpCreator`는 CPMM 풀이 원래 런칭 크리에이터를 기록할지 플랫폼이 선택한 주소를 기록할지 결정합니다.

## 분배 비율 업데이트

플랫폼을 업데이트하기 전에:

- 세 값이 정확히 `1_000_000`으로 합산되는지 확인하세요.
- `platformScale + creatorScale`을 실제 플랫폼 지분으로 표시하세요.
- `creatorScale`을 기반으로 크리에이터 Fee Key를 약속하지 마세요.
- 업그레이드 이전에 완료된 마이그레이션에서 표시된 크리에이터 Fee Key 소유권을 유지하세요. 해당 기록은 다시 작성되지 않습니다.
- 향후 런칭에서 업데이트된 설정을 사용하기 전에 변경 사항을 설명하세요.
