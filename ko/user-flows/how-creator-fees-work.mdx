## 1단계: 본딩 곡선 크리에이터 수수료

토큰이 본딩 곡선에서 거래되는 동안 플랫폼은 매수 및 매도에 대해 크리에이터 수수료 구성 요소를 부과할 수 있습니다.

- 일반적으로 SOL인 견적 토큰으로 발생합니다.
- 플랫폼이 요율을 설정합니다.
- LaunchLab 크리에이터 수수료 청구 흐름을 통해 청구할 수 있습니다.
- 졸업은 새로운 본딩 곡선 발생을 중지합니다. 기존 잔액은 계속 청구 가능합니다.

## 2단계: CPMM 크리에이터 수수료

새로 초기화된 모든 런칭은 CPMM으로 졸업합니다. CPMM 크리에이터 수수료는 선택된 `AmmConfig`에 0이 아닌 크리에이터 수수료 요율이 있을 때만 발생합니다.

기본적으로 런칭 크리에이터가 CPMM 풀 크리에이터가 됩니다. 플랫폼은 대신 `platform_cp_creator`를 설정할 수 있으며, 이 경우 해당 주소가 CPMM 크리에이터 수수료 권리를 받습니다.

기록된 CPMM 크리에이터는 직접 청구할 수 있습니다. 다른 지불자도 권한 없는 수집을 트리거할 수 있지만 CPMM은 목적지를 크리에이터의 정규 토큰 계정으로 고정합니다.

## LP 토큰에 어떤 일이 발생하는가

플랫폼 구성은 `platformScale`, `creatorScale`, `burnScale`을 저장합니다. 2026-08-17 업그레이드 이전에는 `creatorScale`이 크리에이터 소유 Fee Key를 생성했습니다. 업그레이드 이후 실행된 마이그레이션의 경우 LaunchLab이 이를 `platformScale`과 결합합니다:

```text
platform locked LP = platformScale + creatorScale
burned LP          = burnScale
```

잠금된 지분이 0이 아닌 경우 하나의 Fee Key NFT가 플랫폼의 구성된 NFT 지갑으로 이동합니다. 이 NFT는 LP 수수료 수확을 제어합니다. CPMM 크리에이터 수수료 수집을 제어하지 않습니다. 업그레이드 완료 전에 마이그레이션된 크리에이터 Fee Key는 기존 보유자와 함께 유지됩니다.

## 수수료 흐름 요약

```text
본딩 곡선
  크리에이터 수수료 → 런칭 크리에이터 금고

CPMM으로 졸업
  업그레이드 이전 → 플랫폼 Fee Key + 크리에이터 Fee Key + 소각 지분
  업그레이드 이후  → 결합된 플랫폼 Fee Key 지분 + 소각 지분

CPMM 거래
  크리에이터 수수료 → 기록된 CPMM 풀 크리에이터
  LP 수수료      → 잠금된 지분에 대한 플랫폼 Fee Key 보유자
```

## 런칭하기 전에

- 본딩 곡선 `creator_fee_rate`를 확인하세요.
- `platform_cp_creator`가 CPMM 크리에이터 기록으로 당신을 대체하는지 확인하세요.
- 업그레이드 이후 실행된 마이그레이션의 경우 `creatorScale`을 약속된 크리에이터 Fee Key 할당으로 취급하지 마세요. 이전 마이그레이션의 경우 기존 Fee Key 기록을 확인하세요.
- CPMM 구성의 크리에이터 수수료 요율 및 수수료 설정을 확인하세요.
