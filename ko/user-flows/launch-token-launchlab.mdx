<Info>
  LaunchLab은 Raydium의 1차 시장 출시 플랫폼입니다. 프로젝트가 토큰 공급량을 본딩 곡선에 예치하면, 구매자들이 SOL(또는 다른 인용 민트)로 곡선을 상대로 거래합니다. 졸업 임계값에 도달하면 곡선의 자산이 자동으로 CPMM 풀로 이전되고 토큰이 자유롭게 거래 가능해집니다. 이 페이지는 프로젝트 관점에서 전체 흐름을 안내합니다.
</Info>

## 필요한 것

- **토큰 민트** — 판매하려는 토큰. 다음 조건으로 새로 발행되어야 합니다:
  - 전체 공급량이 지갑에 발행됨 (곡선에 예치할 수 있도록).
  - 출시 전에 민트 권한 폐기 (그렇지 않으면 새로운 발행으로 곡선 가격을 조작할 수 있음).
- **메타데이터** — 이름, 심볼, 이미지, 소셜 링크. Metaplex 메타데이터 또는 유사한 형식.
- **지갑** — 생성 렌트 + 볼트 펀딩 + 우선순위 수수료용 약 1 SOL (졸업 자체는 졸업자가 지불하며, 당신이 아님).
- **결정 사항**:
  - 곡선 유형 (이차 vs 가상 준비금 CPMM).
  - 졸업 임계값.
  - LP 처리 정책 (소각 / 잠금 / 생성자에게).
  - 초기 가격 및 상한.

## 곡선 선택

LaunchLab은 두 가지 곡선 계열을 지원합니다:

### 이차 곡선 (`curve_type = 0`)

가격이 판매된 공급량에 따라 이차적으로 증가합니다. 고전적인 "공정한 출시" 느낌 — 초기 구매자는 가격 이점을 얻고, 후기 구매자는 더 많이 지불하며, 가격이 부드럽게 가속합니다.

```
price(s) = a * s^2 + b * s + c
```

여기서 `s`는 판매된 공급량입니다. 일반적으로 `a > 0` (볼록). 초기 가격과 졸업 가격 사이의 스프레드는 `a, b, c`와 상한이 주어지면 결정론적입니다.

최적: 신규 출시, 밈, 커뮤니티 중심 프로젝트.

### 가상 준비금 CPMM (`curve_type = 1`)

*가상* 준비금을 사용하여 상수곱 AMM을 에뮬레이트합니다 — 곡선은 `x * y = k`인 CPMM처럼 동작하지만 풀은 절대 인출되지 않는 합성 토큰으로 시작합니다.

```
price = virtual_quote_reserve / virtual_base_reserve
```

구매자가 구매하면 `virtual_base_reserve`는 감소하고 `virtual_quote_reserve`는 증가합니다 — 곡선은 졸업 후 CPMM과 동일하게 보입니다. 더 부드러운 전환.

최적: 졸업 후 예측 가능한 가격 연속성을 원하는 출시.

## UI 안내

[raydium.io/launchpad/create](https://raydium.io/launchpad/create)에서:

1. **토큰.** 민트 주소를 붙여넣습니다. UI가 메타데이터를 가져와 표시합니다.
2. **곡선 유형.** 이차 또는 가상 CPMM을 선택합니다. UI가 각각에 대한 가격 차트 미리보기를 표시합니다.
3. **졸업 임계값.** 기본값: 곡선은 `total_base_supply`의 모든 것이 판매된 후 종료됩니다. 대안: 특정 `graduation_quote_amount`에서 종료 (예: 85 SOL).
4. **인용 민트.** SOL (기본값), USDC 또는 다른 민트. SOL이 표준입니다.
5. **LP 처리 정책:**
   - **소각** — LP 토큰이 졸업 시 사용 불가능한 주소로 전송됩니다. 생성자는 유동성을 인출할 수 없습니다. 사용자는 풀을 영구적으로 신뢰합니다.
   - **잠금** — LP 토큰이 `lock_duration` 동안 시간 잠금 에스크로로 전송됩니다.
   - **생성자에게** — LP 토큰이 생성자에게 전송됩니다. 가장 유연하고 신뢰 최소화가 가장 적습니다.

   가장 존경받는 출시는 소각을 사용합니다.

6. **검토.** UI가 요약을 표시합니다: 예상 가격 범위, 곡선이 매진되면 초기 모금액, 졸업 CPMM 설정.
7. **서명.** 한 거래가 출시 상태 + 기본 볼트 + 인용 볼트를 생성하고 `total_base_supply`를 지갑에서 기본 볼트로 전송합니다.

## 프로그래밍 방식 안내

곡선 형태, 인용 민트, 모금 목표 및 LP 처리 정책은 **인수가 아닙니다** — 바인딩하는 `GlobalConfig`와 출시가 실행되는 `PlatformConfig`에서 옵니다. 전달하는 것은 민트의 신원, 바인딩할 설정, 그리고 선택적으로 첫 번째 구매입니다:

```ts
import {
  Raydium,
  TxVersion,
  LAUNCHPAD_PROGRAM,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";
import BN from "bn.js";

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });
const programId = LAUNCHPAD_PROGRAM;

// 기본 민트의 키페어를 생성하고 서명합니다.
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// 설정 바인딩: (인용 민트, curve_type, 인덱스). 이것이 곡선
// 형태, 인용 민트 및 모금 목표를 고정합니다.
const configId   = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
const configInfo = LaunchpadConfig.decode(configData!.data);
const mintBInfo  = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "My New Token",
  symbol: "MYNEW",                    // 10자 이하
  uri:    "https://example.com/metadata.json",
  migrateType: "amm",                 // "amm" | "cpmm"

  configId,
  configInfo,
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  createOnly: true,                   // true = 첫 번째 구매 없이 민트 생성
  buyAmount:  new BN(1000),
  slippage:   new BN(100),            // 100 = 1%

  extraSigners: [pair],               // 기본 민트 키페어가 서명해야 함
  txVersion: TxVersion.V0,
  computeBudgetConfig: { units: 400_000, microLamports: 50_000 },
});

// createLaunchpad는 여러 거래를 반환합니다 - 순서대로 실행하세요.
const { txIds } = await execute({ sequentially: true });
console.log("Pool ID:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
```

`raydium.api.fetchLaunchConfigs()`는 기본 공급량, 판매량 및 모금 목표와 함께 사용 가능한 설정을 나열하므로 서명하기 전에 사용자에게 주어진 설정이 의미하는 바를 보여줄 수 있습니다. Token-2022 변형을 포함한 완전히 주석이 달린 버전: [`products/launchlab/code-demos`](/ko/products/launchlab/code-demos#create-a-launch).

## 졸업 전 모니터링

API를 통해 활동을 추적합니다:

LaunchLab은 `api-v3.raydium.io`와 별도의 자체 API 호스트를 가지고 있습니다:

```ts
// 민트 수준 정보, 기본 민트로 키 지정 (배치의 경우 쉼표로 구분).
const r = await fetch(
  `https://launch-mint-v1.raydium.io/get/by/mints?ids=${mintA.toBase58()}`,
).then((r) => r.json());
console.log(r.data.rows[0]);

// 또한 사용 가능: 같은 호스트의 /main/configs (설정 목록), 그리고
// https://launch-history-v1.raydium.io/kline 및 /trade (가격 및 체결).
```

또는 온체인 상태를 직접 읽습니다. 풀 ID는 `(programId, mintA, mintB)`의 PDA입니다:

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log({
  status:      poolInfo.status,
  baseSold:    poolInfo.realA.toString(),
  totalSellA:  poolInfo.totalSellA.toString(),
  quoteRaised: poolInfo.realB.toString(),
  raiseTarget: poolInfo.totalFundRaisingB.toString(),
});
```

진행 상황은 모금액의 분수보다는 **가격** 용어로 표현하는 것이 가장 좋습니다. 곡선이 비선형이기 때문입니다. 데모 저장소의 [`getFinishRate.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/getFinishRate.ts)는 `Curve.getPrice`, `Curve.getPoolEndPriceReal` 및 `Curve.getPoolInitPriceByPool`로 이를 수행합니다:

```
finishRate = (currentPrice − initPrice) / (endPrice − initPrice)   // 1로 제한됨
```

### 모니터링할 지표

- **판매 관통율**: 판매된 기본 토큰의 백분율. 졸업 임계값은 일반적으로 80–100% 판매 시점입니다.
- **현재 가격**: 현재 `baseSold`에서 곡선에서 파생됨.
- **고유 구매자**: 인덱서를 통한 서로 다른 지불자의 수.
- **매수 대 매도 비율**: 초기 출시는 느려지는 강한 매수 압력을 봅니다.

24시간 후 판매 관통율이 `<10%`이면 마케팅이 적절한지 고려하세요. LaunchLab은 과소 홍보된 출시를 구제하지 않습니다.

## 졸업

졸업은 별도의 거래이며 **누구나** 호출할 수 없습니다: `MigrateToCpswap`과 레거시 `MigrateToAmm`은 각각 서명자가 바인딩 `GlobalConfig`에 기록된 지갑과 일치해야 하며 (`migrate_to_cpswap_wallet` / `migrate_to_amm_wallet`), 다른 서명자는 `InvalidOwner`를 받습니다. 보상금이 없습니다. 이러한 지갑은 Raydium의 졸업 크랭크에 의해 실행되며, 임계값이 넘어간 후 몇 초 내에 마이그레이션을 수행합니다. 초기 설정 이상으로 생성자로서 필요한 조치가 없습니다.

### 졸업이 하는 것

1. 볼트 잔액을 읽습니다.
2. 곡선을 닫습니다 (더 이상 매수/매도 불가).
3. 볼트 잔액을 초기 유동성으로 하는 새로운 CPMM 풀을 생성합니다.
4. 볼트 잔액을 기반으로 초기 LP 토큰을 발행합니다.
5. 설정된 정책에 따라 LP 토큰을 처리합니다 (소각 / 잠금 / 생성자에게).

졸업 후 CPMM 풀이 활성화되고 일반 Raydium 라우팅을 통해 거래됩니다.

### 졸업 모니터링

풀 상태의 `status`를 감시하고 변경될 때 UI를 전환합니다:

```ts
const before = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

setInterval(async () => {
  const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
  if (p.status !== before) console.log("migrated - switch to the CPMM pool page");
}, 10_000);
```

졸업된 풀의 주소는 `(cpswap config, token0, token1)`의 CPMM PDA이므로 보고될 때까지 기다리지 않고 파생할 수 있습니다. 인덱서의 경우 폴링 대신 gRPC를 통해 구독하세요 — [`products/launchlab/code-demos`](/ko/products/launchlab/code-demos#watch-configs-and-pools-over-grpc)를 참조하세요.

생성자 또는 제3자를 위한 "수동 졸업" 경로가 없습니다. 출시가 임계값을 넘었는데 마이그레이션되지 않았다면, 이는 클라이언트에서 강제할 수 없는 마이그레이션 지갑의 운영 문제입니다.

## 졸업 후

### CPMM 풀 검증

```ts
const pool = await raydium.cpmm.getPoolInfoFromRpc({ poolId: cpmmPoolId });
console.log("CPMM price:", pool.poolInfo.price);
console.log("CPMM TVL:  ", pool.poolInfo.tvl);
```

CPMM 풀은 (대략) 다음을 가져야 합니다:

- 기본 토큰 잔액: `total_base_supply - baseSold` + 곡선 잔여.
- 인용 토큰 잔액: `quoteRaised - graduationFee`.
- 가격: 마지막 곡선 가격과 일치.

### LP 처리 검증

- **소각**: LP 민트의 공급량이 1nc1nerator11111111111111111111111111111111 또는 유사한 주소로 전송됨을 표시합니다.
- **잠금**: 잠금 해제 타임스탬프가 있는 에스크로 PDA의 LP 토큰.
- **생성자에게**: 생성자의 지갑의 LP 토큰.

### 생성자 수수료 수집

생성자 수수료 공유를 설정한 경우 주기적으로 호출합니다:

빌더는 `claimCreatorFee`이며, **출시**가 아닌 **인용 민트**로 키 지정됩니다 — 한 번의 호출이 해당 민트에서 누적된 생성자 수수료를 모두 수집합니다:

```ts
import { NATIVE_MINT } from "@solana/spl-token";

await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,      // 청구할 인용 민트
  txVersion: TxVersion.V0,
});
```

민트 전체에 배치하려면 `claimMultipleCreatorFee`를 사용합니다. 수수료는 졸업 전 곡선 거래에서 누적되며, 졸업 후 플랫폼의 `platform_cp_creator`가 당신을 기록된 풀 생성자로 남겨두면 CPMM 풀의 생성자 수수료 경로에서 누적됩니다 — [`products/launchlab/platform-config`](/ko/products/launchlab/platform-config)를 참조하세요.

## 공지 체크리스트

졸업 후 공지에는 다음이 포함되어야 합니다:

- [ ] 졸업 거래 해시.
- [ ] 새로운 CPMM 풀 ID.
- [ ] LP 처리 증명 (소각 거래 / 잠금 거래 / 생성자 지갑).
- [ ] 애그리게이터 커버리지 ETA (지갑은 일반적으로 5분 내에 인덱싱).
- [ ] 토큰 계약 검증 (공지 채널 전체에서 민트 주소 일치).

## 함정

### 1. 민트 권한이 폐기되지 않음

`baseMint.mintAuthority`가 여전히 당신이 제어하는 키라면, 새로운 공급량을 발행하고 자신의 곡선에 판매할 수 있습니다. 권한을 폐기하지 않은 출시는 일반적으로 애그리게이터 및 상장 사이트에서 고위험 또는 미검증으로 표시됩니다. 출시 전에 폐기하세요.

### 2. 잘못된 곡선 매개변수

`a`가 너무 높은 이차 곡선은 초기 토큰을 무료로 만들고 (가격 ≈ 0) 후기 토큰을 터무니없게 만듭니다. `a`가 너무 낮은 곡선은 곡선을 거의 선형으로 만듭니다 ("본딩" 느낌 상실). 먼저 devnet에서 매개변수를 테스트하세요.

### 3. 졸업 임계값이 너무 높음

졸업이 현실적인 수요보다 더 많은 자본을 요구하면 곡선이 졸업되지 않고 구매자는 곡선에만 다시 판매할 수 있는 토큰에 갇힙니다 (더 나쁜 가격으로). 실제로 달성할 수 있는 임계값을 선택하세요.

### 4. 인용 민트 사기

인용 민트가 사용자 정의 토큰 (SOL/USDC 아님)이면 사용자가 신뢰하지 않을 것입니다. 인용으로 SOL 또는 USDC를 사용하세요.

### 5. 기본 볼트 펀딩을 잊음

SDK는 생성 시 `totalBaseSupply`를 지갑에서 전송합니다. 지갑에 없으면 거래가 되돌려집니다. 서명하기 전에 잔액을 확인하세요.

### 6. LP 처리 = 소각은 되돌릴 수 없음

LP가 1nc1nerator로 전송되면 *당신을 포함한* 아무도 유동성을 인출할 수 없습니다. 이것이 요점입니다 — 신뢰 최소화. 확실하지 않으면 소각을 선택하지 마세요.

### 7. 졸업 후 CPMM 수수료 계층

졸업된 풀은 LaunchLab의 기본 CPMM 설정 (0.25%)을 사용합니다. 1% 또는 0.01%를 원했다면 졸업 후 직접 두 번째 CPMM 풀을 생성하고 유동성을 마이그레이션해야 합니다 — 번거롭고 분산됩니다. 기본값을 수용하거나 LaunchLab 대신 직접 CPMM 생성을 통해 출시하세요.
