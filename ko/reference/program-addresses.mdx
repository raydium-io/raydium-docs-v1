### 공유 관리자 권한

모든 Anchor 기반 프로그램(CLMM, CPMM, LaunchLab, Lock)은 관리자 경로(예: `CreateAmmConfig` 또는 `UpdatePoolStatus`)에 대한 명령 수준 접근 제어를 위해 단일 하드코딩된 관리자 `Pubkey`를 공유합니다:

| 클러스터 | 관리자 |
|---------|-------|
| mainnet-beta | `GThUX1Atko4tqhN2NaiTazWSeFWMuiUvfFnyJyUghFMJ` |
| devnet | `DRayqG9RXYi8WHgWEmRQGrUWRWbhjYWYkCRJDd6JBBak` |

계정 수준 운영 권한(예: CPMM/CLMM `AmmConfig`의 `protocol_owner`, `fund_owner` 또는 LaunchLab `GlobalConfig`의 마이그레이션 지갑)은 온체인에 저장되며 프로그램 관리자와 다를 수 있습니다. 높은 위험도의 거래를 보내기 전에 관련 구성 계정에서 직접 읽으세요.

### 공유 구성 / PDA 규칙

여러 Raydium 프로그램은 공개 키가 안정적이고 공개 API에 나열된 **구성 계정**을 노출합니다. 하드코딩보다 API 조회를 선호하세요:

```
# CPMM 수수료 구성 (배열 반환 {id, index, tradeFeeRate, ...})
GET https://api-v3.raydium.io/main/cpmm-config

# CLMM 수수료 구성
GET https://api-v3.raydium.io/main/clmm-config
```

기본 CPMM `AmmConfig` 인덱스 `0`(표준 0.25% 풀) 수수료 매개변수, 참고용:

| 필드 | 값 | 의미 |
|-------|-------|---------|
| `trade_fee_rate` | `2500` | 거래량의 0.25% |
| `protocol_fee_rate` | `120000` | 거래 수수료의 12% **(거래량이 아님)** 프로토콜로 라우팅됨 |
| `fund_fee_rate` | `40000` | 거래 수수료의 4% 펀드 멀티시그로 라우팅됨 |
| `creator_fee_rate` | `500` | 거래량의 0.05% 풀 생성자에게 (선택 사항) |

분할이 어떻게 구성되는지는 [`products/cpmm/fees`](/ko/products/cpmm/fees)를 참조하고, 교차 제품 매트릭스는 [`reference/fee-comparison`](/ko/reference/fee-comparison)을 참조하세요.

### PDA 시드

아래 시드는 **정규**이며 SDK 및 온체인 CPI 모두에서 사용됩니다. 항상 PDA를 계산하세요. 파생된 주소를 하드코딩하지 마세요.

```ts
// CPMM — 모든 시드는 명시되지 않은 한 정적 ASCII 문자열입니다.
const [ammConfig]   = PublicKey.findProgramAddressSync(
  [Buffer.from("amm_config"), u16ToBytes(index)],
  CPMM_PROGRAM_ID,
);
const [authority]   = PublicKey.findProgramAddressSync(
  [Buffer.from("vault_and_lp_mint_auth_seed")],
  CPMM_PROGRAM_ID,
);
const [poolState]   = PublicKey.findProgramAddressSync(
  [Buffer.from("pool"), ammConfig.toBuffer(), token0Mint.toBuffer(), token1Mint.toBuffer()],
  CPMM_PROGRAM_ID,
);
const [lpMint]      = PublicKey.findProgramAddressSync(
  [Buffer.from("pool_lp_mint"), poolState.toBuffer()],
  CPMM_PROGRAM_ID,
);
const [vault0]      = PublicKey.findProgramAddressSync(
  [Buffer.from("pool_vault"), poolState.toBuffer(), token0Mint.toBuffer()],
  CPMM_PROGRAM_ID,
);
const [vault1]      = PublicKey.findProgramAddressSync(
  [Buffer.from("pool_vault"), poolState.toBuffer(), token1Mint.toBuffer()],
  CPMM_PROGRAM_ID,
);
const [observation] = PublicKey.findProgramAddressSync(
  [Buffer.from("observation"), poolState.toBuffer()],
  CPMM_PROGRAM_ID,
);
```

`token0Mint` / `token1Mint`는 해싱 전에 **공개 키 바이트 순서로 정렬됩니다**(token0 < token1). 이를 잘못하면 존재하지 않는 풀에 대한 유효한 PDA가 생성됩니다.

동등한 CLMM 시드는 동일한 스타일을 따릅니다. [`products/clmm/accounts`](/ko/products/clmm/accounts)를 참조하세요.

## 온체인에서 주소를 확인하는 방법

1. **Solana Explorer.** 주소를 [explorer.solana.com](https://explorer.solana.com)에 붙여넣고 `Program`으로 표시되고 현재 업그레이드 권한이 있는지 확인하세요. Mainnet-beta는 Raydium의 업그레이드 권한으로 서명된 배포를 표시해야 합니다.
2. **CLI.** `solana program show <PROGRAM_ID> -u mainnet-beta`를 사용하여 배포 슬롯, BPF 로더, 업그레이드 권한 및 데이터 길이를 검사하세요. 이를 실행 설명서에 기록하세요.
3. **IDL 첨부.** `anchor idl fetch <PROGRAM_ID> --provider.cluster mainnet`으로 온체인 IDL을 쿼리하세요. IDL의 `address` 필드가 일치해야 합니다. 동일한 IDL은 [github.com/raydium-io/raydium-idl](https://github.com/raydium-io/raydium-idl)에 미러링됩니다 — 신뢰하기 전에 온체인 IDL을 저장소와 비교하세요.
4. **구성/관리자 권한.** CPMM/CLMM 구성 계정의 경우 `owner`/`protocol_owner` 필드를 읽고 [`security/admin-and-multisig`](/ko/security/admin-and-multisig)에 게시된 현재 Raydium 멀티시그와 일치하는지 확인하세요.

위의 네 가지 확인 중 하나라도 이 페이지와 불일치하면 이 페이지를 잘못된 것으로 취급하고 새 코드를 주소에 대해 작성하기 전에 문제를 열어주세요.

## 이 페이지 업데이트

- 프로그램 ID 변경은 안전 관련 사항입니다. 프로그램 ID 변경을 배포하지 마세요. (a) Raydium 공지로 링크, (b) [`reference/changelog`](/ko/reference/changelog)에 항목 추가, (c) 문서에 대한 링크 확인을 실행하여 이전 값을 여전히 참조하는 페이지가 없는지 확인하지 않고.
- 지원 중단은 삭제되지 않고 상태 메모와 함께 표에 유지됩니다 — 기존 풀은 여전히 이전 프로그램을 통해 해결됩니다.
