## 릴리스

<Update label="2026-08-17" description="LaunchLab: CPMM 전용 런칭 및 플랫폼 설정 제어">
  새로운 런칭 초기화는 이제 CPMM을 필수로 요구하며, 레거시 AMM v4 바인딩 상태는 계속 마이그레이션 가능합니다. 이 릴리스 이전에는 `creator_scale`이 크리에이터 소유 Fee Key를 생성했지만, 업그레이드 후 실행된 CPMM 마이그레이션은 `platform_scale + creator_scale`을 하나의 플랫폼 소유 Fee Key 공유로 통합합니다. 플랫폼은 자체 `PlatformAllowConfig` PDA로 런칭을 제한할 수도 있으며, 마이그레이션 빌더는 CPMM 지원 민트 PDA를 모두 추가해야 합니다.

  [전체 항목 읽기 →](/ko/reference/changelog/2026-08-17-launchlab-cpmm-only-platform-config)
</Update>

<Update label="2026-08-17" description="CLMM: 제한된 발급자 포지션 NFT 동결">
  새로운 CLMM 포지션 NFT 민트는 풀을 동결 권한으로 사용하지만, 토큰 계정은 기본적으로 동결되지 않습니다. 동결은 `OpenPositionV2` 또는 `OpenPositionWithToken22Nft`에서만 발생하며, 기본 볼트 민트의 동결 권한이 제한된 발급자 목록과 일치할 때만 발생합니다. 일치하는 포지션은 전송하거나 소유자를 변경할 수 없지만 여전히 유동성을 관리할 수 있습니다. `ClosePosition` 호출은 CLMM이 원자적으로 해제, 소각 및 종료할 수 있도록 풀을 추가해야 합니다. 기존 포지션은 변경되지 않습니다.

  [전체 항목 읽기 →](/ko/reference/changelog/2026-08-17-clmm-restricted-position-nft-freeze)
</Update>

<Update label="2026-08-17" description="CPMM: 무허가 크리에이터 수수료 수집">
  추가 `CollectCreatorFeePermissionless` 명령어를 통해 누구든지 모든 누적된 크리에이터 수수료를 수집할 수 있으며, 수혜자와 두 토큰 목적지를 `PoolState.pool_creator` 및 크리에이터의 정규 ATA로 제한합니다. 원래의 크리에이터 서명 경로는 변경되지 않습니다. `CreatePermissionPda`는 또한 전용 부여 권한을 수락하며, `ClosePermissionPda`는 관리자 전용으로 유지됩니다.

  [전체 항목 읽기 →](/ko/reference/changelog/2026-08-17-cpmm-permissionless-creator-fee-collection)
</Update>

<Update label="2026-07-30" description="CLMM: 허가된 다중 풀 및 리미트 오더 동결 계정 보호">
  두 가지 추가적이고 하위 호환성이 있는 CLMM 프로그램 업데이트입니다. `CreatePermissionedPool`은 클라이언트 제공 0이 아닌 `seed_index`를 풀 PDA 시드에 포함시켜, 화이트리스트된 운영자(Permission PDA를 보유한 운영자)가 `(config, mint0, mint1)` 당 여러 풀을 생성할 수 있도록 합니다. 따라서 풀 ID는 더 이상 쌍에 대한 정규 식별자가 아닙니다. 새로운 관리자 명령어 `CreatePermissionPda` / `ClosePermissionPda`는 이러한 부여를 관리하며, `PoolState`는 `seed_index` 필드를 얻습니다(패딩에서 추출되어 크기 변경 없음). 별도로, `OpenLimitOrder`는 이제 출력 측 계정을 가져가며 입력 또는 출력 토큰 계정이 동결된(`NotApproved`) 주문을 거부합니다.

  [전체 항목 읽기 →](/ko/reference/changelog/2026-07-30-clmm-permissioned-pools)
</Update>

<Update label="2026-07-22" description="AMM v4: OpenBook / Serum 의존성 제거">
  AMM v4는 오래된 OpenBook/Serum 의존성, 모든 오더북 CPI, 그리고 죽은 마켓 메이킹 명령어를 제거합니다. `SwapBaseIn` / `SwapBaseOut`, `Deposit`, `Withdraw`는 레이아웃을 유지합니다(제거된 마켓 계정은 이제 무시되며 검증되지 않음). **하드 브레이킹** `WithdrawPnl`(17 → 10, 호환성 없음) 및 `SetParams`(계정 감소 + 재번호 매김된 `param`). `Initialize`, `PreInitialize`, `MonitorStep`, `MigrateToOpenBook`, `WithdrawSrm`, `SimulateInfo`, `AdminCancelOrders`는 더 이상 호출할 수 없습니다. 온체인 계정 레이아웃 및 오류 코드는 안정적으로 유지됩니다. 스왑을 V2 엔트리포인트로 마이그레이션하세요.

  [전체 항목 읽기 →](/ko/reference/changelog/2026-07-22-amm-v4-openbook-removal)
</Update>

<Update label="2026-06-22" description="Stable AMM: 죽은 OpenBook(마켓) 코드 제거">
  Stable AMM은 오래된 OpenBook 마켓 메이킹 계정 및 코드를 제거합니다. 더 작은 `SwapBaseIn` / `SwapBaseOut`(18 → 9), `Deposit`(14 → 12), `Withdraw`(21/22 → 12) 레이아웃(이전 레이아웃은 여전히 호환됨). **하드 브레이킹** `WithdrawPnl` 변경(16 → 10, 호환성 없음). 레퍼럴 수수료 폐지 및 단순화된 볼트 전용 풀 자산 공식입니다. 대부분의 다른 Stable 명령어는 더 이상 호출할 수 없습니다.

  [전체 항목 읽기 →](/ko/reference/changelog/2026-06-22-stable-amm-openbook-cleanup)
</Update>

<Update label="2026-05-18" description="CLMM: 리미트 오더, 단측 수수료, 동적 수수료">
  세 가지 선택적이고 하위 호환성이 있는 CLMM 기능입니다. 일급 리미트 오더(`limit_order_admin` 정산 키퍼 포함), 단측 수수료 수집(`CollectFeeOn`), 변동성 추적 동적 수수료입니다. `CreateCustomizablePool`, `PoolState` 재구성(**인덱서 브레이킹 변경**), 새로운 `TickState` 필드, 11개의 새로운 오류 코드(숫자 시프트 포함), 그리고 일치하는 SDK / API 추가를 포함합니다.

  [전체 항목 읽기 →](/ko/reference/changelog/2026-05-18-clmm-limit-orders)
</Update>

## 문서 규칙

- **버전 관리**: 이 문서는 달력 기반 버전 관리(YYYY-MM-DD)를 사용합니다. 각 업데이트는 새로운 항목 페이지를 추가하고 위의 타임라인에 새로운 행을 추가합니다.
- **릴리스당 한 페이지**: 모든 릴리스 요약은 `reference/changelog/` 아래의 자체 페이지에 있으므로 이 인덱스는 짧게 유지되고 각 항목은 독립적으로 링크 가능합니다.
- **검증 날짜**: 모든 항목은 온체인 / API 상태 및 프로그램 소스에 대해 마지막으로 교차 검증된 시기를 기록합니다. 명시되지 않은 경우 항목의 주요 날짜를 가정하세요.
- **브레이킹 변경**: 영향을 받는 페이지의 상자 경고에서 호출되고 항목에 태그됩니다.
- **범위**: 이 변경 로그는 문서 집합 자체를 다룹니다. 프로토콜 자체의 역사적 타임라인은 [`introduction/history-and-milestones`](/ko/introduction/history-and-milestones)에 있으며 "Raydium에서 X가 언제 발생했는가"에 대한 진실의 원천입니다.
