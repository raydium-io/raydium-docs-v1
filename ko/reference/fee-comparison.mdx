## 상품별 스왑 수수료

수수료 값은 입력 금액의 백분율이며, 풀 계산 전에 적용됩니다.

| 상품 | 사용 가능한 단계 | 기본값 / 가장 많이 사용 | 분배 |
|---------|-----------------|---------------------|-------|
| **AMM v4** | 0.25% (유일) | 0.25% | 88% LP, 12% 프로토콜 (25의 22/3) |
| **CPMM** | 0.01%, 0.25%, 1% | 0.25% | 100% LP (프로토콜 분배는 AmmConfig당 설정 가능, 현재 0%) |
| **CLMM** | 0.01%, 0.05%, 0.25%, 1% | 0.25% | 88% LP, 12% 프로토콜 |
| **LaunchLab (졸업 전)** | 1% (기본값) | 1% | 50% 풀 시드, 50% LaunchLab 재무 |
| **LaunchLab (졸업 후 CPMM)** | 0.25% | 0.25% | CPMM 분배 상속 |

### 수수료 분모 규칙

- **AMM v4**: 수수료는 x/10,000으로 인코딩됩니다. "25"는 0.25%를 의미합니다.
- **CPMM/CLMM**: 수수료는 x/1,000,000으로 인코딩됩니다. "2500"은 0.25%를 의미합니다.

온체인 데이터를 직접 읽을 때는 풀의 프로그램에 맞는 분모를 사용하세요.

## 프로토콜 수수료 분배

각 수수료의 "프로토콜" 분배 내에서 추가 분배가 적용됩니다:

| 상품 | 스왑 수수료 중 프로토콜 분배 | 프로토콜 내 분배 |
|---------|----------------------------|------------------------|
| AMM v4 | 12% (3/25) | 100% 재무로 |
| CPMM | AmmConfig당 설정 가능 (현재 0%) | N/A |
| CLMM | 스왑 수수료의 12% | 100% 재무로 |
| LaunchLab | 졸업 전 스왑 수수료의 50% | 100% LaunchLab 재무로 |

**LP 분배**는 LP 토큰 보유자에게 자동으로 흐릅니다:

- AMM v4 / CPMM: 풀 준비금에 누적되며, 출금 시 비례적으로 분배됩니다.
- CLMM: `fee_growth_global_X/Y`에 누적되며, `collectFee`를 통해 청구 가능합니다.

## 생성 비용

풀을 배포하기 위해 SOL로 지불하는 일회성 비용입니다.

| 상품 | 렌트 비용 | 생성 수수료 | 일반적인 총액 |
|---------|-----------|--------------|---------------|
| AMM v4 | ~0.15 SOL (여러 계정) | 0.2 SOL | ~0.35 SOL |
| CPMM | ~0.04 SOL (풀 + 볼트 + 관찰) | 0.15 SOL | ~0.19 SOL |
| CLMM | ~0.075 SOL (풀 + 관찰 + 초기 틱 배열) | 0 SOL | ~0.075 SOL |
| Farm v6 | ~0.02 SOL (팜 상태 + 보상 볼트) | 0.1 SOL (스팸 방지) | ~0.12 SOL |
| LaunchLab 런칭 | ~0.015 SOL (본딩 곡선 계정) | 0.1 SOL (LaunchLab 수수료) | ~0.115 SOL |

모든 렌트는 회수 가능합니다 — 풀 / 포지션 / 팜을 종료하면 램포트가 반환됩니다.

## 졸업 / 마이그레이션 비용

| 이벤트 | 비용 | 지불자 |
|-------|------|----------|
| LaunchLab → CPMM 졸업 | ~0.04 SOL (새 CPMM 풀 생성) | 본딩 곡선 준비금에서 지불 |
| AMM v4 → CPMM 마이그레이션 | ~0.04 SOL CPMM 생성 + ~0.000005 SOL 트랜잭션 수수료 | 마이그레이션을 수행하는 LP |
| CLMM 포지션 NFT 전송 | ~0.000005 SOL 트랜잭션 수수료; 동결된 제한된 발행자 포지션은 불가능 | 전송자 |

## 일반적인 작업당 네트워크 수수료

이는 Solana 기본 + 우선순위 수수료이며, Raydium 프로토콜 수수료와는 별개입니다.

| 작업 | CU | 기본 수수료 | 우선순위 수수료 (10k µL/CU) | 총 네트워크 |
|-----------|-----|----------|---------------------------|---------------|
| CPMM 스왑 | ~140,000 | 0.000005 SOL | 0.0014 SOL | ~0.0015 SOL |
| CLMM 스왑 (틱 없음) | ~170,000 | 0.000005 SOL | 0.0017 SOL | ~0.0017 SOL |
| CLMM 스왑 (4개 틱 교차) | ~320,000 | 0.000005 SOL | 0.0032 SOL | ~0.0032 SOL |
| CLMM 포지션 열기 | ~280,000 | 0.000005 SOL | 0.0028 SOL | ~0.0028 SOL |
| Farm v6 스테이킹 | ~130,000 | 0.000005 SOL | 0.0013 SOL | ~0.0013 SOL |
| 팜 보상 청구 | ~160,000 | 0.000005 SOL | 0.0016 SOL | ~0.0016 SOL |
| v4 → CPMM 마이그레이션 (2 트랜잭션) | ~200,000 + ~200,000 | 0.00001 SOL | 0.004 SOL | ~0.004 SOL |

우선순위 수수료는 CU 가격에 따라 선형으로 조정됩니다. [`integration-guides/priority-fee-tuning`](/ko/integration-guides/priority-fee-tuning)을 참고하세요.

## Token-2022 수수료 상호작용

풀의 한쪽 또는 양쪽이 전송 수수료가 있는 Token-2022를 사용할 때, 유효 수수료가 누적됩니다:

```
net input to pool   = amount_in × (1 − transfer_fee_in)
pool charges swap   = net × swap_fee_rate
net output to user  = out × (1 − transfer_fee_out)
```

예시: CPMM 0.25% 풀, 입력 측에 1% 전송 수수료, 출력 측에 0.5% 전송 수수료가 있는 경우.

```
amount_in        = 1000
net_to_pool      = 1000 × 0.99    = 990
pool swap fee    = 990 × 0.0025   = 2.475 (LP 수수료로 유지)
amount_after_fee = 987.525
amount_out (AMM) = 987.525 × ratio, say 987.525 × 0.98 = 967.77
net_out_to_user  = 967.77 × 0.995 = 962.94
```

유효 수수료: **~3.7%** (명목상 0.25% 풀 수수료에도 불구하고).

SDK는 `getComputeAmountOut`을 통해 유효 비율을 계산합니다 — Token-2022 풀을 견적할 때 항상 이를 사용하세요.

## LaunchLab 세부사항

| 단계 | 수수료 |
|-------|-----|
| 본딩 곡선 거래 (구매 또는 판매) | 1% (50/50 풀/재무 분배) |
| 졸업 (일회성) | 곡선 준비금에서 ~0.04 SOL |
| 졸업 후 (CPMM 풀) | 0.25% (표준 CPMM 수수료) |

토큰을 런칭하는 프로젝트는 본딩 곡선 단계 중에 크리에이터 수수료를 포함할 수 있습니다. 졸업 후, 선택된 CPMM 설정은 기록된 풀 크리에이터에 대해 별도의 CPMM 크리에이터 수수료도 청구할 수 있습니다. 플랫폼 소유 Fee Key는 LP 수수료 권리를 나타내며 크리에이터 수수료 자격증명이 아닙니다. [`products/launchlab/creator-fees`](/ko/products/launchlab/creator-fees)를 참고하세요.

## Farm v6 보상 비용 모델

팜은 엄밀히 말해 수수료를 청구하지 않습니다 — 보상 분배입니다. 하지만 운영에 SOL이 필요합니다:

| 비용 | 일반적인 값 |
|------|---------|
| 팜 생성 | 0.1 SOL 스팸 방지 + ~0.02 SOL 렌트 |
| 보상 볼트 충전 | 토큰만 + ~0.0005 SOL 트랜잭션 |
| 미사용 보상 회수 | ~0.0005 SOL 트랜잭션 |

팜은 또한 팜의 수명 동안 렌트를 충당하기에 충분한 램포트가 보상 볼트에 필요합니다. 종료하면 반환됩니다.

## 온체인에서 현재 값을 읽는 방법

### CPMM/CLMM AmmConfig

```ts
const config = await raydium.cpmm.getAmmConfigs();
console.log(config[0]);
// {
//   id: "...",
//   tradeFeeRate: 2500,         // 2500 / 1_000_000 = 0.25%
//   protocolFeeRate: 0,         // 0 / 1_000_000 = 0%
//   fundFeeRate: 0,
//   ...
// }
```

### AMM v4 풀

```ts
const poolInfo = await raydium.liquidity.getPoolInfoFromRpc({ poolId });
console.log(poolInfo.ammFeesNumerator, poolInfo.ammFeesDenominator);
// 25, 10000 → 0.25%
```

### Farm v6 보상 비율

```ts
const farm = await raydium.farm.getFarmInfoFromRpc({ id: farmId });
console.log(farm.farmData.rewardInfos);
// Per-reward: emissionsPerSecond, startTime, endTime
```
