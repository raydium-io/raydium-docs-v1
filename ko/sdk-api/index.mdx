## 이 장의 대상

오프체인(TS/JS, Python, 백엔드)에서 Raydium과 통합하거나 다른 Solana 프로그램(Rust CPI)에서 호출하는 개발자를 위한 내용입니다. AI 에이전트와 코딩 도구 통합자도 포함됩니다. [AI 통합](/ko/sdk-api/ai-integration)을 참고하세요.

<Info>
  **먼저 실행해 보고 싶으신가요?** 스왑, CPMM 풀 배포, CLMM 풀 배포의 세 가지 엔드-투-엔드 스크립트는 [빠른 시작](/ko/quick-start)에 있습니다. 스왑과 CPMM 스크립트는 복사해서 바로 실행할 수 있는 단일 파일이고, CLMM 흐름은 몇 가지 추가 단계가 필요합니다. 먼저 실제 트랜잭션을 실행한 후 여기로 돌아와 전체 레퍼런스를 확인하세요.
</Info>

## 통합 경로 선택

5가지 경로 중에서 선택할 수 있습니다. 올바른 경로는 Raydium을 호출하는 것이 무엇인지, 그리고 얼마나 많은 제어가 필요한지에 따라 달라집니다.

| 경로 | 최적 사용 사례 | 지연 시간 | 커스텀 로직 | 언어 |
|---|---|---|---|---|
| [Trade API](/ko/sdk-api/trade-api) | 백엔드, 봇, Blink — 서버에서 빌드한 트랜잭션이 필요한 곳 | 최저 | 제한적 (사전 설정된 경로) | 모든 언어 |
| [TypeScript SDK](/ko/sdk-api/typescript-sdk) | 전체 빌더 접근이 필요한 Node/TS 앱과 프론트엔드 | 중간 | 전체 | TS / JS |
| [Python 통합](/ko/sdk-api/python-integration) | Python 백엔드와 ML 파이프라인 | 중간 | 전체 (수동 명령어 빌드) | Python |
| [Rust CPI](/ko/sdk-api/rust-cpi) | Raydium을 온체인에서 호출하는 프로그램 구성 | N/A (온체인) | 전체 + 구성 가능 | Rust |
| [Anchor IDL](/ko/sdk-api/anchor-idl) | 기본 지원이 없는 언어를 위한 코드 생성 (Go, Kotlin, Swift, ...) | 가변 | 전체 | Anchor 코드 생성 도구가 있는 모든 언어 |

확실하지 않으신가요? 백엔드와 봇 → **Trade API**; 프론트엔드와 전체 제어 앱 → **TypeScript SDK**; 온체인 구성 → **Rust CPI**.

  </Card>
