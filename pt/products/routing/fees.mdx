## Taxa do roteador

O programa AMM Routing **não cobra taxa própria**. É um orquestrador puro.

Todas as taxas são pagas diretamente aos pools pelos quais você roteia:

- Cada salto AMM v4 paga a taxa AMM v4 (0,25% dividida).
- Cada salto CPMM paga a taxa CPMM (configurável, tipicamente 0,25% dividida).
- Cada salto CLMM paga a taxa CLMM (configurável por pool).
- Cada salto stable paga a taxa stable-swap (0,02% — muito menor que AMM v4).

## Taxas efetivas totais em uma rota

Se você rotear através de N pools, sua taxa total é a soma de todas as taxas dos N saltos, compostas.

**Exemplo:**

Rota: USDC → SOL (taxa de 0,25%) → STEP (taxa de 0,25%)

```
Entrada: 1000 USDC

Salto 1 (USDC/SOL): taxa de 0,25%
  Taxa: 2,5 USDC
  Saída para salto 2: ~997,5 USDC de poder de compra

Salto 2 (SOL/STEP): taxa de 0,25%
  Taxa: ~2,49 STEP-worth
  Saída: ~995 STEP-worth

Custo total: ~0,5% (não exatamente 0,5%, pois as taxas se compõem)
```

Consulte a documentação de taxas do pool respectivo para divisões exatas:

- [`products/amm-v4/fees`](/pt/products/amm-v4/fees)
- [`products/cpmm/fees`](/pt/products/cpmm/fees)
- [`products/clmm/fees`](/pt/products/clmm/fees) (se disponível)
- [`products/stable/fees`](/pt/products/stable/fees) (se disponível)

## Custo computacional

O custo computacional do roteador é **linear no número de saltos**:

- **Overhead fixo:** ~5k CU para a lógica de dispatch do roteador e validação de contas.
- **Custo por salto:** ~10k–50k CU dependendo do tipo de pool e complexidade:
  - CPMM: ~20k–30k CU
  - AMM v4: ~40k–60k CU (inclui validação OpenBook)
  - CLMM: ~50k–100k CU (matemática de tick intensiva)
  - Stable: ~30k–40k CU
- **Orçamento total de transação:** 1,4M CU na mainnet. Uma rota com 10 saltos CPMM custaria ~305k CU, deixando espaço para outras operações.

Consulte a documentação de cada pool para custos exatos de CU.

## Overhead de inicialização de contas

Cada variante de swap habilitada roteia tokens intermediários através de ATAs controladas pelo usuário. Em cada salto intermediário, você deve pré-criar e fornecer uma ATA de propriedade do usuário:

- **Se a ATA não existir:** inicialização do programa ATA custa ~5k CU + ~0,00203928 SOL de aluguel por ATA. Inicialize-a com o programa SPL Associated Token Account (ou, para wSOL, com a tag [`CreateSyncNative`](/pt/products/routing/instructions#createsyncnative-tag-5) 5).
- **Se a ATA já existir:** sem overhead extra.

Para uma rota de 5 saltos com 4 tokens intermediários, você precisaria de 4 novas ATAs se começar do zero = ~20k CU + ~0,00816 SOL.

Você pode recuperar o aluguel de qualquer ATA temporária — mais comumente uma ATA wSOL usada para uma única rota — fechando-a com [`CloseTokenAccount`](/pt/products/routing/instructions#closetokenaccount-tag-6) (tag 6) uma vez que tenha saldo zero.
