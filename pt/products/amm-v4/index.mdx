## O que é

O AMM v4 é o pool de primeira geração da Raydium. Mantém um invariante de produto constante (xy=k). O pool foi originalmente projetado como um **AMM híbrido**: junto à curva, postava uma grade de ordens limitadas espaçadas por Fibonacci em um mercado OpenBook vinculado, de modo que a liquidez do pool era visível para os tomadores do livro de ordens. **Essa integração com OpenBook foi removida do programa** (veja o aviso acima); o AMM v4 hoje é um AMM de produto constante puro. As contas `AmmInfo` on-chain retêm seus campos de referência `market` / `open_orders` para compatibilidade de layout, mas o programa não os lê mais nem age sobre eles.

Ainda é o produto de maior liquidez na Raydium para muitos pares legados, mas **não é mais recomendado para novos pools** — veja [CPMM](/pt/products/cpmm) para novas implantações.

**ID do Programa:** veja [reference/program-addresses](/pt/reference/program-addresses).

**Token-2022:** não suportado. Os pools AMM v4 aceitam apenas tokens SPL clássicos.
