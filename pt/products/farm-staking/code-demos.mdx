## Configuração

Os exemplos aqui espelham arquivos em [`raydium-sdk-V2-demo/src/farm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/farm). O bootstrap segue o [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) do repositório de demonstração:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Buscar um farm por id

Não há `raydium.farm.getFarmById`. Todo exemplo de farm começa a partir do módulo API, que retorna a forma normalizada `FormatFarmInfoOut` que `deposit` / `withdraw` / `harvestAllRewards` usam:

```ts
const farmId = "CHYrUBX2RKX8iBg7gYTkccoGNBzP44LdaazMHCLcdEgS"; // RAY-USDC farm

const farmInfo = (await raydium.api.fetchFarmInfoById({ ids: farmId }))[0];
if (!farmInfo) throw new Error("farm not found");

console.log("LP mint:", farmInfo.lpMint.address);
console.log("TVL:", farmInfo.tvl);
for (const r of farmInfo.rewardInfos) {
  console.log("  -", r.mint.address, r.mint.symbol);
}
```

`fetchFarmInfoById` recebe uma **string separada por vírgulas** de ids e retorna um array, então uma chamada pode hidratar um portfólio inteiro. Se você precisar das chaves de conta bruta em vez das informações de exibição, `raydium.api.fetchFarmKeysById({ ids })` retorna os vaults e PDAs de autoridade; o SDK a chama internamente para você dentro de cada builder abaixo.

## Fazer stake de tokens LP

Fonte: [`src/farm/stake.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/stake.ts)

```ts
// O exemplo faz stake do saldo LP inteiro da carteira; qualquer BN em unidades brutas funciona.
const amount = raydium.account.tokenAccountRawInfos.find(
  (a) => a.accountInfo.mint.toBase58() === farmInfo.lpMint.address,
)?.accountInfo.amount;

if (!amount || amount.isZero()) throw new Error("user does not have an LP balance");

const { execute } = await raydium.farm.deposit({
  farmInfo,
  amount,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Deposit tx:", txId);
```

O SDK lida com o pré-liquidação de qualquer recompensa pendente, então se essa carteira já tem stake neste farm, a instrução pagará as recompensas acumuladas para os ATAs do usuário na mesma transação.

## Apenas coleta (harvest)

Fonte: [`src/farm/harvest.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/harvest.ts)

`farmInfoList` é um **`Record` indexado por id do farm**, não um array, e o builder retorna **múltiplas** transações — então `execute` deve receber `sequentially: true`:

```ts
const farmIds = [farmId, "<ANOTHER_FARM_ID>"];
const farmInfos = await raydium.api.fetchFarmInfoById({ ids: farmIds.join(",") });

const { execute } = await raydium.farm.harvestAllRewards({
  farmInfoList: Object.fromEntries(farmInfos.map((f) => [f.id, f])),
  txVersion: TxVersion.V0,
});

const { txIds } = await execute({ sequentially: true });
console.log("harvest txs:", txIds);
```

O builder empacota o máximo de farms por transação que o limite de 1232 bytes permite e divide o resto em transações subsequentes, é por isso que retorna `txIds` em vez de um único `txId`.

Para um único farm, faça harvest com o idioma `amount: 0` — isso é o que [`src/farm/harvest.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/harvest.ts) faz, em todas as versões incluindo v6:

```ts
const { execute } = await raydium.farm.withdraw({
  farmInfo,
  amount: new BN(0),        // 0 = harvest-only path
  txVersion: TxVersion.V0,
});
await execute({ sendAndConfirm: true });
```

## Criar um farm v6

Fonte: [`src/farm/createAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/createAmmFarm.ts) e [`editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts)

`create` recebe o **objeto de informações do pool** para o pool cujo mint LP está sendo feito stake (não um mint simples), e cada entrada de `rewardInfos` é um `FarmRewardInfo`: `{ mint: PublicKey, perSecond: string, openTime: number, endTime: number, rewardType: "Standard SPL" | "Option tokens" }`. Os tempos são **segundos simples**, e `perSecond` é uma **string**, não um `BN`. `programId` padrão é o programa v6, então você raramente o passa.

```ts
import type { ApiV3PoolInfoStandardItem, FarmRewardInfo } from "@raydium-io/raydium-sdk-v2";
import { RAYMint } from "@raydium-io/raydium-sdk-v2";

// O pool que você possui cujo mint LP será o mint de staking.
const poolInfo = (
  await raydium.api.fetchPoolById({ ids: "<POOL_ID>" })
)[0] as ApiV3PoolInfoStandardItem;
if (!poolInfo) throw new Error("pool not found");

const rewardMint = await raydium.token.getTokenInfo(RAYMint);

// Use o tempo da chain, não o tempo de parede — o programa valida contra o primeiro.
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);
const endTime  = openTime + 60 * 60 * 24 * 7; // 7 days

const rewardInfos: FarmRewardInfo[] = [
  {
    mint:       new PublicKey(rewardMint.address),
    perSecond:  "1",              // string, in raw units per second
    openTime,                      // seconds, not BN
    endTime,
    rewardType: "Standard SPL",   // "Option tokens" is the only other value
  },
];

const { execute, extInfo } = await raydium.farm.create({
  poolInfo,
  rewardInfos,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Farm:", extInfo.farmId.toBase58(), "createTx:", txId);
```

Pontos-chave:

- `perSecond` é a taxa de emissão por segundo nas unidades **brutas** do mint de recompensa, passada como uma string decimal. O SDK a empacota na representação de ponto fixo on-chain antes de enviar.
- O orçamento completo (`perSecond × (endTime − openTime)`) deve estar presente no seu ATA de recompensa — `create` o move para o vault de recompensa atomicamente.
- **Mints de recompensa Token-2022 não são suportados pelos builders de farm do SDK** nesta versão do SDK; use um mint SPL simples para recompensas.
- Você pode semear até 5 recompensas em uma chamada `create`. A lista de contas cresce por `(reward_mint, reward_vault, sender_ata, token_program)` por stream extra; fique atento ao limite de tamanho de transação de 1232 bytes. Para 4+ recompensas, crie com 1–2 e use `addNewRewardsToken` em transações subsequentes.

## Adicionar um novo stream de recompensa

Não há `raydium.farm.setRewards`. Os dois builders que alteram as recompensas de um farm são `addNewRewardToken` / `addNewRewardsToken` (ocupam um slot livre com um mint **novo**) e `restartReward` / `restartRewards` (re-armam um slot cujo stream terminou). Ambos recebem objetos `FarmRewardInfo` exatamente na forma que `create` usa.

```ts
import { USDCMint } from "@raydium-io/raydium-sdk-v2";

const added = await raydium.token.getTokenInfo(USDCMint);
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);

const { execute } = await raydium.farm.addNewRewardsToken({
  farmInfo,
  newRewardInfos: [
    {
      mint:       new PublicKey(added.address),
      perSecond:  "1",
      openTime,
      endTime:    openTime + 60 * 60 * 24 * 7,
      rewardType: "Standard SPL",
    },
  ],
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

O orçamento delta (`perSecond × duration`) é puxado do ATA do pagador como parte da transação. A instrução subjacente não pode encurtar um stream, não pode reduzir `per_second` em um stream ativo e não pode alterar o mint de recompensa de um slot — para trocar mints, aguarde `end_time` e use `addNewRewardsToken` em um slot liberado, ou crie um novo farm.

<Tip>
  `restartRewards` e `addNewRewardsToken` cada um retornam um builder, então uma única transação pode fazer ambos. [`src/farm/editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts) mostra o padrão: `editFarmBuilder.builder.addInstruction(addNewRewardBuildData.builder.AllTxData)`, depois um `versionBuild({ txVersion })`.
</Tip>

## Reiniciar um stream finalizado

Fonte: [`src/farm/editAmmFarm.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/farm/editAmmFarm.ts)

`restartRewards` recebe **`newRewardInfos`** (plural, um array); `restartReward` é a forma de item único e recebe `newRewardInfo`. O campo mint é `mint`, não `rewardMint`, e deve corresponder a um slot que já existe no farm — o builder procura o slot por mint e gera erro se estiver ausente.

```ts
import type { FarmRewardInfo } from "@raydium-io/raydium-sdk-v2";

// Re-arme o slot de recompensa existente primeiro do farm.
const existing = await raydium.token.getTokenInfo(farmInfo.rewardInfos[0].mint.address);
const openTime = Math.floor((await raydium.currentBlockChainTime()) / 1000);

const newRewardInfos: FarmRewardInfo[] = [
  {
    mint:       new PublicKey(existing.address),
    perSecond:  "1",
    openTime,
    endTime:    openTime + 60 * 60 * 24 * 14,
    rewardType: "Standard SPL",
  },
];

const { execute } = await raydium.farm.restartRewards({
  farmInfo,
  newRewardInfos,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

`restartRewards` é **apenas v6** — o builder lê o id do programa do farm e gera erro para farms v3 / v5. Válido apenas quando o `reward_state == 2` do slot alvo (finalizado); o chamador deve ser o `reward_sender` do slot. Note que `openTime >= endTime` é rejeitado no lado do cliente antes de qualquer RPC ser feito.

## Rust CPI

<Warning>
  **Não há crate Anchor `raydium_farm_v6`.** Nenhum crate com esse nome existe em crates.io, o programa Farm v6 não publica nenhum IDL on-chain (nem uma conta `anchor:idl` legada nem uma entrada no programa Program Metadata), e nenhum repositório de fonte pública para ele existe. Uma revisão anterior desta página mostrou um exemplo `raydium_farm_v6::cpi::deposit`; ele não compilava contra nada e foi removido.
</Warning>

Farm v6 foi implantado pela última vez em 2024-05-13 e não é um programa Anchor do ponto de vista de um integrador. Se você precisar compor com ele a partir do seu próprio programa on-chain, construa a `Instruction` manualmente — derive a lista de contas e discriminadores de instrução independentemente (dos layouts TypeScript do SDK em `raydium-sdk-V2/src/raydium/farm/`, ou decodificando transações reais), e `invoke_signed` isso. Veja [`sdk-api/rust-cpi`](/pt/sdk-api/rust-cpi#farm-v6) para esse procedimento.

Qualquer que seja a rota que você tome, a cauda `remaining_accounts` deve corresponder aos slots de recompensa ativos do farm 1-para-1 (pares de `reward_vault_i`, `user_reward_ata_i` em ordem de índice). Omitir ou desordenar esses produz uma contabilidade silenciosa incorreta — o programa transferirá o valor errado.

## Armadilhas

- **Esquecer de coletar antes de remover stake.** Inofensivo — `Withdraw` liquida recompensas pendentes primeiro. Mas se sua UI mostrar "coletar" separadamente de "remover stake", o usuário pode pensar que ainda há algo para coletar após um `Withdraw`. Não há; tudo acumulado até esse ponto foi pago.
- **`total_staked = 0` durante emissões.** Emissões acumuladas enquanto nada estava em stake são perdidas (a fórmula de atualização `reward_per_share` divide por 0 e o programa pula a atualização). Para programas com `open_time` agendado, execute um "seed stake" em open_time para evitar isso.
- **Taxas de transferência Token-2022.** Em farms v6 com mints de recompensa Token-2022, a taxa de transferência se aplica na emissão (vault → usuário). Fatore isso em cotações de APR.
- **Pequeno `per_second` em v5.** A taxa `u64` do v5 significa que qualquer `per_second < 1` unidade de token por segundo (em mints com ≥9 decimais isso é frequentemente a taxa desejada) não pode ser expressa — a taxa do stream arredonda para 0 e o farm não emite nada. Use v6.
