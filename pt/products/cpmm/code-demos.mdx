## Pré-requisitos

```bash
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js decimal.js
```

Cada exemplo nesta página espelha um arquivo em [`raydium-sdk-V2-demo/src/cpmm`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/cpmm); o link do GitHub fica ao lado de cada seção. O bootstrap segue o `config.ts.template` do repositório de demonstração ([fonte](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)):

```ts
import { Connection, Keypair, clusterApiUrl } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);

const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
```

A instância `Raydium` é a fachada do SDK — cada exemplo abaixo a utiliza. `Raydium.load` é assíncrono porque carrega a lista de tokens por padrão; passe `disableLoadToken: true` para pular essa busca. A verificação de disponibilidade de recursos já é ignorada, a menos que você passe `disableFeatureCheck: false`. As configurações de taxa são buscadas de forma preguiçosa no primeiro uso via `raydium.api.getCpmmConfigs()`.

## Criar um pool CPMM

Fonte: [`src/cpmm/createCpmmPool.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/createCpmmPool.ts)

```ts
import { PublicKey } from "@solana/web3.js";
import BN from "bn.js";
import { CREATE_CPMM_POOL_PROGRAM, CREATE_CPMM_POOL_FEE_ACC }
  from "@raydium-io/raydium-sdk-v2";
// (Se você precisar de cada PDA de pool de uma vez, o auxiliar exportado é `getCreatePoolKeys`.
//  Não há `getCpmmPdas`.)

const mintA = new PublicKey("So11111111111111111111111111111111111111112"); // wSOL
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// 1. Escolha uma configuração de taxa. index=0 é o nível de 0,25%.
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0)!;

// 2. Extraia os metadados de mint para que o SDK possa lidar com extensões Token-2022.
const mintAInfo = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(mintB);

// 3. Construa a transação.
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA:           mintAInfo,
  mintB:           mintBInfo,
  mintAAmount:     new BN(1_000_000_000),   // 1 SOL (assumindo 9 decimais)
  mintBAmount:     new BN(   160_000_000),  // 160 USDC (a 160/SOL)
  startTime:       new BN(0),               // abrir imediatamente
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Pool criado em", extInfo.address.poolId.toBase58());
console.log("Tx:", txId);
```

Algumas coisas que o SDK cuida silenciosamente:

- Ordenar os mints em ordem token0/token1 antes de derivar o PDA.
- Pagar a `create_pool_fee` única para `poolFeeAccount`.
- Criar as contas de token associadas do chamador se estiverem faltando.
- Escolher o programa de token correto (SPL Token vs Token-2022) por lado.

Após a confirmação, você pode buscar o estado do pool ao vivo com:

```ts
// getPoolInfoFromRpc recebe uma string base58 posicional, não uma PublicKey e não um objeto.
const { poolKeys, poolInfo, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(
  extInfo.address.poolId.toBase58(),
);
```

## Swap (entrada base)

Fonte: [`src/cpmm/swap.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swap.ts)

```ts
import { CurveCalculator, FeeOn } from "@raydium-io/raydium-sdk-v2";

const POOL_ID = "<POOL_ID>";   // string base58

// 1. Carregue o estado atual do pool diretamente de um RPC (não da API).
const { poolInfo, poolKeys, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(POOL_ID);

const inputMint  = poolInfo.mintA.address;                // swap A → B
const amountIn   = new BN(100_000_000);                   // 0,1 SOL
const slippage   = 0.005;                                 // 0,5%

// 2. Cotação local. CurveCalculator espelha a matemática on-chain, incluindo
//    taxas de transferência Token-2022 em ambos os lados. Todos os oito argumentos são obrigatórios.
const baseIn = inputMint === poolInfo.mintA.address;
const swapResult = CurveCalculator.swapBaseInput(
  amountIn,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// Os campos swapResult são inputAmount / outputAmount / tradeFee / protocolFee /
// fundFee / creatorFee / newInputVaultAmount / newOutputVaultAmount.
// Não há destinationAmountSwapped ou sourceAmountSwapped.

// 3. Construa e envie. Passar `slippage` aqui é o que aplica o limite —
//    nenhuma aritmética manual de saída mínima é necessária.
const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: amountIn,
  swapResult,
  slippage,
  baseIn,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Tx de swap:", txId);
```

Nota: o SDK **sempre** busca novamente o estado do pool de um RPC dentro de `getPoolInfoFromRpc`. Não faça cotação de `api-v3.raydium.io` para uma transação que você está prestes a assinar — uma cotação que está um bloco desatualizada pode escorregar para `ExceededSlippage` no momento do pouso.

## Swap (saída base)

Fonte: [`src/cpmm/swapBaseOut.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swapBaseOut.ts)

```ts
const amountOutWanted = new BN(15_000_000);        // 15 USDC
const slippage        = 0.005;

const baseIn = false; // false → mintB é o lado de entrada
const swapResult = CurveCalculator.swapBaseOutput(
  amountOutWanted,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
  rpcData.configInfo!.creatorFeeRate,
  rpcData.configInfo!.protocolFeeRate,
  rpcData.configInfo!.fundFeeRate,
  rpcData.feeOn === FeeOn.BothToken || rpcData.feeOn === FeeOn.OnlyTokenB,
);
// swapResult.inputAmount é a entrada necessária; não há sourceAmountSwapped.

const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: new BN(0),   // não utilizado quando fixedOut — o valor vem de swapResult
  fixedOut:    true,
  swapResult,               // obrigatório, e carrega o valor de saída alvo
  baseIn,
  slippage,
  txVersion:   TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

## Depositar liquidez

Fonte: [`src/cpmm/deposit.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/deposit.ts)

```ts
import { Percent } from "@raydium-io/raydium-sdk-v2";
import Decimal from "decimal.js";

// addLiquidity é acionado por um valor de ENTRADA, não por um valor de LP.
const uiInputAmount = "0.0001";
const inputAmount = new BN(
  new Decimal(uiInputAmount).mul(10 ** poolInfo.mintA.decimals).toFixed(0),
);
const slippage = new Percent(1, 100);   // um Percent, não um número

const { execute } = await raydium.cpmm.addLiquidity({
  poolInfo,
  poolKeys,
  inputAmount,
  baseIn: true,           // inputAmount é denominado em mintA
  slippage,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

O SDK deriva o valor emparelhado das reservas atuais do pool, infla cada lado pelo slippage para os argumentos `maximum_*` da instrução e constrói as criações de ATA se necessário. `raydium.cpmm.computePairAmount({ ... })` retorna os mesmos números se você quiser para uma visualização de UI.

## Coletar taxas de protocolo/fundo/criador

Fonte: [`src/cpmm/collectCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectCreatorFee.ts), [`src/cpmm/collectAllCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectAllCreatorFee.ts)

A coleta de protocolo e fundo permanece com portão de autoridade. As taxas do criador têm dois caminhos: o `CollectCreatorFee` assinado pelo criador e o aditivo `CollectCreatorFeePermissionless`, que qualquer pagador pode invocar, mas que pode transferir apenas para as ATAs canônicas do criador. `0.2.64-alpha` envia construtores de nível de módulo para ambos os caminhos do criador:

```ts
// assinado pelo criador
const { execute } = await raydium.cpmm.collectCreatorFees({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// sem permissão — qualquer pagador; os ganhos vão para as ATAs canônicas do criador
const { execute } = await raydium.cpmm.collectCreatorFeesPermissionless({
  poolInfo,
  poolKeys,
  txVersion: TxVersion.V0,
});

// vários pools de uma vez, assinado pelo criador
await raydium.cpmm.collectMultiCreatorFees({ poolInfoList, txVersion: TxVersion.V0 });
```

<Note>
  As duas instruções do criador têm **discriminadores e layouts de conta diferentes** — a
  sem permissão substitui as posições do assinante do criador / `amm_config` por um `payer`
  separado e um `creator` não assinante. Use o construtor correspondente em vez de trocar manualmente
  as contas no outro.

  Não há construtor de taxa de protocolo ou fundo no SDK (`makeCollectProtocolFeeInstruction` e
  `makeCollectFundFeeInstruction` não existem sob nenhum nome) — esses são caminhos de administrador. Os
  construtores de instrução de baixo nível que *existem* são `collectCpFeeInstruction`,
  `makeCollectCreatorFeeInstruction` e `collectCreatorFeePermissionlessInInstruction`.
</Note>

Off-chain você pode ler as taxas acumuladas diretamente de `PoolState`:

```ts
const pool = await raydium.cpmm.getRpcPoolInfo(POOL_ID);   // string base58
console.log("Taxa de protocolo acumulada mintA:", pool.protocolFeesMintA.toString());
console.log("Taxa de protocolo acumulada mintB:", pool.protocolFeesMintB.toString());
// Os campos CpmmPoolInfoLayout são protocolFeesMintA/B, fundFeesMintA/B e
// creatorFeesMintA/B — não há campos ...Token0/...Token1.
```

## Esqueleto de CPI em Rust

Se você quiser invocar CPMM a partir do seu próprio programa Anchor — por exemplo, um vault que faz swap em nome de seus depositantes — o contexto de CPI fica assim. A ordem das contas segue [`products/cpmm/instructions`](/pt/products/cpmm/instructions).

```rust
// Cargo.toml — o branch importa: `master` ainda fixa anchor-lang 0.32.1.
// raydium-cp-swap = { git = "https://github.com/raydium-io/raydium-cp-swap",
//                     branch = "chore/upgrade-anchor", features = ["cpi"] }
// anchor-lang      = "=1.0.2"   // deve corresponder ao que raydium-cp-swap fixa
// anchor-spl       = "=1.0.2"
//
// O recurso `cpi` é obrigatório — o módulo `raydium_cp_swap::cpi` só existe
// sob ele. Observe que este crate não pode compartilhar um programa com a amostra CLMM em
// products/clmm/code-demos, que fixa anchor-lang =0.32.1.

use anchor_lang::prelude::*;
use anchor_spl::token_interface::{TokenAccount, TokenInterface, Mint};
use raydium_cp_swap::cpi::accounts::Swap;
use raydium_cp_swap::cpi;
use raydium_cp_swap::program::RaydiumCpSwap;

#[derive(Accounts)]
pub struct ProxySwap<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,

    /// CHECK: validado pelo programa CPMM
    pub authority:     UncheckedAccount<'info>,
    /// CHECK:
    pub amm_config:    UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub pool_state:    UncheckedAccount<'info>,

    #[account(mut)]
    pub input_token_account:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_token_account: InterfaceAccount<'info, TokenAccount>,

    #[account(mut)]
    pub input_vault:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_vault: InterfaceAccount<'info, TokenAccount>,

    pub input_token_program:  Interface<'info, TokenInterface>,
    pub output_token_program: Interface<'info, TokenInterface>,

    pub input_token_mint:  InterfaceAccount<'info, Mint>,
    pub output_token_mint: InterfaceAccount<'info, Mint>,

    #[account(mut)]
    /// CHECK: anel de buffer
    pub observation_state: UncheckedAccount<'info>,

    pub cpmm_program: Program<'info, RaydiumCpSwap>,
}

pub fn proxy_swap_base_input(
    ctx: Context<ProxySwap>,
    amount_in: u64,
    minimum_amount_out: u64,
) -> Result<()> {
    let cpi_accounts = Swap {
        payer:                ctx.accounts.payer.to_account_info(),
        authority:            ctx.accounts.authority.to_account_info(),
        amm_config:           ctx.accounts.amm_config.to_account_info(),
        pool_state:           ctx.accounts.pool_state.to_account_info(),
        input_token_account:  ctx.accounts.input_token_account.to_account_info(),
        output_token_account: ctx.accounts.output_token_account.to_account_info(),
        input_vault:          ctx.accounts.input_vault.to_account_info(),
        output_vault:         ctx.accounts.output_vault.to_account_info(),
        input_token_program:  ctx.accounts.input_token_program.to_account_info(),
        output_token_program: ctx.accounts.output_token_program.to_account_info(),
        input_token_mint:     ctx.accounts.input_token_mint.to_account_info(),
        output_token_mint:    ctx.accounts.output_token_mint.to_account_info(),
        observation_state:    ctx.accounts.observation_state.to_account_info(),
    };
    // Anchor 1.0 recebe a Pubkey do programa aqui, não sua AccountInfo.
    let cpi_ctx = CpiContext::new(
        *ctx.accounts.cpmm_program.key,
        cpi_accounts,
    );
    cpi::swap_base_input(cpi_ctx, amount_in, minimum_amount_out)
}
```

Se seu CPI assina como um PDA (por exemplo, você gerencia um vault em nome dos depositantes), troque `CpiContext::new` por `CpiContext::new_with_signer` e passe suas sementes.

## Armadilhas comuns

Uma lista de verificação rápida antes de abrir um ticket de suporte:

- **Mints ordenados.** Se seu PDA `poolState` derivado não corresponder ao pool on-chain, você provavelmente esqueceu de ordenar os mints.
- **Cotação de API desatualizada.** Nunca passe um valor de reserva de `api-v3.raydium.io` para `CurveCalculator.swap`. Busque de um RPC.
- **Programa de token errado.** O vault de um mint Token-2022 é de propriedade do programa Token-2022, não do SPL Token. Sempre use os campos `token_0_program` / `token_1_program` do pool.
- **Slippage sub-denominado para mints com taxa de transferência.** Se qualquer lado do pool for um mint Token-2022 com taxa de transferência, seu `minimum_amount_out` deve ser denominado no que o usuário realmente recebe, não no que o vault envia.
- **`NotApproved` em um swap.** Verifique `PoolState.status` — o administrador pode ter pausado swaps nesse pool. Veja [`products/cpmm/instructions`](/pt/products/cpmm/instructions) para a máscara de status.
