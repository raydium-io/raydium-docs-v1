## Pré-requisitos

Execute isto uma vez:

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

Você precisa de:

- **Node 18+** com suporte ESM (`"type": "module"` em `package.json` ou extensão `.mjs`).
- **Um keypair Solana** em `~/.config/solana/id.json` (ou em qualquer lugar — defina `KEYPAIR`). Veja [`solana-fundamentals/toolchain`](/pt/solana-fundamentals/toolchain#solana-cli) para gerar um keypair.
- **Uma carteira financiada.** O script de swap precisa apenas do seu valor de entrada mais uma pequena margem — um swap CPMM custa ~0,0015 SOL em taxas de rede (veja [`reference/fee-comparison`](/pt/reference/fee-comparison#network-fees-per-typical-operation)), mais aluguel único se o swap precisar abrir uma conta de token para você. Criar um pool custa mais: o script CPMM sozinho carrega uma taxa de criação de pool única de ~0,15 SOL antes da liquidez inicial ou aluguel. Veja a seção Setup de cada script para o valor atual antes de financiar sua carteira.
- **Uma URL RPC.** RPC público gratuito funciona para testes; para qualquer coisa além de um teste básico, use um provedor pago.

Defina estes uma vez por shell:

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **Cluster.** Todos os três scripts usam mainnet por padrão. Devnet precisa de `RPC_URL=https://api.devnet.solana.com` mais `cluster: "devnet"` dentro do script — para os dois scripts de criação de pool, essa não é a única mudança; veja a seção Setup de cada script para o que mais precisa mudar. Esteja ciente de que a liquidez inicial do pool em devnet é escassa; espere mintar seus próprios tokens de teste.
</Info>

## Após este capítulo

Cada script imprime seu resultado on-chain — uma cotação de swap e link de transação, novos endereços de pool ou uma nova posição e seu NFT — e uma única linha apontando para a próxima página no capítulo [SDK & API](/pt/sdk-api) para a operação que executou. Quando estiver pronto para escrever sua própria integração:

- **Backends e bots** → [Trade API](/pt/sdk-api/trade-api).
- **Frontends e aplicativos com controle total** → [TypeScript SDK](/pt/sdk-api/typescript-sdk).
- **Composição on-chain** → [Rust CPI](/pt/sdk-api/rust-cpi).
- **Escolhendo entre eles** → a tabela de comparação no topo de [SDK & API](/pt/sdk-api).
