## Para quem é este capítulo

Desenvolvedores e pesquisadores de protocolos vindos de outras blockchains (EVM, Cosmos, Move) ou novos no Solana. Usuários finais podem pular este capítulo.

O objetivo é pragmático: fornecer ao leitor exatamente o que ele precisa para ler os capítulos de Produtos e SDK sem surpresas. Este não é um tutorial geral do Solana — consulte a documentação oficial do Solana para isso.
