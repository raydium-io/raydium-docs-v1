## O que é Burn & Earn

Burn & Earn é um recurso Raydium que permite a um criador de pool (ou qualquer LP) fazer um depósito **permanente** na cadeia enquanto mantém o direito de coletar taxas de negociação. Uma posição se torna não-resgatável, mas um **Raydium Fee Key** NFT recém-cunhado representa o direito contínuo de `collectFees` dessa posição bloqueada.

Casos de uso comuns:

- **Confiança no lançamento.** Projetos se comprometem a não fazer rug-pull bloqueando o LP do implantador. Os detentores podem verificar na cadeia que a liquidez é permanente.
- **Colecionável gerador de taxas.** Um NFT negociável que gera rendimento. Venda o NFT; transfira o fluxo de taxas.
- **LP em nível de tesouro.** Protocolos que desejam manter liquidez para sempre para fins de marca / descoberta, enquanto ainda monetizam o lado das taxas.

## Tipos de pool suportados

| Programa | Suporte a Burn & Earn |
|---|---|
| CPMM | Sim |
| CLMM | **Apenas intervalo completo** (recomendado) |
| AMM v4 (Híbrido) | Não suportado |

Para CLMM, apenas posições que abrangem a faixa de preço completa devem ser bloqueadas. Uma vez bloqueada, você não pode rebalancear — se o preço sair do seu intervalo escolhido, você permanentemente para de ganhar taxas nessa posição. Uma posição Burn & Earn de intervalo apertado é quase sempre um erro.

## Como o bloqueio funciona no nível do programa

1. O token LP original (CPMM) ou NFT de posição (CLMM) é transferido para um PDA de propriedade do programa de propriedade do programa Burn & Earn.
2. Um **Fee Key NFT** é cunhado para o chamador. Seus metadados apontam de volta para o PDA da posição bloqueada.
3. Burn & Earn expõe `collectFees` (ou a chamada equivalente por tipo de pool) que:
   - Verifica se o signatário detém o Fee Key NFT para a posição bloqueada fornecida.
   - Chama a instrução de reivindicação de taxa do programa de pool subjacente via CPI.
   - Roteia as taxas coletadas para os ATAs do detentor da Fee Key.
4. Não há `withdraw` correspondente — o LP / posição subjacente nunca sai do escrow.

O Fee Key é um NFT SPL padrão. Pode ser vendido em qualquer mercado de NFT Solana, movido entre carteiras, usado como garantia em protocolos de empréstimo que aceitam NFTs, ou envolvido em outro contrato. Quem o detém no momento de uma chamada `collectFees` recebe as taxas.

## Passo a passo da interface

1. Crie um pool CPMM ou um pool CLMM com uma posição de intervalo completo, como de costume.
2. Vá para **Liquidity → Create → Burn & Earn**.
3. Selecione a posição a ser bloqueada.
4. Verifique os detalhes da posição (endereço do NFT, tamanho, pool) e digite a frase de confirmação que a interface mostra. Isso é intencionalmente pesado em atrito porque a operação é irreversível.
5. Clique em **Confirm, lock the liquidity permanently** (Confirmar, bloquear a liquidez permanentemente).
6. Um NFT Fee Key chega à sua carteira. Aparece na página Portfolio sob posições bloqueadas.

Reivindicar taxas da mesma forma que você reivindicaria de qualquer posição — através da página Portfolio ou via `collectFees`.

## Superfície da API

O endpoint de informações do pool retorna um campo `burnPercent` indicando a parcela da liquidez desse pool que foi bloqueada via Burn & Earn:

```http
GET https://api-v3.raydium.io/pools/info/list
  ?poolType=standard
  &poolSortField=default
  &sortType=desc
  &pageSize=1
  &page=1
```

```json
{
  "data": [
    {
      "id": "...",
      "burnPercent": 99.17,
      ...
    }
  ]
}
```

`burnPercent` é uma superfície útil para sinalização de confiança: um token cujo LP é 99%+ queimado é dramaticamente menos suscetível a rug-pull do que um cujo LP é 0% queimado.

## Armadilhas

- **Irreversível.** O lado do LP nunca pode ser recuperado. Confirme que o valor é algo que você está disposto a nunca tocar novamente.
- **Intervalos apertados de CLMM são uma armadilha.** Bloqueie apenas posições CLMM de intervalo completo, a menos que você realmente entenda que uma posição bloqueada vinculada a um intervalo para de ganhar assim que o preço sai da banda.
- **Perder o NFT Fee Key é perder as taxas para sempre.** Trate-o como uma escritura. Não o queime acidentalmente; não o coloque em stake em um contrato hostil.
- **Mints Token-2022 com taxas de transferência**: Burn & Earn os suporta, mas o corte de taxa de transferência se aplica a cada reivindicação de taxa — orçamente para isso.
- **Não há bloqueio parcial.** Se você deseja 50% bloqueado e 50% móvel, divida a posição em duas posições primeiro, depois bloqueie apenas uma.
