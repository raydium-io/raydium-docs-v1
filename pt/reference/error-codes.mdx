## Como funcionam os códigos de erro Anchor

Anchor atribui a cada variante do enum `ErrorCode` de um programa um código numérico começando em `6000`. Uma transação que falha expõe:

- **Código de erro numérico** (ex: `0x1771` = 6001) nos logs da transação.
- **Nome do erro** (ex: `InvalidOwner`) a partir do IDL.
- **String `#[msg(...)]`** que Anchor emitiu em `log_messages`.

Os integradores devem fazer correspondência no **código numérico**, não na string de mensagem (a string pode ser reformulada sem aumentar uma versão).

```ts
// Exemplo: detectar o erro de slippage do CPMM e exibir uma mensagem UX limpa.
const CPMM_EXCEEDED_SLIPPAGE = 6005;

try {
  await sdk.cpmm.swap({ ... });
} catch (err: any) {
  const code = err?.error?.errorCode?.number ?? err?.code;
  if (code === CPMM_EXCEEDED_SLIPPAGE) {
    showToast("Price moved past your slippage tolerance. Increase slippage or retry.");
    return;
  }
  throw err;
}
```

Como Anchor numera erros por ordem de origem, cada código em ou após `6000` mudou em relação a compilações pré-lançamento. ## Mapeando erros SDK para erros de programa

O SDK TypeScript oficial envolve erros on-chain em `SendTransactionError` e, para programas Anchor, `AnchorError`:

```ts
import { AnchorError } from "@coral-xyz/anchor";

try {
  await sdk.cpmm.swap({ ... });
} catch (err) {
  if (err instanceof AnchorError) {
    console.log(err.error.errorCode.number, err.error.errorCode.code, err.error.errorMessage);
    // 6005 ExceededSlippage "Exceeds desired slippage limit"
  } else {
    // Raw SendTransactionError — inspect err.logs for the "custom program error: 0x..." line.
  }
}
```

Se você não estiver usando Anchor no lado do cliente, analise os logs da transação:

```
Program <ProgramID> invoke [1]
Program log: AnchorError caused by account: pool_state. Error Code: ExceededSlippage. Error Number: 6005. Error Message: Exceeds desired slippage limit.
```

O padrão `Error Number: (\d+)` é estável entre versões do Anchor e seguro para corresponder.

## Regenerando essas tabelas

Quando um programa é atualizado e adiciona um novo erro, re-extraia da fonte:

```bash
# Clone e grep o enum de erro em ordem.
git clone --depth=1 https://github.com/raydium-io/raydium-cp-swap
awk '/#\[msg\(/{ gsub(/^[ \t]*#\[msg\("|"\)\][ \t]*/,""); m=$0; getline; gsub(/,/,""); gsub(/^[ \t]+/,""); print "6000+++\t" $0 "\t" m }' \
  raydium-cp-swap/programs/cp-swap/src/error.rs
# Substitua 6000+++ por 6000,6001,... monotonicamente crescentes. Acrescente novas linhas à tabela acima.
```

Sempre atualize [`reference/changelog`](/pt/reference/changelog) quando uma nova variante é adicionada, para que os integradores que atualizam o SDK saibam atualizar seus manipuladores de erro.
