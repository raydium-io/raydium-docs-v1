## O que está disponível

| Superfície | Padrão de URL | Use quando |
|---|---|---|
| **Servidor MCP** | `https://docs.raydium.io/mcp` | Você quer que seu editor de IA (Claude Code, Cursor, Windsurf, etc.) consulte e cite a documentação do Raydium nativamente. |
| **Índice `llms.txt`** | `https://docs.raydium.io/llms.txt` | Você está construindo um pipeline de RAG e precisa de um índice simples de todas as páginas. |
| **Corpo `llms-full.txt`** | `https://docs.raydium.io/llms-full.txt` | Você quer o corpus completo como um único arquivo concatenado para indexação offline. |
| **Menu de cópia por página** | O botão `Copy page` no topo de cada página de conteúdo | Você está colando uma página em um chat com um LLM. |
| **Deep-links por página** | `View as Markdown`, `Open in ChatGPT`, `Open in Claude`, `Open in Cursor`, `Open in VS Code` | Transferência com um clique de uma página de documentação para sua ferramenta de escolha. |

O botão `Copy page` e o menu de deep-links ficam no canto superior direito de cada página (ao lado do título da página). Ambos são alimentados pelo menu contextual da plataforma de documentação.

## Servidor MCP

O servidor MCP (Model Context Protocol) permite que clientes de IA consultem a documentação do Raydium como uma ferramenta. Uma vez configurado, seu agente pode perguntar "search Raydium docs for `addLiquidity` parameters" e obter respostas autoritárias citadas.

### Claude Code

```bash
claude mcp add --transport http raydium-docs https://docs.raydium.io/mcp
```

Após adicionar, peça ao Claude Code para "search the Raydium docs for X" e ele usará a ferramenta.

### Cursor

Adicione às suas configurações do Cursor (`Cmd/Ctrl + ,` → MCP):

```json
{
  "mcpServers": {
    "raydium-docs": {
      "url": "https://docs.raydium.io/mcp"
    }
  }
}
```

### Windsurf, Continue, clientes genéricos

Qualquer cliente compatível com MCP pode apontar para `https://docs.raydium.io/mcp`. Se seu cliente exigir um manifesto, ele está em `https://docs.raydium.io/mcp/.well-known/mcp.json`.

### O que o servidor expõe

O servidor MCP de documentação do Raydium expõe uma ferramenta primária, `search_docs(query: string)`, que retorna as passagens com melhor classificação para a consulta junto com suas URLs canônicas. O agente é responsável por citar a URL que usou; não rastreamos ou limitamos a taxa por agente.

## `llms.txt` para RAG

`llms.txt` é um padrão emergente para "índice de documentação legível por máquina". O Raydium publica:

- `https://docs.raydium.io/llms.txt` — uma lista simples de todas as páginas com título e resumo de uma linha, organizado por capítulo.
- `https://docs.raydium.io/llms-full.txt` — o corpo Markdown completo de todas as páginas, concatenado, com limites de página preservados como títulos.

A variante `full` é regenerada a cada deploy da documentação. Puxe-a em um cronograma (diariamente é suficiente) ou busque sob demanda.

```bash
# Coloque o corpus completo em seu pipeline de ingestão de RAG.
curl -sSL https://docs.raydium.io/llms-full.txt -o raydium-docs.md
```

## Menu de transferência por página

Cada página de conteúdo tem um menu contextual (canto superior direito, ao lado do título) com estas ações com um clique:

- **Copy** — copie a página como Markdown simples.
- **View as Markdown** — abra o `.md` de origem em uma nova aba para que você possa salvá-lo.
- **Open in ChatGPT / Claude / Perplexity** — pré-carregue o conteúdo da página em um prompt de chat para a ferramenta nomeada.
- **Open in Cursor / VS Code** — abra um buffer no editor nomeado com o conteúdo da página.

Esta é a superfície correta quando você quer fazer uma pergunta a um modelo sobre uma única página sem configurar MCP.

## Arquivos de contexto pré-construídos para agentes de codificação

Se você está integrando o Raydium e quer que seu agente tenha o conhecimento de linha de base correto desde o início, coloque estes arquivos em seu projeto:

### `.cursorrules` / `.windsurfrules` / prompt do sistema do agente

```text
You are integrating with Raydium, a Solana DeFi protocol with five product
surfaces: AMM v4, CPMM, CLMM, Farm, and LaunchLab. Authoritative docs live
at docs.raydium.io. The official SDK is `@raydium-io/raydium-sdk-v2` (pin
the version you've verified against). For server-built swaps, prefer the
Trade API at transaction-v1.raydium.io. Always:

- Pass a `Connection` and `cluster` that match.
- Keep all amounts as `BN` instances; never call `.toNumber()` on amounts.
- Pre-fund the user's wallet for ATA creation rent.
- Pass an explicit `computeBudgetConfig` for any tx that may compete in
  high-volume windows.
- Re-fetch `poolInfo` immediately before high-value transactions; cached
  state goes stale.

When uncertain about an instruction's accounts list, defer to
`docs.raydium.io/products/<product>/accounts` and the on-chain IDL.
```

Salve como `.cursorrules` (Cursor), `.windsurfrules` (Windsurf), ou `CLAUDE.md` (Claude Code) — ou cole no prompt do sistema do seu agente. O nome exato do arquivo e a localização variam por versão da ferramenta, então verifique a documentação de configurações da sua ferramenta se ela não pegar o arquivo automaticamente.

### Lista de contexto fixado

Para agentes de codificação que aceitam uma lista de páginas "sempre incluir", esta lista é o contexto mínimo útil para a maioria das integrações do Raydium:

## Receita de indexação

Se você está construindo seu próprio RAG e não quer usar `llms-full.txt`, aqui está a receita canônica:

```ts
import { fetch } from "undici";

const INDEX_URL = "https://docs.raydium.io/llms.txt";
const BASE      = "https://docs.raydium.io";

const index    = await (await fetch(INDEX_URL)).text();
const pageUrls = [...index.matchAll(/^- \[(.+?)\]\((.+?)\)/gm)].map(m => m[2]);

for (const path of pageUrls) {
  const md = await (await fetch(`${BASE}${path}.md`)).text();
  // ingest md into your vector store, keyed by path
}
```

Cada página é servida em seu caminho canônico com um sufixo `.md` anexado (por exemplo, `/sdk-api/typescript-sdk` → `/sdk-api/typescript-sdk.md`).

## Ressalvas

- **Não cole estado privado em prompts.** O servidor MCP só conhece o que está na documentação pública. Chaves de carteira, credenciais de RPC e segredos similares nunca devem entrar no contexto do agente.
- **A saída de IA não é autoritária.** Modelos alucinam endereços de programa, nomes de instruções e listas de contas com preocupante facilidade. Sempre verifique contra a documentação e o IDL antes de confiar em transações geradas por agentes.
- **Desvio de versão.** SDK v2 é pré-1.0; agentes treinados em versões mais antigas podem emitir código que não compila contra sua versão fixada. Inclua a versão do SDK fixada no prompt do sistema do seu agente.
