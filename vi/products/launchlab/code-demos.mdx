## Thiết lập

Các demo ở đây phản ánh các tệp trong [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad). Bootstrap tuân theo [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) của repo demo:

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## Tạo một launch

Nguồn: [`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts) (và [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts) cho biến thể Bonk do API điều khiển)

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId: /* LaunchLab program ID from reference/program-addresses */,
  // Token metadata for the new base mint:
  name:   "Example Token",
  symbol: "EXMPL",
  uri:    "https://example.com/metadata.json",
  decimals: 6,

  // Curve params:
  curveType: 0,                                      // 0 = quadratic
  supply:    new BN(1_000_000_000).mul(new BN(10).pow(new BN(6))), // 1B base (6 dec)
  graduationFractionBps: 8000,                       // 80% → graduation
  initialK:  new BN("40"),                           // curve shape parameter

  // Quote side:
  quoteMint: NATIVE_MINT,                            // WSOL
  openTime:  new BN(Math.floor(Date.now() / 1000) + 60),  // opens in 1min

  // Fee policy:
  fees: {
    buyNumerator:   new BN(100),                     // 1.00%
    buyDenominator: new BN(10_000),
    sellNumerator:  new BN(100),
    sellDenominator: new BN(10_000),
    lpShare:         new BN(60),
    creatorShare:    new BN(20),
    protocolShare:   new BN(20),
    totalShare:      new BN(100),
  },

  postGraduationLpPolicy: "burn",                    // "burn" | "lock" | "toCreator"

  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Launch:", extInfo.launchState.toBase58());
console.log("Base mint:", extInfo.baseMint.toBase58());
console.log("Create tx:", txId);
```

Ghi chú:

- `initialK` là hệ số tỷ lệ cho đường cong bậc hai. Điều chỉnh nó để nhắm mục tiêu một giá CPMM mở cụ thể tại graduation. Xem [`products/launchlab/bonding-curve`](/vi/products/launchlab/bonding-curve) để xem cách dẫn xuất.
- SDK xử lý việc tạo base mint, metadata PDA và cả hai vault trong một giao dịch duy nhất. Nó có thể vượt quá 1232 byte nếu URI metadata dài; trong trường hợp đó, SDK chia thành hai giao dịch.
- Sau `Initialize`, launch không thể giao dịch cho đến `openTime`. Đặt `openTime` trước một hoặc hai phút để giảm cơ hội cho những người front-run nắm bắt lần mua đầu tiên.

## Lấy trạng thái launch

```ts
const launchId = new PublicKey("<LAUNCH_STATE>");

const launch = await raydium.launchpad.getLaunchById({ launchId });
console.log("Status:", ["Active","Graduated","Cancelled"][launch.status]);
console.log("Base sold:", launch.baseSold.toString(),
            "/", launch.baseSupplyMax.toString());
console.log("Quote collected:", launch.quoteReserveReal.toString(),
            "target:", launch.quoteReserveTarget.toString());
if (launch.status === 1) {
  console.log("Post-graduation CPMM pool:", launch.cpmmPoolState.toBase58());
}
```

`getLaunchById` trả về `LaunchState` được giải mã cộng với phân số "tiến độ hướng tới graduation" được tính toán dưới dạng `Decimal`.

## Mua — quote chính xác vào

Nguồn: [`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

```ts
const quoteIn        = new BN(1).mul(new BN(10).pow(new BN(9)));  // 1 SOL
const minimumBaseOut = new BN(0);  // accept any; tighten for production

// Preview the quote off-chain so your UI can show expected base_out:
const preview = raydium.launchpad.computeBuyBase({
  launchState: launch,
  quoteIn,
});
console.log("Expected base_out:", preview.baseOut.toString(),
            "price impact:", preview.priceImpact.toString());

const { execute } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn,
  minimumBaseOut,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

`computeBuyBase` phản ánh bộ giải Newton on-chain (đường cong bậc hai) hoặc CPMM-inverse dạng đóng (curve_type 1). Sử dụng nó để điền trường UI "Bạn nhận được".

## Mua — base chính xác ra

```ts
const baseOut         = new BN(1_000_000).mul(new BN(10).pow(new BN(6)));  // 1M base
const maximumQuoteIn  = new BN(2).mul(new BN(10).pow(new BN(9)));          // cap at 2 SOL

const { execute } = await raydium.launchpad.buyExactOut({
  launchInfo: launch,
  baseOut,
  maximumQuoteIn,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Hữu ích cho UI "mua chính xác X token". Từ chối với `ExceededSlippage` nếu đường cong đã di chuyển đủ để yêu cầu quote hiện tại vượt quá `maximumQuoteIn`.

## Bán

Nguồn: [`src/launchpad/sell.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/sell.ts)

```ts
const baseIn           = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M base
const minimumQuoteOut  = new BN(0);

const { execute } = await raydium.launchpad.sellExactIn({
  launchInfo: launch,
  baseIn,
  minimumQuoteOut,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Đường bán của đường cong đối xứng với đường mua: giảm `base_sold` bằng `baseIn` trả về `quote_out` bằng diện tích tích phân dưới đường cong giữa `base_sold − baseIn` và `base_sold`, trừ phí bán.

## Tự động graduation khi lần mua vượt ngưỡng

SDK xâu chuỗi một hướng dẫn `Graduate` bên trong giao dịch `buy*` khi nó phát hiện trạng thái sau mua sẽ vượt qua ngưỡng:

```ts
const { execute, willGraduate } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn: new BN(100).mul(new BN(10).pow(new BN(9))),    // large buy
  minimumBaseOut: new BN(0),
  txVersion: TxVersion.V0,
  autoGraduate: true,                                      // default
});

if (willGraduate) {
  console.log("This buy will trigger graduation.");
}

const { txId } = await execute({ sendAndConfirm: true });
```

Vì `Graduate` không cần phép, bất kỳ ai (bao gồm cả bot MEV) đều có thể cạnh tranh để đặt `Graduate` đầu tiên sau khi ngưỡng bị vượt qua — thường là vài giây sau, không phải vài phút. Người đầu tiên chỉ trả tiền thuê cho các tài khoản pool CPMM; họ không nhận được lợi ích nào khác.

## `Graduate` thủ công

Nếu `autoGraduate` bị tắt hoặc giao dịch vượt ngưỡng thất bại, bạn có thể kích hoạt graduation riêng biệt:

```ts
const { execute } = await raydium.launchpad.graduate({
  launchInfo: launch,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

Hoàn nguyên với `NotAtThreshold` nếu `quote_reserve_real < quote_reserve_target` tại thời điểm gửi. An toàn để thử lại — nỗ lực `Graduate` thứ hai sau khi thành công hoàn nguyên với `NotActive`.

## Theo dõi launch qua vòng đời của nó

Kết hợp lại, một script giám sát có thể trông như:

```ts
async function watch(launchId: PublicKey) {
  while (true) {
    const launch = await raydium.launchpad.getLaunchById({ launchId });
    const progress =
      Number(launch.quoteReserveReal) /
      Number(launch.quoteReserveTarget);

    console.log(
      `status=${["Active","Graduated","Cancelled"][launch.status]}`,
      `progress=${(progress * 100).toFixed(2)}%`,
      `num_buys=${launch.stateData.numBuys}`,
    );

    if (launch.status === 1) {
      console.log("Graduated to CPMM pool:", launch.cpmmPoolState.toBase58());
      break;
    }
    await new Promise(r => setTimeout(r, 10_000));
  }
}
```

## Theo dõi cấu hình và pool qua gRPC

Nguồn: [`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

Đăng ký chương trình LaunchLab qua Yellowstone gRPC và ghi nhật ký mọi cập nhật `GlobalConfig` và `PoolState` với chương trình token của mỗi mint. Hai bộ lọc `datasize` trên một đăng ký `accounts` tách hai loại tài khoản, vì vậy một luồng duy nhất bao gồm cả hai.

Demo là tài liệu tham khảo chính xác ngắn nhất để phân loại mint của launch, mà [bản phát hành quote-mint Token-2022](/vi/reference/changelog/2026-08-24-launchlab-token2022-quote-mint) làm cần thiết:

- **Pools** được phân loại trực tiếp từ `PoolState.token_program_flag`, giải mã bit0 cho base mint và bit1 cho quote mint mà không cần tìm nạp mint nào cả. Kiểm tra toàn bộ byte so với `0` — điều này đủ trong khi quote mint chỉ là legacy — sai lầm một base mint legacy là Token-2022 bất cứ khi nào quote mint là Token-2022.
- **Configs** không thể được phân loại theo cách đó: `GlobalConfig` lưu trữ địa chỉ quote mint của nó và không có cờ chương trình, vì vậy demo đọc chủ sở hữu tài khoản mint một lần và lưu vào bộ nhớ cache cho mỗi mint.

Nó cũng kiểm tra chéo hai cái với nhau, đây là một khẳng định hữu ích để giữ trong indexer của riêng bạn. Lưu ý rằng `create` so với `update` được suy ra từ bộ nhớ cache của demo, được gieo hạt tại khởi động từ `getProgramAccounts`; với việc gieo hạt đó bị vô hiệu hóa, hãy đọc "create" là "lần đầu tiên được nhìn thấy trên luồng này".

Quyền truy cập gRPC không phải là một phần của bề mặt RPC công khai — xem [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md) của repo demo.

## Rust CPI

Gọi LaunchLab từ chương trình Anchor của riêng bạn là hiếm (hầu hết các tích hợp launch chỉ ở phía TS). Nếu bạn làm, chương trình vận chuyển một crate Anchor `raydium_launchlab` với `cpi::accounts::Buy`, `cpi::accounts::Sell`, v.v. — mẫu phản ánh các ví dụ CPI CPMM / CLMM. Xem [`sdk-api/rust-cpi`](/vi/sdk-api/rust-cpi) để xem mẫu tổng quát sau khi trang này được điền đầy đủ.

## Những cạm bẫy

- **Số học chia phí sai lệch một.** Nếu `total_share` không chính xác bằng `lp_share + creator_share + protocol_share`, `Initialize` hoàn nguyên với `InvalidFeeShares`. Đặt `totalShare` bằng tổng.
- **Sử dụng quote mint không được phép.** `launch_config.allowed_quote_mints` là một danh sách cố định; truyền bất kỳ mint nào khác hoàn nguyên. Kiểm tra với `raydium.launchpad.getConfig()` trước.
- **Kích thước metadata.** Các chuỗi `uri` dài đẩy CPI Metaplex vượt quá ngân sách. Giữ `uri` dưới ~200 ký tự — hầu hết metadata JSON được lưu trữ trên CDN phù hợp dễ dàng.
- **Cuộc đua graduation.** Các bot tự động giám sát `quote_reserve_real` và front-run `Graduate` trong một hoặc hai slot sau khi ngưỡng bị vượt qua. Điều này là lành tính — nó chỉ tốn tiền thuê của họ — nhưng điều đó có nghĩa là UI của bạn nên coi các chuyển đổi `status` là các sự kiện nhanh.
