## Danh sách lệnh

| Nhóm | Lệnh | Có thể gọi bởi |
|-------|-------------|-------------|
| Cấu hình toàn cục | `CreateConfig` / `UpdateConfig` | Quản trị viên chương trình; cơ quan tạo cấu hình được ủy quyền cũng có thể gọi `CreateConfig` |
| Vòng đời khởi chạy | `Initialize` / `InitializeV2` | Bất kỳ ai (người tạo) — khởi chạy SPL Token; V2 ghi lại `amm_creator_fee_on` cho việc tốt nghiệp CPMM cuối cùng |
| Vòng đời khởi chạy | `InitializeWithToken2022` | Bất kỳ ai (người tạo) — khởi chạy Token-2022, `TransferFeeConfig` tùy chọn |
| Giao dịch | `BuyExactIn` / `BuyExactOut` | Bất kỳ ai — mua đầu vào chính xác / đầu ra chính xác trên đường cong liên kết |
| Giao dịch | `SellExactIn` / `SellExactOut` | Bất kỳ ai — bán đầu vào chính xác / đầu ra chính xác trên đường cong liên kết |
| Tốt nghiệp | `MigrateToAmm` | Ví di chuyển — tốt nghiệp AMM v4 kế thừa cho các pool được khởi tạo trước khi áp dụng việc tạo chỉ CPMM. |
| Tốt nghiệp | `MigrateToCpswap` | Ví di chuyển — tốt nghiệp thành CPMM. Tất cả các khởi chạy mới được khởi tạo sử dụng đường dẫn này. Bao bọc `InitializeWithPermission` trên CPMM. |
| Phí | `CollectFee` | Quản trị viên — quét phí giao thức từ một khởi chạy |
| Phí | `CollectMigrateFee` | Quản trị viên — quét phí di chuyển tích lũy |
| Phí | `ClaimCreatorFee` | Người tạo — yêu cầu phí người tạo tích lũy trong giai đoạn đường cong |
| Vesting | `CreateVestingAccount` | Người tạo — phân bổ token bị khóa cho người thụ hưởng, mở khóa sau khi tốt nghiệp |
| Vesting | `CreatePlatformVestingAccount` | Quản trị viên nền tảng — phân bổ token bị khóa cho người thụ hưởng phía nền tảng |
| Vesting | `ClaimVestedToken` | Người thụ hưởng — yêu cầu token đã mở khóa sau khoảng thời gian chờ |
| Cấu hình nền tảng | `CreatePlatformConfig` / `UpdatePlatformConfig` | Quản trị viên nền tảng |
| Cấu hình nền tảng | `UpdatePlatformCurveParam` / `RemovePlatformCurveParam` | Quản trị viên nền tảng — quản lý danh sách các hình dạng đường cong được phép trên mỗi nền tảng |
| Phí nền tảng | `ClaimPlatformFee` / `ClaimPlatformFeeFromVault` | Quản trị viên nền tảng |
| Truy cập nền tảng | `CreatePlatformAllowConfig` / `ClosePlatformAllowConfig` | Quản trị viên nền tảng — duy trì danh sách cho phép `GlobalConfig` được sử dụng khi nền tảng đó bật hạn chế |

Sự phân chia "ExactIn/ExactOut" phản ánh `SwapBaseInput` / `SwapBaseOutput` của CPMM — trên chuỗi chúng là các bộ phân biệt lệnh riêng biệt với làm tròn hơi khác nhau.

**Lựa chọn đường dẫn tốt nghiệp.** Mọi lệnh `Initialize`, `InitializeV2` và `InitializeWithToken2022` mới phải đặt `migrate_type = 1` (`CPSWAP`). Bất kỳ nỗ lực nào để khởi tạo một pool mới bị ràng buộc AMM v4 sẽ trả về `MigrateTypeNotMatch`. `amm_creator_fee_on` chỉ chọn xem phí người tạo CPMM kết quả có áp dụng cho token trích dẫn hay cả hai token; nó không chọn chương trình đích.

`MigrateToAmm` vẫn có thể gọi được cho một `PoolState` hiện có được khởi tạo với `migrate_type = 0` trước khi áp dụng hạn chế này. Bản phát hành không viết lại trạng thái pool hiện có hoặc xóa lệnh kế thừa.

## `Initialize`

Tạo một khởi chạy mới.

**Đối số**

```
launch_params: {
    curve_type:                 u8,
    base_supply_max:            u64,
    base_supply_graduation:     u64,
    k:                          u128,              // hoặc initial_virtual_quote_reserve cho curve_type=1
    open_time:                  u64,
    quote_mint:                 Pubkey,
    base_token_metadata: {                         // tên/ký hiệu/uri nội tuyến; chương trình CPI tới Metaplex
        name:   String,
        symbol: String,
        uri:    String,
    },
    fees: {
        buy_numerator:   u64,
        buy_denominator: u64,
        sell_numerator:  u64,
        sell_denominator: u64,
        lp_share:        u64,
        creator_share:   u64,
        protocol_share:  u64,
        total_share:     u64,
    },
    post_graduation_lp_policy:  u8,                // 0 = Burn, 1 = Lock, 2 = ToCreator
}
```

**Tài khoản** (tóm tắt)

| # | Tên | W | S | Ghi chú |
|---|------|---|---|-------|
| 1 | `creator` | W | S | Trả tiền thuê + tạo base mint. |
| 2 | `launch_config` |   |   | Liên kết cấu hình giao thức. |
| 3 | `launch_state` | W |   | Tài khoản mới. |
| 4 | `launch_authority` |   |   | PDA. |
| 5 | `base_mint` | W | S | Keypair mới (hoặc PDA) — lệnh này khởi tạo nó. |
| 6 | `base_vault` | W |   | ATA của `launch_authority` trên `base_mint`. |
| 7 | `quote_mint` |   |   | |
| 8 | `quote_vault` | W |   | ATA của `launch_authority` trên `quote_mint`. |
| 9 | `metadata` | W |   | PDA siêu dữ liệu Metaplex. |
| 10 | `metaplex_program` |   |   | |
| 11 | `token_program` |   |   | Chỉ SPL Token. |
| 12 | `system_program` |   |   | |
| 13 | `rent` |   |   | |

**Điều kiện trước**

- `quote_mint ∈ launch_config.allowed_quote_mints`.
- `base_supply_graduation ≤ base_supply_max`.
- Các tham số phí vượt qua kiểm tra `launch_config.max_*_fee_rate`.
- `open_time ≥ now − slop` (SDK áp dụng `≥ now`; chương trình chấp nhận backdating nhẹ).
- `curve_type` được công nhận.

**Điều kiện sau**

- `base_mint` có `supply = base_supply_max`, tất cả trong `base_vault`.
- `base_mint.mint_authority = launch_authority`, `freeze_authority = None`.
- `LaunchState` được khởi tạo với `status = Active`, `base_sold = 0`, `quote_reserve_real = 0`.
- `quote_reserve_target` được tính từ các tham số đường cong + `base_supply_graduation` + `buy_numerator` (xấp xỉ).

**Lỗi phổ biến** — `InvalidQuoteMint`, `FeeRateTooHigh`, `InvalidCurveParams`, `MathOverflow`.

## `Buy` (biến chính tắc: `BuyExactIn`)

Người dùng cung cấp một `quote_in` cố định; đường cong tính toán `base_out`.

**Đối số**

```
quote_in:          u64
minimum_base_out:  u64
```

**Tài khoản**

| # | Tên | W | S |
|---|------|---|---|
| 1 | `user` | W | S |
| 2 | `launch_state` | W |   |
| 3 | `launch_authority` |   |   |
| 4 | `base_vault` | W |   |
| 5 | `quote_vault` | W |   |
| 6 | `user_base_ata` | W |   |
| 7 | `user_quote_ata` | W |   |
| 8 | `base_mint` |   |   |
| 9 | `quote_mint` |   |   |
| 10 | `token_program` |   |   |
| 11 | `associated_token_program` |   |   |
| 12 | `system_program` |   |   |

**Điều kiện trước**

- `launch_state.status == Active`.
- `now ≥ open_time`.
- `user_quote_ata.balance ≥ quote_in`.
- `quote_in > 0`.

**Hiệu ứng**

1. Chia `quote_in` thành `quote_in_after_fee` và các phần phí.
2. Newton-giải đường cong cho `base_out` được cung cấp bởi post-fee quote.
3. `require(base_out ≥ minimum_base_out)` nếu không hoàn nguyên `ExceededSlippage`.
4. Di chuyển `quote_in` người dùng → vault. Di chuyển `base_out` vault → người dùng.
5. Cập nhật `base_sold += base_out`, `quote_reserve_real += quote_in_after_fee × (lp_share / total_share)`.
6. Cập nhật bộ đếm phí (`protocol_fees_quote`, `creator_fees_quote`).
7. `state_data.num_buys += 1`.
8. Nếu `quote_reserve_real ≥ quote_reserve_target` sau khi cập nhật, SDK thường xuyên chuỗi một lệnh `Graduate` trong cùng một giao dịch. Chương trình không tự động tốt nghiệp bên trong `Buy` — một `Graduate` tiếp theo là bắt buộc.

## `BuyExactOut`

Người dùng chỉ định `base_out` chính xác; chương trình tính toán `quote_in`.

**Đối số**

```
base_out:      u64
maximum_quote_in: u64
```

Các tài khoản giống như `BuyExactIn`. Sử dụng tích phân bậc hai dạng đóng (hoặc CPMM nghịch đảo, cho curve_type 1) thay vì lặp lại Newton.

## `Sell` / `SellExactIn` / `SellExactOut`

Gương của `Buy`. Người dùng trả lại `base_in` cho đường cong và nhận `quote_out`. Phí được khấu trừ từ `quote_out`, vì vậy người dùng nhận được ít hơn các khoản thu nhập tích hợp thô.

**Điều kiện trước** —

- `user_base_ata.balance ≥ base_in`.
- Bán không thể đẩy `base_sold` dưới 0 (dư thừa với điều trên vì kế toán nhất quán).
- Khởi chạy là `Active`.

**Hiệu ứng** — đối xứng với `Buy`. `base_sold` giảm, `quote_reserve_real` giảm. Phí vẫn tích lũy.

## `MigrateToAmm` / `MigrateToCpswap`

Tốt nghiệp một khởi chạy thành một pool có thể giao dịch được khi đường cong đã đạt `total_quote_fund_raising`. Các khởi chạy mới chỉ dành cho CPMM. `MigrateToAmm` được giữ lại cho các pool hiện có có `migrate_type` được lưu trữ là `0`.

**Ai ký**

- `MigrateToAmm` — `migrate_to_amm_wallet` được ghi lại trên `GlobalConfig` liên kết.
- `MigrateToCpswap` — `migrate_to_cpswap_wallet` được ghi lại trên `GlobalConfig` liên kết.

Những ví này thường được giữ bởi crank tốt nghiệp do Raydium vận hành; trong thực tế tốt nghiệp diễn ra vài giây sau khi ngưỡng bị vượt qua, bất kể ai kích hoạt lần mua cuối cùng.

**Đối số**

`MigrateToAmm` lấy ba (chủ yếu là các tham số thị trường OpenBook mà chương trình chuyển tiếp tới AMM v4):

```
base_lot_size:               u64
quote_lot_size:              u64
market_vault_signer_nonce:   u8
```

`MigrateToCpswap` không lấy gì.

**Hiệu ứng (chung cho cả hai)**

1. Xác minh `pool_state.status == Migrate` (tức là `quote_reserve_target` đã được đạt). Nếu không hoàn nguyên với `PoolMigrated` (trạng thái đã là `Migrated`) hoặc `PoolFunding` (vẫn đang tài trợ).
2. Xác minh `pool_state.migrate_type` khớp với lệnh (`0` cho AMM, `1` cho CPMM). Nếu không hoàn nguyên với `MigrateTypeNotMatch`.
3. Tính toán các dự trữ sau tốt nghiệp:
   - `base_amount_out = base_vault.amount − vesting_schedule.total_locked_amount`
   - `quote_amount_out = quote_vault.amount − quote_protocol_fee − migrate_fee − platform_fee`
4. CPI vào chương trình đích (`AMM v4 Initialize2` hoặc `CPMM InitializeWithPermission`) với các dự trữ đó để tạo pool sau tốt nghiệp.
5. Đối với các di chuyển CPMM được thực hiện sau nâng cấp 2026-08-14, kết hợp `platform_scale + creator_scale` thành một cổ phần LP bị khóa do nền tảng sở hữu và tạo ra nhiều nhất một NFT Fee Key cho `platform_nft_wallet`. Đốt phần còn lại `burn_scale`. Trước nâng cấp, `creator_scale` bị khóa riêng biệt và Fee Key của nó đã được gửi tới người tạo token. Các di chuyển lịch sử đã hoàn thành không được sửa đổi. Đối với tốt nghiệp AMM v4 kế thừa, việc xử lý LP tuân theo luồng hiện có của lệnh đó.
6. Thu hồi `base_mint.mint_authority` (đặt thành `None`).
7. Lật `pool_state.status = Migrated`, đặt `vesting_schedule.start_time = block_time + cliff_period`.

**Điều kiện sau** — `BuyExactIn`, `BuyExactOut`, `SellExactIn`, `SellExactOut` sẽ từ chối từ thời điểm này trở đi với `PoolMigrated`. Pool AMM kết quả là chính tắc và giao dịch như bất kỳ pool AMM v4 / CPMM nào khác.

**Lỗi phổ biến** — `PoolFunding`, `PoolMigrated`, `MigrateTypeNotMatch`, `InvalidCpSwapConfig`, `MathOverflow`.

### Các tài khoản còn lại của di chuyển CPMM

Các máy khách xây dựng `MigrateToCpswap` phải sử dụng các chỉ số `remaining_accounts` cố định này:

| Chỉ số | Tài khoản |
|---|---|
| 0–4 | Chủ sở hữu Fee Key nền tảng, mint, tài khoản token, PDA thanh khoản bị khóa và tài khoản siêu dữ liệu |
| 5 | Người tạo khởi chạy gốc; được sử dụng khi `platform_cp_creator` không được đặt |
| 6 | PDA quyền CPMM được lấy từ `[b"permission", launch_authority]` |
| 7 | `platform_cp_creator` được cấu hình; được sử dụng khi trường không phải là mặc định |
| 8 | PDA support-mint CPMM cho `mint0` được sắp xếp, được lấy từ `[b"support_mint", mint0]` |
| 9 | PDA support-mint CPMM cho `mint1` được sắp xếp, được lấy từ `[b"support_mint", mint1]` |

Lệnh yêu cầu ít nhất mười tài khoản còn lại trên đường dẫn được nâng cấp. Các tài khoản support-mint là đầu vào CPI chỉ đọc. Lấy cả hai địa chỉ ngay cả khi mint không có bản ghi hỗ trợ được khởi tạo. Các trình xây dựng cũ vẫn nối các tài khoản khóa người tạo hoặc bỏ qua chỉ số 8–9 phải được cập nhật.

## Danh sách cho phép `GlobalConfig` nền tảng

`PlatformConfig.restrict_global_config` kiểm soát kiểm tra:

- `0`: nền tảng chấp nhận bất kỳ `GlobalConfig` nào hợp lệ; không cần tài khoản cho phép.
- `1`: `Initialize`, `InitializeV2` và `InitializeWithToken2022` phải bao gồm `PlatformAllowConfig` phù hợp ở bất kỳ đâu trong `remaining_accounts`.

Quản trị viên nền tảng tạo hoặc đóng PDA bằng `CreatePlatformAllowConfig` và `ClosePlatformAllowConfig`. Các hạt giống của nó là `[b"platform_allow_config", platform_config, global_config]`. Các lệnh `PlatformGlobalAccess` do quản trị viên quản lý trước đây và PDA đã bị loại bỏ.

## `CollectFee`

Quét quản trị viên của phí giao dịch tích lũy của giao thức trên một khởi chạy duy nhất.

**Đối số** — không có.

**Tài khoản**

| # | Tên | W | S | Ghi chú |
|---|------|---|---|-------|
| 1 | `protocol_fee_owner` |   | S | Phải bằng `global_config.protocol_fee_owner`. |
| 2 | `authority` |   |   | PDA `[b"vault_auth_seed"]`; ký chuyển vault. |
| 3 | `pool_state` | W |   | Đột biến để không `quote_protocol_fee`. |
| 4 | `global_config` |   |   | Nguồn sự thật cho người ký. |
| 5 | `quote_vault` | W |   | Được thoát ra bởi `quote_protocol_fee`. |
| 6 | `recipient_token_account` | W |   | ATA của `protocol_fee_owner` trên `quote_mint`. |
| 7 | `quote_mint` |   |   | |
| 8 | `token_program` |   |   | SPL Token (quote mint luôn là SPL Token). |

**Hiệu ứng** — chuyển `pool_state.quote_protocol_fee` từ `quote_vault` tới `recipient_token_account`, sau đó không bộ đếm. Có thể gọi bất kỳ lúc nào sau lần mua đầu tiên.

## `CollectMigrateFee`

Quét quản trị viên của phí di chuyển tích lũy tại tốt nghiệp. Hình dạng tài khoản giống như `CollectFee` với `migrate_fee_owner` là người ký (thay vì `protocol_fee_owner`) và `pool_state.migrate_fee` là bộ đếm được thoát ra.

## `ClaimCreatorFee`

Quét mỗi người tạo của phí người tạo tích lũy trên **mọi khởi chạy mà người tạo sở hữu** sử dụng cùng một quote mint. Thoát ra khỏi vault phí mỗi người tạo, không phải vault mỗi pool.

**Đối số** — không có.

**Tài khoản**

| # | Tên | W | S | Ghi chú |
|---|------|---|---|-------|
| 1 | `creator` | W | S | Người tạo pool. |
| 2 | `fee_vault_authority` |   |   | PDA `[b"creator_fee_vault_auth_seed"]`. |
| 3 | `creator_fee_vault` | W |   | PDA tại hạt giống `[creator, quote_mint]`; vault người tạo tổng hợp. |
| 4 | `recipient_token_account` | W |   | `init_if_needed`; ATA của `creator` trên `quote_mint`. |
| 5 | `quote_mint` |   |   | |
| 6 | `token_program` |   |   | |
| 7 | `system_program` |   |   | Để tạo ATA nếu cần. |
| 8 | `associated_token_program` |   |   | |

**Hiệu ứng** — chuyển toàn bộ số dư của `creator_fee_vault` tới `recipient_token_account`. Hoàn nguyên với kiểm tra yêu cầu lớn hơn không nếu vault trống.

## `ClaimPlatformFee`

Quét mỗi nền tảng thoát ra khỏi vault trích dẫn của khởi chạy trực tiếp. Sử dụng cái này khi một nền tảng muốn yêu cầu phần của nó cho một khởi chạy cụ thể mà không cần đi qua vault nền tảng tổng hợp.

**Đối số** — không có.

**Tài khoản**

| # | Tên | W | S | Ghi chú |
|---|------|---|---|-------|
| 1 | `platform_fee_wallet` | W | S | Phải bằng `platform_config.platform_fee_wallet`. |
| 2 | `authority` |   |   | PDA `[b"vault_auth_seed"]`. |
| 3 | `pool_state` | W |   | Thoát ra bởi `pool_state.platform_fee`. |
| 4 | `platform_config` |   |   | Nguồn sự thật cho người ký. |
| 5 | `quote_vault` | W |   | Thoát ra. |
