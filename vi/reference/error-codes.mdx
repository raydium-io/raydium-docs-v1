## Cách mã lỗi Anchor hoạt động

Anchor gán cho mỗi biến thể của enum `ErrorCode` của chương trình một mã số bắt đầu từ `6000`. Một giao dịch thất bại sẽ hiển thị:

- **Mã lỗi số** (ví dụ: `0x1771` = 6001) trong nhật ký giao dịch.
- **Tên lỗi** (ví dụ: `InvalidOwner`) từ IDL.
- **Chuỗi `#[msg(...)]`** mà Anchor phát ra trong `log_messages`.

Những người tích hợp nên khớp với **mã số**, không phải chuỗi thông báo (chuỗi có thể được diễn đạt lại mà không cần tăng phiên bản).

```ts
// Ví dụ: phát hiện lỗi slippage của CPMM và hiển thị thông báo UX sạch sẽ.
const CPMM_EXCEEDED_SLIPPAGE = 6005;

try {
  await sdk.cpmm.swap({ ... });
} catch (err: any) {
  const code = err?.error?.errorCode?.number ?? err?.code;
  if (code === CPMM_EXCEEDED_SLIPPAGE) {
    showToast("Price moved past your slippage tolerance. Increase slippage or retry.");
    return;
  }
  throw err;
}
```

> **Ghi chú về đánh số lại.** Enum `ErrorCode` của CLMM đã được đánh số lại trong bản phát hành này: năm biến thể cũ (`LOK`, `ZeroMintAmount`, `InvalidLiquidity`, `TransactionTooOld`, `InvalidRewardDesiredAmount`) và một số lỗi chính tả (`Liquitity`, `enought`, `emissiones`) đã bị xóa/sửa, và mười một biến thể mới được thêm (`6040`–`6050`) bởi bản phát hành limit-order; `6051` (`InvalidTickArrayBitmapExtensionAccount`) đến từ một thay đổi riêng biệt, sau này. Điều đó tạo ra 52 biến thể, `6000`–`6051`, là số lượng mà IDL on-chain của chương trình được triển khai hiện tại báo cáo. Bản nâng cấp [2026-09-30](/vi/reference/changelog/2026-09-30-clmm-anchor-1-and-excess-lamports) thêm `6052` mà không thay đổi bất cứ điều gì, tổng cộng 53. Vì Anchor đánh số lỗi theo thứ tự nguồn, mọi mã ở hoặc sau `6000` đã thay đổi so với các bản dựng trước phát hành. Các client đã hard-code các mã số so với phiên bản trước cần ánh xạ lại.

Nguồn tái tạo: [github.com/raydium-io/raydium-clmm — error.rs](https://github.com/raydium-io/raydium-clmm/blob/master/programs/amm/src/error.rs).

### AMM v4: `AmmError` không được đánh số theo kiểu Anchor

AMM v4 có từ trước Anchor. `AmmError` là một enum `thiserror` thuần túy với `FromPrimitive`, được chuyển đổi thông qua `ProgramError::Custom(e as u32)`, vì vậy các mã của nó bắt đầu từ **`0`**, không phải `6000` — và, giống như của Anchor, được gán theo thứ tự nguồn. Bản nâng cấp 2026-09 thêm một biến thể:

| Mã | Biến thể | Chuỗi `#[error]` | Nguyên nhân |
|---|---|---|---|
| 60 | `LamportsCalculateError` | Lỗi tính toán lamports. | `WithdrawExcessLamports` quét một tài khoản SOL được bao bọc và vòng `SyncNative` → `UnwrapLamports` không để lại số dư token được bao bọc chính xác ở nơi nó bắt đầu. Đường dẫn chỉ dành cho quản trị viên. |

Các mã `0`–`59` không thay đổi, vì vậy không có gì bị dịch chuyển. Trong nhật ký giao dịch, điều này hiển thị dưới dạng `custom program error: 0x3c`. Nguồn tái tạo: [github.com/raydium-io/raydium-amm — error.rs](https://github.com/raydium-io/raydium-amm/blob/master/program/src/error.rs).

## Ánh xạ lỗi SDK tới lỗi chương trình

SDK TypeScript chính thức bao bọc các lỗi trên chuỗi thành `SendTransactionError` và, đối với các chương trình Anchor, `AnchorError`:

```ts
import { AnchorError } from "@anchor-lang/core";

try {
  await sdk.cpmm.swap({ ... });
} catch (err) {
  if (err instanceof AnchorError) {
    console.log(err.error.errorCode.number, err.error.errorCode.code, err.error.errorMessage);
    // 6005 ExceededSlippage "Exceeds desired slippage limit"
  } else {
    // Raw SendTransactionError — inspect err.logs for the "custom program error: 0x..." line.
  }
}
```

Nếu bạn không sử dụng Anchor phía máy khách, hãy phân tích nhật ký giao dịch:

```
Program <ProgramID> invoke [1]
Program log: AnchorError caused by account: pool_state. Error Code: ExceededSlippage. Error Number: 6005. Error Message: Exceeds desired slippage limit.
```

Mẫu `Error Number: (\d+)` ổn định trên các phiên bản Anchor và an toàn để khớp.

## Tái tạo các bảng này

Khi một chương trình được nâng cấp và thêm một lỗi mới, hãy trích xuất lại từ nguồn:

```bash
# Clone and grep the error enum in order.
git clone --depth=1 https://github.com/raydium-io/raydium-cp-swap
awk '/#\[msg\(/{ gsub(/^[ \t]*#\[msg\("|"\)\][ \t]*/,""); m=$0; getline; gsub(/,/,""); gsub(/^[ \t]+/,""); print "6000+++\t" $0 "\t" m }' \
  raydium-cp-swap/programs/cp-swap/src/error.rs
# Replace 6000+++ with monotonically-increasing 6000,6001,... Append new rows to the table above.
```

Luôn cập nhật [`reference/changelog`](/vi/reference/changelog) khi một biến thể mới được thêm, để các nhà tích hợp nâng cấp SDK biết cần làm mới các trình xử lý lỗi của họ.
