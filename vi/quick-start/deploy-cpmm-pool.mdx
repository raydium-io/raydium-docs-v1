## Chuẩn bị

Hãy chắc chắn rằng bạn đã đọc [Điều kiện tiên quyết Bắt đầu nhanh](/vi/quick-start) và có `RPC_URL`, `KEYPAIR`, cũng như các thư viện phụ thuộc đã cài đặt.

Bạn cũng cần **nạp ví với các số lượng khởi tạo của cả hai mint**, cộng với đủ SOL để chi trả phí tạo pool một lần và tiền thuê tài khoản (~0,19 SOL tổng cộng trên mainnet — xem [`reference/fee-comparison`](/vi/reference/fee-comparison#creation-costs) để xem chi tiết phí/tiền thuê, hoặc [`ray/protocol-fees`](/vi/ray/protocol-fees#pool-creation-fees) chỉ để xem phí).

**Chạy trên devnet.** Chỉ thay đổi `cluster` thành `"devnet"` là chưa đủ. Script này sử dụng hai import được đặt tên không tuân theo `cluster`: `programId: CREATE_CPMM_POOL_PROGRAM` và `poolFeeAccount: CREATE_CPMM_POOL_FEE_ACC`, cả hai đều là hằng số mainnet. Hãy import `DEVNET_PROGRAM_ID` từ SDK và sử dụng `DEVNET_PROGRAM_ID.CREATE_CPMM_POOL_PROGRAM` và `DEVNET_PROGRAM_ID.CREATE_CPMM_POOL_FEE_ACC` thay thế — cùng mẫu mà [script CLMM](/vi/quick-start/deploy-clmm-pool) sử dụng.

## Script

Lưu dưới dạng `create-cpmm.mjs`:

```ts create-cpmm.mjs icon="js"
import { Connection, Keypair, PublicKey } from "@solana/web3.js";
import {
  Raydium,
  TxVersion,
  CREATE_CPMM_POOL_PROGRAM,
  CREATE_CPMM_POOL_FEE_ACC,
} from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

// ── Config from env ──────────────────────────────────────────────
const RPC_URL  = process.env.RPC_URL  ?? "https://api.mainnet-beta.solana.com";
const KEYPAIR  = process.env.KEYPAIR  ?? `${process.env.HOME}/.config/solana/id.json`;
const MINT_A   = process.env.MINT_A;   // required, base58
const MINT_B   = process.env.MINT_B;   // required, base58
const AMOUNT_A = process.env.AMOUNT_A; // required, integer raw units
const AMOUNT_B = process.env.AMOUNT_B; // required, integer raw units

if (!MINT_A || !MINT_B || !AMOUNT_A || !AMOUNT_B) {
  console.error("Set MINT_A, MINT_B, AMOUNT_A, AMOUNT_B env vars.");
  process.exit(1);
}

// ── Setup ────────────────────────────────────────────────────────
const connection = new Connection(RPC_URL, "confirmed");
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(KEYPAIR, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});

// ── Pick the 0.25% fee tier ─────────────────────────────────────
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0);
if (!feeConfig) throw new Error("0.25% fee tier not found in CPMM configs.");

// ── Resolve mint metadata (Token-2022-aware) ────────────────────
const mintA = await raydium.token.getTokenInfo(new PublicKey(MINT_A));
const mintB = await raydium.token.getTokenInfo(new PublicKey(MINT_B));

// ── Build and execute ───────────────────────────────────────────
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA,
  mintB,
  mintAAmount:     new BN(AMOUNT_A),
  mintBAmount:     new BN(AMOUNT_B),
  startTime:       new BN(0), // open immediately
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
  computeBudgetConfig: {
    units: 600_000,
    microLamports: 100_000,
  },
});

const { txId } = await execute({ sendAndConfirm: true });

console.log(`Pool ID:  ${extInfo.address.poolId.toBase58()}`);
console.log(`LP mint:  ${extInfo.address.lpMint.toBase58()}`);
console.log(`Vault A:  ${extInfo.address.vaultA.toBase58()}`);
console.log(`Vault B:  ${extInfo.address.vaultB.toBase58()}`);
console.log(`Tx:       https://solscan.io/tx/${txId}`);
```

## Chạy script

Ví dụ: tạo một pool SOL/USDC với 1 SOL và 160 USDC khởi tạo:

```bash icon="terminal"
export MINT_A="So11111111111111111111111111111111111111112"   # wSOL
export MINT_B="EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"   # USDC
export AMOUNT_A="1000000000"   # 1 SOL (9 decimals)
export AMOUNT_B="160000000"    # 160 USDC (6 decimals)

node create-cpmm.mjs
```

Kết quả dự kiến:

```text
Pool ID:  HgC5...3kXb
LP mint:  4ZAS...9rkV
Vault A:  J9Mu...mP2k
Vault B:  AaJq...8wxx
Tx:       https://solscan.io/tx/5dQ...
```

## Điều gì vừa xảy ra

1. **`getCpmmConfigs`** lấy danh sách các mức phí trực tiếp từ `api-v3.raydium.io` và chọn index 0 (mức phí 0,25% — xem [`reference/fee-comparison`](/vi/reference/fee-comparison) để xem bộ đầy đủ).
2. **`getTokenInfo`** giải quyết metadata của mỗi mint, bao gồm chương trình token nào sở hữu nó. CPMM chấp nhận cả mint SPL Token và Token-2022; SDK định tuyến tự động.
3. **`createPool`** xây dựng một giao dịch duy nhất thực hiện:
   - sắp xếp các mint theo thứ tự chính tắc,
   - dẫn xuất PDA pool, vault, LP mint, và authority,
   - thanh toán `create_pool_fee` một lần tới `CREATE_CPMM_POOL_FEE_ACC`,
   - tạo ATA của người gọi nếu thiếu,
   - khởi tạo vault với `AMOUNT_A` và `AMOUNT_B`.
4. **Giá ban đầu** được đặt bởi tỷ lệ khởi tạo: `price = AMOUNT_B / AMOUNT_A` sau điều chỉnh số thập phân. Hãy chọn cẩn thận — bot sẽ arbitrage bất kỳ sai giá nào trong vòng vài giây sau khi pool mở.
5. **`startTime: new BN(0)`** mở giao dịch ngay lập tức. Để chuẩn bị thanh khoản trước khi mở cho công chúng, đặt một timestamp Unix trong tương lai.

## Lỗi phổ biến

- **`pool already exists`** — Một pool đã tồn tại cho cặp mint này ở mức phí này. Hãy tra cứu trước khi tạo.
- **`insufficient funds`** — Ví của bạn không có đủ `MINT_A`, `MINT_B`, hoặc SOL (cho phí tạo pool + tiền thuê).
- **`Token-2022 extension not supported`** — Một trong các mint của bạn sử dụng một extension mà CPMM không chấp nhận. Xem [`reference/token-2022-support`](/vi/reference/token-2022-support).

## Sau khi triển khai

Bạn có thể ngay lập tức swap với pool mới — script [Swap từ CLI](/vi/quick-start/swap-from-cli) chấp nhận `POOL_ID` mới của bạn trực tiếp. Các aggregator (Jupiter, v.v.) sẽ lập chỉ mục pool mới trong vòng vài phút.
