## Công cụ cốt lõi

### Solana CLI

Giao diện dòng lệnh chính thức để tương tác với các cụm Solana — quản lý ví, gọi RPC, triển khai chương trình.

Cài đặt:

```bash
# Phiên bản mà các chương trình Raydium được xây dựng và kiểm tra
sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.10/install)"

# Hoặc theo dõi một kênh thay vì một thẻ
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

Xác minh:

```bash
solana --version   # → solana-cli 3.1.10 (... client:Agave)
```

<Note>
  **Máy chủ cài đặt đã thay đổi.** `release.solana.com` thuộc về Solana Labs; client hiện được duy trì bởi Anza dưới tên **Agave**, và các bản phát hành được phục vụ từ `release.anza.xyz`. Tệp nhị phân tự cập nhật là `agave-install` (`solana-install` được giữ lại như một bí danh kế thừa), vì vậy `agave-install update` và `agave-install init <version>` là các cách viết hiện tại. Tài liệu của Solana cũng cung cấp một trình cài đặt một lệnh kéo CLI, Rust và Anchor cùng nhau:

  ```bash
  curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
  ```

  Trình cài đặt đó theo dõi ý tưởng của riêng nó về phiên bản hiện tại và có thể cung cấp cho bạn một Anchor khác với phiên bản mà các chương trình Raydium sử dụng — kiểm tra `anchor --version` sau đó.
</Note>

Cấu hình cho mainnet:

```bash
solana config set --url https://api.mainnet-beta.solana.com
solana config set --keypair ~/.config/solana/id.json
solana-keygen new                           # tạo ví nếu bạn chưa có
solana address                              # khóa công khai của bạn
```

Để kiểm tra Raydium, bạn hầu như luôn muốn một ví devnet được tài trợ:

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2                            # 2 SOL để kiểm tra
```

### SPL Token CLI

CLI chính thức cho các hoạt động SPL Token / Token-2022 — tạo mint, mint token, chuyển giao.

Cài đặt (bao gồm trong Solana CLI):

```bash
spl-token --version
```

Các hoạt động phổ biến:

```bash
spl-token create-token                                  # tạo một mint SPL Token
spl-token create-token --program-id TOKEN_2022 ...      # tạo một mint Token-2022
spl-token create-account <MINT>                         # tạo một ATA
spl-token mint <MINT> 1000                              # mint 1000 token vào ATA của bạn
spl-token transfer <MINT> 100 <RECIPIENT>               # chuyển 100
spl-token display <ACCOUNT_OR_MINT>                     # kiểm tra
```

### Anchor CLI

Cần thiết để lấy IDL của Raydium, xây dựng client và xác minh chương trình.

Cài đặt:

```bash
cargo install --git https://github.com/solana-foundation/anchor avm --locked --force
avm install 1.0.2
avm use 1.0.2
anchor --version   # → anchor-cli 1.0.2
```

<Note>
  **Anchor đã chuyển kho lưu trữ và phiên bản chính.** Kho lưu trữ chính thức hiện là `github.com/solana-foundation/anchor` (trước đây là `coral-xyz/anchor`), và Anchor 1.0 là dòng phát hành đầu tiên mà các chương trình Raydium sử dụng — CPMM và LaunchLab đều sử dụng `anchor-lang`/`anchor-spl` `=1.0.2` tính đến bản nâng cấp 2026-09-09, tăng từ `0.32.1`. `avm` có thể giữ nhiều phiên bản; `avm use 1.0.2` là cách làm cho `anchor build` tái tạo các tạo phẩm của Raydium. Anchor 1.1 và 1.2 tồn tại và xây dựng tốt cho các chương trình của riêng bạn, nhưng một crate CPI được biên dịch với một `anchor-lang` phụ khác với phiên bản mà chương trình đích sử dụng sẽ không liên kết — xem [`sdk-api/rust-cpi`](/vi/sdk-api/rust-cpi).
</Note>

Các hoạt động phổ biến:

```bash
anchor idl fetch <PROGRAM_ID> -o program.idl.json       # lấy IDL on-chain
anchor idl init -f idl.json <PROGRAM_ID>                # tải lên một IDL
anchor build                                             # xây dựng một chương trình từ nguồn
```

## Thiết lập TypeScript

Đường dẫn tích hợp chính cho Raydium.

### Gói

```bash
npm install \
  @solana/web3.js \
  @solana/spl-token \
  @anchor-lang/core \
  @raydium-io/raydium-sdk-v2 \
  bn.js \
  decimal.js
```

Các phiên bản được biết là hoạt động cùng nhau tính đến tháng 9 năm 2026:

| Gói | Phiên bản | Ghi chú |
|---------|---------|------|
| `@solana/web3.js` | `^1.95` | API 1.x. `2.x` / `3.x` là một bề mặt API khác, không tương thích; SDK Raydium nhắm mục tiêu 1.x. |
| `@solana/spl-token` | `^0.4.15` | 0.4.15 là phiên bản hiển thị `createUnwrapLamportsInstruction` — xem [reclaimable rent](/vi/solana-fundamentals/rent-and-reclaimable-rent). |
| `@anchor-lang/core` | `^1.0` | Client TypeScript Anchor 1.x. |
| `@raydium-io/raydium-sdk-v2` | `0.2.64-alpha` | Phiên bản mà mọi bản demo mã trong tài liệu này sử dụng. |

<Note>
  **`@anchor-lang/core` bị đóng băng; gói hiện là `@anchor-lang/core`.** `@anchor-lang/core` dừng lại ở `0.32.1` khi Anchor chuyển sang Solana Foundation. Anchor 1.x xuất bản dưới dạng `@anchor-lang/core`, và các kho lưu trữ chương trình của Raydium đã chuyển bộ kiểm tra của chúng sang nó trong bản nâng cấp 2026-09-09. Các lần nhập bạn thực sự sử dụng không thay đổi — `import { Program, BN, AnchorProvider } from "@anchor-lang/core"` — vì vậy di chuyển là một đổi tên gói cộng với cập nhật tệp khóa.

  Hai ghi chú về hành vi nếu bạn chuyển từ `0.3x`: `.accounts({...})` hiện chỉ chấp nhận các tài khoản mà Anchor không thể tự giải quyết, vì vậy một trình xây dựng chuyển toàn bộ bộ nên gọi `.accountsPartial({...})` thay thế; và `@anchor-lang/core/dist/cjs/utils/token` là nơi các trợ giúp như `ASSOCIATED_PROGRAM_ID` được chuyển đến.
</Note>

### Tập lệnh tối thiểu

```ts
import { Connection, Keypair } from "@solana/web3.js";
import { Raydium } from "@raydium-io/raydium-sdk-v2";

const connection = new Connection("https://api.mainnet-beta.solana.com", "confirmed");
const owner      = Keypair.fromSecretKey(/* your key */);

const raydium = await Raydium.load({
  connection,
  owner,
  cluster:      "mainnet",
  disableFeatureCheck: true,
});

// `ids` là một danh sách được phân tách bằng dấu phẩy, và lệnh gọi trả về một mảng
const [poolInfo] = await raydium.api.fetchPoolById({ ids: "..." });
console.log(poolInfo);
```

Xem [`sdk-api/typescript-sdk`](/vi/sdk-api/typescript-sdk) để tham khảo SDK đầy đủ.

## Thiết lập Rust

Để tích hợp CPI và các chương trình on-chain.

### Bộ công cụ

```bash
rustup install 1.91.0           # những gì các chương trình Raydium sử dụng
rustup default 1.91.0
rustup component add rustfmt clippy
agave-install init 3.1.10       # Bộ công cụ SBF được bao gồm
```

Xây dựng các chương trình với `cargo build-sbf` (cách viết cũ `cargo build-bpf` đã biến mất).

### Program Cargo.toml cho tích hợp CPI Raydium

```toml
# Tích hợp CPMM (Anchor 1.0)
[dependencies]
anchor-lang        = "=1.0.2"
anchor-spl         = "=1.0.2"
raydium-cp-swap    = { version = "0.2", features = ["cpi"] }
```

```toml
# Tích hợp CLMM — vẫn là Anchor 0.32, vì vậy nó cần crate riêng của nó
[dependencies]
anchor-lang        = "=0.32.1"
anchor-spl         = "=0.32.1"
raydium-clmm       = { version = "0.1", features = ["cpi"] }
```

Ghim `anchor-lang` và `anchor-spl` với `=` vào phiên bản mà chương trình đích sử dụng. Tính đến 2026-09, CPMM sử dụng `=1.0.2` và CLMM vẫn sử dụng `=0.32.1`, vì vậy **một crate duy nhất không thể CPI vào cả hai** — xem [`sdk-api/rust-cpi`](/vi/sdk-api/rust-cpi#cargo-dependencies).

Tính năng `"cpi"` nhập mô-đun `cpi` với các trợ giúp CPI (vì vậy bạn có thể `raydium_cp_swap::cpi::swap_base_input(...)`). Xem [`sdk-api/rust-cpi`](/vi/sdk-api/rust-cpi).

## Thiết lập Python

Đường dẫn tích hợp thứ cấp — phổ biến cho các nhà phát triển bot.

### Gói

```bash
pip install solders solana anchorpy
```

Phiên bản:

| Gói | Tên PyPI | Phiên bản |
|---------|-----------|---------|
| `solders` | `solders` | ≥0.29 |
| solana-py | `solana` | ≥0.40 |
| `anchorpy` | `anchorpy` | ≥0.21 |

<Note>
  Hai bẫy đặt tên. Client RPC được nhập dưới dạng `solana` nhưng dự án được gọi là **solana-py** — `pip install solana-py` không cài đặt bất cứ điều gì hữu ích. Và không có **gói `raydium-py` trên PyPI**: trợ giúp Raydium của cộng đồng là một kho lưu trữ bạn sao chép, [`AL-THE-BOT-FATHER/raydium_py`](https://github.com/AL-THE-BOT-FATHER/raydium_py), không phải là một bản phân phối được xuất bản. Các bản sửa đổi trước của trang này liệt kê một dòng `pip install raydium-py` không bao giờ hoạt động.
</Note>

### Tập lệnh tối thiểu

```python
from solana.rpc.async_api import AsyncClient
from solders.keypair import Keypair
from anchorpy import Provider, Wallet, Program

async def main():
    conn = AsyncClient("https://api.mainnet-beta.solana.com")
    owner = Keypair()
    wallet = Wallet(owner)
    provider = Provider(conn, wallet)

    # Tải IDL và chương trình
    with open("cpmm.idl.json") as f:
        idl = json.load(f)
    program = Program(idl, CPMM_PROGRAM_ID, provider)

    pool = await program.account["PoolState"].fetch(pool_id)
    print(pool)
```

Xem [`sdk-api/python-integration`](/vi/sdk-api/python-integration).

## Điểm cuối RPC

RPC mainnet công khai (`api.mainnet-beta.solana.com`) bị giới hạn tốc độ nặng nề và bị điều chỉnh dưới bất kỳ tải nào. Để sử dụng không tầm thường, hãy lấy một điểm cuối riêng:

| Nhà cung cấp | Ghi chú |
|----------|-------|
| Helius | Phổ biến nhất; mức miễn phí hào phóng. |
| Triton | Doanh nghiệp; giá cao cấp, ổn định. |
| QuickNode | Vững chắc; độ trễ dưới giây. |
| Nút RPC của riêng bạn | Chi phí ~\$500/tháng cho phần cứng; kiểm soát toàn bộ. |

Cấu hình:

```ts
const connection = new Connection("https://mainnet.helius-rpc.com/?api-key=...");
```

Một số hoạt động RPC cần khả năng mở rộng:

- `getProgramAccounts` — quét không hạn chế rất tốn kém; một số nhà cung cấp gating hoặc tính phí cho mỗi lần quét.
- `getPriorityFeeEstimate` — điểm cuối cụ thể của Helius; những người khác có tương đương.
- `geyser` / WebSocket streaming — cần thiết cho bot độ trễ thấp; không phải tất cả các nhà cung cấp đều hiển thị nó.

## Devnet và localnet

### Devnet

Cụm kiểm tra công khai của Solana. Raydium có một triển khai devnet một phần:

- Một số pool CPMM tồn tại để kiểm tra.
- AMM v4 có các pool devnet lịch sử.
- CLMM có một vài pool demo.
- Farm v6 được triển khai.

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2
```

SDK hỗ trợ devnet thông qua `cluster: "devnet"`:

```ts
const raydium = await Raydium.load({ connection, owner, cluster: "devnet" });
```

**Cảnh báo**: các pool devnet có thanh khoản mỏng và có thể có trạng thái cũ. Đừng dựa vào devnet để khám phá giá; chỉ sử dụng nó để xây dựng và kiểm tra luồng hướng dẫn.

### Localnet với trạng thái mainnet được fork

Để kiểm tra thực tế, fork trạng thái mainnet vào một trình xác thực cục bộ:

```bash
solana-test-validator \
  --url https://api.mainnet-beta.solana.com \
  --clone CPMMoo8L3F4NbTegBCKVNunggL7H1ZpdTHKxQB5qKP1C \
  --clone CAMMCzo5YL8w4VFF8KVHrK22GGUsp5VTaW7grrKgrWqK \
  --clone <SOME_POOL_ID> \
  --clone <SOME_MINT_ID>
```

Điều này sao chép trạng thái chương trình/tài khoản cụ thể vào localhost, nơi bạn có thể giao dịch tự do. Lý tưởng cho:

- Kiểm tra đơn vị tích hợp CPI của bạn với một chương trình Raydium thực.
- Phát lại một giao dịch với một tham số được sửa đổi để gỡ lỗi.
- Kiểm tra áp lực với khối lượng tổng hợp lớn.

Nhóm Raydium sử dụng localnet được fork rộng rãi để kiểm tra hồi quy trước khi triển khai mainnet.

## Mẫu dự án

### Bộ khởi động tích hợp TypeScript

```
my-raydium-app/
├── package.json
├── tsconfig.json
├── src/
│   ├── swap.ts           # ví dụ swap
│   ├── add-liquidity.ts
│   └── read-pool.ts
└── .env                  # RPC URL, đường dẫn ví
```

`package.json` tối thiểu:

```json
{
  "name": "my-raydium-app",
  "type": "module",
  "scripts": { "swap": "tsx src/swap.ts" },
  "dependencies": {
    "@raydium-io/raydium-sdk-v2": "0.2.64-alpha",
    "@solana/web3.js": "^1.95",
    "@solana/spl-token": "^0.4.15"
  },
  "devDependencies": {
    "@types/node": "^20",
    "tsx": "^4",
    "typescript": "^5"
  }
}
```

### Bộ khởi động chương trình Anchor CPI

```
my-raydium-cpi/
├── Anchor.toml
├── Cargo.toml
├── programs/
│   └── my-cpi/
│       ├── Cargo.toml
│       └── src/lib.rs
└── tests/
    └── my-cpi.ts
```

Với Anchor 1.0:

```bash
anchor init my-raydium-cpi
cd my-raydium-cpi
# thêm raydium-cp-swap vào Cargo.toml với features = ["cpi"]
anchor build
anchor test
```

## Vệ sinh môi trường

### Ví riêng biệt cho mỗi mục đích

- **Ví phát triển**: giữ testnet SOL, được sử dụng để xây dựng.
- **Ví sản xuất**: giữ SOL thực, chỉ được sử dụng cho triển khai / gửi multisig.
- **Ví nóng cho bot**: số dư nhỏ, quyền hạn hẹp.

Các khóa không bao giờ nên được mã hóa cứng. Sử dụng các biến môi trường hoặc trình quản lý bí mật.

### Mẫu `.env`

```
# .env (không được cam kết)
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=...
WALLET_PATH=/Users/you/.config/solana/id.json
```

```ts
import { config } from "dotenv";
config();

const connection = new Connection(process.env.SOLANA_RPC_URL!);
```

### Ghim phiên bản

Khóa tất cả các phụ thuộc của hệ sinh thái Solana. Hệ sinh thái di chuyển nhanh; một bản sửa đổi phụ của `@solana/web3.js` trước đây đã giới thiệu các thay đổi phá vỡ. Sử dụng `package-lock.json` / `Cargo.lock` một cách tôn giáo.
