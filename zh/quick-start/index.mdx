## 前置条件

运行一次：

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

你需要：

- **Node 18+** 且支持 ESM（`package.json` 中的 `"type": "module"` 或 `.mjs` 扩展名）。
- **Solana 密钥对** 位于 `~/.config/solana/id.json`（或任何位置 — 设置 `KEYPAIR`）。见 [`solana-fundamentals/toolchain`](/zh/solana-fundamentals/toolchain#solana-cli) 了解如何生成密钥对。
- **已充值的钱包。** 交换脚本仅需其输入金额加小额缓冲 — CPMM 交换的网络费约 0.0015 SOL（见 [`reference/fee-comparison`](/zh/reference/fee-comparison#network-fees-per-typical-operation)），如果交换需要为你开设代币账户则需一次性租赁费。创建池成本更高：CPMM 脚本单独就有约 0.15 SOL 的一次性池创建费，不含初始流动性或租赁。在充值钱包前，见各脚本的设置部分了解当前数字。
- **RPC URL。** 免费公共 RPC 适合测试；对于任何超过烟雾测试的操作，使用付费提供商。

每个 shell 会话设置一次：

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **集群。** 三个脚本都默认使用主网。Devnet 需要 `RPC_URL=https://api.devnet.solana.com` 加上脚本内的 `cluster: "devnet"` — 对于两个池创建脚本，这不是唯一的改动；见各脚本的设置部分了解还需要改什么。注意 devnet 上的池初始流动性稀缺；预计需要自己铸造测试代币。
</Info>

## 本章之后

每个脚本都会打印其链上结果 — 交换报价和交易链接、新池地址或新头寸及其 NFT — 以及指向 [SDK & API](/zh/sdk-api) 章节中该操作对应页面的单行链接。当你准备好编写自己的集成时：

- **后端和机器人** → [Trade API](/zh/sdk-api/trade-api)。
- **前端和完全控制应用** → [TypeScript SDK](/zh/sdk-api/typescript-sdk)。
- **链上组合** → [Rust CPI](/zh/sdk-api/rust-cpi)。
- **在它们之间选择** → [SDK & API](/zh/sdk-api) 顶部的对比表。
