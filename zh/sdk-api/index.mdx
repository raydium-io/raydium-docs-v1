## 本章适用于

从链下（TS/JS、Python、后端）或从另一个 Solana 程序（Rust CPI）集成 Raydium 的开发者。也适用于 AI 代理和编码工具集成者——参见 [AI 集成](/zh/sdk-api/ai-integration)。

<Info>
  **想先运行一些东西？** 三个端到端脚本——交换、部署 CPMM 池、部署 CLMM 池——位于 [快速开始](/zh/quick-start)。交换和 CPMM 脚本是单个文件，你可以粘贴并运行；CLMM 流程需要额外的几个步骤。先运行一个真实交易，然后回到这里查看完整参考。
</Info>

## 选择你的集成路径

有五条路径可供选择。正确的路径取决于什么在调用 Raydium 以及你需要多少控制权。

| 路径 | 最适合 | 延迟 | 自定义逻辑 | 语言 |
|---|---|---|---|---|
| [Trade API](/zh/sdk-api/trade-api) | 后端、机器人、Blinks——任何你想要服务器构建交易的地方 | 最低 | 有限（预设路由） | 任何 |
| [TypeScript SDK](/zh/sdk-api/typescript-sdk) | 需要完整构建器访问权限的 Node/TS 应用和前端 | 中等 | 完全 | TS / JS |
| [Python 集成](/zh/sdk-api/python-integration) | Python 后端和 ML 管道 | 中等 | 完全（手动指令构建） | Python |
| [Rust CPI](/zh/sdk-api/rust-cpi) | 从链上调用 Raydium 的组合程序 | N/A（链上） | 完全 + 可组合 | Rust |
| [Anchor IDL](/zh/sdk-api/anchor-idl) | 为没有第一方支持的语言生成代码（Go、Kotlin、Swift 等） | 可变 | 完全 | 任何带有 Anchor 代码生成工具的语言 |

如果你不确定：后端和机器人 → **Trade API**；前端和完全控制应用 → **TypeScript SDK**；链上组合 → **Rust CPI**。
