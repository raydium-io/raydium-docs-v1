## 可用的接口

| 接口 | URL 模式 | 适用场景 |
|---|---|---|
| **MCP 服务器** | `https://docs.raydium.io/mcp` | 你希望 AI 编辑器（Claude Code、Cursor、Windsurf 等）能原生查询和引用 Raydium 文档。 |
| **`llms.txt` 索引** | `https://docs.raydium.io/llms.txt` | 你在构建 RAG 管道，需要所有页面的平面索引。 |
| **`llms-full.txt` 正文** | `https://docs.raydium.io/llms-full.txt` | 你需要完整语料库作为单个连接文件用于离线索引。 |
| **逐页复制菜单** | 每个正文页面顶部的「Copy page」按钮 | 你要将单个页面粘贴到与 LLM 的对话中。 |
| **逐页深链接** | `View as Markdown`、`Open in ChatGPT`、`Open in Claude`、`Open in Cursor`、`Open in VS Code` | 从文档页面一键切换到你选择的工具。 |

「Copy page」按钮和深链接菜单位于每个页面的右上角（页面标题旁）。两者都由文档平台的上下文菜单驱动。

## MCP 服务器

MCP（Model Context Protocol）服务器让 AI 客户端可以将 Raydium 文档作为工具进行查询。配置后，你的代理可以询问「在 Raydium 文档中搜索 `addLiquidity` 参数」并获得带引用的权威答案。

### Claude Code

```bash
claude mcp add --transport http raydium-docs https://docs.raydium.io/mcp
```

添加后，让 Claude Code 「搜索 Raydium 文档中的 X」，它就会使用该工具。

### Cursor

添加到你的 Cursor 设置（`Cmd/Ctrl + ,` → MCP）：

```json
{
  "mcpServers": {
    "raydium-docs": {
      "url": "https://docs.raydium.io/mcp"
    }
  }
}
```

### Windsurf、Continue、通用客户端

任何兼容 MCP 的客户端都可以指向 `https://docs.raydium.io/mcp`。如果你的客户端需要清单文件，它位于 `https://docs.raydium.io/mcp/.well-known/mcp.json`。

### 服务器暴露的功能

Raydium 文档 MCP 服务器暴露一个主要工具 `search_docs(query: string)`，它返回查询的最高排名段落及其规范 URL。代理负责引用它使用的 URL；我们不跟踪或按代理进行速率限制。

## 用于 RAG 的 `llms.txt`

`llms.txt` 是「机器可读文档索引」的新兴标准。Raydium 发布：

- `https://docs.raydium.io/llms.txt` — 所有页面的平面列表，包含标题和单行摘要，按章节组织。
- `https://docs.raydium.io/llms-full.txt` — 所有页面的完整 Markdown 正文，连接在一起，页面边界保留为标题。

`full` 版本在每次文档部署时重新生成。按计划拉取（每天一次足够）或按需获取。

```bash
# 将完整语料库放入你的 RAG 摄取管道。
curl -sSL https://docs.raydium.io/llms-full.txt -o raydium-docs.md
```

## 逐页切换菜单

每个正文页面都有一个上下文菜单（右上角，标题旁），包含以下一键操作：

- **Copy** — 将页面复制为纯 Markdown。
- **View as Markdown** — 在新标签页中打开源 `.md` 文件，以便保存。
- **Open in ChatGPT / Claude / Perplexity** — 将页面内容预加载到指定工具的聊天提示中。
- **Open in Cursor / VS Code** — 在指定编辑器中打开包含页面内容的缓冲区。

当你想向模型提问单个页面的问题而不想设置 MCP 时，这是合适的接口。

## 为编码代理预构建的上下文文件

如果你正在集成 Raydium 并希望代理从一开始就有正确的基础知识，将这些文件放入你的项目：

### `.cursorrules` / `.windsurfrules` / 代理系统提示

```text
You are integrating with Raydium, a Solana DeFi protocol with five product
surfaces: AMM v4, CPMM, CLMM, Farm, and LaunchLab. Authoritative docs live
at docs.raydium.io. The official SDK is `@raydium-io/raydium-sdk-v2` (pin
the version you've verified against). For server-built swaps, prefer the
Trade API at transaction-v1.raydium.io. Always:

- Pass a `Connection` and `cluster` that match.
- Keep all amounts as `BN` instances; never call `.toNumber()` on amounts.
- Pre-fund the user's wallet for ATA creation rent.
- Pass an explicit `computeBudgetConfig` for any tx that may compete in
  high-volume windows.
- Re-fetch `poolInfo` immediately before high-value transactions; cached
  state goes stale.

When uncertain about an instruction's accounts list, defer to
`docs.raydium.io/products/<product>/accounts` and the on-chain IDL.
```

保存为 `.cursorrules`（Cursor）、`.windsurfrules`（Windsurf）或 `CLAUDE.md`（Claude Code）— 或粘贴到你的代理系统提示中。确切的文件名和位置因工具版本而异，如果工具没有自动选择该文件，请检查你的工具设置文档。

## 索引方案

如果你正在构建自己的 RAG 并不想使用 `llms-full.txt`，这是规范方案：

```ts
import { fetch } from "undici";

const INDEX_URL = "https://docs.raydium.io/llms.txt";
const BASE      = "https://docs.raydium.io";

const index    = await (await fetch(INDEX_URL)).text();
const pageUrls = [...index.matchAll(/^- \[(.+?)\]\((.+?)\)/gm)].map(m => m[2]);

for (const path of pageUrls) {
  const md = await (await fetch(`${BASE}${path}.md`)).text();
  // ingest md into your vector store, keyed by path
}
```

每个页面都在其规范路径上提供，并附加 `.md` 后缀（例如 `/sdk-api/typescript-sdk` → `/sdk-api/typescript-sdk.md`）。

## 注意事项

- **不要将私有状态粘贴到提示中。** MCP 服务器只知道公开文档中的内容。钱包密钥、RPC 凭证和类似的机密不应进入代理上下文。
- **AI 输出不是权威的。** 模型以令人担忧的频率幻觉程序地址、指令名称和账户列表。在信任代理生成的交易之前，始终根据文档和 IDL 进行验证。
- **版本漂移。** SDK v2 是 pre-1.0；在较旧版本上训练的代理可能会生成针对你固定版本无法编译的代码。在你的代理系统提示中包含固定的 SDK 版本。
