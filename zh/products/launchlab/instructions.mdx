## 指令清单

| 分组 | 指令 | 可调用者 |
|-------|-------------|-------------|
| 全局配置 | `CreateConfig` / `UpdateConfig` | 程序管理员；委托的创建配置权限也可以调用 `CreateConfig` |
| 启动生命周期 | `Initialize` / `InitializeV2` | 任何人（创建者）— SPL Token 启动；V2 记录 `amm_creator_fee_on` 用于最终的 CPMM 毕业 |
| 启动生命周期 | `InitializeWithToken2022` | 任何人（创建者）— Token-2022 启动，可选 `TransferFeeConfig` |
| 交易 | `BuyExactIn` / `BuyExactOut` | 任何人 — 在联合曲线上精确输入/精确输出买入 |
| 交易 | `SellExactIn` / `SellExactOut` | 任何人 — 在联合曲线上精确输入/精确输出卖出 |
| 毕业 | `MigrateToAmm` | 迁移钱包 — 针对在强制执行仅 CPMM 创建之前初始化的池的遗留 AMM v4 毕业 |
| 毕业 | `MigrateToCpswap` | 迁移钱包 — 毕业到 CPMM。所有新初始化的启动都使用此路径。包装 CPMM 上的 `InitializeWithPermission`。 |
| 费用 | `CollectFee` | 管理员 — 从启动中扫除协议费用 |
| 费用 | `CollectMigrateFee` | 管理员 — 扫除累积的迁移费用 |
| 费用 | `ClaimCreatorFee` | 创建者 — 在曲线阶段声称累积的创建者费用 |
| 归属 | `CreateVestingAccount` | 创建者 — 为受益人分配锁定代币，毕业后解锁 |
| 归属 | `CreatePlatformVestingAccount` | 平台管理员 — 为平台端受益人分配锁定代币 |
| 归属 | `ClaimVestedToken` | 受益人 — 在悬崖期后声称解锁的代币 |
| 平台配置 | `CreatePlatformConfig` / `UpdatePlatformConfig` | 平台管理员 |
| 平台配置 | `UpdatePlatformCurveParam` / `RemovePlatformCurveParam` | 平台管理员 — 管理每个平台允许的曲线形状列表 |
| 平台费用 | `ClaimPlatformFee` / `ClaimPlatformFeeFromVault` | 平台管理员 |
| 平台访问 | `CreatePlatformAllowConfig` / `ClosePlatformAllowConfig` | 平台管理员 — 维护该平台启用限制时使用的 `GlobalConfig` 允许列表 |

"ExactIn/ExactOut" 的分割镜像了 CPMM 的 `SwapBaseInput` / `SwapBaseOutput` — 在链上它们是具有略微不同舍入的单独指令判别器。

**毕业路径选择。** 每个新的 `Initialize`、`InitializeV2` 和 `InitializeWithToken2022` 调用必须设置 `migrate_type = 1`（`CPSWAP`）。任何尝试初始化新的 AMM v4 绑定池都会返回 `MigrateTypeNotMatch`。`amm_creator_fee_on` 仅选择生成的 CPMM 创建者费用是应用于报价代币还是两个代币；它不选择目标程序。

`MigrateToAmm` 对于在此限制之前使用 `migrate_type = 0` 初始化的现有 `PoolState` 仍然可调用。该版本不会重写现有池状态或删除遗留指令。

## `Initialize`

创建新启动。

**参数**

```
launch_params: {
    curve_type:                 u8,
    base_supply_max:            u64,
    base_supply_graduation:     u64,
    k:                          u128,              // 或 curve_type=1 的 initial_virtual_quote_reserve
    open_time:                  u64,
    quote_mint:                 Pubkey,
    base_token_metadata: {                         // 内联名称/符号/uri；程序 CPI 到 Metaplex
        name:   String,
        symbol: String,
        uri:    String,
    },
    fees: {
        buy_numerator:   u64,
        buy_denominator: u64,
        sell_numerator:  u64,
        sell_denominator: u64,
        lp_share:        u64,
        creator_share:   u64,
        protocol_share:  u64,
        total_share:     u64,
    },
    post_graduation_lp_policy:  u8,                // 0 = 销毁，1 = 锁定，2 = 给创建者
}
```

**账户**（简化版）

| # | 名称 | W | S | 备注 |
|---|------|---|---|-------|
| 1 | `creator` | W | S | 支付租金 + 基础铸币创建。 |
| 2 | `launch_config` |   |   | 协议配置绑定。 |
| 3 | `launch_state` | W |   | 新账户。 |
| 4 | `launch_authority` |   |   | PDA。 |
| 5 | `base_mint` | W | S | 新密钥对（或 PDA）— 此指令初始化它。 |
| 6 | `base_vault` | W |   | `launch_authority` 在 `base_mint` 上的 ATA。 |
| 7 | `quote_mint` |   |   | |
| 8 | `quote_vault` | W |   | `launch_authority` 在 `quote_mint` 上的 ATA。 |
| 9 | `metadata` | W |   | Metaplex 元数据 PDA。 |
| 10 | `metaplex_program` |   |   | |
| 11 | `token_program` |   |   | 仅 SPL Token。 |
| 12 | `system_program` |   |   | |
| 13 | `rent` |   |   | |

**前置条件**

- `quote_mint ∈ launch_config.allowed_quote_mints`。
- `base_supply_graduation ≤ base_supply_max`。
- 费用参数通过 `launch_config.max_*_fee_rate` 检查。
- `open_time ≥ now − slop`（SDK 强制 `≥ now`；程序容忍轻微回溯）。
- `curve_type` 被识别。

**后置条件**

- `base_mint` 的 `supply = base_supply_max`，全部在 `base_vault` 中。
- `base_mint.mint_authority = launch_authority`，`freeze_authority = None`。
- `LaunchState` 初始化为 `status = Active`，`base_sold = 0`，`quote_reserve_real = 0`。
- `quote_reserve_target` 从曲线参数 + `base_supply_graduation` + `buy_numerator` 计算（大约）。

**常见错误** — `InvalidQuoteMint`、`FeeRateTooHigh`、`InvalidCurveParams`、`MathOverflow`。

## `Buy`（规范变体：`BuyExactIn`）

用户提供固定的 `quote_in`；曲线计算 `base_out`。

**参数**

```
quote_in:          u64
minimum_base_out:  u64
```

**账户**

| # | 名称 | W | S |
|---|------|---|---|
| 1 | `user` | W | S |
| 2 | `launch_state` | W |   |
| 3 | `launch_authority` |   |   |
| 4 | `base_vault` | W |   |
| 5 | `quote_vault` | W |   |
| 6 | `user_base_ata` | W |   |
| 7 | `user_quote_ata` | W |   |
| 8 | `base_mint` |   |   |
| 9 | `quote_mint` |   |   |
| 10 | `token_program` |   |   |
| 11 | `associated_token_program` |   |   |
| 12 | `system_program` |   |   |

**前置条件**

- `launch_state.status == Active`。
- `now ≥ open_time`。
- `user_quote_ata.balance ≥ quote_in`。
- `quote_in > 0`。

**效果**

1. 将 `quote_in` 分割为 `quote_in_after_fee` 和费用部分。
2. 牛顿求解曲线以获得给定后费用报价的 `base_out`。
3. `require(base_out ≥ minimum_base_out)` 否则回滚 `ExceededSlippage`。
4. 移动 `quote_in` 用户 → 金库。移动 `base_out` 金库 → 用户。
5. 更新 `base_sold += base_out`，`quote_reserve_real += quote_in_after_fee × (lp_share / total_share)`。
6. 更新费用计数器（`protocol_fees_quote`、`creator_fees_quote`）。
7. `state_data.num_buys += 1`。
8. 如果更新后 `quote_reserve_real ≥ quote_reserve_target`，SDK 通常在同一交易中链接 `Graduate` ix。程序不会在 `Buy` 内自动毕业 — 需要后续的 `Graduate`。

## `BuyExactOut`

用户指定精确的 `base_out`；程序计算 `quote_in`。

**参数**

```
base_out:      u64
maximum_quote_in: u64
```

与 `BuyExactIn` 相同的账户。使用闭式二次积分（或 curve_type 1 的 CPMM 逆）而不是牛顿迭代。

## `Sell` / `SellExactIn` / `SellExactOut`

`Buy` 的镜像。用户将 `base_in` 返回给曲线并接收 `quote_out`。费用从 `quote_out` 中扣除，因此用户收到的少于原始集成收益。

**前置条件** —

- `user_base_ata.balance ≥ base_in`。
- 卖出不能将 `base_sold` 推低于 0（考虑到会计一致性是冗余的）。
- 启动是 `Active`。

**效果** — 对称于 `Buy`。`base_sold` 减少，`quote_reserve_real` 减少。费用仍然累积。

## `MigrateToAmm` / `MigrateToCpswap`

一旦曲线达到 `total_quote_fund_raising`，将启动毕业到可交易的池。新启动仅限 CPMM。`MigrateToAmm` 为存储的 `migrate_type` 为 `0` 的现有池保留。

**谁签署**

- `MigrateToAmm` — 绑定 `GlobalConfig` 上记录的 `migrate_to_amm_wallet`。
- `MigrateToCpswap` — 绑定 `GlobalConfig` 上记录的 `migrate_to_cpswap_wallet`。

这些钱包通常由 Raydium 运营的毕业 crank 持有；实际上毕业在阈值被跨越后的几秒内进行，无论谁触发了最后的买入。

**参数**

`MigrateToAmm` 需要三个（主要是程序转发给 AMM v4 的 OpenBook 市场参数）：

```
base_lot_size:               u64
quote_lot_size:              u64
market_vault_signer_nonce:   u8
```

`MigrateToCpswap` 不需要任何参数。

**效果（两者共同）**

1. 验证 `pool_state.status == Migrate`（即 `quote_reserve_target` 已达到）。否则回滚 `PoolMigrated`（状态已是 `Migrated`）或 `PoolFunding`（仍在融资）。
2. 验证 `pool_state.migrate_type` 与指令匹配（AMM 为 `0`，CPMM 为 `1`）。否则回滚 `MigrateTypeNotMatch`。
3. 计算毕业后的储备：
   - `base_amount_out = base_vault.amount − vesting_schedule.total_locked_amount`
   - `quote_amount_out = quote_vault.amount − quote_protocol_fee − migrate_fee − platform_fee`
4. CPI 进入目标程序（`AMM v4 Initialize2` 或 `CPMM InitializeWithPermission`）使用这些储备来创建毕业后的池。
5. 对于在 2026-08-14 升级后执行的 CPMM 迁移，将 `platform_scale + creator_scale` 合并为一个平台拥有的锁定 LP 份额，并最多向 `platform_nft_wallet` 铸造一个费用密钥 NFT。销毁 `burn_scale` 余额。在升级之前，`creator_scale` 被单独锁定，其费用密钥转到代币创建者。已完成的历史迁移不被修改。对于遗留 AMM v4 毕业，LP 处置遵循该指令的现有流程。
6. 撤销 `base_mint.mint_authority`（设置为 `None`）。
7. 翻转 `pool_state.status = Migrated`，设置 `vesting_schedule.start_time = block_time + cliff_period`。

**后置条件** — `BuyExactIn`、`BuyExactOut`、`SellExactIn`、`SellExactOut` 从此时起将以 `PoolMigrated` 拒绝。生成的 AMM 池是规范的，交易就像任何其他 AMM v4 / CPMM 池一样。

**常见错误** — `PoolFunding`、`PoolMigrated`、`MigrateTypeNotMatch`、`InvalidCpSwapConfig`、`MathOverflow`。

### CPMM 迁移剩余账户

构建 `MigrateToCpswap` 的客户端必须使用这些固定的 `remaining_accounts` 索引：

| 索引 | 账户 |
|---|---|
| 0–4 | 平台费用密钥所有者、铸币、代币账户、锁定流动性 PDA 和元数据账户 |
| 5 | 原始启动创建者；在 `platform_cp_creator` 未设置时使用 |
| 6 | 从 `[b"permission", launch_authority]` 派生的 CPMM 权限 PDA |
| 7 | 配置的 `platform_cp_creator`；在字段非默认时使用 |
| 8 | 排序 `mint0` 的 CPMM 支持铸币 PDA，从 `[b"support_mint", mint0]` 派生 |
| 9 | 排序 `mint1` 的 CPMM 支持铸币 PDA，从 `[b"support_mint", mint1]` 派生 |

该指令在升级路径上需要至少十个剩余账户。支持铸币账户是只读 CPI 输入。即使铸币没有初始化的支持记录，也要派生两个地址。仍然附加创建者锁定账户或省略索引 8–9 的旧构建器必须更新。

## 平台 `GlobalConfig` 允许列表

`PlatformConfig.restrict_global_config` 控制检查：

- `0`：平台接受任何其他有效的 `GlobalConfig`；不需要允许账户。
- `1`：`Initialize`、`InitializeV2` 和 `InitializeWithToken2022` 必须在 `remaining_accounts` 中的任何地方包含匹配的 `PlatformAllowConfig`。

平台管理员使用 `CreatePlatformAllowConfig` 和 `ClosePlatformAllowConfig` 创建或关闭 PDA。其种子是 `[b"platform_allow_config", platform_config, global_config]`。前管理员管理的 `PlatformGlobalAccess` 指令和 PDA 已停用。

## `CollectFee`

管理员扫除单个启动上协议累积的交易费用。

**参数** — 无。

**账户**

| # | 名称 | W | S | 备注 |
|---|------|---|---|-------|
| 1 | `protocol_fee_owner` |   | S | 必须等于 `global_config.protocol_fee_owner`。 |
| 2 | `authority` |   |   | PDA `[b"vault_auth_seed"]`；签署金库转账。 |
| 3 | `pool_state` | W |   | 变异为零 `quote_protocol_fee`。 |
| 4 | `global_config` |   |   | 签署者的真实来源。 |
| 5 | `quote_vault` | W |   | 由 `quote_protocol_fee` 排空。 |
| 6 | `recipient_token_account` | W |   | `protocol_fee_owner` 在 `quote_mint` 上的 ATA。 |
| 7 | `quote_mint` |   |   | |
| 8 | `token_program` |   |   | SPL Token（报价铸币始终是 SPL Token）。 |

**效果** — 将 `pool_state.quote_protocol_fee` 从 `quote_vault` 转账到 `recipient_token_account`，然后将计数器清零。可在第一次买入后的任何时间调用。

## `CollectMigrateFee`

管理员扫除毕业时累积的迁移费用。与 `CollectFee` 相同的账户形状，但以 `migrate_fee_owner` 作为签署者（而不是 `protocol_fee_owner`）和 `pool_state.migrate_fee` 作为排空的计数器。

## `ClaimCreatorFee`

每个创建者对创建者拥有的**每个使用相同报价铸币的启动**累积的创建者费用的扫除。排空每个创建者费用金库，而不是每个池的费用金库。

**参数** — 无。

**账户**

| # | 名称 | W | S | 备注 |
|---|------|---|---|-------|
| 1 | `creator` | W | S | 池创建者。 |
| 2 | `fee_vault_authority` |   |   | PDA `[b"creator_fee_vault_auth_seed"]`。 |
| 3 | `creator_fee_vault` | W |   | 种子为 `[creator, quote_mint]` 的 PDA；聚合创建者金库。 |
| 4 | `recipient_token_account` | W |   | `init_if_needed`；`creator` 在 `quote_mint` 上的 ATA。 |
| 5 | `quote_mint` |   |   | |
| 6 | `token_program` |   |   | |
| 7 | `system_program` |   |   | 用于 ATA 创建（如需要）。 |
| 8 | `associated_token_program` |   |   | |

**效果** — 将 `creator_fee_vault` 的全部余额转账到 `recipient_token_account`。如果金库为空，则以大于零的检查回滚。

## `ClaimPlatformFee`

每个平台的扫除，直接排空启动的报价金库。当平台想要为一个特定启动声称其份额而不通过聚合平台金库时使用。

**参数** — 无。

**账户**

| # | 名称 | W | S | 备注 |
|---|------|---|---|-------|
| 1 | `platform_fee_wallet` | W | S | 必须等于 `platform_config.platform_fee_wallet`。 |
| 2 | `authority` |   |   | PDA `[b"vault_auth_seed"]`。 |
| 3 | `pool_state` | W |   | 由 `pool_state.platform_fee` 排空。 |
| 4 | `platform_config` |   |   | 签署者的真实来源。 |
| 5 | `quote_vault` | W |   | 排空。 |
| 6 | `recipient_token_account` | W |   | `init_if_needed`；`platform_fee_wallet` 的 ATA。 |
| 7 | `quote_mint` |   |   | |
| 8 | `token_program` |   |   | |
| 9 | `system_program` |   |   | |
| 10 | `associated_token_program` |   |   | |

**效果** — 将 `pool_state.platform_fee` 从 `quote_vault` 转账到 `recipient_token_account`，将计数器清零。

| 2 | `fee_vault_authority` |   |   | PDA `[b"platform_fee_vault_auth_seed"]`。 |
| 3 | `platform_config` |   |   | |
| 4 | `platform_fee_vault` | W |   | 种子为 `[platform_config, quote_mint]` 的 PDA。 |
| 5 | `recipient_token_account` | W |   | `init_if_needed`；`platform_fee_wallet` 的 ATA。 |
| 6 | `quote_mint` |   |   | |
| 7 | `token_program` |   |   | |
| 8 | `system_program` |   |   | |
| 9 | `associated_token_program` |   |   | |

**效果** — 将 `platform_fee_vault` 的全部余额转账到 `recipient_token_account`。如果金库为空则回滚。

## 状态变化矩阵

| 指令 | `status` | `real_base` | `real_quote` | 费用计数器 | 毕业后池 |
|-------------|----------|-------------|--------------|--------------|------------------|
| `Initialize{V2,WithToken2022}` | Funding | 0 | 0 | 0 | — |
| `BuyExactIn(q_in)` | Funding | +∆ | +∆q_after_fee | `quote_protocol_fee += ∆`，`platform_fee += ∆` | — |
| `SellExactIn(b_in)` | Funding | −∆ | −∆q_before_fee | （相同） | — |
| 阈值达到 | → Migrate | — | — | — | — |
| `MigrateToCpswap` / 遗留 `MigrateToAmm` | → Migrated | （冻结） | （冻结） | `migrate_fee` 设置 | 已创建；CPMM LP 分割为平台锁定和销毁 |
| `CollectFee` / `CollectMigrateFee` | 任何 | — | — | 计数器清零 | — |
| `ClaimCreatorFee` / `ClaimPlatformFee*` | 任何 | — | — | 排空金库 | — |
| `CreateVestingAccount` | Funding | — | — | — | 增加 `allocated_share_amount` |
| `ClaimVestedToken` | Migrated | — | — | — | 排空 `base_vault` |
