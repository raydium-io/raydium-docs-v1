## 设置

此处的示例镜像 [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad) 中的文件。引导程序遵循演示仓库的 [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template)：

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## 创建启动

源代码：[`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts)（以及 [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts) 用于 API 驱动的 Bonk 变体）

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId: /* LaunchLab program ID from reference/program-addresses */,
  // Token metadata for the new base mint:
  name:   "Example Token",
  symbol: "EXMPL",
  uri:    "https://example.com/metadata.json",
  decimals: 6,

  // Curve params:
  curveType: 0,                                      // 0 = quadratic
  supply:    new BN(1_000_000_000).mul(new BN(10).pow(new BN(6))), // 1B base (6 dec)
  graduationFractionBps: 8000,                       // 80% → graduation
  initialK:  new BN("40"),                           // curve shape parameter

  // Quote side:
  quoteMint: NATIVE_MINT,                            // WSOL
  openTime:  new BN(Math.floor(Date.now() / 1000) + 60),  // opens in 1min

  // Fee policy:
  fees: {
    buyNumerator:   new BN(100),                     // 1.00%
    buyDenominator: new BN(10_000),
    sellNumerator:  new BN(100),
    sellDenominator: new BN(10_000),
    lpShare:         new BN(60),
    creatorShare:    new BN(20),
    protocolShare:   new BN(20),
    totalShare:      new BN(100),
  },

  postGraduationLpPolicy: "burn",                    // "burn" | "lock" | "toCreator"

  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Launch:", extInfo.launchState.toBase58());
console.log("Base mint:", extInfo.baseMint.toBase58());
console.log("Create tx:", txId);
```

注意：

- `initialK` 是二次曲线的缩放因子。调整它以在毕业时针对特定的开盘 CPMM 价格。详见 [`products/launchlab/bonding-curve`](/zh/products/launchlab/bonding-curve) 的推导。
- SDK 在单个交易中处理创建基础 mint、元数据 PDA 和两个金库。如果元数据 URI 很长，可能超过 1232 字节；在这种情况下，SDK 会分成两个交易。
- 在 `Initialize` 之后，启动在 `openTime` 之前不可交易。将 `openTime` 设置在未来一两分钟，以减少抢先交易者抢占第一笔买入的机会。

## 获取启动状态

```ts
const launchId = new PublicKey("<LAUNCH_STATE>");

const launch = await raydium.launchpad.getLaunchById({ launchId });
console.log("Status:", ["Active","Graduated","Cancelled"][launch.status]);
console.log("Base sold:", launch.baseSold.toString(),
            "/", launch.baseSupplyMax.toString());
console.log("Quote collected:", launch.quoteReserveReal.toString(),
            "target:", launch.quoteReserveTarget.toString());
if (launch.status === 1) {
  console.log("Post-graduation CPMM pool:", launch.cpmmPoolState.toBase58());
}
```

`getLaunchById` 返回解码后的 `LaunchState` 以及计算的"毕业进度"分数作为 `Decimal`。

## 买入 — 精确报价输入

源代码：[`src/launchpad/buy.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/buy.ts)

```ts
const quoteIn        = new BN(1).mul(new BN(10).pow(new BN(9)));  // 1 SOL
const minimumBaseOut = new BN(0);  // accept any; tighten for production

// Preview the quote off-chain so your UI can show expected base_out:
const preview = raydium.launchpad.computeBuyBase({
  launchState: launch,
  quoteIn,
});
console.log("Expected base_out:", preview.baseOut.toString(),
            "price impact:", preview.priceImpact.toString());

const { execute } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn,
  minimumBaseOut,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

`computeBuyBase` 镜像链上 Newton 求解器（二次曲线）或闭式 CPMM 反函数（curve_type 1）。用它来填充"你将收到"UI 字段。

## 买入 — 精确基础输出

```ts
const baseOut         = new BN(1_000_000).mul(new BN(10).pow(new BN(6)));  // 1M base
const maximumQuoteIn  = new BN(2).mul(new BN(10).pow(new BN(9)));          // cap at 2 SOL

const { execute } = await raydium.launchpad.buyExactOut({
  launchInfo: launch,
  baseOut,
  maximumQuoteIn,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

适用于"精确购买 X 个代币"的 UI。如果曲线移动足够大，使得报价要求现在超过 `maximumQuoteIn`，则以 `ExceededSlippage` 拒绝。

## 卖出

源代码：[`src/launchpad/sell.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/sell.ts)

```ts
const baseIn           = new BN(500_000).mul(new BN(10).pow(new BN(6)));  // 0.5M base
const minimumQuoteOut  = new BN(0);

const { execute } = await raydium.launchpad.sellExactIn({
  launchInfo: launch,
  baseIn,
  minimumQuoteOut,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

曲线的卖出路径与买入路径对称：将 `base_sold` 减少 `baseIn` 返回 `quote_out`，等于曲线下在 `base_sold − baseIn` 和 `base_sold` 之间的积分面积，减去卖出费用。

## 在阈值交叉买入时自动毕业

当 SDK 检测到买入后状态将跨越阈值时，它会在 `buy*` 交易内链接 `Graduate` 指令：

```ts
const { execute, willGraduate } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn: new BN(100).mul(new BN(10).pow(new BN(9))),    // large buy
  minimumBaseOut: new BN(0),
  txVersion: TxVersion.V0,
  autoGraduate: true,                                      // default
});

if (willGraduate) {
  console.log("This buy will trigger graduation.");
}

const { txId } = await execute({ sendAndConfirm: true });
```

因为 `Graduate` 是无权限的，任何人（包括 MEV 机器人）都可以在阈值交叉后竞速登陆第一个 `Graduate` — 通常在几秒内，而不是几分钟。第一个登陆者只需支付 CPMM 池账户的租金；他们没有其他好处。

## 手动 `Graduate`

如果 `autoGraduate` 关闭或阈值交叉交易失败，你可以单独触发毕业：

```ts
const { execute } = await raydium.launchpad.graduate({
  launchInfo: launch,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

如果在提交时 `quote_reserve_real < quote_reserve_target`，则以 `NotAtThreshold` 回滚。重试安全 — 成功后的第二次 `Graduate` 尝试以 `NotActive` 回滚。

## 跟踪启动的整个生命周期

综合起来，监控脚本可能看起来像：

```ts
async function watch(launchId: PublicKey) {
  while (true) {
    const launch = await raydium.launchpad.getLaunchById({ launchId });
    const progress =
      Number(launch.quoteReserveReal) /
      Number(launch.quoteReserveTarget);

    console.log(
      `status=${["Active","Graduated","Cancelled"][launch.status]}`,
      `progress=${(progress * 100).toFixed(2)}%`,
      `num_buys=${launch.stateData.numBuys}`,
    );

    if (launch.status === 1) {
      console.log("Graduated to CPMM pool:", launch.cpmmPoolState.toBase58());
      break;
    }
    await new Promise(r => setTimeout(r, 10_000));
  }
}
```

## 通过 gRPC 监视配置和池

源代码：[`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

通过 Yellowstone gRPC 订阅 LaunchLab 程序，并记录每个 mint 的 token 程序的每个 `GlobalConfig` 和 `PoolState` 更新。一个 `accounts` 订阅上的两个 `datasize` 过滤器分离两种账户类型，因此单个流涵盖两者。

该演示是分类启动 mint 的最短正确参考，[Token-2022 报价 mint 发布](/zh/reference/changelog/2026-08-24-launchlab-token2022-quote-mint) 使其成为必要：

- **池** 直接从 `PoolState.token_program_flag` 分类，为基础 mint 解码 bit0，为报价 mint 解码 bit1，完全不获取 mint。测试整个字节是否为 `0` — 在报价 mint 仅为旧版时足够 — 当报价 mint 是 Token-2022 时，会误读旧版基础 mint 为 Token-2022。
- **配置** 不能以这种方式分类：`GlobalConfig` 存储其报价 mint 的地址且没有程序标志，因此演示读取 mint 账户的所有者一次并按 mint 缓存。

它还相互交叉检查，这是在你自己的索引器中保持的有用断言。注意 `create` 与 `update` 是从演示自己的缓存推断的，在启动时从 `getProgramAccounts` 播种；禁用该播种后，将"create"读作"首次在此流上看到"。

gRPC 访问不是公共 RPC 表面的一部分 — 见演示仓库的 [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md)。

## Rust CPI

从你自己的 Anchor 程序调用 LaunchLab 很少见（大多数启动集成仅在 TS 端）。如果你这样做，程序附带 Anchor crate `raydium_launchlab`，包含 `cpi::accounts::Buy`、`cpi::accounts::Sell` 等 — 模式镜像 CPMM / CLMM CPI 示例。一旦此站点被填充，见 [`sdk-api/rust-cpi`](/zh/sdk-api/rust-cpi) 获取通用模板。

## 陷阱

- **费用分割算术差一。** 如果 `total_share` 不完全等于 `lp_share + creator_share + protocol_share`，`Initialize` 以 `InvalidFeeShares` 回滚。将 `totalShare` 设置为等于总和。
- **使用不允许的报价 mint。** `launch_config.allowed_quote_mints` 是固定列表；传递任何其他 mint 会回滚。首先用 `raydium.launchpad.getConfig()` 检查。
- **元数据大小。** 长 `uri` 字符串会将 Metaplex CPI 推过预算。保持 `uri` 在约 200 个字符以下 — 大多数 CDN 托管的 JSON 元数据轻松适配。
- **毕业竞速。** 自动化机器人监视 `quote_reserve_real` 并在阈值交叉后的一两个 slot 内抢先 `Graduate`。这是良性的 — 它只花费他们租金 — 但这意味着你的 UI 应该将 `status` 转换视为快速事件。
