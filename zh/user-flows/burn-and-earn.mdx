<Info>
  **这里"burn"的含义。** 尽管名字如此，LP 代币/头寸 NFT 是**锁定**在程序所有的托管账户中，而不是销毁。流动性永远无法提取，但费用继续累积，可由 Fee Key NFT 的持有者领取。该 NFT 可转让；谁拥有它，谁就拥有费用流。

</Warning>

## Burn & Earn 是什么

Burn & Earn 是 Raydium 的一项功能，允许池创建者（或任何 LP）在链上进行**永久**存款，同时保留收取交易费的权利。头寸变为不可赎回，但新铸造的 **Raydium Fee Key** NFT 代表从该锁定头寸中 `collectFees` 的持续权利。

常见用例：

- **启动信任。** 项目通过锁定部署者的 LP 来承诺不进行地毯式拉盘。持有者可以在链上验证流动性是永久的。
- **产生费用的收藏品。** 一个可交易的 NFT，产生收益。出售 NFT；转移费用流。
- **机构级 LP。** 希望永久保持流动性以用于品牌/发现目的的协议，同时仍然从费用方面获利。

## 支持的池类型

| 程序 | Burn & Earn 支持 |
|---|---|
| CPMM | 是 |
| CLMM | **仅全范围**（推荐） |
| AMM v4（混合） | 不支持 |

对于 CLMM，只有跨越完整价格范围的头寸应被锁定。锁定后，你无法重新平衡——如果价格移出你选择的范围，你将永久停止从该头寸赚取费用。紧范围的 Burn & Earn 头寸几乎总是一个错误。

## 锁定在程序级别的工作原理

1. 原始 LP 代币（CPMM）或头寸 NFT（CLMM）被转入由 Burn & Earn 程序拥有的程序所有 PDA。
2. **Fee Key NFT** 被铸造给调用者。其元数据指向锁定头寸的 PDA。
3. Burn & Earn 公开 `collectFees`（或每个池类型的等效调用），该调用：
   - 验证签名者持有给定锁定头寸的 Fee Key NFT。
   - 通过 CPI 调用底层池程序的费用领取指令。
   - 将收集的费用路由到 Fee Key 持有者的 ATA。
4. 没有对应的 `withdraw`——底层 LP/头寸永远不会退出托管。

Fee Key 是标准 SPL NFT。它可以在任何 Solana NFT 市场上出售，在钱包之间移动，用作接受 NFT 的借贷协议的抵押品，或包装到另一个合约中。在 `collectFees` 调用时持有它的人会收到费用。

## UI 演练

1. 像往常一样创建 CPMM 池或具有全范围头寸的 CLMM 池。
2. 转到**流动性 → 创建 → Burn & Earn**。
3. 选择要锁定的头寸。
4. 验证头寸详情（NFT 地址、大小、池）并输入 UI 显示的确认句子。这故意设置了摩擦，因为该操作是不可逆的。
5. 点击**确认，永久锁定流动性**。
6. Fee Key NFT 到达你的钱包。它在投资组合页面上显示在锁定头寸下。

以与任何头寸相同的方式领取费用——通过投资组合页面或通过 `collectFees`。

## API 接口

池信息端点返回 `burnPercent` 字段，指示该池通过 Burn & Earn 锁定的流动性份额：

```http
GET https://api-v3.raydium.io/pools/info/list
  ?poolType=standard
  &poolSortField=default
  &sortType=desc
  &pageSize=1
  &page=1
```

```json
{
  "data": [
    {
      "id": "...",
      "burnPercent": 99.17,
      ...
    }
  ]
}
```

`burnPercent` 是信任信号的便捷表面：LP 被 99%+ 锁定的代币比 LP 被 0% 锁定的代币的地毯式拉盘风险要低得多。

## 陷阱

- **不可逆。** LP 方永远无法检索。确认金额是你愿意永远不再接触的。
- **CLMM 紧范围是陷阱。** 仅锁定全范围 CLMM 头寸，除非你真正理解范围限制的锁定头寸在价格退出波段后停止赚取费用。
- **丢失 Fee Key NFT 就是永远丢失费用。** 像对待契约一样对待它。不要意外销毁它；不要将其质押在恶意合约中。
- **具有转账费的 Token-2022 铸币**：Burn & Earn 支持它们，但转账费扣除在每次费用领取时适用——为此做好预算。
- **没有部分锁定。** 如果你想要 50% 锁定和 50% 可移动，首先将头寸分成两个头寸，然后仅锁定其中一个。
