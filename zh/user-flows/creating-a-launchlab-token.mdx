## 两种创建模式

LaunchLab 提供两条创建路径，可从 [raydium.io/launchlab/create](https://raydium.io/launchlab/create) 访问：

| | **JustSendit** | **LaunchLab** |
|---|---|---|
| 设置时间 | 约 1 分钟 | 约 5 分钟 |
| 代币供应 | 固定默认值 | 完全可配置 |
| SOL 目标 | 85 SOL（固定） | 最少 24 SOL，可自定义 |
| 曲线百分比 | 默认值 | 曲线上 51–80% |
| 归属 | 无 | 可选 |
| 迁移后费用 | 平台定义的 CPMM 创建者费用和 LP 政策 | 平台定义的 CPMM 创建者费用和 LP 政策 |
| 最适合 | 快速社区启动 | 结构化代币启动 |

## JustSendit 模式

最快的启动方式。需要最少的输入；平台填充合理的默认值。

### 你需要什么

- 一个已连接的钱包，有足够的 SOL 用于交易费用（创建约需 0.05–0.1 SOL）。
- 代币名称和代码符号。
- 符合 UI 要求的图像或 GIF。

### 步骤

1. 前往 [raydium.io/launchlab/create](https://raydium.io/launchlab/create) 并选择 **JustSendit**。
2. 输入代币**名称**和**代码符号**。
3. 可选：添加**描述**和**社交链接**（网站、Twitter/X、Telegram）。
4. 上传**徽标图像或 GIF**。
5. 可选：输入**初始购买金额**（以 SOL 计），在创建时购买代币。这会改变曲线上的初始价格状态，应在签署前审查。
6. 审查摘要并点击**创建**。
7. 在钱包中批准交易。

你的代币立即在粘合曲线上启动。一旦曲线收集了 85 SOL，它就会升级到 Raydium AMM 池。

## LaunchLab 模式

完全控制的创建，具有可配置的供应量、融资目标、曲线分配、归属和费用参数。

### 你需要什么

- 一个已连接的钱包，有约 0.1–0.5 SOL 用于创建和金库租赁。
- 在开始前准备好下面的所有输入（启动后无法更改设置）。

### 配置选项

#### 代币详情

- **名称、代码符号、徽标** — 与 JustSendit 相同。
- **描述和社交链接** — 建议用于可发现性。

#### 供应量和曲线分配

- **总供应量** — 要铸造的代币总数（例如 1,000,000,000）。
- **曲线分配（%）** — 放在粘合曲线上供公众购买的总供应量百分比（51–80%）。其余部分用于启动迁移后的流动性池。

<Warning>
  曲线分配和总供应量在启动时固定，**无法更改**。在签署前仔细选择。
</Warning>

#### SOL 融资目标

- 最低毕业阈值为 **24 SOL**。你可以设置更高的值。
- 这是曲线在升级到 CPMM 池之前必须收集的 SOL 数量。
- 设置过高会导致如果需求不足，曲线可能永远无法毕业。

#### 归属（可选）

归属将代币供应的一部分锁定，并按计划线性释放给指定的钱包。

| 字段 | 描述 |
|---|---|
| 总锁定金额 | 跨所有受益人锁定的代币（占总供应量的百分比，受程序上限限制）。 |
| 悬崖期 | 毕业后任何代币解锁前的等待时间（例如 180 天）。 |
| 解锁期 | 悬崖后线性解锁的持续时间（例如 365 天）。 |

锁定的代币不进入曲线，也不是毕业流动性池的一部分。它们按上述计划释放给每个受益人的钱包。

**重要的归属规则：**
- 悬崖期和解锁期在启动时固定 — 无法事后更改。
- 如果受益人丢失钱包密钥，锁定的代币将永久无法访问。如果恢复很重要，请使用多签。
- 毕业前未分配给受益人的 `total_locked_amount` 的任何部分都会永久卡住。分配全部金额。

有关完整的链上机制，请参阅 [LaunchLab 归属](/zh/products/launchlab/vesting)。

#### 迁移后费用分享

当代币升级时：
- LP 代币被铸造到 CPMM 池。
- 在签署前阅读当前平台配置。在 2026-08-14 升级之前，`creatorScale` 产生创建者费用密钥。对于之后执行的迁移，`platformScale + creatorScale` 变成平台拥有的费用密钥位置，`burnScale` 被销毁。来自早期迁移的现有创建者费用密钥保持不变。
- 你的迁移后创建者收入仅来自 CPMM 创建者费用，当你保持记录的 CPMM 池创建者身份且选定的配置启用它们时。

有关详情，请参阅 [创建者费用如何工作](/zh/user-flows/how-creator-fees-work)。

### 步骤

1. 在创建页面上选择 **LaunchLab** 模式。
2. 填入代币详情（名称、代码符号、徽标、描述、社交媒体）。
3. 设置**总供应量**和**曲线分配百分比**。
4. 设置你的 **SOL 融资目标**（≥ 24 SOL）。
5. 配置**归属**（如需要，设置受益人钱包和计划）。
6. 启用**迁移后费用分享**（如果你想要创建者 LP 份额）。
7. 可选：输入初始购买金额。
8. 审查完整摘要 — 曲线价格范围、毕业条件、LP 分割。
9. 点击**创建**并批准交易。

## 代币启动后

### 监控曲线进度

你的代币 LaunchLab 页面显示实时进度：
- 曲线售出的百分比。
- 筹集的 SOL 与毕业目标的对比。
- 当前价格和价格图表。

LaunchLab 不会干预未能达到毕业的启动。监控曲线进度并与社区清楚沟通。

### 毕业

毕业由第一笔将曲线推过阈值的交易自动触发 — 任何用户都可以调用此交易（调用者获得小额奖励）。作为创建者，你无需采取任何行动。

毕业后：
- 使用收集的 SOL 和剩余的曲线代币作为初始流动性创建 CPMM 池。
- 如果你启用了迁移后费用，**费用密钥 NFT** 被铸造到你的钱包。
- 从你的投资组合页面认领迁移前创建者费用。

### 认领迁移前创建者费用

如果你的平台在粘合曲线阶段启用创建者费用，它们会在金库中累积。随时从 raydium.io 上的**投资组合**页面认领它们。

## 要避免的陷阱

| 陷阱 | 怎么做 |
|---|---|
| 设置 SOL 目标过高 | 选择市场能够现实达到的目标。 |
| 在受益人确认前过度分配归属 | 未分配的归属供应在毕业后永久无法访问。 |
| 无意中转移或销毁费用密钥 NFT | 费用认领权永久丧失。将 NFT 保留在创建钱包或你控制的钱包中。 |
| 不进行初始购买 | 没有早期购买，狙击机器人可能以接近零的成本捕获所有早期代币，这可能会破坏社区信任。 |
