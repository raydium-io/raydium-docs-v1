<Info>
  LaunchLab 平台是由启动界面或社区使用的链上配置。平台设置可以影响费用、品牌、创建者费用支持和迁移后的流动性池行为。
</Info>

LaunchLab 通过平台 PDA 支持第三方启动环境。平台可以提供自己品牌的代币启动体验，同时使用 LaunchLab 程序基础设施和 Raydium 流动性池迁移。

## 平台可以控制的内容

| 设置 | 重要性 |
|---|---|
| 创建者费用 | 设置联合曲线创建者费用，并可选择 CPMM 创建者记录。 |
| 平台费用 | 设置平台级费用收入的接收地址。 |
| 品牌元数据 | 为平台提供名称、描述和徽标，可在应用界面中显示。 |
| 启动分组 | 让 UI 显示在同一平台下启动的代币。 |
| 迁移后的流动性池设置 | 可在平台将启动迁移到 CPMM 时定义 CPMM 费用配置。 |
| LP 分配 | 设置销毁份额和平台拥有的锁定 LP 份额。保留的创建者比例合并到平台份额中。 |
| 全局配置白名单 | 可限制启动仅使用平台管理员明确允许的 `GlobalConfig` 账户。 |

## 创建者应该检查的内容

在任何平台下启动前，请确认：

- 哪个钱包接收平台费用。
- 是否启用了创建者费用。
- 毕业后平台使用的 CPMM 费用配置和创建者记录。
- 毕业后 LP 代币如何分割。
- 是否会铸造平台费用密钥 NFT。
- 平台是否有自己的条款、政策或资格要求。

<Warning>
  平台设置可能会显著改变创建者经济学和用户预期。在签署启动交易前请审查这些设置。本页仅解释机制，不构成法律、财务或投资建议。
</Warning>

## 交易者应该检查的内容

购买 LaunchLab 代币时，平台可能会影响费用路径和迁移后的流动性处理。交易前：

- 检查代币的平台和启动设置。
- 如果 UI 显示，确认 CPMM 费用等级。
- 检查 LP 是否被销毁、锁定或分配。
- 从代币页面验证代币铸造地址，而不仅从社交媒体文本。
