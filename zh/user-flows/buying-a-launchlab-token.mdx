## LaunchLab 代币是什么

LaunchLab 代币在**联合曲线**上发行：一条由智能合约管理的价格曲线，随着更多代币被购买而上升，随着代币被出售而下降。曲线运行直到达到毕业阈值，此时每个新初始化的启动都会迁移到 Raydium CPMM 池，并可通过正常的 DEX 路由进行交易。

毕业前，你只能对曲线本身进行买卖。毕业后，代币像任何其他池一样在 Raydium 上交易。

## 购买前

### 进行自己的研究

- 验证代币的铸币地址与项目宣布的地址相匹配——骗子经常创建名称相同的代币。
- 检查**铸币权限是否已被撤销**。如果没有，创建者可以铸造新供应并稀释你的头寸。Solflare 等钱包和 Solscan 等浏览器会显示此状态。
- 查看联合曲线进度：已售出多少代币、还剩多少，以及当前价格。这在代币的 LaunchLab 页面上可见。
- 如果可能，检查创建者地址的历史。

### 理解曲线机制

联合曲线上的价格**不是固定的**。每次购买都会推高价格；每次出售都会降低价格。在你之前的大额购买可能会显著提高你支付的价格（抢先交易/三明治风险）。使用滑点限制（见下文）。

## 分步指南：通过 UI 购买

1. 导航到 [raydium.io/launchlab](https://raydium.io/launchlab) 并找到你想购买的代币。
2. 点击代币页面打开其详细视图。
3. 如果还没有连接钱包，请连接钱包。
4. 输入你想花费的 SOL（或报价代币）数量。
5. 查看 UI 中显示的**预计收到的代币**和**价格影响**。
6. 如果需要，调整你的**滑点容限**（见下文）。
7. 点击**购买**并在钱包中批准交易。
8. 交易确认后，代币将出现在你的钱包中。

<Tip>
  毕业前，你可以随时使用同一代币页面上的**出售**按钮将代币卖回曲线。毕业后，代币在 Raydium 池中；改用标准交换界面。
</Tip>

## 滑点

<Warning>
  **设置适当的滑点容限。** 联合曲线代币可能波动很大。如果滑点设置过低，当价格在你的报价和执行之间移动时，你的交易可能会失败。如果设置过高，你会暴露于三明治机器人。对于大多数启动，合理的起点是 1-3%；仅在非常低流动性的接近毕业的启动上根据需要提高。
</Warning>

滑点容限是你愿意接受的报价价格和执行价格之间的最大价格差异。LaunchLab UI 允许你在确认交易前设置此值。

## 毕业后

当曲线的毕业阈值被达到（由任何交易者），代币会自动迁移到 Raydium AMM 池。此时：

- 联合曲线关闭；没有进一步的买卖通过它。
- 你的代币保留在你的钱包中不变。
- 你现在可以在 Raydium 的交换页面或任何索引 Raydium 池的聚合器上交易代币。
- 池迁移可能需要几分钟才能在聚合器 UI 中显示。

## 风险

| 风险 | 描述 |
|---|---|
| 流动性控制风险 | LP 处理取决于平台和启动设置。检查 LP 是否被销毁、锁定、分配给创建者或分配给平台。 |
| 无毕业 | 如果曲线永远不会达到其阈值，交易仍然仅限于曲线。你仍然可以卖回曲线，但价格可能低于你支付的价格。 |
| 价格波动 | 联合曲线本质上是投机性的。价格可能跌至接近零。 |
| 假代币 | 骗子创建外观相似的代币。独立验证铸币地址。 |
| 智能合约风险 | 没有链上程序是无风险的。仅使用你准备承担风险的资金。 |
