<Info>
  LaunchLab 是 Raydium 的一级市场启动平台。项目将代币供应存入联合曲线；买家使用 SOL（或其他报价代币）与曲线交易；当达到毕业阈值时，曲线的资产自动迁移到 CPMM 池，代币变为自由交易。本页介绍从项目方角度的完整流程。
</Info>

## 你需要的东西

- **代币铸造** — 你要出售的代币。必须是新铸造的，具备：
  - 完整供应量铸造到你的钱包（以便存入曲线）。
  - 启动前撤销铸造权限（否则曲线价格可能被新铸造的代币操纵）。
- **元数据** — 名称、符号、图像、社交链接。Metaplex 元数据或类似。
- **钱包** — 约 1 SOL 用于创建租金 + 金库资金 + 优先费用（毕业本身由毕业者支付，不是你）。
- **决定**：
  - 曲线类型（二次方 vs 虚拟储备 CPMM）。
  - 毕业阈值。
  - LP 处置政策（销毁 / 锁定 / 转给创建者）。
  - 初始价格和上限。

## 曲线选择

LaunchLab 支持两种曲线族：

### 二次方（`curve_type = 0`）

价格随售出供应量二次方增长。经典的"公平启动"感觉 — 早期买家获得价格优势，后期买家支付更多，价格平稳加速。

```
price(s) = a * s^2 + b * s + c
```

其中 `s` 是售出的供应量。通常 `a > 0`（凸）。初始价格和毕业价格之间的差价由 `a, b, c` 和上限确定。

最适合：新奇启动、meme、社区驱动的项目。

### 虚拟储备 CPMM（`curve_type = 1`）

使用*虚拟*储备模拟恒定乘积 AMM — 曲线表现得像 CPMM，其中 `x * y = k`，但池从未提取的合成代币开始。

```
price = virtual_quote_reserve / virtual_base_reserve
```

当买家购买时，`virtual_base_reserve` 减少，`virtual_quote_reserve` 增加 — 曲线看起来与毕业后的 CPMM 完全相同。更平稳的交接。

最适合：希望毕业后价格连续性可预测的启动。

## UI 演练

在 [raydium.io/launchpad/create](https://raydium.io/launchpad/create)：

1. **代币**。粘贴铸造地址。UI 获取元数据并显示。
2. **曲线类型**。选择二次方或虚拟 CPMM；UI 为每种显示价格图表预览。
3. **毕业阈值**。默认：曲线在所有 `total_base_supply` 售出后结束。替代方案：在特定 `graduation_quote_amount` 处结束（例如 85 SOL）。
4. **报价代币**。SOL（默认）、USDC 或任何其他代币。SOL 是标准。
5. **LP 处置政策**：
   - **销毁** — LP 代币在毕业时发送到不可用地址。创建者无法提取流动性；用户永远信任该池。
   - **锁定** — LP 代币发送到时间锁定托管，持续 `lock_duration`。
   - **转给创建者** — LP 代币发送给创建者。最灵活，最不信任最小化。

   最受尊敬的启动使用销毁。

6. **审查**。UI 总结：预期价格范围、曲线售罄时的初始融资、毕业 CPMM 配置。
7. **签署**。一笔交易创建启动状态 + 基础金库 + 报价金库，将 `total_base_supply` 从你的钱包转移到基础金库。

## 程序化演练

曲线形状、报价代币、融资目标和 LP 处置政策**不是**参数 — 它们来自你绑定的 `GlobalConfig` 和你的启动运行的 `PlatformConfig`。你传递的是代币的身份、要绑定的配置，以及可选的首次购买：

```ts
import {
  Raydium,
  TxVersion,
  LAUNCHPAD_PROGRAM,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";
import BN from "bn.js";

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });
const programId = LAUNCHPAD_PROGRAM;

// 你生成基础代币的密钥对并用它签署。
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// 绑定配置：（报价代币、curve_type、索引）。这是固定曲线
// 形状、报价代币和融资目标的方式。
const configId   = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
const configInfo = LaunchpadConfig.decode(configData!.data);
const mintBInfo  = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "My New Token",
  symbol: "MYNEW",                    // 10 个字符或更少
  uri:    "https://example.com/metadata.json",
  migrateType: "amm",                 // "amm" | "cpmm"

  configId,
  configInfo,
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  createOnly: true,                   // true = 创建代币而不进行首次购买
  buyAmount:  new BN(1000),
  slippage:   new BN(100),            // 100 = 1%

  extraSigners: [pair],               // 基础代币密钥对必须签署
  txVersion: TxVersion.V0,
  computeBudgetConfig: { units: 400_000, microLamports: 50_000 },
});

// createLaunchpad 返回多个交易 - 按顺序运行。
const { txIds } = await execute({ sequentially: true });
console.log("Pool ID:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
```

`raydium.api.fetchLaunchConfigs()` 列出可用配置及其默认供应、售出金额和融资目标，因此你可以在用户签署前向他们展示给定配置的含义。完整注释版本，包括 Token-2022 变体：[`products/launchlab/code-demos`](/zh/products/launchlab/code-demos#create-a-launch)。

## 毕业前监控

通过 API 跟踪活动：

LaunchLab 有自己的 API 主机，与 `api-v3.raydium.io` 分开：

```ts
// 代币级信息，按基础代币键入（批量用逗号分隔）。
const r = await fetch(
  `https://launch-mint-v1.raydium.io/get/by/mints?ids=${mintA.toBase58()}`,
).then((r) => r.json());
console.log(r.data.rows[0]);

// 也可用：同一主机上的 /main/configs（配置列表），以及
// https://launch-history-v1.raydium.io/kline 和 /trade 用于价格和成交。
```

或直接读取链上状态。池 ID 是 `(programId, mintA, mintB)` 的 PDA：

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log({
  status:      poolInfo.status,
  baseSold:    poolInfo.realA.toString(),
  totalSellA:  poolInfo.totalSellA.toString(),
  quoteRaised: poolInfo.realB.toString(),
  raiseTarget: poolInfo.totalFundRaisingB.toString(),
});
```

进度最好用**价格**术语表示，而不是融资的比例，因为曲线是非线性的。演示仓库的 [`getFinishRate.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/getFinishRate.ts) 用 `Curve.getPrice`、`Curve.getPoolEndPriceReal` 和 `Curve.getPoolInitPriceByPool` 做到：

```
finishRate = (currentPrice − initPrice) / (endPrice − initPrice)   // 限制为 1
```

### 要监控的指标

- **售出率**：售出的基础代币百分比。毕业阈值通常在 80–100% 售出时。
- **当前价格**：从曲线在当前 `baseSold` 处推导。
- **独特买家**：通过索引器的不同支付者计数。
- **买卖比**：早期启动看到重买压力然后放缓。

如果 24 小时后售出率 `<10%`，考虑营销是否充分。LaunchLab 不会拯救宣传不足的启动。

## 毕业

毕业是一个单独的交易，**不是**任何人都可以调用的：`MigrateToCpswap` 和旧版 `MigrateToAmm` 都要求其签署者与绑定 `GlobalConfig` 上记录的钱包匹配（`migrate_to_cpswap_wallet` / `migrate_to_amm_wallet`），任何其他签署者都会得到 `InvalidOwner`。没有赏金。这些钱包由 Raydium 的毕业 crank 运行，在阈值被超过后的几秒内进行迁移。除了初始设置外，作为创建者无需采取任何行动。

### 毕业做什么

1. 读取金库余额。
2. 关闭曲线（不再对其进行买卖）。
3. 使用金库余额作为初始流动性创建新的 CPMM 池。
4. 根据金库余额铸造初始 LP 代币。
5. 根据配置的政策处置 LP 代币（销毁 / 锁定 / 转给创建者）。

毕业后，CPMM 池上线并通过正常 Raydium 路由进行交易。

### 监控毕业

在池状态上监控 `status` 并在其更改时切换你的 UI：

```ts
const before = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

setInterval(async () => {
  const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
  if (p.status !== before) console.log("migrated - switch to the CPMM pool page");
}, 10_000);
```

毕业池的地址是 `(cpswap config, token0, token1)` 的 CPMM PDA，所以你可以推导它而不是等待它被报告。对于索引器，通过 gRPC 订阅而不是轮询 — 见 [`products/launchlab/code-demos`](/zh/products/launchlab/code-demos#watch-configs-and-pools-over-grpc)。

创建者或第三方没有"手动毕业"路径。如果启动已超过其阈值但未迁移，这是迁移钱包的操作问题，不是你可以从客户端强制的。

## 毕业后

### 验证 CPMM 池

```ts
const pool = await raydium.cpmm.getPoolInfoFromRpc({ poolId: cpmmPoolId });
console.log("CPMM price:", pool.poolInfo.price);
console.log("CPMM TVL:  ", pool.poolInfo.tvl);
```

CPMM 池应该有（大约）：

- 基础代币余额：`total_base_supply - baseSold` + 曲线余数。
- 报价代币余额：`quoteRaised - graduationFee`。
- 价格：匹配最后曲线价格。

### 验证 LP 处置

- **销毁**：LP 代币供应显示发送到 1nc1nerator11111111111111111111111111111111 或类似。
- **锁定**：LP 代币在托管 PDA 中，带有解锁时间戳。
- **转给创建者**：LP 代币在创建者的钱包中。

### 收集创建者费用

如果你配置了创建者费用份额，定期调用：

构建器是 `claimCreatorFee`，它由**报价代币**而不是启动键入 — 一次调用扫除你在该代币中累积的创建者费用：

```ts
import { NATIVE_MINT } from "@solana/spl-token";

await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,      // 要在其中声称的报价代币
  txVersion: TxVersion.V0,
});
```

使用 `claimMultipleCreatorFee` 跨代币批处理。费用从毕业前的曲线交易累积，毕业后从 CPMM 池的创建者费用路径累积，当平台的 `platform_cp_creator` 将你留作记录的池创建者时 — 见 [`products/launchlab/platform-config`](/zh/products/launchlab/platform-config)。

## 公告检查清单

毕业后公告应包括：

- [ ] 毕业交易哈希。
- [ ] 新 CPMM 池 ID。
- [ ] LP 处置证明（销毁交易 / 锁定交易 / 创建者钱包）。
- [ ] 聚合器覆盖 ETA（钱包通常在 5 分钟内索引）。
- [ ] 代币合约验证（在公告渠道中匹配铸造地址）。

## 陷阱

### 1. 铸造权限未撤销

如果 `baseMint.mintAuthority` 仍然是你控制的密钥，你可以铸造新供应并卖入你自己的曲线。未撤销的启动通常被聚合器和列表网站标记为高风险或未验证。在启动前撤销。

### 2. 错误的曲线参数

`a` 太高的二次方曲线使早期代币免费（价格 ≈ 0），后期代币荒谬。`a` 太低的曲线使曲线几乎线性（失去"联合"感觉）。先在 devnet 上测试参数。

### 3. 毕业阈值太高

如果毕业需要比现实需求更多的资本，曲线永远不会毕业，买家被困在只能以更差价格卖回曲线的代币中。选择你实际可以达到的阈值。

### 4. 报价代币诈骗

如果你的报价代币是自定义代币（不是 SOL/USDC），用户不会信任它。坚持使用 SOL 或 USDC 作为报价。

### 5. 忘记资助基础金库

SDK 在创建时从你的钱包转移 `totalBaseSupply`。如果你的钱包没有它，交易会恢复。签署前确认余额。

### 6. LP 处置 = 销毁是不可逆的

一旦 LP 发送到 1nc1nerator，没有人可以提取流动性，*包括你*。这是重点 — 信任最小化。如果你不确定，不要选择销毁。

### 7. 毕业后 CPMM 费用等级

毕业池使用 LaunchLab 的默认 CPMM 配置（0.25%）。如果你想要 1% 或 0.01%，你需要在毕业后自己创建第二个 CPMM 池并迁移流动性 — 笨拙且分散。接受默认值，或通过直接 CPMM 创建而不是 LaunchLab 启动。
