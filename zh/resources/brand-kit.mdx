## 名称和大小写

| 形式 | 用途 |
|---|---|
| **Raydium** | 协议名称。始终使用标题大小写。不要写成 `raydium` 或 `RAYDIUM`。 |
| **Raydium Protocol** | 在需要与其他上下文中的 Raydium 名称区分时可用（它也是一种化学元素、一款视频游戏等）。 |
| **\$RAY** 或 **RAY** | Raydium 的原生 SPL 代币。在营销文案中使用美元前缀，在技术或表格上下文中使用纯 `RAY`。 |
| **Raydium AMM v4** / **Raydium CPMM** / **Raydium CLMM** / **LaunchLab** | 产品名称。LaunchLab 是一个单词，两个 L 都大写。 |
| **Burn & Earn** | 一个整体构造，使用 & 符号，两个名词都大写。 |

不要写 `Raydium DEX`、`Ray protocol` 或 `Raydiums`（无复数形式）。该协议是单数名词。

## 标志

Raydium 标志有两种形式：

- **文字标志** — 完整的 "Raydium" 类型锁定。在标题、新闻稿和任何需要名称可读的上下文中使用。
- **符号标志** — 独立的单字标志。在应用图标、网站图标和受限空间（头像、社交资料图片）中使用，其中文字标志在可读大小下无法显示。

### 浅色和深色版本

每种形式有两种配色：

| 文件 | 背景 | 使用场景 |
|---|---|---|
| `logo-light.svg` | 深色背景 | 深色 UI 界面上的主要放置位置。 |
| `logo-dark.svg` | 浅色背景 | 浅色 UI 界面上的主要放置位置。 |
| `mark-light.svg` | 深色背景 | 深色界面上仅显示符号。 |
| `mark-dark.svg` | 浅色背景 | 浅色界面上仅显示符号。 |

所有资源都是矢量 SVG 格式。尽可能使用 SVG。仅在最终渲染尺寸时栅格化为 PNG（避免缩放 PNG）。

### 清晰空间

在标志周围保持清晰空间，其大小等于 Raydium "R" 字符的高度。不要在此边距内用文本、图标或图形挤压标志。

### 最小尺寸

文字标志：屏幕上不低于 **120 px** 宽，印刷品中不低于 **20 mm**。
符号标志：屏幕上不低于 **24 px** 宽，印刷品中不低于 **6 mm**。

低于这些阈值，标志会失去清晰度，合作伙伴应切换到替代形式（例如，在空间受限时用符号替换文字标志）。

## 色彩调色板

Raydium 的视觉识别围绕紫色主色构建，配有更深和更浅的变体用于状态、深度和对比。

| 角色 | 十六进制 | RGB | 用途 |
|---|---|---|---|
| **主色** | `#8C6EFF` | 140 / 110 / 255 | 主品牌颜色。CTA、链接、关键强调。 |
| **浅色** | `#A88BFF` | 168 / 139 / 255 | 悬停状态、次要强调、浅色主题背景。 |
| **深色** | `#5E3BE1` | 94 / 59 / 225 | 活跃/按下状态、深色主题强调、深度。 |

辅助中性色：

| 角色 | 十六进制 | 用途 |
|---|---|---|
| **前景（浅色）** | `#0A0A0F` | 浅色界面上的正文。 |
| **前景（深色）** | `#FAFAFA` | 深色界面上的正文。 |
| **表面（浅色）** | `#FFFFFF` | 页面背景，浅色主题。 |
| **表面（深色）** | `#0F0F1A` | 页面背景，深色主题。 |
| **边框** | `#E5E5EB`（浅色）/ `#1F1F2E`（深色）| 卡片和分隔线边框。 |

不要重新着色标志。文字标志和符号始终以浅色或深色主版本呈现 — 永远不要着色、永远不要替换为渐变、永远不要应用品牌颜色。

## 排版

文档和网站使用 **Inter** 作为 UI 和正文。标题使用 Inter 的粗体权重（600–800）。代码块使用 **JetBrains Mono** 或任何等宽字体备选。

| 样式 | 字体 | 权重 | 用途 |
|---|---|---|---|
| 显示 / H1 | Inter | 800 | 页面标题。 |
| H2–H4 | Inter | 700 | 部分标题。 |
| 正文 | Inter | 400 | 段落文本。 |
| 强调 | Inter | 600 | 内联强调、加粗文本。 |
| 代码 | JetBrains Mono | 400–500 | 内联 `code` 和代码块。 |

Inter 是开源许可的，可从 [rsms.me/inter](https://rsms.me/inter) 获取。

## 标志的做法和禁忌

**应该做：**

- 使用 docs 仓库 `/logo/` 目录中的官方 SVG 主文件。
- 保持清晰空间和最小尺寸。
- 仅在文字标志和符号在视觉上平衡时配对使用（不要并排显示尺寸冲突的两者）。
- 在具有足够对比度的背景上呈现 — 在深色背景上使用浅色主版本，在浅色背景上使用深色主版本。

**不应该做：**

- 重新着色标志。没有紫色文字标志、没有彩虹、没有超出提供的浅色/深色之外的单色变体。
- 扭曲宽高比（无拉伸、无倾斜）。
- 添加投影、轮廓、发光或其他效果。
- 将标志放在繁忙的背景图像上，而不在下方放置对比度保留的纯色面板。
- 裁剪标志（不要仅显示从文字标志中裁剪出的 "R" — 改用符号标志）。
- 使用标志暗示对 Raydium 未正式合作的产品的认可。在中立上下文中使用 "powered by Raydium" 或 "integrated with Raydium" 徽章，不暗示任何审查。

## "Powered by Raydium" 徽章

如果你的集成使用 Raydium 作为路由源或流动性场所，简单的文本或徽章归属是受欢迎的：

```text
Powered by Raydium
Integrated with Raydium
Liquidity via Raydium
```

这些措辞已预先批准。放在集成的定价、交换或池界面附近 — 不要放在显眼的标题位置，这会暗示正式合作。

如果你是聚合器或钱包通过 Raydium 路由，并希望获得更显眼的归属，请在发布前通过 Discord（`#partnerships`）与团队联系。
