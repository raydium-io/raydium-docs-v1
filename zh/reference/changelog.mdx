## 版本发布

<Update label="2026-07-22" description="AMM v4：移除 OpenBook / Serum 依赖">
  AMM v4 移除了其长期未使用的 OpenBook/Serum 依赖、所有订单簿 CPI 和已弃用的做市指令。`SwapBaseIn` / `SwapBaseOut`、`Deposit` 和 `Withdraw` 保持其布局不变（移除的市场账户现在被忽略，不再验证）；**硬性破坏性** `WithdrawPnl`（17 → 10，无兼容性）和 `SetParams`（账户数量减少 + `param` 重新编号）；`Initialize`、`PreInitialize`、`MonitorStep`、`MigrateToOpenBook`、`WithdrawSrm`、`SimulateInfo`、`AdminCancelOrders` 不再可调用。链上账户布局和错误代码保持稳定；将交换迁移到 V2 入口点。

  [阅读完整条目 →](/zh/reference/changelog/2026-07-22-amm-v4-openbook-removal)
</Update>

<Update label="2026-06-22" description="稳定 AMM：移除已弃用的 OpenBook（市场）代码">
  稳定 AMM 移除了其长期未使用的 OpenBook 做市账户和代码。更小的 `SwapBaseIn` / `SwapBaseOut`（18 → 9）、`Deposit`（14 → 12）和 `Withdraw`（21/22 → 12）布局（旧布局仍兼容）；**硬性破坏性** `WithdrawPnl` 变更（16 → 10，无兼容性）；推荐费已停用；以及简化的仅金库池资产公式。大多数其他稳定指令不再可调用。

  [阅读完整条目 →](/zh/reference/changelog/2026-06-22-stable-amm-openbook-cleanup)
</Update>

<Update label="2026-05-18" description="CLMM：限价单、单边费用、动态费用">

## 文档约定

- **版本控制**：本文档使用基于日历的版本控制（YYYY-MM-DD）。每次更新都会在上面的时间线顶部添加一个新条目页面和新行。
