## 版本发布

<Update label="2026-07-30" description="CLMM：许可多池和限价单冻结账户保护">
  两个附加的、向后兼容的 CLMM 程序更新。`CreatePermissionedPool` 将客户端提供的非零 `seed_index` 折叠到池 PDA 种子中，允许白名单操作员（持有 `Permission` PDA 的操作员）为每个 `(config, mint0, mint1)` 创建多个池——因此池 ID 不再是交易对的规范标识。新的管理员指令 `CreatePermissionPda` / `ClosePermissionPda` 管理这些授权，`PoolState` 获得 `seed_index` 字段（从填充中提取，大小不变）。另外，`OpenLimitOrder` 现在接受输出端账户，并拒绝其输入或输出代币账户被冻结的订单（`NotApproved`）。

  [阅读完整条目 →](/zh/reference/changelog/2026-07-30-clmm-permissioned-pools)
</Update>

<Update label="2026-07-22" description="AMM v4：移除 OpenBook / Serum 依赖">
  AMM v4 移除了其长期不活跃的 OpenBook/Serum 依赖、所有订单簿 CPI 和已弃用的做市指令。`SwapBaseIn` / `SwapBaseOut`、`Deposit` 和 `Withdraw` 保持其布局（移除的市场账户现在被忽略，不被验证）；**硬破坏性** `WithdrawPnl`（17 → 10，无兼容性）和 `SetParams`（减少账户 + 重新编号 `param`）；`Initialize`、`PreInitialize`、`MonitorStep`、`MigrateToOpenBook`、`WithdrawSrm`、`SimulateInfo`、`AdminCancelOrders` 不再可调用。链上账户布局和错误代码保持稳定；将交换迁移到 V2 入口点。

  [阅读完整条目 →](/zh/reference/changelog/2026-07-22-amm-v4-openbook-removal)
</Update>

<Update label="2026-06-22" description="稳定 AMM：移除已弃用的 OpenBook（市场）代码">
  稳定 AMM 移除了其长期不活跃的 OpenBook 做市账户和代码。更小的 `SwapBaseIn` / `SwapBaseOut`（18 → 9）、`Deposit`（14 → 12）和 `Withdraw`（21/22 → 12）布局（旧布局仍兼容）；**硬破坏性** `WithdrawPnl` 变更（16 → 10，无兼容性）；推荐费已停用；以及简化的仅保险库池资产公式。大多数其他稳定指令不再可调用。

  [阅读完整条目 →](/zh/reference/changelog/2026-06-22-stable-amm-openbook-cleanup)
</Update>

<Update label="2026-05-18" description="CLMM：限价单、单边费用、动态费用">
  三个可选的、向后兼容的 CLMM 功能：一级限价单（带有 `limit_order_admin` 结算保管人）、单边费用收集（`CollectFeeOn`）和波动率跟踪动态费用。添加 `CreateCustomizablePool`、`PoolState` 重塑（**索引器破坏性变更**）、新的 `TickState` 字段、十一个新错误代码（带有数字偏移）以及匹配的 SDK / API 添加。

  [阅读完整条目 →](/zh/reference/changelog/2026-05-18-clmm-limit-orders)
</Update>

## 文档约定

- **版本控制**：本文档使用基于日历的版本控制（YYYY-MM-DD）。每次更新都会在上面的时间线顶部添加一个新条目页面和新行。
- **每个版本一个页面**：每个版本摘要都位于 `reference/changelog/` 下的自己的页面上，因此此索引保持简洁，每个条目都可独立链接。
- **验证日期**：每个条目记录内容上次与链上 / API 状态和程序源代码交叉检查的时间。如果未说明，假设为条目的主要日期。
- **破坏性变更**：在受影响的页面上用方框警告标注，并在条目中标记。
- **覆盖范围**：此更新日志涵盖文档集本身。协议本身的历史时间线位于 [`introduction/history-and-milestones`](/zh/introduction/history-and-milestones)，是"Raydium 上何时发生 X"的真实来源。
