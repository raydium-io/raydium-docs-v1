## 各产品交换费

费用值为输入金额的百分比，在池数学计算前应用。

| 产品 | 可用档位 | 默认/最常用 | 分配 |
|---------|-----------------|---------------------|-------|
| **AMM v4** | 0.25%（仅此） | 0.25% | 88% LP，12% 协议（25 中的 22/3） |
| **CPMM** | 0.01%、0.25%、1% | 0.25% | 100% LP（协议分成可按 AmmConfig 配置，目前为 0%） |
| **CLMM** | 0.01%、0.05%、0.25%、1% | 0.25% | 88% LP，12% 协议 |
| **LaunchLab（毕业前）** | 1%（默认） | 1% | 50% 到池种子，50% 到 LaunchLab 金库 |
| **LaunchLab（毕业后 CPMM）** | 0.25% | 0.25% | 继承 CPMM 分配 |

### 费用分母约定

- **AMM v4**：费用编码为 x/10,000。"25" 表示 0.25%。
- **CPMM/CLMM**：费用编码为 x/1,000,000。"2500" 表示 0.25%。

直接读取链上数据时，使用该池程序的正确分母。

## 协议费用分配

在每笔费用的「协议」分成中，还有进一步的分配：

| 产品 | 交换费中的协议分成 | 协议内部分配 |
|---------|----------------------------|------------------------|
| AMM v4 | 12%（3/25） | 100% 到金库 |
| CPMM | 按 AmmConfig 可配置（目前 0%） | N/A |
| CLMM | 交换费的 12% | 100% 到金库 |
| LaunchLab | 毕业前交换费的 50% | 100% 到 LaunchLab 金库 |

**LP 分成**自动流向 LP 代币持有者：

- AMM v4 / CPMM：累积在池储备中，提取时按比例分配。
- CLMM：累积在 `fee_growth_global_X/Y` 中，通过 `collectFee` 领取。

## 创建成本

部署池时支付的一次性 SOL 成本。

| 产品 | 租赁成本 | 创建费 | 典型总计 |
|---------|-----------|--------------|---------------|
| AMM v4 | ~0.15 SOL（多个账户） | 0.2 SOL | ~0.35 SOL |
| CPMM | ~0.04 SOL（池 + 金库 + 观察） | 0.15 SOL | ~0.19 SOL |
| CLMM | ~0.075 SOL（池 + 观察 + 初始 tick 数组） | 0 SOL | ~0.075 SOL |
| Farm v6 | ~0.02 SOL（农场状态 + 奖励金库） | 0.1 SOL（反垃圾） | ~0.12 SOL |
| LaunchLab 启动 | ~0.015 SOL（绑定曲线账户） | 0.1 SOL（LaunchLab 费） | ~0.115 SOL |

所有租赁都可恢复——关闭池/头寸/农场会返还 lamports。

## Token-2022 费用交互

当池的一侧或两侧使用带转账费的 Token-2022 时，有效费用会复合：

```
net input to pool   = amount_in × (1 − transfer_fee_in)
pool charges swap   = net × swap_fee_rate
net output to user  = out × (1 − transfer_fee_out)
```

示例：CPMM 0.25% 池，输入侧有 1% 转账费，输出侧有 0.5% 转账费。

```
amount_in        = 1000
net_to_pool      = 1000 × 0.99    = 990
pool swap fee    = 990 × 0.0025   = 2.475 (kept as LP fee)
amount_after_fee = 987.525
amount_out (AMM) = 987.525 × ratio, say 987.525 × 0.98 = 967.77
net_out_to_user  = 967.77 × 0.995 = 962.94
```

有效费用：**~3.7%**，尽管名义上池费仅为 0.25%。

SDK 通过 `getComputeAmountOut` 计算有效费率——引用 Token-2022 池时始终使用它。

## LaunchLab 细节

| 阶段 | 费用 |
|-------|-----|
| 绑定曲线交易（买或卖） | 1%（50/50 分配池/金库） |
| 毕业（一次性） | ~0.04 SOL 从曲线储备中 |
| 毕业后（CPMM 池） | 0.25%（标准 CPMM 费） |

启动代币的项目可在绑定曲线阶段包含创建者费。毕业后，选定的 CPMM 配置也可能为记录的池创建者收取单独的 CPMM 创建者费。平台拥有的 Fee Key 代表 LP 费权利，不是创建者费凭证。见 [`products/launchlab/creator-fees`](/zh/products/launchlab/creator-fees)。

## Farm v6 奖励成本模型

农场本身不收费——它们是奖励分配。但运营需要 SOL：

| 成本 | 典型 |
|------|---------|
| 农场创建 | 0.1 SOL 反垃圾 + ~0.02 SOL 租赁 |
| 充值奖励金库 | 仅代币 + ~0.0005 SOL 交易费 |
| 回收未使用奖励 | ~0.0005 SOL 交易费 |

农场还需要奖励金库中有足够的 lamports 来覆盖农场生命周期的租赁；关闭时返还。

## 如何在链上读取当前值

### CPMM/CLMM AmmConfig

```ts
const config = await raydium.cpmm.getAmmConfigs();
console.log(config[0]);
// {
//   id: "...",
//   tradeFeeRate: 2500,         // 2500 / 1_000_000 = 0.25%
//   protocolFeeRate: 0,         // 0 / 1_000_000 = 0%
//   fundFeeRate: 0,
//   ...
// }
```

### AMM v4 池

```ts
const poolInfo = await raydium.liquidity.getPoolInfoFromRpc({ poolId });
console.log(poolInfo.ammFeesNumerator, poolInfo.ammFeesDenominator);
// 25, 10000 → 0.25%
```

### Farm v6 奖励率

```ts
const farm = await raydium.farm.getFarmInfoFromRpc({ id: farmId });
console.log(farm.farmData.rewardInfos);
// Per-reward: emissionsPerSecond, startTime, endTime
```
