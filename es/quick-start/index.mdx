## Requisitos previos

Ejecuta esto una vez:

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

Necesitas:

- **Node 18+** con soporte ESM (`"type": "module"` en `package.json` o extensión `.mjs`).
- **Un par de claves de Solana** en `~/.config/solana/id.json` (o en cualquier lugar — establece `KEYPAIR`). Consulta [`solana-fundamentals/toolchain`](/es/solana-fundamentals/toolchain#solana-cli) para generar un par de claves.
- **Una billetera financiada.** El script de intercambio necesita solo su cantidad de entrada más un pequeño colchón — un intercambio CPMM cuesta ~0.0015 SOL en tarifas de red (consulta [`reference/fee-comparison`](/es/reference/fee-comparison#network-fees-per-typical-operation)), más renta única si el intercambio tiene que abrir una cuenta de token para ti. Crear un pool cuesta más: el script CPMM solo lleva una tarifa de creación de pool única de ~0.15 SOL antes de liquidez inicial o renta. Consulta la sección Setup de cada script para la cifra actual antes de financiar tu billetera.
- **Una URL de RPC.** El RPC público gratuito funciona para pruebas; para algo más que una prueba de humo, usa un proveedor de pago.

Establece estos una vez por shell:

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **Cluster.** Los tres scripts usan mainnet por defecto. Devnet necesita `RPC_URL=https://api.devnet.solana.com` más `cluster: "devnet"` dentro del script — para los dos scripts de creación de pool, ese no es el único cambio; consulta la sección Setup de cada script para ver qué más tiene que cambiar. Ten en cuenta que la liquidez inicial del pool en devnet es escasa; espera tener que acuñar tus propios tokens de prueba.
</Info>

## Después de este capítulo

Cada script imprime su resultado en cadena — una cotización de intercambio y enlace de transacción, direcciones de nuevos pools, o una nueva posición y su NFT — y una sola línea apuntando a la siguiente página en el capítulo [SDK & API](/es/sdk-api) para la operación que realizó. Cuando estés listo para escribir tu propia integración:

- **Backends y bots** → [Trade API](/es/sdk-api/trade-api).
- **Frontends y aplicaciones de control total** → [TypeScript SDK](/es/sdk-api/typescript-sdk).
- **Composición en cadena** → [Rust CPI](/es/sdk-api/rust-cpi).
- **Elegir entre ellos** → la tabla de comparación en la parte superior de [SDK & API](/es/sdk-api).
