<Info>
  LaunchLab es el principal lugar de lanzamiento de mercado primario de Raydium. Un proyecto deposita su suministro de tokens en una curva de vinculación; los compradores intercambian contra la curva usando SOL (u otro mint de cotización); cuando se alcanza un umbral de graduación, los activos de la curva se migran automáticamente a un pool CPMM, y el token se vuelve libremente comercializable. Esta página te guía a través de todo el flujo desde el lado del proyecto.
</Info>

## Lo que necesitas

- **Mint de token** — el token que deseas vender. Debe ser recién acuñado con:
  - Suministro completo acuñado en tu billetera (para que puedas depositarlo en la curva).
  - Autoridad de acuñación revocada antes del lanzamiento (de lo contrario, el precio de la curva puede ser manipulado por nuevas acuñaciones).
- **Metadatos** — nombre, símbolo, imagen, enlaces sociales. Metadatos de Metaplex o similar.
- **Billetera** — ~1 SOL para renta de creación + financiamiento de bóveda + tarifas de prioridad (la graduación en sí es pagada por el graduador, no por ti).
- **Decisión sobre**:
  - Tipo de curva (cuadrática vs CPMM de reservas virtuales).
  - Umbral de graduación.
  - Política de disposición de LP (Quemar / Bloquear / AlCreador).
  - Precio inicial y límite.

## Selección de curva

LaunchLab admite dos familias de curvas:

### Cuadrática (`curve_type = 0`)

El precio crece cuadráticamente con el suministro vendido. Sensación clásica de "lanzamiento justo" — los compradores tempranos obtienen una ventaja de precio, los compradores tardíos pagan más, el precio se acelera suavemente.

```
price(s) = a * s^2 + b * s + c
```

donde `s` es el suministro vendido. Típicamente `a > 0` (convexo). El diferencial entre los precios inicial y de graduación es determinista dado `a, b, c` y el límite.

Mejor para: lanzamientos novedosos, memes, proyectos impulsados por la comunidad.

### CPMM de reservas virtuales (`curve_type = 1`)

Emula un AMM de producto constante usando reservas *virtuales* — la curva se comporta como un CPMM con `x * y = k` pero el pool comienza sembrado con tokens sintéticos que nunca se retiran.

```
price = virtual_quote_reserve / virtual_base_reserve
```

A medida que los compradores compran, `virtual_base_reserve` disminuye y `virtual_quote_reserve` aumenta — la curva se ve idéntica a lo que el CPMM posterior a la graduación se verá. Transición más suave.

Mejor para: lanzamientos que desean continuidad de precio predecible posterior a la graduación.

## Recorrido de la interfaz de usuario

En [raydium.io/launchpad/create](https://raydium.io/launchpad/create):

1. **Token.** Pega la dirección del mint. La interfaz obtiene los metadatos y los muestra.
2. **Tipo de curva.** Elige cuadrática o CPMM virtual; la interfaz muestra una vista previa del gráfico de precios para cada una.
3. **Umbral de graduación.** Predeterminado: la curva termina después de que todo el `total_base_supply` haya sido vendido. Alternativa: terminar en un `graduation_quote_amount` específico (p. ej., 85 SOL).
4. **Mint de cotización.** SOL (predeterminado), USDC, u otro mint. SOL es estándar.
5. **Política de disposición de LP:**
   - **Quemar** — Tokens LP enviados a una dirección inutilizable en la graduación. El creador no puede retirar liquidez; los usuarios confían en el pool para siempre.
   - **Bloquear** — Tokens LP enviados a un depósito con bloqueo de tiempo por `lock_duration`.
   - **AlCreador** — Tokens LP enviados al creador. Más flexible, menos minimización de confianza.

   Los lanzamientos más respetados usan Quemar.

6. **Revisar.** La interfaz resume: rango de precio esperado, recaudación inicial si la curva se agota, configuración de CPMM de graduación.
7. **Firmar.** Una transacción crea el estado de lanzamiento + bóveda base + bóveda de cotización, transfiere `total_base_supply` desde tu billetera a la bóveda base.

## Recorrido programático

La forma de la curva, el mint de cotización, el objetivo de recaudación y la política de disposición de LP **no** son argumentos — provienen del `GlobalConfig` al que te vinculas y del `PlatformConfig` bajo el cual se ejecuta tu lanzamiento. Lo que pasas es la identidad del mint, la configuración a vincular, y opcionalmente una primera compra:

```ts
import {
  Raydium,
  TxVersion,
  LAUNCHPAD_PROGRAM,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";
import BN from "bn.js";

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });
const programId = LAUNCHPAD_PROGRAM;

// Generas el par de claves del mint base y firmas con él.
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// Vincula una configuración: (mint de cotización, curve_type, índice). Esto es lo que fija la forma de la curva,
// el mint de cotización y el objetivo de recaudación.
const configId   = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
const configInfo = LaunchpadConfig.decode(configData!.data);
const mintBInfo  = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "My New Token",
  symbol: "MYNEW",                    // 10 caracteres o menos
  uri:    "https://example.com/metadata.json",
  migrateType: "amm",                 // "amm" | "cpmm"

  configId,
  configInfo,
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  createOnly: true,                   // true = crear el mint sin una primera compra
  buyAmount:  new BN(1000),
  slippage:   new BN(100),            // 100 = 1%

  extraSigners: [pair],               // el par de claves del mint base debe firmar
  txVersion: TxVersion.V0,
  computeBudgetConfig: { units: 400_000, microLamports: 50_000 },
});

// createLaunchpad devuelve varias transacciones - ejecútalas en orden.
const { txIds } = await execute({ sequentially: true });
console.log("Pool ID:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
```

`raydium.api.fetchLaunchConfigs()` lista las configuraciones disponibles con su suministro predeterminado, cantidad de venta y objetivo de recaudación, para que puedas mostrar al usuario lo que una configuración dada implica antes de que firme. Versión completamente anotada, incluyendo la variante Token-2022: [`products/launchlab/code-demos`](/es/products/launchlab/code-demos#create-a-launch).

## Monitoreo previo a la graduación

Rastrea la actividad a través de la API:

LaunchLab tiene sus propios hosts de API, separados de `api-v3.raydium.io`:

```ts
// Información a nivel de mint, indexada por mint base (separada por comas para un lote).
const r = await fetch(
  `https://launch-mint-v1.raydium.io/get/by/mints?ids=${mintA.toBase58()}`,
).then((r) => r.json());
console.log(r.data.rows[0]);

// También disponible: /main/configs (lista de configuración) en el mismo host, y
// https://launch-history-v1.raydium.io/kline y /trade para precio y ejecuciones.
```

O lee el estado en cadena directamente. El ID del pool es un PDA de `(programId, mintA, mintB)`:

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log({
  status:      poolInfo.status,
  baseSold:    poolInfo.realA.toString(),
  totalSellA:  poolInfo.totalSellA.toString(),
  quoteRaised: poolInfo.realB.toString(),
  raiseTarget: poolInfo.totalFundRaisingB.toString(),
});
```

El progreso se expresa mejor en términos de **precio** en lugar de como una fracción de la recaudación, porque la curva es no lineal. El repositorio de demostración [`getFinishRate.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/getFinishRate.ts) lo hace con `Curve.getPrice`, `Curve.getPoolEndPriceReal` y `Curve.getPoolInitPriceByPool`:

```
finishRate = (currentPrice − initPrice) / (endPrice − initPrice)   // limitado a 1
```

### Métricas a monitorear

- **Tasa de venta**: porcentaje del base vendido. El umbral de graduación es típicamente del 80–100% vendido.
- **Precio actual**: derivado de la curva en el `baseSold` actual.
- **Compradores únicos**: recuento de pagadores distintos a través del indexador.
- **Relación compra-venta**: los lanzamientos tempranos ven una fuerte presión de compra que se ralentiza.

Si la venta es `<10%` después de 24 horas, considera si el marketing es adecuado. LaunchLab no rescata lanzamientos poco promocionados.

## Graduación

La graduación es una transacción separada, y **no** es invocable por nadie: `MigrateToCpswap` y el legado `MigrateToAmm` requieren que su firmante coincida con una billetera registrada en el `GlobalConfig` vinculante (`migrate_to_cpswap_wallet` / `migrate_to_amm_wallet`), y cualquier otro firmante obtiene `InvalidOwner`. No hay recompensa. Esas billeteras son ejecutadas por el crank de graduación de Raydium, que aterriza la migración dentro de segundos de que se cruce el umbral. No se requiere acción de tu parte como creador más allá de la configuración inicial.

### Qué hace la graduación

1. Lee los saldos de la bóveda.
2. Cierra la curva (sin más compras/ventas contra ella).
3. Crea un nuevo pool CPMM con los saldos de la bóveda como liquidez inicial.
4. Acuña tokens LP iniciales basados en los saldos de la bóveda.
5. Dispone de los tokens LP según la política configurada (Quemar / Bloquear / AlCreador).

Después de la graduación, el pool CPMM está activo y se negocia a través del enrutamiento normal de Raydium.

### Monitoreo para graduación

Observa `status` en el estado del pool y cambia tu interfaz cuando cambie:

```ts
const before = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

setInterval(async () => {
  const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
  if (p.status !== before) console.log("migrated - switch to the CPMM pool page");
}, 10_000);
```

La dirección del pool graduado es el PDA de CPMM para `(cpswap config, token0, token1)`, por lo que puedes derivarla en lugar de esperar a que se reporte. Para un indexador, suscríbete sobre gRPC en lugar de hacer polling — ver [`products/launchlab/code-demos`](/es/products/launchlab/code-demos#watch-configs-and-pools-over-grpc).

No hay una ruta de "graduación manual" para un creador o un tercero. Si un lanzamiento ha cruzado su umbral y no ha migrado, eso es un asunto operativo para la billetera de migración, no algo que puedas forzar desde un cliente.

## Posterior a la graduación

### Verifica el pool CPMM

```ts
const pool = await raydium.cpmm.getPoolInfoFromRpc({ poolId: cpmmPoolId });
console.log("CPMM price:", pool.poolInfo.price);
console.log("CPMM TVL:  ", pool.poolInfo.tvl);
```

El pool CPMM debe tener (aproximadamente):

- Saldo de token base: `total_base_supply - baseSold` + remanente de curva.
- Saldo de token de cotización: `quoteRaised - graduationFee`.
- Precio: coincide con el último precio de la curva.

### Verifica la disposición de LP

- **Quemar**: El suministro del mint LP se muestra enviado a 1nc1nerator11111111111111111111111111111111 o similar.
- **Bloquear**: Tokens LP en el PDA del depósito con marca de tiempo de desbloqueo.
- **AlCreador**: Tokens LP en la billetera del creador.

### Recauda tarifas del creador

Si configuraste una participación de tarifa del creador, llama periódicamente:

El constructor es `claimCreatorFee`, y está indexado por el **mint de cotización** en lugar de por un lanzamiento — una llamada barre tus tarifas de creador acumuladas en ese mint:

```ts
import { NATIVE_MINT } from "@solana/spl-token";

await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,      // el mint de cotización a reclamar
  txVersion: TxVersion.V0,
});
```

Usa `claimMultipleCreatorFee` para agrupar entre mints. Las tarifas se acumulan desde operaciones de curva previas a la graduación, y posteriores a la graduación desde la ruta de tarifa del creador del pool CPMM cuando el `platform_cp_creator` de la plataforma te deja como el creador del pool registrado — ver [`products/launchlab/platform-config`](/es/products/launchlab/platform-config).

## Lista de verificación de anuncio

El anuncio posterior a la graduación debe incluir:

- [ ] Hash de transacción de graduación.
- [ ] Nuevo ID de pool CPMM.
- [ ] Prueba de disposición de LP (tx de quema / tx de bloqueo / billetera del creador).
- [ ] ETA de cobertura del agregador (las billeteras típicamente indexan dentro de 5 minutos).
- [ ] Verificación del contrato de token (coincide con la dirección del mint en todos los canales de anuncio).

## Trampas

### 1. Autoridad de acuñación no revocada

Si `baseMint.mintAuthority` sigue siendo una clave que controlas, puedes acuñar nuevo suministro y venderlo en tu propia curva. Los lanzamientos que no han revocado comúnmente se marcan como de alto riesgo o no verificados por agregadores y sitios de listado. Revoca antes de lanzar.

### 2. Parámetros de curva incorrectos

Las curvas cuadráticas con `a` demasiado alto hacen que los tokens tempranos sean gratis (precio ≈ 0) y los tokens posteriores absurdos. Las curvas con `a` demasiado bajo hacen que la curva sea casi lineal (pierden la sensación de "vinculación"). Prueba los parámetros en devnet primero.

### 3. Umbral de graduación demasiado alto

Si la graduación requiere más capital que la demanda realista, la curva nunca se gradúa y los compradores quedan atrapados con tokens que solo pueden vender de vuelta a la curva (a peores precios). Elige un umbral que realmente puedas alcanzar.

### 4. Estafas de mint de cotización

Si tu mint de cotización es un token personalizado (no SOL/USDC), los usuarios no confiarán en él. Mantente en SOL o USDC para cotización.

### 5. Olvidó financiar la bóveda base

El SDK transfiere `totalBaseSupply` desde tu billetera en la creación. Si tu billetera no lo tiene, la tx se revierte. Confirma el saldo antes de firmar.

### 6. Disposición de LP = Quemar es irreversible

Una vez que LP se envía a 1nc1nerator, nadie puede retirar liquidez, *incluyéndote a ti*. Este es el punto — minimización de confianza. No elijas Quemar si no estás seguro.

### 7. Nivel de tarifa CPMM posterior a la graduación

El pool graduado usa la configuración CPMM predeterminada de LaunchLab (0.25%). Si querías 1% o 0.01%, necesitas crear un segundo pool CPMM tú mismo posterior a la graduación y migrar liquidez — incómodo, y fragmentando. Acepta el predeterminado, o lanza a través de creación directa de CPMM en lugar de LaunchLab.
