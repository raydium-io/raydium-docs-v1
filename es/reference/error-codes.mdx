## Cómo funcionan los códigos de error de Anchor

Anchor asigna a cada variante de la enumeración `ErrorCode` de un programa un código numérico comenzando en `6000`. Una transacción fallida expone:

- **Código de error numérico** (p. ej. `0x1771` = 6001) en los registros de la transacción.
- **Nombre del error** (p. ej. `InvalidOwner`) del IDL.
- **Cadena `#[msg(...)]`** que Anchor emitió en `log_messages`.

Los integradores deben coincidir con el **código numérico**, no con la cadena de mensaje (la cadena puede reescribirse sin cambiar de versión).

```ts
// Ejemplo: detectar el error de slippage de CPMM y mostrar un mensaje UX limpio.
const CPMM_EXCEEDED_SLIPPAGE = 6005;

try {
  await sdk.cpmm.swap({ ... });
} catch (err: any) {
  const code = err?.error?.errorCode?.number ?? err?.code;
  if (code === CPMM_EXCEEDED_SLIPPAGE) {
    showToast("El precio se movió más allá de tu tolerancia de slippage. Aumenta el slippage o reinténtalo.");
    return;
  }
  throw err;
}
```

## Mapeo de errores del SDK a errores del programa

El SDK oficial de TypeScript envuelve errores en cadena en `SendTransactionError` y, para programas de Anchor, `AnchorError`:

```ts
import { AnchorError } from "@coral-xyz/anchor";

try {
  await sdk.cpmm.swap({ ... });
} catch (err) {
  if (err instanceof AnchorError) {
    console.log(err.error.errorCode.number, err.error.errorCode.code, err.error.errorMessage);
    // 6005 ExceededSlippage "Exceeds desired slippage limit"
  } else {
    // SendTransactionError sin procesar — inspecciona err.logs para la línea "custom program error: 0x...".
  }
}
```

Si no estás usando Anchor en el lado del cliente, analiza los registros de la transacción:

```
Program <ProgramID> invoke [1]
Program log: AnchorError caused by account: pool_state. Error Code: ExceededSlippage. Error Number: 6005. Error Message: Exceeds desired slippage limit.
```

El patrón `Error Number: (\d+)` es estable en versiones de Anchor y seguro para coincidir.

## Regeneración de estas tablas

Cuando se actualiza un programa y añade un nuevo error, vuelve a extraer de la fuente:

```bash
# Clona y grep la enumeración de error en orden.
git clone --depth=1 https://github.com/raydium-io/raydium-cp-swap
awk '/#\[msg\(/{ gsub(/^[ \t]*#\[msg\("|"\)\][ \t]*/,""); m=$0; getline; gsub(/,/,""); gsub(/^[ \t]+/,""); print "6000+++\t" $0 "\t" m }' \
  raydium-cp-swap/programs/cp-swap/src/error.rs
# Reemplaza 6000+++ con 6000,6001,... monótonamente crecientes. Añade nuevas filas a la tabla anterior.
```

Siempre actualiza [`reference/changelog`](/es/reference/changelog) cuando se añade una nueva variante, para que los integradores que actualicen el SDK sepan que deben actualizar sus manejadores de error.
