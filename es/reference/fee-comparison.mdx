## Comisiones de swap por producto

Los valores de comisión son porcentajes del monto de entrada, aplicados antes de la matemática del pool.

| Producto | Niveles disponibles | Predeterminado / más usado | División |
|---------|-----------------|---------------------|-------|
| **AMM v4** | 0.25% (solo) | 0.25% | 88% LP, 12% protocolo (22/3 de 25) |
| **CPMM** | 0.01%, 0.25%, 1% | 0.25% | 100% LP (participación del protocolo configurable por AmmConfig, actualmente 0%) |
| **CLMM** | 0.01%, 0.05%, 0.25%, 1% | 0.25% | 88% LP, 12% protocolo |
| **LaunchLab (pre-graduación)** | 1% (predeterminado) | 1% | 50% al pool semilla, 50% a tesorería de LaunchLab |
| **LaunchLab (post-graduación CPMM)** | 0.25% | 0.25% | Hereda división de CPMM |

### Convención de denominador de comisión

- **AMM v4**: las comisiones se codifican como x/10,000. "25" significa 0.25%.
- **CPMM/CLMM**: las comisiones se codifican como x/1,000,000. "2500" significa 0.25%.

Al leer datos en cadena directamente, usa el denominador correcto para el programa del pool.

## Divisiones de comisiones del protocolo

Dentro de la participación del "protocolo" de cada comisión, se aplican divisiones adicionales:

| Producto | Participación del protocolo en comisión de swap | División dentro del protocolo |
|---------|----------------------------|------------------------|
| AMM v4 | 12% (3/25) | 100% a tesorería |
| CPMM | Configurable por AmmConfig (actualmente 0%) | N/A |
| CLMM | 12% de comisión de swap | 100% a tesorería |
| LaunchLab | 50% de comisión de swap pre-graduación | 100% a tesorería de LaunchLab |

La **participación de LP** fluye a los tenedores de tokens LP automáticamente:

- AMM v4 / CPMM: acumulada en reservas del pool, distribuida pro-rata al retiro.
- CLMM: acumulada en `fee_growth_global_X/Y`, reclamable vía `collectFee`.

## Costos de creación

Costos únicos pagados en SOL para desplegar un pool.

| Producto | Costo de renta | Comisión de creación | Total típico |
|---------|-----------|--------------|---------------|
| AMM v4 | ~0.15 SOL (múltiples cuentas) | 0.2 SOL | ~0.35 SOL |
| CPMM | ~0.04 SOL (pool + bóvedas + observación) | 0.15 SOL | ~0.19 SOL |
| CLMM | ~0.075 SOL (pool + observación + arrays de tick iniciales) | 0 SOL | ~0.075 SOL |
| Farm v6 | ~0.02 SOL (estado de farm + bóvedas de recompensa) | 0.1 SOL (anti-spam) | ~0.12 SOL |
| Lanzamiento de LaunchLab | ~0.015 SOL (cuenta de curva de vinculación) | 0.1 SOL (comisión de LaunchLab) | ~0.115 SOL |

Toda la renta es recuperable — cerrar el pool / posición / farm devuelve los lamports.

## Interacción de comisión de Token-2022

Cuando uno o ambos lados de un pool usan Token-2022 con una comisión de transferencia, la comisión efectiva se compone:

```
entrada neta al pool   = monto_entrada × (1 − comisión_transferencia_entrada)
pool cobra swap        = neto × tasa_comisión_swap
salida neta al usuario = salida × (1 − comisión_transferencia_salida)
```

Ejemplo: pool CPMM 0.25%, lado de entrada tiene comisión de transferencia de 1%, lado de salida tiene comisión de transferencia de 0.5%.

```
monto_entrada        = 1000
neto_al_pool         = 1000 × 0.99    = 990
comisión_swap_pool   = 990 × 0.0025   = 2.475 (mantenida como comisión LP)
monto_después_comisión = 987.525
monto_salida (AMM)   = 987.525 × ratio, digamos 987.525 × 0.98 = 967.77
salida_neta_al_usuario  = 967.77 × 0.995 = 962.94
```

Comisión efectiva: **~3.7%** a pesar de una comisión de pool nominal de 0.25%.

El SDK calcula la tasa efectiva vía `getComputeAmountOut` — siempre úsala al cotizar pools de Token-2022.

## Especificidades de LaunchLab

| Fase | Comisión |
|-------|-----|
| Operaciones de curva de vinculación (compra o venta) | 1% (dividida 50/50 pool/tesorería) |
| Graduación (única) | ~0.04 SOL desde reservas de curva |
| Post-graduación (pool CPMM) | 0.25% (comisiones estándar de CPMM) |

Los proyectos que lanzan tokens pueden incluir una comisión de creador durante la fase de curva de vinculación. Después de la graduación, la configuración de CPMM seleccionada también puede cobrar una comisión de creador de CPMM separada para el creador del pool registrado. La Fee Key propiedad de la plataforma representa derechos de comisión LP y no es una credencial de comisión de creador. Consulta [`products/launchlab/creator-fees`](/es/products/launchlab/creator-fees).

## Modelo de costo de recompensa de Farm v6

Los farms no cobran comisiones per se — son distribución de recompensas. Pero cuestan SOL para operar:

| Costo | Típico |
|------|---------|
| Creación de farm | 0.1 SOL anti-spam + ~0.02 SOL renta |
| Recargar bóveda de recompensa | Solo los tokens + ~0.0005 SOL tx |
| Reclamar recompensas no utilizadas | ~0.0005 SOL tx |

Los farms también requieren suficientes lamports en la bóveda de recompensa para cubrir renta durante la vida útil del farm; el cierre los devuelve.

## Cómo leer valores actuales en cadena

### AmmConfig de CPMM/CLMM

```ts
const config = await raydium.cpmm.getAmmConfigs();
console.log(config[0]);
// {
//   id: "...",
//   tradeFeeRate: 2500,         // 2500 / 1_000_000 = 0.25%
//   protocolFeeRate: 0,         // 0 / 1_000_000 = 0%
//   fundFeeRate: 0,
//   ...
// }
```

### Pool AMM v4

```ts
const poolInfo = await raydium.liquidity.getPoolInfoFromRpc({ poolId });
console.log(poolInfo.ammFeesNumerator, poolInfo.ammFeesDenominator);
// 25, 10000 → 0.25%
```

### Tasa de recompensa de Farm v6

```ts
const farm = await raydium.farm.getFarmInfoFromRpc({ id: farmId });
console.log(farm.farmData.rewardInfos);
// Por recompensa: emissionsPerSecond, startTime, endTime
```
