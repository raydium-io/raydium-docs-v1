## Para quién es este capítulo

Desarrolladores que integran Raydium desde fuera de la cadena (TS/JS, Python, backends) o desde otro programa de Solana (Rust CPI). También agentes de IA e integradores de herramientas de codificación — consulta [Integración de IA](/es/sdk-api/ai-integration).

<Info>
  **¿Quieres ejecutar algo primero?** Tres scripts de extremo a extremo — swap, desplegar pool CPMM, desplegar pool CLMM — están en [Inicio rápido](/es/quick-start). Los scripts de swap y CPMM son archivos únicos que pegas y ejecutas; el flujo CLMM requiere algunos pasos adicionales. Ejecuta una transacción real primero, luego vuelve aquí para la referencia completa.
</Info>

## Elige tu ruta de integración

Cinco rutas para elegir. La correcta depende de qué está llamando a Raydium y cuánto control necesitas.

| Ruta | Mejor para | Latencia | Lógica personalizada | Lenguajes |
|---|---|---|---|---|
| [Trade API](/es/sdk-api/trade-api) | Backends, bots, Blinks — en cualquier lugar donde quieras una tx construida por servidor | Más baja | Limitada (rutas preestablecidas) | Cualquiera |
| [TypeScript SDK](/es/sdk-api/typescript-sdk) | Aplicaciones Node/TS y frontends que necesitan acceso completo al constructor | Media | Completa | TS / JS |
| [Integración Python](/es/sdk-api/python-integration) | Backends de Python y pipelines de ML | Media | Completa (construcción manual de instrucciones) | Python |
| [Rust CPI](/es/sdk-api/rust-cpi) | Programas de composición que llaman a Raydium desde la cadena | N/A (en cadena) | Completa + componible | Rust |
| [IDL de Anchor](/es/sdk-api/anchor-idl) | Generación de código para lenguajes sin soporte de primera clase (Go, Kotlin, Swift, ...) | Variable | Completa | Cualquiera con herramienta de generación de código Anchor |

Si no estás seguro: backends y bots → **Trade API**; frontends y aplicaciones con control total → **TypeScript SDK**; composición en cadena → **Rust CPI**.
