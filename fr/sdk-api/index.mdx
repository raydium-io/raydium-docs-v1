## À qui s'adresse ce chapitre

Développeurs intégrant Raydium hors chaîne (TS/JS, Python, backends) ou depuis un autre programme Solana (Rust CPI). Également pour les agents IA et les intégrateurs d'outils de codage — voir [Intégration IA](/fr/sdk-api/ai-integration).

<Info>
  **Vous voulez exécuter quelque chose en premier ?** Trois scripts de bout en bout — swap, déployer un pool CPMM, déployer un pool CLMM — se trouvent dans [Démarrage rapide](/fr/quick-start). Les scripts swap et CPMM sont des fichiers uniques que vous collez et exécutez ; le flux CLMM nécessite quelques étapes supplémentaires. Exécutez d'abord une vraie transaction, puis revenez ici pour la référence complète.
</Info>

## Choisissez votre chemin d'intégration

Cinq chemins au choix. Le bon dépend de ce qui appelle Raydium et du niveau de contrôle dont vous avez besoin.

| Chemin | Idéal pour | Latence | Logique personnalisée | Langages |
|---|---|---|---|---|
| [Trade API](/fr/sdk-api/trade-api) | Backends, bots, Blinks — partout où vous voulez une tx construite par serveur | La plus basse | Limitée (routes prédéfinies) | N'importe lequel |
| [TypeScript SDK](/fr/sdk-api/typescript-sdk) | Applications Node/TS et frontends nécessitant un accès complet au builder | Moyenne | Complète | TS / JS |
| [Intégration Python](/fr/sdk-api/python-integration) | Backends Python et pipelines ML | Moyenne | Complète (construction manuelle d'instr) | Python |
| [Rust CPI](/fr/sdk-api/rust-cpi) | Programmes composables qui appellent Raydium depuis la chaîne | N/A (on-chain) | Complète + composable | Rust |
| [IDL Anchor](/fr/sdk-api/anchor-idl) | Codegen pour les langages sans support natif (Go, Kotlin, Swift, ...) | Variable | Complète | N'importe lequel avec un outil codegen Anchor |

Si vous n'êtes pas sûr : backends et bots → **Trade API** ; frontends et applications avec contrôle complet → **TypeScript SDK** ; composition on-chain → **Rust CPI**.

## Discipline de versioning

Chaque exemple de code sur chaque page de ce chapitre a une bannière en haut :

```
SDK:       @raydium-io/raydium-sdk-v2 vX.Y.Z
Program:   see /reference/program-addresses
Cluster:   mainnet-beta
Verified:  YYYY-MM-DD
```

Si vous modifiez un exemple de code, mettez à jour la bannière.
