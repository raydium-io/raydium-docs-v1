## À qui s'adresse ce chapitre

Développeurs et chercheurs en protocoles provenant d'autres chaînes (EVM, Cosmos, Move) ou nouveaux sur Solana. Les utilisateurs finaux peuvent ignorer ce chapitre.

L'objectif est pragmatique : vous donner exactement ce que vous devez lire pour aborder les chapitres Produits et SDK sans surprise. Ce n'est pas un tutoriel Solana général — consultez la documentation officielle de Solana pour cela.
