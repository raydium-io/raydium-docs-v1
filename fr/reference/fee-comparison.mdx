## Frais de swap par produit

Les valeurs de frais sont des pourcentages du montant d'entrée, appliqués avant les calculs du pool.

| Produit | Niveaux disponibles | Par défaut / plus utilisé | Répartition |
|---------|-----------------|---------------------|-------|
| **AMM v4** | 0,25 % (uniquement) | 0,25 % | 88 % LP, 12 % protocole (22/3 de 25) |
| **CPMM** | 0,01 %, 0,25 %, 1 % | 0,25 % | 100 % LP (part protocole configurable par AmmConfig, actuellement 0 %) |
| **CLMM** | 0,01 %, 0,05 %, 0,25 %, 1 % | 0,25 % | 88 % LP, 12 % protocole |
| **LaunchLab (pré-graduation)** | 1 % (par défaut) | 1 % | 50 % au pool seed, 50 % au trésor LaunchLab |
| **LaunchLab (post-graduation CPMM)** | 0,25 % | 0,25 % | Hérite de la répartition CPMM |

### Convention du dénominateur de frais

- **AMM v4** : les frais sont codés en x/10 000. « 25 » signifie 0,25 %.
- **CPMM/CLMM** : les frais sont codés en x/1 000 000. « 2500 » signifie 0,25 %.

Lors de la lecture directe des données on-chain, utilisez le dénominateur correct pour le programme du pool.

## Répartitions des frais du protocole

Dans la part « protocole » de chaque frais, des répartitions supplémentaires s'appliquent :

| Produit | Part protocole du frais de swap | Répartition au sein du protocole |
|---------|----------------------------|------------------------|
| AMM v4 | 12 % (3/25) | 100 % au trésor |
| CPMM | Configurable par AmmConfig (actuellement 0 %) | N/A |
| CLMM | 12 % du frais de swap | 100 % au trésor |
| LaunchLab | 50 % du frais de swap pré-graduation | 100 % au trésor LaunchLab |

La **part LP** est versée automatiquement aux détenteurs de tokens LP :

- AMM v4 / CPMM : accumulée dans les réserves du pool, distribuée au prorata lors du retrait.
- CLMM : accumulée dans `fee_growth_global_X/Y`, réclamable via `collectFee`.

## Coûts de création

Coûts uniques payés en SOL pour déployer un pool.

| Produit | Coût de rent | Frais de création | Total typique |
|---------|-----------|--------------|---------------|
| AMM v4 | ~0,15 SOL (plusieurs comptes) | 0,2 SOL | ~0,35 SOL |
| CPMM | ~0,04 SOL (pool + vaults + observation) | 0,15 SOL | ~0,19 SOL |
| CLMM | ~0,075 SOL (pool + observation + tick arrays initiaux) | 0 SOL | ~0,075 SOL |
| Farm v6 | ~0,02 SOL (farm state + reward vaults) | 0,1 SOL (anti-spam) | ~0,12 SOL |
| Lancement LaunchLab | ~0,015 SOL (bonding curve account) | 0,1 SOL (frais LaunchLab) | ~0,115 SOL |

Tout le rent est récupérable — fermer le pool / position / farm retourne les lamports.

## Interaction des frais Token-2022

Quand l'un ou les deux côtés d'un pool utilisent Token-2022 avec un frais de transfert, le frais effectif se compose :

```
net input to pool   = amount_in × (1 − transfer_fee_in)
pool charges swap   = net × swap_fee_rate
net output to user  = out × (1 − transfer_fee_out)
```

Exemple : pool CPMM 0,25 %, côté entrée avec frais de transfert 1 %, côté sortie avec frais de transfert 0,5 %.

```
amount_in        = 1000
net_to_pool      = 1000 × 0.99    = 990
pool swap fee    = 990 × 0.0025   = 2.475 (kept as LP fee)
amount_after_fee = 987.525
amount_out (AMM) = 987.525 × ratio, say 987.525 × 0.98 = 967.77
net_out_to_user  = 967.77 × 0.995 = 962.94
```

Frais effectifs : **~3,7 %** malgré un frais de pool nominal de 0,25 %.

Le SDK calcule le taux effectif via `getComputeAmountOut` — utilisez-le toujours lors de la cotation de pools Token-2022.

## Spécificités LaunchLab

| Phase | Frais |
|-------|-----|
| Trades bonding curve (achat ou vente) | 1 % (répartition 50/50 pool/trésor) |
| Graduation (une seule fois) | ~0,04 SOL depuis les réserves de curve |
| Post-graduation (pool CPMM) | 0,25 % (frais CPMM standard) |

Les projets lançant des tokens peuvent inclure un frais créateur pendant la phase bonding-curve. Après graduation, la config CPMM sélectionnée peut également facturer un frais créateur CPMM séparé pour le créateur du pool enregistré. La Fee Key détenue par la plateforme représente les droits de frais LP et n'est pas une credential de frais créateur. Consultez [`products/launchlab/creator-fees`](/fr/products/launchlab/creator-fees).

## Modèle de coût des récompenses Farm v6

Les farms ne facturent pas de frais à proprement parler — ce sont des distributions de récompenses. Mais elles coûtent des SOL à exploiter :

| Coût | Typique |
|------|---------|
| Création farm | 0,1 SOL anti-spam + ~0,02 SOL rent |
| Top-up vault de récompenses | Juste les tokens + ~0,0005 SOL tx |
| Réclamation récompenses inutilisées | ~0,0005 SOL tx |

Les farms nécessitent également suffisamment de lamports dans le vault de récompenses pour couvrir le rent pendant la durée de vie de la farm ; la fermeture les retourne.

## Comment lire les valeurs actuelles on-chain

### AmmConfig CPMM/CLMM

```ts
const config = await raydium.cpmm.getAmmConfigs();
console.log(config[0]);
// {
//   id: "...",
//   tradeFeeRate: 2500,         // 2500 / 1_000_000 = 0.25%
//   protocolFeeRate: 0,         // 0 / 1_000_000 = 0%
//   fundFeeRate: 0,
//   ...
// }
```

### Pool AMM v4

```ts
const poolInfo = await raydium.liquidity.getPoolInfoFromRpc({ poolId });
console.log(poolInfo.ammFeesNumerator, poolInfo.ammFeesDenominator);
// 25, 10000 → 0.25%
```

### Taux de récompense Farm v6

```ts
const farm = await raydium.farm.getFarmInfoFromRpc({ id: farmId });
console.log(farm.farmData.rewardInfos);
// Per-reward: emissionsPerSecond, startTime, endTime
```
