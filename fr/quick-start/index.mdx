## Prérequis

Exécutez ceci une fois :

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

Vous avez besoin de :

- **Node 18+** avec support ESM (`"type": "module"` dans `package.json` ou extension `.mjs`).
- **Une paire de clés Solana** à `~/.config/solana/id.json` (ou n'importe où — définissez `KEYPAIR`). Consultez [`solana-fundamentals/toolchain`](/fr/solana-fundamentals/toolchain#solana-cli) pour générer une paire de clés.
- **Un portefeuille financé.** Le script swap n'a besoin que du montant d'entrée plus un petit coussin — un swap CPMM coûte environ 0,0015 SOL en frais réseau (voir [`reference/fee-comparison`](/fr/reference/fee-comparison#network-fees-per-typical-operation)), plus un loyer unique si le swap doit ouvrir un compte de token pour vous. La création d'un pool coûte plus cher : le script CPMM seul entraîne un frais de création de pool unique d'environ 0,15 SOL avant la liquidité initiale ou le loyer. Consultez la section Setup de chaque script pour le chiffre actuel avant de financer votre portefeuille.
- **Une URL RPC.** Le RPC public gratuit fonctionne pour les tests ; pour plus qu'un test de fumée, utilisez un fournisseur payant.

Définissez ceci une fois par shell :

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **Cluster.** Les trois scripts utilisent par défaut mainnet. Devnet nécessite `RPC_URL=https://api.devnet.solana.com` plus `cluster: "devnet"` à l'intérieur du script — pour les deux scripts de création de pool, ce n'est pas le seul changement ; consultez la section Setup de chaque script pour voir ce qui d'autre doit changer. Sachez que la liquidité initiale du pool sur devnet est clairsemée ; attendez-vous à créer vos propres tokens de test.
</Info>
