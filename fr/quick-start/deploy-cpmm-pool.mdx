## Configuration

Assurez-vous d'avoir lu les [prérequis du démarrage rapide](/fr/quick-start) et que vous disposez de `RPC_URL`, `KEYPAIR` et des dépendances installées.

Vous devez également **approvisionner le portefeuille avec les montants initiaux** des deux mints, plus suffisamment de SOL pour couvrir les frais de création du pool et la location des comptes (~0,19 SOL au total sur mainnet — consultez [`reference/fee-comparison`](/fr/reference/fee-comparison#creation-costs) pour la répartition des frais/location, ou [`ray/protocol-fees`](/fr/ray/protocol-fees#pool-creation-fees) pour les frais uniquement).

**Exécuter ceci sur devnet.** Changer `cluster` en `"devnet"` ne suffit pas à lui seul. Ce script épingle deux imports nommés qui ne suivent pas `cluster` : `programId: CREATE_CPMM_POOL_PROGRAM` et `poolFeeAccount: CREATE_CPMM_POOL_FEE_ACC`, tous deux des constantes mainnet. Importez `DEVNET_PROGRAM_ID` du SDK et utilisez `DEVNET_PROGRAM_ID.CREATE_CPMM_POOL_PROGRAM` et `DEVNET_PROGRAM_ID.CREATE_CPMM_POOL_FEE_ACC` à la place — le même modèle que le [script CLMM](/fr/quick-start/deploy-clmm-pool) utilise.

## Le script

Enregistrez sous `create-cpmm.mjs` :

```ts create-cpmm.mjs icon="js"
import { Connection, Keypair, PublicKey } from "@solana/web3.js";
import {
  Raydium,
  TxVersion,
  CREATE_CPMM_POOL_PROGRAM,
  CREATE_CPMM_POOL_FEE_ACC,
} from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

// ── Config from env ──────────────────────────────────────────────
const RPC_URL  = process.env.RPC_URL  ?? "https://api.mainnet-beta.solana.com";
const KEYPAIR  = process.env.KEYPAIR  ?? `${process.env.HOME}/.config/solana/id.json`;
const MINT_A   = process.env.MINT_A;   // required, base58
const MINT_B   = process.env.MINT_B;   // required, base58
const AMOUNT_A = process.env.AMOUNT_A; // required, integer raw units
const AMOUNT_B = process.env.AMOUNT_B; // required, integer raw units

if (!MINT_A || !MINT_B || !AMOUNT_A || !AMOUNT_B) {
  console.error("Set MINT_A, MINT_B, AMOUNT_A, AMOUNT_B env vars.");
  process.exit(1);
}

// ── Setup ────────────────────────────────────────────────────────
const connection = new Connection(RPC_URL, "confirmed");
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(KEYPAIR, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});

// ── Pick the 0.25% fee tier ─────────────────────────────────────
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0);
if (!feeConfig) throw new Error("0.25% fee tier not found in CPMM configs.");

// ── Resolve mint metadata (Token-2022-aware) ────────────────────
const mintA = await raydium.token.getTokenInfo(new PublicKey(MINT_A));
const mintB = await raydium.token.getTokenInfo(new PublicKey(MINT_B));

// ── Build and execute ───────────────────────────────────────────
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA,
  mintB,
  mintAAmount:     new BN(AMOUNT_A),
  mintBAmount:     new BN(AMOUNT_B),
  startTime:       new BN(0), // open immediately
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
  computeBudgetConfig: {
    units: 600_000,
    microLamports: 100_000,
  },
});

const { txId } = await execute({ sendAndConfirm: true });

console.log(`Pool ID:  ${extInfo.address.poolId.toBase58()}`);
console.log(`LP mint:  ${extInfo.address.lpMint.toBase58()}`);
console.log(`Vault A:  ${extInfo.address.vaultA.toBase58()}`);
console.log(`Vault B:  ${extInfo.address.vaultB.toBase58()}`);
console.log(`Tx:       https://solscan.io/tx/${txId}`);
```

## L'exécuter

Exemple : créer un pool SOL/USDC avec 1 SOL et 160 USDC initiaux :

```bash icon="terminal"
export MINT_A="So11111111111111111111111111111111111111112"   # wSOL
export MINT_B="EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"   # USDC
export AMOUNT_A="1000000000"   # 1 SOL (9 decimals)
export AMOUNT_B="160000000"    # 160 USDC (6 decimals)

node create-cpmm.mjs
```

Résultat attendu :

```text
Pool ID:  HgC5...3kXb
LP mint:  4ZAS...9rkV
Vault A:  J9Mu...mP2k
Vault B:  AaJq...8wxx
Tx:       https://solscan.io/tx/5dQ...
```

## Ce qui vient de se passer

1. **`getCpmmConfigs`** a récupéré la liste en direct des paliers de frais depuis `api-v3.raydium.io` et a sélectionné l'index 0 (le palier de 0,25 % — consultez [`reference/fee-comparison`](/fr/reference/fee-comparison) pour l'ensemble complet).
2. **`getTokenInfo`** a résolu les métadonnées de chaque mint, y compris le programme de token qui le possède. CPMM accepte à la fois les mints SPL Token et Token-2022 ; le SDK achemine automatiquement.
3. **`createPool`** a construit une transaction qui :
   - trie les mints dans l'ordre canonique,
   - dérive la PDA du pool, les vaults, le mint LP et l'autorité,
   - paie les frais uniques `create_pool_fee` à `CREATE_CPMM_POOL_FEE_ACC`,
   - crée les ATA de l'appelant s'ils manquent,
   - initialise les vaults avec `AMOUNT_A` et `AMOUNT_B`.
4. **Le prix initial** est défini par le ratio initial : `price = AMOUNT_B / AMOUNT_A` après ajustement décimal. Choisissez cela avec soin — les bots arbitreront tout misprix quelques secondes après l'ouverture du pool.
5. **`startTime: new BN(0)`** ouvre les échanges immédiatement. Pour préparer la liquidité avant l'ouverture au public, définissez un timestamp Unix futur.

## Erreurs courantes

- **`pool already exists`** — Un pool existe déjà pour cette paire de mints à ce palier de frais. Recherchez-le avant de créer.
- **`insufficient funds`** — Votre portefeuille n'a pas assez de `MINT_A`, `MINT_B` ou SOL (pour les frais de création du pool + location).
- **`Token-2022 extension not supported`** — L'un de vos mints utilise une extension que CPMM n'accepte pas. Consultez [`reference/token-2022-support`](/fr/reference/token-2022-support).

## Après le déploiement

Vous pouvez immédiatement échanger contre le nouveau pool — le script [Swap from CLI](/fr/quick-start/swap-from-cli) accepte votre nouvel `POOL_ID` directement. Les agrégateurs (Jupiter, etc.) indexeront le nouveau pool en quelques minutes.
