## Frais du routeur

Le programme AMM Routing ne prélève **aucun frais propre**. C'est un pur orchestrateur.

Tous les frais sont payés directement aux pools par lesquels vous routez :

- Chaque saut AMM v4 paie les frais AMM v4 (0,25 % répartis).
- Chaque saut CPMM paie les frais CPMM (configurables, généralement 0,25 % répartis).
- Chaque saut CLMM paie les frais CLMM (configurables par pool).
- Chaque saut stable paie les frais stable-swap (0,02 % — bien inférieur à AMM v4).

## Frais effectifs totaux sur une route

Si vous routez par N pools, vos frais totaux sont la somme des frais de tous les N sauts, composés.

**Exemple :**

Route : USDC → SOL (frais 0,25 %) → STEP (frais 0,25 %)

```
Entrée : 1000 USDC

Saut 1 (USDC/SOL) : frais 0,25 %
  Frais : 2,5 USDC
  Sortie vers saut 2 : ~997,5 USDC de pouvoir d'achat

Saut 2 (SOL/STEP) : frais 0,25 %
  Frais : ~2,49 STEP-équivalent
  Sortie : ~995 STEP-équivalent

Coût total : ~0,5 % (pas exactement 0,5 %, car les frais se composent)
```

Consultez la documentation des frais du pool respectif pour les répartitions exactes :

- [`products/amm-v4/fees`](/fr/products/amm-v4/fees)
- [`products/cpmm/fees`](/fr/products/cpmm/fees)
- [`products/clmm/fees`](/fr/products/clmm/fees) (si disponible)
- [`products/stable/fees`](/fr/products/stable/fees) (si disponible)

## Coût de calcul

Le coût de calcul du routeur est **linéaire en fonction du nombre de sauts** :

- **Surcharge fixe :** ~5k CU pour la logique de dispatch du routeur et la validation des comptes.
- **Coût par saut :** ~10k–50k CU selon le type de pool et la complexité :
  - CPMM : ~20k–30k CU
  - AMM v4 : ~40k–60k CU (inclut la validation OpenBook)
  - CLMM : ~50k–100k CU (calculs de tick intensifs)
  - Stable : ~30k–40k CU
- **Budget de transaction total :** 1,4M CU sur mainnet. Une route avec 10 sauts CPMM coûterait ~305k CU, laissant de la place pour d'autres opérations.

Consultez la documentation de chaque pool pour les coûts CU exacts.

## Surcharge d'initialisation des comptes

Chaque variante de swap activée route les jetons intermédiaires par des ATA contrôlés par l'utilisateur. À chaque saut intermédiaire, vous devez pré-créer et fournir une ATA appartenant à l'utilisateur :

- **Si l'ATA n'existe pas :** l'initialisation du programme ATA coûte ~5k CU + ~0,00203928 SOL de loyer par ATA. Initialisez-la avec le programme SPL Associated Token Account (ou, pour wSOL, avec la balise [`CreateSyncNative`](/fr/products/routing/instructions#createsyncnative-tag-5) 5).
- **Si l'ATA existe déjà :** aucune surcharge supplémentaire.

Pour une route à 5 sauts avec 4 jetons intermédiaires, vous auriez besoin de 4 nouvelles ATA si vous commencez de zéro = ~20k CU + ~0,00816 SOL.

Vous pouvez récupérer le loyer de toute ATA temporaire — généralement une ATA wSOL utilisée pour une seule route — en la fermant avec [`CloseTokenAccount`](/fr/products/routing/instructions#closetokenaccount-tag-6) (balise 6) une fois qu'elle a un solde zéro.
