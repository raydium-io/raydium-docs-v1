## Qu'est-ce que c'est

AMM v4 est le pool de première génération de Raydium. Il maintient un invariant à produit constant (xy=k). Le pool a été initialement conçu comme un **AMM hybride** : en plus de la courbe, il publiait une grille d'ordres limités espacés selon la suite de Fibonacci sur un marché OpenBook lié, de sorte que la liquidité du pool était visible pour les preneurs du carnet d'ordres. **Cette intégration OpenBook a depuis été supprimée du programme** (voir l'avertissement ci-dessus) ; AMM v4 est aujourd'hui un AMM à produit constant pur. Les comptes `AmmInfo` on-chain conservent leurs champs de référence `market` / `open_orders` pour la compatibilité de l'agencement, mais le programme ne les lit ni n'agit plus sur eux.

C'est toujours le produit avec la plus haute liquidité sur Raydium pour de nombreuses paires héritées, mais il est **plus recommandé pour les nouveaux pools** — consultez [CPMM](/fr/products/cpmm) pour les nouveaux déploiements.

**ID du programme :** consultez [reference/program-addresses](/fr/reference/program-addresses).

**Token-2022 :** non supporté. Les pools AMM v4 n'acceptent que les jetons SPL classiques.

## Quand lire ceci

- Vous auditez ou intégrez des pools AMM v4 existants.
- Vous construisez un routeur qui doit supporter la liquidité v4.
- Vous planifiez une migration de v4 vers CPMM — consultez aussi [user-flows/migrate-amm-v4-to-cpmm](/fr/user-flows/migrate-amm-v4-to-cpmm).

Si vous créez un **nouveau** pool, lisez plutôt [CPMM](/fr/products/cpmm).
