<Update label="2026-07-30" description="CLMM: 許可制マルチプールとリミットオーダー凍結アカウントガード">
  2つの追加的で後方互換性のあるCLMMプログラム更新。`CreatePermissionedPool`は、クライアント提供の非ゼロ`seed_index`をプールPDAシードに組み込み、ホワイトリストに登録されたオペレーター（`Permission` PDAを保有する）が`(config, mint0, mint1)`ごとに複数のプールを作成できるようにします。これにより、プールIDはペアの正規識別子ではなくなります。新しい管理者命令`CreatePermissionPda` / `ClosePermissionPda`がこれらの権限を管理し、`PoolState`は`seed_index`フィールドを取得します（パディングから確保、サイズ変更なし）。別途、`OpenLimitOrder`は出力側アカウントを受け取り、入力または出力トークンアカウントが凍結されている（`NotApproved`）オーダーを拒否するようになりました。

  [詳細を読む →](/ja/reference/changelog/2026-07-30-clmm-permissioned-pools)
</Update>

<Update label="2026-07-22" description="AMM v4: OpenBook / Serum依存関係の削除">
  AMM v4は、長く休止していたOpenBook/Serum依存関係、すべてのオーダーブックCPI、および廃止されたマーケットメイキング命令を削除します。`SwapBaseIn` / `SwapBaseOut`、`Deposit`、`Withdraw`はレイアウトを保持します（削除されたマーケットアカウントは無視され、検証されません）。**破壊的な**`WithdrawPnl`（17 → 10、互換性なし）と`SetParams`（アカウント削減 + `param`の再番号付け）。`Initialize`、`PreInitialize`、`MonitorStep`、`MigrateToOpenBook`、`WithdrawSrm`、`SimulateInfo`、`AdminCancelOrders`は呼び出し不可になりました。オンチェーンアカウントレイアウトとエラーコードは安定したままです。スワップをV2エントリポイントに移行してください。

  [詳細を読む →](/ja/reference/changelog/2026-07-22-amm-v4-openbook-removal)
</Update>

<Update label="2026-06-22" description="Stable AMM: 廃止されたOpenBook（マーケット）コードの削除">
  Stable AMMは、長く休止していたOpenBookマーケットメイキングアカウントとコードを削除します。より小さい`SwapBaseIn` / `SwapBaseOut`（18 → 9）、`Deposit`（14 → 12）、`Withdraw`（21/22 → 12）レイアウト（古いレイアウトは互換性あり）。**破壊的な**`WithdrawPnl`変更（16 → 10、互換性なし）。リファラルフィーは廃止され、ボルトのみのプールアセット式が簡略化されました。その他のほとんどのStable命令は呼び出し不可になりました。

  [詳細を読む →](/ja/reference/changelog/2026-06-22-stable-amm-openbook-cleanup)
</Update>

## ドキュメンテーション規約

- **バージョニング**: このドキュメンテーションはカレンダーベースのバージョニング（YYYY-MM-DD）を使用します。各更新は新しいエントリページを追加し、上記のタイムラインに新しい行を追加します。
- **リリースごとに1ページ**: すべてのリリース概要は`reference/changelog/`の下の独自のページに存在するため、このインデックスは短く保たれ、各エントリは独立してリンク可能です。
- **検証日**: すべてのエントリは、コンテンツがオンチェーン / API状態とプログラムソースに対して最後に相互確認された時期を記録します。記載されていない場合は、エントリのメイン日付を想定してください。
- **破壊的変更**: 影響を受けるページのボックス警告で呼び出され、エントリでタグ付けされます。
- **カバレッジ**: この変更履歴はドキュメンテーションセット自体をカバーしています。プロトコル自体の歴史的タイムラインは[`introduction/history-and-milestones`](/ja/introduction/history-and-milestones)に存在し、「Raydiumで何がいつ起こったか」の信頼できる情報源です。
