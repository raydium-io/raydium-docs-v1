## プロダクト別スワップ手数料

手数料値は入力額のパーセンテージで、プール計算の前に適用されます。

| プロダクト | 利用可能なティア | デフォルト / 最頻使用 | 分配 |
|---------|-----------------|---------------------|-------|
| **AMM v4** | 0.25%（のみ） | 0.25% | 88% LP、12% プロトコル（25 の 22/3） |
| **CPMM** | 0.01%、0.25%、1% | 0.25% | 100% LP（プロトコル分配は AmmConfig ごとに設定可能、現在 0%） |
| **CLMM** | 0.01%、0.05%、0.25%、1% | 0.25% | 88% LP、12% プロトコル |
| **LaunchLab（卒業前）** | 1%（デフォルト） | 1% | 50% プール シード、50% LaunchLab トレジャリー |
| **LaunchLab（卒業後 CPMM）** | 0.25% | 0.25% | CPMM 分配を継承 |

### 手数料分母の規約

- **AMM v4**: 手数料は x/10,000 でエンコードされます。「25」は 0.25% を意味します。
- **CPMM/CLMM**: 手数料は x/1,000,000 でエンコードされます。「2500」は 0.25% を意味します。

オンチェーンデータを直接読み取る場合は、プールのプログラムに対して正しい分母を使用してください。

## プロトコル手数料分配

各手数料の「プロトコル」シェア内で、さらに分配が適用されます。

| プロダクト | スワップ手数料のプロトコル分配 | プロトコル内の分配 |
|---------|----------------------------|------------------------|
| AMM v4 | 12%（3/25） | 100% トレジャリーへ |
| CPMM | AmmConfig ごとに設定可能（現在 0%） | N/A |
| CLMM | スワップ手数料の 12% | 100% トレジャリーへ |
| LaunchLab | 卒業前のスワップ手数料の 50% | 100% LaunchLab トレジャリーへ |

**LP シェア**は LP トークンホルダーに自動的に流れます。

- AMM v4 / CPMM: プール準備金に蓄積され、引き出し時に按分配分されます。
- CLMM: `fee_growth_global_X/Y` に蓄積され、`collectFee` 経由で請求可能です。

## Token-2022 手数料の相互作用

プールの一方または両方が転送手数料を持つ Token-2022 を使用する場合、実効手数料は複合します。

```
net input to pool   = amount_in × (1 − transfer_fee_in)
pool charges swap   = net × swap_fee_rate
net output to user  = out × (1 − transfer_fee_out)
```

例：CPMM 0.25% プール、入力側に 1% 転送手数料、出力側に 0.5% 転送手数料。

```
amount_in        = 1000
net_to_pool      = 1000 × 0.99    = 990
pool swap fee    = 990 × 0.0025   = 2.475 (kept as LP fee)
amount_after_fee = 987.525
amount_out (AMM) = 987.525 × ratio, say 987.525 × 0.98 = 967.77
net_out_to_user  = 967.77 × 0.995 = 962.94
```

実効手数料：名目上 0.25% プール手数料にもかかわらず、**約 3.7%**。

SDK は `getComputeAmountOut` 経由で実効レートを計算します — Token-2022 プールを見積もる場合は常にこれを使用してください。

## LaunchLab 仕様

| フェーズ | 手数料 |
|-------|-----|
| ボンディング カーブ トレード（買いまたは売り） | 1%（50/50 プール/トレジャリー分配） |
| 卒業（一回限り） | カーブ準備金から約 0.04 SOL |
| 卒業後（CPMM プール） | 0.25%（標準 CPMM 手数料） |

トークンをローンチするプロジェクトは、ボンディング カーブ フェーズ中にクリエイター手数料を含めることができます。卒業後、選択された CPMM 設定は、記録されたプール クリエイターに対して別の CPMM クリエイター手数料も請求する場合があります。プラットフォーム所有の Fee Key は LP 手数料権を表し、クリエイター手数料認証情報ではありません。[`products/launchlab/creator-fees`](/ja/products/launchlab/creator-fees) を参照してください。

## Farm v6 リワード コスト モデル

ファームは厳密には手数料を請求しません — リワード配分です。ただし、SOL で運用するコストがかかります。

| コスト | 典型的 |
|------|---------|
| ファーム作成 | 0.1 SOL スパム対策 + 約 0.02 SOL レント |
| リワード ボルト トップアップ | トークンのみ + 約 0.0005 SOL トランザクション |
| 未使用リワード 回収 | 約 0.0005 SOL トランザクション |

ファームは、ファームの有効期間中のレント をカバーするのに十分なランプをリワード ボルトに必要とします。クロージャーはそれらを返却します。

## オンチェーンで現在の値を読み取る方法

### CPMM/CLMM AmmConfig

```ts
const config = await raydium.cpmm.getAmmConfigs();
console.log(config[0]);
// {
//   id: "...",
//   tradeFeeRate: 2500,         // 2500 / 1_000_000 = 0.25%
//   protocolFeeRate: 0,         // 0 / 1_000_000 = 0%
//   fundFeeRate: 0,
//   ...
// }
```

### AMM v4 プール

```ts
const poolInfo = await raydium.liquidity.getPoolInfoFromRpc({ poolId });
console.log(poolInfo.ammFeesNumerator, poolInfo.ammFeesDenominator);
// 25, 10000 → 0.25%
```

### Farm v6 リワード レート

```ts
const farm = await raydium.farm.getFarmInfoFromRpc({ id: farmId });
console.log(farm.farmData.rewardInfos);
// Per-reward: emissionsPerSecond, startTime, endTime
```
