このドキュメンテーションのすべての内容は、動作する Solana 開発ツールチェーンがあることを前提としています。このページでは、ツール、2026 年 9 月時点で Raydium で動作することが確認されているバージョン、および特定のセットアップの注意点をリストアップしています。後の章のコード例を実行する前に、ここから始めてください。

**2 つのバージョンセットが重要であり、それらは同じではありません。** Raydium プログラムを*構築またはフォーク*するには、それらがピンしている正確なツールチェーン（2026-09-09 アップグレード時点で Rust 1.91.0、Agave 3.1.10、Anchor 1.0.2）が必要です。TypeScript または Python からデプロイされたプログラムに対して*統合*するには、それらと通信するのに十分な最新のクライアント ライブラリのみが必要であり、ピンはアドバイザリーです。以下の各セクションでは、どのケースをカバーしているかを示しています。

## コア ツール

### Solana CLI

Solana クラスタと対話するための標準的なコマンドライン インターフェース — ウォレット管理、RPC 呼び出し、プログラム デプロイメント。

インストール：

```bash
# Raydium プログラムが構築およびテストされるバージョン
sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.10/install)"

# またはタグの代わりにチャネルを追跡する
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

確認：

```bash
solana --version   # → solana-cli 3.1.10 (... client:Agave)
```

<Note>
  **インストール ホストが移動しました。** `release.solana.com` は Solana Labs に属していました。クライアントは現在 Anza によって **Agave** として保守されており、リリースは `release.anza.xyz` から提供されています。自己更新バイナリは `agave-install` です（`solana-install` はレガシー エイリアスとして保持されています）。したがって、`agave-install update` と `agave-install init <version>` が現在のスペルです。Solana 自体のドキュメントでは、CLI、Rust、Anchor を一緒にプルする 1 つのコマンド インストーラーも提供しています：

  ```bash
  curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
  ```

  そのインストーラーは独自の現在の概念を追跡し、Raydium のプログラムがピンしているものとは異なる Anchor を渡す可能性があります — その後 `anchor --version` を確認してください。
</Note>

メインネット用に設定：

```bash
solana config set --url https://api.mainnet-beta.solana.com
solana config set --keypair ~/.config/solana/id.json
solana-keygen new                           # ウォレットがない場合は作成
solana address                              # あなたの公開鍵
```

Raydium テスト用には、ほぼ常に資金が供給された devnet ウォレットが必要です：

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2                            # テスト用に 2 SOL
```

### SPL Token CLI

SPL Token / Token-2022 操作の公式 CLI — ミント作成、トークン ミント、転送。

インストール（Solana CLI に含まれています）：

```bash
spl-token --version
```

一般的な操作：

```bash
spl-token create-token                                  # SPL Token ミントを作成
spl-token create-token --program-id TOKEN_2022 ...      # Token-2022 ミントを作成
spl-token create-account <MINT>                         # ATA を作成
spl-token mint <MINT> 1000                              # あなたの ATA に 1000 トークンをミント
spl-token transfer <MINT> 100 <RECIPIENT>               # 100 を転送
spl-token display <ACCOUNT_OR_MINT>                     # 検査
```

### Anchor CLI

Raydium IDL の取得、クライアントの構築、プログラムの検証に必要です。

インストール：

```bash
cargo install --git https://github.com/solana-foundation/anchor avm --locked --force
avm install 1.0.2
avm use 1.0.2
anchor --version   # → anchor-cli 1.0.2
```

<Note>
  **Anchor がリポジトリとメジャー バージョンを移動しました。** 標準的なリポジトリは現在 `github.com/solana-foundation/anchor` です（以前は `coral-xyz/anchor` でした）。Anchor 1.0 は Raydium プログラムが使用する最初のリリース ラインです — CPMM と LaunchLab は両方とも 2026-09-09 アップグレード時点で `anchor-lang`/`anchor-spl` `=1.0.2` をピンしており、CLMM は 2026-09-30 アップグレードで続きます。すべて `0.32.1` からアップグレードされています。`avm` は複数のバージョンを保持できます。`avm use 1.0.2` は `anchor build` が Raydium のアーティファクトを再現するようにします。Anchor 1.1 と 1.2 が存在し、独自のプログラムに対して正常にビルドされますが、ターゲット プログラムがピンしているものとは異なる `anchor-lang` マイナー バージョンに対してコンパイルされた CPI クレートはリンクされません — [`sdk-api/rust-cpi`](/ja/sdk-api/rust-cpi) を参照してください。
</Note>

一般的な操作：

```bash
anchor idl fetch <PROGRAM_ID> -o program.idl.json       # オンチェーン IDL を取得
anchor idl init -f idl.json <PROGRAM_ID>                # IDL をアップロード
anchor build                                             # ソースからプログラムをビルド
```

## TypeScript セットアップ

Raydium の主要な統合パス。

### パッケージ

```bash
npm install \
  @solana/web3.js \
  @solana/spl-token \
  @anchor-lang/core \
  @raydium-io/raydium-sdk-v2 \
  bn.js \
  decimal.js
```

2026 年 9 月時点で一緒に動作することが確認されているバージョン：

| パッケージ | バージョン | 注記 |
|---------|---------|------|
| `@solana/web3.js` | `^1.95` | 1.x API。`2.x` / `3.x` は異なる互換性のない API サーフェスです。Raydium SDK は 1.x をターゲットにしています。 |
| `@solana/spl-token` | `^0.4.15` | 0.4.15 は `createUnwrapLamportsInstruction` を公開しています — [回収可能なレント](/ja/solana-fundamentals/rent-and-reclaimable-rent)を参照してください。 |
| `@anchor-lang/core` | `^1.0`（現在 `1.2.0` に解決） | Anchor 1.x TypeScript クライアント。Raydium 自体のリポジトリは正確に `1.0.2` をピンしています。クライアント側の使用には任意の 1.x が機能しますが、テスト スイートと一致させたい場合は `1.0.2` をピンしてください。 |
| `@raydium-io/raydium-sdk-v2` | `0.2.64-alpha` | これらのドキュメント内のすべてのコード デモが使用するピン。 |

<Note>
  **`@coral-xyz/anchor` は凍結されています。パッケージは現在 `@anchor-lang/core` です。** `@coral-xyz/anchor` は Anchor が Coral から移動したときに `0.32.1` で停止しました。Anchor 1.x は `@anchor-lang/core` として公開され、Raydium 自体のプログラム リポジトリは 2026-09-09 アップグレード（CLMM は 2026-09-30）でテスト スイートをそれに切り替えました。実際に使用するインポートは変わりません — `import { Program, BN, AnchorProvider } from "@anchor-lang/core"` — したがって、移行はパッケージ名の変更とロックファイルの更新です。

  `0.3x` から移動する場合の 2 つの動作上の注記：`.accounts({...})` は現在、Anchor が自身で解決できないアカウントのみを受け入れるため、完全なセットを渡すビルダーは代わりに `.accountsPartial({...})` を呼び出す必要があります。また、`@anchor-lang/core/dist/cjs/utils/token` は `ASSOCIATED_PROGRAM_ID` などのヘルパーが移動した場所です。
</Note>

### 最小限のスクリプト

```ts
import { Connection, Keypair } from "@solana/web3.js";
import { Raydium } from "@raydium-io/raydium-sdk-v2";

const connection = new Connection("https://api.mainnet-beta.solana.com", "confirmed");
const owner      = Keypair.fromSecretKey(/* your key */);

const raydium = await Raydium.load({
  connection,
  owner,
  cluster:      "mainnet",
  disableFeatureCheck: true,
});

// `ids` はカンマ区切りリストであり、呼び出しは配列を返します
const [poolInfo] = await raydium.api.fetchPoolById({ ids: "..." });
console.log(poolInfo);
```

完全な SDK リファレンスについては、[`sdk-api/typescript-sdk`](/ja/sdk-api/typescript-sdk) を参照してください。

## Rust セットアップ

CPI 統合とオンチェーン プログラム用。

### ツールチェーン

```bash
rustup install 1.91.0           # Raydium プログラムがピンしているもの
rustup default 1.91.0
rustup component add rustfmt clippy
agave-install init 3.1.10       # SBF ツールチェーンが含まれています
```

`cargo build-sbf` でプログラムをビルドします（古い `cargo build-bpf` スペルは廃止されました）。

### Raydium CPI 統合用のプログラム Cargo.toml

```toml
# CPMM および/または CLMM 統合（Anchor 1.0）— 1 つのクレートは両方を取得できます
[dependencies]
anchor-lang     = "=1.0.2"
anchor-spl      = "=1.0.2"
raydium-cp-swap = { git = "https://github.com/raydium-io/raydium-cp-swap", branch = "master", features = ["cpi"] }
raydium-clmm    = { git = "https://github.com/raydium-io/raydium-clmm",    branch = "master", features = ["cpi"] }
```

`anchor-lang` と `anchor-spl` をターゲット プログラムがピンしているバージョンに `=` でピンしてください。`master` では、CPMM と CLMM は両方とも `=1.0.2` をピンしているため、**単一のクレートは両方に CPI できます**。Anchor 1.0 アップグレード前の `rev` と混在するクレートはビルドされません。[`sdk-api/rust-cpi`](/ja/sdk-api/rust-cpi#cargo-dependencies) を参照してください。

`"cpi"` フィーチャーは CPI ヘルパーを含む `cpi` モジュールをインポートします（`raydium_cp_swap::cpi::swap_base_input(...)` を使用できます）。[`sdk-api/rust-cpi`](/ja/sdk-api/rust-cpi) を参照してください。

### パッケージ

バージョン：

|---------|-----------|---------|

<Note>
  2 つの命名トラップがあります。RPC クライアントは `solana` としてインポートされますが、プロジェクトは **solana-py** と呼ばれています — `pip install solana-py` は何も有用なものをインストールしません。また、**PyPI に `raydium-py` パッケージはありません**：コミュニティ Raydium ヘルパーは、公開されたディストリビューションではなく、クローンするリポジトリ [`AL-THE-BOT-FATHER/raydium_py`](https://github.com/AL-THE-BOT-FATHER/raydium_py) です。このページの以前のリビジョンでは、決して機能しなかった `pip install raydium-py` 行をリストアップしていました。
</Note>

### 最小限のスクリプト

```python
from solana.rpc.async_api import AsyncClient
from solders.keypair import Keypair
from anchorpy import Provider, Wallet, Program

async def main():
    conn = AsyncClient("https://api.mainnet-beta.solana.com")
    owner = Keypair()
    wallet = Wallet(owner)
    provider = Provider(conn, wallet)

    # IDL とプログラムをロード
    with open("cpmm.idl.json") as f:
        idl = json.load(f)
    program = Program(idl, CPMM_PROGRAM_ID, provider)

    pool = await program.account["PoolState"].fetch(pool_id)

```

## RPC エンドポイント

パブリック メインネット RPC（`api.mainnet-beta.solana.com`）は大幅にレート制限されており、負荷がかかると調整されます。重要でない使用の場合は、プライベート エンドポイントを取得してください：

| プロバイダー | 注記 |
|----------|-------|
| Helius | 最も人気。寛大な無料ティア。 |
| Triton | エンタープライズ。プレミアム価格、安定。 |
| QuickNode | 堅実。サブ秒のレイテンシー。 |
| 独自の RPC ノード | ハードウェアで月額約 \$500。完全な制御。 |

設定：

```ts
const connection = new Connection("https://mainnet.helius-rpc.com/?api-key=...");
```

一部の RPC 操作には拡張機能が必要です：

- `getProgramAccounts` — 無制限スキャンは高コスト。一部のプロバイダーはゲートまたはスキャンごとに課金します。
- `getPriorityFeeEstimate` — Helius 固有のエンドポイント。他のプロバイダーには同等のものがあります。
- `geyser` / WebSocket ストリーミング — 低レイテンシー ボットに必要。すべてのプロバイダーが公開しているわけではありません。

## Devnet と Localnet

### Devnet

Solana のパブリック テスト クラスタ。Raydium には部分的な devnet デプロイメントがあります：

- テスト用に一部の CPMM プールが存在します。
- AMM v4 には履歴 devnet プールがあります。
- CLMM にはいくつかのデモ プールがあります。
- Farm v6 がデプロイされています。

```bash
solana config set --url https://api.devnet.solana.com
solana airdrop 2
```

SDK は `cluster: "devnet"` を介して devnet をサポートします：

```ts
const raydium = await Raydium.load({ connection, owner, cluster: "devnet" });
```

**注意**：devnet プールは流動性が薄く、状態が古い可能性があります。価格発見に devnet を使用しないでください。命令フロー構築とテストのみに使用してください。

### フォークされたメインネット状態を使用した Localnet

現実的なテストのために、メインネット状態をローカル バリデーターにフォークします：

```bash
solana-test-validator \
  --url https://api.mainnet-beta.solana.com \
  --clone CPMMoo8L3F4NbTegBCKVNunggL7H1ZpdTHKxQB5qKP1C \
  --clone CAMMCzo5YL8w4VFF8KVHrK22GGUsp5VTaW7grrKgrWqK \
  --clone <SOME_POOL_ID> \
  --clone <SOME_MINT_ID>
```

これにより、特定のプログラム/アカウント状態をローカルホストにクローンし、自由にトランザクションできます。理想的な用途：

- 実際の Raydium プログラムに対して CPI 統合をユニット テストする。
- 修正されたパラメーターでトランザクションを再生してデバッグする。
- 大規模な合成ボリュームでストレス テストする。

Raydium チームは、メインネット デプロイメント前の回帰テストのために、フォークされた localnet を広範に使用しています。

## 環境管理

### 目的別に異なるウォレットを使用

- **開発用ウォレット**：テストネット SOL を保有し、ビルドに使用します。
- **本番用ウォレット**：実際の SOL を保有し、デプロイ・マルチシグ送信にのみ使用します。
- **ボット用ホットウォレット**：少額の残高、限定的な権限。

秘密鍵はハードコードしてはいけません。環境変数またはシークレット管理ツールを使用してください。

### `.env` パターン

```
# .env（コミットしない）
SOLANA_RPC_URL=https://mainnet.helius-rpc.com/?api-key=...
WALLET_PATH=/Users/you/.config/solana/id.json
```

```ts
import { config } from "dotenv";
config();

const connection = new Connection(process.env.SOLANA_RPC_URL!);
```

### バージョンの固定

Solana エコシステムのすべての依存関係をロックしてください。エコシステムは急速に変化しており、`@solana/web3.js` のマイナーバージョン更新でも過去に破壊的な変更が導入されています。`package-lock.json` / `Cargo.lock` を厳密に使用してください。
