LaunchLab を使用すると、クリエイターはトークンを発行し、ボンディングカーブを通じて初期流動性をブートストラップできます。買い手はグラデュエーション前にカーブに対して取引します。ローンチがグラデュエーション閾値に達すると、流動性は Raydium AMM プールに移行し、通常の Raydium ルーティングを通じて取引が続きます。

## LaunchLab の利用者

| ユーザー | 一般的なタスク |
|---|---|
| トレーダー | 初期段階のトークンを発見し、ボンディングカーブで売買し、グラデュエーション進捗を追跡します。 |
| クリエイター | コードなしでトークンをローンチし、カーブパラメータを設定し、オプションでクリエイターフィーを獲得します。 |
| プラットフォーム | 独自のフィー設定、ブランディング、ローンチディスカバリーサーフェスを備えたブランド化されたローンチ環境を構築します。 |

## ローンチの仕組み

1. クリエイターがトークンメタデータ、供給量、カーブ設定、グラデュエーション目標、およびオプションのフィー設定を設定します。
2. トークンはボンディングカーブで開始します。買い手と売り手はそのカーブに対して直接取引します。
3. 買いと売りが発生するにつれて、カーブの価格が変わります。
4. カーブがグラデュエーション目標に達すると、流動性は Raydium プールに移行します。
5. グラデュエーション後、ユーザーは Raydium Swap と Raydium プールを通じてルーティングするアグリゲーターを通じてトークンを取引します。

## 作成モード

| モード | 使用する場合 | 主要設定 |
|---|---|---|
| JustSendit | デフォルト設定で最速のノーコードローンチが必要な場合。 | 名前、ティッカー、画像、オプションのソーシャルリンク、オプションの初回購入。 |
| LaunchLab | 供給量、グラデュエーション目標、カーブ配分、ベスティング、またはクリエイターフィーをより細かく制御する必要がある場合。 | 供給量、調達目標、カーブ配分、ベスティング、マイグレーション後のフィーシェア。 |

JustSendit はデフォルトのグラデュエーション目標を使用します。LaunchLab モードでは、クリエイターは UI とプログラムの制限に従ってグラデュエーション目標を設定できます。

## グラデュエーションと流動性

グラデュエーションはボンディングカーブを閉じ、資産を CPMM プールに移行します。LP 処理と CPMM の記録者は、プラットフォーム設定に依存します。

- 新しく初期化されたすべてのローンチは CPMM に移行します。
- プラットフォームとクリエイターのスケールフィールドは 1 つのプラットフォーム所有のロック LP シェアに結合され、残りのシェアはバーンされます。
- CPMM クリエイターフィーはプラットフォーム Fee Key とは別であり、記録された CPMM プールクリエイターに従います。

## セーフティの基本

- ティッカーまたはロゴだけでなく、トークンミントを確認してください。
- 取引前にグラデュエーション目標とカーブの進捗を確認してください。
- ローンチまたは購入前に、クリエイターとプラットフォームのフィー設定を確認してください。
- プラットフォーム Fee Key NFT をフィー権資産として扱ってください。転送またはバーンされた場合、LP フィー請求権は移動するか失われる可能性があります。
- ウォレットを接続またはトランザクションに署名する前に、[信頼とセーフティ](/ja/getting-started/trust-and-safety)を読んでください。
