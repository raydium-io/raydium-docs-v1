## 2つの作成モード

LaunchLab は [raydium.io/launchlab/create](https://raydium.io/launchlab/create) からアクセスできる2つの作成パスを提供しています。

| | **JustSendit** | **LaunchLab** |
|---|---|---|
| セットアップ時間 | 約1分 | 約5分 |
| トークン供給量 | 固定デフォルト | 完全にカスタマイズ可能 |
| SOL目標 | 85 SOL（固定） | 24 SOL 以上、カスタム設定可 |
| カーブ % | デフォルト | 51～80% |
| ベスティング | なし | オプション |
| 移行後フィー | プラットフォーム定義の CPMM クリエイターフィーと LP ポリシー | プラットフォーム定義の CPMM クリエイターフィーと LP ポリシー |
| 最適な用途 | クイックなコミュニティローンチ | 構造化されたトークンローンチ |

## JustSendit モード

最速のローンチ方法です。最小限の入力で、プラットフォームが適切なデフォルト値を自動設定します。

### 必要なもの

- トランザクション手数料用の SOL が十分にある接続済みウォレット（作成時に約 0.05～0.1 SOL）。
- トークン名とティッカーシンボル。
- UI 要件を満たす画像または GIF。

### ステップ

1. [raydium.io/launchlab/create](https://raydium.io/launchlab/create) にアクセスして **JustSendit** を選択します。
2. トークンの **名前** と **ティッカー** を入力します。
3. 必要に応じて **説明** と **ソーシャルリンク**（ウェブサイト、Twitter/X、Telegram）を追加します。
4. **ロゴ画像または GIF** をアップロードします。
5. 必要に応じて、作成時にトークンを購入するための **初期購入額**（SOL）を入力します。これは最初のオンカーブ価格状態を変更するため、署名前に確認してください。
6. サマリーを確認して **Create** をクリックします。
7. ウォレットでトランザクションを承認します。

トークンはボンディングカーブ上で即座にローンチされます。カーブが 85 SOL を集めると、Raydium AMM プールに移行します。

## LaunchLab モード

供給量、資金調達目標、カーブ配分、ベスティング、フィーパラメータを完全に制御できる作成モードです。

### 必要なもの

- 作成とボルト家賃用に約 0.1～0.5 SOL がある接続済みウォレット。
- 開始前に以下のすべての入力を準備してください（ローンチ後は設定を変更できません）。

### 設定オプション

#### トークン詳細

- **名前、ティッカー、ロゴ** — JustSendit と同じです。
- **説明とソーシャルリンク** — 発見性向上のため推奨します。

#### 供給量とカーブ配分

- **総供給量** — ミントされるトークンの総数（例：1,000,000,000）。
- **カーブ配分（%）** — 公開購入用のボンディングカーブに配置される総供給量の割合（51～80%）。残りは移行後のリクイディティプールにシードされます。

<Warning>
  カーブ配分と総供給量はローンチ時に固定され、**変更できません**。署名前に慎重に選択してください。
</Warning>

#### SOL 資金調達目標

- 最小移行閾値は **24 SOL** です。より高い値を設定できます。
- これはカーブが CPMM プールに移行する前に集める必要がある SOL の量です。
- 目標を高すぎる値に設定すると、需要が不足した場合にカーブが移行しないリスクがあります。

#### ベスティング（オプション）

ベスティングはトークン供給量の一部をロックし、指定されたウォレットに対してスケジュールに従って線形にリリースします。

| フィールド | 説明 |
|---|---|
| ロック総額 | すべての受益者にロックするトークン（総供給量の %、プログラム上限の対象）。 |
| クリフ期間 | 移行後、トークンがアンロックされるまでの待機時間（例：180日）。 |
| アンロック期間 | クリフ後の線形アンロック期間（例：365日）。 |

ロックされたトークンはカーブに入らず、移行後のリクイディティプールの一部ではありません。上記のスケジュールに従って各受益者のウォレットにリリースされます。

**重要なベスティングルール：**
- クリフ期間とアンロック期間はローンチ時に固定され、遡って変更できません。
- 受益者がウォレットキーを失った場合、ロックされたトークンは永久にアクセス不可になります。リカバリーが重要な場合はマルチシグを使用してください。
- 移行前に受益者に割り当てられていない `total_locked_amount` の一部は永久に固定されます。全額を割り当ててください。

オンチェーンメカニクスの詳細は [LaunchLab ベスティング](/ja/products/launchlab/vesting) を参照してください。

#### 移行後フィー共有

トークンが移行する際：
- LP トークンが CPMM プールにミントされます。
- 署名前に現在のプラットフォーム設定を確認してください。2026-08-17 アップグレード前は、`creatorScale` がクリエイター Fee Key を生成していました。その後に実行された移行では、`platformScale + creatorScale` がプラットフォーム所有の Fee Key ポジションになり、`burnScale` がバーンされます。以前の移行から既存のクリエイター Fee Key は変更されません。
- 移行後のクリエイター収益は、記録された CPMM プールクリエイターのままで、選択された設定がそれらを有効にしている場合にのみ、CPMM クリエイターフィーから得られます。

詳細は [クリエイターフィーの仕組み](/ja/user-flows/how-creator-fees-work) を参照してください。

### ステップ

1. 作成ページで **LaunchLab** モードを選択します。
2. トークン詳細（名前、ティッカー、ロゴ、説明、ソーシャル）を入力します。
3. **総供給量** と **カーブ配分パーセンテージ** を設定します。
4. **SOL 資金調達目標**（≥ 24 SOL）を設定します。
5. 必要に応じて **ベスティング** を設定します（受益者ウォレットとスケジュールを設定）。
6. 必要に応じて **移行後フィー共有** を有効にします。
7. 必要に応じて初期購入額を入力します。
8. 完全なサマリーを確認します — カーブ価格範囲、移行条件、LP 分割。
9. **Create** をクリックしてトランザクションを承認します。

## トークンローンチ後

### カーブの進捗を監視する

トークンの LaunchLab ページはリアルタイムの進捗を表示します：
- カーブ売却率（%）。
- 集めた SOL vs. 移行目標。
- 現在の価格と価格チャート。

LaunchLab は移行に失敗したローンチに介入しません。カーブの進捗を監視し、コミュニティと明確にコミュニケーションを取ってください。

### 移行

移行はカーブを閾値を超えるトランザクションによって自動的にトリガーされます — これは任意のユーザーが呼び出せます（呼び出し者は小額の報酬を得ます）。クリエイターとしてのアクションは不要です。

移行後：
- 集めた SOL と残りのカーブトークンを初期リクイディティとして CPMM プールが作成されます。
- 移行後フィーを有効にした場合、**Fee Key NFT** がウォレットにミントされます。
- Portfolio ページから移行前クリエイターフィーを請求します。

### 移行前クリエイターフィーを請求する

プラットフォームがボンディングカーブ段階でクリエイターフィーを有効にしている場合、それらはボルトに蓄積されます。raydium.io の **Portfolio** ページからいつでも請求できます。

## 避けるべき落とし穴

| 落とし穴 | 対応方法 |
|---|---|
| SOL 目標を高すぎる値に設定する | 市場が現実的に達成できる目標を選択してください。 |
| 受益者が確認される前にベスティングを過度に割り当てる | 割り当てられていないベスティング供給量は移行後に永久にアクセス不可になります。 |
| Fee Key NFT を意図せず転送またはバーンする | フィー請求権は永久に失われます。NFT を作成ウォレットまたは制御するウォレットに保管してください。 |
| 初期購入を行わない | 初期購入がないと、スニーピングボットがほぼゼロコストですべての初期トークンをキャプチャする可能性があり、コミュニティの信頼を損なう可能性があります。 |
