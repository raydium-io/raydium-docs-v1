## Burn & Earn とは

Burn & Earn は Raydium の機能で、プール作成者（または任意の LP）がデポジットをオンチェーンで**永続的**にしながら、トレーディング手数料を収集する権利を保持できます。ポジションは償却不可能になりますが、新たにミントされた **Raydium Fee Key** NFT がロックされたポジションから `collectFees` を行う継続的な権利を表します。

一般的なユースケース：

- **ローンチ時の信頼構築。** プロジェクトがデプロイヤーの LP をロックすることでラグプルを行わないことを約束します。ホルダーはオンチェーンでリクイディティが永続的であることを確認できます。
- **手数料生成型コレクティブル。** イールドを生成する譲渡可能な NFT。NFT を売却すれば、手数料ストリームが転送されます。
- **トレジャリーグレード LP。** ブランド / ディスカバリーの目的でリクイディティを永遠に保ちたいプロトコルが、手数料側を収益化しながら実現できます。

## サポートされているプールタイプ

| プログラム | Burn & Earn サポート |
|---|---|
| CPMM | はい |
| CLMM | **フルレンジのみ**（推奨） |
| AMM v4（ハイブリッド） | サポートなし |

CLMM の場合、ロックするのは完全な価格範囲にまたがるポジションのみです。ロック後は再バランスできません。価格が選択した範囲外に移動すると、そのポジションで手数料を獲得することが永久に停止します。タイトレンジの Burn & Earn ポジションはほぼ常に間違いです。

## プログラムレベルでのロック仕組み

1. 元の LP トークン（CPMM）またはポジション NFT（CLMM）が、Burn & Earn プログラムが所有するプログラム所有 PDA に転送されます。
2. **Fee Key NFT** が呼び出し元にミントされます。そのメタデータはロックされたポジションの PDA を指します。
3. Burn & Earn は `collectFees`（またはプールタイプごとの同等の呼び出し）を公開します。これは以下を行います：
   - 署名者が指定されたロックされたポジションの Fee Key NFT を保有していることを確認します。
   - CPI を介して基礎となるプール プログラムの手数料請求命令を呼び出します。
   - 収集された手数料を Fee Key ホルダーの ATA にルーティングします。
4. 対応する `withdraw` はありません。基礎となる LP / ポジションはエスクロー内から決して出ません。

Fee Key は標準的な SPL NFT です。任意の Solana NFT マーケットプレイスで売却でき、ウォレット間で移動でき、NFT を受け入れるレンディング プロトコルで担保として使用でき、別のコントラクトにラップできます。`collectFees` 呼び出し時にそれを保有している者が手数料を受け取ります。

## UI ウォークスルー

1. 通常通り CPMM プール、またはフルレンジ ポジションを持つ CLMM プールを作成します。
2. **Liquidity → Create → Burn & Earn** に移動します。
3. ロックするポジションを選択します。
4. ポジション詳細（NFT アドレス、サイズ、プール）を確認し、UI が表示する確認文を入力します。この操作は取り消し不可能なため、意図的に摩擦が大きくなっています。
5. **Confirm, lock the liquidity permanently** をクリックします。
6. Fee Key NFT がウォレットに到着します。ポートフォリオ ページのロックされたポジションの下に表示されます。

手数料の請求は、任意のポジションから請求するのと同じ方法で行います。ポートフォリオ ページを通じて、または `collectFees` 経由で行います。

## API サーフェス

プール情報エンドポイントは、Burn & Earn を通じてロックされたそのプールのリクイディティのシェアを示す `burnPercent` フィールドを返します：

```http
GET https://api-v3.raydium.io/pools/info/list
  ?poolType=standard
  &poolSortField=default
  &sortType=desc
  &pageSize=1
  &page=1
```

```json
{
  "data": [
    {
      "id": "...",
      "burnPercent": 99.17,
      ...
    }
  ]
}
```

`burnPercent` は信頼シグナリングの便利なサーフェスです。LP が 99% 以上 burn されているトークンは、LP が 0% burn されているトークンよりもはるかにラグプルされにくいです。

## 落とし穴

- **取り消し不可能。** LP 側は決して取得できません。二度と触れたくない金額であることを確認してください。
- **CLMM タイトレンジはトラップです。** フルレンジ CLMM ポジションのみをロックしてください。範囲限定ロック ポジションが価格がバンドを出ると手数料獲得を停止することを本当に理解していない限り。
- **Fee Key NFT を失うことは手数料を永遠に失うことです。** 権利書のように扱ってください。誤って burn しないでください。敵対的なコントラクトにステーキングしないでください。
- **転送手数料を持つ Token-2022 ミント**：Burn & Earn はそれらをサポートしていますが、転送手数料のヘアカットは手数料請求のたびに適用されます。それを予算に入れてください。
- **部分的なロックはありません。** 50% ロックして 50% 移動可能にしたい場合は、まずポジションを 2 つのポジションに分割してから、1 つだけロックしてください。

## LaunchLab は Burn & Earn を内部で使用しています

[LaunchLab](/ja/products/launchlab) から卒業したトークンはロックされた LP に LP-Lock を使用します。2026-08-17 アップグレード前は、`creatorScale` はクリエイター所有の Fee Key を生成しました。その後に実行されたマイグレーションは `platformScale + creatorScale` を 1 つのプラットフォーム Fee Key ポジションに結合し、`burnScale` を burn します。以前に完了したマイグレーションからの Fee Key は変更されません。[`products/launchlab/platforms`](/ja/products/launchlab/platforms) と [`products/launchlab/creator-fees`](/ja/products/launchlab/creator-fees) を参照してください。
