<Info>
  LaunchLabはRaydiumのプライマリマーケットローンチ会場です。プロジェクトはトークン供給をボンディングカーブにデポジットし、買い手はSOL（または別のクォートミント）を使用してカーブに対して取引します。卒業閾値に達すると、カーブの資産は自動的にCPMMプールに移行し、トークンは自由に取引可能になります。このページではプロジェクト側の全フローを説明します。
</Info>

## 必要なもの

- **トークンミント** — 売却したいトークン。以下の条件で新規ミントされている必要があります：
  - 完全な供給量がウォレットにミントされている（カーブにデポジットできるように）。
  - ローンチ前にミント権が取り消されている（そうでないと、新しいミントによってカーブ価格がゲーム化される可能性があります）。
- **メタデータ** — 名前、シンボル、画像、ソーシャルリンク。Metaplexメタデータまたは同等のもの。
- **ウォレット** — 作成レント + ボルトファンディング + プライオリティフィー用に約1 SOL（卒業自体は卒業者が支払い、あなたではありません）。
- **以下の決定**：
  - カーブタイプ（二次 vs 仮想リザーブCPMM）。
  - 卒業閾値。
  - LP処分ポリシー（バーン / ロック / クリエイターへ）。
  - 初期価格とキャップ。

## カーブの選択

LaunchLabは2つのカーブファミリーをサポートしています：

### 二次（`curve_type = 0`）

価格は売却供給量に対して二次的に増加します。古典的な「フェアローンチ」の感覚 — 早期の買い手は価格優位性を得られ、後期の買い手はより多く支払い、価格は滑らかに加速します。

```
price(s) = a * s^2 + b * s + c
```

ここで `s` は売却供給量です。通常 `a > 0`（凸）。初期価格と卒業価格の間のスプレッドは、`a, b, c` とキャップが与えられれば決定論的です。

最適な用途：ノベルティローンチ、ミーム、コミュニティ主導のプロジェクト。

### 仮想リザーブCPMM（`curve_type = 1`）

*仮想*リザーブを使用して定積AMMをエミュレートします — カーブは `x * y = k` のCPMMのように動作しますが、プールは決して引き出されない合成トークンでシードされた状態で開始します。

```
price = virtual_quote_reserve / virtual_base_reserve
```

買い手が購入すると、`virtual_base_reserve` は減少し、`virtual_quote_reserve` は増加します — カーブは卒業後のCPMMと同じに見えます。より滑らかなハンドオフ。

最適な用途：卒業後の価格継続性が予測可能なローンチ。

## UIウォークスルー

[raydium.io/launchpad/create](https://raydium.io/launchpad/create) で：

1. **トークン。** ミントアドレスを貼り付けます。UIはメタデータを取得して表示します。
2. **カーブタイプ。** 二次またはバーチャルCPMMを選択します。UIは各タイプの価格チャートプレビューを表示します。
3. **卒業閾値。** デフォルト：`total_base_supply` のすべてが売却された後、カーブは終了します。代替案：特定の `graduation_quote_amount`（例：85 SOL）で終了します。
4. **クォートミント。** SOL（デフォルト）、USDC、または他のミント。SOLが標準です。
5. **LP処分ポリシー：**
   - **バーン** — LP トークンは卒業時に使用不可能なアドレスに送信されます。クリエイターはリクイディティを引き出せません。ユーザーはプールを永遠に信頼します。
   - **ロック** — LP トークンは `lock_duration` のタイムロックエスクローに送信されます。
   - **クリエイターへ** — LP トークンはクリエイターに送信されます。最も柔軟で、信頼最小化が最も低い。

   最も尊敬されるローンチはバーンを使用します。

6. **レビュー。** UIは以下をまとめます：予想価格範囲、カーブが売り切れた場合の初期調達、卒業CPMM設定。
7. **署名。** 1つのトランザクションでローンチ状態 + ベースボルト + クォートボルトを作成し、`total_base_supply` をウォレットからベースボルトに転送します。

## プログラマティックウォークスルー

カーブ形状、クォートミント、調達目標、LP処分ポリシーは**引数ではなく**、バインドする `GlobalConfig` と、ローンチが実行される `PlatformConfig` から来ます。渡すのはミントのアイデンティティ、バインドするコンフィグ、およびオプションで最初の買いです：

```ts
import {
  Raydium,
  TxVersion,
  LAUNCHPAD_PROGRAM,
  LaunchpadConfig,
  getPdaLaunchpadConfigId,
} from "@raydium-io/raydium-sdk-v2";
import { Keypair, PublicKey } from "@solana/web3.js";
import { NATIVE_MINT } from "@solana/spl-token";
import BN from "bn.js";

const raydium = await Raydium.load({ connection, owner, cluster: "mainnet" });
const programId = LAUNCHPAD_PROGRAM;

// ベースミントのキーペアを生成し、それで署名します。
const pair  = Keypair.generate();
const mintA = pair.publicKey;

// コンフィグをバインドします：（クォートミント、curve_type、インデックス）。これはカーブ
// 形状、クォートミント、調達目標を固定します。
const configId   = getPdaLaunchpadConfigId(programId, NATIVE_MINT, 0, 0).publicKey;
const configData = await raydium.connection.getAccountInfo(configId);
const configInfo = LaunchpadConfig.decode(configData!.data);
const mintBInfo  = await raydium.token.getTokenInfo(configInfo.mintB);

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId,
  mintA,
  decimals: 6,
  name:   "My New Token",
  symbol: "MYNEW",                    // 10文字以下
  uri:    "https://example.com/metadata.json",
  migrateType: "amm",                 // "amm" | "cpmm"

  configId,
  configInfo,
  mintBDecimals: mintBInfo.decimals,
  mintBProgram:  new PublicKey(mintBInfo.programId),

  createOnly: true,                   // true = 最初の買いなしでミントを作成
  buyAmount:  new BN(1000),
  slippage:   new BN(100),            // 100 = 1%

  extraSigners: [pair],               // ベースミントキーペアが署名する必要があります
  txVersion: TxVersion.V0,
  computeBudgetConfig: { units: 400_000, microLamports: 50_000 },
});

// createLaunchpadは複数のトランザクションを返します - 順番に実行してください。
const { txIds } = await execute({ sequentially: true });
console.log("Pool ID:", extInfo.address.poolId.toBase58());
console.log("Base mint:", mintA.toBase58());
```

`raydium.api.fetchLaunchConfigs()` は利用可能なコンフィグをデフォルト供給量、売却量、調達目標とともにリストアップするため、ユーザーが署名する前に特定のコンフィグが何を意味するかを表示できます。Token-2022バリアントを含む完全な注釈付きバージョン：[`products/launchlab/code-demos`](/ja/products/launchlab/code-demos#create-a-launch)。

## 卒業前の監視

APIを通じてアクティビティを追跡します：

LaunchLabは `api-v3.raydium.io` とは別の独自のAPIホストを持っています：

```ts
// ミントレベルの情報、ベースミントでキー化（バッチの場合はカンマ区切り）。
const r = await fetch(
  `https://launch-mint-v1.raydium.io/get/by/mints?ids=${mintA.toBase58()}`,
).then((r) => r.json());
console.log(r.data.rows[0]);

// また利用可能：同じホストの /main/configs（コンフィグリスト）、および
// https://launch-history-v1.raydium.io/kline と /trade（価格とフィル）。
```

またはオンチェーン状態を直接読み取ります。プールIDは `(programId, mintA, mintB)` のPDAです：

```ts
import { getPdaLaunchpadPoolId, Curve } from "@raydium-io/raydium-sdk-v2";

const poolId = getPdaLaunchpadPoolId(programId, mintA, NATIVE_MINT).publicKey;
const poolInfo = await raydium.launchpad.getRpcPoolInfo({ poolId });

console.log({
  status:      poolInfo.status,
  baseSold:    poolInfo.realA.toString(),
  totalSellA:  poolInfo.totalSellA.toString(),
  quoteRaised: poolInfo.realB.toString(),
  raiseTarget: poolInfo.totalFundRaisingB.toString(),
});
```

進捗は調達の割合ではなく**価格**の観点で表現するのが最適です。カーブは非線形だからです。デモリポジトリの [`getFinishRate.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/getFinishRate.ts) は `Curve.getPrice`、`Curve.getPoolEndPriceReal`、`Curve.getPoolInitPriceByPool` で実行します：

```
finishRate = (currentPrice − initPrice) / (endPrice − initPrice)   // 1にクランプ
```

### 監視するメトリクス

- **売却率**：売却されたベースの割合。卒業閾値は通常80～100%売却時です。
- **現在価格**：現在の `baseSold` でのカーブから導出。
- **ユニークな買い手**：インデクサーを通じた異なる支払い者の数。
- **買い対売り比率**：初期ローンチは重い買い圧力を見て、その後減速します。

24時間後に売却率が `<10%` の場合、マーケティングが適切かどうかを検討してください。LaunchLabは過度に宣伝されていないローンチを救済しません。

## 卒業

卒業は別のトランザクションであり、**誰でも呼び出せるわけではありません**：`MigrateToCpswap` と従来の `MigrateToAmm` は、それぞれの署名者がバインディング `GlobalConfig`（`migrate_to_cpswap_wallet` / `migrate_to_amm_wallet`）に記録されたウォレットと一致する必要があり、他の署名者は `InvalidOwner` を取得します。報奨金はありません。これらのウォレットはRaydiumの卒業クランクによって実行され、閾値を超えた数秒以内にマイグレーションを実行します。初期設定以外にクリエイターとしてのアクションは不要です。

### 卒業が行うこと

1. ボルト残高を読み取ります。
2. カーブを閉じます（カーブに対する買い/売りはできなくなります）。
3. ボルト残高を初期リクイディティとして新しいCPMMプールを作成します。
4. ボルト残高に基づいて初期LPトークンをミントします。
5. 設定されたポリシー（バーン / ロック / クリエイターへ）に従ってLPトークンを処分します。

卒業後、CPMMプールはライブで、通常のRaydiumルーティングを通じて取引されます。

### 卒業の監視

プール状態の `status` を監視し、変更時にUIを切り替えます：

```ts
const before = (await raydium.launchpad.getRpcPoolInfo({ poolId })).status;

setInterval(async () => {
  const p = await raydium.launchpad.getRpcPoolInfo({ poolId });
  if (p.status !== before) console.log("migrated - switch to the CPMM pool page");
}, 10_000);
```

卒業したプールのアドレスは `(cpswap config, token0, token1)` のCPMM PDAなので、報告されるのを待つのではなく導出できます。インデクサーの場合、ポーリングの代わりにgRPCで購読してください — [`products/launchlab/code-demos`](/ja/products/launchlab/code-demos#watch-configs-and-pools-over-grpc) を参照してください。

クリエイターまたは第三者による「手動卒業」パスはありません。ローンチが閾値を超えており、マイグレーションされていない場合、それはクライアントから強制できるものではなく、マイグレーションウォレットの運用上の問題です。

## 卒業後

### CPMMプールを検証する

```ts
const pool = await raydium.cpmm.getPoolInfoFromRpc({ poolId: cpmmPoolId });
console.log("CPMM price:", pool.poolInfo.price);
console.log("CPMM TVL:  ", pool.poolInfo.tvl);
```

CPMMプールは（概ね）以下を持つべきです：

- ベーストークン残高：`total_base_supply - baseSold` + カーブ残余。
- クォートトークン残高：`quoteRaised - graduationFee`。
- 価格：最後のカーブ価格と一致。

### LP処分を検証する

- **バーン**：LPミントの供給量は1nc1nerator11111111111111111111111111111111 または同等に送信されたことを示します。
- **ロック**：エスクロー PDA のLPトークンとロック解除タイムスタンプ。
- **クリエイターへ**：クリエイターのウォレット内のLPトークン。

### クリエイターフィーを回収する

クリエイターフィーシェアを設定した場合、定期的に呼び出します：

ビルダーは `claimCreatorFee` で、**クォートミント**ではなくローンチでキー化されます — 1回の呼び出しでそのミントで発生したクリエイターフィーをすべて回収します：

```ts
import { NATIVE_MINT } from "@solana/spl-token";

await raydium.launchpad.claimCreatorFee({
  programId,
  mintB: NATIVE_MINT,      // クレームするクォートミント
  txVersion: TxVersion.V0,
});
```

`claimMultipleCreatorFee` を使用してミント間でバッチ処理します。フィーはカーブ取引から卒業前に発生し、卒業後はプラットフォームの `platform_cp_creator` があなたを記録されたプールクリエイターとして残す場合、CPMMプールのクリエイターフィーパスから発生します — [`products/launchlab/platform-config`](/ja/products/launchlab/platform-config) を参照してください。

## 落とし穴

### 1. ミント権が取り消されていない

`baseMint.mintAuthority` がまだあなたが制御するキーの場合、新しい供給量をミントして独自のカーブに売却できます。取り消していないローンチは、アグリゲーターとリスティングサイトによって一般的に高リスクまたは未検証としてフラグが立てられます。ローンチ前に取り消してください。

### 2. 間違ったカーブパラメータ

`a` が高すぎる二次カーブは、初期トークンを無料（価格 ≈ 0）にし、後期トークンを不合理にします。`a` が低すぎるカーブは、カーブをほぼ線形にします（「ボンディング」の感覚を失う）。devnetで最初にパラメータをテストしてください。

### 3. 卒業閾値が高すぎる

卒業に現実的な需要より多くの資本が必要な場合、カーブは決して卒業せず、買い手はカーブにのみ売却できるトークンで立ち往生します（より悪い価格で）。実際に達成できる閾値を選択してください。

### 4. クォートミント詐欺

クォートミントがカスタムトークン（SOL/USDC以外）の場合、ユーザーはそれを信頼しません。クォートにはSOLまたはUSDCを使用してください。

### 5. ベースボルトへの資金提供を忘れた

SDKは作成時にウォレットから `totalBaseSupply` を転送します。ウォレットにそれがない場合、トランザクションは戻ります。署名する前に残高を確認してください。

### 6. LP処分 = バーンは取り消し不可

LPが1nc1nerator に送信されると、あなたを含む誰もリクイディティを引き出せません。これがポイントです — 信頼最小化。確実でない場合はバーンを選択しないでください。

### 7. 卒業後のCPMMフィーティア

卒業したプールはLaunchLabのデフォルトCPMMコンフィグ（0.25%）を使用します。1%または0.01%が必要な場合、卒業後に自分で2番目のCPMMプールを作成してリクイディティを移行する必要があります — 面倒で、フラグメント化します。デフォルトを受け入れるか、LaunchLabの代わりに直接CPMM作成でローンチしてください。
