<Info>
  LaunchLab プラットフォームは、ローンチサーフェスまたはコミュニティによって使用されるオンチェーン設定です。プラットフォーム設定は、手数料、ブランディング、クリエイター手数料サポート、マイグレーション後のプール動作に影響を与える可能性があります。
</Info>

LaunchLab は Platform PDA を通じてサードパーティ製ローンチ環境をサポートしています。プラットフォームは LaunchLab プログラムインフラストラクチャと Raydium プールマイグレーションを使用しながら、独自のブランド化されたトークンローンチ体験を提供できます。

## プラットフォームが制御できる項目

| 設定 | 重要な理由 |
|---|---|
| クリエイター手数料 | ボンディングカーブのクリエイター手数料を設定し、CPMM クリエイター・オブ・レコードを選択できます。 |
| プラットフォーム手数料 | プラットフォームレベルの手数料収益の送信先を設定します。 |
| ブランディングメタデータ | プラットフォームに名前、説明、ロゴを付与し、アプリサーフェスに表示できます。 |
| ローンチグループ化 | UI が同じプラットフォーム下でローンチされたトークンを表示できるようにします。 |
| マイグレーション後のプール設定 | プラットフォームがローンチを CPMM にマイグレーションする際の CPMM 手数料設定を定義できます。 |
| LP 分配 | バーン対象シェアとプラットフォーム所有のロック済み LP シェアを設定します。保持されたクリエイタースケールはプラットフォームシェアに統合されます。 |
| グローバル設定ホワイトリスト | ローンチをプラットフォーム管理者によって明示的に許可された `GlobalConfig` アカウントに制限できます。 |

## クリエイターが確認すべき項目

任意のプラットフォーム下でローンチする前に、以下を確認してください：

- プラットフォーム手数料を受け取るウォレット。
- クリエイター手数料が有効になっているかどうか。
- グラデュエーション後にプラットフォームが使用する CPMM 手数料設定とクリエイター・オブ・レコード。
- グラデュエーション後の LP トークンの分割方法。
- プラットフォーム Fee Key NFT がミントされるかどうか。
- プラットフォームが独自の利用規約、ポリシー、または適格性ルールを持っているかどうか。

<Warning>
  プラットフォーム設定はクリエイターの経済性とユーザーの期待に大きな影響を与える可能性があります。ローンチトランザクションに署名する前に確認してください。このページは仕組みのみを説明しており、法的、財務的、または投資アドバイスではありません。
</Warning>

## トレーダーが確認すべき項目

LaunchLab トークンを購入する場合、プラットフォームは手数料パスとマイグレーション後のリクイディティ処理に影響を与える可能性があります。トレードする前に：

- トークンのプラットフォームとローンチ設定を確認してください。
- UI に表示されている場合は CPMM 手数料ティアを確認してください。
- LP がバーン、ロック、または割り当てられているかどうかを確認してください。
- ソーシャルメディアのテキストだけでなく、トークンページからトークンミントを確認してください。
