## 前提条件

以下を 1 回実行してください：

```bash icon="terminal"
mkdir raydium-quickstart && cd raydium-quickstart
npm init -y
npm install @raydium-io/raydium-sdk-v2 @solana/web3.js @solana/spl-token bn.js
```

必要なもの：

- **Node 18 以上** ESM サポート付き（`package.json` に `"type": "module"` または `.mjs` 拡張子）。
- **Solana キーペア** `~/.config/solana/id.json` に配置（または任意の場所 — `KEYPAIR` を設定）。キーペア生成については [`solana-fundamentals/toolchain`](/ja/solana-fundamentals/toolchain#solana-cli) を参照してください。
- **資金が入ったウォレット。** スワップスクリプトは入力額と小額のクッション — CPMM スワップはネットワーク手数料で約 0.0015 SOL かかります（[`reference/fee-comparison`](/ja/reference/fee-comparison#network-fees-per-typical-operation) を参照）、スワップがトークンアカウントを開く必要がある場合は 1 回限りのレント。プール作成はより多くかかります：CPMM スクリプトだけで、シード流動性またはレント前に約 0.15 SOL の 1 回限りのプール作成手数料がかかります。ウォレットに資金を入れる前に、各スクリプトの Setup セクションで現在の数字を確認してください。
- **RPC URL。** テスト用は無料の公開 RPC で問題ありませんが、スモークテスト以上の場合は有料プロバイダーを使用してください。

シェルごとに 1 回設定してください：

```bash icon="terminal"
export RPC_URL="https://api.mainnet-beta.solana.com"
export KEYPAIR="$HOME/.config/solana/id.json"
```

<Info>
  **クラスター。** 3 つのスクリプトすべてはデフォルトでメインネットです。Devnet には `RPC_URL=https://api.devnet.solana.com` と、スクリプト内の `cluster: "devnet"` が必要です — 2 つのプール作成スクリプトの場合、これが唯一の変更ではありません。各スクリプトの Setup セクションで他に何を変更する必要があるかを確認してください。Devnet のプールシード流動性は限定的です。テストトークンを自分でミントすることを想定してください。
</Info>

## このチャプターの後

各スクリプトはオンチェーン結果 — スワップクォートとトランザクションリンク、新しいプールアドレス、または新しいポジションとその NFT — と、実行した操作の [SDK & API](/ja/sdk-api) チャプターの次のページを指す 1 行を出力します。独自の統合を書く準備ができたら：

- **バックエンドとボット** → [Trade API](/ja/sdk-api/trade-api)。
- **フロントエンドとフルコントロールアプリ** → [TypeScript SDK](/ja/sdk-api/typescript-sdk)。
- **オンチェーン構成** → [Rust CPI](/ja/sdk-api/rust-cpi)。
- **それらの中から選択** → [SDK & API](/ja/sdk-api) の上部の比較表。
