## 利用可能なもの

| サーフェス | URLパターン | 使用場面 |
|---|---|---|
| **MCPサーバー** | `https://docs.raydium.io/mcp` | AIエディター（Claude Code、Cursor、Windsurfなど）がRaydiumドキュメントをネイティブにクエリして引用したい場合。 |
| **`llms.txt`インデックス** | `https://docs.raydium.io/llms.txt` | RAGパイプラインを構築していて、すべてのページのフラットインデックスが必要な場合。 |
| **`llms-full.txt`本体** | `https://docs.raydium.io/llms-full.txt` | オフラインインデックス作成用に、完全なコーパスを単一の連結ファイルとして必要な場合。 |
| **ページごとのコピーメニュー** | すべてのボディページの上部にある「ページをコピー」ボタン | 1ページをLLMとのチャットに貼り付けたい場合。 |
| **ページごとのディープリンク** | `Markdownとして表示`、`ChatGPTで開く`、`Claudeで開く`、`Cursorで開く`、`VS Codeで開く` | ドキュメントページから選択したツールへのワンクリックハンドオフ。 |

「ページをコピー」ボタンとディープリンクメニューは、すべてのページの右上（ページタイトルの横）に配置されています。どちらもドキュメントプラットフォームのコンテキストメニューによって提供されます。

## MCPサーバー

MCP（Model Context Protocol）サーバーを使用すると、AIクライアントはRaydiumドキュメントをツールとしてクエリできます。設定後、エージェントは「Raydiumドキュメントで`addLiquidity`パラメータを検索」と尋ねることができ、引用された権威ある回答を取得できます。

### Claude Code

```bash
claude mcp add --transport http raydium-docs https://docs.raydium.io/mcp
```

追加後、Claude Codeに「RaydiumドキュメントでXを検索」と指示すると、ツールが使用されます。

### Cursor

Cursorの設定に追加します（`Cmd/Ctrl + ,` → MCP）：

```json
{
  "mcpServers": {
    "raydium-docs": {
      "url": "https://docs.raydium.io/mcp"
    }
  }
}
```

### Windsurf、Continue、汎用クライアント

MCP互換のクライアントは`https://docs.raydium.io/mcp`を指すことができます。クライアントがマニフェストを必要とする場合、`https://docs.raydium.io/mcp/.well-known/mcp.json`にあります。

### サーバーが公開するもの

Raydiumドキュメント MCPサーバーは、1つの主要なツール`search_docs(query: string)`を公開します。これはクエリの最高ランクの段落とその正規URLを返します。エージェントは使用したURLを引用する責任があります。エージェントごとの追跡またはレート制限は行いません。

## RAG用の`llms.txt`

`llms.txt`は「機械可読ドキュメントインデックス」の新興標準です。Raydiumは以下を公開しています：

- `https://docs.raydium.io/llms.txt` — タイトルと1行の概要を含むすべてのページのフラットリスト（章ごとに整理）。
- `https://docs.raydium.io/llms-full.txt` — すべてのページの完全なMarkdown本体を連結したもの（ページ境界は見出しとして保持）。

`full`バリアントはドキュメントのデプロイのたびに再生成されます。スケジュール（毎日で十分）で取得するか、オンデマンドで取得します。

```bash
# 完全なコーパスをRAG取り込みパイプラインにドロップします。
curl -sSL https://docs.raydium.io/llms-full.txt -o raydium-docs.md
```

## ページごとのハンドオフメニュー

すべてのボディページには、タイトルの横（右上）にコンテキストメニューがあり、以下のワンクリックアクションが含まれています：

- **コピー** — ページをプレーンMarkdownとしてコピー。
- **Markdownとして表示** — ソース`.md`を新しいタブで開いて保存できるようにします。
- **ChatGPT / Claude / Perplexityで開く** — 指定されたツールのチャットプロンプトにページコンテンツを事前ロード。
- **Cursor / VS Codeで開く** — 指定されたエディターでページコンテンツを含むバッファを開く。

MCPを設定せずに、単一ページについてモデルに質問したい場合に適切なサーフェスです。

## コーディングエージェント用の事前構築されたコンテキストファイル

Raydiumと統合していて、エージェントが最初から正しいベースラインナレッジを持つようにしたい場合、これらのファイルをプロジェクトにドロップします：

### `.cursorrules` / `.windsurfrules` / エージェントシステムプロンプト

```text
You are integrating with Raydium, a Solana DeFi protocol with five product
surfaces: AMM v4, CPMM, CLMM, Farm, and LaunchLab. Authoritative docs live
at docs.raydium.io. The official SDK is `@raydium-io/raydium-sdk-v2` (pin
the version you've verified against). For server-built swaps, prefer the
Trade API at transaction-v1.raydium.io. Always:

- Pass a `Connection` and `cluster` that match.
- Keep all amounts as `BN` instances; never call `.toNumber()` on amounts.
- Pre-fund the user's wallet for ATA creation rent.
- Pass an explicit `computeBudgetConfig` for any tx that may compete in
  high-volume windows.
- Re-fetch `poolInfo` immediately before high-value transactions; cached
  state goes stale.

When uncertain about an instruction's accounts list, defer to
`docs.raydium.io/products/<product>/accounts` and the on-chain IDL.
```

`.cursorrules`（Cursor）、`.windsurfrules`（Windsurf）、または`CLAUDE.md`（Claude Code）として保存するか、エージェントのシステムプロンプトに貼り付けます。正確なファイル名と場所はツールのバージョンによって異なるため、ファイルが自動的に取得されない場合はツールの設定ドキュメントを確認してください。

### ピン留めされたコンテキストリスト

「常に含める」ページのリストを受け入れるコーディングエージェントの場合、このリストはほとんどのRaydium統合に対する最小限の有用なコンテキストです：

```text
https://docs.raydium.io/sdk-api/typescript-sdk
https://docs.raydium.io/sdk-api/trade-api
https://docs.raydium.io/products/cpmm/instructions
https://docs.raydium.io/products/clmm/instructions
https://docs.raydium.io/integration-guides/priority-fee-tuning
https://docs.raydium.io/reference/program-addresses
https://docs.raydium.io/reference/error-codes
```

統合しているプロダクトに基づいて調整します。

## インデックス作成レシピ

独自のRAGを構築していて`llms-full.txt`を使用したくない場合、以下が正規レシピです：

```ts
import { fetch } from "undici";

const INDEX_URL = "https://docs.raydium.io/llms.txt";
const BASE      = "https://docs.raydium.io";

const index    = await (await fetch(INDEX_URL)).text();
const pageUrls = [...index.matchAll(/^- \[(.+?)\]\((.+?)\)/gm)].map(m => m[2]);

for (const path of pageUrls) {
  const md = await (await fetch(`${BASE}${path}.md`)).text();
  // ingest md into your vector store, keyed by path
}
```

すべてのページは正規パスで`.md`サフィックスが追加されて提供されます（例：`/sdk-api/typescript-sdk` → `/sdk-api/typescript-sdk.md`）。

## 注意事項

- **プライベート状態をプロンプトに貼り付けないでください。** MCPサーバーは公開ドキュメントに含まれているもののみを認識します。ウォレットキー、RPC認証情報、および同様のシークレットはエージェントコンテキストに入力されるべきではありません。
- **AI出力は権威的ではありません。** モデルはプログラムアドレス、命令名、アカウントリストを懸念すべき容易さで幻覚します。エージェント生成トランザクションを信頼する前に、常にドキュメントとIDLに対して検証してください。
- **バージョンドリフト。** SDK v2はプレ1.0です。古いリリースで訓練されたエージェントは、ピン留めされたバージョンに対してコンパイルされないコードを発行する可能性があります。ピン留めされたSDKバージョンをエージェントのシステムプロンプトに含めます。
