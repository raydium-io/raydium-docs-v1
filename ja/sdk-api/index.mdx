## このセクションの対象者

Raydium をオフチェーン（TS/JS、Python、バックエンド）から、または別の Solana プログラム（Rust CPI）から統合する開発者向けです。また、AI エージェントやコーディングツール統合者向けでもあります。詳細は [AI 統合](/ja/sdk-api/ai-integration) を参照してください。

<Info>
  **まず何か実行したいですか？** スワップ、CPMM プール デプロイ、CLMM プール デプロイの 3 つのエンドツーエンド スクリプトは [クイックスタート](/ja/quick-start) にあります。スワップと CPMM スクリプトは単一ファイルで、コピーして実行できます。CLMM フローはいくつかの追加ステップが必要です。まず実際のトランザクションを実行してから、ここに戻ってきて完全なリファレンスを確認してください。
</Info>

## 統合パスを選択する

5 つのパスから選択できます。最適なパスは、Raydium を呼び出すものと必要な制御レベルによって異なります。

| パス | 最適な用途 | レイテンシ | カスタムロジック | 言語 |
|---|---|---|---|---|
| [Trade API](/ja/sdk-api/trade-api) | バックエンド、ボット、Blink — サーバー構築 tx が必要な場所 | 最低 | 限定的（プリセットルート） | 任意 |
| [TypeScript SDK](/ja/sdk-api/typescript-sdk) | フルビルダーアクセスが必要な Node/TS アプリとフロントエンド | 中程度 | 完全 | TS / JS |
| [Python 統合](/ja/sdk-api/python-integration) | Python バックエンドと ML パイプライン | 中程度 | 完全（手動命令構築） | Python |
| [Rust CPI](/ja/sdk-api/rust-cpi) | Raydium をオンチェーンから呼び出すプログラムの構成 | N/A（オンチェーン） | 完全 + 構成可能 | Rust |
| [Anchor IDL](/ja/sdk-api/anchor-idl) | ファーストパーティサポートのない言語向けのコード生成（Go、Kotlin、Swift など） | 可変 | 完全 | Anchor コード生成ツール対応の任意の言語 |

確実でない場合：バックエンドとボット → **Trade API**；フロントエンドと完全制御アプリ → **TypeScript SDK**；オンチェーン構成 → **Rust CPI**。

## バージョン規律

このセクションのすべてのページのすべてのコードサンプルの上部にはバナーがあります：

```
SDK:       @raydium-io/raydium-sdk-v2 vX.Y.Z
Program:   see /reference/program-addresses
Cluster:   mainnet-beta
Verified:  YYYY-MM-DD
```

コードサンプルに変更を加える場合は、バナーを更新してください。
