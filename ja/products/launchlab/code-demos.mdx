## セットアップ

ここのデモは [`raydium-sdk-V2-demo/src/launchpad`](https://github.com/raydium-io/raydium-sdk-V2-demo/tree/master/src/launchpad) のファイルを反映しています。ブートストラップはデモリポジトリの [`config.ts.template`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/config.ts.template) に従います：

```ts
import { Connection, Keypair, clusterApiUrl, PublicKey } from "@solana/web3.js";
import { Raydium, TxVersion } from "@raydium-io/raydium-sdk-v2";
import BN from "bn.js";
import fs from "node:fs";

const connection = new Connection(process.env.RPC_URL ?? clusterApiUrl("mainnet-beta"));
const owner = Keypair.fromSecretKey(
  new Uint8Array(JSON.parse(fs.readFileSync(process.env.KEYPAIR!, "utf8"))),
);
const raydium = await Raydium.load({
  owner,
  connection,
  cluster: "mainnet",
  disableFeatureCheck: true,
  blockhashCommitment: "finalized",
});
export const txVersion = TxVersion.V0;
```

## ローンチを作成する

ソース：[`src/launchpad/createMint.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createMint.ts)（および API 駆動の Bonk バリアント用の [`createBonkMintApi.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/launchpad/createBonkMintApi.ts)）

```ts
import { NATIVE_MINT } from "@solana/spl-token";

const { execute, extInfo } = await raydium.launchpad.createLaunchpad({
  programId: /* reference/program-addresses の LaunchLab プログラム ID */,
  // 新しいベースミントのトークンメタデータ：
  name:   "Example Token",
  symbol: "EXMPL",
  uri:    "https://example.com/metadata.json",
  decimals: 6,

  // カーブパラメータ：
  curveType: 0,                                      // 0 = 二次
  supply:    new BN(1_000_000_000).mul(new BN(10).pow(new BN(6))), // 1B ベース（6 dec）
  graduationFractionBps: 8000,                       // 80% → グラデュエーション
  initialK:  new BN("40"),                           // カーブ形状パラメータ

  // クォート側：
  quoteMint: NATIVE_MINT,                            // WSOL
  openTime:  new BN(Math.floor(Date.now() / 1000) + 60),  // 1分後にオープン

  // フィーポリシー：
  fees: {
    buyNumerator:   new BN(100),                     // 1.00%
    buyDenominator: new BN(10_000),
    sellNumerator:  new BN(100),
    sellDenominator: new BN(10_000),
    lpShare:         new BN(60),
    creatorShare:    new BN(20),
    protocolShare:   new BN(20),
    totalShare:      new BN(100),
  },

  postGraduationLpPolicy: "burn",                    // "burn" | "lock" | "toCreator"

  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Launch:", extInfo.launchState.toBase58());
console.log("Base mint:", extInfo.baseMint.toBase58());
console.log("Create tx:", txId);
```

注記：

- `initialK` は二次カーブのスケール係数です。グラデュエーション時の特定のオープニング CPMM 価格をターゲットにするようにチューニングしてください。導出については [`products/launchlab/bonding-curve`](/ja/products/launchlab/bonding-curve) を参照してください。
- SDK は単一トランザクションでベースミント、メタデータ PDA、および両方のボールトを作成します。メタデータ URI が長い場合は 1232 バイトを超える可能性があります。その場合、SDK は 2 つのトランザクションに分割します。
- `Initialize` 後、ローンチは `openTime` までは取引できません。フロントランナーに最初の買いを掴む機会を減らすために、`openTime` を 1～2 分先に設定してください。

## ローンチ状態を取得する

```ts
const launchId = new PublicKey("<LAUNCH_STATE>");

const launch = await raydium.launchpad.getLaunchById({ launchId });
console.log("Status:", ["Active","Graduated","Cancelled"][launch.status]);
console.log("Base sold:", launch.baseSold.toString(),
            "/", launch.baseSupplyMax.toString());
console.log("Quote collected:", launch.quoteReserveReal.toString(),
            "target:", launch.quoteReserveTarget.toString());
if (launch.status === 1) {
  console.log("Post-graduation CPMM pool:", launch.cpmmPoolState.toBase58());
}
```

`getLaunchById` はデコードされた `LaunchState` と、計算された「グラデュエーションへの進捗」分数を `Decimal` として返します。

## 買い — 正確なクォート入力

```ts
const quoteIn        = new BN(1).mul(new BN(10).pow(new BN(9)));  // 1 SOL
const minimumBaseOut = new BN(0);  // 任意を受け入れる；本番環境ではタイトにする

// UI が期待されるベース出力を表示できるようにオフチェーンでクォートをプレビューします：
const preview = raydium.launchpad.computeBuyBase({
  launchState: launch,
  quoteIn,
});
console.log("Expected base_out:", preview.baseOut.toString(),
            "price impact:", preview.priceImpact.toString());

const { execute } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn,
  minimumBaseOut,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Buy tx:", txId);
```

`computeBuyBase` はオンチェーン Newton ソルバー（二次カーブ）またはクローズドフォーム CPMM 逆関数（curve_type 1）をミラーリングします。「受け取る」UI フィールドを入力するために使用してください。

## 買い — 正確なベース出力

```ts
const baseOut         = new BN(1_000_000).mul(new BN(10).pow(new BN(6)));  // 1M ベース
const maximumQuoteIn  = new BN(2).mul(new BN(10).pow(new BN(9)));          // 2 SOL でキャップ

const { execute } = await raydium.launchpad.buyExactOut({
  launchInfo: launch,
  baseOut,
  maximumQuoteIn,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

「正確に X トークンを買う」UI に便利です。カーブが十分に移動して、クォート要件が `maximumQuoteIn` を超える場合は `ExceededSlippage` で拒否されます。

## しきい値交差買いでの自動グラデュエーション

SDK は、買い後の状態がしきい値を超えることを検出したときに、`buy*` トランザクション内に `Graduate` 命令をチェーンします：

```ts
const { execute, willGraduate } = await raydium.launchpad.buyExactIn({
  launchInfo: launch,
  quoteIn: new BN(100).mul(new BN(10).pow(new BN(9))),    // 大きな買い
  minimumBaseOut: new BN(0),
  txVersion: TxVersion.V0,
  autoGraduate: true,                                      // デフォルト
});

if (willGraduate) {
  console.log("This buy will trigger graduation.");
}

const { txId } = await execute({ sendAndConfirm: true });
```

`Graduate` はパーミッションレスなので、誰でも（MEV ボットを含む）しきい値交差後の最初の `Graduate` をランディングするために競争できます。通常は数分ではなく数秒後です。最初のランダーは CPMM プールアカウントのレントを支払うだけです。他の利益はありません。

## 手動 `Graduate`

`autoGraduate` がオフだったか、しきい値交差トランザクションが失敗した場合、グラデュエーションを個別に実行できます：

```ts
const { execute } = await raydium.launchpad.graduate({
  launchInfo: launch,
  txVersion: TxVersion.V0,
});

await execute({ sendAndConfirm: true });
```

送信時に `quote_reserve_real < quote_reserve_target` の場合、`NotAtThreshold` で戻ります。再試行安全です。成功後の 2 番目の `Graduate` 試行は `NotActive` で戻ります。

## ローンチをそのライフサイクル全体で追跡する

まとめると、監視スクリプトは次のようになります：

```ts
async function watch(launchId: PublicKey) {
  while (true) {
    const launch = await raydium.launchpad.getLaunchById({ launchId });
    const progress =
      Number(launch.quoteReserveReal) /
      Number(launch.quoteReserveTarget);

    console.log(
      `status=${["Active","Graduated","Cancelled"][launch.status]}`,
      `progress=${(progress * 100).toFixed(2)}%`,
      `num_buys=${launch.stateData.numBuys}`,
    );

    if (launch.status === 1) {
      console.log("Graduated to CPMM pool:", launch.cpmmPoolState.toBase58());
      break;
    }
    await new Promise(r => setTimeout(r, 10_000));
  }
}
```

## gRPC 経由でコンフィグとプールを監視する

ソース：[`src/grpc/launchpadPoolInfo.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/launchpadPoolInfo.ts)

Yellowstone gRPC 経由で LaunchLab プログラムをサブスクライブし、各ミントのトークンプログラムで `GlobalConfig` と `PoolState` の更新をログします。1 つの `accounts` サブスクリプション上の 2 つの `datasize` フィルタが 2 つのアカウントタイプを分離するため、単一ストリームが両方をカバーします。

デモは、[Token-2022 クォートミントリリース](/ja/reference/changelog/2026-08-24-launchlab-token2022-quote-mint)が必要にするローンチのミントを分類するための最短の正しいリファレンスです：

- **プール**は `PoolState.token_program_flag` から直接分類され、ミント取得なしでベースミント用のビット 0 とクォートミント用のビット 1 をデコードします。バイト全体を `0` に対してテストすることは、クォートミントが Token-2022 の場合、レガシーベースミントを Token-2022 として誤読します。
- **コンフィグ**はそのように分類できません：`GlobalConfig` はそのクォートミントのアドレスを格納し、プログラムフラグはないため、デモはミントアカウントの所有者を 1 回読み取り、ミントごとにキャッシュします。

また、2 つを相互にクロスチェックします。これは、独自のインデクサーに保つのに便利なアサーションです。`create` と `update` は、デモ独自のキャッシュから推測されることに注意してください。スタートアップ時に `getProgramAccounts` からシードされます。そのシードが無効になった場合、「作成」を「このストリームで最初に見た」と読んでください。

gRPC アクセスはパブリック RPC サーフェスの一部ではありません。デモリポジトリの [`src/grpc/README.md`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/grpc/README.md) を参照してください。

## Rust CPI

独自の Anchor プログラムから LaunchLab を呼び出すことはまれです（ほとんどのローンチ統合は TS 側のみです）。その場合、プログラムは `cpi::accounts::Buy`、`cpi::accounts::Sell` などを備えた Anchor クレート `raydium_launchlab` を出荷します。パターンは CPMM / CLMM CPI の例をミラーリングします。このサイトが入力されたら、一般化されたテンプレートについては [`sdk-api/rust-cpi`](/ja/sdk-api/rust-cpi) を参照してください。

## 落とし穴

- **フィー分割算術のオフバイワン。** `total_share` が正確に `lp_share + creator_share + protocol_share` でない場合、`Initialize` は `InvalidFeeShares` で戻ります。`totalShare` を合計に等しく設定してください。
- **許可されていないクォートミントを使用する。** `launch_config.allowed_quote_mints` は固定リストです。他のミントを渡すと戻ります。最初に `raydium.launchpad.getConfig()` で確認してください。
- **メタデータサイズ。** 長い `uri` 文字列は Metaplex CPI を予算を超えてプッシュします。`uri` を約 200 文字以下に保ってください。ほとんどの CDN ホスト JSON メタデータは簡単に適合します。
- **グラデュエーションレース。** 自動化されたボットは `quote_reserve_real` を監視し、しきい値交差の 1～2 スロット以内に `Graduate` をフロントランします。これは無害です。レントのみがかかります。ただし、UI は `status` 遷移を高速イベントとして扱う必要があります。
