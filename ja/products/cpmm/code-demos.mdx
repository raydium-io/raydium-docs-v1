## CPMM プールの作成

ソース：[`src/cpmm/createCpmmPool.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/createCpmmPool.ts)

```ts
import { PublicKey } from "@solana/web3.js";
import BN from "bn.js";
import { getCpmmPdas, CREATE_CPMM_POOL_PROGRAM, CREATE_CPMM_POOL_FEE_ACC }
  from "@raydium-io/raydium-sdk-v2";

const mintA = new PublicKey("So11111111111111111111111111111111111111112"); // wSOL
const mintB = new PublicKey("EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"); // USDC

// 1. 手数料設定を選択します。index=0 は 0.25% ティアです。
const feeConfigs = await raydium.api.getCpmmConfigs();
const feeConfig  = feeConfigs.find((c) => c.index === 0)!;

// 2. ミントメタデータを取得して、SDK が Token-2022 拡張機能を処理できるようにします。
const mintAInfo = await raydium.token.getTokenInfo(mintA);
const mintBInfo = await raydium.token.getTokenInfo(mintB);

// 3. トランザクションを構築します。
const { execute, extInfo } = await raydium.cpmm.createPool({
  programId:       CREATE_CPMM_POOL_PROGRAM,
  poolFeeAccount:  CREATE_CPMM_POOL_FEE_ACC,
  mintA:           mintAInfo,
  mintB:           mintBInfo,
  mintAAmount:     new BN(1_000_000_000),   // 1 SOL（9 デシマルを想定）
  mintBAmount:     new BN(   160_000_000),  // 160 USDC（160/SOL）
  startTime:       new BN(0),               // 即座にオープン
  feeConfig,
  associatedOnly:  false,
  ownerInfo:       { useSOLBalance: true },
  txVersion:       TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Pool created at", extInfo.address.poolId.toBase58());
console.log("Tx:", txId);
```

SDK が静かに処理する事項：

- PDA を導出する前にミントを token0/token1 の順序にソートします。
- 1 回限りの `create_pool_fee` を `poolFeeAccount` に支払います。
- 呼び出し元の関連トークンアカウントが不足している場合は作成します。
- 各側に対して正しいトークンプログラム（SPL Token vs Token-2022）を選択します。

確認後、ライブプール状態を取得できます：

```ts
const { poolKeys, poolInfo, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(
  extInfo.address.poolId,
);
```

## スワップ（ベース入力）

ソース：[`src/cpmm/swap.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/swap.ts)

```ts
import { CurveCalculator } from "@raydium-io/raydium-sdk-v2";

const poolId = new PublicKey("<POOL_ID>");

// 1. RPC から直接現在のプール状態を読み込みます（API からではなく）。
const { poolInfo, poolKeys, rpcData } = await raydium.cpmm.getPoolInfoFromRpc(poolId);

const inputMint  = new PublicKey(poolInfo.mintA.address); // A → B をスワップ
const amountIn   = new BN(100_000_000);                   // 0.1 SOL
const slippage   = 0.005;                                 // 0.5%

// 2. ローカルで見積もります。SDK の CurveCalculator はオンチェーン数学をミラーリングします。
//    両側の Token-2022 転送手数料を含みます。
const baseIn = inputMint.equals(new PublicKey(poolInfo.mintA.address));
const swapResult = CurveCalculator.swap(
  amountIn,
  baseIn ? rpcData.baseReserve : rpcData.quoteReserve,
  baseIn ? rpcData.quoteReserve : rpcData.baseReserve,
  rpcData.configInfo!.tradeFeeRate,
);
const minimumAmountOut =
  swapResult.destinationAmountSwapped.muln(1 - slippage * 100).divn(100);

// 3. 構築して送信します。
const { execute } = await raydium.cpmm.swap({
  poolInfo,
  poolKeys,
  inputAmount: amountIn,
  swapResult,
  slippage,
  baseIn,
  txVersion: TxVersion.V0,
});

const { txId } = await execute({ sendAndConfirm: true });
console.log("Swap tx:", txId);
```

注意：SDK は常に `getPoolInfoFromRpc` 内から RPC のプール状態を再フェッチします。署名しようとしているトランザクションの見積もりを `api-v3.raydium.io` から取得しないでください。1 ブロック古い見積もりはランド時に `ExceededSlippage` にスリップする可能性があります。

## プロトコル・ファンド・クリエイター手数料の回収

ソース：[`src/cpmm/collectCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectCreatorFee.ts)、[`src/cpmm/collectAllCreatorFee.ts`](https://github.com/raydium-io/raydium-sdk-V2-demo/blob/master/src/cpmm/collectAllCreatorFee.ts)

プロトコルおよびファンド回収は権限ゲート付きのままです。クリエイター手数料には 2 つのパスがあります：既存のクリエイター署名 `CollectCreatorFee` と、追加の `CollectCreatorFeePermissionless` で、任意のペイヤーが呼び出せますが、クリエイターの正規 ATA にのみ転送できます。ピン留めされた SDK は既存の生ビルダーを公開します：

```ts
import {
  makeCollectProtocolFeeInstruction,
  makeCollectFundFeeInstruction,
  makeCollectCreatorFeeInstruction,
} from "@raydium-io/raydium-sdk-v2";

// PDA と権限はプール作成時に設定されました。正規シードについては
// reference/program-addresses を参照してください。SDK が好みに応じてヘルパーを公開します。
```

<Warning>
  `@raydium-io/raydium-sdk-v2@0.2.42-alpha` はまだ `CollectCreatorFeePermissionless` のビルダーを公開していません。SDK リリースがそれを追加するまで、アップグレードされた CPMM IDL から構築するか、プログラムを直接呼び出してください。`makeCollectCreatorFeeInstruction` を再利用しないでください：新しいインストラクションは異なるディスクリミネータを持ち、クリエイター署名者 / `amm_config` の位置を別の `payer` と署名しない `creator` アカウントに置き換えます。
</Warning>

オフチェーンでは `PoolState` から直接発生した手数料を読み取ることができます：

```ts

console.log("Accrued protocol fee token0:", pool.protocolFeesToken0.toString());
console.log("Accrued protocol fee token1:", pool.protocolFeesToken1.toString());
```

## Rust CPI スケルトン

独自の Anchor プログラムから CPMM を呼び出したい場合（例えば、デポジターの代わりにスワップするボールト）、CPI コンテキストは次のようになります。アカウント順序は [`products/cpmm/instructions`](/ja/products/cpmm/instructions) に従います。

```rust
// Cargo.toml
// raydium-cp-swap = { git = "https://github.com/raydium-io/raydium-cp-swap" }
// anchor-spl       = "0.30"

use anchor_lang::prelude::*;
use anchor_spl::token_interface::{TokenAccount, TokenInterface, Mint};
use raydium_cp_swap::cpi::accounts::Swap;
use raydium_cp_swap::cpi;
use raydium_cp_swap::program::RaydiumCpSwap;

#[derive(Accounts)]
pub struct ProxySwap<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,

    /// CHECK: validated by the CPMM program
    pub authority:     UncheckedAccount<'info>,
    /// CHECK:
    pub amm_config:    UncheckedAccount<'info>,
    #[account(mut)]
    /// CHECK:
    pub pool_state:    UncheckedAccount<'info>,

    #[account(mut)]
    pub input_token_account:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_token_account: InterfaceAccount<'info, TokenAccount>,

    #[account(mut)]
    pub input_vault:  InterfaceAccount<'info, TokenAccount>,
    #[account(mut)]
    pub output_vault: InterfaceAccount<'info, TokenAccount>,

    pub input_token_program:  Interface<'info, TokenInterface>,
    pub output_token_program: Interface<'info, TokenInterface>,

    pub input_token_mint:  InterfaceAccount<'info, Mint>,
    pub output_token_mint: InterfaceAccount<'info, Mint>,

    #[account(mut)]
    /// CHECK: ring buffer
    pub observation_state: UncheckedAccount<'info>,

    pub cpmm_program: Program<'info, RaydiumCpSwap>,
}

pub fn proxy_swap_base_input(
    ctx: Context<ProxySwap>,
    amount_in: u64,
    minimum_amount_out: u64,
) -> Result<()> {
    let cpi_accounts = Swap {
        payer:                ctx.accounts.payer.to_account_info(),
        authority:            ctx.accounts.authority.to_account_info(),
        amm_config:           ctx.accounts.amm_config.to_account_info(),
        pool_state:           ctx.accounts.pool_state.to_account_info(),
        input_token_account:  ctx.accounts.input_token_account.to_account_info(),
        output_token_account: ctx.accounts.output_token_account.to_account_info(),
        input_vault:          ctx.accounts.input_vault.to_account_info(),
        output_vault:         ctx.accounts.output_vault.to_account_info(),
        input_token_program:  ctx.accounts.input_token_program.to_account_info(),
        output_token_program: ctx.accounts.output_token_program.to_account_info(),
        input_token_mint:     ctx.accounts.input_token_mint.to_account_info(),
        output_token_mint:    ctx.accounts.output_token_mint.to_account_info(),
        observation_state:    ctx.accounts.observation_state.to_account_info(),
    };
    let cpi_ctx = CpiContext::new(
        ctx.accounts.cpmm_program.to_account_info(),
        cpi_accounts,
    );
    cpi::swap_base_input(cpi_ctx, amount_in, minimum_amount_out)
}
```

CPI が PDA として署名する場合（例えば、デポジターの代わりにボールトを管理する場合）、`CpiContext::new` を `CpiContext::new_with_signer` に置き換え、シードを渡します。

## よくある落とし穴

サポートチケットを開く前の短いチェックリスト：

- **ソート済みミント。** 導出した `poolState` PDA がオンチェーンプールと一致しない場合、おそらくミントのソートを忘れています。
- **古い API 見積もり。** `api-v3.raydium.io` からのリザーブ値を `CurveCalculator.swap` に渡さないでください。RPC から取得してください。
- **間違ったトークンプログラム。** Token-2022 ミントのボールトは SPL Token ではなく Token-2022 プログラムによって所有されています。常にプールの `token_0_program` / `token_1_program` フィールドを使用してください。
- **転送手数料ミントに対して過小評価されたスリッページ。** プールのいずれかの側が Token-2022 転送手数料ミントの場合、`minimum_amount_out` はボールトが送信するものではなく、ユーザーが実際に受け取るものの単位で表示される必要があります。
- **スワップで `NotApproved`。** `PoolState.status` を確認してください。管理者がそのプールのスワップを一時停止している可能性があります。ステータスビットマスクについては [`products/cpmm/instructions`](/ja/products/cpmm/instructions) を参照してください。
